# 第 13 章 度量空间 METRIC SPACES

<span style="color:#2471a3;">**[section]**</span> §13.1 引言 Introduction

实数系统 $\mathbb{R}$ 并不仅仅是对象的集合。它还具有各种我们在前面诸章中得以利用的结构。其中有允许我们对数进行加、减、乘、除运算的代数结构（algebraic structure）。还有由 $<$（或 $\leq$、$>$、$\geq$）给出的 $\mathbb{R}$ 上的序结构（order structure）。此外还有由 $|x-y|$ 给出的 $\mathbb{R}$ 中两两元素之间的距离（distance）概念。这些结构以各种方式相互作用。

事实上，我们正是借助这些结构来刻画实数系统 $\mathbb{R}$ 的：粗略地说，我们可以称 $\mathbb{R}$ 是唯一的完备有序域（complete ordered field）（习题 1.11.3）。这些结构相互作用的一些简单方式可见于本节末尾的习题（exercises）中。

现在，除了 $\mathbb{R}$ 之外，还有许多在分析学（analysis）中重要的对象集合。我们在较早的章节中已经遇到过其中若干（例如序列的集合或函数的集合）。其中许多具有自然的代数结构（不必然是它们构成域），自然的序结构（不必然满足 1.3 节中所列的公理），以及一个或多个自然的距离概念。

例如，考虑区间 $[0,1]$ 上连续函数构成的集合 $C[0,1]$。在通常的函数加法与乘法定义之下，$C[0,1]$ 并非域（field）。它的确满足另一种代数结构——代数（algebra）——的公理（见习题 13.1.2）。若当对每个 $x\in(0,1)$ 都有 $f(x)\leq g(x)$ 时记为 $f\leq g$，那么 $\leq$ 便提供了一种序结构，但这一结构并不满足 1.4 节为 $\mathbb{R}$ 所指明的公理。不过它的确满足另一组公理，即偏序集（partially ordered set）的公理。（习题 13.1.2 与 13.1.3 使这最后两条陈述精确化。）

在连续函数的两两之间，也存在若干可加以考虑的"距离"概念。我们将在本章看到其中一部分。我们将基于距离概念，在对象集合上发展一种抽象结构。由此得到的结构称为度量空间（metric space）。这种抽象结构可施加于任何非空集合上。

以抽象的方式来发展这些内容最为高效，但我们将花费大量时间把理论应用于具体的（concrete）度量空间。我们的具体例子将相当多样。特别是，我们的应用将包括这样的度量空间——其元素由若干截然不同的对象组成，例如序列（sequence）、函数与集合。

<span style="color:#2471a3;">**[section]**</span> ## 13.2 度量空间——具体例子（Metric Spaces—Specific Examples）

在 §1.10 中，我们通过绝对值的概念引入了实直线 $\mathbb{R}$ 的度量结构。对 $x, y \in \mathbb{R}$，我们把
```math
d(x, y) = |x - y|
```
称作 $x$ 与 $y$ 之间的距离。我们认定了距离函数（distance function）$d$ 所具有的四条性质：

1. $d(x, y) \geq 0$　[一切距离都是正的或零。]
2. $d(x, y) = 0$ 当且仅当 $x = y$　[不同的点彼此间隔一个正距离。]
3. $d(x, y) = d(y, x)$　[距离是对称的，即从 $x$ 到 $y$ 的距离与从 $y$ 到 $x$ 的距离相同。]
4. $d(x, y) \leq d(x, z) + d(z, y)$　[三角不等式；直接从 $x$ 走到 $y$ 不会比先走到 $z$ 再到 $y$ 更远。]

我们所做的与极限概念及收敛有关的所有工作，归根结底都建立在 $d$ 的这四条性质之上。研读过第 11、12 章中欧几里得空间（euclidean spaces）$\mathbb{R}^n$ 的读者已经看到，点 $x$ 与 $y$ 之间的欧几里得距离
```math
d(x, y) = \|x - y\|,
```
同样满足这些性质。

牢记这些事实，我们将把度量空间的定义建立在一种具有这些性质的度量之上。下列概念归功于莫里斯·勒内·弗雷歇（Maurice René Fréchet，1878–1973），他在 1906 年的博士论文中予以引入。"度量空间"（metric space）这个名称并非一开始就使用，而是后来在 1914 年由费利克斯·豪斯多夫（Felix Hausdorff，1868–1942）提出；他承接了弗雷歇的思想，在其上发展并加以推广，从而创立了如今被称为拓扑学（topology）的数学分支。度量空间在拓扑学的研究中起着根本性的作用。<span style="color:#7f8c8d">*（原书此处将 Hausdorff 生年误写为 1869，实为 1868 年 11 月 8 日生；译文已按史实勘误。）*</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 度量定义的四条公理并非互相独立——揪出冗余正是第一性原理的乐趣。由公理 (2)(3)(4) 可反推出公理 (1)：取中间点 $z=x$，则 $0=d(x,x)\le d(x,y)+d(y,x)=2d(x,y)$，立得 $d(x,y)\ge 0$，非负性是"免费的"。所以距离的全部几何内容都压在公理 (2)(3) 尤其三角不等式 (4) 上。公理 (2)"零距离当且仅当同一点"保证了极限的唯一性，可视为 6.042J 中等价关系的"同一性"层面被距离重新编码。三角不等式则是分析学一切"逐站逼近"策略的总发动机——它允许你经由中间点分步逼近目标，TBB 第 11 章紧致性里那些"先分区间、再并区间"的论证骨架都靠它。与 Strang 中范数公理 $\|x+y\|\le\|x\|+\|y\|$（也叫三角不等式）对照，可见范数正是"度量公理"与"线性结构"在向量空间上的交汇点。

<span style="color:#2471a3;">**[example]**</span>

**例 13.5（欧几里得 $n$ 维空间 Euclidean $n$-dimensional space）**：设
```math
\mathbb{R}^n = \mathbb{R} \times \mathbb{R} \times \cdots \times \mathbb{R}
= \{(x_1, x_2, \ldots, x_n) : x_i \in \mathbb{R},\ i = 1, 2, \ldots, n\}.
```
对 $x = (x_1, x_2, \ldots, x_n)$ 与 $y = (y_1, y_2, \ldots, y_n)$，定义
```math
d_2(x, y) = \sqrt{(x_1 - y_1)^2 + (x_2 - y_2)^2 + \cdots + (x_n - y_n)^2}.
```
一如既往，$d_2$ 是 $\mathbb{R}^n$ 上的一个度量（metric）。其中的三角不等式（第 (4) 式）可由 Cauchy–Schwarz 不等式（柯西–施瓦茨不等式）直接推出（参见 §11.2）。$\square$

<span style="color:#7f8c8d">*（译者注：下面一段紧接举例，引出度量空间的正式语言。）*</span>

当 $d$ 是集合 $X$ 上的一个度量时，我们把 $X$ 称为"配备"了度量 $d$ 的度量空间（metric space）。精确的说法体现在下面的定义之中，不过你大概会发现讲课时老师谈论度量空间的方式并没有这么正式。

<span style="color:#7f8c8d">*（页眉：度量空间 Metric Spaces）*</span>

<span style="color:#2471a3;">**[definition]**</span>
> <span style="color:#7f8c8d;">TBB §13.2, p.541</span>
**定义 13.6**：<span style="color:#00838f;">一个度量空间（metric space）是一个有序对 $(X, d)$，其中 $X$ 是非空集合，而 $d$ 是 $X$ 上的一个度量。</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 定义 13.6 的精髓在一个记号：度量空间是**有序对** $(X,d)$，而不是底集 $X$。这等于宣告：**集合 $X$ 本身不是度量空间，$X$ 配上度量的组合才是**。于是同一底集 $X$ 上若放两个不同的度量 $d$ 与 $e$，就得到两个不同的度量空间、可能刻画出完全不同的"哪个序列收敛"与"哪些集合开"。这与 6.042J 中你学的代数结构如出一辙——群也是 (carrier, 运算) 的对子，环、域同理，都是"结构挂在底集上"。这也呼应 CSAPP 中"同一个 bit 串，解释成 int 还是 float 取决于类型标签"：同一像素、同一函数集，解释成什么"距离"由你选定的度量标签决定。教材随即约定，上下文明确时可用 $X$ 简称整个空间，但你要清楚这是**记号省略**，不是把 $d$ 丢掉了。例 13.14 会再次用它敲打你：$C[a,b]$ 换一个积分度量就不再是 $M[a,b]$ 的子空间——底集相同、度量不同，空间即不同。

---

有时候，$X$ 上的这个度量可以由上下文得知。在这种情况下，我们常把记号加以简化，用"$X$"而不是"$(X, d)$"来称呼这个度量空间。特别是，当不会产生混淆时，我们约定 $\mathbb{R}$ 配备的是通常的欧几里得度量（euclidean metric）
```math
d(x, y) = |x - y|.
```
同一个集合 $X$ 上可以存在许多不同的度量。如果在讨论中同时涉及不止一个度量，我们就必须交代清楚，在讨论的某个特定位置考虑的究竟是哪一个度量。（参见习题 13.2.6，那里在空间 $\mathbb{R}^2$ 上给出了另外两个有趣的度量；习题 13.6.31 则说明，当两个度量同时使用而处理又不够严谨时，会引出怎样的错误。）

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 13.7 可以看成把例 13.5 的 Euclidean norm（欧氏范数）从有限个坐标一路推向无穷多个坐标：$\ell_2$ 由平方可和序列组成，即 $\sum x_k^2<\infty$，距离取 $d_2(x,y)=\sqrt{\sum(x_k-y_k)^2}$。你熟悉的"有限长向量"在这里被换成"无穷长向量"，但几何直觉没有变：$d_2$ 仍是勾股定理式的求和开方，只是求和从 $n$ 项变成了收敛级数。注意 $\sum x_k^2<\infty$ 这条限制不是摆设：度量必须是实值函数，若平方和发散，$d_2$ 会变成 $+\infty$，空间就不成其为度量空间。这正好是 Strang 线性代数（MIT 18.06）里 $\|x\|=\sqrt{\sum x_i^2}$ 的无限维版本，那一章的内积、正交、范数脚手架可以原样搬过来。顺带说，$\ell_2$ 上还有内积 $\langle x,y\rangle=\sum x_k y_k$，Cauchy–Schwarz（柯西–施瓦茨）不等式保证该级数绝对收敛，$\|x\|_2^2=\langle x,x\rangle$ 正好恢复范数——这是 Strang 内积一节可以无缝衔接的下一块跳板。以 David Hilbert（1862–1943）命名并非偶然：正是 Hilbert 系统研究这类平方可和序列空间，使它成为 20 世纪泛函分析与量子力学的发源地之一。量子力学里一个态正是 $\ell_2$（或其复版本）中的单位向量；内积结构是否完备、范数定义是否得当，直接决定理论能否自洽——这套脚手架你在 Strang 内积一节已经搭过，只是坐标从有限变成了可数无穷。值得立刻做的思想实验是代入例末的数：$x=\{3,4,0,\dots\}$、$y=\{0\}$ 时 $d_1=3+4=7$，$d_2=\sqrt{3^2+4^2}=5$，$d_\infty=\max\{3,4\}=4$。同一对点在不同度量下距离不同，这不是无伤大雅的记号差异：它预告了 §13.5 之后"同一个收敛命题，换一个度量就可能失效"的主题——一个序列可以在这个度量下逼近目标、在另一个度量下远离目标。

```math

```
替换为序列
```math
x = \{x_1, x_2, \ldots\}
```
时，欧几里得 $n$ 维空间 $\mathbb{R}^n$ 的推广便自然出现。令 $\ell_2$ 表示所有满足
```math
\sum_{k=1}^{\infty} (x_k)^2 < \infty
```
的实数序列构成的集合。对 $x = \{x_1, x_2, \ldots\}$ 与 $y = \{y_1, y_2, \ldots\}$，定义
```math
d_2(x, y) = \sqrt{\sum_{k=1}^{\infty} (x_k - y_k)^2}.
```
由此得到的度量空间 $\ell_2$ 通常称为经典（sequential）Hilbert 空间，以当时最重要且最具影响力的数学家之一 David Hilbert（1862–1943）命名。我们来验证 $d_2$ 是 $\ell_2$ 上的一个度量（metric）。显然对 $x, y \in \ell_2$，$d_2(x, y) \ge 0$，但我们还必须检验 $d_2(x, y)$ 是有限的。由初等不等式
```math
(x_k \pm y_k)^2 \le 2(x_k^2 + y_k^2)
```
我们看到，级数 $\sum_{k=1}^{\infty} x_k^2$ 与 $\sum_{k=1}^{\infty} y_k^2$ 的收敛可推出级数 $\sum_{k=1}^{\infty} (x_k - y_k)^2$ 的收敛。因此对所有 $x, y \in \ell_2$，均有 $d_2(x, y) < \infty$。显然，$d_2(x, y) = 0$ 当且仅当 $x = y$。对称性条件（第 (3) 式）也是显然的。

我们再来验证三角不等式（triangle inequality）。在此空间中，它取如下形式
```math
\sqrt{\sum_{k=1}^{\infty} (x_k - y_k)^2} \le \sqrt{\sum_{k=1}^{\infty} (x_k - z_k)^2} + \sqrt{\sum_{k=1}^{\infty} (z_k - y_k)^2}.
```

## <span style="color:#c0392b;">13.3.2 函数空间（Function Spaces）</span>

当我们所指的度量空间的元素是函数时，我们常用"函数空间（function space）"这一术语。函数空间在二十世纪分析学（analysis）的发展中扮演了重要角色。

<span style="color:#2471a3;">**[example]**</span>
> <span style="color:#7f8c8d;">TBB §13.3, p.545</span>
**例 13.10**：我们用 $C[a, b]$ 表示 $[a,b]$ 上连续函数构成的集合。为了界定两个连续函数 $f$ 与 $g$ 之间的"距离"，我们度量它们图像曲线上各点之间的最大竖直（vertical）距离。于是我们采用如下的度量（metric）：

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 13.10 第一次真正把"函数"当作"点"落实成度量：$C[a,b]$ 中两个函数 $f,g$ 的距离取它们图像的最大竖直间隔 $d(f,g)=\max_{a\le t\le b}|f(t)-g(t)|$。这里用 $\max$ 而非 $\sup$ 是合法且要紧的：因为 $f,g$ 连续，$|f-g|$ 也连续，而闭区间上的连续函数必取最大值——这正是前几章连续函数部分的极值定理（Extreme Value Theorem）在新场景里被再次征用（其本质是 $[a,b]$ 的紧致性（compactness），本章稍后会给出一般形式）。这个距离的几何直觉是"最严格的一位裁判"：只要在某一个点 $t$ 上两个函数差得很远，整个距离就被拉大，哪怕在其余位置几乎重合。不妨代入 $f(t)=t$、$g(t)=t^2$（$t\in[0,1]$）：$d(f,g)=\max_{t\in[0,1]}(t-t^2)=1/4$，最大值在 $t=1/2$ 取到；与例 13.14 的积分距离 $1/6$ 对比，同一对函数被两种度量打了不同的分。它与第 9 章的一致收敛有直通关系：$d(f_k,g)<\varepsilon$ 的意思正是对**所有** $t\in[a,b]$ 同时有 $|f_k(t)-g(t)|<\varepsilon$，即一致收敛定义里的那个公共 $\varepsilon$；所以 $d(f_k,g)\to0$ 意味着**在全区间同步逼近**，不再允许个别点拖后腿。这个 $\max$ 定义满足度量三公理也不难验证：三角不等式来自对每个 $t$ 有 $|f(t)-h(t)|\le|f(t)-g(t)|+|g(t)-h(t)|$，先对右边取 $\max$ 再对左边取 $\max$ 即可。对照例 13.14 的积分度量你会看到鲜明对比：那里是平均差异说了算，这里是最大差异说了算。两个度量并存于同一底集 $C[a,b]$，正是理解定义 13.6 为什么强调"度量是空间的一部分"的最好注脚：同一个集合配上不同度量，就变成不同的度量空间，收敛与逼近的含义也随之改变。

---
```math
d(f, g) = \max_{a \le t \le b} |f(t) - g(t)|.
```

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 13.11 的改动只有一字之差：把 $\max$ 换成 $\sup$，而动机是第一位的——底集变了。把底集从连续函数 $C[a,b]$ 扩成有界函数 $M[a,b]$ 后，$|f-g|$ 不再保证连续，闭区间上的最大值未必取得到。形式地写，$M[a,b]$ 上的 sup 度量是 $d_\infty(f,g)=\sup_{a\le t\le b}|f(t)-g(t)|$；三条公理照旧成立，三角不等式的证法与连续情形一字不差：对每个 $t$，$|f(t)-h(t)|\le|f(t)-g(t)|+|g(t)-h(t)|\le d_\infty(f,g)+d_\infty(g,h)$，左边取 $\sup$ 即得。一个直观例子：在 $[0,1]$ 上取 $g=0$，$f(t)=t$（$0\le t<1$）、$f(1)=0$，则 $|f-g|$ 的上确界是 1，却没有一个点真的取到 1：$t$ 越接近 1 差越接近 1，却永远差一点。但你仍可以用 $\sup$ 描述上确界距离：$f,g$ 有界保证 $|f-g|$ 有上界，实数的完备性（completeness）保证有界非空集合的上确界作为实数存在，它不必真的被某个点顶到。所以规则很简单：**能保证取到用 $\max$，不能保证就用 $\sup$，两者恰在连续情形不谋而合**（教材特意点出：$f,g$ 连续时两个度量一致）。这正是你在第 9 章一致收敛定义里早已遇到的上界—上确界之辨，现在被抬升为度量定义里的语法问题。进一步看，$C[a,b]$ 是 $M[a,b]$ 中由连续函数组成的子集；在 sup 度量下，$M[a,b]$ 中的收敛 $d_\infty(f_k,g)\to0$ 恰好就是一致收敛——每个点处的差都被同一个 $\varepsilon$ 控制。这既是第 9 章的复习，也是本章稍后一致收敛正式登场前的第一块跳板。

```math

```
<span style="color:#7f8c8d">（上式即原文标号 (3)。）</span>
这常被称为上确界度量（supremum metric，sup metric）。易于验证 $(M[a,b], d)$ 是一个度量空间。尤其要注意的是，如果 $f$ 与 $g$ 是连续函数，那么这个度量所赋的距离 $d(f, g)$，与前一例中 $C[a,b]$ 空间里那个度量所赋的距离相同。$\square$

这两个例子引入了度量空间的"子空间（subspace）"这一重要概念。有界函数空间 $M[a,b]$ 在自身内部含有连续函数空间 $C[a,b]$，并且两者的度量是相一致的。

**注（Note）**：既然我们的主题是度量空间，我们打算把子空间理解为相对于该结构（即度量）而言的。你也可能曾在线性代数向量空间（vector space）的背景下学过"子空间"；那完全是另一种含义，你应当避免混淆这两种含义。

**定义 13.12**：若 $(X, d)$ 是一个度量空间且 $A \subset X$，则称 $(A, d)$ 为 $(X, d)$ 的一个子空间。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 定义 13.12 语义很薄：$A\subset X$ 配上同一个度量 $d$ 就是度量空间意义下的子空间（metric subspace）$(A,d)$。形式上说，子空间里的度量就是 $d$ 限制在 $A\times A$ 上的函数 $d|_A$；因为三条公理对 $X$ 中一切点都成立，限制到 $A$ 上自然一条不少。但教材特意加注提醒你别跟 Strang 线性代数（MIT 18.06）里的子空间混淆，这是两套完全不同的结构。线性子空间要求**对加法与数乘封闭**：像过原点的平面，向量随便拉伸、叠加都还留在里面；度量子空间**只要求继承同一个度量**，除 $A$ 是 $X$ 的子集外别无他求，所以 $\mathbb R$ 的任意非空子集（连 $\mathbb Q$、Cantor 集都行）自动成为度量空间。线性子空间的反例随手可得：$\mathbb R^2$ 中不过原点的直线，向量一相加就滑出去，因此不是线性子空间；但它作为 $\mathbb R^2$ 的度量子空间没有任何问题。第二个反差在收敛上：$X$ 中收敛的序列在子空间 $A$ 中**不一定**收敛——教材在子空间一节的注给出范本：$1/n\to0$ 在 $\mathbb R$ 和子空间 $[0,1]$ 中都成立，但在子空间 $(0,1)$ 中不成立，因为极限点 $0\notin(0,1)$。收敛在子空间里可继承的判据也很干净：若 $a_k\to a$ 在 $X$ 中成立且 $a\in A$，则在 $(A,d)$ 中也成立，因为判定式 $d(a_k,a)\to0$ 根本没变；反之若 $a\notin A$，$(A,d)$ 里根本没有名为 $a$ 的点，收敛无从谈起。可以类比 MIT 6.042J《计算机科学中的数学》里"子集继承性质"与"对运算重新封闭"的区分：度量子空间更接近"截取"——把距离函数限制到子集上即可；线性子空间更接近"封闭"——少了封闭性就塌缩，连子空间都不是。

## <span style="color:#c0392b;">§13.4 收敛（Convergence）</span>

我们回忆一下，实数序列（sequence）$\{x_k\}$ 收敛到（converges to）$x_0$，当且仅当 $|x_k - x_0|$ 收敛到零，也就是说，当且仅当
```math
d(x_k, x_0) \to 0,
```
其中 $d$ 是通常的度量（metric）。这种收敛的含义可以推广到任意度量空间（metric space）上。

<span style="color:#2471a3;">**[definition]**</span>
> <span style="color:#7f8c8d;">TBB §13.4, p.548</span>
**定义 13.15**：设 $(X, d)$ 是一个度量空间。设 $\{x_k\}$ 是 $X$ 中成员构成的一个序列，并设 $x_0 \in X$。如果 $\lim_{k\to\infty} d(x_k, x_0) = 0$，我们就说 $\{x_k\}$ 收敛到 $x_0$，并记作 $\lim_{k\to\infty} x_k = x_0$ 或 $x_k \to x_0$。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 定义 13.15 是全章最重要的归约装置：空间中序列收敛 $x_k\to x_0$，**定义就是实数序列 $d(x_k,x_0)\to0$**。它把任意度量空间里陌生的收敛问题，一步译回你最熟的实数列极限——这正是 CLRS 式归约：把新问题的可解性压到旧问题上，度量 $d$ 就是那台"翻译机"。代价是要记住两点。一是**收敛是空间连同极限点的整体性质**：序列必须在某点收敛，极限点必须落在空间里（教材在子空间与多项式空间两处的注给出范本：$(0,1)$ 里 $1/n$ 不收敛，因为 $0\notin(0,1)$；$P[0,\tfrac12]$ 里几何级数部分和 $s_n(t)=\sum_{k=0}^{n}t^k=(1-t^{n+1})/(1-t)$ 在 $[0,\tfrac12]$ 上一致收敛到 $1/(1-t)$——尾差 $t^{n+1}/(1-t)\le(1/2)^n$，因为 $t\le1/2$ 时 $1-t\ge1/2$，一个与 $t$ 无关的量控制住整个区间——但 $1/(1-t)$ 不是多项式，故该序列在 $P[0,\tfrac12]$ 里不收敛）。二是**收敛依赖度量**：定义里明确由 $d$ 判定，换一个 $d$ 就等于换一套"哪些序列算收敛"，除非两个度量等价（equivalent metrics）到收敛类一致（这指向习题 13.4.9 与 13.4.12 的框架）。最有价值的即时验证是习题 13.4.6(a)：证明极限唯一。短证如下：若 $x_k\to a$ 且 $x_k\to b$，三角不等式给出 $0\le d(a,b)\le d(a,x_k)+d(x_k,b)\to0$，夹逼得 $d(a,b)=0$，再由"零距离当且仅当同点"得 $a=b$——这里三角不等式与恒等公理缺一不可。

---

由度量空间中序列收敛的这个定义方式可以清楚地看到，在 $\mathbb{R}$ 中（配以通常度量）的收敛，正是我们迄今所研究的收敛概念本身。那么在其他度量空间中，哪些序列会收敛呢？

接下来的几个例子以及部分习题将对这一点加以阐明。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 13.16 给出一个可命名的模板——**坐标化—夹逼论证**。目标是把 $d_2(x_n,z)\to0$ 等价地拆成每个坐标收敛。手段是写出上下夹住的两串不等式：记 $u=|a_n-c|$、$v=|b_n-d|$，则 $u\le d_2(x_n,z)\le u+v$（$v$ 同理）。左边 $u\le d_2$ 说明 $d_2\to0$ 时每个坐标差被压着趋于 0，即 $d_2$-收敛 $\Rightarrow$ 逐坐标收敛；右边 $d_2\le u+v$ 说明逐坐标收敛时 $d_2$ 被夹着趋于 0，即逐坐标收敛 $\Rightarrow d_2$-收敛。两次夹逼一合，等价性到手。这套论证的几何实质是：欧氏距离 $\sqrt{u^2+v^2}$ 被两个坐标差及其和从两侧夹住，三者同趋于零。这个模板只对乘积结构空间成立：$\mathbb R^n$ 与例 13.16 能这么拆，是因为坐标差精确控制着欧氏距离。习题 13.4.3/13.4.4 立刻反将一军：在 $\ell_2$ 里逐坐标收敛**不足以保证** $d_2$-收敛——标准单位向量 $e_n$（第 $n$ 个坐标是 1）逐坐标都趋于 0，但 $d_2(e_n,0)=1$ 不趋于 0；也可构造前 $n$ 个坐标各为 $1/\sqrt n$ 的序列，让 $n$ 个"小尾巴"累积出 1 的距离。但在 Hilbert 立方体 $H=\{(x_k):|x_k|\le1/k\}$ 里又成立了：坐标被 $1/k$ 快速压缩，第 $K$ 项以后的尾差平方和 $\sum_{k>K}4/k^2$ 可以被 $K$ 控制得任意小，前 $K$ 个坐标再用有限维夹逼，于是逐坐标收敛推出 $d_2$-收敛。这是维度从有限到无穷的第一道真正门槛，也是后面紧致性（compactness）与坐标压缩思想的预告。

```

```

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 13.17 应作为向第 9 章（函数列与函数项级数）的一次精确回访来读。设 $X$ 为 $[a,b]$ 上的连续（或至少是有界）函数全体，赋以 sup 度量（sup metric）$d(f,g)=\sup_{a\le t\le b}|f(t)-g(t)|$，则 $d(f_k,g)\to0$ 的 $\varepsilon$-$N$ 展开是：对每个 $\varepsilon>0$，存在 $N$，使 $k\ge N$ 时对所有 $t\in[a,b]$ 同时成立 $|f_k(t)-g(t)|<\varepsilon$。这正是你已在第 9 章学过的一致收敛（uniform convergence，见 TBB §9.3 与习题 9.3.12 的刻画），一字不差。机制在于 $\sup$ 是全局量：它在所有点 $t$ 上一并把差距压下去，使逼近误差在全区间由一个与位置无关的数 $\varepsilon$ 控制，这就是"一致"的本意。对照之下，逐点收敛（pointwise convergence）只要求对每个固定的 $t$、每个 $\varepsilon$，存在可以依赖 $t$ 的 $N$；各点误差各自趋于零，但快慢可以没有任何统一节奏。经典例子 $f_k(t)=t^k$（$0\le t\le1$）逐点趋于 $g$（$t=1$ 处为 $1$，其余点为 $0$），但 $\sup|f_k-g|=1$ 不趋于零，故不一致收敛；几何上，函数在 $t=1$ 附近隆起一个越来越窄而高度始终为 $1$ 的"尖坡"。现在第 13 章给了你一个更漂亮的视角：一致收敛不再是一个悬空的"加强版"定义，而是函数空间在某个具体度量下的距离趋于零，从而被统一进"度量→距离→极限"的机器。反过来也要警惕：同一底集换一个度量，收敛含义就改变。若换成积分度量 $e(f,g)=\int_a^b|f(t)-g(t)|\,dt$，$e(f_k,g)\to0$ 只表示平均误差趋于零，即平均收敛（$L^1$ convergence），它允许个别点出现越来越窄的尖峰，因而推不出一致收敛；反之，一致收敛因误差有全局上界，必推出 $L^1$ 收敛。把例 13.11、例 13.14、例 13.17 与习题 13.4.13 串起来，便是函数空间里"度量决定收敛"的完整闭环：先选定距离，才有资格谈逼近；第 9 章那些与一致收敛绑定的事实（连续函数列的一致极限连续、积分与极限可交换等）本质上是这个特定度量 $d$ 下的定理，换一个 $d$，前提就被抽走。

---
```math
d(f, g) = \sup_{a \le t \le b} |f(t) - g(t)|.
```
于是 $d(f_k, g) \to 0$ 当且仅当
```math
\sup_{a \le t \le b} |f_k(t) - g(t)| \to 0.
```
我们曾在（习题 9.3.12 中）看到，这一条件刻画了一致收敛。$\square$

## <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">§13.5 度量空间中的集合（Sets in a Metric Space）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> §13.5 的这一排定义，本质上是把你早已在 $\mathbb{R}$（TBB 第 4 章，尤其 §4.2–§4.4）和 $\mathbb{R}^n$（TBB §11.2–§11.3）里学过的词汇，原封不动地搬到任意度量空间 $X$ 上，唯一的改动是把 $|x-y|$ 或欧氏距离换成抽象度量 $d$。纲领只有一条：把开球（open ball）$B(x_0,r)=\{x\in X:d(x_0,x)<r\}$ 当作唯一的"原子"，其余概念都从它生长出来——开集（open set）是每点都能被一个小球完全垫住的集合；闭集（closed set）是补集为开集的集合；邻域（neighborhood）是含 $x$ 的开集；内点与内部（interior point/interior）用"存在一个小球整个落在集合内"定义；聚点（point of accumulation）用"每个邻域都含 $A$ 中无穷多点"定义；孤立点（isolated point）则要求有一个只含该点自身的小球；闭包（closure）是集合与其聚点的并。这一体系与 TBB 第 11 章用欧氏球界定 $\mathbb{R}^n$ 开闭集的做法完全平行，只是半径判据换成了抽象的 $d$。术语上请注意：聚点的定义措辞是"每个邻域含 $A$ 的无穷多点"，它与"每个去心邻域都含 $A$ 的点"在度量空间中等价（不断缩小半径即可），本书措辞更贴近第 4 章；中译建议统一沿用"聚点"而不用"极限点"，以免与序列极限混淆（glossary 已如此建议）。这块地基直接服务后续：开集导出开覆盖（open cover），$X$ 紧致（compact）定义为每个开覆盖有有限子覆盖，于是你在第 4 章（$\mathbb{R}$）与第 11 章（$\mathbb{R}^n$）学过的紧致性、Bolzano–Weierstrass 性质，将在 §13.12 换上度量空间的抽象外衣重建。最后把 CSAPP（Computer Systems: A Programmer's Perspective，计算机系统导论）的浮点比喻说精确：开球 $B(x,\varepsilon)$ 就是把"两个对象在误差 $\varepsilon$ 内不可区分"这条判据形式化；CSAPP 第 2 章用机器精度（machine epsilon）刻画一次舍入的一致误差界，本质上就是在某个具体度量下画半径为 $\varepsilon$ 的球。换一个度量，等于换掉"足够接近"的判据，后续收敛与连续的结果自然跟着变。

本节使用以下记号与背景：$X$ 之前已是指配了度量（metric）$d$ 的非空集合 $X$；$d$ 也写作距离函数（distance function）。为发展收敛（convergence）的概念，我们需要把第 3 章中针对 $\mathbb{R}$、第 11 章中针对 $\mathbb{R}^n$ 所讨论的一些概念推广（extend）到任意度量空间（metric space）之上。作为起步，你也许希望在 $\mathbb{R}^2$ 中绘制图形来示意这些概念。但要获得对这些概念的切实感受，我们还必须拥有大量的例子，可参见本节末尾的习题。

下面列出本节关于度量空间中集合的框架性定义。

<span style="color:#2471a3;">**[definition]**</span>
> <span style="color:#7f8c8d;">TBB §13.5, p.552</span>
**框架定义（约定惯例）**：
<span style="color:#7f8c8d">*（注：以下 1–13 与下一书页（553）的定义 14–17，均为原书 §13.5 逐条列出的编号定义清单，这里沿用原书编号 1–17，并非本书官方定义的编号。）*</span>

1. 对于 $x_0 \in X$ 与 $r > 0$，集合
```math
B(x_0, r) = \{x \in X : d(x_0, x) < r\}
```
称为以 $x_0$ 为中心、以 $r$ 为半径的**开球**（open ball）。<span style="color:#00838f">（§13.5 核心定义句）</span>

2. 集合
```math
B[x_0, r] = \{x \in X : d(x_0, x) \le r\}
```
称为以 $x_0$ 为中心、以 $r$ 为半径的**闭球**（closed ball）。<span style="color:#00838f">（核心定义句）</span>

3. 若对每个 $x_0 \in G$ 均存在 $r > 0$ 使得 $B(x_0, r) \subset G$，则称集合 $G \subset X$ 为**开集**（open set）。<span style="color:#00838f">（核心定义句——开集由开球刻画）</span>

4. 若集合 $F \subset X$ 的补集（complement）$X \setminus F$ 是开集，则称 $F$ 为**闭集**（closed set）。<span style="color:#00838f">（核心定义句——闭集为补集开者）</span>

5. 对于非空集合 $E$，$E$ 的**直径**（diameter）是数
```math
\sup\{d(x, y) : x, y \in E\},
```
该量可能为无穷大。<span style="color:#00838f">（核心定义句）</span>

6. 若非空集合 $E$ 满足 $\sup\{d(x, y) : x, y \in E\}$ 有限（即集合 $E$ 具有有限的直径），则称 $E$ 为**有界**（bounded）。<span style="color:#00838f">（核心定义句——有界即直径有限）</span>

7. $x_0$ 的一个**邻域**（neighborhood）是任何包含 $x_0$ 的开集 $G$。<span style="color:#00838f">（核心定义句）</span>

8. 若 $G = B(x_0, \varepsilon)$，我们称 $G$ 为 $x_0$ 的 **$\varepsilon$-邻域**（$\varepsilon$-neighborhood）。<span style="color:#00838f">（核心定义句）</span>

9. 若 $x_0$ 具有一个被包含（contained）在 $A$ 中的邻域，则称点 $x_0$ 为集合 $A$ 的一个**内点**（interior point）。<span style="color:#00838f">（核心定义句）</span>

10. 集合 $A$ 的**内部**（interior）由 $A$ 的所有内点组成，记作 $A^\circ$，有时也记作 $\mathrm{int}(A)$。<span style="color:#00838f">（核心定义句）</span>

11. 若 $x_0$ 的每个邻域（neighborhood）中都含有 $A$ 的无穷多个点，则称点 $x_0 \in X$ 为 $A$ 的一个**聚点**（limit point），或称**累点/极限点**（point of accumulation）。<span style="color:#00838f">（核心定义句）</span>

12. 集合 $A$ 的一个**孤立点**（isolated point）是这样一个点 $x_0$：它有一个邻域 $G$，使得 $G \cap A = \{x_0\}$。<span style="color:#00838f">（核心定义句）</span>

13. 集合 $A$ 的**闭包**（closure）$\overline{A}$ 由所有属于 $A$ 或为 $A$ 的聚点的点组成。<span style="color:#00838f">（核心定义句）</span>

这些定义把第 5 章与第 11 章中关于开集、闭集、邻域、内部、聚点、孤立点与闭包的概念统一到任意度量空间 $X$ 之中，为后续建立收敛刻画提供框架基础。

<span style="color:#7f8c8d">*（注：以下定义 14–17 与上一页（书页 552）的框架定义 1–13，均为原书 §13.5 逐条列出的编号定义清单，这里沿用原书编号 1–17，并非本书官方定义的编号。）*</span>

14. **边界点**（boundary point）：$A$ 的一个边界点是这样的点 $x_0$：$x_0$ 的每一个邻域（neighborhood）中既至少含有 $A$ 的一个点，又至少含有补集（complement）$X \setminus A$ 的一个点。<span style="color:#00838f">（核心定义句——边界点处处同时接触集合与其外部）</span>

15. 设 $A$ 与 $B$ 是 $X$ 的子集。若 $A \supset B$，或者等价的、以 $B$ 中任一点为中心的每一个开球（open ball）都含有 $A$ 的一个点，则称 $A$ 在 $B$ 中**稠密**（dense）。（注意：这并不要求 $A$ 是 $B$ 的子集。）若 $A = X$，我们干脆称 $A$ 是稠密的。<span style="color:#00838f">（核心定义句——稠密以开球交叠刻画）</span>

16. 度量空间 $X$ 中的集合 $A$ 称为（在 $X$ 中）**无处稠密**（nowhere dense），若每一个开球 $B(x, \varepsilon)$ 都含有另一个开球 $B(y, \delta)$，使得 $B(y, \delta) \cap A = \emptyset$。<span style="color:#00838f">（核心定义句——任一开球内部都含有一个避开了 $A$ 的开球）</span>

17. 点 $x \in X$ 与**非空**集合 $A \subset X$ 之间的**距离**（distance）定义为
```math
\mathrm{dist}(x, A) = \inf\{d(x, y) : y \in A\}。
```
<span style="color:#00838f">（核心定义句——点到集距离即到集合内各点距离的下确界）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 到集合的距离 $\mathrm{dist}(x,A)=\inf\{d(x,y):y\in A\}$ 之所以用下确界（infimum）而不用最小值（minimum），是刻意为之：距离值集合 $\{d(x,y):y\in A\}$ 是 $\mathbb{R}$ 的非空子集，由实数确界原理，其下确界总存在；而最小值只有当某个 $y\in A$ 恰好实现这个最短距离时才存在。例如在 $\mathbb{R}$ 中取 $A=(0,1)$、$x=0$，则 $\mathrm{dist}(0,A)=\inf\{y:0<y<1\}=0$，但没有任何 $y\in A$ 与 $0$ 的距离等于 $0$，故最小值不存在。这个 $\inf$ 手法是把你"到集合距离必取到最近点"的离散直觉延拓到一般集合时的保险装置，之后在泛函分析、逼近论里还会反复出现；顺带记住一条判据：$\mathrm{dist}(x,A)=0$ 当且仅当 $x$ 属于 $A$ 的闭包。稠密的定义同样值得从第一性原理读：$A$ 在 $B$ 中稠密（dense），是说以 $B$ 中任一点为中心的开球都碰到 $A$，等价于 $B\subset\overline{A}$。它并不要求 $A$ 把 $B$"填满"，也不要求 $A=B$；稠密性不是大小概念——既不是基数大小，也不是长度大小——而是分布概念。典型样本：$\mathbb{Q}$ 在 $\mathbb{R}$ 中稠密，但 $\mathbb{Q}$ 可数、测度为零；这正是 TBB §6.2（稠密集）与 §6.8（零测度集）两个看似矛盾的性质可以并存的例子。把无处稠密（nowhere dense）并排看会更清楚：$A$ 无处稠密指 $\overline{A}$ 没有内点，即每个开球里都能再找到一个完全避开 $\overline{A}$ 的子开球；Cantor 集在 $\mathbb{R}$ 中无处稠密，而它被挖去的开区间的并集却稠密于 $[0,1]$——稠密与无处稠密争夺的正是开球内部是否还能掏出"空腔"。这把 §13.13 Baire 纲定理的种子埋下了：第一纲（first category）集定义为可数个无处稠密集的并，Baire 纲定理说完备度量空间自己不会是第一纲的。到泛函分析里，$\mathrm{dist}(x,A)$ 在 Hilbert 空间、$A$ 为闭线性子空间时升级为到该子空间的正交投影距离；这与线性代数（Strang, Introduction to Linear Algebra）里你在 $\mathbb{R}^n$ 中计算点到子空间最短距离（最小二乘的几何版）是同一机制。

---

你一定已经注意到，我们给出的诸如开集（open set）、闭集（closed set）、聚点（limit point）等等这些概念的**定义**，与早先在 $\mathbb{R}$ 中、在 $\mathbb{R}^n$ 中给出的相应定义完全类似。<span style="color:#00838f">（定义框架在一般度量空间中延续）</span>

因而毫不足怪：在 $\mathbb{R}$ 中关于这些概念的许多基本关系（elementary relations），都原样搬到任意度量空间（metric space）上来成立。<span style="color:#00838f">（$\mathbb{R}$ 中的关系可平移至一般度量空间）</span>

我们把其中一些比较重要的关系，放到本节末尾的习题（exercises）中去突出强调。

我们来看几个例子。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 请注意，开球、开集、闭集、聚点、闭包这一串定义，几乎是逐字地把第 4 章里 $\mathbb{R}$ 的定义与第 11 章里 $\mathbb{R}^n$ 的定义照搬到一般度量空间，唯一的替换是把 $|x-y|$（或欧氏距离）换成抽象的 $d(x,y)$。这是数学中把具体对象上已证成的定理提升为抽象定理的经典操作，其合法性来自一次"逐行审计"：检查证明里是否只用到了度量公理——非负性、对称性、三角不等式，以及 $d(x,y)=0\Leftrightarrow x=y$——而没有借用 $\mathbb{R}$ 的其它结构。凡是通过审计的论证自动获得度量空间版本，无需重写。具体地说，第 2 章里只靠 $\varepsilon$-$\delta$ 与三角不等式的序列收敛论证、第 4 章里只靠距离的开闭集论证，都在此列；例如数列极限的唯一性只用三角不等式，故对一切度量空间成立。反之，凡是借用了 $\mathbb{R}$ 的加法、乘法、序或确界原理的结果（如确界定理、单调收敛定理、代数极限定理中依赖乘法的部分），就不能原样平移，因为一般度量空间里没有加法、乘法与序。这一刀切下去，恰好划出两类性质：只用距离就能定义和证明的，属于后面要学的拓扑性质（topological property）的胚胎；必须依靠 $\mathbb{R}$ 特殊结构的，则留在实分析内部。你在第 11 章其实已经演练过同一套路：§11.2 用欧氏距离、§11.3 用欧氏球建立 $\mathbb{R}^n$ 的拓扑，只是把 $\mathbb{R}$ 换成 $\mathbb{R}^n$；现在 §13.5 把 $\mathbb{R}^n$ 再换成任意度量空间 $X$，路径完全一致。理解了这个"换底集、只留度量"的操作，后续同胚（homeomorphism）为什么只保持开集而不保持距离数值，也就顺理成章了。

## 例 13.18（离散空间）

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 13.18（离散空间）是你第一次见到度量空间可以和 $\mathbb{R}$ 在结构上如此"普通地不同"。取 $d(x,x_0)=1$（$x\ne x_0$），则每个单点集 $\{x_0\}$ 本身就是开球 $B(x_0,1)=\{x:d(x_0,x)<1\}$，于是单点集开；任意集合是单点集的并，故每个集合都开；再取补，每个集合又都闭。每一点都是孤立点（isolated point），因为以它为中心、半径 $1$ 的球里只有它自己；因此全空间没有聚点（accumulation point）——对任意点 $x$ 和任意集合 $A$，删去 $x$ 后的球 $B(x,1)\setminus\{x\}$ 是空集，聚点定义永远落空。$X$ 唯一的稠密子集就是 $X$ 自身：若 $A$ 稠密，则每个单点开球 $\{x\}$ 都必须与 $A$ 相交，所以每个 $x$ 都在 $A$ 中。这些结论初看与直觉相抵触，但逐条代回开集、聚点、稠密的定义，句句为真；抵触感恰恰来自你潜意识里把 $\mathbb{R}$ 的连续性当成了度量空间的必备品。第一性原理的教训是：在离散度量下，每个点被距离 $1$ 拉开是合法的，孤立不是病态，而是另一类度量空间的常态。离散空间因此成为一块试金石：凡在 $\mathbb{R}$ 中成立、在离散空间失效的命题，其证明必借用了 $\mathbb{R}$ 的特殊结构而非纯度量公理；例如"非空开集不可数""每个有界序列有收敛子列"在离散空间都垮掉（离散空间中序列收敛当且仅当最终常值）。另一个值得钉死的现象是开球闭包与闭球：在 $\mathbb{R}$ 中总有 $\overline{B(x,\varepsilon)}=B[x,\varepsilon]$，但在离散空间中 $B(x,1)=\{x\}$，其闭包仍是 $\{x\}$，而闭球 $B[x,1]=\{y:d(x,y)\le1\}=X$，两者差得最远（例 13.18 第 (11) 款正是此意）。把 CSAPP（Computer Systems: A Programmer's Perspective，计算机系统导论）的比喻说精确：同一底层硬件可以承载不同指令集架构（ISA）抽象，改接口就改变上层可见行为；同样，同一底集 $X$ 配上不同度量，等于改了"邻域"这台机器的接口，上层的收敛、连续、稠密行为随之改变。

<span style="color:#2471a3;">**[example]**</span>
> <span style="color:#7f8c8d;">TBB §13.5, p.553</span>
**例 13.18（离散空间）**：设 $X$ 是任意非空集合，令 $(X, d)$ 为离散空间（discrete space，见例 13.3）。设 $x_0 \in X$ 是空间中任一点。你应当自行验证下面每一句话都是真的。

1. $B(x_0, 1) = \{x_0\}$；
2. $X$ 中每一点都是**孤立点**（isolated point）；
3. $B[x_0, 1] = X$；
4. 每一个集合既开又闭（both open and closed）；
5. $X$ 是**有界**（bounded）的；
6. 每个包含 $x_0 \in X$ 的集合，都是 $x_0$ 的一个邻域；
7. $x_0$ 的每一个 $\varepsilon$-邻域，要么是 $\{x_0\}$，要么是 $X$；
8. 对每一个集合 $A \subset X$，内部 $A^\circ = A = \overline{A}$，且 $A$ 没有边界点（boundary points）；
9. $X$ 没有聚点（accumulation points）；
10. $X$ 唯一的稠密（dense）子集就是 $X$ 本身；
11. 开球 $B(x, \varepsilon)$ 的闭包（closure），未必是闭球（closed ball）$B[x, \varepsilon]$。

如果上述任何一句话似乎与你对度量空间的直觉相抵触（contradict），务必重新研读相关的定义。

$\square$

## 例 13.19（Cantor 集子空间）

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 13.19 把 Cantor 集 $K$ 与被挖去的开区间的中点集 $S$ 拼成子空间 $X=K\cup S$，造出一个奇特的度量空间。先回忆 Cantor 集（TBB §6.5）：它由 $[0,1]$ 不断挖去中间三分之一的开区间得到，剩下的 $K$ 是闭集、没有孤立点（即完全集 perfect set）、不可数（基数为连续统 $\mathfrak{c}$）且测度为零（§6.8）。现在把每次挖掉的开区间 $(a_k,b_k)$ 的中点 $m_k=(a_k+b_k)/2$ 全部收集成 $S$。在 $X$ 中，每个 $m_k$ 到 $K$ 和其余 $S$ 点的最近距离至少是 $(b_k-a_k)/2$，于是 $B(m_k,(b_k-a_k)/2)\cap X=\{m_k\}$，故 $S$ 在 $X$ 中是开的，且每点孤立；另一方面，$K$ 的每一点附近都有长度趋于零的挖去区间，其中点随之逼近该点，故 $S$ 在 $X$ 中稠密。于是同一空间里出现两副面孔：$K$ 闭、无孤立点、不可数；$S$ 开、全由孤立点组成、可数却稠密。第一性原理的洞察是：孤立点与聚点不是集合"天生"的标签，而是相对于它所在的度量空间而言的属性。同一个中点 $m_k$，在 $X$ 中是孤立点；把它放回 $\mathbb{R}$，它周围挤满实数，立刻不再是孤立点。这与你在第 4 章分析 $S=\{1/k:k\in\mathbb{N}\}$ 的结构互为镜像：那里每点孤立，唯一的聚点 $0$ 在集合之外；这里孤立点集 $S$ 的聚点集合恰是与它不交的 Cantor 集 $K$，把"孤立 + 稠密"的纠缠推到连续统规模。最后它给 §13.6.2 的同胚（homeomorphism）一个预告：度量空间关心的不是集合的"具体面貌"（点是谁、坐标是什么），而是谁在谁附近、谁孤立、谁稠密这些由开集表达的关系；孤立与否、稠密与否都由开集结构决定，因此在同胚下被保持，但一旦把 $X$ 换一个更大的空间嵌入，同一个点集的面貌就不同了。

<span style="color:#2471a3;">**[example]**</span>
> <span style="color:#7f8c8d;">TBB §13.5, p.554</span>
**例 13.19（Cantor 集子空间）**：设 $K$ 是把 **Cantor 集**（Cantor set）看作 $[0, 1]$ 的一个子空间（subspace）所得的集合。设 $\{(a_k, b_k)\}$ 是 $K$ 的补区间（complementary intervals）构成的序列，并令 $S$ 由这些区间的**中点**（midpoints）组成。<span style="color:#00838f">（构造空间背景）</span>

对我们的度量空间而言，取 $X = K \cup S$，并配备通常的实度量（usual real metric）。

1. $S$ 中每一点都是孤立点（isolated），而 $K$ 中没有任何点是孤立的；
2. $K$ 是闭集（closed）；
3. $S$ 是开集（open）；
4. $\overline{S} = X$，故 $S$ 是**稠密**（dense）的；
5. $S$ 的每个子集都是开集。

同样，请务必逐一核对这些论断。

$\square$

## 例 13.20（$C[a,b]$ 上确界度量开球）

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 13.20 把以函数 $f$ 为中心的开球 $B(f,\varepsilon)$ 几何化为夹在两条曲线 $f-\varepsilon$ 与 $f+\varepsilon$ 之间的一条函数带（图 13.2）。这是你第一次把开球从 $\mathbb{R}^n$ 中圆盘/球的直觉迁移到 $C[a,b]$ 这类无穷维函数空间，值得钉牢：$g\in B(f,\varepsilon)$ 当且仅当对所有 $t\in[a,b]$ 同时有 $|g(t)-f(t)|<\varepsilon$，即 $d_{\sup}(f,g)<\varepsilon$。这正是第 9 章一致收敛（uniform convergence）的几何化身：整条 $g$ 的图像被夹在宽 $2\varepsilon$ 的带子里，不允许任何一点越界。第一性原理的洞察是：上确界度量捕捉的是"全区间同时接近"——误差由一个与位置无关的数 $\varepsilon$ 统一控制；而点态收敛（pointwise convergence）只要求每个 $t$ 各自接近，允许某些点的误差在别的点已经很好时仍然很大。这正是 $C[a,b]$ 上一致收敛与逐点收敛的本质分歧。闭球 $B[f,\varepsilon]$ 的边界点则要求整条带子闭合（不等式取 $\le$），并且至少有一点贴到上界 $f+\varepsilon$ 或下界 $f-\varepsilon$；开闭球在函数空间里如此敏感，正是因为"全区间一致受控"这种全局条件容不得半点松动。与 CSAPP（Computer Systems: A Programmer's Perspective，计算机系统导论）的呼应可以讲精确：第 2 章用机器精度（machine epsilon）给出一次舍入的一致相对误差界——它同时约束所有可表示数，而不是对某个数单独成立；这与 $B(f,\varepsilon)$ 要求全区间误差被同一个 $\varepsilon$ 管住是同一思想。这个度量选择还有后续后果：稍后的例 13.32 会看到，在 sup 度量下积分算子 $S(f)(x)=\int_a^x f(t)\,dt$ 连续（误差最多被区间长度 $(b-a)$ 放大），而微分算子 $D(f)=f'$ 不连续（把微小的高频振荡放大成巨大斜率）；直观上说，积分是误差的"平滑器"，微分是高频误差的"放大器"。

**例 13.20（$C[a, b]$ 上确界度量开球）**：考虑空间 $C[a, b]$，配备**上确界度量**（supremum metric，见例 13.10）。设 $f \in C[a, b]$，并设 $\varepsilon > 0$。

1. 开球 $B(f, \varepsilon)$ 由所有满足如下条件的连续函数 $g$ 组成：
```math
|f(t) - g(t)| < \varepsilon \quad (\forall\, t \in [a, b])。
```
2. $g$ 是 $B(f, \varepsilon)$ 的一个**边界点**（boundary point），当且仅当对所有 $t \in [a, b]$ 都有 $|f(t) - g(t)| \le \varepsilon$，并且存在 $t_0$ 使得 $|f(t_0) - g(t_0)| = \varepsilon$。<span style="color:#00838f">（边界点界区间闭、且至少一点取到界）</span>

3. 从几何上看，$g \in B(f, \varepsilon)$ 当且仅当 $g$ 的**图象**（graph）严格地位于 $f - \varepsilon$ 与 $f + \varepsilon$ 的图象之间。<span style="color:#00838f">（开球几何化——图象严格夹于两条界曲线之间）</span>

4. 类似地，$g$ 是 $B(f, \varepsilon)$ 的一个边界点，当且仅当 $g$ 的图象位于 $f - \varepsilon$ 与 $f + \varepsilon$ 的图象之间，并且存在 $t_0$ 使得 $g(t_0) = f(t_0) + \varepsilon$ 或 $g(t_0) = f(t_0) - \varepsilon$。<span style="color:#00838f">（边界点在闭带内、且至少一处切到上界或下界）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这一段提出全章最关键的转念：同一个集合 $X$ 配两条度量 $d_1,d_2$，何时它们"本质相同"？答案是当两者诱导的开集族（family of open sets）完全相同，即 $\mathcal{G}_1=\mathcal{G}_2$ 时，称两度量等价（equivalent）。要理解为什么是开集族而非距离数值在起决定作用，只需看两个事实：收敛序列 $x_k\to x$ 的定义是"对 $x$ 的任一开邻域 $U$，最终有 $x_k\in U$"；连续性（定理 13.28）的刻画是"开集的原像是开集"。两者都只通过开集族说话，不关心 $d(x,y)$ 的具体大小。于是第一性原理的结论浮现：距离是更细的信息，开集族是更粗的骨架，而我们真正关心的收敛、连续等性质其实住在粗的那一层；两条度量只要骨架相同，行为就相同。这正是拓扑性质（topological property）概念的伏笔——§13.6.2 将用同胚（homeomorphism）严格定义"两个空间长相一样"：双射且双向连续，即双向保持开集。例 13.33 中 $d_1,d_2,d_\infty$（Minkowski 度量：曼哈顿距离、欧氏距离、最大坐标差）在 $\mathbb{R}^n$ 上给出相同开集，就是这个抽象概念的具体例证：三种距离公式数值不同，却定义同一收敛与同一连续。你也可以用 6.042J（Mathematics for Computer Science，计算机科学中的数学）里的等价关系来组织：在固定 $X$ 上"诱导相同开集族"是自反、对称、传递的等价关系（equivalence relation），把全体度量划分成等价类；"同胚"则是空间之间的等价关系（习题 13.6.20），两个同胚的空间具有相同的拓扑性质。CSAPP（Computer Systems: A Programmer's Perspective，计算机系统导论）的抽象层思想在这里有精确回响：上层程序（收敛/连续）只依赖接口（开集族），不依赖实现（具体度量公式）；改实现不改接口，上层行为不变——两个不同的度量公式只要编译出同一套开集，就是同一台"拓扑机器"。

# 度量空间中的集合（Sets in a Metric Space）

假设 $X$ 是一个配有两条不同度量 $d_1$ 与 $d_2$ 的集合。

于是我们便得到两个度量空间 $(X, d_1)$ 与 $(X, d_2)$。

一般说来，我们应当预期本节引入的这些概念在二者中会有所不同。

例如，某个集合关于其中一条度量可能是有界的（bounded）或闭的（closed），但关于另一条度量却并非如此。

不过在实践当中，这些性质之间往往会存在紧密的联系。

举例而言，可能发生这样的情况：关于 $d_1$ 为开的集合类 $\mathcal{G}_1$，恰好与关于 $d_2$ 为开的集合类 $\mathcal{G}_2$ 相同。

在此情形下，两个空间 $(X, d_1)$ 与 $(X, d_2)$ 将拥有完全相同的收敛序列类（class of convergent sequences）。

并且，在某种我们将在 §13.6.2 中使之精确化的意义下，这两个空间是相同的。

然而一般而言，这两个空间是不同的：底集 $X$ 相同，但各自的开集类（classes of open sets）并不相同。

于是，在一个空间中收敛的序列，在另一个空间中未必收敛（need not converge）。

习题 13.4.13 与 13.5.13 为这一现象提供了重要的例证（illustrations）。

<span style="color:#2471a3;">**[section]**</span> **13.6 函数**（Functions）

我们对于函数 $f:\mathbb{R}\to\mathbb{R}$ 的极限与连续性的研究，可以通过研究把某个度量空间映射到另一个度量空间的那些函数的相同概念来加以推广。

让我们先从一些把一个度量空间映到另一个度量空间的函数的例子开始。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b;">**例 13.21（Example 13.21）**</span>
> <span style="color:#7f8c8d;">TBB §13.6, p.558</span>

我们定义函数 $f:\mathbb{R}^2\to\mathbb{R}$ 为：

```math
f(x_1, x_2) = \frac{x_1 x_2}{x_1^2 + x_2^2}, \qquad f(0, 0) = 0.
```

我们自然会很关心这样的函数在 $\mathbb{R}^2$ 与 $\mathbb{R}$ 配备通常的欧几里得度量（见例 13.5）时会拥有哪些性质。

于是我们把它视为这样一个函数：定义域（domain）在一个度量空间中，而值域（range）落在另一个度量空间中。

$\square$

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这五个例子共同完成一次视角革命：不再把积分、微分、Fourier 系数看成对单个函数施加的运算，而是把运算本身当作从一个度量空间（metric space）到另一个度量空间的映射来研究。积分 $T(f)=\int_a^b f$ 把 $C[a,b]$ 映成实数，到达空间就是 $\mathbb{R}$ 配通常距离；变上限积分 $S(f)(t)=\int_a^t f$ 把函数映成函数，到达空间是连续函数空间配 $d(f,g)=\sup|f-g|$ 的上确界度量；微分 $D(f)=f'$ 从 $C^1$ 映到 $C$；Fourier 正弦系数 $F(f)=\{b_k\}$ 则把函数映成数列。这里用大写字母与算子（operator）、变换（transform）之名不是偶然：它们作用的对象本身就是函数。这正是泛函分析（functional analysis）的起点——空间里的点变成了函数，而函数变成了从函数空间到函数空间的算子。在 $\mathbb{R}$ 上你只研究数到数的函数，这里要研究函数到函数、函数到数列的映射，研究对象与被研究对象同时抬升一层，但工具——度量、开球、连续性——原封不动。  例 13.25 的落点值得单独拆开：$F(f)=\{b_k\}$ 把一个函数编码成一列系数，Bessel 不等式 $\sum b_k^2\le \frac{2}{\pi}\int_0^\pi f^2$ 则保证这列系数落在 $\ell_2$——平方可和序列空间，即满足 $\sum x_k^2<\infty$ 的数列全体——里。这里 $b_k=\frac{2}{\pi}\int_0^\pi f(x)\sin kx\,dx$ 取的是带因子 $2/\pi$ 的正弦系数，不等式方向与常数都依赖这个约定，读的时候要留意。这条不等式不是可有可无的技术细节：$\{\sin kx\}$ 配上归一化因子 $\sqrt{2/\pi}$ 后是 $L^2[0,\pi]$ 的正交系，真正的投影坐标是 $c_k=\frac{\pi}{2}b_k$（即 $\langle f,\sin kx\rangle/\langle \sin kx,\sin kx\rangle$），Bessel 不等式 $c_k^2$ 求和不超过 $\int f^2$ 说的正是正交投影长度不超过原向量长度，与 Strang 线性代数里的 $\|Pv\|\le\|v\|$ 是同一件事；当正交系完备时等号成立，即 Parseval 等式，不过此处只需不等式。它也解释了到达空间为什么选 $\ell_2$：平方和度量累加各频率分量的能量差，逐点度量在此没有意义。连接 CSAPP 与信号处理的思路：把连续信号换成一列系数，正是变换域表示与压缩的思想源头——系数记录每个频率占多少能量，$\ell_2$ 距离则衡量各频率能量累积的差异。这也是后续把连续性、有界性、算子范数串成一条线时，第一次出现的具体范本。带着这层铺垫进入 13.6.1：这些算子的连续性，即将成为主角。

## <span style="color:#c0392b;">§13.6 函数（Functions）</span>

本节标题"函数"在上一页（书页 558）已经开启，其引言指出：对 $f : \mathbb{R} \to \mathbb{R}$ 的极限与连续性的研究，可以通过研究把某个度量空间映到另一个度量空间的函数来加以推广；我们先看一些从一个度量空间到另一个度量空间的函数例子。上一页已给出例 13.21，本页继续给出例 13.22 至 13.25。

<span style="color:#2471a3;">**[example]**</span>
> <span style="color:#7f8c8d;">TBB §13.6, p.559</span>
**例 13.22**：我们可以把积分（integration）这一运算解释为一个函数（function），它把度量空间 $C[a, b]$ 映射到 $\mathbb{R}$，其定义为
```math
T(f) = \int_a^b f(t)\,dt 。
```
于是，积分可以被看成一个定义在由函数组成的度量空间之上的实值函数（real-valued function）。$\square$

<span style="color:#2471a3;">**[example]**</span>
> <span style="color:#7f8c8d;">TBB §13.6, p.559</span>
**例 13.23**：我们定义一个函数 $S$，它把度量空间 $C[a, b]$ 映射到自身，其定义为
```math
(S(f))(t) = \int_a^t f(s)\,ds 。
```
这样一来，不定积分（indefinite integral）的概念就被实现为度量空间 $C[a, b]$ 上的一个运算（operation）或函数，它的取值也在 $C[a, b]$ 之中。$\square$

<span style="color:#2471a3;">**[example]**</span>
> <span style="color:#7f8c8d;">TBB §13.6, p.559</span>
**例 13.24**：微分（differentiation）这一运算可以解释为某个恰当度量空间上的一个函数。设 $C^1[0, 1]$ 由在 $[0,1]$ 上具有连续导数（continuous derivatives）的全体函数组成。我们定义函数 $D : C^1[0, 1] \to C[0, 1]$ 为
```math
D(f) = f' 。
```
若在这些空间上使用上确界度量（sup metrics），那么我们就能把微分运算解释为一个从一个度量空间到另一个度量空间的函数。$\square$

<span style="color:#2471a3;">**[example]**</span>
> <span style="color:#7f8c8d;">TBB §13.6, p.559</span>
**例 13.25**：若 $f$ 是区间 $[0, \pi]$ 上的连续函数，我们把它的 Fourier 正弦级数（Fourier sine series）写作
```math
\sum_{k=1}^{\infty} b_k \sin kx，
```
其中系数由 Fourier 的公式（Fourier's formulas）给出：
```math
b_k = \frac{2}{\pi} \int_0^{\pi} f(t) \sin kt \, dt 。
```
稍稍转换一下视角，这个运算就可以放在度量空间的语境中来考虑。输入函数 $f$ 被变换成一个数列 $\{b_k\}$。因此，在“序列 $\{b_k\}$ 的各项由上述公式给出”这一理解之下，我们可以把它写作 $F(f) = \{b_k\}$。
那么，哪个序列空间（sequence space）才恰当呢？Fourier 级数的基本不等式（elementary inequalities）之一指明了该使用哪个空间。要证明下面这个不等式并不困难：
```math
\sum_{k=1}^{\infty} b_k^2 \le \frac{2}{\pi} \int_0^{\pi} f^2(t)\,dt 。
```
（这称为 Bessel 不等式（Bessel's inequality）。）显然，我们可以把 $F$ 解释为从 $C[0, \pi]$ 到序列空间 $\ell_2$ 的一个映射。$\square$

> <span style="color:#7f8c8d">（译者核：此处常数 $\frac{2}{\pi}$ 正确——按本示例的傅里叶正弦系数约定 $b_k=\frac{2}{\pi}\int_0^{\pi} f(t)\sin kt\,dt$，函数 $\sqrt{\frac{2}{\pi}}\sin kt$ 在 $[0,\pi]$ 上构成标准正交系，故正余弦 Bessel 不等式为 $\sum_k b_k^2 \le \frac{2}{\pi}\int_0^{\pi} f^2$（Parseval 时取等号）。该 $\frac{2}{\pi}$ 与周期 $2\pi$ 的复傅里叶归一化（$\sum|c_k|^2\le\frac{1}{2\pi}\int_{-\pi}^{\pi}|f|^2$）不同，系由本节的 $b_k$ 归一化所致，非笔误。）</span>

在上述五个例子的每一个中，我们都引入了一个从一个度量空间 $(X, d)$ 到另一个度量空间 $(Y, e)$ 的函数 $f : X \to Y$。在例 13.22、13.23 与 13.24 中，我们遵循一个常见惯例：当这些度量空间同时也是向量空间（vector spaces）时，就使用大写字母（$T$、$S$ 与 $D$）。我们常常使用变换（transformation）或算子（operator）这两个术语来代替术语函数（function）。

<span style="color:#2471a3;">**[section]**</span>
## <span style="color:#c0392b;">13.6.1 连续性（Continuity）</span>

正如在从 $\mathbb{R}$ 到 $\mathbb{R}$ 的函数情形中那样，我们希望知道前面定义的这些函数（变换，transformations）的例子是否“连续”。在定义度量空间之间函数的连续性时，我们试图捕捉以下想法：
若 $T : X \to Y$，则称 $T$ 在 $x_0 \in X$ 处连续（continuous），前提是 $x_0$ 附近的所有点都被映射到 $T(x_0)$ 附近的点。
我们以与处理从 $\mathbb{R}$ 的子集到 $\mathbb{R}$ 的函数（见 5.1.2 节）、以及从 $\mathbb{R}^n$ 的子集到 $\mathbb{R}^m$ 的函数（见 11.7 节）完全相同的方式，把上述想法精确化。

<span style="color:#2471a3;">**[definition]**</span>
> <span style="color:#7f8c8d;">TBB §13.6, p.560</span>
**定义 13.26**：设 $(X, d)$ 与 $(Y, e)$ 为度量空间，并设 $T : X \to Y$。若对每个收敛到 $x_0 \in X$ 的序列 $\{x_k\}$，序列 $\{T(x_k)\}$ 都收敛到 $T(x_0) \in Y$，则称 $T$ 在 $x_0 \in X$ 处连续。<span style="color:#00838f">（核心定义句——序列刻画）</span>若 $T$ 在 $X$ 的每一点处都连续，则称 $T$ 是连续的。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 定义 13.26 把度量空间之间的连续性压缩成一句话：$x_k\to x_0$ 蕴含 $T(x_k)\to T(x_0)$。这是连续性的三种等价刻画——序列、$\varepsilon$-$\delta$、邻域——中最操作友好的一种，因为当前手上的脚手架（一致收敛、Bolzano–Weierstrass 性质）几乎全是序列语言。为什么在度量空间里序列刻画一定等价于 $\varepsilon$-$\delta$ 刻画？连续推序列只需把 $\delta$ 套在 $x_k\to x_0$ 上；反向用逆否：若 $T$ 在 $x_0$ 不连续，则存在 $\varepsilon>0$，对每个 $k$ 都存在 $x_k$ 满足 $d(x_k,x_0)<1/k$ 但 $e(T(x_k),T(x_0))\ge\varepsilon$，于是 $x_k\to x_0$ 而 $T(x_k)\not\to T(x_0)$。这个反向证明的关键是每个点都有可数的开球邻域基（第一可数性），所以序列已经够用。  用它证连续的标准套路是三步：任取 $X$ 中满足 $x_k\to x_0$ 的序列；利用 $d(x_k,x_0)\to0$ 和已知的映射性质推出 $e(T(x_k),T(x_0))\to0$；最后由序列的任意性下结论。当映射满足 Lipschitz 条件 $e(T(x),T(y))\le M\,d(x,y)$ 时，第二步一步完成：$e(T(x_k),T(x_0))\le M\,d(x_k,x_0)\to0$，这也是 13.6.1 各例最常用的估计。用它证不连续更省力：只需找到一条 $x_k\to x_0$ 的序列，使 $T(x_k)$ 不收敛到 $T(x_0)$；或者干脆找两条都趋于 $x_0$ 的序列，其像趋于不同极限。  这套证连续取任意序列、证不连续取一条序列的战术，正是全称与存在量词的直接翻译：连续性是全称断言，所有逼近序列都要保持收敛，而否定一个全称断言只需一个反例。你在实数轴上证极限与连续性时反复用过同一逻辑：任意 $\varepsilon$ 证存在，一个反例否证。第一性原理的洞察在于，连续性被改写为保序列收敛这一性质，拓扑问题被翻译成序列问题。不过要提醒一句，序列刻画在一般拓扑空间里会失效，那时需要把可数逼近推广为网（net，指标集不必是自然数，而允许带方向的偏序集，让越来越靠近仍有意义）或滤子（filter，直接收集最终事件的集合族）。定理 13.27、13.28 随后会把这同一条连续性翻译成更几何的邻域语言与开集语言。练手时拿例 13.29–13.32 逐例标出取序列、估界、下结论三段即可。

## 定理 13.27（邻域与 $\varepsilon$-$\delta$ 刻画）

你可以自行验证：此前对实值函数成立的那些连续性的替代刻画（alternate characterizations），即 $\varepsilon$-$\delta$ 刻画（$\varepsilon$-$\delta$ characterization）与邻域刻画（neighborhood characterization），在此处也成立。其证明是相同的。我们把这些刻画列出供参考。

<span style="color:#2471a3;">**[theorem]**</span>
> <span style="color:#7f8c8d;">TBB §13.6, p.560</span>
**定理 13.27**：设 $(X, d)$ 与 $(Y, e)$ 为度量空间，并设 $T : X \to Y$。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 定理 13.27 给出连续性的两张同一观点的照片。$\varepsilon$-$\delta$ 版你早在实数轴上学过：对每个 $\varepsilon>0$ 存在 $\delta>0$，使 $d(x,x_0)<\delta$ 蕴含 $e(T(x),T(x_0))<\varepsilon$。邻域版则说：$T(x_0)$ 的每个邻域 $V$，其原像 $T^{-1}(V)$ 都包含某个含 $x_0$ 的邻域 $U$，等价地 $T(U)\subset V$。所谓邻域（neighborhood），在度量空间里就是包含一个以该点为中心的开球的集合；把 $\varepsilon$-$\delta$ 版里的开球 $B(x_0,\delta)$、$B(T(x_0),\varepsilon)$ 换成任意的 $U$、$V$，就是邻域版。关键的新增是邻域版——它剥掉半径这个数值外壳，只保留邻域这一集合概念，已经是一次去数值化，为的是干净地过渡到定理 13.28 的开集版。  两版为什么等价，看证明只用了一步翻译。由 $\varepsilon$-$\delta$ 推邻域：给定 $T(x_0)$ 的邻域 $V$，按定义 $V$ 含某个开球 $B(T(x_0),\varepsilon)$；对该 $\varepsilon$ 取 $\delta$，令 $U=B(x_0,\delta)$，则 $U$ 是 $x_0$ 的邻域且 $T(U)\subset B(T(x_0),\varepsilon)\subset V$。反向更简单：给定 $\varepsilon$，把 $V$ 取成开球 $B(T(x_0),\varepsilon)$，它当然是 $T(x_0)$ 的邻域；邻域版给出的 $U$ 含某个开球 $B(x_0,\delta)$，于是 $d(x,x_0)<\delta$ 推出 $T(x)\in V$，即 $e(T(x),T(x_0))<\varepsilon$。所以两种语言的翻译完全由开球与邻域的关系完成，没有借用 $\mathbb{R}$ 的完备性、序或代数结构。  第一性原理的洞察：连续性的本质不是误差小于 $\varepsilon$ 这类数值陈述，而是一个挑战—回应博弈——你指定 $Y$ 中要多近（邻域 $V$），我都能在 $X$ 中给出足够近的范围（邻域 $U$）。$\varepsilon$ 与 $\delta$ 是这个博弈的计分，邻域与开集是它的规则语言。这套任意—存在博弈贯穿整个分析：极限是一点的博弈，连续是逐点的博弈，一致连续与一致收敛是同一个 $\delta$ 对全体点成立的博弈（第 9 章的 $\delta$ 不依赖点），而紧集上的连续自动一致连续说明紧致性能把每点的局部赢法统一成全局赢法。CSAPP 的类比很贴切：把 $T$ 想成一条电路，$V$ 是输出允许的误差带，$U$ 是输入需要保证的精度带——连续性断言对任意输出误差要求，总存在充分的输入精度去满足它，这就是鲁棒性（robustness）的形式定义。练手时把定理 13.27 的两个方向各写一遍，再证两个连续映射的复合仍连续：取复合后像点的邻域，用 $g$ 的连续性拉回一层，再用 $f$ 的连续性拉回一层即可。

## 定理 13.28（开集刻画连续性）
(i) $T$ 在 $x_0$ 处连续，当且仅当对 $T(x_0)$ 的每个邻域 $V$，都存在 $x_0$ 的一个邻域 $U$ 使得 $T(U) \subset V$。
(ii) $T$ 在 $x_0$ 处连续，当且仅当对每个 $\varepsilon > 0$ 都存在 $\delta > 0$，使得只要 $d(x, x_0) < \delta$ 就有 $e(T(x), T(x_0)) < \varepsilon$。

一个重要的特殊情形如下。对于处处连续性（continuity everywhere）而言，最具意义的是处理开集（open sets）的方式。请注意：当 $G \subset X$ 为开集时，并不要求像集（image set）$T(G)$ 为开集；而是在当 $G \subset Y$ 为开集时，要求原像（preimage）$T^{-1}(G)$ 为开集。

<span style="color:#2471a3;">**[theorem]**</span>
> <span style="color:#7f8c8d;">TBB §13.6, p.560</span>
**定理 13.28**：设 $(X, d)$ 与 $(Y, e)$ 为度量空间，并设 $T : X \to Y$。则 $T$ 在 $X$ 的每一点处连续，当且仅当对 $Y$ 中的每个开集 $G$，集合
```math
T^{-1}(G) = \{x : T(x) \in G\}
```
在 $X$ 中都是开集。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 定理 13.28 是全节最深刻的一条：$T$ 处处连续，当且仅当 $Y$ 中每个开集 $G$ 的原像 $T^{-1}(G)$ 在 $X$ 中都是开集。译文特别提醒不要搞反：是原像承开性，像集不必保持开性（$T(G)$ 未必开）。一个最小反例：连续函数 $T(x)=x^2$ 把开区间 $(-1,1)$ 映成 $[0,1)$，右端取不到，不是开集；常数映射更极端，把任何非空开集映成单点集，而单点集在通常度量下不是开集。这个方向性不对称是理解定理的关键。为什么是原像而不是像？因为连续性本质上是局部、逐点的条件：$T$ 在 $x_0$ 连续只关心 $x_0$ 附近发生什么，而 $x_0$ 附近的点被 $T$ 送进 $G$ 翻译成集合语言正是 $x_0$ 是 $T^{-1}(G)$ 的内点。要求每个开集的原像开，就等价于在每个点都做到这一点。反过来，若要求开集的像仍开，那是开映射（open mapping），是一个整体得多、强得多的条件，它管的是 $Y$ 那边的全局形状，不能由逐点连续推出。  证明方向一（连续推原像开）只要顺着定义走：任取 $x_0\in T^{-1}(G)$，则 $T(x_0)\in G$；$G$ 开给出 $\varepsilon$ 使 $B(T(x_0),\varepsilon)\subset G$；连续性给出 $\delta$ 使 $T(B(x_0,\delta))\subset B(T(x_0),\varepsilon)\subset G$，即 $B(x_0,\delta)\subset T^{-1}(G)$，所以 $x_0$ 是内点。方向二（原像开推连续）更便宜：给定 $x_0$ 与 $\varepsilon$，$B(T(x_0),\varepsilon)$ 是 $Y$ 中开集，其原像按假设是 $X$ 中开集且含 $x_0$，于是含某个 $B(x_0,\delta)$，即 $d(x,x_0)<\delta$ 蕴含 $e(T(x),T(x_0))<\varepsilon$。两个方向都没有用到任何数轴结构。  直觉上可以把 $T$ 看成一个拉回（pullback）：它把 $Y$ 的开集族搬回 $X$，要求搬回来的仍是 $X$ 的开集。由此连续性第一次被纯集合语言刻画，完全脱离距离数值——这直接为同胚与拓扑性质铺路：既然连续性只依赖开集族，那么凡是用开集加原像能表达的映射性质，就只依赖拓扑结构而非具体度量；事实上一般拓扑空间正是把这条定理当定义用。对照 CSAPP 的接口思想：把 $X$ 与 $Y$ 想成两个模块，$Y$ 声明它认可的合法状态集合（开集），$T$ 的契约要求每个这样的集合经 $T^{-1}$ 拉回后仍是 $X$ 认可的合法状态集合；连续就是契约保持的精确版本。请把定义 13.26、定理 13.27、定理 13.28 三张照片并排：同一条连续性，分别用序列、邻域、开集三种语言说话，这是一个概念多重刻画的典型样本。

## <span style="color:#2471a3;">**[section]**</span> §13.6 函数（Functions）

你可以（在你熟悉的背景中用图画来）示意这些刻画，例如取 $\mathbb{R}^2$ 中的 $X=Y=\mathbb{R}^2$。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**示例 13.29**</span>：让我们再看一次示例 13.21。这里
```math
f(x_1,x_2)=\frac{x_1 x_2}{x_1^2+x_2^2}, \qquad f(0,0)=0.
```
让我们在 $(0,0)$ 处检查连续性。由于（按定义）$f(0,0)=0$，当且仅当对每一序列 $(u_n,v_n)\to(0,0)$ 都有 $\lim_{n\to\infty} f(u_n,v_n)=0$ 时，$f$ 在 $(0,0)$ 才连续。

只要有某一个序列使上述极限失败，就足以说明 $f$ 在那里不连续。例如，观察 $f(1/n,1/n)\to 1/2$。

[也许我们应当把 $f(0,0)$ 重新定义为 $1/2$；在这种情况下 $f$ 依然不连续，因为 $f(1/n,0)\to 0$。于是无论 $f(0,0)$ 取何值，都无法使该函数在那里连续。]

在其余每一点处都容易验证 $f$ 连续。取任一趋于 $(a,b)\neq(0,0)$ 的序列 $(u_n,v_n)$，并用通常的初等序列方法验证 $f(u_n,v_n)\to f(a,b)$。$\square$

> <span style="color:#7f8c8d;">TBB §13.6, p.561</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这是方向性序列证不连续的教科书级实例：$f(x_1,x_2)=\frac{x_1x_2}{x_1^2+x_2^2}$ 在原点无论赋何值都无法连续。用极坐标看得最清楚：令 $x_1=r\cos\theta$、$x_2=r\sin\theta$，则 $f=r^2\sin\theta\cos\theta/r^2=\sin\theta\cos\theta=\tfrac12\sin2\theta$，函数值与半径 $r$ 无关，只与靠近原点的方向角 $\theta$ 有关。于是沿对角线取序列 $(1/n,1/n)\to(0,0)$，函数值恒为 $1/2$；沿 $x_1=0$ 轴取 $(0,1/n)\to(0,0)$，函数值恒为 $0$。两条序列都趋于原点，函数值却趋于不同极限，因此二重极限不存在，原点赋任何值也救不回来。  第一性原理的洞察：极限沿不同方向可以取不同值，而连续性要求所有走近方式收敛到同一个值。一元函数只有左右两侧可走，多元函数却有无数条直线、更有抛物线等曲线路径，所以逐方向检查的工作量完全不同。沿直线 $x_2=m x_1$ 逼近时，$f=m/(1+m^2)$，不同斜率给出不同极限：$m=0$ 得 $0$，$m=1$ 得 $1/2$，$m=2$ 得 $2/5$。更微妙的是，即使沿每一条直线路径都收敛到同一个值，仍不足以保证二重极限存在——例如 $g(x,y)=\frac{xy^2}{x^2+y^4}$ 沿所有直线 $y=mx$ 都趋于 $0$，但沿抛物线 $x=y^2$ 趋于 $1/2$。这也解释了为什么序列刻画（定义 13.26）在此最省力：$\varepsilon$-$\delta$ 要一次性给出一条对所有路径同时有效的 $\delta$，而序列刻画只需逐条击破路径。本书译文还指出，即使把 $f(0,0)$ 重设为 $1/2$，沿 $x_1=0$ 轴仍得到极限 $0$——所以露馅的不是原点赋值，而是方向极限不一致。CSAPP 里有个同构的现象：浮点加法不满足结合律，$(a+b)+c$ 与 $a+(b+c)$ 可能不同，计算路径不同结果可能不同。请以本例为模板理解：$\lim_{x\to a}$ 存在必须与路径选择无关。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**示例 13.31**</span>：让我们再看一次示例 13.23。我们验证由
```math
(S(f))(t)=\int_a^t f(s)\,ds
```
定义的 $S$ 在每一 $f\in C[a,b]$ 处连续。设在该度量空间中 $f_k\to f$。这意味着当 $k\to\infty$ 时
```math
d(f_k,f)=\max_t |f_k(t)-f(t)|\to 0
```
（也就是说 $f_k\to f$ 在 $[a,b]$ 上一致收敛）。你应当验证以下计算中的每一步：
```math
d(S(f_k),S(f))=\max_t |(S(f_k))(t)-(S(f))(t)|
```
```math
=\max_t \left|\int_a^t (f_k(s)-f(s))\,ds\right|
```
```math
\le \max_t \int_a^t |f_k(s)-f(s)|\,ds =\int_a^b |f_k(s)-f(s)|\,ds
```
```math
\le (b-a)\max_t |f_k(t)-f(t)| = (b-a)d(f_k,f).
```

由假设 $\lim_{k\to\infty} d(f_k,f)=0$，我们可得出 $\lim_{k\to\infty} d(S(f_k),S(f))=0$。因此 $S(f_k)\to S(f)$，从而 $S$ 连续。$\square$

> <span style="color:#7f8c8d;">TBB §13.6, p.561</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 13.30、13.31 是用一致收敛加定理 9.26 证算子连续、并由此引出 Lipschitz/算子范数估计模板的第一个案例。以例 13.31 的变上限积分算子 $S$ 为例，核心是一步直框：对任意 $t\in[a,b]$，$|S(f_k)(t)-S(f)(t)|=\left|\int_a^t(f_k-f)\right|\le\int_a^t|f_k-f|\le(t-a)\,d(f_k,f)\le(b-a)\,d(f_k,f)$，两边对 $t$ 取上确界即得 $d(S(f_k),S(f))\le(b-a)\,d(f_k,f)$。于是 $d(f_k,f)\to0$ 必然推出 $d(S(f_k),S(f))\to0$，连续性随之而来。例 13.30 的定积分 $T(f)=\int_a^b f$ 同样线性，且 $|T(f_k)-T(f)|\le(b-a)\,d(f_k,f)$，证明更短。  放大因子 $(b-a)$ 是有界线性算子范数（operator norm）的最早雏形。注意这句话的适用范围：在赋范线性空间（normed linear space）之间，线性算子连续当且仅当存在常数 $M$ 使 $d(Tf,Tg)\le M\,d(f,g)$，即 Lipschitz 条件；没有线性结构的一般度量空间谈不上算子范数。证明这个等价只需两步：若 $T$ 在 $0$ 点连续，则存在 $\delta$ 使 $\|x\|<\delta$ 时 $\|Tx\|<1$；对任意 $x\ne0$，缩放 $\delta x/(2\|x\|)$ 后代入得 $\|Tx\|<2\|x\|/\delta$，取 $M=2/\delta$ 即得界；反过来有界显然蕴含 Lipschitz 连续。第一性原理的直觉要说得准确：积分把误差按区间长度累积，最坏情形是把常数误差放大 $(b-a)$ 倍——当 $b-a>1$ 时确实放大，关键是有界放大而非无界；说积分一定压缩误差是不对的。事实上取 $f\equiv1$，$T(f)=b-a$ 而 $d(f,0)=1$，放大倍数恰好达到 $b-a$，说明这个上界是紧的。与之相对，例 13.32 的微分是取斜率，对高频小振幅抖动可以无界放大。对照 Strang 线性代数：线性映射连续等价于范数有界，正如矩阵满足 $\|Ax\|\le\|A\|\|x\|$，$S$ 正是无穷维版本的矩阵，$(b-a)$ 是它的一个范数上界。数值分析的视角：$d(S(f_k),S(f))\le(b-a)\,d(f_k,f)$ 是一条误差传递上界——输入误差经算子后至多按常数倍增长，这正是条件数（condition number）思想的雏形，与 CSAPP 中算法稳定、误差不爆炸的关切同源。你在第 9 章已建立一致收敛可穿过积分号（定理 9.26），这里不过是用度量语言把同一事实重述为 $S$ 连续。

# 第 13 章 度量空间（Metric Spaces）· §13.6

<span style="color:#7f8c8d">书页 565 …（承接 §13.6 对函数与三种度量关系的讨论）</span>

对于点 $x = (x_1, x_2)$、$y = (y_1, y_2)$，我们已在**示例 13.4** 与**习题 13.2.6** 中见过这三种度量（metric）。

虽然它们是在 $\mathbb{R}^2$ 上三种不同的度量，但我们将会看到，在三种度量下开集（open set）是相同的，收敛序列（convergent sequence）也是完全一致的。为什么会出现这种情况？

考察以原点为中心的若干个单位球，可以帮助解释其中的缘由。（我们这里的分析会重复部分 §11.6.2 的论述，你此前可能跳过了那里。）第 456 页的**图 11.4** 展示了这三种度量下以原点为中心的三个单位球。更一般地，关于度量 $d_\infty$、以 $x$ 为中心、半径为 $r$ 的开球（open ball），其内部是一个各边平行于坐标轴的正方形；它的中心在 $x$，边长等于 $2r$。对于度量 $d_2$，该球是以半径 $r$ 的圆的内侧；而对于 $d_1$，该球是边长为 $r\sqrt{2}$、各边平行于直线 $x_2 = \pm x_1$ 的正方形之内侧。

让我们把这三个空间 $(\mathbb{R}^2, d_1)$、$(\mathbb{R}^2, d_2)$ 与 $(\mathbb{R}^2, d_\infty)$ 中的球分别记为 $B_1(x, r)$、$B_2(x, r)$ 与 $B_\infty(x, r)$。用解析方法容易验证，对每个 $x \in \mathbb{R}^2$ 与 $r > 0$，恒有

```math
B_1(x, r) \subset B_2(x, r) \subset B_\infty(x, r). \tag{5}
```

此外，对每个 $x \in \mathbb{R}^2$ 与 $r > 0$，都存在 $s > 0$ 使得

```math
B_\infty(x, s) \subset B_1(x, r). \tag{6}
```

（见**习题 13.6.24**。）由此可知：关于某一种度量、以 $x$ 为中心的任一球，都包含关于另外两种度量中任意一种、以 $x$ 为中心的某个球。于是，关于其中一种度量是开集的任一集合，关于另外两种度量也同样是开集。 $\square$

我们这份例子所揭示的事实——三种不同的度量竟然给出同一族开集——具有重要的后果。如果开集相同，那么收敛序列就相同；如果开集相同，那么连续函数就相同。因此，关于其中一种度量收敛到某点 $x_0$ 的任一序列 $\{x_n\}$，关于另外两种度量同样收敛到 $x_0$。进一步地，一个把 $\mathbb{R}^2$ 映入度量空间 $(Y, e)$ 的函数 $f$，关于其中一种度量连续，当且仅当它关于另外两种度量也连续。

我们可以用一句话总结上面的例子：三个度量空间 $(\mathbb{R}^2, d_1)$、$(\mathbb{R}^2, d_2)$ 与 $(\mathbb{R}^2, d_\infty)$ 具有相同的「拓扑性质」（topological property）；从拓扑（topology）的观点看，它们是难以区分的。我们需要把这一概念弄精确。我们例子中的关键观察在于相对三种度量各自的开集。一个度量空间的拓扑，简单地说就是它的开集族。因此，粗略地讲，所谓拓扑性质，就是能够用开集来表达、而不必直接用该空间上定义的度量来表达的性质。

在陈述我们的定义之前，先考虑第二个问题。假设两个度量空间 $(X, d)$ 与 $(Y, e)$ 密切相关，其含义是存在一个一一的、映上的函数 $h : X \to Y$。于是 $Y = h(X)$ 就是 $X$ 的一个「副本」，且每个点 $x \in X$ 对应到唯一的点 $y = h(x) \in Y$。问题是这样：$h$ 还应具备哪些额外性质，才能使 $X$ 的开集与 $Y$ 的开集之间维持同样的关系——即 $G$ 是 $X$ 的开子集当且仅当 $h(G)$ 是 $Y$ 的开子集？这个问题的答案蕴含在如下定义之中。

<span style="color:#2471a3;">**[example]**</span> **例 13.37（Example 13.37）：** Example 13.33 中的三个空间 $(\mathbb{R}^2, d_1)$、$(\mathbb{R}^2, d_2)$ 与 $(\mathbb{R}^2, d_\infty)$ 是拓扑等价的。对任意一对空间，取 $h$ 为恒等映射（identity map）。可以用断言式（5）与（6）来证明 $h$ 是一个同胚。由于恒等映射是同胚，我们可以说得更多：对三种度量中的每一种，开集都是相同的。 $\square$

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这是证明两个度量诱导同一拓扑的通用模板，例 13.33 是标准示范。对 $\mathbb{R}^2$ 上的三种度量 $d_1(x,y)=|x_1-y_1|+|x_2-y_2|$、$d_2=\sqrt{(x_1-y_1)^2+(x_2-y_2)^2}$、$d_\infty=\max(|x_1-y_1|,|x_2-y_2|)$，先有不等式 $d_\infty\le d_2\le d_1$，故开球满足 $B_1(x,r)\subset B_2(x,r)\subset B_\infty(x,r)$；反向有 $|a|+|b|\le 2\max(|a|,|b|)$ 即 $d_1\le 2d_\infty$，取 $s=r/2$ 得 $B_\infty(x,s)\subset B_1(x,r)$。于是任意度量下的每个开球都含另一个度量下同心的某个开球；而开集的定义是「每点都被一个开球包住」，所以三种度量选出完全相同的开集族。这套「球套球」夹逼法不必枚举开集，只要每个开球能在对方体系里被套住，拓扑就相同。第一性原理：三种球的形状（$d_1$ 菱形、$d_2$ 圆盘、$d_\infty$ 正方形）差异很大，但拓扑只关心包含关系与「落入邻域」，不关心邻域是圆是方，因为收敛只要求最终进入任意给定的邻域。对照 Strang：$d_1,d_2,d_\infty$ 分别是 $\ell_1,\ell_2,\ell_\infty$ 范数诱导的度量；有限维范数两两等价，如 $\|x\|_\infty\le\|x\|_2\le\|x\|_1\le\sqrt n\|x\|_2\le n\|x\|_\infty$，系数只依赖维数 $n$——这正是 Strang 范数估计的直接应用，也是 $\mathbb{R}^n$ 中任意范数等价的雏形。CSAPP 抽象层隐喻再次生效：三种度量是三种底层实现，开集族是公开接口，接口一致则上层收敛、连续行为无差别。注意「度量等价」是拓扑等价（诱导同一开集族），不是等距：三种度量给出的距离数值并不相同，只是判定开集的结果一致；等距是更强的刚性结论（见 §13.6.3）。

## 定义 13.34（同胚 / 拓扑等价）

> <span style="color:#7f8c8d;">TBB §13.6, p.566</span>

<span style="color:#2471a3;">**[note]**</span> <span style="color:#1e8449;">**Note（注）.：**</span> 在最后一个例子中，三种度量给出了 $\mathbb{R}^2$ 完全相同的开集族。然而，并不总成立：如果 $d$ 与 $e$ 是集合 $X$ 上的两个度量，且 $(X, d)$ 同胚于 $(X, e)$，那么 $d$ 与 $e$ 未必诱导出同一族开集。（见 Exercise 13.6.30。）事实上成立的是：若 $h : (X, d) \to (X, e)$ 是一个同胚，那么集合 $A \subset X$ 在 $(X, d)$ 中为开集，当且仅当集合 $h(A)$ 关于 $(X, e)$ 是开集。

有时两个空间是否同胚并不立刻一目了然。证明两空间不同胚的一种方式，是找出某个拓扑性质，这个性质为其中一个空间具有、而另一个空间却不具有。

# §13.6.3 等距同构 Isometries

当两个度量空间 $(X, d)$ 与 $(Y, e)$ 拓扑等价（topologically equivalent）时，它们会共享某些性质——若其中一个空间具备某种性质，则另一个空间亦然。

$X$ 中子集的拓扑性质（topological property）会如实地迁移（carry over）到 $Y$ 中它们对应的像（image）之上。

拓扑性质的具体例子已分别在习题 13.6.21 与 13.6.37 中给出。

我们将在 §13.7 与 §13.12 两节进一步研究两种重要的拓扑性质——可分性（separability）与紧致性（compactness），它们是度量空间理论中的关键概念。

然而，两个拓扑等价的空间仍然可能具有截然不同的性质。

<span style="color:#7d3c98">*（例如，$(0,1)$ 与 $(0,\infty)$ 虽然拓扑等价，但其中一个有界、另一个无界。）*</span>

于是自然要问：究竟哪种更强的等价概念，才能精确刻画"两个空间具有完全一致的度量空间性质"这一情形？

这种更强的度量空间等价形式，正是建立在等距同构（isometry）或全等（congruence）的概念之上。

回忆初等几何中所学：例如，若平面内三角形 $T_1$ 的三条边分别与三角形 $T_2$ 的三条边长度相等，则 $T_1$ 与 $T_2$ 是全等的（congruent）。

这表明 $T_1$ 可以通过刚体运动（rigid motion，刚性移动）被整体移动到与三角形 $T_2$ 完全重合。

我们完全可以在度量空间的普遍框架下，把这个"刚体运动"的概念精确化到严格的数学形式。

<span style="color:#2471a3;">**[definition]**</span>

<span style="color:#c0392b">**定义 13.40（等距同构 isometry）**</span>

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 这里实际在建立等价关系的阶梯。同胚是拓扑等价（保开集、保收敛），等距同构更强，还要保两点之间的实际距离。用 Strang 的话说，满射等距同构把整个度量空间当作刚体整体搬动，所有点对距离原封不动，正如线性代数里的正交矩阵 $Q$ 满足 $\|Qx-Qy\|=\|x-y\|$。第一性原理的区分：拓扑等价刻画连续性，等距同构才刻画长度与刚性。例 13.41 给出清晰对照：$(0,1)$ 与 $(0,\infty)$ 同胚（如 $x\mapsto x/(1-x)$）但不等距，前者直径是 $1$、后者直径无穷；$(0,1)$ 与 $(0,2)$ 也同胚而不等距，直径 $1\ne2$ 直接否决任何保距双射。可见直径是等距不变量，却不是同胚不变量。定义中映满（onto）的条件不可省：只保距而不满射只是嵌入，满射才保证逆也保距——对任意 $u,v$ 取 $x=h^{-1}(u),y=h^{-1}(v)$，则 $d(h^{-1}(u),h^{-1}(v))=d(x,y)=e(h(x),h(y))=e(u,v)$——等距同构因此成为度量空间范畴里的同构（isomorphism）；当定义域等于值域、映射映到自身时，才进一步称为自同构/自守（automorphism）。与 CLRS 图算法里提到的图同构（graph isomorphism，顶点重排后边集完全相同的双射）类比更精确：图同构保邻接结构，等距同构保距离结构，二者都是「保持各自核心结构的双射」，且都靠结构不变量（度数、距离分布）来否证。等距同构的逆仍等距、复合仍等距，所以它在全体度量空间上给出等价关系；同胚是更粗的等价关系，一个等距类里只有刚性相同的空间，一个同胚类里则允许任意连续伸缩。把「刚体」与「橡皮」两把尺子分清楚之后，例 13.42–13.45 的等距构造就都归结为：找一个保距离的显式双射，或找一个距离不变量来否决。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 例 13.44 教的是等距否证中的不变量侦察法：等距同构必须保持有限点集的全部两两距离。TBB 的论证很妙：在 $(\mathbb{R}^2,d_\infty)$ 中取四点 $(\pm\frac12,\pm\frac12)$，任意两点（含对角两点）的 $d_\infty$ 距离都是 $1$，也就是说存在四个两两相距为 $1$ 的点；这四点可看成 $d_\infty$ 单位球面的顶点，构成一个每边长为 $1$ 的完全图 $K_4$。若存在等距同构 $h:(\mathbb{R}^2,d_\infty)\to(\mathbb{R}^2,d_2)$，这四个点的像在欧氏平面里也必须两两相距 $1$。但欧氏平面中两两距离相等的点集最多只有 $3$ 个：三点构成正三角形后，第四点必须同时落在以这三个顶点为圆心的三个单位圆上；这三个圆两两相交于原三角形的顶点，但三者没有公共点（画图或用余弦计算即可验证），故第四个点无论放哪都会破坏与某个顶点的等距性。这个例子的结论是 $d_\infty$ 与 $d_2$ 不等距，尽管它们拓扑等价（例 13.33）——拓扑等价与等距的差距在此量化可见。这与 CLRS/图论里判断两图是否同构的策略同源：先找不变量（顶点度数、边数、距离分布），一个不变量对不上就绝对不可能同构。第一性原理：等距同构不是逐点对照，而是保持整个「距离图」的嵌入结构，因此「最多能有几个点两两相距给定值」这类组合不变量成了最强有力的否定武器。这也解释为什么例 13.44 不直接构造映射：构造等距双射往往需要解坐标方程，而数出四点的组合结构只需一次观察。记住这个思路：证明两个空间不等距，通常比硬证等距容易——找到一个等距不变量不一致即可，这正是「否证优先于构造」的实战策略。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 例 13.41 与 13.42 把等距同构和单纯同胚的区别讲得很清楚：同胚只要求双向连续，等距还必须保距离数值。例 13.41 说任意两个非空开区间都同胚：有界区间先仿射地映到 $(0,1)$，无界区间用 $\log$ 或 $x/(1-x)$ 之类与有界区间连接，再复合即可。但两个有界开区间 $(a,b)$ 与 $(c,d)$ 等距当且仅当 $b-a=d-c$：$h(x)=2x$ 把 $(0,1)$ 映到 $(0,2)$，是连续双射、逆也连续，所以是同胚，但 $|h(x)-h(y)|=2|x-y|$，距离被放大一倍，不是等距。无界情形要更细：$\mathbb{R}$ 与 $(0,\infty)$ 都「无限长」却不等距，因为 $\mathbb{R}$ 完备而 $(0,\infty)$ 不完备（$1/n$ 是 Cauchy 列但无极限），完备性也是等距不变量。例 13.42 用 $h(x)=x+1$ 把 $\mathbb{N}\cup\{0\}$ 平移到 $\mathbb{N}$（等价地，$x-1$ 把 $\mathbb{N}$ 映到 $\mathbb{N}\cup\{0\}$），这是平移这一刚体运动的离散版，把中学「全等」用严格语言抽象出来。第一性原理的好问题：有限集合上的等距同构是什么？答案不是任意重排，而是保距离的重排——对有限度量空间，等距必为单射从而为双射，故必是某个置换（permutation，6.042J 里学过），但它必须保持所有点对距离。例如 $X=\{-1,0,1\}$ 取通常距离时，恒等与 $x\mapsto -x$ 是等距，而交换 $0,1$ 的置换会破坏 $d(-1,1)$ 与 $d(-1,0)$ 的匹配，不是等距。最后警惕一个常见过度推广：「等距同构=平移+旋转+反射」只在欧氏空间 $\mathbb{R}^n$ 里成立（那里满射等距由正交变换加平移组成）；一般度量空间里等距可以是各种保距离置换或更奇异的双射，根本没有「旋转」可谈。普遍成立的结论是：满射等距保持一切由距离定义的性质——有界性、直径、完备性、全有界性，所以这些量都能用作否证等距的不变量。

对一切 $x,y \in X$ 成立。若存在从其中一个到另一个满的等距同构（isometry），则称这两个空间为等距的（isometric）。一个性质若被等距同构所保持，则称为度量性质（metric property）。

注意，等距同构正是保持距离的同胚（homeomorphism）。因此，平面中两个全等的三角形，当被视作平面的子空间时，就是等距的度量空间。

<span style="color:#1e8449;">**[note]**</span> 注．我们在使用"刚体运动"（rigid motion）一词须稍加小心。考虑图 13.3 中的直角三角形。三角形 $T_1$ 与 $T_2$ 全等——满足 $h(T_1)=T_2$ 的等距同构 $h$ 可以先作平移（translation）$t$、再作旋转（rotation）$r$：$h = r \circ t$。于是 $T_1$ 在平面内被移动到 $T_2$。但在 $\mathbb{R}^2$ 内并不存在把 $T_1$ 映到 $T_3$ 的此类运动（即平移与旋转的组合）。尽管如此，$T_1$ 与 $T_3$ 仍是等距的。你或许愿意演示一下如何构造 $T_1$ 与 $T_3$ 之间的一个等距同构。（$\mathbb{R}^3$ 到 $\mathbb{R}^3$ 的一个等距同构就能办到，但这并非必要；我们所需要的一切只是把 $T_1$ 映到 $T_3$ 的等距映射，该映射的定义域只需是 $T_1$ 本身，而不必是某个更大的空间。）请将这些说明与习题 13.6.44 及 13.6.45 作比较。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 嵌入（embedding）这个概念值得单独咀嚼。例 13.45 说 $\mathbb{R}$ 与 $\mathbb{R}^2$ 中的 $x$ 轴等距，但严格讲 $\mathbb{R}$ 并不等于那条 $x$ 轴：$x$ 轴的点是二维元组 $(x,0)$，$\mathbb{R}$ 的点是实数 $x$，身份不同，不能直接写 $\mathbb{R}\subset\mathbb{R}^2$。等距嵌入 $h:X\to Y$ 正是为弥合这种身份错位而设：它不要求 $X$ 是 $Y$ 的子集，只要求对一切 $x,y\in X$ 有 $d_Y(h(x),h(y))=d_X(x,y)$，于是 $X$ 与它的像 $h(X)\subset Y$ 等距，$h$ 把 $X$ 的距离结构原样复制进 $Y$。因此我们不说 $\mathbb{R}^2$ 包含 $\mathbb{R}$，而说它包含 $\mathbb{R}$ 的一个等距复制。第一性原理的洞察是：数学家把“子集”这个朴素直觉锤炼成“可嵌入”这个精确陈述——等距是度量空间之间的等价关系，它只保留距离结构，不保留点的具体身份；$x\mapsto(x,0)$ 就是最典型的嵌入。初学时容易觉得这种咬文嚼字多余，但若不区分，后续把 $\mathbb{R}$ 当 $\mathbb{R}^2$ 的子集来运算，会在维数、范数、内积上处处碰壁；一旦改写成嵌入，命题就干净了：嵌入的复合仍是嵌入，$X$ 嵌入 $Y$、$Y$ 嵌入 $Z$ 则 $X$ 嵌入 $Z$。还要注意嵌入与同胚的强度差异：同胚只保开集结构，等距嵌入连距离数值都保，因此自动保持 Cauchy 性、有界性等由距离定义的性质。这条思路在本章扮演地基角色：后文 §13.8 的完备化定理正是证明，任何不完备空间都能等距嵌入一个更大的完备空间，并成为其中稠密子空间，等于给抽象空间造一个“身份正确、性质更好”的副本。不妨把它理解成 CSAPP（《深入理解计算机系统》）里进程的地址空间：不同进程中同样的虚拟地址编号互不影响，各自在物理内存里有独立副本——编号相同、身份不同，正如 $\mathbb{R}$ 与 $x$ 轴上的 $(x,0)$；当然这个类比只取“同号不同身”这一点，虚拟地址到物理页的映射并不保持距离。嵌入是把跨空间的鸿沟翻译成同构复制的标准工具，后续许多存在性证明都靠它先把对象搬进好空间再操作。

<span style="color:#7f8c8d">书页 573　§13.7 可分空间（Separable Spaces）</span>

<span style="color:#2471a3">**[section]**</span> # 13.7 可分空间（Separable Spaces）

在先前各章对初等分析（elementary analysis）的研究中，我们偶尔会用到一个事实：有理数构成实数空间 $\mathbb{R}$ 的稠密子集（dense subset）。这一事实之所以方便，有两个原因：第一，有理数远比实数更容易描述和处理；第二，它们构成一个可数（countable）子集。一般而言，在度量空间（metric space）理论中，一个度量空间内存在可数稠密集，会让许多论证变得简单得多。这引导我们引入下述术语。

<span style="color:#2471a3">**[definition]**</span> <span style="color:#00838f">**定义 13.46：**</span> 度量空间 $(X,d)$ 称为**可分的（separable）**，如果它拥有一可数稠密子集（countable dense subset）。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 可分（separable）本质上在说：这个空间用可数多个点就能逼近到头。严格定义是：度量空间 $X$ 可分，若存在可数子集 $D\subset X$ 使 $\overline{D}=X$。直觉上，把空间想成一片连续海面，可数稠密集就像密密麻麻撒在海面上的灯笼——任意一点（无论多刁钻）附近总有一盏灯，而灯的总数顶多可数。这里要抓住两个词：可数（countable，有限或与 $\mathbb{N}$ 一一对应）与稠密（dense，任意非空开球都与 $D$ 相交，等价于 $\overline{D}=X$）。注意“稠密”不等于“均匀”：灯笼可以有的地方密、有的地方疏，只要每个开球都不落空即可。$\mathbb{R}$ 的可分性靠的就是你在 MIT 6.042J《计算机科学中的数学》里反复使用的 $\mathbb{Q}$：它可数（可列枚举），又在 $\mathbb{R}$ 中稠密（任意两个实数之间都夹着有理数）。这条“可数 + 稠密”配方带来一条重要方法论：可分空间里的许多证明可以先对可数点集证明，再用稠密逼近把结论搬到任意点，从而把不可数的问题降为可数问题。可数性的妙处在于它是“最小的无穷”：可数集能被 $\mathbb{N}$ 编号，于是可以在其上做枚举、归纳、对角化；很多构造一旦落到可数稠密集上，就变成可数个条件的联立。还要记得稠密点的选取不唯一：$\mathbb{Q}$ 与 $\mathbb{Q}+\sqrt2$ 都在 $\mathbb{R}$ 中稠密，灯笼的位置可以整片平移。它与 §13.12 的紧致性（compactness）形成呼应：紧致讲用有限开覆盖就能罩住，可分讲用可数点就能逼近，二者都是把无限变成可控之物的策略，是度量空间理论里两把核心钥匙。更精确的联系是：紧度量空间必可分（对每个 $\varepsilon=1/n$ 取有限网再取并集），而可分只给可数骨架、不保证有限控制，所以可分是比紧致弱得多的条件。留意一个埋伏：可分性是拓扑性质，紧致性也是，但完备性不是——这个差异到 §13.8 会看得更清楚。

<span style="color:#7f8c8d">书页 574　§13.7 可分空间（接上）</span>

我们往往可以通过展示一个不可数的不相交开集族（uncountable disjoint family of open sets）来证明一个空间不可分。由于一个稠密集必须与每个非空开集相交，因此不可能存在可数稠密集。

<span style="color:#7d3c98">**一些不可分例子（Some Nonseparable Examples）**</span>

<span style="color:#2471a3">**[example]**</span> <span style="color:#c0392b">**例 13.53：**</span> 任何配备离散度量（discrete metric）的不可数集 $X$ 都是不可分的，因为每个单点集（singleton set）都是开集。没有可数集合能够是稠密的。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 这里 TBB 交付了一个证明不可分的通用武器库，可称为不可数不相交开球模板：要证 $X$ 不可分，就找出一族不可数个两两不相交的开球。理由是：若 $D$ 稠密，则 $D$ 必须与每个开球相交；而这些开球两两不相交，所以 $D$ 要在每个球里各取一个点，元素个数至少不可数——这与可分要求的可数稠密集直接矛盾。使用模板时不必苛求所有开球半径相同，只要彼此不相交即可；隔离越强，可数逼近越不可能。三个例子是同一模板的三种变体。例 13.53：离散度量下任意两个不同点的距离都是 $1$，于是每个单点 $\{x\}=B(x,1/2)$ 都是开球，点集本身不可数即得。例 13.54：给 $[a,b]$ 的每个子集 $A$ 一个特征函数 $\chi_A$，任意两个不同特征函数在 $\sup$ 度量下距离为 $1$，于是以它们为心、半径 $1/2$ 的开球互不相交，而子集个数不可数，故 $M[a,b]$ 不可分。例 13.55：$\ell_\infty$ 中全部 $0/1$ 二元序列之间距离为 $1$，其个数与 $\mathbb{R}$ 的二进小数一样不可数，同样的构造切断可数逼近。这与 MIT 6.042J 里用 Cantor 对角化证明 $\mathbb{R}$ 不可数是同一条思想主干：只要能造出一堆彼此隔离（距离为 $1$ 或互不相交）的不可数个成员，任何可数集都无法在每个成员处插一脚，可数稠密自然无望。模板还可与全有界（totally bounded）对照：全有界要求对每个 $\varepsilon>0$ 都存在有限 $\varepsilon$-网，而模板造出的恰是不可数互斥开球，二者天然对立——这也解释了为什么紧度量空间（全有界 + 完备）一定可分，而模板正是给不可分空间开具的诊断书。

任何与可分度量空间拓扑等价（topologically equivalent）的空间本身也必然可分。我们可以从一个关于"稠密集在连续映射下如何被保持"的、略更一般的陈述中得到这一点。

<span style="color:#7d3c98">**可分性是一种拓扑性质（Separability Is a Topological Property）**</span>

<span style="color:#2471a3">**[theorem]**</span> <span style="color:#c0392b">**定理 13.56：**</span> 设 $(X,d)$ 与 $(Y,e)$ 是度量空间，且设 $f:X\to Y$ 是连续函数（continuous function）。若 $D$ 在 $X$ 中稠密，则集合 $f(D)$ 在 $f(X)$ 中稠密。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 定理 13.56 与推论 13.57 把可分性托举成拓扑性质，技术核心是连续映射把稠密集映成稠密集。证明的关键是像与原像的换序：设 $V$ 是 $f(X)$ 中的开集，按子空间拓扑可写成 $V=W\cap f(X)$，其中 $W$ 是 $Y$ 中开集；因 $f$ 连续，$f^{-1}(W)$ 是 $X$ 中开集，且 $f^{-1}(V)=f^{-1}(W)$；又因 $D$ 在 $X$ 中稠密，必有 $x\in D$ 落入 $f^{-1}(V)$，于是 $f(x)\in V\cap f(D)$。这一步把像空间的开集逆向拉回原空间，让稠密性在原像一侧发力——开集的原像仍是开集，这个连续性的等价刻画现在成了传递拓扑性质的引擎。逻辑迁移干净利落：$D$ 在 $X$ 中稠密，经连续 $f$，得到 $f(D)$ 在 $f(X)$ 中稠密；若 $D$ 可数，$f(D)$ 也可数，于是可分性被连续映射保持。推论随之而来：可分性在同胚下不变，因而不依赖具体度量、只依赖开集结构，是拓扑性质。这里务必警惕一个常见陷阱：可分、紧致、连通等都是拓扑性质，但完备性不是——$\mathbb{R}$ 与 $(0,1)$ 同胚，前者完备后者不完备，可见完备性依赖度量本身，不能放进同一检验流程。把“性质在同胚下不变”当作模板来检验，是贯穿本章（可分、紧致、连通等）的高频动作，值得背下来。这条传递引理还提示一种通用技术：凡拓扑性质，都可尝试用连续映射的前推或后拉来搬运；凡度量性质，搬运时则要检查距离是否被保持。等距嵌入比连续映射更强，因而既传递可分性，也传递完备性——这是后文完备化定理的伏笔。

<span style="color:#2471a3">**[proof]**</span> <span style="color:#c0392b">**证明：**</span> 设 $V$ 是 $f(X)$ 中的非空开集。由于 $f$ 连续，集合 $U=f^{-1}(V)$ 在 $X$ 中是开集。由于 $D$ 在 $X$ 中稠密，存在 $x\in D\cap U$。于是 $f(x)\in V$。由此可知 $f(D)$ 在 $f(X)$ 中稠密。$\square$

# §13.8 完备空间（Complete Spaces）

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 这里 TBB 交给你一条可直接复用的三步完备性证明模板，务必固化。第一步猜极限候选：对每个 $t$ 取逐点极限，得到候选函数 $f_0$——逐点极限只是“猜测”，它提示候选者是谁。为什么允许先逐点猜测？因为逐点极限最容易算，而度量收敛的极限必然同时是逐点极限，先逐点后验证是安全的侦查顺序；若逐点极限不存在，序列在大多数函数度量下都无望收敛。第二步验证候选者真属于所在空间：这是本质一步，要依赖 Cauchy 性而非逐点极限性。例如在 $M[a,b]$ 中要证 $f_0$ 有界：取 $N$ 使 $n,m\ge N$ 时 $|f_n-f_m|<1$，固定 $n$ 让 $m\to\infty$ 得 $|f_n-f_0|\le1$，于是 $f_0$ 被 $f_n$ 的有界性控制；在 $C[a,b]$ 中则要证 $f_0$ 连续。第二步最容易漏：很多同学默认极限函数自动继承有界性、连续性，但那需要一致收敛或 Cauchy 条件支撑，逐点极限并不继承这些性质。第三步验证收敛是那个度量下的收敛：$\sup$ 度量下就是一致收敛，必须对全区间同步逼近，不能只停在逐点收敛。例 13.62 强调第二步的本质性：$P[0,1]$ 中的多项式序列 $\sum_{k=0}^{n}t^k/k!$ 逐点收敛到 $e^t$，但 $e^t$ 不是多项式——候选者越出空间正是不完备的根源。注意这里还必须说明该序列按 $\sup$ 度量是一致收敛（从而 Cauchy）的：Taylor 余项在 $[0,1]$ 上一致趋于零；单说逐点收敛不足以在 $\sup$ 度量下构成 Cauchy 列。三步法的核心洞见是：候选来自逐点、归属靠 Cauchy、收敛靠度量，三者各司其职。这与数值分析课程中的不动点迭代思路相近：先凭直觉给候选初值（第一步），再验证候选落在合法区间且迭代映射把区间映回自身（第二步），最后用压缩性验证迭代稳定逼近真实解（第三步）。套过例 13.63 一遍，这套模板就能内化。

<span style="color:#2471a3;">**[section]**</span> 在第二章研究序列时我们引入了实数 Cauchy 序列（Cauchy sequence）的概念，并证明了每个这样的序列都收敛到某个实数。

在第九章研究一致收敛时我们看到，对函数的一致 Cauchy 序列（uniformly Cauchy sequence）也有类似的结论成立（定理 9.12）。

序列的这一概念——即 Cauchy 序列（Cauchy sequence）——可以在任一度量空间中被定义。

<span style="color:#2471a3;">**[definition]**</span> **定义 13.58（Definition 13.58）**：设 $(X,d)$ 是一个度量空间（metric space），$\{x_k\}$ 是 $X$ 中的序列。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> Cauchy 序列是本章最精妙的定义之一，值得用第一性原理彻底理解它的动机：判断一个序列“该不该收敛”，却完全不给出极限候选。定义只要求：对任意 $\varepsilon>0$，存在指标 $N$，使 $m,n\ge N$ 时 $d(x_m,x_n)<\varepsilon$——尾巴上任意两点的距离能任意小，不必知道它们逼近谁。注意“任意两点”比“相邻两项之差缩小”强得多：相邻项趋近只能说明步伐变小，尾部若在多个位置间来回跳动，相邻差仍可趋近零而序列不是 Cauchy。这在计算上极其务实：你在 CSAPP（《深入理解计算机系统》）里做浮点迭代时，常常只能监测到相邻迭代值之差在缩小，却永远猜不出精确目标值——Cauchy 条件正是对这种“自持收敛”的数学化。从 CLRS《算法导论》二分搜索的视角看，对任意 $\varepsilon>0$ 存在 $N$ 这层结构，就像二分循环里的终止阈值：指标 $N$ 依赖 $\varepsilon$，是任意逼近的节奏控制器。请务必把 Cauchy 与收敛严格区分：收敛需要预先给定的极限存在且属于背景空间，Cauchy 只要求内部自洽。收敛序列必为 Cauchy（三角不等式一步可得），但反过来只在完备空间成立——完备性就是“Cauchy 必有极限”。在 $\mathbb{R}$ 中两者等价（Cauchy 判别法），但这依赖实数的完备性；在一般度量空间里，Cauchy 未必有极限。例 13.61 的 $\mathbb{Q}$ 中，逼近 $\sqrt2$ 的有理数列是 Cauchy 列却无极限——自洽并不必然等于落地。这个自洽但不落地的张力，正是本节稍后完备化定理（定理 13.66）要缝补的漏洞：完备化正是把 Cauchy 序列本身当作新空间的点，让每个“该收敛”的序列都获得一个落点。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 完备空间的定义——每个 Cauchy 序列都收敛到空间内的点——实际上是对 $\mathbb{R}$ 既有性质的一次提炼再泛化。你在 TBB 第一章把 $\mathbb{R}$ 的完备性解释为最小上界性质（least upper bound property），这里给出等价的第二种说法：Cauchy 收敛。这两者是同一条性质的两副面孔：最小上界性质讲界限必有确界，Cauchy 收敛讲自洽必有归宿；在 $\mathbb{R}$ 上它们严格等价（等价性的证明还要用到 Archimedean 性质，TBB 已给出完整链条）。例 13.59 是漂亮的回扣：$M[a,b]$ 中的 Cauchy 序列正是第九章定义 9.11 的一致 Cauchy 列，而定理 9.12 保证一致 Cauchy 必一致收敛，其一致极限仍是有界函数，所以 $M[a,b]$ 完备——你早就无意中证明了 $M[a,b]$ 完备，只是当时没意识到那个概念叫完备。同一命题换了坐标，意义完全不同：定理 9.12 当时被读作“一致收敛的判别法”，现在重读为“$M[a,b]$ 的完备性”。这提示一个重要的学习元方法：每遇到一个新定义，先问“我过去有没有已经证明过它的特例”，往往能把新概念立刻锚定在旧经验上。完备性不是孤立的新定义，而是把实数完备性、一致收敛保证等多个收敛结论统一收编进一个抽象框架。可以预见，完备 + 紧致将是后续许多定理（压缩映射不动点定理、Cantor 交集定理等）共同的舞台道具：紧致提供有限性，完备提供极限的落点，两者配合才能让迭代、逼近类证明落地。不过要提醒一句：完备性不是拓扑性质，同胚可能破坏它（$\mathbb{R}$ 与 $(0,1)$ 同胚而完备性不同），所以凡涉及完备的论证都必须盯住度量本身，而不能只依赖开集结构。

---

因此定理 9.12 可以被解释为：$M[a,b]$ 中每个 Cauchy 序列都在 $M[a,b]$ 中收敛。$\square$

> <span style="color:#7f8c8d;">TBB §13.8, p.576</span>

并非在一般的度量空间中所有 Cauchy 序列都会收敛。

这一性质在实数直线上成立，而例 13.59 表明它在空间 $M[a,b]$ 中也成立。

确实具有这一性质的度量空间被称作是完备的（complete）。

我们此前已经用过这个词来描述实数的一个性质。

事实上，$\mathbb{R}$ 的完备性——我们在第一章中用最小上界性质（least upper bound property）来解释它——恰好等价于 Cauchy 序列收敛这一事实。

<span style="color:#2471a3;">**[definition]**</span> **定义 13.60（Definition 13.60）**：一个度量空间 $(X,d)$ 是完备的，如果 $X$ 中每个 Cauchy 序列都收敛（到 $X$ 中的某个元素）。

> <span style="color:#7f8c8d;">TBB §13.8, p.576</span>

我们知道 $\mathbb{R}$ 与 $M[a,b]$ 都是完备的。

下面来看几个不完备的常见例子，并考察它们为何不完备。

<span style="color:#2471a3;">**[example]**</span> **例 13.61（Example 13.61）**：带 $\mathbb{R}$ 之通常度量的空间 $\mathbb{Q}$ 不是完备的。

$\mathbb{Q}$ 中每个 Cauchy 序列确实收敛到某个实数，但未必收敛到 $\mathbb{Q}$ 中的元素。

例如，序列 $\{(1 + 1/n)^n\}$ 是一个有理数的 Cauchy 序列，却不在 $\mathbb{Q}$ 中收敛。$\square$

> <span style="color:#7f8c8d;">TBB §13.8, p.576</span>

<span style="color:#2471a3;">**[example]**</span> **例 13.62（Example 13.62）**：带上确界度量（sup metric）的 $[0,1]$ 上多项式空间 $P[0,1]$ 不是完备的。

例如，序列 $\{p_k\}$ 中

```math
p_k(t) = 1 + t + \frac{t^2}{2} + \cdots + \frac{t^k}{k!}
```

在 $[0,1]$ 上一致收敛到函数 $e^t$。

这源于 10.3 节对幂级数一致收敛的研究。

因此 $\{p_k\}$ 是空间 $M[0,1]$ 中的 Cauchy 序列（习题 13.8.1）。

于是它也是 $M[0,1]$ 的子空间 $P$ 中的 Cauchy 序列。

但 $\{p_k\}$ 并不在 $P$ 中收敛，因为函数 $e^t$ 不是多项式。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 例 13.62 是理解「不完备」最干净的教科书范例。在 $[0,1]$ 上带确界度量 $d(f,g)=\sup_{t\in[0,1]}|f(t)-g(t)|$ 时，多项式列 $p_k(t)=1+t+\frac{t^2}{2!}+\cdots+\frac{t^k}{k!}$ 是 $e^t$ 的 Taylor 部分和。由第 10 章的幂级数理论，$e^t$ 的级数在 $[0,1]$ 上一致收敛，所以 $(p_k)$ 在 $M[0,1]$（$[0,1]$ 上的有界函数空间）里是 Cauchy 列，也收敛到 $e^t$；用 Taylor 余项可写成 $\sup_{t\in[0,1]}|e^t-p_k(t)|\le\frac{e}{(k+1)!}\to0$。也可以完全不依赖极限地按 Cauchy 定义直接检验：$\sup_{t\in[0,1]}|p_m(t)-p_n(t)|\le\sum_{j=n+1}^{m}\frac1{j!}$，右端随 $m,n\to\infty$ 趋于 $0$。关键区分由此浮现：这同一个序列在子空间 $P[0,1]$（全体多项式，度量是 $M[0,1]$ 度量的限制）里**仍然是 Cauchy 列**，因为 Cauchy 性只由距离与序列本身决定，与空间里有哪些对象无关；但它**不在** $P[0,1]$ 里收敛，因为极限 $e^t$ 不是多项式。换句话说，Cauchy 性由度量决定，收敛性还要看极限点是否落在所在集合里：同一个序列放进 $M[0,1]$ 就收敛，放进 $P[0,1]$ 就「该收敛却无处可去」。下面的定理 13.64 给出一般判定：$P$ 是完备空间 $M[0,1]$ 的非闭子集，故不可能完备；其闭包（closure）补上的正是 $e^t$ 这类非多项式的一致极限。由 Weierstrass 逼近定理，$[0,1]$ 上每个连续函数都是多项式的确界度量极限，所以 $\overline P=C[0,1]$，这正是 $P$ 的完备化（completion，例 13.67）。注意不完备不是说所有 Cauchy 列都逃逸：$P[0,1]$ 里常数列或收敛到多项式的列照样收敛，不完备只要求存在至少一条 Cauchy 列逃出集合。第一性原理：完备性就是在问「极限点会不会逃出门槛」；把逃出去的点全部收回，得到的就是唯一的最小完备扩张。这个例子也是逼近论与泛函分析的共同起点：完备化把「近似工具」（多项式）扩充成「近似对象的全体极限」（连续函数）。

# §13.8.1 完备性证明（Completeness Proofs）

<span style="color:#2471a3;">**[section]**</span> 我们怎样才能证明给定的度量空间 $(X,d)$ 是完备的呢？

有时可以应用某些定理（例如本节后文出现的定理 13.64）来给出证明。

但更多时候我们必须直接用定义，直接证明 $X$ 中每个 Cauchy 序列都在 $X$ 中收敛。

这可以通过对 $X$ 中任意的 Cauchy 序列 $\{x_k\}$ 施行如下步骤来完成。

1. 找出该序列极限的一个自然「候选」$x_0$。

2. 证明这个候选者确实属于空间 $X$。

3. 验证 $x_k \to x_0$。


<!-- ===== W21 ===== -->

> <span style="color:#7f8c8d">书页 577</span>

<span style="color:#2471a3;">**[section]**</span> 了解到第（2）步是本质性的是很重要的。

例如，正如我们在例 13.61（Example 13.61）中所观察到的，序列 $\{(1 + 1/n)^n\}$ 是空间 $\mathbb{Q}$ 中的 Cauchy 序列（Cauchy sequence），它具有一个自然的极限候选者，即数 $e$，但 $e$ 并不属于 $\mathbb{Q}$。

<span style="color:#2471a3;">**[example]**</span> **例 13.63（Example 13.63）**：为了说明这一过程如何运作，让我们严格用这些步骤给出 $M[a,b]$ 完备（complete）的直接证明。

（在例 13.59 中我们已将此作为定理 9.12（Theorem 9.12）的一个推论得到；现在我们可以反过来把定理 9.12 作为 $M[a,b]$ 完备性的一个推论来获取。）

回忆此处的度量是上确界度量（sup metric）

```math
d(f, g) = \sup_{a \leq t \leq b} |f(t) - g(t)|,
```

收敛性归结为我们在第九章中所称的一致收敛（uniform convergence）。

设 $\{f_k\}$ 是 $M[a,b]$ 中的一个 Cauchy 序列。

**第 1 步。** 我们希望为极限找到一个自然的候选者。

对一致收敛含义稍作反思，就会想到对每个 $t \in [a,b]$ 考虑形如 $\lim_{k \to \infty} f_k(t)$ 的极限。

我们观察到，对每个 $t \in [a,b]$，序列 $\{f_k(t)\}$ 都是实数的一个 Cauchy 序列。

这可由下列不等式立即推出：

```math
|f_n(t) - f_m(t)| \leq \sup_{a \leq s \leq b} |f_n(s) - f_m(s)| = d(f_n, f_m).
```

由于 $\mathbb{R}$ 是完备的，所以对每个 $t \in [a,b]$，

```math
f_0(t) = \lim_{k \to \infty} f_k(t)
```

都存在。

这个极限在 $[a,b]$ 上定义了一个函数 $f_0$。

函数 $f_0$ 就是我们的候选者。

**第 2 步。** 我们必须验证 $f_0 \in M[a,b]$。

为此，我们必须证明 $f_0$ 是一个有界函数（bounded function）。

注意到，$f_0$ 按其定义是有界函数序列的逐点极限（pointwise limit），这一事实本身并不能保证 $f_0$ 有界。

正是 $\{f_k\}$ 是 Cauchy 序列这一事实保证了 $f_0$ 有界。

为看清这一点，选取 $N \in \mathbb{N}$ 使得对所有 $m, n \geq N$ 都有 $d(f_m, f_n) < 1$。

则对所有 $m \geq N$ 以及 $t \in [a,b]$ 有 $|f_N(t) - f_m(t)| \leq 1$。

让该不等式中的 $m \to \infty$，我们看到对所有 $t \in [a,b]$ 有 $|f_N(t) - f_0(t)| \leq 1$。

由于 $f_N \in M[a,b]$，$f_N$ 有界，比方说对所有 $t \in [a,b]$ 有 $|f_N(t)| \leq A$。

于是对所有 $t \in [a,b]$ 有 $|f_0(t)| \leq A + 1$，故 $f_0$ 有界，从而它是 $M[a,b]$ 的一个成员。

**第 3 步。** 我们必须证明在空间 $M[a,b]$ 中 $f_k \to f_0$；也就是说，在 $[a,b]$ 上 $f_k \to f_0$ 一致成立。

同样，仅仅知道逐点地 $f_k \to f_0$ 是不够的。

我们利用逐点收敛来得到候选者，深知倘若存在极限，那它必定是逐点极限。

因此我们仍需验证该收敛是一致收敛。

设 $\varepsilon > 0$。

由于 $\{f_k\}$ 是 $M[a,b]$ 中的 Cauchy 序列，故存在 $N \in \mathbb{N}$，使得若 $n \geq N$，

```math
d(f_n, f_N) \leq \frac{\varepsilon}{2},
```

> <span style="color:#7f8c8d">书页 578</span>

也就是说，

```math
|f_N(t) - f_n(t)| < \frac{\varepsilon}{2}
```

对所有 $t \in [a,b]$ 成立。（7）

于是，对所有 $t \in [a,b]$，

```math
|f_N(t) - f_0(t)| = \lim_{m \to \infty} |f_N(t) - f_m(t)| \leq \frac{\varepsilon}{2}.
```

由（7）和（8）推出，对 $n \geq N$ 且 $t \in [a,b]$，有

```math
|f_n(t) - f_0(t)| \leq |f_n(t) - f_N(t)| + |f_N(t) - f_0(t)| < \varepsilon.
```

（8）

这就证明了在 $[a,b]$ 上 $f_k \to f_0$ 一致成立。$\square$

# §13.8.2 完备空间的子空间（Subspaces of a Complete Space）

<span style="color:#2471a3;">**[section]**</span> 现在假设我们想要证明空间 $C[a,b]$ 是完备的。

我们本可以像处理 $M[a,b]$ 那样来论述，但将 $C[a,b]$ 视为完备空间 $M[a,b]$ 的一个子空间（subspace）更为简便。

一个子空间应当具备何种性质，才能使它自身也是完备的呢？

定理 13.64（Theorem 13.64）给出了答案，并且是检验我们可能遇到的许多空间之完备性的一个有用工具。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 定理 13.64 是本章最该刻进脑子的双向等价：设 $X$ 完备、$Y\subset X$ 是子空间，则 $Y$ 完备当且仅当 $Y$ 在 $X$ 中闭。它把序列式的完备性翻译成了拓扑式的闭性。两个方向互为镜像。$(\Rightarrow)$ 若 $Y$ 闭，任取 $Y$ 中 Cauchy 列 $(y_n)$：先在完备的 $X$ 中拿到极限 $x_0$，再由闭性保证 $x_0\in Y$（闭集装得住自己序列的极限点）。$(\Leftarrow)$ 若 $Y$ 完备，任取 $Y$ 在 $X$ 中的聚点（cluster point）$x_0$，由聚点定义对每个 $n$ 可取 $y_n\in Y\cap B(x_0,1/n)$，于是 $(y_n)\to x_0$；收敛列必为 Cauchy 列，而 $Y$ 中度量就是 $X$ 度量的限制，故 $(y_n)$ 在 $Y$ 中也是 Cauchy 列；借 $Y$ 的完备性，$(y_n)$ 在 $Y$ 内有极限 $y_0\in Y$；再由 $X$ 中极限的唯一性逼出 $x_0=y_0\in Y$。最实用的推论是：**证一个子空间完备，只需证明它是某个完备大空间的闭子集**——例 13.63 用的正是 $C[a,b]$ 是完备 $M[a,b]$ 的闭子空间。这个「向下继承」与算法里「把新问题归约到已解决的母问题」同构：CLRS 讲归约（reduction）时，正是先有母算法的保证，再只验证子条件成立即可；这里也只验「闭」这一条。但要提醒：闭性判据只在母空间完备时生效——$\mathbb{Q}\cap[0,1]$ 在 $\mathbb{Q}$ 中是闭集，却因 $\mathbb{Q}$ 不完备而照样不完备。由此也能理解闭子空间（在完备大空间中即完备）与可分（separable，存在可数稠密子集）为何常在度量空间与泛函分析中成对出现：一个管「极限不逃逸」，一个管「用可数多元素逼近」。

---

<span style="color:#2471a3;">**[theorem]**</span> **定理 13.64**：设 $X$ 是一个完备度量空间（complete metric space），并设 $Y$ 是 $X$ 的一个子空间。

<b style="color:#c0392b;">则 $Y$ 完备当且仅当 $Y$ 在 $X$ 中是闭的。</b>

<span style="color:#2471a3;">**[proof]**</span> **证明**：首先假设 $Y$ 是闭的，且 $\{y_k\}$ 是 $Y$ 中的一个 Cauchy 序列。

由于 $X$ 完备，$\{y_k\}$ 收敛到 $X$ 中的某个点 $x_0$。

但 $Y$ 是闭的，所以 $x_0 \in Y$。

于是 $Y$ 完备。

反过来，假设 $Y$ 完备。

我们证明 $Y$ 是闭的。

设 $x_0$ 是 $Y$ 的一个聚点（limit point）。

则存在 $Y$ 中的序列 $\{y_k\}$ 使得 $y_k \to x_0$。

这个序列在 $X$ 中收敛，因而是 $X$ 中的 Cauchy 序列，从而也是 $Y$ 中的 Cauchy 序列。

由于 $Y$ 完备，序列 $\{y_k\}$ 收敛到 $Y$ 中的某个点 $y_0$。

但极限是唯一的，故 $y_0 = x_0$。

于是 $x_0 \in Y$，且 $Y$ 是闭的。$\square$

# §13.8.3 Cantor 交集性质（Cantor Intersection Property）

> <span style="color:#7f8c8d">*（本小节为 Enrichment section（拓展节），可略去。）*</span>

<span style="color:#2471a3;">**[section]**</span> 这里给出完备性的另一个判别准则。

你会认出，这个定理是 $\mathbb{R}$ 中那熟悉的 Cantor 交集定理（Cantor intersection theorem，见第 4.5.2 节）的直接推广。

<span style="color:#2471a3;">**[theorem]**</span> **定理 13.65**：一个度量空间 $(X,d)$ 是完备的，当且仅当每个半径趋于 0 的闭球（closed ball）递降序列之交恰由单个点构成。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 定理 13.65 把实数轴上的闭区间套直觉升级为一般度量空间版本：**$X$ 完备当且仅当对任一递降的非空闭集列 $F_1\supset F_2\supset\cdots$，只要直径（diameter）$\operatorname{diam}(F_n)\to0$，交集就恰含一个点**。你在 TBB 第 4 章学过实数版 Cantor 交集定理（递降闭区间且长度趋于 $0$ 则交于一点），这里把「区间长度」换成「直径」、把「实数的完备性」换成「任意度量空间的完备性」。两个守恒条件缺一不可。若集合不闭：$I_n=(0,10^{-n})$ 递降且直径趋于 $0$，交集却是空集，因为极限点 $0$ 始终落在每个开区间之外。若直径不趋于 $0$：$\bigcap_n [n,\infty)=\varnothing$（闭但无界、直径恒为 $\infty$），或者 $F_n=[0,1+1/n]$ 交成整个 $[0,1]$——「恰一点」退化成「一坨」。反过来，若 $X$ 不完备，就有一条不收敛的 Cauchy 列，可用它造出直径趋于 $0$、交集为空的递降闭集族，所以这个性质与完备性等价。直观上，直径趋于 $0$ 的递降闭集族像越箍越紧的铁环，完备性保证这组铁环最终箍住且只箍住一个点；这与单调收敛定理同宗，都是用「单调收缩」逼出极限。它也直接为压缩映射铺路：引理 13.73 与定理 13.75 的证明要构造一列递降闭球，其直径恰按 $\alpha^n$ 萎缩，正是本定理的用武之地。算法上的对应物是 CLRS 的二分搜索（binary search）：区间逐轮减半、长度趋于 $0$，Cantor 交集性质保证唯一解被稳稳套住。

**13.8.4 度量空间的完备化（Completion of a Metric Space）**

<span style="color:#7f8c8d" >*（拓展小节，可省略。）*</span>

在我们此前遇到的所有不完备度量空间例子中，我们其实都只是
在某个完备度量空间里挑了一个**非闭**（not closed）的子集。

采用这种方式，我们得到的那个子集里就会出现一些在本子集内不收敛的 Cauchy 序列。

例 13.61 与例 13.62 正是这种情形。

从某种意义上讲，可以证明这正是 Cauchy 序列不能收敛的唯一途径（the only way）。

事实上总是这样：一个不完备空间必然"栖身"于某个更大的完备度量空间之内，
而前者中那些不收敛的 Cauchy 序列，势必会收敛到更大空间里的某一点。

更精确地说，若 $(X,d)$ 是一个度量空间，则总存在一个完备度量空间，
使得 $X$ 能够**等距嵌入**（isometrically embedded）到其中。

于是，存在一个完备度量空间 $(Y,e)$ 及一个函数 $h: X \to Y$，
使得 $h$ 将 $X$ 等距地（isometrically）映到 $h(X)$ 上。

此外，还可以做到让 $(h(X), e)$ 在 $(Y,e)$ 中**稠密**（dense）。

空间 $(Y,e)$ 被称为 $(X,d)$ 的**完备化**（completion），且在等距意义下唯一。

它的含义是：若 $(Y',e')$ 是另一个使 $(X,d)$ 可以作为**稠密子空间**（dense subspace）嵌入其中的完备度量空间，
则 $(Y',e')$ 与 $(Y,e)$ 是**等距的**（isometric）。

让我们将其正式陈述为一条定理，但并不在此给出证明。[^1]

<span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">**定理 13.66**</span>

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 完备化（completion）是本章的「再造奇迹」，可概括成四步模板。(1) 取 $X$ 中全体 Cauchy 序列。(2) 把距离趋于 $0$ 的两条 Cauchy 序列视为等价：$(x_n)\sim(y_n)$ 当且仅当 $d(x_n,y_n)\to0$；这确是一个等价关系。(3) 用等价类构成新空间 $\widehat X$，并定义 $\hat d([(x_n)],[(y_n)])=\lim_n d(x_n,y_n)$——需先证明该极限存在且与代表元选取无关，再验证 $\hat d$ 是度量。(4) 把每个 $x\in X$ 映到常数列 $(x,x,\dots)$ 代表的等价类，证明这是等距嵌入且像在 $\widehat X$ 中稠密。你立刻有两个现成案例：$\mathbb{R}=\overline{\mathbb{Q}}$——例 13.61 展示的正是 $\mathbb{Q}$ 中 Cauchy 列「无处落地」的困境，上述构造把洞补成实数；$C[a,b]=\overline{P[a,b]}$——例 13.62 的多项式列一致收敛到 $e^t$ 却不在 $P[a,b]$ 中，Weierstrass 逼近定理再把所有连续函数补进闭包（例 13.67）。第一性原理：完备化回答的问题是「该收敛却无处可去」的点值不值得收编；补齐前是不完备，补齐后得到唯一的最小完备扩张。这套 Cauchy 列构造与历史一脉相承：Cantor 1872 年用基本列定义实数，Dedekind 同年用分割（cut）完成同一目标。与 CSAPP 的浮点可作对照：IEEE 754 只能表示实数的一个有洞的有限子集，舍入是把真值投回这个有洞子集，与完备化把洞填上是方向相反的操作。唯一性定理则是定心丸：任何包含 $X$ 为稠密子空间的完备空间都与 $\widehat X$ 等距同构，所以「最小」是本质的，不依赖具体构造。

# §13.9 压缩映射 Contraction Maps

设 $f$ 为把区间 $[a,b]$ 映到自身的连续函数（continuous function）。
则 $f$ 必有一个不动点（fixed point）；也就是说，存在点 $x \in [a,b]$ 使得 $f(x) = x$。

为看清这一点，注意若 $a$ 与 $b$ 均非不动点，则 $f(a) > a$ 且 $f(b) < b$。

函数 $g(t) = f(t) - t$ 满足 $g(a) > 0 > g(b)$。

由于 $g$ 连续，可应用中间值定理（intermediate value theorem）证得存在一点 $x$ 使 $g(x) = 0$（定理 5.53）。

由此即得 $f(x) = x$。

对于把 $\mathbb{R}$ 映到 $\mathbb{R}$ 的连续函数，对应的结论则未必成立。

<span style="color:#2471a3;">**[example]**</span>

<span style="color:#c0392b">**例 13.68**</span>

函数 $f(x) = x + 1$ 把 $\mathbb{R}$ 映到自身，却没有任何不动点，因为对任何 $x$ 值 $f(x) = x$ 均不成立。

# §13.9 压缩映射（续）

映射不动点的存在性在分析学中已被证明具有相当的重要性。

我们会问：究竟需要空间 $X$ 具备怎样的性质，才能保证每一个连续函数 $f : X \to X$ 都有不动点。

例如，Luitzen Brouwer（1881–1966）的一个著名定理断言：$\mathbb{R}^n$ 中的任何闭球（closed sphere）都具有这一性质。

我们转而把注意力加以限制：并不考虑一切连续函数，而只考虑在将要定义的意义下为压缩映射（contraction）的那些函数。

例如，若函数 $f : \mathbb{R} \to \mathbb{R}$ 满足 Lipschitz 条件（Lipschitz condition）
```math
|f(x) - f(y)| \le \alpha |x - y|
```
对一切 $x, y \in \mathbb{R}$ 成立，其中 $0 < \alpha < 1$，则 $f$ 就是"压缩"的，其含义是：任意两点 $x$ 与 $y$ 被映到更靠近一起的点 $f(x)$ 与 $f(y)$。

这一条件足以保证 $f$ 必有一个不动点。

<span style="color:#2471a3;">**[example]**</span>

<span style="color:#c0392b">**例 13.69**</span>

函数 $f(x) = x/2$ 或 $g(x) = \sin(x/2)$ 都把 $\mathbb{R}$ 映到 $\mathbb{R}$，并且二者都满足 $\alpha = 1/2$ 的上述 Lipschitz 条件。
<p style="color:#7d3c98">*（只需检验其导数并应用均值定理 mean value theorem。）*</p>

此时 $f$ 与 $g$ 的不动点很容易求出：只要看 $f$（或 $g$）的图像与直线 $y = x$ 的交点即可。

<span style="color:#7f8c8d">*（例如 $f(x)=x/2$ 与 $y=x$ 交于 $x=0$，故不动点为 $0$。）*</span>

> <span style="color:#7f8c8d;">TBB §13.9, p.582</span>

关于某些 Lipschitz 函数不动点存在性的这一陈述，是完备度量空间一个重要性质的特殊情形。

这一性质通常称为 Banach 不动点定理（Banach's fixed point theorem），它断言：完备度量空间到自身的每一个压缩映射都有唯一的不动点。

让我们给出这些术语的精确定义。

<span style="color:#2471a3;">**[definition]**</span>

<span style="color:#c0392b">**定义 13.70（压缩映射 contraction map）**</span>

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 压缩映射（contraction）定义里最重要的红线是**严格且统一**：$d(A(x),A(y))\le\alpha\,d(x,y)$ 中的 $\alpha$ 必须是同一个、贯穿全程小于 $1$ 的常数；只是「每对点都靠近一点」（$d(A(x),A(y))<d(x,y)$ 对一切 $x\ne y$ 成立）不够。例 13.74 的 $f(x)=x+1/x$ 马上演示这种「看上去收缩」的映射如何没有不动点。第一性原理追问：为什么必须统一 $\alpha<1$？因为不动点的证据链是 $d(A^n(x),p)\le\alpha^n d(x,p)$；若只有逐点严格收缩，比值 $d(A(x),A(y))/d(x,y)$ 的上确界可能等于 $1$，$\alpha^n$ 就不会按几何级数归零，误差失去统一的衰减速率。形象地说，逐点收缩保证「每走一步都更近」，但不保证「每步至少按某个固定比例靠近」；只有后一条才能把无穷多步的累计误差压成几何级数。这与数值分析里不动点迭代的收敛条件同源：把第 $n$ 步的距离看成残差，$\alpha$ 就是残差衰减因子，$\alpha<1$ 保证残差按 $\sum_{n\ge0}\alpha^n=1/(1-\alpha)$ 的节奏被控制；工程上「局部表现好但全局衰减因子逼近 $1$」正是迭代慢得不可用的根源。另有一条检验捷径（例 13.69）：当 $A$ 在区间上可微且 $|A'(x)|\le\alpha<1$ 处处成立时，由第 5 章的均值定理，$|A(x)-A(y)|=|A'(c)|\,|x-y|\le\alpha|x-y|$，立得压缩性——这是你用导数控制函数增量的老经验在压缩语言下的直接移植。

---

设 $(X, d)$ 为度量空间，且设 $A : X \to X$。
<span style="color:#00838f">若存在数 $\alpha \in (0, 1)$ 使得
```math
d\big(A(x),\, A(y)\big) \le \alpha\, d(x,y)
```
对一切 $x, y \in X$ 成立，则称 $A$ 为压缩映射（contraction map）。</span>

> <span style="color:#7f8c8d;">TBB §13.9, p.582</span>

<span style="color:#2471a3;">**[definition]**</span>

<span style="color:#c0392b">**定义 13.71（不动点 fixed point）**</span>

设 $(X, d)$ 为度量空间，且设 $A : X \to X$。
<span style="color:#00838f">满足 $A(x) = x$ 的点 $x \in X$ 称为不动点（fixed point）。</span>

> <span style="color:#7f8c8d;">TBB §13.9, p.582</span>

属于压缩映射的若干直接性质需要我们加以确立。
第一条表明：若一个压缩映射有不动点，则它至多只有一个不动点。

<span style="color:#2471a3;">**[lemma]**</span>

<span style="color:#c0392b">**引理 13.72**</span>

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 引理 13.72 与 13.73 合起来装配了压缩迭代的「收敛—不动点」双向引擎，且这两步都不需要完备性。引理 13.72 的唯一性证明清新明洁：设 $x,y$ 都是不动点，代入压缩不等式得 $d(x,y)=d(A(x),A(y))\le\alpha\,d(x,y)$；因 $\alpha<1$，唯一能喂饱这个不等式的是 $d(x,y)=0$，即 $x=y$。这个「把同一个量反向套在自身上、逼它等于 $0$」的手法，是唯一性证明里的常客。引理 13.73 讨论迭代序列 $x_0, A(x_0), A^2(x_0),\dots$ 的两个方向：(1) 若不动点存在，则迭代必收敛到它，因为 $d(A^n(x_0),p)\le\alpha^n d(x_0,p)\to0$；(2) 若迭代收敛到某点 $y$，则 $y$ 必是不动点——由 $A$ 的连续性（压缩映射是 Lipschitz 的），$A(y)=A(\lim_n A^n(x_0))=\lim_n A^{n+1}(x_0)=y$。证明的技术核心是把压缩不等式反复复合，得到 $d(A^n(s),A^n(t))\le\alpha^n d(s,t)$：收缩逐层叠加成几何衰减。这正是 CLRS 递归分析里「每层把规模缩 $\alpha$ 倍、总工作量 $\sum\alpha^n$ 可求和」的思想；相邻迭代点的距离 $d(A^n(x_0),A^{n+1}(x_0))\le\alpha^n d(x_0,A(x_0))$ 也是几何级数，收敛的本源就在这里。要强调的是，这两个引理只谈「若不动点存在」与「若迭代收敛」两条条件结论，尚未保证任何一条前提成立；把存在性这缺掉的一环补上，要等定理 13.75 动用完备性。顺序记牢：**先唯一性，再收敛性，最后完备性，三层各司其职**。

---

设 $A$ 是有一个不动点的压缩映射。
则那个不动点是唯一的。

<span style="color:#2471a3;">**[proof]**</span>

<span style="color:#c0392b">**证明**</span>

为证明同一收缩映射不可能有两个不动点，注意若 $A(x) = x$ 且 $A(y) = y$，则
```math
d(x, y) = d\big(A(x), A(y)\big) \le \alpha\, d(x, y).
```
由于 $\alpha < 1$，这蕴含 $d(x, y) = 0$，从而 $x = y$。

$\square$

> <span style="color:#7f8c8d;">TBB §13.9, p.582</span>

压缩与不动点之间关系的另一特征在于：若 $A$ 是压缩映射，则迭代序列（sequence of iterates）
```math
x_0,\; A(x_0),\; A\big(A(x_0)\big),\; A\Big(A\big(A(x_0)\big)\Big),\; \dots
```
要么必然收敛到不动点，要么（若不存在不动点）必然发散。

# <span style="color:#2471a3;">**[section]**</span> §13.9 压缩映射（Contraction Maps）

<span style="color:#2471a3;">**[lemma]**</span> **引理 13.73**：设 $A$ 是一个压缩映射 contraction map，令 $x_0$ 是（某个）度量空间中的元素，并构造序列

```math
x_1 = A(x_0),\quad x_2 = A(x_1),\quad x_3 = A(x_2),\ \ldots
```

那么

1. <span style="color:#00838f">若 $A$ 有不动点 fixed point $x$，则 $x_n \to x$。</span>
2. <span style="color:#00838f">若 $x_n \to x$，则 $x$ 是 $A$ 的不动点。</span>

<span style="color:#2471a3;">**[proof]**</span> **证明**：设 $s, t$ 是度量空间中的任意两个元素，并令 $A^n$ 表示 $A$ 与其自身的 $n$ 次复合 composition。注意到，由压缩映射的定义，

```math
d(A(s), A(t)) \le \alpha\, d(s, t),
```

以及

```math
d(A^2(s), A^2(t)) \le \alpha\, d(A(s), A(t)) \le \alpha^2\, d(s, t),
```

如此这般继续下去，便得到

```math
d(A^n(s), A^n(t)) \le \alpha^n\, d(s, t) \qquad (9)
```

对所有 $n$ 成立。将 $s$ 换成 $x_0$，将 $t$ 换成 $x$，其中 $x$ 是 $A$ 的不动点，故而 $x = A(x) = A^2(x) = \cdots = A^n(x)$，于是得到

```math
d(A^n(x_0), x) \le \alpha^n\, d(x_0, x) \to 0 \qquad (10)
```

当 $n \to \infty$ 时成立。这证明了第一个断言。

为证第二个断言，我们先来验证每个压缩映射都是连续的（见习题 13.9.5）。设 $x_n \to x$。注意 $x_{n+1} = A(x_n)$ 且 $x_{n+1} \to x$；由连续性，$A(x_n) \to A(x)$，因此 $A(x) = x$，即 $x$ 是 $A$ 的不动点。$\square$

> <span style="color:#7f8c8d;">TBB §13.9, p.583</span>

这两个引理并未确立一个压缩映射不动点的存在性；事实上，很容易举出一个没有不动点的压缩映射的例子。我们将看到，完备空间 complete space 上的压缩映射必有一个不动点。但请注意，一个压缩映射所做到的并不仅仅是"把点彼此拉得更近"：它把它们以一个严格小于 1 的因子 factor 拉到一起。下面的例子展示了一个（在完备空间上）近乎压缩的映射，却没有任何不动点。

<span style="color:#2471a3;">**[example]**</span> **例 13.74**：函数

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> 例 13.74 是区分「逐点严格收缩」与「统一 $\alpha<1$」的分水岭，反复体会能避免概念误判。函数 $f(x)=x+1/x$ 在 $[1,\infty)$ 上满足 $|f'(x)|=|1-1/x^2|<1$，且 $x\ne x+1/x$ 故无不动点，看似压缩实则不是。由均值定理，任取 $x<y$ 都有 $|f(x)-f(y)|=|f'(c)|\,|x-y|<|x-y|$，逐点看确实「每对点都被拉近」；但压缩定义要求的是 $\sup_{x\ne y}\frac{|f(x)-f(y)|}{|x-y|}\le\alpha<1$，而这个上确界在 $[1,\infty)$ 上等于 $1$——因为 $x\to\infty$ 时 $f'(x)\to1$，不存在任何低于 $1$ 的常数 $\alpha$ 能统一压住所有点对的收缩率。图 13.4 的标注 $A/B\to1$ 点破的正是这一点：当 $x_1,x_2\to\infty$ 时，两像点距离与原像点距离之比趋于 $1$。第一性原理：压缩关心的不是在某个有限区域里缩得多狠，而是最坏处（这里是无穷远）的收缩率是否被钉死在 $<1$。这个训诫在工程上同样成立：数值迭代若只是局部表现好、全局衰减因子逼近 $1$，残差可能收敛极慢甚至停滞。最后对比两种不动点配方：Brouwer 型（紧致）给存在性但不给唯一性，也未必可构造；Banach 型（完备+统一压缩）给出可构造、可估计误差且收敛到唯一不动点的迭代。Wikipedia 的 Contraction mapping 词条也以 $[1,\infty)$ 上的 $x+1/x$ 为经典反例。

---

```math
f(x) = x + 1/x
```

把完备度量空间 $[2, \infty)$ 映到自身，并且 $f'(x) = 1 - x^{-2}$ 满足 $0 < |f'(x)| < 1$ 对所有 $x \in [2, \infty)$ 成立。因此，若 $x$ 与 $y$ 彼此靠近，则 $f(x)$ 与 $f(y)$ 甚至更靠近。但这个函数没有不动点，因为对所有 $x$，

```math
x \ne x + 1/x.
```

请注意，它却并非一个压缩映射。不等式

```math
|x + 1/x - (y + 1/y)| \le \alpha\, |x - y|
```

不可能对所有 $x, y \in [2, \infty)$ 和任何 $\alpha < 1$ 都成立（尽管它确实对 $\alpha = 1$ 成立）。[参见图 13.4。注意 $A/B < 1$，但 $\lim_{x_1,\,x_2 \to \infty} A/B = 1$，这正说明函数 $f$ 在 $[2, \infty)$ 上不可能是压缩映射。] $\square$

注意到，在定理 13.75 中，压缩映射满足 $\alpha < 1$ 这一事实在证明中起着本质作用 essential role。

> <span style="color:#1e8449;">**[note] Note（译者注）：**</span> Banach 不动点定理（Banach fixed-point theorem）是二十世纪分析学里被反复套用的工具之一，通常追溯到他 1920 年的博士论文，核心结果 1922 年发表于《Fundamenta Mathematicae》。先回顾定义：度量空间 $(X,d)$ 上的映射 $A:X\to X$ 若存在常数 $\alpha\in(0,1)$ 使 $d(A(x),A(y))\le\alpha d(x,y)$ 对一切 $x,y$ 成立，就称为压缩映射（contraction map）；满足 $A(x)=x$ 的点称为不动点（fixed point）。注意 $\alpha$ 必须严格小于 $1$：TBB 例 13.74 的 $f(x)=x+1/x$ 在 $[2,\infty)$ 上每两点都被拉近（$0<f'<1$），却不是压缩映射，也没有不动点，这正说明“严格收缩因子”是定理的心脏。  证明可凝成一个两层模板。第一层构造候选：任取 $x_0\in X$，反复迭代得 $x_n=A^n(x_0)$。第二层证 Cauchy 列（Cauchy sequence）：对 $n\le m$，先用压缩不等式 (9) 写出 $d(x_n,x_m)=d(A^n(x_0),A^n(x_{m-n}))\le\alpha^n d(x_0,x_{m-n})$；再用三角不等式把末项拆成 $d(x_0,x_1)+\cdots+d(x_{m-n-1},x_{m-n})$，逐项套 (9) 得 $d(x_0,x_{m-n})\le d(x_0,x_1)(1+\alpha+\cdots+\alpha^{m-n-1})$。有限几何级数（geometric series）部分和不超过无限级数 $\sum_{k=0}^{\infty}\alpha^k=1/(1-\alpha)$，于是 $d(x_n,x_m)\le\alpha^n d(x_0,x_1)/(1-\alpha)$。因 $\alpha^n\to0$，任给 $\varepsilon>0$ 取 $N$ 使 $\alpha^N d(x_0,x_1)<\varepsilon(1-\alpha)$，即得 Cauchy 条件。第三层由完备性（completeness）落地：$X$ 完备保证 $x_n\to x\in X$，压缩映射必连续，对 $x_{n+1}=A(x_n)$ 两边取极限得 $x=A(x)$。唯一性来自引理 13.72：若 $A(x)=x$、$A(y)=y$，则 $d(x,y)\le\alpha d(x,y)$，$\alpha<1$ 迫使 $x=y$。合起来就是 TBB 的 Theorem 13.75（Banach）。前提缺一不可：不完备时 $A(x)=x/2$ 在 $(0,1]$ 上是压缩映射却无不动点；把压缩换成恒等映射，不动点可以有无穷多个，唯一性随之失效。  这个证明同时给出误差估计：把 $m$ 取极限得 $d(x_n,x)\le\alpha^n d(x_0,x_1)/(1-\alpha)$，即逐次逼近（successive approximations）按几何速率收敛，这也是数值上实用的停机判据。应用时最常见的验证手段是第 7 章的微分中值定理（mean value theorem）：若 $A$ 可微且 $|A'|\le\alpha<1$ 恒成立，则中值定理直接给出压缩条件。TBB 例 13.76 解 $\cos x=x$ 时，$|\cos'|=|\sin|$ 在 $[1/2,1]$ 上最大为 $\sin 1<1$，故 $\cos$ 在该区间是压缩映射（习题 13.9.3 还提醒它在 $[0,\pi]$ 上不是）；用计算器反复按 cos 键，数字迅速逼近 $0.73908513$，读者不妨亲手试。  这条线索与本书前后章节同源。第 2 章 Sequences 引入迭代与几何级数部分和（Example 2.34），第 3 章 Infinite Sums 的几何级数正是分母 $1-\alpha$ 的来源；第 5 章连续函数那套不动点结论（习题 5.8.6：$f:[a,b]\to[a,b]$ 连续必有不动点）只保证存在、不给唯一性与收敛速度，Banach 定理用更强的压缩假设换来了三者；第 9 章一致收敛（uniform convergence）在此现身——$C[a,b]$ 配 sup 度量后，逐次逼近的收敛正是函数列的一致收敛，Picard 定理（Theorem 13.86）对 $y'=f(x,y)$ 构造积分算子 $(\mathcal A\varphi)(x)=y_0+\int_{x_0}^x f(t,\varphi(t))\,dt$，验证它是压缩映射便得初值问题局部唯一解；数值分析课程里的不动点迭代与 Newton 法也是同一套路：把解方程 $A(x)=x$ 变成迭代、误差按几何速率收缩。Banach（1892–1945）是泛函分析（functional analysis）的奠基人之一，Banach 空间（Banach space）即以他命名；定理因此成为从常微分方程（ODE）到数值分析的广谱工具。

<span style="color:#2471a3;">**[theorem]**</span> **定理 13.75（Banach 定理）**：<span style="color:#c0392b">定义在完备度量空间 $(X, d)$ 上的压缩映射 $A$ 有唯一的一个不动点。</span>

> <span style="color:#7f8c8d;">TBB §13.9, p.584</span>

<span style="color:#2471a3;">**[proof]**</span> **证明**：我们从空间中任意一点 $x_0$ 出发并对该函数做迭代，从而获得 $A$ 的不动点。令 $x_0 \in X$。令 $x_1 = A(x_0)$，$x_2 = A(x_1) = A^2(x_0)$，一般而言，

```math
x_n = A(x_{n-1}) = A^n(x_0) \qquad (n = 1, 2, \ldots)
```

这里我们采用了惯常记号 $A^{n+1}(x) = A(A^n(x))$。

我们要证明序列 $\{x_n\}$ 是一个 Cauchy 序列。设 $n \le m$。那么，利用不等式 (9)，我们得到

```math
d(x_n, x_m) = d(A^n(x_0), A^m(x_0))
= d\bigl(A^n(x_0), A^n(A^{m-n}(x_0))\bigr) \le \alpha^n\, d(x_0, x_{m-n}).
```

我们可以借助三角不等式与不等式 (9) 来估计后面这一项：

```math
d(x_0, x_{m-n}) \le d(x_0, x_1) + d(x_1, x_2) + \cdots + d(x_{m-n-1}, x_{m-n})
```

```math
\le d(x_0, x_1)\,\bigl[\, 1 + \alpha + \alpha^2 + \cdots + \alpha^{\,m-n-1} \bigr]
```

```math
\le \frac{d(x_0, x_1)}{1 - \alpha}.
```

令 $\varepsilon > 0$。选取 $N$ 使得

```math
\alpha^N\, d(x_0, x_1) < \varepsilon\,(1 - \alpha).
```

那么，当 $m \ge n \ge N$ 时，从这些不等式可得

```math
d(x_n, x_m) \le \frac{\alpha^n\, d(x_0, x_1)}{1 - \alpha} < \varepsilon
```

于是 $\{x_n\}$ 是 $X$ 中的 Cauchy 序列。由于 $X$ 完备，$\{x_n\}$ 收敛到某点 $x \in X$。又因压缩映射必连续（习题 13.9.5），故
```math
A(x) = A\Bigl(\lim_{n\to\infty} x_n\Bigr) = \lim_{n\to\infty} A(x_n) = \lim_{n\to\infty} x_{n+1} = x,
```
即 $A(x) = x$，$x$ 是 $A$ 的不动点。不动点的唯一性由引理 13.72 保证。$\square$
