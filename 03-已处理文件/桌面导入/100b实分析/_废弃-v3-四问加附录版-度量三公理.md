## 问题一：度量凭什么能自己换？

> 「度量还能自己换？只要满足性质就行？」

**三行短答**：

1. 度量不是"上帝给的距离"，是**一座桥**：你写下一个满足三条的函数，就指定了一套几何。
2. 课上那个怪例子不是新发明，它是把 $\mathbb R$ 上现成的几何**搬到** $\mathbb N$ 上（拉回 / pullback）。
3. 每次换尺子，换掉的不是"数值"，而是**哪些定理还活着** —— 所以"可塑性"的代价落在问题三、四里。

### 1.1 那个怪例子到底是什么

课上给的例子：$\mathbb N=\{1,2,3,\dots\}$ 上 $d(m,n)=\left|\frac1m-\frac1n\right|$。取 $f(n)=1/n$（单射），把 $\mathbb R$ 的通常距离沿 $f$ 拉回：

```math
d_{\mathbb N}(m,n)\;:=\;d_{\mathbb R}\bigl(f(m),f(n)\bigr)\;=\;\left|\frac1m-\frac1n\right|.
```

于是 $\bigl(\mathbb N,d_{\mathbb N}\bigr)$ 与子空间 $\bigl(\{1,\tfrac12,\tfrac13,\dots\},|\cdot|\bigr)$ **等距同构**，只是点的名字换了。三条公理逐条免费继承：

- **非负、只在同点为零**：靠 $f$ 是单射（$f(m)=f(n)\Rightarrow m=n$）；
- **对称**：$|a-b|=|b-a|$；
- **三角**：$|a-c|\le|a-b|+|b-c|$，$\mathbb R$ 的三角不等式。

**教训不是"度量可以随便造"，而是"标签会撒谎"**：$n$ 与 $n+1$ 名字挨着，$1/n$ 与 $1/(n+1)$ 却越走越近；换回 $f(n)=n$，同一个 $\mathbb N$ 立刻变回"无界、不完备"的通常几何。**同一个集合，两套几何。**

### 1.2 为什么"只要满足性质就行"是正当的

公理化方法的全部要点：**公理不指认对象，只规定关系**。三条公理说"距离满足这几条关系"，至于 $X$ 里装的是点、函数、字符串还是图上的节点，公理不管。所以任何满足三条的对象都是合法模型 —— 这不是大意，是设计意图。

这个操作在社区有标准条目：MSE [*What is a pullback of a metric, and how does it work?*](https://math.stackexchange.com/questions/2849050)（45 票）专讲它。[C]

> **原文（双语双链，[B] TBB Definition 13.6 及其后一段）**：
> "A metric space is an ordered pair $(X,d)$, where $X$ is a nonempty set and $d$ is a metric on $X$. … **There can be many different metrics on a set $X$.** If more than one metric is under consideration, we must make it clear which metric is considered at a particular point of …"
>
> **中文批注（术语保留原词）**：教材**自己**把"同一个集合 $X$ 上可以有很多不同的 metric、必须说清当下用的是哪一个"写进了定义之后的第一段。所以问题一不是教授的个人癖好，是**教材级事实**：metric 是 $(X,d)$ 这个 ordered pair 的一半，不是你从 $\mathbb R$ 继承来的固有属性。

### 1.3 数学家拿它干什么（四个真实结构）

| 度量 | 力学机制 | 它服务的东西 |
|---|---|---|
| 最短路径度量 | 路径长度取下确界；三角不等式 = 路径可拼接 | 有向图 / 路由；有向图上退化为**拟度量**（$d(u,v)\ne d(v,u)$） |
| 编辑距离 | 编辑操作序列的最短代价 | 字符串 / 序列比对（纠错、生物序列） |
| 上确界度量 $\sup_x|f(x)-g(x)|$ | 函数当点；三角不等式靠 $\sup$ 的单调性 | **一致收敛**、Banach 不动点、ODE 的 Picard 迭代 |
| 离散度量 $d(x,y)=1\ (x\ne y)$ | 三条全满足（三角取等号） | 任意集合上的"最干净"度量，**候选定理的试金石** |

社区经验：候选"度量定理"先丢进**离散度量**验一遍，它必须成立（哪怕退化）。MSE [*Nonobvious examples of metric spaces that do not work like $\mathbb R^n$*](https://math.stackexchange.com/questions/1064375)（56 票）是这类例子库。[C]

### 1.4 常见错误

- ❌「度量可以随便造」——造完要**逐条验公理**，最常死在三角不等式：$|x-y|^2$ 就崩，$d(0,4)=16>d(0,1)+d(1,4)=10$。
- ❌「换了度量，结论当然还成立」——恰恰不成立（问题三、四）。

## 问题二：凭什么"满足三公理"就能迁移？

> 「怎么证明只要该度量符合度量定义，数学工具就能迁移？……怎么证明一个工具只依赖于这三个条件？」

**三行短答**：

1. 迁移**不需要**为每个空间重证一遍：从公理推出的东西，在每个满足公理的对象里都真。
2. 检验"只用三公理"的唯一可靠办法：**把证明一行一行读，写出每行的依据**。
3. "能否迁移"是**证明的属性**，不是定理名字的属性 —— 同一句话换一种表述，答案可能变（§3.3）。

### 2.1 迁移的机制（一句话）

设 $\Sigma$ 是三条度量公理，$\pi$ 是从 $\Sigma$ 出发、结论为 $T$ 的证明。则对**每个**满足 M1–M3 的 $(X,d)$，把 $\pi$ 的每一行按这个 $(X,d)$ 解释，每行仍为真，故 $T$ 在 $(X,d)$ 里成立。教材里"验证它是度量，然后所有度量定理随便用"的全部依据就是这一句，不多不少。

它为什么不是循环论证：

- **审计是句法的**：数的是"这行依据了哪条"，不预设结论真假（像链接器数未解析符号，不运行程序）。
- **审计必然终止**：每行只有四类可能（见 2.2）。
- **桥在审计之外**：审计给出"没有多要"；"没有多要 ⇒ 处处成立"由上面那句机制负责。

### 2.2 怎么检验（可操作）

把证明摊开，**每行问一句"凭什么"**，答案只能落进四格：

| 依据 | 处理 |
|---|---|
| 逻辑规则（重言式、等词、量词规则） | 不记（任何结构里都成立） |
| 已证过的引理 | 递归查它的账 |
| 直接引用 $d(x,x)=0$ / $d(x,y)=d(y,x)$ / $d(x,z)\le d(x,y)+d(y,z)$ | 记 M1 / M2 / M3 |
| 展开某个定义 | **查定义右边有没有引入新东西**（序、代数、开集族、测度） |

再配一张**背景清单**：$\mathbb R$ 的加法、乘法、序、$0<1$、"有限个实数有最大元"—— 一律算免费（只谈数值，不谈 $X$）。而 $\mathbb R$ 的**完备性**（上确界存在）、阿基米德性：用了就要写明。

### 2.3 哪些工具能迁移？特征是什么？

**特征一句话**：只谈"接近与分离"，只触碰 $d$ 的**值**；点只作为 $d$ 的自变量出现。

| 类别 | 例子 | 说明 |
|---|---|---|
| **能迁移** | 收敛列唯一；收敛 ⇒ 有界；收敛 ⇒ Cauchy；连续保收敛；连续复合连续；闭集对极限封闭；开球/闭球基本性质；压缩映射定理（需完备） | 压缩映射只要求完备，不要线性结构 —— 正面重注 |
| **能说、但不保证** | 完备、紧、连通、可分 | 定义写得出来（§4），但"每 Cauchy 列收敛"不是三公理的推论 |
| **根本写不出来** | 单调收敛、夹逼、介值（原形）、可微、最值（除非值域全序） | 需要 $X$ 上的序或代数 |

### 2.4 三个"看起来用了、其实没算"的坑

1. **提到 ≠ 用到**：写下 $d(x,y)\ge0$ 不代表用了它的内容。
2. **定义展开偷渡**：展开定义把"$X$ 上的序""开集族"引进来，不是免费的。
3. **参数顺序不一致**：收敛写 $d(x_n,a)$、有界写 $d(c,x_n)$，则从前者推后者要用 **M2**，依赖表从空变 $\{M2\}$。

## 问题三：怎么证明「$\mathbb R$ 上某条定理」本质上只用了三公理？

> 「如何证明实数轴上的这些定理本质上只用了这三个公理」

**三行短答**：

1. 把定理**改写成只用 $d$ 说话的句子**（写不出 ⇒ 它不是度量定理，直接判死）。
2. 逐行审计，得到依赖表 $D$。
3. 想证明"不止三条"就反过来：**删一条公理，造一个模型**，看它死在哪。

下面两个示范你自己能复现。

### 3.1 示范一：「收敛 ⇒ 有界」——审计结果是**空集**

> **定理**：$(X,d)$ 度量空间，$x_n\to a$，则 $\exists c\in X,\exists R\in\mathbb R,\forall n: d(x_n,c)\le R$。

**证明（左）与依据（右）**：

1. 取 $\varepsilon=1$：$\exists N,\forall n\ge N: d(x_n,a)<1$ ——〔定义展开 + $\mathbb R$ 含 $1$〕
2. 令 $S=\{d(x_1,a),\dots,d(x_{N-1},a),1\}$ ——〔集合论，背景〕
3. $S$ 有限非空 ⇒ 有最大值 $R$ ——〔**背景**：有限非空全序集有最大元〕
4. $n<N$ 时 $d(x_n,a)\in S\Rightarrow\le R$；$n\ge N$ 时 $d(x_n,a)<1\le R$ ——〔$\mathbb R$ 的序，背景〕
5. 取 $c=a$：$\forall n,d(x_n,c)\le R$。$\square$

**$D=\varnothing$：M1、M2、M3 一条都没用。**

**这不是"白干"**，它给出更强的结论：**这条定理对任意函数 $d:X\times X\to\mathbb R$ 都成立**（不对称、不满足三角、甚至不必非负）。所以它**不是度量定理**。这解释了它为什么对汉明、编辑、离散全部成立 —— 不是"它们都是度量"，而是这条定理连度量都不需要。

### 3.2 示范二：「极限唯一性」——三条，而且三条都真的需要

> **定理**：$x_n\to a$ 且 $x_n\to b$，则 $a=b$。

1. 任取 $\varepsilon>0$：$\exists N_1,\forall n\ge N_1: d(x_n,a)<\varepsilon/2$；$\exists N_2$ 同理对 $b$ ——〔定义 + $\mathbb R$ 算术〕
2. 取 $n\ge\max(N_1,N_2)$：$d(a,b)\le d(a,x_n)+d(x_n,b)$ ——〔**M3**〕
3. $d(a,x_n)=d(x_n,a)<\varepsilon/2$ ——〔**M2**〕
4. $d(a,b)<\varepsilon$ 对一切 $\varepsilon>0$ ⇒ $d(a,b)=0$ ——〔$\mathbb R$ 的序〕
5. $d(a,b)=0\Rightarrow a=b$ ——〔**M1 的定性半**〕

**$D=\{\text{M1},\text{M2},\text{M3}\}$。** 更精确的归因：**M2 是实质承担者**（第 3 行纯粹为对称）；M1 只需"$d=0\Rightarrow$ 同点"这一半；M3 只需一族单侧估计。

### 3.3 同一句人话，两种表述，两张依赖表

「收敛列有界」若写成**直径形式** $\exists M\,\forall m,n:d(x_m,x_n)\le M$，从球形式推过去要补两行：

```math
d(x_m,x_n)\le d(x_m,a)+d(a,x_n)=d(x_m,a)+d(x_n,a)\qquad[\text{M3，然后 M2}]
```

于是 $D=\{\text{M2},\text{M3}\}$，不再是空集。**所以"这条定理依赖几条公理"在固定表述与证法之前是病句。** 换表述就是换题目。

### 3.4 反方向：怎么证明"不止三条"

唯一办法：**造一个违反它的模型，其余都正常，看定理在里面是否为假**。针对极限唯一性的三个坏世界：

| 删掉 | 模型 | 见证 |
|---|---|---|
| M1 的定性半 | 伪度量 $d\equiv0$ | 每个序列收敛到每个点 |
| M2 | $X=\{a,b\}$，$d(a,a)=d(b,b)=0$，$d(a,b)=0$，$d(b,a)=1$ | 常序列 $a,a,\dots$ 同时收敛到 $a$ 与 $b$ |
| M3 | $X=\{a,b\}\cup\{u_n\}$，$d(a,u_n)=d(b,u_n)=1/n$，$d(a,b)=1$，$d(u_m,u_n)=|1/m-1/n|$ | $n\ge3$ 时 $1=d(a,b)>\tfrac1n+\tfrac1n$；而 $d(u_n,a),d(u_n,b)\to0$ |

第三个必须自己逐条验 M1、M2 —— **这是造反例真正的工作量，也最容易做错**；M3 只在三元组 $(a,b,u_n)$ 上崩，且要 $n\ge3$。

这套做法在数学里的名字是"**公理的独立性**"。社区同题：MSE [*Unneeded Restriction in Metric Spaces?*](https://math.stackexchange.com/questions/85697)。历史源头是 Hilbert 1899《几何基础》用模型证平行公理独立（球面几何、Poincaré 模型）。[C]/[B]

### 3.5 一个提醒

日常不必每次都摆形式表格；判据就是 2.2 的四格 + 背景清单。但**必须写下来**：只靠脑子记"我好像只用了三角不等式"，就会在参数顺序与定义展开这两处栽跟头。

## 问题四：怎么证明「某些概念」只依赖三公理？

> 「如何证明你刚刚说的很多概念都只依赖于这三个公理？」

**三行短答**：

1. 概念层的判据只有一条：**这个概念能不能只用 $d$（和量词）说清楚**。
2. "能说清楚"和"能推出"是两件事：完备、紧、连通**说得清**，但它们的定理**推不出**。
3. 还有一个免费否证器：**不是等距不变的，就一定不是度量概念**。

### 4.1 判据：写得出公式吗

一个概念 $C$ 只依赖度量 $\iff$ 存在一个**只用 $d$、变量跑在 $X$ 与 $\mathbb R$（含指标 $\mathbb N$）上**的公式 $\varphi_C$，使得在每个 $(X,d)$ 里

```math
C(x_1,\dots,x_k)\iff\varphi_C(x_1,\dots,x_k).
```

举三个立刻能写的：

- 「$x_n\to a$」：$\forall\varepsilon>0\ \exists N\ \forall n\ge N:\ d(x_n,a)<\varepsilon$；
- 「$f$ 在 $a$ 连续」：$\forall\varepsilon>0\ \exists\delta>0\ \forall x:\ d(x,a)<\delta\Rightarrow d(f(x),f(a))<\varepsilon$；
- 「$x$ 是 $B(a,r)$ 的内点」：$\exists s>0\ \forall y:\ d(x,y)<s\Rightarrow d(y,a)<r$。

**写不出来**的典型： 「$x_n$ 单调递增」（要 $X$ 上的 $\le$）、「$f$ 可微」（要减法和除法）、「$f$ 在 $[a,b]$ 上取到最小值」（要序，且要比大小）。这类概念**死在表达层**：不是证明难，是这句话在一般度量空间里根本没有意义。

### 4.2 "能写" ≠ "能证"：完备性就是分界样本

「每 Cauchy 列收敛」是纯 $d$-语句（写得出来 ✓），但它**不是**三公理的推论：

- 若它是，则它在每个度量空间成立；
- 反例：$(\mathbb N,d)$，$d(m,n)=|1/m-1/n|$（问题一的拉回），$x_n=n$ 是 Cauchy（$|1/n-1/m|\le 1/n+1/m\to0$），但不收敛（若 $\to k$，则 $d(n,k)\to1/k\ne0$）。
- 所以 $(\mathbb N,d)$ 不完备，而它满足全部三条公理。**反例就是"证不出来"的证书。**

> **教材级对照（[B] TBB，同章）**：Definition 13.60 把完备定义为 "A metric space $(X,d)$ is **complete** if every Cauchy sequence in $X$ converges (to an element of $X$)."；紧接着 Example 13.61 就给反例 —— $\mathbb Q$ 配 $\mathbb R$ 的通常度量**不完备**：序列 $\{(1+1/n)^n\}$ 是 Cauchy 却不收敛于 $\mathbb Q$ 中的点。**这条比我上面那个 $(\mathbb N,|1/m-1/n|)$ 更贴身**：它说明"完备"这句话完全写得进 metric language（Definition 13.60 就是纯 $d$-语言），但在 $\mathbb Q$ 里就是假的。**写得出口 ≠ 证得出来**，教材用一个 Example 就把这条界线画完。

这个分界在数学里有专门的名字，而且是**两个不同层次的"性质"**：

| 说法 | 正确版本 |
|---|---|
| 「完备性是拓扑性质」 | ❌ 反例一：$\mathbb R$ 与 $(0,1)$ 同胚，但 $\mathbb R$ 完备、$(0,1)$ 不完备（$x_n=1/n$ 是 Cauchy，极限 $0\notin(0,1)$）。反例二：$\mathbb R$ 上 $d(x,y)=|x-y|$ 与 $d'(x,y)=|\arctan x-\arctan y|$ 生成**同一个拓扑**，但 $x_n=n$ 在 $d'$ 下是 Cauchy 而不 $d'$-收敛 ⇒ $d'$ 不完备。所以完备性依赖**具体 $d$**，同胚保不住 |
| 「完备性是度量性质」 | ✅ 对：它只由 $d$ 决定（这点与"三公理的推论"是两件事 —— 见问题三的反例）。MSE [*Connections between metrics, norms and scalar products*](https://math.stackexchange.com/questions/38460) 里用 "purely metric property of completeness" 这个措辞把界线钉住。[C] |

> **一处必须点明的常见误传**：不少人以为 $d$ 与 $\min(d,1)$ 是"同拓扑但完备性不同"的例子 —— **这是错的**。两者有**相同的 Cauchy 列与相同的收敛列**（$\varepsilon<1$ 时 $\min(d,1)<\varepsilon\iff d<\varepsilon$），所以完备性完全一致。要打这个例子，必须换成上面那两个。

一句话记法：**完备性说得出口（度量语言），但推不出来（不是三公理的结论），也不被拓扑保住（不是拓扑性质）。**

### 4.3 免费的否证器：等距不变性

> **命题**：若概念 $C$ 由**不含任何参数**的 $d$-公式定义，则 $C$ 在每个 $(X,d)$ 的每个**等距同构**（$d(fx,fx')=d(x,x')$ 的双射 $f$）下不变。

**证明**：$d$ 是唯一的空间符号，而等距恰是保 $d$ 的双射；$f$ 双射故 $X$ 上量词保真，$\mathbb R$、$\mathbb N$ 的解释跨空间固定。对公式复杂度归纳即得。

**用法（逆否）**：只要你发现某个概念在搬动后变了，它就不可能是度量概念 —— 不用读完任何证明。

- 「$x$ 是自然数」：平移 $x\mapsto x+1/2$ 就变 ⇒ 不是度量概念；
- 「$x$ 恰好是球心」：球心依赖"谁被选作中心"，不是等距不变的 ⇒ 不是；
- 「$X$ 完备」「$X$ 紧」「$X$ 连通」：等距不变的 ✓（所以它们是**能说**的概念，问题只出在"能不能证"）。

**一个陷阱（这条是行家会问的）**：公式里一旦带了参数，命题就假。取 $X=\mathbb R$ 通常度量，公式 $\varphi(x):=(d(x,1)=0)$ 定义的集合是 $\{1\}$；但等距 $f(x)=x+0.5$ 把它搬到 $\{1.5\}$。所以判据必须写"**不含任何参数**"，否则"可定义"会被参数偷渡。这套想法在逻辑学里有名字：**Padoa 1900 的不可定义性方法**（用"两个模型、其余符号相同、这个符号不同"来证不可定义），后续由 Tarski、Beth 整理成现代形式。[A]

### 4.4 概念层与定理层的分工表（这一张表是四问的总账）

| | 概念层（问题四） | 定理层（问题三） |
|---|---|---|
| 问什么 | 这个概念**说得出口**吗 | 这条定理**证得出来**吗 |
| 手段 | 给一个只用 $d$ 的公式；或查等距不变 | 逐行审计（§2.2） |
| 失败形态 | 死在表达层（单调、可微、介值原形） | 说得出口但证不出来（完备、紧、连通） |
| 免费否证器 | 不是等距不变 ⇒ 一定不是 | 造出反例模型 ⇒ 一定证不出来 |

### L4 前沿：开问题、失效边界、今天能做的实验

- **"$\mathbb R$ 墙"可以量化** [A]：reverse mathematics —— 完备可分度量空间在 $RCA_0$ 里可编码，大量分析在 $RCA_0$ 内展开；**Heine–Borel $\leftrightarrow WKL_0$**、**Bolzano–Weierstrass $\leftrightarrow ACA_0$**。坐标：Simpson *SOSOA*；Hirst [ASL 2001 slides](https://www.appstate.edu/~hirstjl/snp/pdfslides/asl2001.pdf)。
- **三角不等式的范畴解释** [A]：Lawvere 1973 —— 度量空间 = 在 $[0,\infty]$ 上**富化**的范畴，三角不等式 = composition，$d(x,x)=0$ = identity；删掉对称性 = 换 enrichment base。[nLab](https://ncatlab.org/nlab/show/metric+on+a+category)
- **值域也能换** [A]：Kurepa 1934 pseudo-metric spaces（取值为全序集）、Sikorski 的 $\omega_\mu$-metric（取值为全序 abelian group）—— "值域不必是 $\mathbb R$" 是有 90 年历史的纲领。
- **边界仍在移动** [A]：余弦相似度的完整三角不等式直到 **SISAP 2021**（E. Schubert）才补出来 —— "缺一条公理就得补一次"不是历史遗迹。
- **今天就能做的三个实验**：① 把「收敛 ⇒ 有界」写成球形式与直径形式，各审一遍，得到 $\varnothing$ 与 $\{M2,M3\}$；② 用 float32 造 M3 反例（灾难性抵消），打印三项距离；③ 给 DTW 检索硬套三角剪枝，观察"召回下降而延迟不变"。

### 6.2 五道闭卷自推题（对齐"每类证明 ≥5 题"）

1. 证「开球是开集」，逐行写依据 → 预期 $D=\{\text{M3}\}$。
2. 证「收敛列 ⇒ Cauchy 列」→ 预期 $D=\varnothing$（只用 $\varepsilon/2$ 与 $d<\varepsilon$）。
3. 证「$f$ 连续 ⇒ 送收敛列到收敛列」→ 预期 $D=\{\text{M2}\}$（要用 $d(fx_n,fa)=d(fa,fx_n)$ 对齐方向）。

5. 用**等距不变**否证一个概念（例如"$x$ 恰好是这个球的球心"），写出那个破坏不变性的等距映射。

## 附录 A · 想把这事做成机器（可选，别当主线）

日常用 §2.2 的四格就够。若你要的是**机器可检验**的版本，标准做法是形式化：

- 固定一个三排序语言：点（sort $X$，其上无专有符号）、实数（值域）、指标（$\mathbb N$），唯一跨 sort 符号是 $d$；
- 固定"背景理论" $T_{\mathrm{bg}}$：完备有序域 + 集合论与有限组合基元，**硬纪律：背景里不许出现任何关于 $X$ 的符号或量词**；
- 判据：存在推导 $\pi$ 使 $T_{\mathrm{bg}}+\{\text{M1},\text{M2},\text{M3}\}\vdash T$ 且 $\pi$ 的叶子里没有超出 $T_{\mathrm{bg}}$ 的非逻辑公理（即依赖集 $D(\pi)=\varnothing$）；
- 桥：可靠性定理（$\Sigma\vdash T\Rightarrow\Sigma$ 的每个模型满足 $T$）—— 这一步只做一次，不必每个空间重跑。

三个必须记的坑：① 定义展开会把它右边的东西引进来，要单独记账；② 免检的只有**一阶逻辑**，二阶量词（"对所有子集/对所有序列"）必须降型或记账；③ 选择公理不是逻辑，用一次记一次。

**这一层能给什么**：它把"只依赖"变成可计算的判断，并且能解释为什么"审计不是循环论证"。**这一层不能给什么**：它不会替你发现数学错误 —— 审计只查依赖，不查证明对不对。

## 收束：四问各自的答案是一句话

- **问题一**：度量是**约定**，换尺子就是换几何；怪例子是拉回，不是魔法。
- **问题二**：迁移靠"从公理推出 ⇒ 对所有模型成立"；检验靠**逐行问凭什么**。
- **问题三**：审证明得依赖表；想证"必须"就**造坏世界**。两者合起来才是"依赖三条"。
- **问题四**：审概念的**表达能力**（写得出来吗）；写完还要查"能不能证"（完备就是样板）。

> 下一次教授再端出一个古怪的度量，问题不是"这也能叫距离"，而是：**这套几何里，我刚证过的那条定理还活着吗？我凭什么说它还活着？**
