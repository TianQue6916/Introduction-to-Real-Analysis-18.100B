## 0. 允许使用的东西（先把底牌摊开）

推导之前先声明"能用什么"，否则后面每条结论都会悬空：

| 类别 | 内容 | 地位 |
|---|---|---|
| 语言 | 一个集合 $X$；唯一专有符号是二元函数 $d:X\times X\to\mathbb R$；量词跑在 $X$、$\mathbb R$、$\mathbb N$ 上 | 约定 |
| 公理 M1 | $d(x,y)\ge0$，且 $d(x,y)=0\iff x=y$ | 给定 |
| 公理 M2 | $d(x,y)=d(y,x)$ | 给定 |
| 公理 M3 | $d(x,z)\le d(x,y)+d(y,z)$ | 给定 |
| 底座 | $\mathbb R$ 的算术与大小比较；有限个实数有最大元 | 给定（只谈数值，不谈 $X$） |
| 元定理 | 可靠性：$\Sigma\vdash T\Rightarrow\Sigma$ 的每个 model 满足 $T$ | 逻辑学结论，外部支撑 |
| 元定理 | 完备性（Gödel 1929）：$\Sigma$ 的每个 model 满足 $T\Rightarrow\Sigma\vdash T$ | 同上 |

**注意最后两行**：它们是外部支撑，不是本稿推出来的。凡用到，我标明"〔元定理〕"。这套坦白是"结论要有东西撑着"的最低要求。

## 一、为什么是这三条：把"接近"压成可运算形式的三次决策

**原始问题**：分析要谈"趋近"，那么"趋近"必须被写成什么，才谈得下去？

**推导**：

1. 要谈"趋近"，必须有"有多近"的比较 —— 于是需要每一对元素对应一个数。〔定义：distance〕
2. 这个数若允许为负，则"更近"与"更远"无法由数值大小直接读出；若零不意味着同一，则两个不同元素在语言里不可区分，$\varepsilon$-语句会同时真于它们。〔推导：M1 的必要性〕
3. 若 $d$ 有方向，则"$x$ 趋近 $a$"与"$a$ 趋近 $x$"是两个不同命题，收敛概念要写两遍并各自限定方向。〔推导：M2 的作用是取消这一分支〕
4. 若"接近"不可传递，则"$d(x_n,a)<\varepsilon$"无法从"$x_n$ 与 $a$ 各自靠近中间量"推得，$\varepsilon$-论证的链条断在第一处。〔推导：M3 是"链条可拼接"的算术化〕

**结论**：三条不是三条并列的美德，而是**"接近"要变成可运算量时必须同时支付的三个代价**：可比较（M1）、无方向（M2）、可传递（M3）。

**支撑强度必须说清**：上面 2–4 只证明了"少了它，$\varepsilon$-论证会缺一步"，这是**动机**，不是**最少性**。要证明"三条都不可省"，必须做独立性证明：对每条公理，构造一个满足其余两条、使某条既有定理为假的 model。〔方法论；具体构造属"举例"，本稿不做〕

## 二、度量为什么能换

**原始问题**：为什么 distance 不是集合的固有属性？

**推导**：

1. 一个数学命题只谈**符号之间的关系**，不谈符号所指对象的"本质"。〔定义：形式语言里的句子〕
2. 三条公理是这些关系的全部约定；它们的表述里没有一处提到元素"是什么"。〔回看 §0 的语言行〕
3. 因此凡满足三条的 $(X,d)$ 都是这套约定的一个 model；约定对所有 model 同真。〔推导〕
4. 故"换 $d$"= 换 model，命题的真值由"它用了约定的哪部分"决定，与 model 无关。〔推导〕

**结论**：换度量是合法的，因为**命题谈的是结构，结构不挑实现**。这不是宽容，而是形式语言的直接后果。

**这条结论的支撑**：第 1、2 步是约定（可核对：回看 §0 语言与公理，确认无一处提到元素的本性）；第 3、4 步是第 1、2 步的直接推论，无额外假设。

## 三、为什么"只引用三公理"的证明能迁移

**原始问题**：验证一个对象满足三条之后，凭什么把别处证的定理搬过来？

**推导**（对证明的长度作归纳）：

- 基例：长度为 1 的证明，其唯一句子是公理或逻辑公理。公理在每个 model 中真；逻辑公理在一切结构中真。〔〔公理〕+〔元定理：逻辑有效性〕〕
- 归纳步：设前 $k$ 步在每个 model 中真；第 $k+1$ 步由推理规则从前面的句子得出，而推理规则只依赖句子的形状，不依赖 model。〔定义：推理规则〕
- 故结论在每个 model 中真。〔归纳完成〕

**这就是迁移的全部机制**，它没有用到任何数学内容 —— **它是"证明"这个概念自身的性质**，而不是度量空间的性质。

**推论（可操作形式）**：既然范围由"前提引用"决定，判据就是逐行找引用，只有四类：逻辑规则（不记）／已证引理（递归查其清单）／三条公理之一（记为 M1/M2/M3）／定义展开（**必须查右侧是否引进新结构**）。

**边界（都是"引用漏记"的三条路）**：

- **提到 ≠ 用到**：句子里出现 $d(x,y)\ge0$ 不等于该步消费了 M1；
- **定义展开偷渡**：展开一个把 $X$ 上的序或代数引出来的定义，等于扩大了前提；
- **表述不一致**：同一对元素在两处写反参数顺序，从一处推另一处就多消费了 M2。

## 四、为什么"只依赖"必须两侧一起算

**原始问题**：怎么把"只依赖三公理"变成可算的判断？

**推导**：

1. 由 §三，可迁移范围 = 证明里引用的东西的**传递闭包**（引理引用引理、展开引用右侧）。〔推导〕
2. 闭包可以一次算完：每个节点记"继承了哪些公理"。〔推导：依赖集由证明树递归定义〕
3. 于是"只依赖三条"= 该闭包相对 §0 的底座**为空**。〔定义〕
4. 但闭包只记录**写下来的**引用；它不排除"作者未写而实际需要"。故必须补另一侧：**若删某条公理仍有 model 使结论为假，则该公理不可省**。〔推导：可靠性取逆否 —— 若结论在某个只满足其余公理的 model 中为假，则不存在只引用其余公理的证明〕

**结论**：上界读证明，下界造 model；前者是静态计算，后者是构造，**方法论上不可互相替代**。只做一侧，得到的都不是"依赖几条"，而是"清单里记了几条"。

**一个结构性推论（不举例，直接推）**：

- 三条公理的形式都是"量的比较"（$d$ 的值的等式与不等式），没有一条断言"存在某个 $X$ 中的元素"。
- 而语言里没有 $X$ 的常元（§0 只给了 $d$，没给任何具体点）。
- 因此：要证出一个形如"存在 $x\in X$ 使得…"的结论，必须在某一步由 $\exists$-引入或由某个已存在的 $X$-项实例化得到；而前提中既无 $X$-常元、也无 $X$-存在断言，故这一步不可能完成。〔推导：一阶证明的项结构〕
- 所以**一切存在型的结论原则上都推不出来**，无论它多"自然"。构造反例只是把"推不出来"变成一个可核对的见证。〔推导〕

这条推论解释了后面 §五的一个分界：概念写得出来，不等于关于它的存在型命题能被证明。

## 五、概念怎么审：可定义 vs 可证

**原始问题**：定理可以审证明；概念没有证明可读，审什么？

**推导**：

1. 概念要被使用，必须有**外延**（哪些元素属于它）。〔定义〕
2. 若概念"只由 $d$ 决定"，则其外延是 $d$ 的函数：给定 $d$ 的值，外延就被确定。〔定义：可定义〕
3. 于是：任何保持 $d$ 的双射（$d(fx,fy)=d(x,y)$）必然保持该外延 —— 因为它保持 $d$ 的一切值，而外延只由这些值决定。（严格写法：对公式复杂度归纳，$d$ 是唯一 $X$-符号，$f$ 双射保证 $X$ 上量词保真，$\mathbb R/\mathbb N$ 的解释固定。）〔已证〕
4. 取逆否即得否证器：**若概念在保距搬动下改变，则它不可能只由 $d$ 决定**，无需读任何证明。〔推导〕

**两个必须分开的量**：

| | 问什么 | 判据 | 缺它会发生什么 |
|---|---|---|---|
| 可定义 | 概念说得出口吗 | 存在只用 $d$ 与量词的公式 | 连陈述都无法写出，谈不上证明 |
| 可证 | 关于它的命题站得住吗 | 依赖闭包相对底座为空（§四） | 陈述写得出，但在某些 model 中为假 |

**为什么二者不等价**：由 §四的结构性推论 —— 存在型命题不可能由比较型前提推出。而"完备"恰是存在型（每条 Cauchy 列都**存在**极限点），故它可定义、不可证。〔推导〕这条不需要反例，反例只是它的见证。

**边界（必须写进判据的补充）**：公式**不得含参数**。一旦公式里出现一个具体点或数，它就在"相对于那个东西"说话，而那个东西会被保距搬动改变 —— 于是"只用 $d$"的外表掩盖了"点名"的实质。〔推导：参数是刚性的，空间在动〕

## 六、四问的依赖关系（一张推导图，不是并列清单）

```
(0) 分析要谈「趋近」 ──〔必须可运算〕──→ 三条公理（M1 可比较 / M2 无方向 / M3 可传递）
                                            │
                                            公理只说关系，不说元素是什么
                                            ▼
(一) 命题谈结构 ⇒ 换 d = 换 model，真值由「用了哪部分」决定
                                            │
                                            证明只按规则走，规则只看形状
                                            ▼
(二) 只引用公理的证明对所有 model 有效（对证明长度归纳）
                                            │
                        ┌───────────────────┴───────────────────┐
                        ▼                                       ▼
(三) 依赖可算：闭包相对底座为空                  (四) 概念外延由 d 决定
     上界读证明 / 下界造 model                    ⇒ 保距不变（逆否作否证器）
                        │                                       │
                        └──── 都存在型结论推不出 ───────────────┘
                              （前提无 X-常元、无 X-存在断言）
```

一句话收束：**公理把「接近」压成量（0）→ 命题只谈结构（一）→ 证明只按规则走（二）→ 于是依赖可算（三）→ 而算之前概念得说得出口（四）；两条路都在同一处被卡住：存在型结论缺原料。**

## 摘要

| 问 | 答 | 凭什么 |
|---|---|---|
| 为什么是这三条 | 「接近」要变成可运算量，必须付三个代价：可比较、无方向、可传递 | 定义 + 反事实（少了它哪一步断） |
| 为什么能换 $d$ | 命题只谈结构，结构不挑实现 | 形式语言的定义（§0 语言行） |
| 为什么证明能迁移 | 推理规则只看句子形状，不看 model | 对 proof（证明）长度归纳 |
| 为什么两侧都要算 | 上界读证明（存在），下界造 model（全称否定）；两界夹住，这个数才定死 | soundness（可靠性）取逆否 |
| 为什么概念要审 | 判据只能从外面看：isometry（保距双射）搬得动的，就不是只用 $d$ 写的 | 对 formula（公式）复杂度归纳 |

**一条主线**：公理把「接近」压成量（§一）→ 命题只谈结构（§二）→ 证明只按规则走（§三）→ 于是依赖可算（§四）→ 而算之前，概念得先说得出口（§五）。

**同一个卡点**：语言里没有 $X$-常元、也没有一条 axiom（公理）断言 $X$ 里有东西 —— 所以「存在某个 $x\in X$ 使 …」缺原料。反例不产生这个结论，只是把「推不出来」变成一个可核对的 witness（见证）。
