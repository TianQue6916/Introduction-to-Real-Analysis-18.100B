## 1. Q1 本质：剥掉符号之后它到底断言了什么

剥掉 $d$、$\varepsilon$、$N$，这句话在说：

> **一份证明能用多少原料，是一件看得见的事；看不见的原料，要么在清单上，要么就在偷。**

这就是全部。它断言两件互相咬合的事：

- **上界（句法）**：把证明摊成一棵有限树，逐行记账 ⇒ 这份证明**没有多要**什么。
- **下界（语义）**：造一个"其他都正常、只有某条坏了"的世界 ⇒ 这条定理**确实需要**它。

只有当两个数字相等，说"这条定理依赖三条公理"才不是口号。这里有一个必须点破的次序，否则整篇都会读飘：

> **删公理实验只能给出下界，逐行审计只能给出上界。** 删掉 M2 之后极限唯一性死了，只说明它需要 M2，**不**说明它不需要 M1 或 M3。

这也是为什么"公理三选几"这种问法在拿到**具体证明、具体表述**之前是病句（§3 会给出反例：同一句人话，两种形式化，两个依赖集）。

## 2. 九个疑问 · 逐个结算

### 疑问 1｜「为什么这个八竿子打不着的减法能引出子空间？」

> 原话（`DS#71443`）：「我是说，书上说这个例子引入子空间，我想知道，为什么这个八竿子打不着的减法能引出子空间 ---」

**当时答的要点**：讲了"把 $\mathbb R$ 的距离搬到一般集合上"这个教学动作。方向对，但没有点破最关键的一句：**这不是新发明，这是一次改名。**

**现在能站住的答法**。Colding 举的例子是 $d(m,n)=\left|\frac1m-\frac1n\right|$，作用在 $\mathbb N$ 上。取 $f:\mathbb N\to\mathbb R$，$f(n)=1/n$。$f$ 是 injective（单射），把它沿 $f$ **拉回**（pullback）：

```math
d_{\mathbb N}(m,n) \;:=\; d_{\mathbb R}\bigl(f(m),f(n)\bigr) \;=\; \left|\frac1m-\frac1n\right| .
```

于是 $(\mathbb N,d_{\mathbb N})$ 与子空间 $\bigl(\{1,\tfrac12,\tfrac13,\dots\},d_{\mathbb R}\bigr)$ **等距同构**，差别只在点的名字。三条公理的继承是逐条的、免费的：

- **M1**：靠 $f$ 的单射性（$f(m)=f(n)\Rightarrow m=n$）；
- **M2 / M3**：只涉及 $d_{\mathbb R}$ 的值，拉回只改了自变量，故原封继承。

所以"减法能引出子空间"的正确读法是：**减法从来没有引出子空间，它是 $\mathbb R$ 上的度量；引出子空间的是那个单射 $f$。** 教训不是"度量可以随便造"，而是——

> **标签会撒谎，名字不是数值。** $n$ 与 $n+1$ 名字挨着，$1/n$ 与 $1/(n+1)$ 却越走越近；换回 $f(n)=n$，同一个 $\mathbb N$ 立刻变回"无界、不完备"的通常几何。**同一个集合，两种几何。**

**残余风险**：这里真正被使用的结构是"存在单射"这一条，而不是"减法"这个运算。若 $f$ 不单射，M1 当场死 —— 这正是 §2 疑问 2 里"拉回"那一行的危险点。

### 疑问 2｜「度量还能自己换？只要满足性质就行？那这度量很有可塑性啊，都有哪些应用？」

> 原话（`DS#71529`）：「教授举了一个m分之一和n分之一的度量例子，为什么？度量还能自己换？只要满足性质就行？那这度量很有可塑性啊，都有哪些应用？数学家们怎么应用他们？ ---

**当时答的要点**：给了"只要满足三条公理就是度量"的应用清单（最短路、汉明距离等）。清单对，但"可塑性"这个词的边界没有画。

**现在能站住的答法**。可塑性有边界，而且是**三条可复用的流水线加一张成本矩阵**：

| 流水线 | 做法 | 公理成本 | 何时崩 |
|---|---|---|---|
| **拉回** | $d_Y(f(\cdot),f(\cdot))$，$f$ 单射 | M1 靠单射，M2/M3 继承 | $f$ 不单射 ⇒ M1 死 |
| **有界化** | $d'=\min(d,1)$ 或 $d/(1+d)$ | 三条全保 | 拓扑不变、**有界性与紧性变**（§6 事实核对第 5 条） |
| **范数诱导** | $d(x,y)=\lVert x-y\rVert$ | 三条全保，M3 = 范数的三角不等式 | 一旦写成 $d$，就**假定**了线性结构（签名扩大） |

可塑性的真实边界不是"能不能满足三条"，而是**代价**：每一次换度量，都要重算"哪些定理还活着"。这就引出下面这张矩阵（旧稿 §1 的矩阵，此处精简为判定用的四行）：

| 度量 | M1 | M2 | M3 | 见证 |
|---|:--:|:--:|:--:|---|
| 通常 $|x-y|$ | ✓ | ✓ | ✓ | 参照系 |
| 最短路径度量（有向图） | ✓ | **✗** | ✓ | $d(u,v)\ne d(v,u)$ ⇒ 拟度量 |
| $|x-y|^2$ | ✓ | ✓ | **✗** | $d(0,4)=16>d(0,1)+d(1,4)=10$ |
| 浮点 $|\mathrm{fl}(x)-\mathrm{fl}(y)|$ | ✓ | ✓ | **✗**（舍入） | **可运行的**反例，见 §4 |
| 离散度量 | ✓ | ✓ | ✓（取等号） | 最强三角不等式，随身试金石 |

**应用面（你要的"数学家怎么用"）**：最短路径度量是有向图算法的语言；编辑距离是序列比对的语言；上确界度量 $\sup_x|f(x)-g(x)|$ 是**一致收敛**的定义；拉回是"给同一个集合换几何"的通用手段（$p$-adic 度量就是把 $\mathbb Q$ 沿 $|\cdot|_p$ 拉回得到的另一套几何）。**破坏实验造出来的每个"坏世界"都对应一个真实用途** —— 这句不是安慰，四行里三行都有生产系统承重。

**残余风险**：可塑性的天花板不在定义层，**在签名层**。一旦你为了造新度量引入"范数""图结构""测度"，已经不在"只依赖度量三公理"的场景里了（§6 事实核对第 5 条）。

### 疑问 3｜「怎么证明只要该度量符合度量定义，数学工具就能迁移？怎么证明一个工具只依赖于这三个条件？」

> 原话（`DS#71645`）：「呃，怎么证明只要该度量符合度量定义，数学工具就能迁移？我的意思是，怎么证明一个工具只依赖于这三个条件？只要满足这三个条件就能使用的数学工具有哪些？有什么特征？」

**当时答的要点**：给了五步操作法（抽象公理 → 重写证明 → 验证只用公理 → 若用了序就标"需额外结构"），并给了"可迁移 / 不可迁移"两张清单。**这是正确的工程回答，但它把两个不同的问题混成了一个**：①"工具能迁移"（语义）②"工具只用三公理"（句法）。

**现在能站住的答法**。拆成两句，各配一台机器：

**(a) 句法侧：依赖集 $D(\pi)$。** 证明 $\pi$ 是一棵**有限树**：叶子贴公理，内部节点是一次 inference rule，根是目标 $T$。

> **定义（依赖集，初版）**：$D(\pi)$ 为 $\pi$ 叶子上贴的**非逻辑公理**的集合；引用引理 $L$ 时把 $D(\pi_L)$ 递归并入。

**(b) 语义侧：相对化可靠性。** 逻辑学已证：$\Sigma\vdash T\Rightarrow\Sigma\models T$，且**对可变的公理集成立**：

```math
\forall\Sigma\,\forall\pi\,\forall T:\quad \bigl(\pi\ \text{是}\ \Sigma\ \text{中}\ T\ \text{的证明}\bigr)\ \Longrightarrow\ \bigl(\forall\mathcal M\models\Sigma:\ \mathcal M\models T\bigr).
```

把 $\Sigma$ 取成"背景 + 三条度量公理"，桥就接通：句法一侧算出 $D(\pi)$，语义一侧保证它在**每个**度量空间里为真。**这个归纳只做一次**，不需要为每个具体空间重跑 —— 所以"逐行检查"不是"每个空间各证一遍"的缩写，它是可靠性的可操作版本。

**两个缺口必须当场补上，旧稿 §2.4 / §3.3 就是补丁**：

1. **背景条款**：证明里出现"有限非空实数集有最大元"怎么办？若把它塞进 $D(\pi)$，任何用到 $\mathbb R$ 事实的证明都永远不满足 $D\subseteq\{\text{M1,M2,M3}\}$，判据空转。若塞进"逻辑"，违反"逻辑在任何结构里都成立"。**修法**：把背景升格为签名的第三部分 —— 三排序签名（sort $X$ / sort $\mathbb R$ / sort $\mathbb N$），背景理论 $T_{\mathrm{bg}}$ 含完备有序域 + 集合与有限组合，**硬纪律：$T_{\mathrm{bg}}$ 里不得出现任何 sort-$X$ 的符号或量词**。于是判据从 $D\subseteq\{$M1,M2,M3$\}$ 变成：

```math
T_{\mathrm{bg}}+\{\mathrm{M1},\mathrm{M2},\mathrm{M3}\}\ \vdash\ T,\qquad D(\pi)=\varnothing .
```

2. **定义展开条款**：展开定义会把它右侧的符号全部引进证明。若右侧落在 $\mathcal L_d$ 之外（序、代数、测度、开集族），展开就是**偷渡** —— 拆账：属背景 sort 的旁注"经 $T_{\mathrm{bg}}$"；引入 sort-$X$ 上新结构的，**记入 $D(\pi)$，判据立即失败**。

**特征（回答你"有什么特征"）**：可迁移的工具只谈**接近与分离**，只触碰 $d$ 的**值**；点只作为 $d$ 的自变量出现。三条判据合起来是一句话：**写得进 $\mathcal L_d$（可定义性）+ 证得出（$D=\varnothing$）**。两列必须分开——这是下一问的战场。

**残余风险**：逻辑这一格要单独记账。免检的只有**多类一阶逻辑**（重言式、等词、量词规则、cut）；二阶逻辑不免检（full second-order validity 不可递归枚举，"对所有子集"式的量化必须降型或记账）；选择原则必须显式声明。

### 疑问 4｜「度量空间的三角不等式到底咋出来的？如何证明一个概念满足三角不等式？」

> 原话（`DS#72142`）：「忘记说了，度量空间的那个三角不等式到底咋出来的？之前我记得问过你，还有，如何证明一个概念满足三角不等式 ---

**当时答的要点**：讲了"它不是推出来的，是被提升为公理的"，然后给了 5 个具体距离满足 M3 的验证例。**答对了，但漏了这题真正的两半**：

**半 1：它是公理，所以不可证。** 这一半没有讨论余地。若有人要你"证明度量空间的三角不等式"，正确回应是：**"这不是命题，是定义的一部分"**；能证明的只有"某个具体的 $d$ 满足它"。

**半 2：为什么偏偏是这一条被提升为公理？** 这一半才是有内容的，三个层次：

- **几何层**：两点之间直达不短于绕行，即 $d(x,z)\le d(x,y)+d(y,z)$。
- **逻辑层**：M1、M2 是**逐对**条件，M3 是唯一把**三个点**耦合起来的**合成**条件。删掉它，你只是有一堆两两比较，没有"路线"这个概念。
- **范畴层 [A]**：Lawvere 1973 指出度量空间恰是**在 $[0,\infty]$（取反向序、以加法为张量）上富化（enriched）的范畴**：$d(x,z)\le d(x,y)+d(y,z)$ 就是 composition 的三角恒等式，$d(x,x)=0$ 就是 identity。[nLab: `metric on a category`](https://ncatlab.org/nlab/show/metric+on+a+category)。**三角不等式不是"关于距离的一条性质"，它是"复合"这件事在距离语言里的投影。**

**一个三行定理把"最几何"从感受变成命题**：

> **命题（开球是开集，只需 M3）**：设 $d$ 满足 M3（加 $\mathbb R$ 的严格不等号），$B(x,r)=\{y:d(x,y)<r\}$，则 $B(x,r)$ 是开集。

**证明**：取 $p\in B(x,r)$，令 $s=r-d(x,p)>0$。对任意 $q\in B(p,s)$：

```math
d(x,q)\ \le\ d(x,p)+d(p,q)\ <\ d(x,p)+s\ =\ r ,
```

故 $B(p,s)\subseteq B(x,r)$。$\square$

**审计**：只用了 **M3** 与 $\mathbb R$ 的序；M1 的唯一作用是让你能说 $x\in B(x,r)$；**M2 完全不出场**。所以：**删 M3，开性、连续性、紧性整套拓扑机器同时停机。**

**残余风险**：完整的三条公理下 $d$ **自身**是连续函数，但那需要 **M3 与 M2 合用** —— 不等式 $|d(x,y)-d(x',y')|\le d(x,x')+d(y,y')$ 的反向要把 $d(x',y')$ 与 $d(y',x')$ 互换。**"恰由 M3 保证"是错的**；M2 不可省的最小见证是两点拟度量（$d(a,b)=0,d(b,a)=1$），那里该不等式当场失效。

### 疑问 5｜「如何证明欧氏距离的正确性？施瓦茨那个也要证明」——以及那句「循环论证，重写」

> 原话序列（`DS#73845`、`DS#74036`、`DS#74506`、`DS#74751`、`DS#74875`）：
> 「如何证明欧氏距离的正确性？」→「术语就用它原来的名字吧，不用强行变成中文了，详述三角不等式这里的证明，施瓦茨那个也要证明」→「证明方向不对吧？我让你说明为什么欧氏距离定义符合三角不等式吧？你这个第一性原理的结论错了吧」→「你的证明维系于范数定义的合理性，恰恰你没有证明」→「你的施瓦茨不等式的证明依赖于范数…？循环论证，重写」。

这一串是整段会话里最值得保留的**方法论事件**：你连续四次拒绝了一个"看起来完整但前提被偷换"的证明。把它写成一条可复用的纪律：

> **证明 Minkowski 时不许假定范数。** 因为范数（norm）本身是用 M3 定义的（$d(x,y)=\lVert x-y\rVert$ 要成为度量，前提正是 $\lVert\cdot\rVert$ 满足三角不等式）。用范数证 Minkowski，就是用 M3 证 M3。

**干净的路只有一条**：从 Cauchy–Schwarz 出发，且 Cauchy–Schwarz 本身必须用**初等代数**证，不许调用内积空间的任何"已知性质"。

> **Cauchy–Schwarz（$\mathbb R^n$）**：$\left(\sum_{i}a_ib_i\right)^2\le\left(\sum_i a_i^2\right)\left(\sum_i b_i^2\right)$。[B] Rudin, *PMA*, Thm 1.35。

**证明（判别的技巧，零假设）**：对任意实数 $t$，$\sum_i(a_i+tb_i)^2\ge0$，即

```math
\underbrace{\Bigl(\sum_i b_i^2\Bigr)}_{A}t^2 \;+\; \underbrace{2\Bigl(\sum_i a_ib_i\Bigr)}_{B}t \;+\; \underbrace{\Bigl(\sum_i a_i^2\Bigr)}_{C}\ \ge\ 0 .
```

若 $A=0$ 则所有 $b_i=0$，结论显然。否则 $A>0$，上面的二次式对一切 $t$ 非负 $\iff$ 判别式 $B^2-4AC\le0$，整理即得。取 $t=-B/(2A)$ 便达到最小值，这一步只用"$\mathbb R$ 是全序域 + 平方非负"。

**然后 Minkowski（$p=2$ 的三角不等式）** 从它出来：

```math
\sum_i(a_i+b_i)^2=\sum_i a_i^2+2\sum_i a_ib_i+\sum_i b_i^2\ \le\ \sum_i a_i^2+2\sqrt{\textstyle\sum a_i^2\sum b_i^2}+\sum_i b_i^2=\Bigl(\sqrt{\textstyle\sum a_i^2}+\sqrt{\textstyle\sum b_i^2}\Bigr)^2 ,
```

开方即得 $d_2(x,z)\le d_2(x,y)+d_2(y,z)$。**全程没有出现"范数"这个词**，也没有用 M3 给自己背书。

**残余风险（必须记进卡点）**：这套证明本身用了 $\mathbb R$ 的完备性（$\sqrt{\cdot}$ 的存在性、判别式判据）。所以"欧氏距离是度量"这条事实**依赖 $\mathbb R$ 的结构**，而它不是"只依赖度量三公理"的定理 —— 它是**证明某个具体对象满足公理**的定理，逻辑地位完全不同。混同这两件事，是这段追问最容易被误答的地方。

### 疑问 6｜「如何证明实数轴上的这些定理本质上只用了这三个公理？」

> 原话（`DS#71812`、`DS#71984`、`DS#75572`）：「如何证明实数轴上的这些定理本质上只用了这三个公理」→「如何证明你刚刚说的很多概念都只依赖于这三个公理？」→「我不接受任何除了公理以外的东西出现在你的前提里，一切从头证明，除非是公理」。

最后那句是整个会话的**方法论纲领**，也是这份笔记的判据来源。它和上面的判据 v2 完全同构：**允许的原料要写在清单上，清单外的一律记入 $D(\pi)$。**

**答法（两个层，不能混）**：

- **概念层（可定义性）**：$C$ 只依赖度量 $\iff$ 存在 $\mathcal L_d$ 公式 $\varphi_C$ 在每个 $(X,d)$ 里界定 $C$。
- **定理层（可证性）**：$\mathcal L_d$ 句子 $\varphi$ 是可迁移定理 $\iff$ 存在推导 $\pi$ 使 $D(\pi)=\varnothing$（相对 $T_{\mathrm{bg}}$）。

两层的分界线是一张能背下来的三行表：

```text
                    说得出口？(可定义性)      证得出来？(可证性)
  开球 / 收敛 / 连续         ✅                      ✅
  完备 / 紧致 / 连通         ✅                      ❌ ← 需要额外假设
  单调 / 可微 / 介值原形      ❌                      ❌ ← 死在表达层
```

**"死在表达层"是什么意思**：单调收敛定理的障碍不在证明，在**陈述**。"$x_n$ 单调递增"要写 $x_1\le x_2\le\cdots$，而一般度量空间里元素之间根本没有 $\le$，这句话在 $\mathcal L_d$ 里**写不出来**。夹逼同理。**判据最锋利的用法是先问"这句话说不说得出口"，说不出来直接判死刑，一行证明都不用读。**

**残余风险**：即便 $X=\mathbb R$ 自带序，用序的证明引用的是度量语言之外的结构 —— 那是"$\mathbb R$-定理"（有序域 + 度量的定理），不是度量定理。这正是"换度量后同一句话换意思"的根源。

### 疑问 7｜「$\forall\varepsilon>0$ 算不算偷运了 $\mathbb R$ 的序？」

这是旧稿 §3.4 记下的**卡点 2**，也是"零依赖"结论最容易崩的地方。原话形态是："我把 $\forall\varepsilon>0$ 写进定义，这算不算用了 $\mathbb R$ 的序？如果算，那个零依赖结论当场就假。"

**答法（一句诊断句，值得抄在页边）**：

> **序一直在场；有价格的是完备性。** 审计问的不是"这一步有没有用序"，而是"这一步是否要求 $\mathbb R$ 没有洞"。

精确切分：

- **免费（签名自带）**：$\mathbb R$ 的全序、加法、乘法、$0<1$、非负性 —— 每个度量都活在 $\mathbb R$ 里，这些随签名附送。
- **要记账（背景假设）**：$\mathbb R$ 的**完备性**（确界存在）、阿基米德性、以及任何"取 $N$ 使 $1/N<\varepsilon$"式的步骤。若约定背景 = 完备有序域，它们已经包含在 $T_{\mathrm{bg}}$ 里；若不约定，就必须显式列出。

**这条切分带来一个意外红利**：本文案例"收敛 $\Rightarrow$ 有界"真正消费的甚至比 $\mathbb R$ 更弱 —— 只要**全序环**（ordered ring）。因为那一行用的是"有限非空全序集有最大元"，一条纯序事实，与完备性、阿基米德性、确界原理全不相干。这解释了为什么同一条定理对汉明、编辑、离散全部成立：**它不是度量定理，它连度量都不是必需的。**（旧稿 §5.2 已给模板层命题。）

**残余风险**：`$1_R>0_R$` 在标准有序环定义里免费（$1_R=1_R^2>0_R$），所以"取 $\varepsilon=1_R$"不构成额外假设。这条细节是行家会问的，别漏。

### 疑问 8｜「完备性为什么说得出口，却证不出来？」

> 原话（`DS#75844`、`DS#75925`）：「柯西完备和完备是什么关系？」「说的稍微有些浅显，还没有严谨证明，注意之前的对话习惯」。

**先答后者（易混词）**：在**同一度量空间内部**，"完备（complete）"与"柯西完备（Cauchy complete）"是**同一个概念**：每个 Cauchy 序列都收敛。词面上的差别出现在你把"完备"推广到别的范畴时 —— 一致空间里用 Cauchy net / Cauchy filter 定义完备，一般拓扑空间里根本没有"完备"这个概念。度量空间是第一可数、可序列化的，三种刻画（序列 / 网 / filter）等价，于是两个名字指一件事。**别把它们当成两条不同公理。**

**再答前者（为什么证不出来）**。这是全文最漂亮的一处"两层判据"分工：

- **可定义性 ✓**："每条 Cauchy 列收敛"是纯 $\mathcal L_d$ 句子（量词只跑在 $X$ 的序列与 $\mathbb R$ 上），而且它是**等距不变**的 —— 等距映射把 Cauchy 列送到 Cauchy 列、把极限送到极限。
- **可证性 ✗**：若它是三公理的推论，相对可靠性保证它在**每个**度量空间成立；造一个反例即证它不可能被证出。

**反例（教授的例子上场，一石二鸟）**：$(\mathbb N,d)$，$d(m,n)=|1/n-1/m|$。

- 它是度量：疑问 1 已验（拉回）。
- $x_n=n$ 是 Cauchy：取 $N>2/\varepsilon$，则 $n,m\ge N$ 时 $|1/n-1/m|\le 1/n+1/m\le 2/N<\varepsilon$。
- 它**不收敛**：若收敛到 $k\in\mathbb N$，则 $d(n,k)=|1/n-1/k|\to 1/k\ne0$，与收敛矛盾。

所以 $(\mathbb N,d)$ 不完备 —— 而它**满足全部三条公理**。结论：完备性**不是**度量定理。

**这里有一个免费的否证器**（旧稿 §3.3(b)，我认为是全文最实用的工具）：

> **命题**：若概念 $C$ 由**不含任何参数**的 $\mathcal L_d$ 公式定义，则 $C$ 在每个 $(X,d)$ 的每个等距同构下不变。

**证明**：$\mathcal L_d$ 中唯一的 sort-$X$ 符号是 $d$，等距同构恰是保持 $d$ 的双射；$f$ 是双射故 $X$ 上量词保真，$\mathbb R / \mathbb N$ 的解释跨模型固定故其量词不受影响；对公式复杂度作结构归纳得 $\varphi(\bar x)\iff\varphi(f\bar x)$。[A] 这是 automorphism invariance 的标准形态（Hodges, *Model Theory*；源头是 Padoa 1900 的不可定义性方法，见 §8）。

**"不含任何参数"是硬的，去掉就假**：$X=\mathbb R$ 配通常度量，公式 $\varphi(x):=\bigl(d(x,1)=0\bigr)$ 里的 $1$ 是 sort-$\mathbb R$ 参数，它定义 $\{1\}$；取等距 $f(x)=x+0.5$ 后 $\{1\}$ 变 $\{1.5\}$。机制值得单独记：**$\mathbb R$-参数是刚性的（跨模型钉死），$X$ 在等距下会动**，于是带参数的公式定义的其实是"相对于参数的位置"，而等距不变问的是"集合本身动不动"—— 两个不同的对象。

**残余风险**：这条命题只写单向（可定义 $\Rightarrow$ 等距不变）。反向一般不成立：等距不变是对集合的粗糙约束，可定义要求有公式逐点判定。别把它当"等距不变 $\iff$ 可定义"用。

### 疑问 9｜「度量空间括号里那两个位置是什么意思？」

> 原话（`DS#75761`）：「度量空间括号里面两个位置的含义」。

$d:X\times X\to\mathbb R$ 是二元函数，两个位置就是**源**与**目标**。问题在于：**这个区分在度量空间里几乎不承载信息**，因为 M2 把所有方向信息抹平了：

```math
d(x,y)=d(y,x)\qquad\text{（M2）}\ \Longrightarrow\ \text{位置 1 与位置 2 的角色不可区分。}
```

一旦删掉 M2，两个位置立刻**装满语义**：

- **有向图最短路**：$d(u,v)$ = 从 $u$ 走到 $v$ 的单向成本，$d(u,v)\ne d(v,u)$ 是常态（下坡 vs 上坡）。
- **编辑距离**：若编辑算子集不是成对可逆（允许"删除"不许"插入"），$d(A,B)\ne d(B,A)$。
- **信息/代价的非对称**：$\mathrm{KL}(p\|q)$ 不对称，正是"$p$ 到 $q$ 的代价"这种位置语义。

这就是**参数顺序脆点**的来源（旧稿 §5.4，我认为它是全文最该被记住的一条纪律）：

> §5.1 的零依赖结论有一个隐藏约定：收敛写 $d(x_n,a)$，有界写 $d(x_n,c)$，**两处参数顺序必须一致**。若把有界写成 $d(c,x_n)\le R$，从 $d(x_n,a)<1$ 推到 $d(a,x_n)<1$ 就要用 **M2**，$D$ 从 $\varnothing$ 变成 $\{M2\}$。

这不是吹毛求疵：它说明"依赖几条公理"对**符号顺序**都敏感 —— 而符号顺序对应的是"你打算让这个距离函数区分方向吗"这个**设计决策**。这也解释了为什么拟度量（quasimetric）下结论必须写成单侧：$d(x_n,a)\to0$ 推不出 $\{d(a,x_n)\}$ 有界。

## 3. Q2 公式层：最小充分形式与一次闭合的账本

上面九个疑问收敛成一页公式。**这是全篇唯一需要背的部分**，其余都是它的注脚。

### 3.1 签名与背景（判据的底座）

- **三排序签名**：sort $X$（点，其上无专有符号）、sort $\mathbb R$（距离值域）、sort $\mathbb N$（指标）；唯一跨 sort 符号是 $d:X\times X\to\mathbb R$。
- **背景理论 $T_{\mathrm{bg}}$**：完备有序域 $\mathrm{Th}(\mathbb R,+,\cdot,0,1,<)$ + 集合论与有限组合基元 +（必要时）DC。**硬纪律：不含任何 sort-$X$ 的符号或量词。**
- **两级语义**：$\mathbb R$ 的解释跨模型**钉死**（rigid），$X$ 与 $d$ 是**变元**。

### 3.2 判据 v2

```math
T\ \text{只依赖度量三公理}\quad:\Longleftrightarrow\quad \exists\pi:\quad T_{\mathrm{bg}}+\{\mathrm{M1,M2,M3}\}\vdash T,\ \ D(\pi)=\varnothing ,
```

其中 $D(\pi)$ 是 $\pi$ 中出现的、**不属于 $T_{\mathrm{bg}}$** 的非逻辑公理集合（引理递归并入），$\pi$ 为多类一阶推导。**迁移桥**：此时每个满足 M1–M3 的 $(X,d)$ 都满足 $T$（多排序可靠性）。

### 3.3 四步操作手册（每步配失败模式）

| 步 | 动作 | 失败模式（比成功路径重要） |
|---|---|---|
| 1 | 把定理写成 $\mathcal L_d$ 句 | **写不出** ⇒ 不是度量定理。注意这是**设计决策**：选哪种表述就是选择为度量结构付多少钱 |
| 2 | 逐行审计，每行归四类（逻辑 / 已入库引理 / 公理 / 定义展开） | 定义展开偷渡；背景泄漏（把完备性当免费）；**参数顺序不一致**让 M2 从两处写法里溜进来 |
| 3 | 审计通过 ⇒ 可靠性背书，一切度量空间成立 | 忘了查**签名是否被扩大**（偷偷用了范数 / 图 / 测度） |
| 4 | 想证"不是推论" ⇒ 造反例模型 | 反例造完必须**逐条验证其余公理**（真正的工作量，极易做错）；且它只证**这一句话**，不证**概念** |

### 3.4 账本：四条定理，四个判决

| 定理 | 审计上界 $D(\pi)$ | 下界（最强坏世界） | 判决 |
|---|---|---|---|
| 极限唯一性 | $\{\mathrm{M1},\mathrm{M2},\mathrm{M3}\}$ | 删 M1 / M2 / M3 各一个坏世界 | **公理基恰为三条** |
| 收敛 $\Rightarrow$ 有界（球形式） | $\varnothing$ | 不存在反例 | **不携带度量信息**（对任意 $d:X^2\to\mathbb R$ 成立） |
| 收敛 $\Rightarrow$ 有界（直径形式） | $\{\mathrm{M2},\mathrm{M3}\}$ | —— | 同一句人话，另一个依赖集 |
| 球是开集 | $\{\mathrm{M3}\}$ | 删 M3 即失效（浮点距离可运行） | **M3 是几何的全部** |
| 完备（每 Cauchy 列收敛） | 不可证 | $(\mathbb N,|1/n-1/m|)$ | 说得出口，证不出来 |

### 3.5 极限唯一性的下界：三个坏世界（必须自己走一遍第三行）

- **删 M1 的定性半**：$d\equiv0$（伪度量 pseudometric）⇒ 每个序列收敛到每个点。
- **删 M2**：$X=\{a,b\}$，$d(a,a)=d(b,b)=0$，$d(a,b)=0$，$d(b,a)=1$ ⇒ 常序列 $a,a,\dots$ 同时收敛到 $a$ 与 $b$。
- **删 M3**：$X=\{a,b\}\cup\{u_n\}$，$d(a,u_n)=d(b,u_n)=1/n$，$d(a,b)=1$，$d(u_m,u_n)=|1/m-1/n|$，其余自距离 $0$。逐条验：M1 ✓（非负、仅对角为零）；M2 ✓（逐族对称）；**M3 在 $n\ge3$ 失败**：

```math
d(a,b)=1\ >\ \frac1n+\frac1n=d(a,u_n)+d(u_n,b)\qquad(n\ge3) ;
```

而 $d(u_n,a)=d(u_n,b)=1/n\to0$ 且 $a\ne b$ ⇒ 极限不唯一。**上界 = 下界 = 三条。**

顺带一个精确的归因（旧稿 §4.2 注，比"三条同等重要"准确得多）：**M2 是结论的实质承担者**（删掉即死）；**M1 只被消费了定性一半**；**M3 只被消费了一族单侧估计**（$d(a,b)\le d(a,x_n)+d(x_n,b)$），不需要"任意三点"的最强形式。审计的价值不只在"用没用"，在**"用到多少"**。

## 4. Q3 现实承重：这些结构在哪台机器上跑着，以及消失测试

四问里最容易被写成空话的一问。**只给"组件 + 该功能"，每条配消失测试。**

### 4.1 拟度量（缺 M2）→ 有向图最短路

- **承重**：`networkx.shortest_path_length(G, u, v)` 在 `G` 为 `DiGraph` 时返回的正是拟度量；OSPF/BGP 的路由代价、单行道导航里"从 A 到 B 与从 B 到 A 不同"都由这一条实现。
- **消失测试**：假设世界不允许 M2 失效（即强制对称化）⇒ 必须把有向图替换成"每对点取 $\min(d(u,v),d(v,u))$"。退化的后果不是报错，而是**方向语义被抹掉**：单行道会被当成双向道，路由表给出的路径在物理上不可行。这正是疑问 9 里"两个位置"的生产版本。

### 4.2 半度量（缺 M3）→ 浮点距离

- **承重**：$d(x,y)=|\mathrm{fl}(x)-\mathrm{fl}(y)|$（或任何浮点度量/相似度）**破坏**三角不等式，因为舍入误差不满足"绕路不短于直达"。任何对"距离矩阵"做三角不等式剪枝的代码（例如某些 KNN / 索引结构）必须显式修正这一点。
- **消失测试**：假设 M3 成立 ⇒ 用三角不等式剪枝（$d(x,z)>r\Rightarrow d(x,y)$ 与 $d(y,z)$ 里至少一个大）是合法的，检索与聚类的候选剪枝可以无脑用。**一旦 M3 失效，剪枝会静默丢召回**——不报错、不崩，只是少返回结果。这是"缺一条公理"在生产系统里最典型的失败形态：**没有异常，只有错误的答案。**
- **一个可当场跑的构造**（你可以今天就做）：取 $\mathrm{fl}$ 为 float32，找 $x,y,z$ 使 $|\mathrm{fl}(x)-\mathrm{fl}(z)|>|\mathrm{fl}(x)-\mathrm{fl}(y)|+|\mathrm{fl}(y)-\mathrm{fl}(z)|$。使用"灾难性抵消"（$x\approx y$ 时相减丢有效位）即可命中。

### 4.3 伪度量（缺 M1 定性半）→ 商空间与哈希碰撞

- **承重**：$d\equiv0$ 或 $d(x,y)=0$ 但 $x\ne y$ 的结构，正是"把距离为零的点粘成等价类"的商构造。6.042J 学的等价关系 + 商集在这里承重：$x\sim y:\iff d(x,y)=0$ 是等价关系，$d$ **下降（descend）**到 $X/{\sim}$ 上成为真正的度量。
- **消失测试**：若强制 M1 的定性半（$d=0\Rightarrow$ 同一点），就**不允许**"不同输入视为相同"⇒ 任何需要"容错相等"的系统（哈希桶、去重、近似匹配、$p$-adic 里 $|x-y|_p=0$ 表示同余类）全部需要手工加回等价类层。**"删 M1 的代价"的精确说法是：你其实是在做商空间上的度量。**

### 4.4 上确界度量 → 一致收敛（这是 18.100B 后期的主线）

- **承重**：$d_\infty(f,g)=\sup_x|f(x)-g(x)|$ 的值域是 $\mathbb R$，M3 靠 $\sup$ 的单调性与 $\mathbb R$ 的三角不等式；**"一致收敛"就是按它收敛**。Banach 不动点定理（压缩映射）只需完备度量空间即可运行，不依赖任何线性结构 —— 这是"只依赖三公理"的正面重注。
- **消失测试**：若没有 $d_\infty$（只有逐点收敛）⇒ 连续函数的极限可能不连续、求和与极限不可交换、ODE 的 Picard 迭代法无法收敛到一个函数。**代价不是复杂度，是定理失效。**

### 4.5 [未定位] 的一格

- **"三公理承载了哪个真实系统的哪个功能"** 这个问题在**纯数学内部**（拓扑学、泛函分析）成立，但要给出一条"工业系统因为 M1–M3 才工作"的**因果链**，目前只能给到上面四条，第四条属于"数学内部承重"。**不编造第五条** —— 按规矩标 `[未定位]`，待查方向：度量索引结构的正确性证明（VP-tree / M-tree 的剪枝正确性前提）、差分隐私的距离度量选择、以及机器学习里的 metric learning 是否真的需要 M3。

## 5. Q4 拓展进阶：四层坐标

每条都能点开；不给"详见相关资料"这种废话。

### L1 上游：它依赖哪条更基本的事实

- **公理化方法的元定理**：相对可靠性（多排序版本）+ 证明树的结构归纳 —— 抽掉"可靠性"，整条审计链断裂，$D(\pi)=\varnothing$ 就只是一张纸。
- **Gödel 1929 完备性定理**（$\Gamma\vdash\varphi\iff\Gamma\models\varphi$）：它保证"处处真"与"能证"严格等价，于是"逐行审计"恰好是正确且充分的验证手段。**注意与"度量空间的完备性"同名不同物**（见 §6 第 1 条）。
- **等词公理 + 一阶逻辑免检**：抽掉它，连"$d(x,x)=0$ 与 $x=x$ 的关系"都说不清。

### L2 平行：另一个领域里同构的机制

- **6.042J 结构归纳**：同一个"有限树 + 基例/归纳步"格式，在这里产出的是**关于证明系统的元定理**（$D(\pi)$ 良定义、审计终止）。同一台机器，站在元层。
- **CSAPP 第 7 章链接器**：证明 = 目标文件，公理 = 库符号，$D(\pi)$ = 未解析引用表，"只依赖三公理" = 链接器报告"静态库之外没有未定义符号"。**失效点必须记住**：链接器解析的是**名字且可判定**；数学依赖是**语义的**，会出现「假阳性（提到却没用）」与「假阴性（用了却没有名字）」两种泄漏 —— 背景明文清单就是修法。
- **6.042J 偏序**：理论按 $\subseteq$ 排序，"只依赖"= 上界，精确公理基 = 最小上界，独立性 = 严格不等式。**可判定性的丧失**在这里发生：有限偏序看两眼就能判序，无穷理论之间"这条证明真的需要 M2"**必须造模型**——这就是"反例是证书"的深层原因。
- **Lawvere 富化范畴**：三角不等式 = composition，$d(x,x)=0$ = identity；去掉对称性就是富化在非对称 monoidal 结构上。这让"拟度量"从"变态例子"变成"另一个 base of enrichment"。

### L3 实现：真实系统里的哪一行

- `networkx.algorithms.shortest_paths.generic.shortest_path_length`（DiGraph 分支）—— 拟度量的生产实例。
- `scipy.spatial.distance.cdist / pdist` 的 `p=2` 分支 —— 只有验证过 Minkowski 才敢称为 metric；文档里 "metric" 与 "distance" 的分野正是本文判据的工程化。
- 任何 float32 距离矩阵的三角剪枝代码 —— 半度量的静默失败现场。
- 证明助手侧的对应物：Lean/mathlib 中 `MetricSpace` 是一个 typeclass，**M1–M3 是 class 字段**，"只依赖三公理"在类型论里变成"这个定理的假设列表里没有出现 class 之外的字段"。这是本文判据的**机器可检验版本**，也是判据真正的未来形态。

### L4 前沿：开问题与今天就能做的验证

- **reverse mathematics 的精确强度**：完备可分度量空间在 $RCA_0$ 里用 code 表示，大量分析在 $RCA_0$ 内可展；**Heine–Borel 等价于 $WKL_0$**；**Bolzano–Weierstrass 等价于 $ACA_0$**。[A] Simpson, *SOSOA*；Brown, "Notions of compactness in weak subsystems of second order arithmetic"；Hirst, "Reverse Mathematics and the Heine/Borel Theorem"（[slides](https://www.appstate.edu/~hirstjl/snp/pdfslides/asl2001.pdf)）。这条结果把本文的"$\mathbb R$ 墙"从直觉变成**逻辑强度刻度**：BW 不是"需要多一点结构"，它的证明强度是**算术理解公理**级别。
- **广义度量（valued in 更弱的结构）**：Kurepa 1934 引入 pseudo-metric spaces（距离取值于全序集），Sikorski 的 $\omega_\mu$-metric（取值于全序 abelian group）[A]，以及 magma-valued metric spaces 的近期工作 —— 这些正是"§3.5 全序环就够"的历史与前沿。[A] Kurepa, *Sur l'écart abstrait*（1956）。
- **今天就能做的验证实验**（三个，成本半小时内）：
  1. 用 Python 造浮点反例，打印 $(x,y,z)$ 与三项距离，看 M3 差多少 ulp；
  2. 对 $(\mathbb N,|1/n-1/m|)$ 数值画出 $d(n,k)$ 随 $n$ 的变化，亲眼看到它趋于 $1/k$ 而非 $0$；
  3. 把"有界"分别写成球形式与直径形式，各写一遍证明，数一数第二份多用了几行 —— 这是 §3.4 账本第四行的亲手复现。

## 6. 事实核对：旧稿五条 + 我复核新增的五条

### 6.1 旧稿 §6.6 的五条（复核后全部站得住，措辞已收紧）

| # | 常见说法 | 校准后的版本 |
|---|---|---|
| 1 | "Gödel 完备性与度量完备性完全无关" | **同名不同物，三件事**：①证明系统的完备性（1929，$\vdash\iff\models$）②理论的完备性（每句可判真假）③度量空间的完备性（每 Cauchy 列收敛）。①③不互相推出；说"完全无关"作为措辞过强。1931 年的**不完备性**定理与③确实无关 |
| 2 | "极限唯一性分别用到 M3、M2、M1" | 用到了三条，**但必要性不同**：M2 是实质承担者；M1 只需定性一半；M3 只需一族单侧估计 |
| 3 | "离散度量下紧致 $\iff$ 有限" | 正确，但来自**离散性**这一额外结构（单点集是开集），不是 M1–M3 的推论 |
| 4 | "距离函数 $d$ 的连续性恰由 M3 保证" | **错的**：需要 **M3 与 M2 合用**（反向要把 $d(x',y')$ 与 $d(y',x')$ 互换）。准确说法：$d$ 在**积度量** $d_{\mathrm{sum}}((x,y),(x',y'))=d(x,x')+d(y,y')$ 下是 1-Lipschitz，故连续 |
| 5 | "每造出一个满足三公理的新距离，全部度量定理零改动接入" | 迁移的是**句子（模板）**，不是结构。三类不适用：$\mathcal L_d$ 不可表达的结构（完备/全有界/测地）、涉及具体度量的陈述（"$d$ 是欧氏度量"）、签名扩展（"$X$ 是赋范空间且 $d$ 由该范数诱导"）。且**有界性、完备性、紧性都不是拓扑性质**：$\mathbb R$ 上 $d$ 与 $\min(d,1)$ 同拓扑，但后者下有界且不紧 |

### 6.3 一条方法论上的自我警告

旧稿 §5.1 的 "$D(\pi)=\varnothing$" 有一个隐藏约定（收敛与有界的参数顺序一致，见疑问 9）。**这类"结论正确但对约定敏感"的地方是本文最脆的一环**，而它恰好是旗舰案例。处理方式不是藏进脚注，是**把它写成教学点**：审计的结论永远要连同"签名与约定"一起读。
