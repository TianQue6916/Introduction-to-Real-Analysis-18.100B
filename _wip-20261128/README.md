## 行尾符（重要）

本目录的 `TBB_part003_p101-150.md` 在**工作区是 CRLF**（2705 个 CRLF / 2705 个 LF），而 `01-教材/` 的同名文件是**纯 LF**。本仓库 `core.autocrlf=true` 且 `.gitattributes` 写了 `text eol=lf`，所以：

- **仓库里存的是 LF**（`git ls-files --eol` 显示 `i/lf w/crlf`）；
- 以后 checkout 出来会是 LF，与 `01-教材/` 的既有形态一致；
