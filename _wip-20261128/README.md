## 派发纪律（这一轮踩出来的）

- **派活前由调度者冻结只读基线**，验收不用 worker 自己那个 `.bak` —— 防「worker 重做 bak 让闸门通过」，也防同步回滚。
- **worker 自报的 md5 不可信**：它收工时算的，之后可能被它自己、被同步、或被主代理改动。只认调度者落盘后自己算的。
- **同一路径只允许一个 writer**：这一轮犯过一次 —— 批次 C 还在做第二轮重扫时，主代理直接改了它的 5 处，导致它误判「有野进程写入」。
- **1200 行的粒度是对的**：3 个批次 × 3 块，每块一文件一 worker，没有路径冲突。
