<span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">**Theorem（定理）.**</span>
$\mathbb{R}$ 是一个包含 $\mathbb{Q}$ 的 complete ordered field（完备有序域）。

<span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3;">**Definition（定义）—— Upper Bound（上界）与 Lower Bound（下界）.**</span>
设 $S$ 是一个 ordered set（序集）。$S$ 的一个 non-empty（非空）subset（子集）$A$ 被称为有一个 upper bound（上界），如果存在 $M \in S$ 使得对所有 $a \in A$ 都有 $a \leq M$。Completeness（完备性）是指每个 bounded（有界）non-empty subset 都有一个 least upper bound（最小上界）。我们用 $\sup A$ 表示 $A$ 的 smallest upper bound（最小上界），称为 supremum（上确界）。

类似地，一个 non-empty subset $A$ 被称为有一个 lower bound（下界），如果存在 $m \in S$ 使得对所有 $a \in A$ 都有 $m \leq a$。Greatest lower bound（最大下界）是一个大于或等于所有其他 lower bounds 的 lower bound，记为 $\inf A$，称为 infimum（下确界）。

此后我们将集中讨论 $\mathbb{R}$ 的情形。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">How to Write a Mathematical Proof（如何写数学证明）</span>

本讲我们将学习如何撰写一个 mathematical proof（数学证明）。我们将通过两个上次讨论过的结果来说明这一点。

回顾证明 $\sqrt{2} \in \mathbb{R}$ 的例子。我们之前已经证明过，但当时没有将其写成"proper proof（规范证明）"。下面我们就来做这件事。

<span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">**Theorem（定理）.**</span>
存在 $\alpha > 0$ 使得 $\alpha^2 = 2$。

<span style="color:#2471a3;">**[proof]**</span> <span style="color:#2471a3;">**Proof（证明）.**</span>

> 定义一个集合 $A$ 为
> ```math
> A = \{ x \in \mathbb{R} \mid x > 0 \text{ and } x^2 \leq 2 \}.
> ```
> 我们将证明 $A$ 是一个 non-empty bounded subset，并且 $\alpha = \sup A$ 满足 $\alpha > 0$ 且 $\alpha^2 = 2$。
>
> 首先观察到 $1 \in A$，因此 $A$ 是 non-empty 的。此外，$2$ 是 $A$ 的一个 upper bound，因此 $A$ 是 bounded from above（上有界）的。令 $\alpha = \sup A$，我们需要证明 $\alpha > 0$ 且 $\alpha^2 = 2$。由于 $1 \in A$，可得 $0 < 1 < \alpha$。为了证明 $\alpha^2 = 2$，我们将证明分为两部分。
>
> **Part 1（第一部分）:** 证明 $\alpha^2 \leq 2$。假设不成立，我们将看到这会导出 contradiction（矛盾）。具体来说，我们将证明如果 $\alpha^2 > 2$，那么存在一个 $0 < \alpha_0 < \alpha$ 使得 $\alpha_0^2 > 2$，从而 $\alpha_0$ 是一个比 $\alpha$ 更小的 upper bound。为此，令
> ```math
> h = \frac{\alpha^2 - 2}{4\alpha}
> ```
> 并设
> ```math
> \alpha_0 = \alpha - h.
> ```
> 注意到由于我们假设 $\alpha^2 > 2$，因此 $h > 0$，从而 $\alpha_0 < \alpha$。同时，由于 $1 \leq \alpha \leq 2$，我们有
> ```math
> h \leq \frac{1}{2} \quad \text{且} \quad 0 < \alpha_0.
> ```
> 接下来，
> ```math
> \alpha_0^2 = \alpha^2 + h^2 - 2h\alpha > \alpha^2 - 2h\alpha = \alpha^2 - \frac{\alpha^2 - 2}{2} = \frac{\alpha^2}{2} + 1 \geq 2.
> ```
> 这就得到了所需的 contradiction，从而证明了 $\alpha^2 \leq 2$。
>
> **Part 2（第二部分）:** 接下来证明 $\alpha^2 \geq 2$。假设不成立，我们将看到这会导出 contradiction。具体来说，如果 $\alpha^2 < 2$，那么存在一个 $\alpha_1 > \alpha$ 使得 $\alpha_1^2 < 2$，这与 $\alpha$ 是 $A$ 的一个 upper bound 相矛盾。假设 $\alpha^2 < 2$，这次令
> ```math
> h = \frac{2 - \alpha^2}{4\alpha}.
> ```
> 注意 $1 > h > 0$（第一个不等式由 $1 \leq \alpha$ 推出）。设 $\alpha_1 = \alpha + h$。则有
> ```math
> \alpha_1^2 = \alpha^2 + h^2 + 2h\alpha < \alpha^2 + h \cdot \frac{2 - \alpha^2}{2\alpha} = \alpha^2 + \frac{2 - \alpha^2}{2} = 2.
> ```
>
> 综合 Part 1 和 Part 2，可得 $\alpha^2 = 2$，证明完成。∎

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Archimedean Property（阿基米德性质）</span>

<span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">**Theorem（定理）.**</span>
Natural numbers（自然数）的集合 $\mathbb{N}$ 不是 bounded from above（上有界）的。

<span style="color:#2471a3;">**[proof]**</span> <span style="color:#2471a3;">**Proof（证明）.**</span>

> 假设 $\mathbb{N}$ 是 bounded from above 的，则令 $M$ 为其 least upper bound（最小上界）。那么对所有 $n \in \mathbb{N}$，有 $n \leq M$。我们断言此时 $M - 1$ 也是一个 upper bound，这与 $M$ 是 least upper bound 相矛盾。事实上，对任意给定的 $n$，由于 $M$ 是所有自然数的 upper bound，我们有 $n + 1 \leq M$，这意味着 $n \leq M - 1$，从而 $M - 1$ 是一个 upper bound。这就得到了所需的 contradiction。∎

<span style="color:#2471a3;">**[corollary]**</span> <span style="color:#c0392b">**Corollary（推论）.**</span>
对任意 $\epsilon > 0$，存在 $n \in \mathbb{N}$ 使得 $\frac{1}{n} < \epsilon$。

<span style="color:#2471a3;">**[proof]**</span> <span style="color:#2471a3;">**Proof（证明）.**</span>

> 设 $\alpha = \frac{1}{\epsilon}$。由 Archimedean property（阿基米德性质）可知存在 $n \in \mathbb{N}$ 满足 $n > \alpha$。于是 $\frac{1}{n} < \epsilon$。∎

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Sequences（序列）</span>

$\sqrt{2}$ 可以被看作一个由十进制数组成的 sequence（序列）的 limit（极限），如下所示：
```math
1 < 1.4 < 1.41 < 1.414 < \cdots.
```

**Limit（极限）何时存在？**

一个 real numbers（实数）的 sequence 是一个函数 $f : \mathbb{N} \to \mathbb{R}$。通常我们使用记号 $a_n = f(n)$。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#00838f;">**Example 1（例 1）.**</span> $\sqrt{2}$ 是 $a_1 = 1$, $a_2 = 1.4$, $a_3 = 1.41$, $a_4 = 1.414$ 等的 limit。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#00838f;">**Example 2（例 2）.**</span> $a_n = (-1)^n$。这个 sequence 没有 limit，因为 $a_n$ 在 $-1$ 和 $1$ 之间交替。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#00838f;">**Example 3（例 3）.**</span> Sequence $a_n = \frac{1}{n}$ 以 $0$ 为 limit。

<span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3;">**Definition（定义）—— Limit of a Sequence（序列的极限）.**</span>
设 $\{a_n\}$ 是一个 sequence，$a$ 是一个 real number。我们说 $a_n$ **converges（收敛）** 到 $a$，如果对任意 $\epsilon > 0$，存在 $N \in \mathbb{N}$ 使得当 $n \geq N$ 时，有
```math
|a_n - a| < \epsilon.
```
