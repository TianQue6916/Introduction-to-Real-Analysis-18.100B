# Introduction to Real Analysis · MIT 18.100B

实分析课程的双语学习资料库。

- 教材：Thomson / Bruckner / Bruckner《Elementary Real Analysis》（TBB）
- 参考：Rudin《Principles of Mathematical Analysis》
- 视频：MIT OCW 18.100B（视频本体因体积未收录，字幕见 `05-subtitles/`）

## 目录结构

| 目录 | 内容 |
|---|---|
| `01-lecture-notes/` | 课堂讲义 L01–L23 逐句双语翻译（`.bilingual.md`）+ 排版 PDF |
| `02-textbook-TBB/` | TBB 教材逐段双语翻译，按 50 页分块（`part001`–`part014`）；`_old-drafts/` 为早期草稿 |
| `03-problem-sets/` | Problem Set PS01–PS10：原题 PDF + 双语详解 |
| `04-exams/` | 期中 / 期末复习资料 |
| `05-subtitles/` | 全部讲次的中英双语字幕（`.srt` 英文原轨 + `.zho-hans.srt` 中文轨） |
| `06-notes/` | 个人推导笔记与专题解析（度量空间公理、完备性、Archimedean 性质、三次方根存在性等） |

## 双语规范

正文以中文为主体，英文术语以 `English term（中文）` 形式行内嵌入，不出现英中分段对照；公式与 LaTeX 环境保留英文原样。

## 学习定位

本库对应方舟计划中的**实分析主线**，服务于后续的测度论、泛函分析与概率论公理化。
