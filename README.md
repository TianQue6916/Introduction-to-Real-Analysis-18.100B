# Introduction to Real Analysis · MIT 18.100B

实分析课程的双语学习资料库。

- 教材：Thomson / Bruckner / Bruckner《Elementary Real Analysis》（TBB）
- 参考：Rudin《Principles of Mathematical Analysis》
- 视频：MIT OCW 18.100B（视频本体因体积未收录，字幕见 `05-subtitles/`）

## 双语规范

正文以中文为主体，英文术语以 `English term（中文）` 形式行内嵌入，不出现英中分段对照；公式与 LaTeX 环境保留英文原样。

## 学习定位

本库对应方舟计划中的**实分析主线**，服务于后续的测度论、泛函分析与概率论公理化。
