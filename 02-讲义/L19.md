### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Question: What kind of functions are integrable?（问题：什么样的函数是可积的？）</span>

本讲从一个问题出发：什么样的 function（函数）是 integrable（可积的）？

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem（定理）</span>

任何在 $[a, b]$ 上的 continuous function（连续函数）都属于 $\mathcal{R}([a, b])$（这里 $\mathcal{R}([a, b])$ 表示 $[a, b]$ 上 Riemann integrable functions（黎曼可积函数）的全体）。

> <span style="color:#7f8c8d;">TBB Theorem 8.17 (Riemann–Lebesgue), §8.6.3 Lebesgue's Criterion, p.353（连续函数是"除一个零测集外连续"的特例；另见 Corollary 8.19, §8.6.4, p.355）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条定理在 L18 已经证过，今天是把它当作出发点重新亮出来。真正要抓住的是它背后的工作引擎：一个有界函数 Riemann integrable（黎曼可积）当且仅当对每个 $\varepsilon > 0$ 都存在一个 partition（划分）$P$，使 $U(f, P) - L(f, P) < \varepsilon$。Colding 复述这条引理时的措辞是：🎥 *Colding*："we were talking about that this was a useful lemma to determine whether a function was Riemann integrable"（翻译：我们上次说过，这是一个判定函数是否黎曼可积的有用引理）。
>
> 为什么它是引擎，而不是又一条定理？因为黎曼积分的原始定义是一个「两个极限相等」的陈述：upper sum（上和）的下极限，等于 lower sum（下和）的上极限。这句话里有两个量同时在动，没法直接摆弄。引理把「两个极限相等」换成「单个有限对象的比较」：只要造出一张具体的 partition（划分），让上和与下和靠得足够近，可积性就成立。于是「证明可积」从分析问题变成构造问题——本讲后面每一个 [proof] 块的第一步都是同一句话：给定 $\varepsilon$，去找划分。
>
> 两个方向都值得看清，免得把它当纯技巧。反方向（可积蕴含存在好划分）靠上积分与下积分相等的定义：两个数既然相等，就能取到差距任意小的划分。正方向（存在好划分蕴含可积）靠单调性：加细只让上和下降、下和上升，而上和永远压着上积分、下和永远顶着下积分，所以一旦某个划分把差距压到 $\varepsilon$ 以下，上积分与下积分之间也就差不到 $\varepsilon$；$\varepsilon$ 任意，两者只能相等。本讲只用正方向——这解释了为什么后面每次出现 $\varepsilon$，第一动作都是造 partition（划分），而不是去算两个积分。
>
> 手算一个例子，体会误差账本。取 $f(x) = x^2$ 在 $[0, 1]$ 上做 n 等分 partition（划分）：第 $i$ 个小区间是 $[(i-1)/n, i/n]$。因为 $x^2$ 单调递增，$\sup$ 在右端点取到、$\inf$ 在左端点取到，于是 $U(f, P) = \sum_{i=1}^{n} (i/n)^2 (1/n)$，$L(f, P) = \sum_{i=1}^{n} ((i-1)/n)^2 (1/n)$，相减只剩每段的平方差：$U - L = \sum_{i=1}^{n} (i^2 - (i-1)^2)/n^3 = n^2/n^3 = 1/n$。用 python 复算：$n = 100$ 时 $U = 0.33835$、$L = 0.32835$、差 $0.01$；$n = 101$ 时差 $0.009901$。所以要让 $\varepsilon = 0.01$ 兑现，段数必须严格大于 100——等号那一档不算数，这正是引理写成严格小于的原因。留意误差随段数只按 $1/n$ 衰减，很慢：想要 $10^{-6}$ 的精度，得切百万段。
>
> 跨课程连接：这和 CSAPP 第 2 章处理浮点比较是同一个思路。判断两个浮点数相等时，工程上不写 $a == b$，而写 $|a - b| < \varepsilon$，因为舍入让「精确相等」失去意义；引理同样不要求 $U = L$，只要求 $U - L$ 落进给定的 budget（预算）。区别有两处：浮点的 $\varepsilon$ 由机器精度给定，还会被运算一路放大，relative error（相对误差）逐次累积；这里的 $\varepsilon$ 由证明者任意指定，并由「加密 partition（划分）」这个动作可控兑现。浮点判据回答「两个数够不够近」，引理回答「一个函数够不够可积」，后者是前者的极限化版本。
>
> 回到正文：接下来的四条基本公式、fundamental theorem of calculus（微积分基本定理）的两个版本，套路都是同一条——把可积性翻译成「找一个 partition（划分）」，把等式翻译成「上积分与下积分被同时夹住」。换句话说，本讲的每一次证明都在花同一笔钱：把任意给定的一分误差，换成一张具体的 partition（划分）。看清这一点，后面那些看起来重复的 $\varepsilon$ 论证就不再是重复，而是同一个引擎换了不同的负载。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Basic properties of integrals（积分的基本性质）</span>

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem: Basic formulas for integrals（定理：积分的基本公式）</span>

我们关于积分有如下几条基本公式：

**(1)** 若 $f \in \mathcal{R}([a, b])$ 且 $c \in \mathbb{R}$，则 $cf \in \mathcal{R}([a, b])$，且

```math
\int_a^b (cf)(x)\,dx = c \int_a^b f(x)\,dx .
```

**(2)** 若 $f, g \in \mathcal{R}([a, b])$，则 $f + g \in \mathcal{R}([a, b])$，且

```math
\int_a^b (f + g)(x)\,dx = \int_a^b f(x)\,dx + \int_a^b g(x)\,dx .
```

**(3)** 若 $f, g \in \mathcal{R}([a, b])$ 且 $f \le g$，则

```math
\int_a^b f(x)\,dx \le \int_a^b g(x)\,dx .
```

**(4)** 若 $f \in \mathcal{R}([a, b])$ 且 $c \in (a, b)$，则 $f \in \mathcal{R}([a, c])$ 且 $f \in \mathcal{R}([c, b])$，并且

```math
\int_a^c f(x)\,dx + \int_c^b f(x)\,dx = \int_a^b f(x)\,dx .
```

> <span style="color:#7f8c8d;">TBB 8.22 (Additive), 8.23 (Linear), 8.24 (Monotone), 8.25 (Absolute), §8.7 Properties of the Riemann Integral, p.356（TBB 的 8.22 是"两段拼一段"方向，本讲的 (4) 是"一段拆两段"方向，两者等价）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，课堂取舍）:**</span> 四条公式的证明讲义里都有，课堂只证第 (2) 与第 (4)。Colding 的取舍说得很直接：🎥 *Colding*："I won't prove the first one. But let's prove the second one."（翻译：第一条我不证了，我们证第二条。）讲到第 (3) 条时他说：🎥 *Colding*："I won't prove this. It's sort of, in a way-- maybe I'll just say words"（翻译：这条我不证了……也许我只说几句想法）。随后补了一句交底：🎥 *Colding*："the proofs are all in the notes"（翻译：证明都在讲义里）。
>
> 这不是偷懒，是成本核算。四条里第 (1) 与第 (3) 各自只有一步，第 (2) 与第 (4) 才需要真正的机制。第 (3) 为什么一步就够？因为 $f \le g$ 是逐点的，于是在每个小区间上都有 $\sup f \le \sup g$ 与 $\inf f \le \inf g$，上和与下和逐项被压住，再对上、下积分取极限就得到不等式。关键在于「逐点不等式升级成逐项不等式」：$\sup$ 与 $\inf$ 都保序，这正是它们比「取某一点的值」更好用的地方——某一点的值可以相等或翻转，而界不会。
>
> 第 (1) 看起来最平凡，技术点却藏在符号上。$c > 0$ 时 $\sup(cf) = c \sup f$，直接把常数提出去即可；但 $c < 0$ 时不等式翻转，$\sup(cf) = c \inf f$，上和会变成下和的形状，只有先靠「$-$ 号提出来」把符号正过来，才能复用同一套逐项估计。这就是为什么第 (1) 在讲义里占的篇幅最少、却最容易被写错。
>
> 那么为什么偏偏选第 (4) 条进课堂？因为它是后面 FTC 版本 1 的支点。证明 $F'(x_0) = f(x_0)$ 时，要把 $F(x) - F(x_0)$ 化成 $[x_0, x]$ 上的一段积分，靠的正是 $a \to x_0 \to x$ 的拆分；没有这一条，差商就降不下一维。课堂时间有限，Colding 优先讲被后续定理反复调用的那条，把只被调用一次的第 (1) 与第 (3) 留给讲义。
>
> 再补一句关于「只说想法」的可信度。第 (3) 的口头论证其实已经含着完整逻辑：逐点序、逐项序、取极限，三步都在，缺的只是把 $\varepsilon$ 与 partition（划分）显式写出来。这类「缺形式不缺骨架」的口头证明在课堂上很常见，读讲义时要补的正是那句「给定 $\varepsilon$，取使 $U - L < \varepsilon$ 的 partition（划分）」。分清缺的是骨架还是缺的是量化，才不至于把口头的三步当成启发式。
>
> 具体算一遍第 (3) 的逐项压住。取 $f(x) = x^2$、$g(x) = x$ 在 $[0,1]$ 上，n = 10 等分：第 $i$ 段上 $\sup f = i^2/100$、$\sup g = i/10$，而 $i^2/100 \le i/10$ 等价于 $i \le 10$，每段都成立。求和得 $U(f) = 0.385$、$U(g) = 0.55$（python 复算），取极限后 $\int_0^1 x^2\,dx = 1/3$、$\int_0^1 x\,dx = 1/2$，$0.3333 \le 0.5$。再验第 (1) 的符号翻转：取 $c = -2$ 与 $f(x) = x$ 在小区间 $[0.4, 0.6]$ 上，$\sup f = 0.6$、$\inf f = 0.4$，而 $\sup(cf) = -0.8$、$\inf(cf) = -1.2$，正是 $\sup$ 与 $\inf$ 互换后再乘 $|c|$。
>
> 跨课程连接：这四条合起来，等于宣布「积分是一个正的线性算子」。Probability（概率论）里 expectation（期望）的公理几乎是同一组：$E[cX] = cE[X]$、$E[X + Y] = E[X] + E[Y]$、$X \ge 0$ 蕴含 $E[X] \ge 0$。路径很直白：把函数看成「取值 × 权重」的加权平均，积分就是这种平均；区别在于概率论多要求总质量为 1，积分不归一化，所以积分是「未归一化的期望」，而概率密度只是积分的一个特例。顺带一提，$E[X + Y] = E[X] + E[Y]$ 对任意两个随机变量都成立、不需要独立，这与积分的线性对任意两个可积函数成立完全并列——独立性的位置在乘法那一侧，不在加法。
>
> 一句话收束：课堂上省下的不是思想，只是把「序关系蕴含逐项关系蕴含取极限」这条链子当众念一遍的时间。

> <span style="color:#1e8449;">**[note] Note（译者注，符号的来历）:**</span> 记号本身就是压缩过的算法。Colding 的原话：🎥 *Colding*："this is like a giant S. So it's referring to summation. This here is, of course, a d. And delta is the Greek letter for d. And so this here, you should think about this here as referring to some sort of limit of this delta xi."（翻译：积分号像一个拉长的 S，指代求和；这里的 d 当然就是 d，而 delta 是希腊字母版的 d；所以 $dx$ 应当被理解为 $\Delta x_i$ 的某种极限。）
>
> 拆开看，两套记号是同一个动作的两个阶段。$\int$ 与 $\sum$ 对应「有限段求和之后取极限」；$dx$ 与 $\Delta x_i$ 对应「第 $i$ 段的长度，然后让最大段长趋于零」。黎曼和 $\sum_i M_i \Delta x_i$ 是原型，积分记号是段数推向无穷之后的写法。理解这层，$U - L < \varepsilon$ 那套语言就不抽象了：它说的是「用有限段近似，误差可以被段长控制」，而 $dx$ 只是提醒你，那个控制已经做完了。
>
> 史实部分可以落到一手材料上。积分号首次出现于 Leibniz 1675 年 10 月 29 日的一份未发表手稿，MacTutor 的日历条目写作「integral symbol was first used by Gottfried Leibniz in an unpublished manuscript, Analyseos tetragonisticae pars secunda」（https://mathshistory.st-andrews.ac.uk/OfTheDay/oftheday-10-29/）；Leibniz 手稿的英译，即 Child 译本（密歇根大学 umhistmath 藏本），把引入记号的两段文字定在 1675 年 10 月 26 日那份手稿里，符号是 summa（求和）首字母的长写体。至于 $d$ 取自拉丁词 differentia 这一常见说法，我没有查到 Leibniz 本人手稿的一手表述，标为「未能一手核实」。
>
> 这段记号史插得突然，位置却很讲究。它出现在一个学生追问之后：既然「可积性靠找划分」这套框架已经稳固，谁还会回头去算划分？Colding 的回答是不必回头，框架一稳就直接写积分。也就是说，记号不是装饰，它是「可以停止追问、开始计算」的许可证：$dx$ 把「取过极限的划分」封了进去，从此积分是好用的符号，而不是待证的极限。
>
> 记号也有陷阱：$dx$ 不是数，不能约分。$\frac{df}{dx}$ 看着像除法，实质是 difference quotient（差商）的极限；链式法则里把 $dx$ 当分母消掉只是记忆法，真正的理由是导数定义加极限定理。凡在公式里对 $dx$ 做乘除，都要能退回「先写差商、再取极限」这一步去验。
>
> 算一笔账，看极限记号到底省了什么。$f(x) = x$ 在 $[0,1]$ 上，n = 100 等分：$U = \sum_{i=1}^{100} (i/100)(1/100) = 0.505$，$L = \sum_{i=1}^{100} ((i-1)/100)(1/100) = 0.495$，两者相差 $1/n = 0.01$，而积分值 $0.5$ 正好是两端共同的极限。也就是说 $dx$ 不是「无穷小量」，它是「$\Delta x_i$ 已经取过极限」的提示符；真实存在的是那 $0.01$ 的误差，它最后被 $\varepsilon$ 收走。
>
> $dx$ 还有第二个作用：指明谁在变。写 $\int_a^b f(s)\,ds$ 时，$ds$ 锁定了变量是 $s$，函数与积分变量才配得上对；换元时 $ds$ 要跟着变形，正是「$\Delta s$ 会被拉伸」的记账。这一点在 FTC 的证明里已经用到：$F(x) = \int_a^x f(s)\,ds$ 里 $x$ 出现在上限而不是 $ds$ 里，所以对 $x$ 求导时得到的是 $f(x)$ 本身，而不是某个含 $dx$ 的复杂对象。
>
> 跨课程连接：CLRS 分析算法代价时用的 $\sum$ 与本讲的 $\int$ 是同族工具，区别是离散与连续——$\sum_{i=1}^{n} i = n(n+1)/2$ 是精确闭式，$\int$ 给连续近似。到 CSAPP 第 2、3 章，$\sum$ 又换了第三种身份：浮点累加不满足结合律，$0.1$ 加十次不等于 $1.0$，求和顺序会改变结果。数学的 $\sum$ 精确且可交换，浮点的 $\sum$ 有舍入且不可交换——同一个符号，三种语义，这是读代码与读公式时必须分开的两套账。

<span style="color:#2471a3;">**[proof]**</span> *Proof of (2)（性质 (2) 的证明）.* 我们证明：若 $f, g$ 都 Riemann 可积，则 $f + g$ 也 Riemann 可积。给定 $\varepsilon > 0$。由于 $f$ 可积，由 L18 的引理，存在划分 $P_1$ 使得 $U(f, P_1) - L(f, P_1) < \frac{\varepsilon}{2}$；同样地，由于 $g$ 可积，存在第二个划分 $P_2$ 使得 $U(g, P_2) - L(g, P_2) < \frac{\varepsilon}{2}$。现在令 $P$ 为同时拥有 $P_1$ 与 $P_2$ 的全部分点的划分，即 $P$ 是 $P_1$ 与 $P_2$ 两者的 refinement（加细）。加细只会让上和下降、下和上升，于是

```math
U(f, P) - L(f, P) \le U(f, P_1) - L(f, P_1) < \frac{\varepsilon}{2}, \qquad U(g, P) - L(g, P) \le U(g, P_2) - L(g, P_2) < \frac{\varepsilon}{2} .
```

接着看任一小区间 $[x_{i-1}, x_i]$ 上的贡献。这里要小心一个细节：在这个区间上，

```math
m_i(f) + m_i(g) \;\le\; m_i(f + g) \;\le\; M_i(f + g) \;\le\; M_i(f) + M_i(g),
```

其中两端的两个不等式（"和的下确界不小于下确界之和"、"和的上确界不大于上确界之和"）一定成立，但中间的等号不必成立——两个不等式都可能严格。Colding 给的反例是：取 $g = -f$，则 $f + g$ 恒为零，而 $M_i(f) + M_i(g)$ 与 $m_i(f) + m_i(g)$ 是一正一负的两个数，可以离 $0$ 很远。由上述不等式，这个小区间对上、下和之差的贡献满足

```math
\bigl(M_i(f + g) - m_i(f + g)\bigr)\,\Delta x_i \;\le\; \bigl(M_i(f) - m_i(f)\bigr)\,\Delta x_i + \bigl(M_i(g) - m_i(g)\bigr)\,\Delta x_i .
```

对所有 $i$ 求和，右边恰好拆成两个黎曼和之差，得

```math
U(f + g, P) - L(f + g, P) \;\le\; \bigl[U(f, P) - L(f, P)\bigr] + \bigl[U(g, P) - L(g, P)\bigr] \;<\; \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon .
```

由引理即知 $f + g \in \mathcal{R}([a, b])$。至于积分的等式部分：把上面得到的 $m_i(f) + m_i(g) \le m_i(f+g) \le M_i(f) + M_i(g)$ 两端对 $i$ 求和并取极限，配合 $f+g$ 与 $f+g$ 上、下积分的夹逼，即得 $\int_a^b (f+g)\,dx = \int_a^b f\,dx + \int_a^b g\,dx$。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这个证明是两个旧模板的合体，各管一半。第一个模板是「公共加细法」：两个函数各自能给出一个好划分，两张划分不必相同，于是把两边的分点并起来，得到一张同时加细了两者的 partition（划分）$P$。第二个模板是「$\varepsilon/2$ 劈分」：把目标误差平半分给两个函数，各自出一张牌，合并后误差才恰好不超预算。Colding 把这两处易错点讲得很明确：🎥 *Colding*："when you're looking at two functions, and you're looking at a little interval, and you're taking the sup of the sum, then that's bounded by the sum of the sup. But it's not equal to the sum, and likewise for the inf."（翻译：对两个函数在同一小区间上取和的上确界，它被两个上确界之和控制，但并不等于那个和；下确界同理。）
>
> 先看公共加细为什么有效。加细是单调的：多切几刀，上和只会下降、下和只会上升，于是 $U - L$ 只会变小。所以只要 $P$ 同时是 $P_1$ 与 $P_2$ 的 refinement（加细），$f$ 在 $P$ 上的差距就不超过它在 $P_1$ 上的差距，$g$ 同理。反过来说，如果不取并，只用 $P_1$ 去估 $g$，那 $g$ 的好性质就没了——这就是「一个函数一张划分，必须取并」的全部理由。
>
> 再看那个只能取不等号的地方。在小区间上，$\sup(f + g) \le \sup f + \sup g$ 与 $\inf(f + g) \ge \inf f + \inf g$ 恒成立，而等号可以不成立。Colding 给的反例是 $g = -f$：取 $f(x) = x$、$g(x) = -x$ 在 $[0.4, 0.6]$ 上，$\sup f = 0.6$、$\sup g = -0.4$，两者之和是 $0.2$，可 $\sup(f + g) = \sup 0 = 0$，严格小于；下界那头，$\inf f + \inf g = 0.4 + (-0.6) = -0.2$，而 $\inf(f + g) = 0$，严格大于。所以不等式两侧的界是「松的界」，证明必须容忍这点松弛，而不能指望等号。
>
> 有了这层松弛，$\varepsilon/2$ 的算术才成立。取 $\varepsilon = 0.02$，两张划分各自保证差距小于 $0.01$，合并后总差距小于 $0.02$；如果偷懒只要求各自小于 $\varepsilon$，合并就变成 $2\varepsilon$，超支一倍。这条「两处误差相加要小于目标」的账，与你在 L06 柯西收敛、L11 度量空间「收敛蕴含柯西」里见到的骨架完全一样，只是每次的「两处」换成不同的对象。
>
> 还有一点容易漏：等式之所以能成立，是因为两个函数最终共用同一张 $P$。若不共用，$f$ 的上和在 $P_1$ 上取极限、$g$ 的上和在 $P_2$ 上取极限，两条极限序列没法对齐相加；取并之后同一张 partition（划分）同时服务两边，逐项的加法才和极限交换得了。
>
> 还要注意证明的不对称：本块只用引理证了「$f + g$ 可积」，等式部分则是顺着同一串上、下和不等式夹逼出来的，两条结论的证明深度不同。这不是省略——可积性是存在性命题，需要构造划分；等式是数值命题，只需要把已经压住的两端贴上积分。
>
> 跨课程连接：6.042J 里的 partition（划分）与这里的 partition（划分）同名同源。6.042J 用等价关系把集合切成互不相交的 block（块），加细指「每个新块落在某个旧块里」；这里的 partition（划分）只是区间上的分点集合，加细就是在原有分点之外再添分点，正是同一概念在一维区间上的特例。区别在于：6.042J 的划分由等价关系唯一决定，这里的划分是人手挑的构造物，可自由加细——正因为自由，才能被 $\varepsilon$ 指挥。

<span style="color:#2471a3;">**[proof]**</span> *Proof of (4)（性质 (4) 的证明）.* 先证：$f$ 在 $[a, b]$ 上可积，则 $f$ 限制到 $[a, c]$ 与 $[c, b]$ 这两个子区间上仍可积。再次使用引理：给定 $\varepsilon > 0$，由于 $f$ 在 $[a, b]$ 上可积，存在划分 $P$ 使得 $U(f, P) - L(f, P) < \varepsilon$。划分 $P$ 未必把 $c$ 作为分点，于是取 $P^*$ 为在 $P$ 的全部分点之外再添入 $c$ 的加细（若 $c$ 本来就是分点，则 $P^* = P$ 即可）。由于 $P^*$ 是 $P$ 的加细，仍有

```math
U(f, P^*) - L(f, P^*) < \varepsilon .
```

现在把 $P^*$ 按 $c$ 切开：$P^*$ 在 $[a, c]$ 上的部分记为 $P^*|_{[a,c]}$，在 $[c, b]$ 上的部分记为 $P^*|_{[c,b]}$。由黎曼和逐段相加的算术性质，

```math
U(f, P^*) = U(f, P^*|_{[a,c]}) + U(f, P^*|_{[c,b]}), \qquad L(f, P^*) = L(f, P^*|_{[a,c]}) + L(f, P^*|_{[c,b]}) .
```

两式相减并重新排列，得

```math
\bigl[U(f, P^*|_{[a,c]}) - L(f, P^*|_{[a,c]})\bigr] + \bigl[U(f, P^*|_{[c,b]}) - L(f, P^*|_{[c,b]})\bigr] < \varepsilon .
```

方括号里的两项都是非负的（上和总不小于下和），而它们的和小于 $\varepsilon$，所以每一项各自都不超过 $\varepsilon$。由引理，$f$ 在 $[a, c]$ 与 $[c, b]$ 上都可积。至于积分的拆分等式：上述两个等式在上、下和层面本来就是"整体和等于两段之和"，对上、下积分取极限即得 $\int_a^c f\,dx + \int_c^b f\,dx = \int_a^b f\,dx$。（等式部分的细节 Colding 留作练习，并说课堂证明的核心是可积性那一半：🎥 *"But really, what I, technically speaking, proved was just this part here."*（翻译：不过严格来说，我证明的其实只是这一部分。））$\square$

### <span style="color:#2471a3;">**[corollary]**</span> <span style="color:#c0392b">Corollary（推论）</span>

设 $f, |f| \in \mathcal{R}([a, b])$，则

```math
\left| \int_a^b f(x)\,dx \right| \le \int_a^b |f(x)|\,dx .
```

> <span style="color:#7f8c8d;">TBB 8.25 (Absolute Property), §8.7, p.356（TBB 进一步证明 $f$ 可积时 $|f|$ 自动可积，见 Corollary 8.21, §8.6.4, p.355，故其陈述无需假设 $|f|$ 可积）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 这是一个非常简单却极其有用的不等式。既然已假设一切函数都 Riemann 可积，我们只需建立这个不等式。对一切 $x$ 显然有

```math
f(x) \le |f(x)|,
```

因为 $f$ 为正时二者相等，$f$ 为负时右边非负。同样显然的是 $-f(x) \le |f(x)|$。把第一条不等式（记为 $*$）与性质 (3) 结合，得 $\int_a^b f\,dx \le \int_a^b |f|\,dx$。把第二条不等式（记为 $**$）与性质 (3) 结合，得 $\int_a^b (-f)\,dx \le \int_a^b |f|\,dx$。而 $-f$ 就是 $-1$ 乘以 $f$，由性质 (1)，$-1$ 可以提到积分号外，于是左端等于 $-\int_a^b f\,dx$。两个不等式合起来，正是 $-\int_a^b f\,dx \le \int_a^b |f|\,dx$ 与 $\int_a^b f\,dx \le \int_a^b |f|\,dx$ 同时成立，即积分的绝对值被 $\int_a^b |f|\,dx$ 控制。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，方法论）:**</span> 这个不等式的作用是把「绝对值的界」拆成两个「不带绝对值的界」。Colding 的原话是：🎥 *Colding*："this is very simple inequality, but extremely useful"（翻译：这是一个非常简单的不等式，却极其有用。）
>
> 机制只有一行恒等式：$|A| = \max\{A, -A\}$。所以 $|A| \le B$ 等价于「$A \le B$ 且 $-A \le B$」两条同时成立——这是定义层面的等价，不是技巧。剩下的事全交给两条旧性质：由 $f \le |f|$ 与性质 (3) 得 $\int f \le \int |f|$；由 $-f \le |f|$ 与性质 (3) 得 $\int(-f) \le \int |f|$，再用性质 (1) 把 $-f$ 的积分写成 $-\int f$。两式并起来就是 $-\int |f| \le \int f \le \int |f|$。
>
> 为什么不直接对 $f$ 用性质 (3)？因为第 (3) 条比较的是两个函数，而 $f$ 与 $|f|$ 之间没有固定方向的大小关系：$f$ 取负时 $f < |f|$，取正时相等。要把结论落到 $\int f$ 自己身上，只能绕路——先造出两个都能与 $|f|$ 比较的对象（$f$ 与 $-f$），各自压住，再合并。这是「把不可比对象换成可比对象」的标准操作，后面解不等式时你会反复用到。
>
> > 这个不等式的损失可以算清楚。取 $f(x) = x - 0.5$ 在 $[0, 1]$ 上：正部在 $[0.5, 1]$、负部在 $[0, 0.5]$，两块各是底 $0.5$、高 $0.5$ 的三角形，面积各 $0.125$，故 $\int_0^1 f\,dx = 0.125 - 0.125 = 0$，而 $\int_0^1 |f|\,dx = 0.25$（python 复算）。左边 $|0| = 0$、右边 $0.25$，缺口正好是负部面积的两倍。等号成立当且仅当 $f$ 不变号，此时没有互相抵消，绝对值那一层白加。
>
> 所以这条不等式该这样读：它是「抵消会亏钱」的定量版。变号的面积越大，$\int |f|$ 与 $|\int f|$ 的差越大，差值恰好等于两倍负部面积。这个数在数值计算里非常具体：用浮点累加一个变号的序列时，抵消会让有效位被吃掉，误差界就是按 $\int |f|$ 这个量级给的，而不是按 $\int f$。
>
> 再算一个连续的例子：$f(x) = \sin x$ 在 $[0, 2\pi]$ 上，$\int_0^{2\pi} \sin x\,dx = 0$，而 $\int_0^{2\pi} |\sin x|\,dx = 4$（python 数值积分给 $4.0000000002$）。缺口 $4$ 正好是两倍负部面积——负半周期的面积是 2。这类例子说明：只要函数在一个周期里来回变号，用 $\int |f|$ 去界 $\int f$ 就非常宽松；界依然正确，但不紧。判断界紧不紧，就看负部面积有多大。
>
> > 还有个细节值得点名：证明里「提负号」的那一步，用的是性质 (1) 在 $c = -1$ 时的特例，而不是什么交换律。$-f$ 不是「减法」，它是数乘 $-1$ 乘以 $f$；把它写清楚，才不会在更复杂的式子里把 $\int (g - f)$ 误当成「两个积分相减」而不加证明地拆开。
>
> > 再看它与三角不等式的关系。$|a + b| \le |a| + |b|$ 是两项的离散情形；推广到 $n$ 项得 $|\sum a_i| \le \sum |a_i|$；把求和换成积分、有限项换成连续统，就得到本条的 $\left|\int f\right| \le \int |f|$。三者是同一条命题的三个粒度，证明手法也同一个——拆成上下两条不带绝对值的估计，再合并。
>
> 跨课程连接：Strang 的线性代数里，$\|(x, y)\|_1 = |x| + |y|$ 与欧氏长度都是范数，三角不等式对两者都成立。本条的 $\|f\|_1 = \int |f|$ 正是同一个 $L^1$ 范数在函数空间上的写法，而 $\int f$ 是一个线性泛函，不等式说的是「这个泛函的算子范数不超过 1」。区别很关键：有限维里所有范数彼此等价，函数空间里并不等价——$x^{-1/2}$ 在 $[0, 1]$ 上 $L^1$ 范数为 2 却无界，所以这里必须单独讨论可积函数类。
>
> 回到正文：整个证明只用到性质 (1) 与 (3)，第 (4) 条完全没出现，这就是 Colding 说它是第 (3) 条而非第 (4) 条的推论的原因。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Fundamental theorem of calculus（微积分基本定理）</span>

接下来要谈的是**如何计算积分**。这里的主角就是 fundamental theorem of calculus（微积分基本定理），我们给出它的两个版本。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Fundamental theorem of calculus, version 1（微积分基本定理，版本 1）</span>

设 $f$ 是 $[a, b]$ 上的连续函数，并在 $[a, b]$ 上定义

```math
F(x) = \int_a^x f(s)\,ds .
```

则函数 $F$ 是 differentiable（可微的），且其导数为 $F' = f$。

> <span style="color:#7f8c8d;">TBB 8.26 (Differentiation of the Indefinite Integral), §8.7, p.358（TBB 版本对可积 $f$ 只断言在 $f$ 的连续点处 $F'(x) = f(x)$；本讲 $f$ 连续，故结论处处成立）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 要证明 $F$ 在某点 $x_0$ 处可导，就要考察 difference quotient（差商）$\frac{F(x) - F(x_0)}{x - x_0}$，并证明它当 $x \to x_0$ 时有极限，其中 $x_0$ 固定。为了估计它，先不除，只看差 $F(x) - F(x_0)$ 本身。不妨设 $x > x_0$（从另一侧逼近的论证类似）。这时

```math
F(x) - F(x_0) = \int_a^x f(s)\,ds - \int_a^{x_0} f(s)\,ds ,
```

对第一个积分使用性质 (4)（积分可以拆开）：$\int_a^x = \int_a^{x_0} + \int_{x_0}^x$，于是

```math
F(x) - F(x_0) = \int_{x_0}^x f(s)\,ds + \int_a^{x_0} f(s)\,ds - \int_a^{x_0} f(s)\,ds = \int_{x_0}^x f(s)\,ds ,
```

后两项相消，差恰好是 $f$ 在 $[x_0, x]$ 上的积分。现在对这个积分上下夹逼：$f$ 在 $[x_0, x]$ 上连续，由 EVT（极值定理），$\max$ 与 $\sup$ 相同，且 $f(s)$ 介于该区间上 $f$ 的 $\inf$ 与 $\sup$ 之间；常数提出积分号（性质 (1)），剩下 $\int_{x_0}^x 1\,ds$ 就是区间长度，故

```math
\bigl(\inf_{[x_0,x]} f\bigr)(x - x_0) \;\le\; F(x) - F(x_0) \;\le\; \bigl(\sup_{[x_0,x]} f\bigr)(x - x_0) .
```

两边同除以 $x - x_0 > 0$，得差商被夹在 $\inf_{[x_0,x]} f$ 与 $\sup_{[x_0,x]} f$ 之间。当 $x \to x_0$ 时，$f$ 在 $x_0$ 处连续，不仅 $x$ 点的值、而是整个区间 $[x_0, x]$ 上的值都趋于 $f(x_0)$，于是夹逼的两端都趋于 $f(x_0)$。差商被两个收敛到同一数的量夹住，从而也趋于 $f(x_0)$。严格说我们只做了 $x > x_0$ 的情形；对 $x < x_0$ 从下方收敛到 $x_0$ 的情形，只需平凡修改，同样的证明成立（细节在讲义中）。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这个证明可以命名——「积分中值夹逼」。它由三件旧工具拼成：(4) 把 $F(x) - F(x_0)$ 化简成一段积分；$\sup$ 与 $\inf$ 界住这段积分；最后由 squeeze theorem（夹逼定理）收尾。Colding 把最后一步说得极直白：🎥 *Colding*："this difference quotient here goes to f of x0, because it's squeezed between those two numbers that converge to the same number — namely, to little f of x0."（翻译：这个差商趋于 $f(x_0)$，因为它被两个收敛到同一个数的量夹住了，那个数就是 $f(x_0)$。）
>
> 逐步看因果链。第一步先不除，只看差：$F(x) - F(x_0) = \int_a^x f - \int_a^{x_0} f$，用 (4) 把第一个积分在 $x_0$ 处劈开，后两项相消，只剩 $\int_{x_0}^x f$。「差的消失」是全场最要紧的一步，因为它把两个变上限积分换成一个定区间积分。第二步，$f$ continuous（连续）意味着在 $[x_0, x]$ 上取得到最大值与最小值，于是这段积分被 $\inf \cdot (x - x_0)$ 与 $\sup \cdot (x - x_0)$ 左右夹住——常数按 (1) 提出积分号，剩下 $\int 1\,ds$ 就是区间长度。第三步，除以 $x - x_0 > 0$，差商被夹在 $\inf$ 与 $\sup$ 之间；$x \to x_0$ 时区间缩成一点，连续性保证两端同趋于 $f(x_0)$。
>
> 这里有个容易忽略的设计选择：为什么不用积分中值定理？中值定理说存在 $\xi \in [x_0, x]$ 使差等于 $f(\xi)(x - x_0)$，差商就等于 $f(\xi)$，看着一步到位。问题在于 $\xi$ 依赖 $x$，而我们对 $\xi$ 没有任何控制，无法证明 $f(\xi) \to f(x_0)$。用 $\sup$ 与 $\inf$ 夹住，等于把「未知的 $\xi$」换成「两个已知的、必然随区间收缩而收敛的量」——可控性就是从这里来的，这也是夹逼比中值定理更适合做极限论证的原因。
>
> > 算一个数验证两端的夹。取 $F(x) = \int_0^x s^2\,ds = x^3/3$、$x_0 = 1$、$x = 1.1$：差商是 $(1.331/3 - 1/3)/0.1 = 1.103333$，而两端是 $\inf_{[1, 1.1]} s^2 = 1$ 与 $\sup_{[1, 1.1]} s^2 = 1.21$。$1 \le 1.103333 \le 1.21$ 成立；让 $x$ 继续贴近 $1$，两端一起收到 $1$，差商也收到 $f(1) = 1$（python 复算）。
>
> 为什么必须要求 $f$ continuous（连续）？因为最后一环用的是「区间上的 $\sup$ 与 $\inf$ 都趋于 $f(x_0)$」，这依赖该点的连续性。反例：令 $f$ 在 $[0, 1)$ 上为 $0$、在 $x = 1$ 处为 $1$，则 $F(x) = 0$（$x < 1$）、$F(1) = 0$，在 $x_0 = 1$ 处差商恒为 $0$，而 $f(1) = 1$，$F' \ne f$。所以 TBB 的版本只说「在 $f$ 的连续点处成立」，本讲因为假设 $f$ 连续，才敢写处处成立。
>
> 至于 $x < x_0$ 的情形，不必重做一遍：除以 $x - x_0$ 时不等号要翻转，其余推理逐字相同，所以讲义把它归入「平凡修改」。这是分析里常见的写法——先在一个方向把机制讲透，另一个方向只交代对称性，把笔墨省给真正的难点。
>
> > 跨课程连接：这与 CLRS 二分搜索的区间不变式是同一骨架的算法版。二分搜索维护「答案必落在 $[lo, hi]$ 里」，每步砍掉一半，直到两端相等；夹逼定理维护「差商必落在 $[\inf, \sup]$ 里」，靠连续性让两端同时收敛到同一点。区别在收敛速率的来源：二分是人手砍半，误差按 $1/2^k$ 指数下降；夹逼的速率由 $f$ 在 $x_0$ 附近的连续性模决定，可以任意慢，所以它只证明极限存在，不给出误差估计。
>
> 把这个模板压缩成三步记住：拆、夹、缩。拆用性质 (4)，把差化成一段积分；夹用 $\sup$ 与 $\inf$，得到两条常数乘长度的界；缩用 $f$ 在该点的连续性，让两端收到同一个数。命名它不是为了给方法起外号，而是为了下次遇到别的变上限对象（比如 $x \mapsto \int_a^{x^2} f$）时能直接调用同一副骨架。
>
> > 收束：可微性从此有了第二个来源。L15 用差商直接定义导数，今天看到变上限积分自动把 $f$ 变成 $F'$，微分与积分互为逆运算的前一半就落在这里。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Fundamental theorem of calculus, version 2（微积分基本定理，版本 2）</span>

设 $F : [a, b] \to \mathbb{R}$ 是可微函数，且 $F' = f \in \mathcal{R}([a, b])$，则

```math
F(b) - F(a) = \int_a^b f(s)\,ds .
```

> <span style="color:#7f8c8d;">TBB 8.27 (Integral of a Derivative), §8.7, p.358</span>

So maybe I'll just skip that."（翻译：这个证明我也写在讲义里了，所以也许我就跳过。）他还顺手把两个版本的关系摆平：🎥 *Colding*："I don't really think about it as two versions. ... it's two things about the same stuff."（翻译：我其实并不把它当作两个版本……它们是同一件事的两个侧面。）
>
> 两版的关系说得再清楚一点。版本 1 说：给 $f$ 造一个变上限积分 $F(x) = \int_a^x f(s)\,ds$，则 $F' = f$——先积分再求导，回到原处。版本 2 说：给一个可微的 $F$ 与它的导数 $f$，则 $F(b) - F(a) = \int_a^b f(s)\,ds$——先求导再积分，只差一个端点项。后者是计算工具，把「黎曼和的极限」换成「两个端点值相减」。
>
> 但版本 2 有一条不能省的前提：$f$ 必须 Riemann integrable（黎曼可积）。TBB 在 p.358 明确提醒，不能不加检验地把 $\int_a^b F'(x)\,dx$ 当成 $F(b) - F(a)$ 的替身，得先确认导数本身可积；而这件事可以失败。Volterra 在 1881 年造出了处处可微、导数有界却黎曼不可积的例子。Biskup 的讲义第 41 章说得很直：「Volterra's example has been a source of motivation for the creation of Lebesgue's theory of integration」（https://www.math.ucla.edu/~biskup/131bh.1.26s/PDFs/ch41.pdf）。
>
> Lebesgue 本人的说法也能查到一手引文。他在给 Borel 的信里写：「Je sais qu'il existe un article de Volterra, Giornale di Matematiche, tome 19, page 337, traitant du sujet」（我知道 Volterra 有一篇文章讨论这个题目），原文见 Mazliak 论文中的引述，网址为 https://perso.lpsm.paris/~mazliak/Wasiolek.pdf 。所以「正是黎曼积分积不动某些导数，促成了更一般的积分理论」这句话不是后人附会，有当事人书信为据。
>
> 那么版本 2 的证明长什么样，值得补一句。标准做法还是靠 partition（划分）：把 $[a, b]$ 切成若干小段，每段上对 $F$ 用中值定理，得 $F(x_i) - F(x_{i-1}) = f(c_i)\,\Delta x_i$，逐段相加后左边望远镜式抵消成 $F(b) - F(a)$，右边是 $f$ 的一个黎曼和 $\sum_i f(c_i)\Delta x_i$。再取划分的极限，右边收到积分。看清这套骨架，就明白课堂为什么跳过它：三步与版本 1 同族，都是分割、取材、取极限，边际收益不高。
>
> > 算一下版本 2 究竟省了多少事。要算 $\int_0^1 x^2\,dx$：用黎曼和（左端点）取 $n = 1000$，得 $0.3328335$，与真值 $1/3 = 0.3333333$ 差 $0.0004998$（python 复算），误差是 $1/(2n)$ 的量级；改用 antiderivative（原函数）$F(x) = x^3/3$，一步得 $F(1) - F(0) = 1/3$，误差为零。这就是微积分基本定理的实际价值：把「极限加估计」换成「查表加相减」。
>
> 使用时还有一条约定不能漏：定积分有方向。若 $b < a$，则 $\int_a^b f = -\int_b^a f$，端点项 $F(b) - F(a)$ 也自动跟着改号，两边仍然一致。这条约定让版本 2 在任意端点上成立，不必每次先假设 $a < b$。
>
> > 跨课程连接：这与 CLRS 里「用闭式公式替代循环累加」是同一个节约动作。$\sum_{i=1}^{n} i$ 逐项加是 $O(n)$，换成 $n(n+1)/2$ 是 $O(1)$；版本 2 把「$n$ 段求和再取极限」换成「两个端点值相减」，复杂度从无穷降到一次求值。区别也很硬：等差、等比求和总有闭式，原函数却未必是初等函数——$e^{-x^2}$ 就没有初等原函数，此时只能退回数值求和，误差又回到 $1/n$ 量级。
>
> 所以在动手之前问三个问题：找到的 $F$ 是否满足 $F' = f$、$f$ 在区间上是否可积、端点顺序是否交代清楚。三问都过，才能直接把值写成端点之差；任一条不过，就得回到定义或者改用别的积分理论。
>
> > 收束：版本 2 是计算法，版本 1 是存在性保证；两者之间隔着一道「导数可积」的门槛，TBB 的提醒正是让你别把这道门槛当成不存在。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Application of integrals: arclength（积分的应用：弧长）</span>

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#c0392b">Definition: Arclength（弧长）</span>

设 $f, g : [a, b] \to \mathbb{R}$ 是可微函数，且它们的导数连续，则我们定义曲线

```math
s \mapsto (f(s), g(s))
```

的 arclength（弧长）为

```math
L = \int_a^b \sqrt{(f'(s))^2 + (g'(s))^2}\,ds .
```

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这是本讲的收尾，一句话给一个定义。Colding 用 $\gamma(s) = (f(s), g(s))$ 这样的记号讲它：曲线是平面上的映射，有两个坐标；假设 $f$ 与 $g$ 可微、导数 continuous（连续），参数 $s$ 跑遍 $[a, b]$，然后宣布曲线的长度按定义就是那个积分。他留了一句尾巴：🎥 *Colding*："Maybe I'll talk a little bit more about that next time."（翻译：也许下次我会再多讲一点这一点。）
>
> 为什么这是定义而不是定理？因为长度在弯曲对象上没有先验含义，只有直线段才有。定义的合理性来自逼近：把 $[a, b]$ 切成小段，第 $i$ 段对应曲线上的一条小弦，弦长是 $\sqrt{(\Delta x_i)^2 + (\Delta y_i)^2}$；由中值定理，$\Delta x_i \approx f'(s_i)\Delta s_i$ 且 $\Delta y_i \approx g'(s_i)\Delta s_i$，于是弦长约等于 $\sqrt{f'(s_i)^2 + g'(s_i)^2}\,\Delta s_i$。求和取极限就是那个积分。
>
> 所以导数出现在公式里不是巧合：它是把曲线「局部拉直」的线性化系数，而弧长正是「无数小段直线长度的极限」。这也解释了为什么要求导数连续——只有被积函数连续，这个积分才名正言顺地存在，收敛性才不需要另做讨论。
>
> 算两个数对照。抛物线 $(s, s^2)$ 在 $s \in [0, 1]$ 上，$L = \int_0^1 \sqrt{1 + 4s^2}\,ds \approx 1.4789429$（python 数值积分，与闭式 $(2\sqrt{5} + \mathrm{asinh}\,2)/4$ 一致）；同样端点的直线 $(s, s)$ 给 $L = \int_0^1 \sqrt{2}\,ds = 1.4142136$。两端点相同，长度差 $0.0647293$——弯得越多、绕路越多，长度必然更大，这说明定义没有把「两点之间直线最短」这个性质弄丢。
>
> 严格化这一定义只需补一个上确界。取所有内接折线，折线长度随分点加密单调不减，而只要曲线不太野，这些长度有上界，于是上确界存在；当 $f'$ 与 $g'$ 连续时，这个上确界恰好等于积分。所以公式不是随手拍的约定，它算的是「所有折线长度的最小上界」，与直觉里的长度对齐。
>
> > 还有一个必须成立的性质：弧长可加。把 $[a, b]$ 拆成 $[a, c]$ 与 $[c, b]$，两个积分相加正好是整段积分，这正是性质 (4)。若定义没有这条性质，它就不配叫长度；反过来，正因为有它，沿曲线分段测量与一次测量才会给出同一个数。
>
> 另一个检验标准是参数化无关：同一条几何曲线换一种走法（重参数化）长度不变。这一点在公式里看得见——被积函数是速度的大小 $\sqrt{f'^2 + g'^2}$，换参数时它按链式法则乘上一个伸缩因子，而 $ds$ 同时按同一因子变化，两者抵消。若定义对重参数化敏感，它就不是几何量，只是某个参数下的记账。
>
> > 顺带说清 $\pi$ 在这里的位置。用这个公式量单位圆：参数化 $(\cos t, \sin t)$、$t \in [0, 2\pi]$，被积函数恒为 1，长度就是 $2\pi$。也就是说，一旦角与弧长一同定义，$\pi$ 的干净定义就是「单位圆周长的一半」——这与弧度制里「半圈是 $\pi$」完全对齐，而不是从面积公式里借来的常数。
>
> 跨课程连接：Strang 的线性代数里，向量 $(x, y)$ 的长度是 $\sqrt{x^2 + y^2}$；弧长公式把同一个表达式沿曲线积分了一次——局部用向量长度，全局用积分累加。这是「离散对象连续化」的标准手法，与把 $\sum$ 变成 $\int$ 同构。区别在于：线性代数里的长度是一个数，弧长可以看成参数的函数 $s \mapsto L(s) = \int_a^s \sqrt{f'^2 + g'^2}$，而由版本 1 它可微，导数正是局部伸缩率 $\sqrt{f'(s)^2 + g'(s)^2}$。
>
> 收束：这一页看着只是收尾，实际把积分的三个用途摆齐了——判定可积、计算数值、定义几何量。下一讲若继续谈弧长，接着用的一定是这三件工具。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1（例 1）</span>

设 $f(s) = s$，$g(s) = s^2$，则 $f'(s) = 1$，$g'(s) = 2s$。于是曲线 $(s, s^2)$（其中 $s \in [0, 1]$，即抛物线的一段）的弧长为

```math
L = \int_0^1 \sqrt{1 + (2s)^2}\,ds = \int_0^1 \sqrt{1 + 4s^2}\,ds .
```

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Improper integrals（反常积分）</span>

接下来讨论 improper integrals（反常积分，又称瑕积分）。它有两个版本：**版本 1** 是 interval（区间）无界，**版本 2** 是函数无界。当然还有各种变体（区间向左无界、左右均无界，奇点在右端点等），课上以"向右无界/奇点在左端点"为代表。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Unbounded interval（无界区间）</span>

设对一切 $b > a$ 都有 $f \in \mathcal{R}([a, b])$（$a$ 固定）。如果极限

```math
\lim_{b \to \infty} \int_a^b f(x)\,dx
```

存在，那么我们说 improper integral（反常积分）$\int_a^\infty f(x)\,dx$ 存在，且

```math
\int_a^\infty f(x)\,dx = \lim_{b \to \infty} \int_a^b f(x)\,dx .
```

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Unbounded function（无界函数）</span>

设对一切 $c > a$ 都有 $f \in \mathcal{R}([c, b])$（$a, b$ 固定，$f$ 可能在 $a$ 处无界甚至没有定义）。如果极限

```math
\lim_{c \to a^+} \int_c^b f(x)\,dx
```

存在，那么我们说反常积分 $\int_a^b f(x)\,dx$ 存在，且

```math
\int_a^b f(x)\,dx = \lim_{c \to a^+} \int_c^b f(x)\,dx .
```

> <span style="color:#7f8c8d;">TBB Definition 8.29（无界区间 $[a, \infty)$）与 Definition 8.28（无界函数，左端点奇点）, §8.8 The Improper Riemann Integral, p.359–360（TBB 标注此节为 enrichment（选学）章节，思想是回到 Cauchy 的第二方法——用极限把黎曼积分拼接出去）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，直观图像与级数的平行）:**</span> 为什么叫 improper（反常）？Colding 说得直白：区间不是有界的，或者函数不是有界的，黎曼积分的原始定义根本不适用，只能靠极限往外推。他还给了一个统一的心像：把积分想成 weighted area（加权面积），权重只是说函数在某段取负时，那块面积按负号记账。理解全部四个例题的总钥匙是与级数平行：🎥 *Colding*："it's a little bit like what we did for series that you're summing infinitely many numbers."（翻译：这有点像我们处理级数时对无穷多个数求和的情形。）
>
> 两个版本的做法完全一样，都是「先截断、再取极限」。版本 1 截区间：固定 $a$，让上限 $b \to \infty$，考察 $\int_a^b f$ 的极限。版本 2 截函数：固定 $b$，让下限 $c \to a^+$，考察 $\int_c^b f$ 的极限。为什么必须绕这一步？因为黎曼积分只对有界闭区间上的有界函数定义过，无穷区间与无穷大取值都不在定义域内；极限是唯一的出口。
>
> 判别直觉也只有一句话：函数必须足够快地趋零，否则面积发散。Colding 的讲法是：🎥 *Colding*："if we kind of stay above a certain line... the area below the graph would, of course, be larger than this thing. And that would be infinite. So it's not going to converge. So it will have to go to 0 in some way."（翻译：如果我们某种意义上停留在某条直线之上，图形下的面积当然会大于它，而那是无穷大，所以不会收敛；函数必须以某种方式趋于零。）
>
> 这条直觉有两半，值得分开记。必要性一半：若 $f$ 不趋零，图形永远压在某条正的水平线之上，面积必然无穷——这就是级数里「通项趋零是收敛的必要条件」。非充分一半：趋零还不够，速度要够快。级数里 $\sum 1/n$ 发散而 $\sum 1/n^2$ 收敛，正是同一个分界。
>
> 顺带看清一件事：两个版本其实是同一个机制。把上限 $b$ 或下限 $c$ 当成一个参数，积分就变成一个普通函数，收敛性问题就是问这个函数有没有极限——这与版本 1 把上限当变量造出 $F(x)$ 的手法一致。所以 improper（反常）并不需要新理论，它只是把「变量在端点」的老技巧用在无穷处。
>
> > 数字上看得更清。$\int_1^c x^{-2}\,dx = 1 - 1/c$：$c = 10$ 得 $0.9$，$c = 100$ 得 $0.99$，$c = 1000$ 得 $0.999$（python 复算），稳稳爬向 1。换成 $\int_1^c x^{-1}\,dx = \log c$：$c = 10$ 得 $2.302585$，$c = 1000$ 得 $6.907755$，没有任何要停下来的意思——要它超过 20，得取 $c \approx 4.85\times 10^{8}$。
>
> 记号上有个陷阱得提。$\int_a^\infty f$ 不是某个函数的积分，它是极限的简写；因此它不能像定积分那样无条件拆段。要把它拆成 $\int_a^M + \int_M^\infty$，必须先确认两段各自收敛，否则会出现「无穷减无穷」的无意义式子。这与级数里不能随意重排、拆项是同一类警告。
>
> > 级数与积分之间的换算也有个常用不等式，顺手可以验证收敛性。由 $1/n^2 \le \int_{n-1}^{n} x^{-2}\,dx$ 对 $n \ge 1$ 的阶梯比较，得 $\sum_{n=1}^{N} 1/n^2 \le 1 + \int_1^{N} x^{-2}\,dx = 2 - 1/N$；取 $N = 1000$，右边 $1.999$，而部分和是 $1.643935$（python 复算），界成立但不紧。真值 $\pi^2/6 = 1.644934$，说明这条界只用来判收敛，不用来估数值。
>
> 跨课程连接：Probability（概率论）里，离散分布的归一化是 $\sum_k P(X = k) = 1$，连续分布的归一化是 $\int f = 1$，两句话的差别只是「求和」换成「积分」。路径也一样：密度的尾部要足够快地趋零，否则总质量无穷，分布不存在。区别在于概率论里「收敛慢」会直接表现为期望发散——柯西分布就是密度趋零太慢，均值不存在。
>
> 收束：improper（反常）的「反常」只在定义域，不在思想；判定收敛靠的还是那条老经验——无穷本身不可怕，可怕的是无穷没有被足够快的速度压住。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 2（例 2）</span>

在 $[1, \infty)$ 上设 $f(x) = \frac{1}{x^2}$，则

```math
\int_1^c \frac{1}{x^2}\,dx = \left[ -\frac{1}{x} \right]_1^c = -\frac{1}{c} + 1 .
```

由于 $-\frac{1}{c} + 1 \to 1$（当 $c \to \infty$），反常积分 $\int_1^\infty \frac{1}{x^2}\,dx$ 存在且等于 $1$。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 3（例 3）</span>

在 $[1, \infty)$ 上设 $f(x) = \frac{1}{x}$，则

```math
\int_1^c \frac{1}{x}\,dx = \bigl[\log x\bigr]_1^c = \log c .
```

反常积分

```math
\int_1^\infty \frac{dx}{x}
```

不存在（$\log c \to \infty$）。

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 例 2 与例 3 的对比是本节最重要的信息：两个函数都趋零，命运却相反。Colding 先卖了个关子：🎥 *Colding*："It still goes to 0. So maybe it has a chance."（翻译：它仍然趋于零，所以也许它有机会。）随后揭晓答案，$\frac{1}{x^2}$ 的制胜性质是趋零真的很快，而 $\frac{1}{x}$ 不够快：🎥 *Colding*："It does not go to 0 fast enough."（翻译：它趋于零的速度不够快。）
>
> 机制落在一句话上：收敛性由 antiderivative（原函数）在无穷远处的极限决定。$\frac{1}{x^2}$ 的原函数是 $-\frac{1}{x}$，它在 $b \to \infty$ 时有极限 $0$，所以 $\int_1^b = -\frac{1}{b} + 1$ 收敛到 1。$\frac{1}{x}$ 的原函数是 $\log x$，它跑到无穷，所以积分发散。这也解释了为什么算反常积分总是先找原函数：微积分基本定理的版本 2 把「极限」变成「端点相减」，问题就从「求和是否收敛」变成「原函数有没有界」。
>
> 把「快」量化一下。$\int_1^c x^{-2} = 1 - 1/c$，误差是 $1/c$；$\int_1^c x^{-1} = \log c$，增长是 $\log c$。前者有界、后者无界，就是全部区别。若把指数换成一般的 $p$，$\int_1^c x^{-p}\,dx = (c^{1-p} - 1)/(1 - p)$（$p \ne 1$）：$p > 1$ 时 $c^{1-p} \to 0$，收敛；$p < 1$ 时 $c^{1-p} \to \infty$，发散；$p = 1$ 正好落在中间，长出 $\log c$。所以 $p = 1$ 是唯一的分界线，它对应对数这个「最慢的发散」。
>
> 把「怎么算」变成流程，就不容易卡住：第一步找原函数，第二步把端点代入得一个含 $c$ 的表达式，第三步考察 $c \to \infty$ 时的极限。三步的顺序不能颠倒——先取极限再积分得不到任何东西，$f(c) \to 0$ 与 $\int f$ 收敛是两件事，这也是下一块要点出的卡点。
>
> > 数值上把这条分界线摆出来。$c = 10$：$1 - 1/10 = 0.9$ 对 $\log 10 = 2.302585$；$c = 100$：$0.99$ 对 $4.605170$；$c = 1000$：$0.999$ 对 $6.907755$（python 复算）。一个在逼近 1，一个每乘 10 就加 $2.302585$——后者是 $\log 10$，正是「每十倍只涨一点、但永不停止」的速率。
>
> 换个刻度看「对数级发散」是什么意思。取 $c = 10^k$，则 $\int_1^c x^{-1}\,dx = k\log 10 = 2.302585\,k$：每把截断点乘十，面积就固定多出 $2.302585$。这正是对数增长的图像——无限延伸，但每一段增量越来越不值钱。而 $\int_1^c x^{-2}$ 在 $c = 10^k$ 时只差 $10^{-k}$，几乎已经到顶。
>
> > 这条分界线有个名字，叫 p-test（p-判别法）：$\int_1^\infty x^{-p}\,dx$ 收敛当且仅当 $p > 1$。级数那边的判据一模一样：$\sum n^{-p}$ 收敛当且仅当 $p > 1$。两者相同的理由就是上面那段阶梯比较——积分与级数只差一个常数因子，收敛性同生同死。
>
> > 与级数对照更能记住这个分界。$\sum_{n=1}^{1000} 1/n^2 = 1.643935$（趋近 $\pi^2/6 = 1.644934$），而 $\sum_{n=1}^{1000} 1/n = 7.485471$，与 $\log 1000 + \gamma = 7.484971$ 只差 $0.0005$（$\gamma$ 是欧拉常数，python 复算）。调和级数的部分和几乎就是对数，这条经验在算法分析里天天用。
>
> 再往深处一点，这套对应并非处处等号。$\sum 1/n$ 与 $\int_1^\infty dx/x$ 同时发散，$\sum 1/n^2$ 与 $\int_1^\infty dx/x^2$ 同时收敛，是因为幂律函数性质规整；换成 $\sum 1/(n\log n)$ 就要小心，它与 $\int_2^\infty dx/(x\log x)$ 都要单独算，而这条积分又是发散的（原函数是 $\log\log x$）。所以「积分与级数平行」是找思路的地图，不是可以盲抄的公式。
>
> > 跨课程连接：CLRS 里增长率的分级与此完全平行：常数、$\log n$、$n$、$n^2$ 的排序决定了算法能不能用。$\log n$ 在算法里是「好」的，因为它增长极慢；可在这里，$\log c$ 却代表发散——同一函数，不同角色：算法里比的是操作次数随规模增长，这里比的是面积随截断点增长。开窍的一点是：判断发散不需要具体数值，只需要知道增长的量级有没有上界。
>
> 收束：例 2 与例 3 的差别不在函数值的大小（都趋于零），而在原函数的形状——有界还是无界，这是之后的判断标准。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 4（例 4）</span>

在 $(0, 1]$ 上设 $f(x) = \frac{1}{\sqrt{x}}$（当 $x \to 0$ 时函数无界），则对 $c > 0$，

```math
\int_c^1 \frac{1}{\sqrt{x}}\,dx = \bigl[\,2\sqrt{x}\,\bigr]_c^1 = 2 - 2\sqrt{c} .
```

由于 $2 - 2\sqrt{c} \to 2$（当 $c \to 0$），反常积分存在且等于

```math
\int_0^1 \frac{dx}{\sqrt{x}} = 2 .
```

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 5（例 5）</span>

在 $(0, 1]$ 上设 $f(x) = \frac{1}{x}$，则

```math
\int_c^1 \frac{1}{x}\,dx = \bigl[\log x\bigr]_c^1 = -\log c .
```

注意 $-\log c \to \infty$（当 $c \to 0$），所以反常积分

```math
\int_0^1 \frac{dx}{x}
```

不存在。

> <span style="color:#1e8449;">**[note] Note（译者注，直觉颠覆）:**</span> 例 4 是「无界函数也能有有限积分」的示范。函数在 $0$ 附近 blow up（爆炸），但图形下的面积仍然有限：🎥 *Colding*："It's blowing up. It's going to infinity. But the area below the graph-- that's where we calculated-- is still actually finite."（翻译：它在爆炸，趋于无穷；但图形下的面积，我们刚算过，其实仍然是有限的。）Colding 接着问的反面正是自然的下一步：那如果炸得更快呢？🎥 *Colding*："But what if the function is blowing up faster than this?"（翻译：可要是函数爆得比这更快呢？）
>
> 例 5 给出答案：$\frac{1}{x}$ 在 $0$ 附近比 $\frac{1}{\sqrt{x}}$ 爆得猛，积分就发散。判断的关键照旧是原函数在奇点处的行为：$\frac{1}{\sqrt{x}}$ 的原函数 $2\sqrt{x}$ 在 $0$ 处有极限 $0$，于是 $\int_c^1 = 2 - 2\sqrt{c}$ 收敛到 2；$\frac{1}{x}$ 的原函数 $\log x$ 在 $0$ 处跑到负无穷，于是 $-\log c$ 发散。
>
> 数字上看得清。$\int_c^1 x^{-1/2}\,dx = 2 - 2\sqrt{c}$：$c = 10^{-2}$ 得 $1.8$，$c = 10^{-4}$ 得 $1.98$，$c = 10^{-6}$ 得 $1.998$（python 复算），稳稳爬向 2。对照 $\int_c^1 x^{-1}\,dx = -\log c$：$c = 10^{-2}$ 得 $4.605170$，$c = 10^{-4}$ 得 $9.210340$——每把 $c$ 缩小一百倍，就多 $4.605170$，永不收敛。
>
> 机制上，「无界却有有限面积」并不神秘：面积是两个方向的乘积，高度可以无穷，但只要宽度收缩得更快，乘积就被压住。$\sqrt{c}$ 的收缩速度远快于 $c$，所以 $\frac{1}{\sqrt{x}}$ 那点「高」很快就只落在极窄的一条上。用一般指数说更清楚：$\int_c^1 x^{-p}\,dx$ 在 $p < 1$ 时收敛，$p \ge 1$ 时发散；$p = \frac{1}{2}$ 是收敛的一侧，$p = 1$ 刚好落在临界线上。
>
> 补一条常被忽略的操作细节：奇点在区间内部时，必须把它拆成两段、各自取极限，两段都收敛才算收敛。比如 $\int_{-1}^{1} dx/x$，左右两段一个是 $-\infty$、一个是 $+\infty$，并不存在；若强行对称地取极限，会得到 0，那个数叫 Cauchy principal value（柯西主值），它和积分存在不是一回事。判断时先看有没有奇点、奇点在哪，再决定要不要拆。
>
> > 把四个例题并排看，本节的结构就出来了。例 2 与例 3 变的是区间（向右无限延伸），例 4 与例 5 变的是函数（在端点无限升高）；两组里都是「慢的失败、快的成功」。所以收敛与否取决于无穷被压制的速度，而不取决于无穷是否存在——区间可以无限长，函数可以无限高，只要速度够快，面积依然有限。
>
> 另外别把「无界」与「不可积」混为一谈。$\frac{1}{\sqrt{x}}$ 在 $0$ 附近无界，但它限制到任何 $[c, 1]$（$c > 0$）上都有界、都黎曼可积，所以反常积分有资格定义；真正不能定义的是那种在每一小段上都无界的病态情形。这里的假设是「对一切 $c > a$，$f \in \mathcal{R}([c, b])$」，这句话就是给定义发的通行证。
>
> > 跨课程连接：Probability（概率论）里这种「密度无界、总质量有限」的情形到处都是。取 $f(x) = \frac{1}{2\sqrt{x}}$ 在 $(0, 1]$ 上，它在 $0$ 处无界，但 $\int_0^1 f = 1$（python 复算），于是它是一个合法的 probability density（概率密度），对应的期望 $\int_0^1 x f(x)\,dx = 1/3$ 也存在。换成 $1/x$ 就归一化不了，任何分布都无法以它为密度。区别在于：概率论还要求非负与总质量为 1，而积分本身只关心面积是否有限。
>
> 收束：这一节真正要带走的是那条判据——先找原函数，再看它在奇点有没有极限；「无穷」本身不是敌人，速度才是。四个例题看似四道题，其实是同一句话的四种写法。
>
> 把这条判据推到一般形式：一除以 x 的 p 次方在零到一上的积分，p 小于一时收敛、p 大于等于一时发散，p 恰好等于一就是临界点。同一条一除以 x 在两个奇点上的命运刚好相反——往无穷远处走要求衰减足够快，往零走近则要求发散别太猛。所以判据必须写成原函数在奇点处有没有有限极限，而不能只写函数在奇点附近有没有界。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Question: How do we define angle?（问题：我们如何定义角？）</span>

问题：我们如何定义 angle（角）？回答：我们通过弧长来定义它。

在单位圆

```math
\{(x, y) \mid x^2 + y^2 = 1\}
```

上，我们同时定义角与弧长。也就是说，设 $(x, y)$ 位于单位圆上，则 $(1, 0)$ 与 $(x, y)$ 之间的角 $\theta$ 定义为单位圆上从 $(1, 0)$ 到 $(x, y)$ 那一段的弧长。这一段圆弧被

```math
(f(s), g(s)) = (s, \sqrt{1 - s^2})
```

参数化，其中 $x \le s \le 1$。由于 $f'(s) = 1$ 且 $g'(s) = -\frac{s}{\sqrt{1 - s^2}}$，我们得到

```math
\theta = \int_x^1 \sqrt{1 + \frac{s^2}{1 - s^2}}\;ds = \int_x^1 \frac{1}{\sqrt{1 - s^2}}\,ds .
```

于是函数 $\arcsin x$ 定义为

```math
\arcsin x = \int_0^x \frac{1}{\sqrt{1 - s^2}}\,ds .
```

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理）:**</span> 最后一页回答一个平时不会追问的问题：角到底是什么？答案是——角就是弧长，而且这个「是」是定义。在单位圆上，把 $(1, 0)$ 与 $(x, y)$ 之间的角 $\theta$ 定义为单位圆上这两点之间那一段的 arclength（弧长）。这句话把「角」这个几何概念换成了刚讲的积分，于是角度有了可计算的表达式。
>
> 把计算走一遍。单位圆可以被参数化成 $(f(s), g(s)) = (s, \sqrt{1 - s^2})$，其中 $s = \cos\theta$ 从小到大跑；从 $(x, y)$ 到 $(1, 0)$ 那一段对应 $s \in [x, 1]$。$f'(s) = 1$，$g'(s) = -s/\sqrt{1 - s^2}$，于是 $\sqrt{f'(s)^2 + g'(s)^2} = \sqrt{1 + s^2/(1 - s^2)} = 1/\sqrt{1 - s^2}$。所以 $\theta = \int_x^1 \frac{1}{\sqrt{1 - s^2}}\,ds$，这就是 $\arcsin$ 的积分写法：$\arcsin x = \int_0^x \frac{1}{\sqrt{1 - s^2}}\,ds$。
>
> 验证一个具体角度。取 $x = 0.5$，对应点 $(0.5, \sqrt{3}/2) \approx (0.5, 0.8660254)$。用对称性：$\int_0^{0.5} \frac{ds}{\sqrt{1 - s^2}} = 0.5235988$（python 数值积分），正是 $\pi/6 = 0.5235988$；而 $\int_{0.5}^{1}$ 那一段等于整段 $\pi/2$ 减去 $\pi/6$，得 $\pi/3 = 1.0471976$，也就是 $60$ 度。数值与几何完全对上，说明这个定义没有把「角」弄歪。
>
> 顺带说一句这个积分在端点的行为，它和上一节是同一件事。$\int_0^x \frac{ds}{\sqrt{1 - s^2}}$ 在 $x \to 1^-$ 时被积函数爆炸，但积分收敛到 $\pi/2$——因为 $1/\sqrt{1 - s}$ 在 $s = 1$ 附近是指数 $p = 1/2$ 的幂律奇点，落在收敛的一侧。也就是说，「四分之一圆弧长等于 $\pi/2$」这个常识，本身就是一个反常积分收敛的实例。
>
> 为什么这件事值得专门强调？因为常规讲法里存在一个循环：先用角定义 $\sin$ 与 $\cos$，而「角」又悄悄依赖某种长度度量（量角器、单位圆的弧）。这套定义把依赖方向反过来：先用积分锚定 $\arcsin$，再由 $\sin(\arcsin x) = x$ 把正弦函数恢复出来，逻辑链条上没有环。这也是为什么分析学偏爱「积分定义函数」——它把几何直觉变成可验证的对象。
>
> 同样的手法你已经见过一次：$\log x = \int_1^x \frac{ds}{s}$。对数不再靠「$e$ 的幂」定义，而是先由积分造出一个函数，再证明它就是那个满足 $\log(xy) = \log x + \log y$ 的对象；本讲例 3 用的原函数正是它。指数函数则作为它的反函数出场。弧长定义角、积分定义对数，两者是同一姿势的两次使用。
>
> 一个容易踩的坑：这里所有的角度都用弧度，因为只有弧度制下弧长与角在数值上相等。若换成角度制，$\theta$ 与弧长之间要乘一个 $180/\pi$ 的因子，公式立刻变脏；弧度制的全部价值就是把这个因子设成 1。
>
> 跨课程连接：数值库里的 $\arcsin$ 不会去算这个积分。C 标准库的 asin 通常用有理函数逼近（分段的多项式与倒数组合，按区间查系数），再靠对称性把参数折到 $[0, 0.5]$ 上；它追求的是几个 ulp 的精度与有限步数。而这里的定义追求的是逻辑无环与可证明性。区别在于：定义告诉你这个函数是什么，实现告诉你怎样在有限精度下把它算出来；两者必须一致，但责任不同。Strang 那边还有第三条路——用幂级数定义 $\sin$ 与 $\cos$，再证明它与几何定义一致。
>
> 收束：本讲从「哪些函数可积」出发，经四条基本性质、微积分基本定理的两版、反常积分，最后落在「用积分定义几何量」上。角就是弧长这句话，把整讲的工具一次性用掉了：可积性判定、FTC 计算、弧长公式。
