### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Recall: The Taylor expansion theorem（回顾：泰勒展开定理）</span>

回忆一下，上一讲我们证明了 Taylor expansion theorem（泰勒展开定理）：

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem: Taylor expansion（泰勒展开定理）</span>

设 $f : [a, b] \to \mathbb{R}$ 是一个函数，$k$ 是正整数。假设 $f, f', f^{(2)}, \cdots, f^{(k-1)}$ 在 $[a, b]$ 上存在且连续，而 $f^{(k)}$ 在 $(a, b)$ 上有定义，则存在介于 $a$ 与 $b$ 之间的 $c$ 使得

```math
f(b) = f(a) + f'(a) (b - a) + \frac{f^{(2)}(a)}{2} (b - a)^2 + \cdots + \frac{f^{(k-1)}(a)}{(k - 1)!} (b - a)^{k-1} + \frac{f^{(k)}(c)}{k!} (b - a)^k .
```

> <span style="color:#7f8c8d;">TBB Theorem 7.43 (Lagrange 余项形式), §7.12 Taylor Polynomials, p.320（该节自 p.319 起）</span>

对 $\mathbb{R}$ 上 infinitely differentiable（无穷次可导）的函数 $f$，我们把它在 $a$ 处的 $(k-1)$ 阶 Taylor polynomial（泰勒多项式）定义为

```math
P_{k-1}(x) = f(a) + f'(a) (x - a) + \frac{f^{(2)}(a)}{2} (x - a)^2 + \cdots + \frac{f^{(k-1)}(a)}{(k - 1)!} (x - a)^{k-1} .
```

> <span style="color:#7f8c8d;">TBB §7.12, p.319–321（TBB 记 $P_n$ 为 nth Taylor polynomial，并指出它是泰勒级数的第 $n$ 个部分和）</span>

<span style="color:#2471a3;">**[question]**</span> <span style="color:#c0392b">**Question（问题）.**</span> 很自然会问：当 $x$ 靠近 $a$ 时，这个多项式把 $f$ 逼近（approximate）得有多好？

<span style="color:#2471a3;">**[answer]**</span> <span style="color:#c0392b">**Answer（回答）.**</span> 这取决于 remainder（余项）

```math
R_k(x) = \frac{f^{(k)}(c)}{k!} (x - a)^k
```

的值。

> <span style="color:#1e8449;">**[note] Note（译者注，视频与讲义的顺序差）:**</span> 这条注要回答一个很实际的困惑：对着视频读讲义时，两边的顺序完全接不上。视频是"还债式"推进的——先把上一讲欠下的两个 mean value theorem（中值定理）回忆完，再用 Cauchy mean value theorem（柯西中值定理）去证 L'Hôpital's rule（洛必达法则），最后才回到泰勒展开；讲义则按主题归档，第一句就是 Taylor expansion theorem（泰勒展开定理）的回顾。这个差别不是剪辑的随意安排，而是一条真实的依赖链。
>
> 先看依赖链。Colding 的开场原话是：🎥 *Colding*："The second thing I want to talk about is something we didn't get to last time. And these are these-- L'Hopital's rule."（翻译：第二件我想谈的事，是我们上次没来得及讲的内容——也就是洛必达法则。）他当堂只讲一个版本：🎥 *Colding*："There are two versions, and they're both in the notes, but I will just state one of them."（翻译：有两个版本，它们都在讲义里，但我只陈述其中一个。）之所以只能"顺手讲"，是因为 L'Hôpital's rule（洛必达法则）的证明本身就是 Cauchy mean value theorem（柯西中值定理）的一次直接套用：取 $a < y < x$，在闭区间 $[y, x]$ 上套用，得到 $x_0 \in (y, x)$ 使 $f'(x_0)\left(g(x)-g(y)\right) = g'(x_0)\left(f(x)-f(y)\right)$；固定 $x$、让 $y \to a$，因为 $g(x) \neq 0$ 而 $g(y) \to 0$，两边可以除，比值就变成 $\frac{f(x)-f(y)}{g(x)-g(y)}$，再让 $y \to a$ 就落到 $\frac{f(x)}{g(x)}$。整套证明唯一的"活口"是这个 $x_0$：你只知道它夹在 $y$ 与 $x$ 之间，随 $y \to a$ 一起被挤向 $a$，因此 $\frac{f'(x_0)}{g'(x_0)}$ 最终落在 $L$ 的 $\varepsilon$ 邻域里。
>
> 这个"存在但不可定位"的结构，正是泰勒余项的同一个结构。Colding 把它点破：🎥 *Colding*："the catch is, that you don't really know what c is. The only thing you know about c is that c is lying between a and x."（翻译：麻烦在于，你并不知道 $c$ 是什么——关于 $c$ 你唯一知道的就是它介于 $a$ 与 $x$ 之间。）于是整个前半讲的问题意识就统一了：中值定理、洛必达、泰勒余项，三者共用同一个"夹住未知点、只取其界"的手法，区别只是夹出来的东西不同——前者夹出导数值，后者夹出高阶导数。
>
> 具体算一遍就明白这个"只取其界"有多实用。取 $f(x) = e^x$、$a = 0$、$x = 1$、$k = 3$，则 $P_2(1) = 1 + 1 + \frac{1}{2} = 2.5$，而 $e - 2.5 = 0.21828$。余项形如 $\frac{e^{c}}{3!}$，由 $c \in (0, 1)$ 得它必然落在 $\frac{1}{6} = 0.16667$ 与 $\frac{e}{6} = 0.45305$ 之间——0.21828 确实在里面。反解 $\frac{e^{c}}{6} = 0.21828$ 得 $c \approx 0.2698$，但请注意：这个 $c$ 是事后算出来的，定理本身给不了它。定理给的只有那个区间，而区间已经足够把误差压成一个可用的数。
>
> 跨课程连接可以落在 CSAPP 第 6 章 cache（高速缓存）。那一章分析 cache（高速缓存）性能时，miss rate（缺失率）是个统计量，你永远拿不到"这一次访问到底命中没有"的确定性，工程上的做法就是拿最坏情况或期望值做界，再据此设计。两条路径的形状完全一样：未知量不可定位，于是退而求其次，只保留一个可证的上界。区别在于界的来源——cache（高速缓存）的界来自程序访问模式的可测统计，必须跑基准测试才拿得到；这里的界来自 $|f^{(k)}|$ 在区间上的 sup（上确界），是纯分析的，不需要测量，也不需要样本。
>
> 所以顺序差本身不重要，重要的是它暴露的骨架：本讲前半段的全部工具都建立在"存在性 + 夹逼"之上，而不是建立在"算出那个点"之上。看清这一点，后面两个例子（一个成功、一个彻底失灵）就不再是零散技巧，而是同一手法在不同函数上的两种命运。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Two examples（两个例子）</span>

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1: The exponential function（例 1：指数函数）</span>

设 $f(x) = e^x$，则对一切 $k$ 都有 $f^{(k)}(x) = f(x)$。这意味着在 $a = 0$ 附近的泰勒展开变为

```math
P_{k-1}(x) = \sum_{i=0}^{k-1} \frac{x^i}{i!} .
```

由泰勒展开定理我们有

```math
f(x) = P_{k-1}(x) + \frac{f^{(k)}(c)}{k!} x^k .
```

由于对一切 $k$ 都有 $f^{(k)}(x) = f(x)$，由泰勒展开定理可得

```math
|f(x) - P_{k-1}(x)| \le \frac{e^{|x|}}{k!} .
```

我们得出结论：当 $k$ 很大时，多项式 $P_{k-1}$ 给出 $f$ 的相当好的逼近。例如，若 $|x| \le 1$，则我们有

```math
|f(x) - P_{k-1}(x)| \le \frac{e}{k!} .
```

> <span style="color:#1e8449;">**[note] Note（译者注，跨讲连接与"好的那一个"）:**</span> 例 1 之所以"好"，不是因为它简单，而是因为它把余项里那个不可定位的 $c$ 彻底无害化了：对 $f(x) = e^x$ 有 $f^{(k)} = f$，于是 $|f^{(k)}(c)| = e^{c}$，而 $c$ 被夹在 $0$ 与 $x$ 之间，所以 $e^{c} \le e^{|x|}$。这一步只用到 $e^t$ 的单调性，就把一个未知点换成了一个已知常数。
>
> 机制展开成一句话：误差 $= \frac{|f^{(k)}(c)|}{k!}|x|^{k}$ 是两个因子的乘积，一个被 $e^{|x|}$ 封顶，另一个被阶乘压向零。前者是"函数本身有多狂野"，后者是"多项式阶数能压多狠"。两个因子独立地起作用，这正是泰勒逼近可以预期的原因：只要高阶导数不失控，剩下的全交给阶乘。
>
> 算一下量级。在 $|x| \le 1$ 时余项不超过 $\frac{e}{k!}$：$k = 4$ 时是 $0.11326$，$k = 8$ 时是 $6.74 \times 10^{-5}$，$k = 10$ 时是 $7.49 \times 10^{-7}$，$k = 12$ 时是 $5.67 \times 10^{-9}$。也就是说每加两阶，小数点后多三四位。Colding 在课上对这个速度有个生动的自我更正：🎥 *Colding*："I mean, you don't even need to make k very large because it's exponential."（翻译：我的意思是，你甚至不需要让 $k$ 很大，因为它是指数级的。）紧接着他改口：🎥 *Colding*："Not exponential, it's factorial."（翻译：不是指数级的，是阶乘级的。）这个更正值得记住：$2^{20} = 1048576$，而 $20! = 2432902008176640000$，后者是前者的 $2.3 \times 10^{12}$ 倍；混淆 exponential（指数）与 factorial（阶乘）会把收敛速度低估十几个数量级。
>
> 但"好"有个前提，就是靠近展开点。Colding 提醒：🎥 *Colding*："So it's really-- like the Taylor polynomial, it's only a good approximation near a."（翻译：所以它其实就像泰勒多项式那样，只在 $a$ 附近才是好的逼近。）原因是几何的：余项含因子 $(x-a)^{k}$，当 $|x-a| < 1$ 时这个因子随 $k$ 衰减，一旦 $|x-a| > 1$ 它反而指数增长，阶乘也救不回来。课堂上学生追问能否反过来问"给定误差预算，能走多远"，他的回答把这个局部性质翻译成了一个可解的问题：固定 $k$、给定 $\varepsilon$，要求 $\frac{e^{|x|}}{k!}|x|^{k} < \varepsilon$，解出最大的 $|x|$。他还强调了必须做的事：🎥 *Colding*："You have to eliminate c because you don't know anything really about c."（翻译：你必须把 $c$ 消掉，因为你其实对 $c$ 一无所知。）"消掉"的准确含义是把 $c$ 换成它的上界，于是不等式里只剩下一个变量。
>
> 跨课程连接：机器上算 $e^{x}$ 的库函数走的就是这条多项式逼近的路子，而不是查表或迭代。区别在于一旦进入工业实现，目标函数就换了——不是"在 $a$ 处各阶导数都对上"，而是"把区间上的最大误差压到最低"。这两个目标不等价：Taylor polynomial（泰勒多项式）在 $a$ 处误差为零，误差却全部堆在区间远端；minimax（极小极大）多项式牺牲展开点附近的精度，换取误差在整段上均匀摊开，同阶数下最大误差更小。这就是为什么 `libm` 里的实现不直接读泰勒系数，也是第一性原理层面"公式正确不等于数值正确"的最小范例。再叠加你在 CSAPP 第 2 章学过的 floating-point（浮点数）表示，也就是 binary32（单精度） 与 binary64（双精度） 这两种格式，误差还得按 ulp（末位单位）折算，于是"用多少阶多项式"就变成"多少条指令、多少 ulp"的工程权衡。这里的换算关系值得记住：binary32（单精度） 的有效位数是 24 位，相对精度约 $6 \times 10^{-8}$，所以把余项压到 $10^{-8}$ 以下对本格式毫无意义，纯属白算。
>
> 回到正文：例 1 的价值不在于证明了 $\sum \frac{x^{i}}{i!}$ 收敛到 $e^{x}$，而在于示范了"如何把不可定位的 $c$ 换成可计算的上界"。下一节的例 2 会给出一个连这一步都做不到的函数，两者的对照才是本节真正的主题。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 2: A function equal to its remainder（例 2：一个等于自己余项的函数）</span>

在 $\mathbb{R}$ 上定义函数 $f$ 为

```math
f(x) = \begin{cases} 0 & \text{if } x \le 0 \\ e^{-\frac{1}{x^2}} & \text{otherwise} \end{cases}
```

容易看出 $f$ 是无穷次可导的，且对一切 $k$ 都有 $f^{(k)}(0) = 0$。于是对一切 $k$，在 $0$ 处的泰勒多项式都满足 $P_{k-1} \equiv 0$。因此在这个情形下 $f(x) = R_k(x)$。

> <span style="color:#1e8449;">**[note] Note（译者注，直觉颠覆：泰勒多项式可以完全失灵）:**</span> 例 2 与例 1 是刻意配对的：同一个定理、同一套余项估计，结果却从"极好"跌到"完全无用"。差别不在定理，而在函数自身的高阶导数在展开点附近的行为。
>
> 先把"所有导数在 $0$ 处为零"这件事的机制说清，否则它看起来像数学系的恶作剧。当 $x > 0$ 时，对 $f(x) = e^{-\frac{1}{x^{2}}}$ 求导，每次都会产生两类因子：一类是 $\frac{1}{x}$ 的多项式（求导一次多一个负幂次），另一类是 $e^{-\frac{1}{x^{2}}}$ 本身。也就是说 $f^{(k)}(x) = p_k\!\left(\frac{1}{x}\right)e^{-\frac{1}{x^{2}}}$，其中 $p_k$ 是某个多项式。关键在第二类因子：$e^{-\frac{1}{x^{2}}}$ 趋于零的速度快过任何幂函数，即对每个 $n$ 都有 $\frac{e^{-\frac{1}{x^{2}}}}{x^{n}} \to 0$（$x \to 0^{+}$）。指数衰减压过代数增长，于是多项式因子无论多凶都被吃掉，每一阶导数在 $0$ 处都只能取 $0$。
>
> 数字能把这个"快"量出来：$f(1) = 0.36788$，$f(0.5) = 0.01832$，$f(0.1) = 3.72 \times 10^{-44}$，$f(0.05) = 1.92 \times 10^{-174}$。而一阶导数 $f'(x) = \frac{2}{x^{3}}e^{-\frac{1}{x^{2}}}$ 在 $x = 0.1$ 处只有 $7.44 \times 10^{-41}$。可见不是"导数为零"这种代数巧合，而是函数在 $0$ 附近平坦到任何有限阶都察觉不到它已经离开 $0$。
>
> 后果是决定性的：泰勒系数全是 $\frac{f^{(k)}(0)}{k!} = 0$。Colding 的原话：🎥 *Colding*："all of the coefficients in the polynomial are 0."（翻译：多项式中所有系数都是 $0$。）他接着说：🎥 *Colding*："So this polynomial is just 0."（翻译：所以这个多项式就是 $0$。）于是 $P_{k-1} \equiv 0$，泰勒展开定理退化成一句废话：$f(x) = 0 + R_k(x)$，也就是 $f$ 与它自己的 remainder（余项）相等，误差等于函数值本身，阶数再高也不缩小。他的评价是：🎥 *Colding*："the Taylor polynomial is too trivial. It doesn't really help you all that much."（翻译：这个泰勒多项式太平凡了，帮不上你什么忙。）
>
> 这个反例划出了一条必须记住的分界线：infinitely differentiable（无穷次可导）弱于 analytic（解析）。所谓 analytic（解析），指的是在每个点附近都能用收敛到函数本身的泰勒级数表示；本例的泰勒级数处处收敛，但收敛到常数 $0$，只在 $x \le 0$ 的半边与函数重合。所以"光滑"（各阶导数存在且连续）与"能被幂级数表示"是两个不同强度的条件，前者的名字听着更强，实际上更弱——这正是历史上把"解析函数"单列一类的动机。
>
> 跨课程连接放在 floating-point（浮点数）表示上，即 CSAPP 第 2 章。binary32（单精度） 的最小 subnormal（次正规数）约 $1.4 \times 10^{-45}$，而 $f(0.05) = 1.92 \times 10^{-174}$ 在这个格式下直接下溢成 $0.0$。于是在 binary32（单精度） 里，"泰勒多项式 $\equiv 0$"与真函数在整段 $[0, 0.05]$ 上完全无法区分——分析学上那个触目惊心的反例，到了硬件上表现为"看不出差别"。区别必须说清：分析的结论是数学事实（级数收敛到 $0$ 而不收敛到 $f$），浮点的结论是表示精度的下限把差异吞掉了（是格式的 artifact，即人为产物的性质）；两者指向同一个教训——"数值上相等"永远需要先问"在什么精度下"。
>
> 顺带一句构造性的意义：正因为这类函数在 $0$ 处无限平坦，它才能把"从 $0$ 平滑地升起来"这件事做到各阶导数都连续，成为光滑截断函数的原型；凡是需要"只在局部起作用、其余处严格为零且足够光滑"的场合，都得靠这种平坦性。回到正文：例 1 与例 2 一起说明，泰勒逼近的质量是函数的属性，不是定理的承诺。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Riemann integrals（黎曼积分）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理：从矩形出发）:**</span> 这一节是本讲第二 half（半场）的开场，主题从"逼近一个函数"换成"定义一块面积"。Colding 先划定了选择空间：🎥 *Colding*："And there are different ways of defining integrals. This here is-- this is certainly one of the-- maybe the most natural ones."（翻译：定义积分有若干种不同的方式；这里这一种肯定是其中之一——也许是最自然的那个。）讲义前几节走的是 Cauchy（柯西）的两条老路，本节换成以 Riemann（黎曼）命名的那条：先把区间切碎，再在每一小块上用矩形顶替函数。
>
> 为什么必须从矩形出发？因为"面积"这个词在此之前并没有被定义过。你想定义一个图形的面积，就必须把它归结为某个已经能计算的量，否则就是循环定义。Colding 把这一点说得极干脆：🎥 *Colding*："if this length here is-- let's call it d, and this here is e, then you know that the area here-- so area-- is d times e. That's the only thing we have."（翻译：如果这段长度是——就叫它 $d$ 吧——这段是 $e$，那么你就知道这里的面积——也就是面积——是 $d$ 乘 $e$。这是我们唯一拥有的东西。）于是整个构造的逻辑链条变成三步：先用 partition（分割）把 $[a, b]$ 切成有限多段；每一段上放一个矩形；再用 sup（上确界）与 inf（下确界）把"矩形顶替"这件事变成可以夹逼的上下界。
>
> 第三步是全部智慧所在。如果只放一个矩形去"近似"，你永远说不出近似有多差；但若同时放两个——一个从外面罩住图像（高度取该段上的 sup（上确界）），一个从里面垫住图像（高度取 inf（下确界））——误差就被夹在两个可计算的数之间。这不是为了精确，而是为了把"我不知道差多少"改写成"我知道差不超过某个数"。若函数穿过 $x$ 轴，还要加符号约定，否则"面积"会算错正负：🎥 *Colding*："then this area here would count negatively and this area here would count positively."（翻译：那么这边的面积按负的计，那边的面积按正的计。）
>
> 手算一遍，量级立刻清楚。取 $f(x) = x$ 在 $[0, 1]$ 上，用 $n = 4$ 的等距 partition（分割）：每段长 $\frac{1}{4}$，上矩形高度依次是 $\frac{1}{4}, \frac{1}{2}, \frac{3}{4}, 1$，于是 $U(f, P) = \left(\frac{1}{4}+\frac{1}{2}+\frac{3}{4}+1\right)\cdot\frac{1}{4} = 0.625$；下矩形高度依次是 $0, \frac{1}{4}, \frac{1}{2}, \frac{3}{4}$，于是 $L(f, P) = 0.375$。真值是 $0.5$，恰好被夹在中间。更妙的是把 $n$ 等分的一般情形算出来：$U - L = \frac{1}{n}$——上和的误差全部来自"每段差一个格子高"，加起来正好是整个区间长度乘段宽。这个 $\frac{1}{n}$ 会在后面反复出现，它是"分割越细、窗口越窄"的最简样本。
>
> 跨课程连接放在 CLRS 里讲过的 divide and conquer（分治）。工业数值库里的 adaptive quadrature（自适应求积）就是这条思路的工程版：把区间劈成两半，分别估一次，再和整段的粗估比较，差值超过误差预算就继续劈下去。这与归并排序的递归树形状完全一致——都是"劈开、各自求解、合并"。区别在两处：其一，分治的合并是把结果加起来，成本 $O(n)$；这里合并要做的是 sup（上确界）与 inf（下确界）的再估计，成本取决于你愿意把函数采样多少次。其二，分治的终止条件是子问题规模降到 1；这里的终止条件是全局的 $U - L$ 掉到 $\varepsilon$ 以下，而 $\varepsilon$ 是外部给的精度要求，不是数据结构的内在属性。
>
> 收束一句：你在微积分课上背了很久的 $\int_{a}^{b} f\,dx$，直到这一刻才第一次拥有定义——而定义的全部内容，就是"用矩形夹、用分割逼"。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Partition（分割）</span>

设 $[a, b]$ 是一个区间。区间 $[a, b]$ 的一个 partition（分割）$P$ 是若干 sub-division（细分点）$x_i$，使得

```math
a = x_0 < x_1 < x_2 < \cdots < x_n = b .
```

这个分割就是那些 sub-interval（子区间）$[x_{i-1}, x_i]$。我们记 $\Delta x_i = x_i - x_{i-1}$。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Upper and lower sums（上和与下和）</span>

现在设 $f : [a, b] \to \mathbb{R}$ 是一个 bounded function（有界函数），且 $P = \{x_i\}$ 是区间 $[a, b]$ 的一个分割。我们如下定义上和与下和。令

```math
M_i = \sup_{[x_{i-1}, x_i]} f ,
```

```math
m_i = \inf_{[x_{i-1}, x_i]} f ,
```

并定义 upper sum（上和）$U(f, P)$ 与 lower sum（下和）$L(f, P)$ 为

```math
U(f, P) = \sum_{i=1}^{n} M_i \, \Delta x_i ,
```

```math
L(f, P) = \sum_{i=1}^{n} m_i \, \Delta x_i .
```

> <span style="color:#7f8c8d;">TBB Exercise 8.2.17, p.338（上/下和在 TBB 中以习题形式引入：$M(f, \dot{\mathcal{P}})$、$m(f, \dot{\mathcal{P}})$）；Darboux 积分视角见 TBB Exercise 8.10.1, §8.10, p.363</span>

> <span style="color:#1e8449;">**[note] Note（译者注，几何图像）:**</span> 上和与下和的几何含义只有一句话：$M_i \Delta x_i$ 是能罩住图像的最小矩形，$m_i \Delta x_i$ 是能塞进图像下方的最大矩形。但"最小"与"最大"这两个词用得不严谨，准确的措辞是"以该段长度为底、高度恰为 sup（上确界）或 inf（下确界）的矩形"，因为严格说来矩形不"罩住"任何东西，是它的高决定了覆盖关系。Colding 画图时的说法更直白：🎥 *Colding*："And you try to look at the smallest right angle that kind of have the graph that fits-- where the graph fits inside that."（翻译：你试着去找那个能把图像装进去的最小矩形——就是图像落在它内部的那个。）
>
> 为什么定义里用 sup（上确界）与 inf（下确界），而不用 max（最大值）与 min（最小值）？这不是形式上的讲究，而是能否定义的分界线。取 $[0, 1]$ 上的函数 $f(x) = x$（当 $x < 1$）与 $f(1) = 0$，它有界，但整段上的最大值为不到 $1$：任何 $x < 1$ 都小于 $1$，而 $1$ 只在极限处被逼近。这时 max（最大值）不存在，sup（上确界）仍然是 $1$。如果定义写成 max（最大值），这个函数在第一段上就没有对应的矩形，整套上和的记法立刻失效；写成 sup（上确界），定义对一切有界函数都成立。这正是"上界中最小的那个"这个说法的价值：它不要求被逼近的目标真的被取到。
>
> 第二个必需的条件是 bounded（有界）。若无界，sup（上确界）可能取 $+\infty$，$M_i \Delta x_i$ 就不是实数，和也没有意义。所以本讲的每一处定义都先把"有界"写进前提，这不是作者谨慎，而是构造的地基——没有上界，就没有"最小上界"可选。
>
> 把例 3 的数字复核一遍，几何图像会变得很具体。$f(x) = x^{2}+1$ 在 $[-2, 2]$ 上，partition（分割）由 $-2, -1, 0, 1, 2$ 这五个分点组成，四段等长、每段 $\Delta x_i = 1$。第一段 $[-2, -1]$ 上函数递减，于是 $M_1 = f(-2) = 5$、$m_1 = f(-1) = 2$；第二段 $[-1, 0]$ 上递减，$M_2 = 2$、$m_2 = 1$；第三段 $[0, 1]$ 上递增，$M_3 = 2$、$m_3 = 1$；第四段 $[1, 2]$ 上递增，$M_4 = 5$、$m_4 = 2$。于是 $L(f, P) = 2+1+1+2 = 6$、$U(f, P) = 5+2+2+5 = 14$。真值是 $\int_{-2}^{2}(x^{2}+1)\,dx = \frac{28}{3} \approx 9.3333$，确实落在 $6$ 与 $14$ 之间——上下界都错得很厉害，但错的方向是明确的：一个偏小、一个偏大。
>
> 跨课程连接放在 6.042J 的偏序集。那里讲过 least upper bound（最小上界）与 join（上确界）的概念：在偏序集里，两个元素的 join 是最小的上界，但 join 未必存在。这里的 sup（上确界）就是同一件事在 $(\mathbb{R}, \le)$ 上的特例。区别在于存在性由谁保证：一般偏序集里 join 可能根本没有，所以那门课要专门讨论lattice（格）；而 $\mathbb{R}$ 的完备性公理保证了任何非空有上界的子集都有 sup（上确界），于是"有界"这一个条件就足以让上下和处处有定义。可以说，本讲把 6.042J 里一个"有时存在"的抽象概念，换到了一个"只要非空有界就一定存在"的具体空间里使用。
>
> 还有一点容易被忽略：定义中对"每段取一个矩形"没有任何限制，矩形的底就是该子区间本身，高由 sup（上确界）与 inf（下确界）决定，所以同一个分割给出的上下和是唯一确定的两个数，不依赖你画图时的手感。这正是把几何直觉写成公式的好处：图的画法可以商量，数字不能。所以几何图像的真正作用是提示你：上下和不是两个数，而是两族数——分割一变，两边各自移动，而它们在每个分割上都守住 $L \le U$ 这条底线。剩下的问题自然变成：这两族数随分割变化时，朝哪个方向动、动得多快。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 3（例 3）</span>

设函数为区间 $[-2, 2]$ 上的 $f(x) = x^2 + 1$，分割为 $P = \{-2, -1, 0, 1, 2\}$。我们有

```math
m_1 = 2 \text{ 且 } M_1 = 5 ,
```

```math
m_2 = 1 \text{ 且 } M_2 = 2 ,
```

```math
m_3 = 1 \text{ 且 } M_3 = 2 ,
```

```math
m_4 = 2 \text{ 且 } M_4 = 5 .
```

对下和与上和我们有

```math
L(f, P) = 2 + 1 + 1 + 2 = 6 ,
```

```math
U(f, P) = 5 + 2 + 2 + 5 = 14 .
```

下面的引理是立时的（immediate）——由每个子区间上 $M_i \ge m_i$ 立得：

### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 1（引理 1）</span>

我们总有

```math
L(f, P) \le U(f, P) .
```

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Sub-partitions（子分割）</span>

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Sub-partition（子分割）</span>

设 $[a, b]$ 是一个区间，$P_1$ 与 $P_2$ 是区间 $[a, b]$ 的两个分割。若 $P_1$ 的所有分点也在 $P_2$ 中（于是 $P_2$ 大概还有一些额外的分点），我们就说 $P_2$ 是 $P_1$ 的 sub-partition（子分割），或 refinement（加细）。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 4（例 4）</span>

设区间为 $[-2, 2]$，给定的分割 $P_1$ 为

```math
\{-2, -1, 0, 1, 2\} .
```

则分割

```math
P_2 = \left\{-2, -\frac{3}{2}, -1, 0, \frac{1}{2}, 1, 2\right\}
```

是 $P_1$ 的一个加细（或细分）。确实，$P_2$ 除了拥有 $P_1$ 的全部分点之外还多出一些分点。

现在我们有：

### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 2（引理 2）</span>

设 $f : [a, b] \to \mathbb{R}$ 是有界函数，$P_1$ 是区间 $[a, b]$ 的分割，$P_2$ 是 $P_1$ 的加细，则

```math
L(f, P_1) \le L(f, P_2) \le U(f, P_2) \le U(f, P_1) .
```

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 中间那个不等式就是前一条引理。右边的不等式来自"$P_2$ 是 $P_1$ 的细分"这一事实。也就是说，设 $a = x_0 < x_1 < \cdots < x_n = b$ 是 $P_1$ 的分点，并设在 $x_{i-1}$ 与 $x_i$ 之间有 $P_2$ 的一个额外分点 $y$，即 $x_{i-1} < y < x_i$，则我们有

```math
\sup_{[x_{i-1}, y]} f \le M_i
```

以及

```math
\sup_{[y, x_i]} f \le M_i ,
```

于是

```math
\left[ \sup_{[x_{i-1}, y]} f \right] (y - x_{i-1}) + \left[ \sup_{[y, x_i]} f \right] (x_i - y) \le M_i \, \Delta x_i .
```

由此容易得出

```math
U(f, P_2) \le U(f, P_1) .
```

左边的不等式同理（把 sup 换成 inf）。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 引理 2 讲的是同一件事的两面：把一个 partition（分割）加细成 sub-partition（子分割）之后，上和只降不升、下和只升不降。用图像的话说，"罩在外面"的矩形随分点变密而收紧，"垫在下面"的矩形随分点变密而长高——两个界同时向内挤压，把面积夹得更紧。
>
> 机制只有两块砖。第一块是 sup（上确界）的单调性：子区间上的点集是原区间上点集的子集，因此子区间上的 sup（上确界）不可能更大，即 $\sup_{[x_{i-1}, y]} f \le M_i$ 与 $\sup_{[y, x_i]} f \le M_i$ 同时成立。第二块是一次拆项合并：新分割在这一段贡献的是 $\left[\sup_{[x_{i-1}, y]} f\right](y - x_{i-1}) + \left[\sup_{[y, x_i]} f\right](x_i - y)$，两个 sup（上确界）都不超过 $M_i$，而两段长之和恰好是 $y - x_{i-1} + x_i - y = \Delta x_i$。于是新贡献不超过原来的 $M_i \Delta x_i$。逐段这样做再求和，就得到 $U(f, P_2) \le U(f, P_1)$；把 sup（上确界）换成 inf（下确界）、不等号反向，就得到另一半。
>
> 这里有一步容易滑过去的隐含前提：加细必须保留旧分点。若允许分割演化时把旧分点挪走，比如把由 $-2, -1, 0$ 三个分点给出的分割换成由 $-2, -1.5, 0$ 给出的另一个，单调性立刻失效——后者不是 sub-partition（子分割），而是另一个互不相干的分割，两者之间没有任何可比性。所以引理的严格表述不是"分割更细"，而是"分点集合的包含关系"。这个区分在后面取 inf（下确界）与 sup（上确界）时至关重要：所有 partition（分割）只有在这样一张包含关系的网里，才有资格被比较。
>
> 拿例 4 的数字验一遍。$f(x) = x^{2}+1$、区间 $[-2, 2]$、$P_1$ 由 $-2, -1, 0, 1, 2$ 五个分点给出，前面已算出 $L = 6$、$U = 14$，窗口宽 $8$。取 $P_2$ 由 $-2, -\frac{3}{2}, -1, 0, \frac{1}{2}, 1, 2$ 七个分点给出，它保留了 $P_1$ 的全部分点，另外在第一段插入 $-\frac{3}{2}$、在第三段插入 $\frac{1}{2}$。逐段算：$[-2, -\frac{3}{2}]$ 上 $M = 5$、$m = 3.25$；$[-\frac{3}{2}, -1]$ 上 $M = 3.25$、$m = 2$；$[-1, 0]$ 上 $M = 2$、$m = 1$；$[0, \frac{1}{2}]$ 上 $M = 1.25$、$m = 1$；$[\frac{1}{2}, 1]$ 上 $M = 2$、$m = 1.25$；$[1, 2]$ 上 $M = 5$、$m = 2$。乘以各自段长得 $L(f, P_2) = 6.75$、$U(f, P_2) = 12.75$，窗口从 $8$ 收到 $6$：下表从 $6$ 升到 $6.75$，上表从 $14$ 降到 $12.75$，两边都朝真值 $\frac{28}{3} \approx 9.3333$ 靠近了。
>
> 跨课程连接放在 CLRS 里讲过的 binary search（二分搜索）。二分每走一步都把答案所在的索引区间缩一半，这里的加细每插一个分点都把面积所在的数值窗口收一点，形状相似：都是靠单调性排除一部分可能性。区别有两处，都很关键。其一，二分依赖全序——索引可以比大小、可以取中点，因此能定义"下一半"；而 partition（分割）之间只有偏序（子分割关系），并不给出唯一的"下一个"分割，所以这里根本不存在"逐步迭代"的路径，只能在所有分割的集合上一次性取 sup（上确界）与 inf（下确界）。其二，二分的正确性来自不变量"答案始终落在当前区间内"，这里的单调性正是同一条不变量：$L(f, P)$ 永远不超过真值，$U(f, P)$ 永远不低于真值，两者从两侧向真值逼近。
>
> Colding 给这组不等式的评价恰好点出了它的地位：🎥 *Colding*："Each of these steps is completely trivial, but together, it actually means that you can really define something non-trivial."（翻译：每一步都完全平凡，但合在一起，它实际上意味着你真的能定义出一个非平凡的东西。）这不是修辞：分析学里大量深刻的对象都是沿着"平凡步骤 + 单调挤压"这条路造出来的。模板可以这样记：先证单调，再取 sup（上确界）与 inf（下确界）。这条引理还有第二个用途——可积性判据要把两个不同分割的上和与下和拼到同一个分割上，靠的正是"合并加细"，而"合并加细不破坏单调性"就是引理 2 的结论。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Upper and lower integrals; the Riemann integral（上积分与下积分；黎曼积分）</span>

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Upper and lower Riemann integrals（上黎曼积分与下黎曼积分）</span>

现在设 $f : [a, b] \to \mathbb{R}$ 是有界函数。定义 $f$ 的 upper Riemann integral（上黎曼积分）为

```math
\overline{\int_a^b} f \, dx = \inf_P U(f, P) .
```

这里的 infimum（下确界）取遍 $[a, b]$ 的所有分割。同样地，我们定义 lower Riemann integral（下黎曼积分）为

```math
\underline{\int_a^b} f \, dx = \sup_P L(f, P) .
```

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断："极限"要打引号）:**</span> 上积分的直觉说法是"分割取得越来越细时，上和的极限"，下积分是对偶的下和极限。这个说法很好用，也能一眼看出为什么上下积分应该相等，但它在逻辑上不成立。Colding 特意停下来纠正：🎥 *Colding*："when I say that it's a limit over finer and finer partitions, you should really think about that in quotation marks."（翻译：当我说它"是越来越细的分割上的极限"时，你真该把这句话放进引号里理解。）紧接着给出严格版本：🎥 *Colding*："the precise statement is just that it's infimum over all partitions."（翻译：精确的陈述只是：它是对所有分割取的下确界。）
>
> 为什么"极限"必须在引号里？因为取极限需要一条序列——得有 $\mathbb{N}$ 给出的次序，才能谈"第 $n$ 项"。而"分割越来越细"给不出这样一条序列：给定一个 partition（分割），它的 sub-partition（子分割）有无穷多个，彼此之间没有任何顺序，谁也不比谁"更细"。加细关系只给出偏序，不给出全序，所以根本挑不出"下一个分割"。你当然可以人为选一条链，比如 $P_1 \subset P_2 \subset P_3 \subset \cdots$，但那条链的极限凭什么等于"所有分割上的下确界"？这需要额外证明，而且还得先证明不同的链给出同一个值。sup（上确界）与 inf（下确界）绕开了这一切：它们在偏序集的任意子集上都有定义，不需要索引，不需要选链。
>
> 存在性由谁保证？由完备性。$f$ 有界意味着每段上 $m_i \le M_i \le M$、$m_i \ge m$，于是对一切 partition（分割）都有 $m(b - a) \le L(f, P) \le U(f, P) \le M(b - a)$；上和的集合有下界、下和的集合有上界，完备性公理就保证 inf（下确界）与 sup（上确界）都存在。注意这里"有界"这个前提又一次成了地基：不先写"有界"，inf（下确界）可能取到 $-\infty$，定义没有意义。
>
> 课堂上学生追问了一个关键设定：是不是只允许有限多个分点？Colding 的回答区分了两件事：🎥 *Colding*："there are only finitely many divisions."（翻译：每个分割里只有有限多个分点。）以及 🎥 *Colding*："but there are infinitely many partitions."（翻译：但分割本身有无穷多个。）前半句保证每个 $\Delta x_i$ 是正实数、每个和是有限和，不会变成需要检查收敛性的级数；后半句则说明 inf（下确界）是在一个无穷集合上取的——事实上分割的全体不可数。这两条合起来正好解释了为什么不能写成一个序列的极限：索引集不是 $\mathbb{N}$，而是不可数集。
>
> 数字上把这个"逼近"看得更清楚。取 $f(x) = x^{2}+1$ 在 $[-2, 2]$ 上，用 $n$ 等分的均匀 partition（分割），算得上和 $U$：$n = 4$ 时 $14$，$n = 8$ 时 $11.5$，$n = 16$ 时 $10.375$，$n = 32$ 时 $9.84375$，$n = 64$ 时 $9.585938$，$n = 256$ 时 $9.395996$；同时 $U - L = \frac{32}{n}$，$n = 32$ 时窗口已只剩 $1$。真值是 $\frac{28}{3} \approx 9.3333$，数列确实单调下降着朝它爬。但请注意这个数列只是"所有分割"里的一个极小子集：定义要求的是对全体分割取 inf（下确界），所以严格的等号还要证明"任意分割都能被进一步加细到足够细"，以及"均匀族的下确界恰好就是真值"。定义里那个 all 不是装饰词。
>
> 跨课程连接放在 6.042J 的偏序集与链。那门课区分了偏序关系与全序（链），并说明只有链上的元素才能排成序列。这个区分在这里变成了一条硬约束：极限只对链有定义，sup（上确界）和 inf（下确界）对偏序集的任意子集都有定义。所以"打引号"不是措辞洁癖，而是在提示你：你脑子里的图像（一条越来越细的链）比定义（一个不可数集合上的下确界）窄得多。区别还在于存在性——一般偏序集里 sup（上确界）可能不存在，而 $\mathbb{R}$ 的完备性让"非空有界"就足够。
>
> 把直观说法与精确定义分开，是这门课从第一讲就在训练的习惯：先用图像建立直觉，再回头检查图像是否偷偷假设了定义里没有的东西。这里被偷偷假设掉的，正是"存在一条可以取极限的链"。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Riemann integrable（黎曼可积）</span>

设 $f : [a, b] \to \mathbb{R}$ 是有界函数。若

```math
\underline{\int_a^b} f \, dx = \overline{\int_a^b} f \, dx ,
```

我们就说 $f$ 是 Riemann integrable（黎曼可积）的。若函数黎曼可积，则 Riemann integral（黎曼积分）就是

```math
\int_a^b f \, dx = \overline{\int_a^b} f \, dx = \underline{\int_a^b} f \, dx .
```

黎曼可积函数全体记作 $\mathcal{R}([a, b])$。

> <span style="color:#7f8c8d;">TBB Definition 8.12, §8.6 The Riemann Integral, p.347–348（TBB 主线用 Riemann sum（黎曼和）极限定义黎曼可积；上/下积分的 Darboux 定义见 TBB Exercise 8.10.1, §8.10, p.363，其中让读者自证两种定义等价）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，"躲懒"背后的真问题）:**</span> 这个定义乍看像在躲懒：我们并没有直接写出 $\int_{a}^{b} f\,dx$ 是什么，而是说"当上积分与下积分相等时，才把公共值叫作积分"。Colding 自己把这句话替学生说了出来：🎥 *Colding*："so you may think that we wimped out of saying when this-- because we just define it, we just say that it's Riemann-integrable if those two things are equal. But then the question, of course, becomes, when are those two things equal?"（翻译：你们可能觉得我们在这里躲懒——因为我们只是定义：若这两样东西相等，就称它是黎曼可积的。但问题当然就变成了：这两样东西何时相等？）
>
> 这不是躲懒，而是把"存在性"从定义里赶出去的标准手法。若直接定义成"黎曼和的极限"，你就得先证明那个极限存在，否则定义悬空——而证明存在恰恰是最难的部分，这会构成循环。改用 sup（上确界）与 inf（下确界），两个数一定存在（有界 + 完备性），定义立刻落地；"它们相等"则被降级成一个附加条件，可以被检验、被证明、也可以被反例否证。定义与定理就此分开：定义负责命名，定理负责回答"什么时候能命名"。
>
> 手算一个"能相等"的例子，把这件事坐实。取 $f(x) = x^{2}$ 在 $[0, 1]$ 上，用 $n$ 等分的 partition（分割）：第 $i$ 段上 $M_i = \left(\frac{i}{n}\right)^{2}$、$m_i = \left(\frac{i-1}{n}\right)^{2}$，段长 $\frac{1}{n}$。于是 $U(f, P) - L(f, P) = \frac{1}{n}\sum_{i=1}^{n}\left(\frac{i^{2} - (i-1)^{2}}{n^{2}}\right) = \frac{1}{n^{3}}\sum_{i=1}^{n}\left(2i - 1\right) = \frac{n^{2}}{n^{3}} = \frac{1}{n}$。交叉项全部抵消，结果只剩一项：只要 $n = 100$，窗口就小于 $0.01$；要 $10^{-6}$，取 $n = 10^{6}$ 即可。对任意 $\varepsilon > 0$ 都能找到分割，于是上积分与下积分相等，积分值为 $\frac{1}{3}$。注意这个 $\frac{1}{n}$ 与 $f(x) = x$ 的情形完全一致——两者都是"每段的振幅之和恰好等于全区间长度"这条性质的两种长相。
>
> 视频在这里就到点了，后面两个结果都留成了欠账。一是下一讲才证的"连续即可积"：🎥 *Colding*："And we'll answer this next time where we will show that if f is continuous, then they're equal."（翻译：这个我们下次回答，届时会证明：若 $f$ 连续，那么这两个量相等。）二是不可积的反例，即讲义里的例 5，Colding 明说没讲到：🎥 *Colding*："it's in the notes, but I didn't get to it"（翻译：这个例子在讲义里，但我没来得及讲。）所以读讲义的人要注意：例 5 与引理 3 都只存在于文本里，视频没有覆盖，笔记里的对应注解只能依据讲义，不能声称"课上讲过"。
>
> 跨课程连接放在 CLRS 的近似算法。那里研究的目标不是"精确求出最优值"，而是"给出一个与最优值相差不超过 $(1+\varepsilon)$ 倍的可计算答案"，即 approximation scheme（近似方案）。本讲的做法在结构上完全同构：不问 $\int f$ 精确等于多少，只问能否用有限个可算的数把真值夹进任意窄的窗口。区别有两处：其一，近似比是相对误差、要求随输入规模多项式时间可算；这里的 $\varepsilon$ 是绝对误差、只要求"存在某个分割"，不管找到它要多少代价。其二，近似算法要交付的是算法，可积性判据要交付的是一条数学命题。
>
> 所以"何时相等"才是本讲真正的引擎：它不是定义的补丁，而是下一讲全部内容的入口。判据一旦给出，可积性就从"看我能不能算出积分"变成"看我能不能造出一个窗口够窄的 partition（分割）"。

> <span style="color:#1e8449;">**[note] Note（译者注，人物背景，译自讲义所引 Wikipedia）:**</span> 讲义此处附了一段 Wikipedia 的黎曼小传，先逐句译出。Georg Friedrich Bernhard Riemann（格奥尔格·弗里德里希·伯恩哈德·黎曼，1826–1866）是一位德国数学家，他在 analysis（分析学）、number theory（数论）与 differential geometry（微分几何）中都做出了深刻的贡献。黎曼于 1854 年首次开课授课，这些讲稿创立了 Riemannian geometry（黎曼几何）这一领域，从而为 Albert Einstein 的 general theory of relativity（广义相对论）搭好了舞台。在实分析领域，他最广为人知的是对积分的首次严格表述——即 Riemann integral（黎曼积分）——以及他在 Fourier series（傅里叶级数）上的工作。他对 complex analysis（复分析）的贡献中最著名的是引入 Riemann surface（黎曼面），为复分析提供了自然而几何化的处理方式。他 1859 年关于 prime-counting function（素数计数函数）的论文——其中包含 Riemann hypothesis（黎曼猜想）的原始陈述——被公认为 analytic number theory（解析数论）的奠基性论文。许多人认为他是历史上最伟大的数学家之一。
>
> 上面这段里有几处可以与一手材料对齐，也有几处只能标为"未能一手核实"。可以确认的：生卒为 1826 年 9 月 17 日至 1866 年 7 月 20 日，得年 39；1854 年 6 月 10 日在哥廷根大学哲学院作了那场著名的试讲，讲稿在他死后数年才付印（不同辞书分别记 1867 与 1868，两说互相矛盾，故此处只写"死后数年"）；1859 年 11 月的《Monatsberichte der Berliner Akademie》上刊出素数计数那篇短文，Clay Mathematics Institute 收藏手稿的介绍页记作 "first published in Monatsberichte der Berliner Akademie, November 1859"。只能标为未核实的是"1854 年首次开课授课"这一句：一手材料能确认的是取得 Privatdozent（编外讲师）资格所要求的试讲，至于"首次开课"的具体时间，本次查证未能一手核实。
>
> 机制层面的意义比年表重要。在黎曼之前，"函数可积"要么依赖连续、要么依赖原函数存在——两种说法都把可积性绑在别的概念上。黎曼把可积性改成对函数自身的一个判定：把区间切碎、用矩形上下夹，若两个界的下确界与上确界相等，就叫可积。这一步的产物是概念独立：可积性不再需要先有导数，于是可以谈论那些"没有原函数却能积分"的函数。这也解释了本讲为什么一开口就要"有界"：无界就没有 sup（上确界），整套构造无处落地。Colding 介绍这个话题时的话很朴素：🎥 *Colding*："So it's after German mathematician Riemann, integrals."（翻译：所以这是以德国数学家黎曼命名的积分。）
>
> 用一个可算的量说明这种"阶梯式"对象有多难缠。prime-counting function（素数计数函数）$\pi(n)$ 数的是不超过 $n$ 的素数个数：$\pi(10) = 4$，$\pi(100) = 25$，$\pi(10^{3}) = 168$，$\pi(10^{4}) = 1229$，$\pi(10^{5}) = 9592$，$\pi(10^{6}) = 78498$。它是不连续的阶梯函数，每一跳幅度都是 1。把它与两个光滑近似对比：$\frac{n}{\ln n}$ 在 $n = 10^{6}$ 时给出 $72382$，偏低约百分之八；对数积分 $\mathrm{Li}(n)$ 给出 $78627$，只高出 $129$。黎曼 1859 年那篇论文的价值就在于：他给出的不是"更好用的近似"，而是一个把 $\pi(n)$ 与复平面上一个函数的零点联系起来的恒等式——误差项的行为由零点位置决定，于是"素数分布有多规整"被翻译成"零点多靠近某条竖直线"，这就是 Riemann hypothesis（黎曼猜想）。
>
> 跨课程连接放在 6.042J 的数论。那门课证明的是定性结论，比如素数有无穷多个（欧几里得论证）、算术基本定理；它给出的工具是整除性与归纳，处理的是有限、离散、精确的对象。这里的 prime-counting function（素数计数函数）是同一批对象的定量版本，而本讲新建的这套"先有界、再夹逼"的机器，恰好是处理这类不连续对象的标准框架。区别在于目标：6.042J 关心"有没有、唯一不唯一"，分析关心"大概有多少、误差多大"。
>
> 所以读人物小传时，值得记住的不是生平年份，而是这条线索：本讲定义的那套上下和，从一开始就是为不连续的对象准备的。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 5: Not Riemann integrable（例 5：不可积的有界函数）</span>

设 $f : [0, 1] \to \mathbb{R}$ 为

```math
f(x) = \begin{cases} 1 & \text{if } x \in [0, 1] \cap \mathbb{Q} \\ 0 & \text{otherwise} \end{cases}
```

对此函数与一切分割 $P$ 我们都有

```math
L(f, P) = 0 \text{ 且 } U(f, P) = 1 .
```

因此 $f$ 不是黎曼可积的。

> <span style="color:#7f8c8d;">TBB Example 8.13, §8.6.1 Some Examples, p.349（同一函数：有理点取 $1$、无理点取 $0$，任何黎曼和都无法收敛）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 这就是著名的 Dirichlet function（狄利克雷函数）的变体：有理点取 $1$、无理点取 $0$。它把"有界"与"可积"之间的距离一次性摆到了台面上——函数有界（值域只有两个点），却在任何分割下都不可积。
>
> 原因是一句话：任何子区间里都既有有理数又有无理数。有理数与无理数都在 $\mathbb{R}$ 中稠密，不管你把区间切得多细，每一小段里都同时住着这两类点。于是每一段上都 $\sup f = 1$（有理点在那里）、$\inf f = 0$（无理点在那里），与分割的取法完全无关。乘上段长再求和，$U(f, P) = \sum_{i} 1 \cdot \Delta x_i = b - a$，而 $L(f, P) = \sum_{i} 0 \cdot \Delta x_i = 0$。在 $[0, 1]$ 上就是恒等式 $U = 1$、$L = 0$。
>
> 关键差别在于"加细有没有用"。例 3 里窗口是 $8$，加细后降到 $6$，继续加细只会更小——窗口的大小是分割的函数。这里窗口恒等于区间长度：$n = 1000$ 等分逐段算，$U$ 仍然是 $1$，$L$ 仍然是 $0$；$n = 10^{6}$ 也一样。窗口不随加细改变，说明它不是"还没切够细"，而是"结构上不允许弥合"。可积性判据要求"存在一个分割使 $U - L < \varepsilon$"，取 $\varepsilon = 0.5$ 就已经失败，因此这个函数不在可积函数类里。
>
> 一个必须并排看的对照是 Thomae function（托梅函数）：$f\left(\frac{p}{q}\right) = \frac{1}{q}$（$\frac{p}{q}$ 为最简分数），在无理点取 $0$。它在每个有理点都不连续、不连续点还是稠密的，$L(f, P) = 0$ 依然恒成立；但 $U$ 能被压小，因为"高度不小于 $\frac{1}{q}$"的点只有分母小的那些，数量有限。用 $n = 1000$ 等分逐段取 $\sup$ 数值算，得到 $U \approx 0.0296$——取 $\varepsilon = 0.1$ 就通过了判据。两种函数的对比说明：不可积的根源不是"有不连续点"，也不是"不连续点稠密"，而是"每一段上的振幅都无法被段长稀释"。
>
> 视频没有讲这个例子。Colding 下课前把它留成了讲义内容：🎥 *Colding*："we will also look at an example-- it's in the notes, but I didn't get to it, we look at an example of function that is not-- where you don't have this equality."（翻译：我们还会看一个例子——它在讲义里，但我没来得及讲，我们看一个函数不满足这个等式的例子。）所以这一条注的内容完全来自讲义文本，不能声称"课上讲过"。
>
> 跨课程连接放在 6.042J 的稠密性与基数。那门课证明了有理数可数、实数不可数，也讲过 $\mathbb{Q}$ 在 $\mathbb{R}$ 中稠密。这里用到的正是"稠密"这条局部性质，而不是"可数"这条基数性质：第 $i$ 段里存在有理点，所以 $M_i = 1$；存在无理点，所以 $m_i = 0$。区别值得说清——可数性决定了"能不能把点排成序列"，稠密性决定了"任何区间都躲不开这类点"；不可积性只依赖后者。顺带一提，正因为不可数的那一侧无法被有限的段数"跳过去"，加细才对它完全无效。
>
> 那么真正的判据是什么？要等到 Lebesgue（勒贝格）的条件：函数可积当且仅当其不连续点集"测度为零"。所谓测度为零，可以这样理解：用一列区间把这个点集盖住，把所有区间的长度加起来，若总长度能压到任意小，就称它测度为零；有限点集、甚至可数点集都满足这条，而整段区间不满足。这条判别法超出本课范围，但它解释了为什么 Thomae function（托梅函数）过关而 Dirichlet function（狄利克雷函数）不过关：前者的不连续点集是可数的（只有有理点），后者的不连续点集是整个区间。

我们将会关心这两个问题："什么样的函数是黎曼可积的？"……以及"我们如何计算积分？"第二个问题的答案将是 fundamental theorem of calculus（微积分基本定理）。这将是后面某一讲的主题。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">A criterion for integrability（可积性判据）</span>

### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 3（引理 3）</span>

设 $f : [a, b] \to \mathbb{R}$ 是有界函数，则 $f \in \mathcal{R}([a, b])$ 当且仅当对任意 $\varepsilon > 0$，存在一个分割 $P$ 使得

```math
U(f, P) - L(f, P) < \varepsilon .
```

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 设 $f \in \mathcal{R}([a, b])$，则

```math
\sup_P L(f, P) = \underline{\int_a^b} f \, dx = \overline{\int_a^b} f \, dx = \inf_P U(f, P) .
```

这意味着：给定 $\varepsilon > 0$，存在分割 $P_1$ 与 $P_2$ 使得

```math
\int_a^b f \, dx - \frac{\varepsilon}{2} < L(f, P_1)
```

以及

```math
U(f, P_2) < \int_a^b f \, dx + \frac{\varepsilon}{2} .
```

令 $P$ 为同时拥有 $P_1$ 与 $P_2$ 全部分点的分割，于是 $P$ 是 $P_1$ 与 $P_2$ 两者的加细。由此得

```math
\int_a^b f \, dx - \frac{\varepsilon}{2} < L(f, P_1) \le L(f, P) \le U(f, P) \le U(f, P_2) < \int_a^b f \, dx + \frac{\varepsilon}{2} .
```

这就证明了命题的前一半。

为看相反方向，设对任意 $\varepsilon > 0$ 存在分割 $P$ 使得 $U(f, P) - L(f, P) < \varepsilon$。由于

```math
L(f, P) \le \underline{\int_a^b} f \, dx
```

以及

```math
\overline{\int_a^b} f \, dx \le U(f, P) ,
```

我们有

```math
\overline{\int_a^b} f \, dx - \underline{\int_a^b} f \, dx \le U(f, P) - L(f, P) < \varepsilon .
```

由于这对一切 $\varepsilon > 0$ 成立，我们得到结论。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板与文本复原说明）:**</span> 引理 3 的内容是"可积"的一个等价刻画：$f$ 可积当且仅当对任意 $\varepsilon > 0$，存在一个 partition（分割）使 $U(f, P) - L(f, P) < \varepsilon$。整条引理的价值在于把"两个下确界与上确界相等"这种整体陈述，换成"存在一个好分割"这种可以动手构造的陈述。视频没有讲到这一步，Colding 把它留给了下一讲，并明确说了为什么：🎥 *Colding*："I will first-- we need, anyway, some more information about these upper and lower integrals"（翻译：我首先——不管怎样，我们需要关于这些上积分与下积分的更多信息。）
>
> 前一半的证明是一个可以命名的模板：「$\frac{\varepsilon}{2}$ 劈分」。它的第一步是把"下确界"翻译成"存在某个分割几乎达到它"——这正是 inf（下确界）的 $\varepsilon$ 刻画：若 $\sup_{P} L(f, P) = I$，则对任意 $\frac{\varepsilon}{2} > 0$，必存在 $P_1$ 使 $L(f, P_1) > I - \frac{\varepsilon}{2}$；同理存在 $P_2$ 使 $U(f, P_2) < I + \frac{\varepsilon}{2}$。注意这两步各自只用到一侧，所以它们的误差预算必须劈开、各占一半：若两边都用 $\varepsilon$，串起来会得到 $2\varepsilon$ 的窗口，结论就弱了。
>
> 第二步是这条引理真正的技巧所在：必须把两个分割合并成同一个分割。取 $P$ 为同时拥有 $P_1$ 与 $P_2$ 全部分点的 partition（分割），于是 $P$ 是两者的 sub-partition（子分割），引理 2 给出 $L(f, P_1) \le L(f, P) \le U(f, P) \le U(f, P_2)$。把四段串起来，就得到 $I - \frac{\varepsilon}{2} < L(f, P) \le U(f, P) < I + \frac{\varepsilon}{2}$，即 $U - L < \varepsilon$。为什么非合并不可？因为 $P_1$ 只保证下和够高、$P_2$ 只保证上和够低，两个"好性质"分居两个分割之上；不合并，你无法说"存在一个分割同时满足两头"，而引理的结论正是这个存在性。
>
> 后半句只做一次相减：由 $L(f, P) \le \underline{\int} f$ 与 $\overline{\int} f \le U(f, P)$ 得 $\overline{\int} f - \underline{\int} f \le U(f, P) - L(f, P) < \varepsilon$；对一切 $\varepsilon > 0$ 成立，夹出一个非负数不超过零，故两者相等。
>
> 拿数字验一遍。取 $f(x) = x^{2}$ 在 $[0, 1]$ 上、$\varepsilon = 0.1$，真值 $I = \frac{1}{3}$。平分预算得 $\frac{\varepsilon}{2} = 0.05$：需要 $P_1$ 使 $L > 0.28333$、$P_2$ 使 $U < 0.38333$。用 $n = 20$ 等分，算得 $L = 0.30875$、$U = 0.35875$，两者都落在各自要求的范围内，而同一个分割给出的窗口 $U - L = 0.05$ 确实小于 $0.1$。反过来，$n = 10$ 时窗口恰好是 $0.1$，取不到严格小于，所以判据里的严格不等号不是形式主义——它逼你再多切一刀。
>
> 两点文本复原说明必须交代。其一，源 PDF 提取时本证明里的两行上下划线积分记号丢失了，上面按上下文还原为 $\overline{\int}$ 与 $\underline{\int}$。其二，原文倒数第二段写作"suppose that for some $\varepsilon > 0$"，但引理的假设是"对任意 $\varepsilon > 0$"，译文按引理陈述改正为"对任意"。讲义所引的 TBB 对应结果是 Theorem 8.16（§8.6.2, p.351），用 oscillation（振幅）表述同一件事；它前面的 Theorem 8.15（p.351）要求"所有足够细的分割"都满足条件，而本讲的"存在一个分割"版本更易用——这正是 TBB 自己强调的变体。
>
> 跨课程连接放在 Strang 的矩阵分解。数值线性代数里分析 $A = LU$ 的 backward error（后向误差）时，用的也是同一套预算分配：每一步的舍入误差各记一小份，最后用三角不等式把所有小份加起来，得到 $\|E\| \le \gamma_n \|A\|$ 形式的界。结构上完全同构：先把总误差拆成可控的小份，再用一次不等式合并。区别在于界的形状——那里的界是范数型的、随矩阵规模 $n$ 增长（$\gamma_n$ 里含 $n$ 与机器精度 $u$），这里的界是标量型的、只含一个任给的 $\varepsilon$，与区间长度无关。
>
> 模板可以这样记下来：要证"存在一个对象同时满足两个逼近要求"，先分别为两个要求各找一个对象，再用某种单调性把两个对象合并成一个，最后串不等式。$\frac{\varepsilon}{2}$ 只是预算的名字，真正的手段是"合并 + 单调"。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Continuous functions are integrable; uniform continuity（连续函数可积；一致连续）</span>

我们现在来到一个关键定理，它给出了"函数黎曼可积"的一个简单判据：

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem（定理）</span>

$[a, b]$ 上的任何连续函数都属于 $\mathcal{R}([a, b])$。

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 我们将在下一讲证明它——先证明"闭有界区间上的连续函数其实是一致连续的"之后再来证。$\square$

> <span style="color:#7f8c8d;">TBB §8.6 开头的两条 observations（p.348–349）：所有连续函数都黎曼可积；所有黎曼可积函数都有界</span>

> <span style="color:#1e8449;">**[note] Note（译者注，课后问答实录）:**</span> 视频到这里只把结论立成一个欠账：闭区间上的连续函数一定黎曼可积。讲义里的 proof（证明）也只有一句话——"下一讲再证，先证闭有界区间上的连续函数其实是一致连续的"。Colding 说得很直白：🎥 *Colding*："we return to that next time because to make it really clear, it will take a few minutes."（翻译：这个我们下次再讲，因为要把它真正讲清楚，需要几分钟。）
>
> 下课前有学生追问：连续是不是可积的充要条件？回答是否定的：🎥 *Colding*："It's a good initial answer, but there are many functions that are not continuous"（翻译：它是一个很好的初始答案，但有许多不连续的函数……）。这个否定有两面，而且两面都必须记住。第一面：连续不是必要条件——Thomae function（托梅函数）在每个有理点都不连续，不连续点还稠密，却仍然可积；阶跃函数在跳变点不连续，也能积分。第二面：连续甚至不是"可积"的刻画工具所能单独承担的——本节末尾的 Dirichlet function（狄利克雷函数）处处不连续且不可积，但它有界，说明"坏"有多种坏法，连续只是其中一种"好"的充分条件。
>
> 机制要先看清，否则一致连续出现得很突然。判据要求把 $U(f, P) - L(f, P) = \sum_{i}(M_i - m_i)\Delta x_i$ 压到 $\varepsilon$ 以下。若每一段上的振幅都不超过 $\varepsilon'$，那么整个和不超过 $\varepsilon'(b - a)$，于是取 $\varepsilon' = \frac{\varepsilon}{b - a}$ 就成了。问题在于"每一段振幅都小"这句话里，段是被分割决定的，而分割要由你选。于是逻辑顺序必须是：先固定一个对所有位置都有效的 $\delta$，再用它去切分割，最后验算。逐点连续给不出这个 $\delta$——它只保证"每个点各自存在某个 $\delta$"，而那些 $\delta$ 依赖点，你在切分割之前并不知道要切在哪里，无法预先取到它们的最小值。
>
> 数字上验证一遍。取 $f(x) = x^{2}$ 在 $[0, 1]$ 上，用到的估计是 $|x^{2} - y^{2}| = |x + y|\,|x - y| \le 2|x - y|$，于是 $\delta = \frac{\varepsilon}{2}$ 就够。取 $\varepsilon = 0.01$，得 $\delta = 0.005$：段内任两点相距不超过 $0.005$，振幅因此不超过 $2 \times 0.005 = 0.01$，于是 $U - L$ 被压在 $0.01$ 乘总长 $1$ 以内。这个界恰好等于 $\varepsilon$，不满足严格小于，所以实操中把段宽再取一半，即 $0.0025$、切 $400$ 段，界降到 $0.005$。有意思的是等分直接算出的真值是 $U - L = \frac{1}{n}$，$n = 200$ 时只有 $0.005$，比振幅估计紧一倍：$x^{2}$ 的段内振幅是 $x_i^{2} - x_{i-1}^{2}$，只在右端点附近才接近 $2\delta$，而振幅估计取的是该段上最坏的情况。请留意这个 $0.005$ 是"算出来的"，不是"证出来的存在性"——正因为 $\delta$ 与位置无关，它才是一个可以预先算出的算法参数。
>
> 顺带把"充分而非必要"的那一面也数字地坐实。取 $[0, 1]$ 上的阶跃函数：$x < \frac{1}{2}$ 时取 $0$，$x \ge \frac{1}{2}$ 时取 $1$。用 $n$ 等分去切，只有跨越 $\frac{1}{2}$ 的那一段振幅是 $1$，其余各段振幅都是 $0$，于是 $U - L = \frac{1}{n}$：$n = 100$ 时窗口只有 $0.01$。一个不连续的函数，窗口照样能任意小——这就把"连续是可积的充分条件"与"连续是可积的必要条件"两句话彻底分开了。
>
> 跨课程连接放在 CSAPP 第 11 章的 socket（套接字）编程。在那里，`send` 返回成功只保证数据进了内核缓冲区，这是逐次、局部的保证；"对端收到完整且有序的字节流"才是整条连接的全局保证。分析学里是同一对范畴："每点存在自己的 $\delta$"是局部的，逐点验证永远拼不出一个统一参数；"存在一个 $\delta$ 通吃"才是全局的，可以被上层当作不变量使用。区别在于全局性从哪来：TCP 的全局保证靠序号与重传这些工程机制构造出来，一致连续的全局保证靠闭区间上连续这一结构性质推出来。
>
> 所以这个定理的真正内容不是"连续函数能积分"这条消息，而是"闭有界区间上那种'任何序列都抽得出收敛子列'的性质，可以把局部性质升级成全局性质"这套手法。下一讲要做的，正是这个升级。

这个定理的证明需要下面这个关键概念。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Uniformly continuous（一致连续）</span>

设 $f : I \to \mathbb{R}$ 是一个函数，其中 $I$ 是一个区间。若对任意 $\varepsilon > 0$，存在一个 $\delta > 0$ 使得只要 $|x - y| < \delta$ 就有

```math
|f(x) - f(y)| < \varepsilon ,
```

我们就称 $f$ 是 uniformly continuous（一致连续）的。

注意：一致连续比连续更强。它的意思是：对一个给定的 $\varepsilon > 0$，同一个 $\delta$ 可以用于所有的 $x$。

> <span style="color:#7f8c8d;">TBB Definition 5.46, §5.6 Uniform Continuity, p.219；TBB Theorem 5.48（$[a,b]$ 上连续 ⇒ 一致连续），§5.6, p.220</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 把这个定义与逐点连续并排看，差别只有一个字的重量：逐点版本里 $\delta = \delta(x_0, \varepsilon)$，可以随点变化；一致连续版本要求 $\delta = \delta(\varepsilon)$，一个数对整个区间统一有效。这个"统一"就是 uniformly（一致）的全部含义，别处没有隐藏条件。
>
> 把两句话的量词顺序写出来，差别立刻显形。逐点是：对每个 $x_0$、对每个 $\varepsilon$，存在 $\delta$，使得 $|x - x_0| < \delta$ 的点满足 $|f(x) - f(x_0)| < \varepsilon$——先把点定死，再为它找 $\delta$。一致是：对每个 $\varepsilon$，存在 $\delta$，使得对一切 $x$ 与一切 $y$，只要 $|x - y| < \delta$ 就有 $|f(x) - f(y)| < \varepsilon$——先定精度，再找一个通吃的 $\delta$。前者给出一整族 $\delta$（每个点一个），后者只给一个数。能不能把前者加个"取最小"变成后者？不能：那族 $\delta$ 可能是无穷多个正数，其下确界可以是 $0$，而 $\delta$ 必须是正数。
>
> $f(x) = \frac{1}{x}$ 在 $(0, 1)$ 上就是这个失败的标准样本。取 $x = \frac{1}{n}$、$y = \frac{1}{2n}$：两点距离是 $\frac{1}{2n}$，而函数值之差是 $n - 2n$ 的绝对值，即 $n$。$n = 10$ 时距离 $0.05$、落差 $10$；$n = 1000$ 时距离 $0.0005$、落差 $1000$；$n = 10^{6}$ 时距离 $5 \times 10^{-7}$、落差 $10^{6}$。距离越压越小，落差却按同样的速度往上涨，任何候选的 $\delta$ 都会被足够大的 $n$ 击穿。注意这里函数是连续的，每一点的 $\delta$ 都存在（取 $\delta = x_0^{2}\varepsilon$ 之类即可），只是它们随 $x_0 \to 0$ 一起趋零，没有正的公共下界。
>
> 为什么可积性非得要这个更强的性质？回到判据：要把 $\sum_{i}(M_i - m_i)\Delta x_i$ 压到 $\varepsilon$ 以下，需要"每段振幅都小"。而段的位置由你选的 partition（分割）决定，所以你必须在选分割之前就握有一个与位置无关的 $\delta$——否则你切完刀再回头找 $\delta$，验算时又得重新切，永远闭环不了。一致连续把 $x_0$ 这层依赖抹掉，$\delta$ 才变成一个可以预先算出的常数，误差界才成为"可以写下来的界"。
>
> 补上这一环的定理是：闭有界区间上的连续函数一定一致连续（讲义引 TBB Theorem 5.48, §5.6, p.220）。证明思路值得先看一眼，因为它再一次用到"反证 + 抽子列"这套本课反复出现的动作：若不一致连续，则存在某个 $\varepsilon > 0$，使得对每个 $n$ 都能找到两点 $x_n, y_n$ 满足 $|x_n - y_n| < \frac{1}{n}$ 而 $|f(x_n) - f(y_n)| \ge \varepsilon$；从有界区间里抽出一个收敛的子列（这是闭有界区间上序列必有收敛子列的结论），再配合连续性就得到矛盾。关键在于"失败的一致性"可以被压缩成一对照样接近、函数值却分不开的点列，而连续性恰恰禁止这种事。这里只交代思路，正式证明在下一讲；附带说明，视频全片没有出现 uniform（一致）这个词，本节内容只存在于讲义。
>
> 跨课程连接放在 6.042J 的谓词逻辑。那门课专门讨论过量词顺序：$\forall x \exists \delta$ 与 $\exists \delta \forall x$ 不是同一命题，交换之后真假可以完全反转，练习题里就有"每个人的母亲"与"存在一个人是所有人的母亲"这种对照。这里的两个连续定义正是同一个现象的数学版本。区别在于代价：在逻辑课里量词顺序只影响命题真假，在这里它决定"$\delta$ 是每点一份的无穷族、还是一个可以写进算法的常数"——换句话说，量词顺序换的是可计算性，不只是真值。
>
> 收束一句：一致连续不是"更强的连续"，而是"把局部的存在性升级成全局的可选择性"。下一讲证明连续可积时，用的正是这次升级。
