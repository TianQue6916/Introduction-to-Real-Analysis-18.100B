# 度量三公理：四个问题的解答

> 18.100B · L11–L12 延伸。教材 TBB（Thomson–Bruckner–Bruckner）**13 METRIC SPACES** p.537 起。
> 每节固定四段：**一句话答案 → 一个最小例子 → 为什么真的成立 → 边界在哪**。

---

## 先把四个问题的答案摆出来

| 问题 | 一句话答案 |
|---|---|
| 一、度量凭什么能自己换？ | 度量是**约定**，不是固有属性；换的是尺子，不是世界。 |
| 二、凭什么满足三公理就能迁移？ | 因为证明里只用到这三条；凡是满足这三条约定的对象，同一份证明原样有效。 |
| 三、怎么证明某条定理只用三公理？ | **逐行读证明**写下每行依据；再**删一条公理造反例**，看它死不死。 |
| 四、怎么证明某个概念只依赖三公理？ | 看它**能不能只用 $d$ 说清楚**；能说清楚 ≠ 它的定理能推出来。 |

## 一、度量凭什么能自己换？

**一句话**：度量是给集合"装"上去的，一个集合可以装很多把不同的尺子。

**最小例子**。课上 $\mathbb N$ 上 $d(m,n)=\left|\frac1m-\frac1n\right|$ 看着奇怪，其实只是把 $\mathbb R$ 上现成的距离**搬过去**：取 $f(n)=1/n$，令

```math
d_{\mathbb N}(m,n)=d_{\mathbb R}\bigl(f(m),f(n)\bigr)=\left|\frac1m-\frac1n\right| .
```

于是 $(\mathbb N,d_{\mathbb N})$ 与数集 $\{1,\tfrac12,\tfrac13,\dots\}$ 上的距离**一模一样**，只是点的名字从 $1/n$ 换成了 $n$。三条约定逐条继承：非负靠 $f$ 不重复取值，对称与三角不等式直接从 $\mathbb R$ 抄。

**为什么真的成立**。公理不指认对象，只规定关系。三条约定说的是"距离满足这几条关系"，集合里装的是数、函数还是字符串，公理不管。教材自己就把这件事写在定义后面：

> TBB Definition 13.6 后一段："**There can be many different metrics on a set $X$.** If more than one metric is under consideration, we must make it clear which metric is considered…"
> 中文批注：一个集合 $X$ 上可以有许多不同的 metric，同时考虑多个时必须说清当下用的是哪一个 —— 所以"换尺子"不是教授的个人癖好，是定义的一部分。

**边界**：换尺子换掉的不是数值，而是**哪些定理还活着**。名字挨着（$n$ 与 $n+1$）不代表距离挨着；换回 $f(n)=n$，同一个 $\mathbb N$ 立刻变回"无界、不完备"。

## 二、凭什么"满足三公理"就能迁移？

**一句话**：证明里只说到 $d$ 的**值**，没说到具体是谁的距离，所以换谁都成立。

**最小例子**。"$|x-z|\le|x-y|+|y-z|$" 换成 "$d(x,z)\le d(x,y)+d(y,z)$" 之后，证明一个字都不用改 —— 这就是迁移的全部内容。教材里"验证它是 metric，然后所有度量定理随便用"凭的就是这一句。

**为什么真的成立**。逻辑上的事实：一份证明若只从某组约定出发，则任何满足这组约定的对象都满足结论。所以不必为每个空间重证一遍。日常判据是**逐行问一句"这一步凭什么"**，答案只有四种：

1. 逻辑规则（任何结构里都成立）→ 不记；
2. 已证过的引理 → 去查它的账；
3. 直接用了某条公理 → 记下是 M1 / M2 / M3 哪条；
4. 展开了某个概念的定义 → **注意**：展开会把定义右边的东西全引进来，要查它有没有偷带别的结构。

再备一份"免费清单"：$\mathbb R$ 的加减乘、大小比较、"有限个实数能取最大"都免费；而 $\mathbb R$ 的**完备性**（上确界一定存在）不免费，用了要说明。

**边界**（三条最容易栽的）：

- **提到 ≠ 用到**：写下 $d(x,y)\ge0$ 不等于用了它的内容；
- **定义展开会偷渡**：展开"$x$ 是内点"没事，展开一个用到 $X$ 上序的定义就有事；
- **参数顺序要对齐**：收敛写 $d(x_n,a)$、有界写 $d(c,x_n)$，那从前者推后者就得多用一条 M2。

## 三、怎么审"某条定理"只用三公理？

**一句话**：把证明摊开逐行标依据；再用反例确认"少一条就死"。

### 3.1 例子：极限唯一性（三条都用到，一条不少）

要证：若 $x_n\to a$ 且 $x_n\to b$，则 $a=b$。

1. 取任意 $\varepsilon>0$：存在 $N_1$ 使 $n\ge N_1$ 时 $d(x_n,a)<\varepsilon/2$；同理有 $N_2$ 对 $b$。〔定义展开 + $\mathbb R$ 的算术〕
2. 取 $n\ge\max(N_1,N_2)$，则 $d(a,b)\le d(a,x_n)+d(x_n,b)$。〔**M3**；"取最大"是免费背景〕
3. 而 $d(a,x_n)=d(x_n,a)<\varepsilon/2$。〔**M2**〕
4. 故 $d(a,b)<\varepsilon$ 对一切 $\varepsilon>0$，所以 $d(a,b)=0$。〔$\mathbb R$ 的大小比较〕
5. 于是 $a=b$。〔**M1 的"零距离即同点"这一半**〕

**记账结果**：$\{\text{M1},\text{M2},\text{M3}\}$。再细一点：**M2 是真正承重的**（第 3 行纯粹为了把方向掉过来）；M1 只用到一半；M3 只用到"经过一个中间点"这一种情形。

### 3.2 例子：收敛 ⇒ 有界（结果空集，说明它不是度量定理）

同样逐行标：取 $\varepsilon=1$ 得 $N$；把前 $N-1$ 个距离与 $1$ 一起取最大值当 $R$；两种情形都比 $R$ 小。全程只用到 $\mathbb R$ 的算术和"有限个数能取最大"。

**结论是空集：一条公理都没用到。** 这不是白干，而是更强的结论：**这条定理对任意函数 $d:X\times X\to\mathbb R$ 都成立**（不对称、不满足三角不等式也行）。所以它不是度量定理 —— 这解释了它为什么对离散度量、编辑距离、汉明距离全都对。

### 3.3 反方向：怎么证明"少一条就不行"

只有一条路：**造一个违反它的例子，其余都正常，让定理在里面为假**。

- 删 M2（对称）：$X=\{a,b\}$，$d(a,a)=d(b,b)=0$，$d(a,b)=0$，$d(b,a)=1$。常序列 $a,a,\dots$ 同时收敛到 $a$ 和 $b$。
- 删 M1 的"零距离即同点"：取 $d\equiv0$，每个序列收敛到每个点。
- 删 M3（三角不等式）：要造得长一点 —— 取 $X=\{a,b\}\cup\{u_n\}$，$d(a,u_n)=d(b,u_n)=1/n$，$d(a,b)=1$，其余按 $|1/m-1/n|$；则 $n\ge3$ 时 $1=d(a,b)>\tfrac1n+\tfrac1n$，而 $u_n$ 同时收敛到 $a$、$b$。这段的真正工作量在**逐条验 M1、M2 仍然成立**，不在写公式。

### 3.4 一个必须知道的后果

同一句话，两种写法，两个答案。「收敛列有界」写成**球形式**（$\exists c,R\ \forall n:d(x_n,c)\le R$）时上表是空集；写成**直径形式**（$\exists M\ \forall m,n:d(x_m,x_n)\le M$）时，从前者推过去要多两行：$d(x_m,x_n)\le d(x_m,a)+d(a,x_n)$〔M3〕$=d(x_m,a)+d(x_n,a)$〔M2〕，于是答案是 $\{\text{M2},\text{M3}\}$。

**所以"这条定理依赖几条公理"这句话，在说清"怎么表述、怎么证"之前没有意义。** 这不是抠字眼，是提醒你：写定理时你已经在做选择了。

## 四、怎么审"某个概念"只依赖三公理？

**一句话**：看它的定义能不能只用 $d$ 和量词写出来；写不出来，谈证明就是空谈。

**最小例子**。

- 写得出来：「$x_n\to a$」就是 $\forall\varepsilon>0\ \exists N\ \forall n\ge N: d(x_n,a)<\varepsilon$；「$f$ 在 $a$ 连续」「$x$ 是球 $B(a,r)$ 的内点」同样能写。
- 写不出来：「$x_n$ 单调递增」需要 $X$ 上的大小关系；「$f$ 可微」需要减法和除法。这类概念不是"证明难"，而是**这句话本身没有意义**。

**"能写" ≠ "能证"：完备性就是分界样本**。完备写得很干净（教材 Definition 13.60："a metric space $(X,d)$ is complete if every Cauchy sequence in $X$ converges (to an element of $X$)"），但它**不是**三公理的推论：$\mathbb Q$ 配通常距离就不完备 —— 序列 $\{(1+1/n)^n\}$ 是 Cauchy 却不收敛到 $\mathbb Q$ 里的点（教材 Example 13.61 原话）。写得出口、证不出来，这条界线用一个例子就画完了。

**一个免费的否证器**：若概念能只用 $d$ 写出来（且公式里不带参数），则它必然在**等距搬动**下不变 —— 把整个空间按"距离不变"的方式挪一下，概念不变。逆否：**发现它被挪变了，它就不可能是度量概念**。

例：「$x$ 是球的球心」不是度量概念（球心依赖"谁被选作中心"）；「$x$ 是整数」也不是（把 $\mathbb R$ 平移 $0.5$ 就变）。

**边界（这条是行家会问的）**：公式里一旦**带参数**就不灵了。$\varphi(x):=(d(x,1)=0)$ 定义的集合是 $\{1\}$，而平移 $0.5$ 之后变 $\{1.5\}$ —— 它看着"只用 $d$ 说话"，其实偷偷点了名。所以判据必须写"不含参数"。

## 五、四个问题其实是一条链

1. **能换尺子**（一）是前提：不能换，"迁移"就没有对象。
2. **迁移为什么成立**（二）是机制：只说 $d$ 的值，所以换谁都行。
3. **审定理**（三）是对机制的操作化：逐行标依据 + 造反例。
4. **审概念**（四）是审更前面的东西：概念本身得先"说得出口"，定理才谈得上"证得出来"。

一句话收束：**说得出口（四）→ 证得出来（三）→ 所以处处成立（二）→ 于是敢换尺子（一）。**
