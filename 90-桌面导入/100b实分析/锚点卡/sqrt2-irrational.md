# 锚点卡：$\sqrt{2}$ 为什么是无理数

> 生态位：**中轴**。实分析里"实数系为什么要构造出来"的第一块砖（100b 实分析 §1 之前的前置）。
> 一句话可判真假的断言：**不存在整数 $m,n$ 满足 $m^2=2n^2$ 且 $n\neq 0$。**

---

## Q1 本质

剥掉所有术语，$\sqrt2$ 无理性断言的是：**$\sqrt2$ 无法用有限个整数完全确定。**

一个有理数 $m/n$ 携带的信息是有限的：两个整数。它被写死为"取到第 $k$ 位就终止，之后是循环节"。而 $\sqrt2$ 不是。

容易混的一点：**dense（稠密）≠ 覆盖**。任意精度逼近 $\sqrt2$ 都做得到，$1393/985$ 的误差只有 $3.6\times10^{-7}$。但"误差可以任意小"与"误差等于 0"之间隔着一整个无限——所有有理数分母都是有限的，而逼近误差的下界是 $1/(2\sqrt2 q^2)$，$q$ 有限则误差恒正。

---

## Q2 公式（三版证明，同一件事的三种记账法）

### 版 1 · 奇偶归谬（Hippasus 传统版，Euclid X.117 附注）

设 $\sqrt2=m/n$，$m,n\in\mathbb Z$，$n>0$，且 $\gcd(m,n)=1$。两边平方：

```math
m^2=2n^2
```

右端是偶数 ⇒ $m^2$ 偶 ⇒（引理）$m$ 偶，记 $m=2k$。代回：

```math
4k^2=2n^2\ \Longrightarrow\ n^2=2k^2
```

同理 $n$ 偶。于是 $2\mid\gcd(m,n)$，与既约矛盾。

**引理（不许省）**：$m$ 偶 $\iff m^2$ 偶。
- $\Leftarrow$ 取逆否：$m$ 奇 ⇒ $m=2a+1$ ⇒ $m^2=2(2a^2+2a)+1$ 奇。
- $\Rightarrow$ 直接：$m=2k$ ⇒ $m^2=4k^2$。

这一步是全部证明里唯一"看起来显然、实则必须证"的地方。跳掉它，证明就退化成"因为 2 不是平方数所以矛盾"的口头循环。

### 版 2 · $v_2$ 记账（把两次归谬压成一次）

定义 $v_2(x)$ = $x$ 的质因数分解里 $2$ 的指数（不是新东西，就是你分解质因数时数出来的那个数）。它满足

```math
v_2(ab)=v_2(a)+v_2(b)\ \Longrightarrow\ v_2(x^2)=2v_2(x)\ \text{是偶数}
```

而由 $m^2=2n^2$：

```math
v_2(m^2)=1+2v_2(n)\ \text{是奇数}
```

偶数 = 奇数，矛盾。一次记账，没有"再来一次"。

实测（脚本 §B）：$v_2(6^2)=2$、$v_2(12^2)=4$、$v_2(35^2)=0$，全是偶数；$v_2(2\cdot6^2)=3$、$v_2(2\cdot12^2)=5$、$v_2(2\cdot35^2)=1$，全是奇数。

### 版 3 · 无限下降（Fermat descent）

不做"既约"归一化，直接：任一解 $m^2=2n^2$ ⇒ $m$ 偶 ⇒ $m=2k$ ⇒ $2k^2=n^2$，且

```math
k=\frac m2=\frac{\sqrt2}{2}n<n\quad(\text{因 }\sqrt2<2)
```

于是 $(n,k)$ 是分母更小的同类解。正整数不能无限下降（well-ordering），矛盾。

版 1 与版 3 等价——版 1 里"可以假设既约"这个动作，理由本身就得用 well-ordering。

### 证明到底用了什么（这是"为什么"的正解）

只有两样东西：

1. **整数可以唯一分解成素数之积**（算术基本定理），因此"某素数 $p$ 的指数" $v_p$ 是良定义的。
2. **$d$ 不是完全平方 ⇒ 存在素数 $p$ 使 $v_p(d)$ 为奇数。**（对 $d=2$，取 $p=2$，指数 $=1$。）

所以真正的定理不是"$\sqrt2$ 无理"，而是：

> **对正整数 $d$，$\sqrt d$ 是有理数 $\iff d$ 是完全平方数。**

- $\Leftarrow$：$d=s^2$ ⇒ $\sqrt d=s\in\mathbb Z$，有理。
- $\Rightarrow$：取 $p$ 使 $v_p(d)$ 奇，则 $v_p(m^2)$ 偶而 $v_p(dn^2)=v_p(d)+2v_p(n)$ 奇，矛盾。

这条升级几乎零成本（同一模板换一个素数），而且它解释了"$\sqrt4$ 为什么不是反例"。用奇偶论证去看 $d=4$：$m^2=4n^2$ ⇒ $m$ 偶，$m=2k$ ⇒ $4k^2=4n^2$ ⇒ $n=k$，**没有任何矛盾**；用 $v_2$ 看：两边指数都是偶数，也不矛盾。分水岭不在 $d$ 长得"整齐不整齐"，而在**质因数指数是否全为偶**。

实测（脚本 §A2）：$d\in\{2,3,5,6,7,8,10,11\}$ 在 $n\le10^5$ 内 $dn^2$ 从不是完全平方（$0$ 个解）；$d\in\{4,9,16,25\}$ 则**每一个** $n$ 都给出平方（最小例子 $m=2,3,4,5$）。

> **一般化的代价（一句话交代）**：完整版是 $p$-adic valuation $v_p$ 与 $\mathbb Q_p$ 上的理论，它把"每个素数一套记账"统一成一个框架。这里用不上——我们只需要"数 2 的指数"这一个初等操作，引入 $\mathbb Q_p$ 不会让证明更短。**在 $\mathbb Z$ 上讲完就够。**

## Q3 现实承重 + 消失测试

$\sqrt2$ 无理性本身不"实现"任何功能，但它锁死了一条工程事实：**有理数 ≡ 有限信息可精确表示**。三个承重位置：

### 承重 1：IEEE 754 的 `squareRoot` 必须规定舍入方向

IEEE 754-2019 把 `squareRoot` 列为**必须正确舍入**（correctly rounded）的操作：硬件不许"算个近似糊过去"，必须返回把精确值 $\sqrt x$ 舍到最近可表示数的那个结果。这条规范之所以必须存在且必须写成"正确舍入"，根因是：$\sqrt2$ 在任何有限精度二进制格式里都不可表示（有限精度数 = 分母为 $2^k$ 的有理数）。x86-64 上它落成单条 `SQRTSD`。

**消失测试**：若 $\sqrt2$ 是有理数且分母适中，标准可以直接写"$\sqrt2$ 的精确值 = 某分数"，舍入条款就成了空话，`x*x == 2` 会返回 `True`。实测：`math.sqrt(2.0)**2 - 2 = 4.44e-16`，恰好是 $2^{-51}$；`x**2 == 2.0` 为 `False`。

### 承重 2：精确算术库的能力边界

`fractions.Fraction`（CPython `Lib/fractions.py`）只能表示有理数。要拿 $\sqrt2$ 的精确值，必须换成符号承诺（`sympy.sqrt(2)`）或代数数类型。"有理数闭包在 $+,-,\times,\div$ 下"这句话的补集，就是所有精确算术库必须承认的失败点。

实测：`Fraction(math.sqrt(2.0))` 给出精确有理数 `6369051672525773/4503599627370496`，其平方是 `2.0000000000000004` —— **任何有限表示都是"错的那个数"**，误差不为零，只可缩小。

### 承重 3：连分数 = 有理逼近的最优速度

$\sqrt2=[1;2,2,2,\dots]$，收敛子 $3/2,\ 7/5,\ 17/12,\ 41/29,\ 99/70,\ 239/169,\ 577/408,\ 1393/985$。误差有闭式：由 Pell 型 $p^2-2q^2=\pm1$，

```math
\left|\sqrt2-\frac pq\right|=\frac{|p^2-2q^2|}{q^2\left(\frac pq+\sqrt2\right)}=\frac{1}{q^2\left(\frac pq+\sqrt2\right)}\ \longrightarrow\ \frac{1}{2\sqrt2\,q^2}\approx\frac{0.3536}{q^2}
```

实测八行 $q^2\cdot|\text{误差}|$ 全部落在 $0.3536$（$q=985$ 时为 $0.3536$）。

**消失测试**：若 $\sqrt2$ 有理，分母有限 ⇒ 存在 $q$ 使误差恰为 $0$，$q^2\cdot\text{误差}$ 会**掉到 0 而不是稳定在 $0.3536$**。这个"稳定不动的常数"就是"分母有限"这条限制被量化后的指纹。它承重于一切"用小的整数比近似无理比"的场合：采样率比、屏幕长宽比、齿轮比、十二平均律（见 L2）。

## Q4 拓展进阶（四层坐标）

### L1 上游
- **算术基本定理**（唯一分解）是全部三版证明的地基。抽掉它，$v_p$ 就不良定义，版 2 直接失效。
- **well-ordering（正整数不能无限下降）** 是版 3 的地基，也是"可以假设既约"的合法性来源。抽掉它，版 1 的第一步就没有理由。
- 对照实验（自己就能做）：同样的下降论证搬到 $\mathbb Q$ 上立刻崩——$\mathbb Q$ 里没有最小正元。**这正是为什么必须先把 $m,n$ 归一化成互素整数。**

### L2 平行
- **$\varphi=(1+\sqrt5)/2$**：连分数 $[1;1,1,\dots]$，最慢逼近，$q^2\cdot\text{误差}\to1/\sqrt5=0.4472$（实测 $0.4472138$）。Hurwitz 定理说 $1/\sqrt5$ 是这个常数能做到的最好值，$\varphi$ 是极值情形，$\sqrt2$ 只是 $1/(2\sqrt2)=0.3536$。同一族二次无理数，同一套 Pell 机制。
- **音乐（十二平均律）**：八度用 $2$ 分十二份，每个半音 $2^{1/12}$；纯五度是 $3/2$。实测 $1200\log_2(3/2)=701.955$ cents，与十二平均律的 $700$ cents 差 **$1.955$ cents**，纯四度同样差 $1.955$。这个"永远差一点"就是"$\log$ 把有理比映成无理比"的听觉版本——调音师撞的是同一个事实。
- **几何原版**：正方形对角线与边不可公度（incommensurable）。这是公元前 5 世纪希腊人撞上的版本，比代数版更早。

### L3 实现
- x86-64 `SQRTSD`：IEEE 754 正确舍入，单指令。规范依据 IEEE 754-2019 §5.4.1（`squareRoot` 属 correctly-rounded 操作）；指令语义见 Intel SDM Vol.1/Vol.2 `SQRTSD` 条目。
- CPython：`math.sqrt` → `Modules/mathmodule.c` 的 `math_sqrt` → C 库 `sqrt`；有理数是 `Lib/fractions.py` 的 `Fraction`；符号根是 `sympy.core.power`。
- 想读源码：`python -c "import fractions,inspect;print(inspect.getsource(fractions.Fraction.__new__))"`。

### L4 前沿 / 今天能做的验证
- **形式化**：Lean 4 + Mathlib 里 `irrational_sqrt_two` 是现成定理（本机 Lean 4.32.2 已装，但 Mathlib 未拉，需要数 GB clone，网络不稳——**待做**）。
- **代数 vs 超越**：$\sqrt2$ 是 algebraic（次数 2，根为 $x^2-2$），不是 transcendental；$e^{\alpha}$ 对代数 $\alpha\neq0$ 超越（Lindemann–Weierstrass）。这条链把"无理性"分成两级难度。
- **可复现实验**：见「验证脚本」一节，$2\times10^6$ 穷举 + 连分数误差常数 + 浮点残差。

## 历史坐标（来源分级）

- 公元前 5 世纪毕达哥拉斯学派"万物皆数（$\mathbb Q$）"因此崩塌；**Hippasus 因泄密被投海是传说，来源等级 D（口传）**，不可当史实。
- **Euclid《Elements》X.117** 的奇偶证明是通行教材版；现代学者（Heath 译本注）普遍认为该条为后人增补，**真伪有争议，B/C 级**。
- Theodorus 证明过 $\sqrt3$ 到 $\sqrt{17}$ 的无理性（柏拉图《Theaetetus》转述，C 级）。
- 实数系的严格基础要等到 **Dedekind 1872 的 cut**：在此之前，欧多克索斯的比例论（Eudoxus, 《Elements》V）是"不直接面对无理数"的绕行方案。这正是 100b 实分析开端要重建的东西。
