## Q1 本质：一句可判真假的话

> **"定理 $T$ 只依赖度量三公理"** 断言的是：**存在一份 $T$ 的推导（一棵有限树），它的语法叶子只贴上背景公理与 M1、M2、M3 —— 一个可以用逐行检查算出来的句法事实**；而 **"$T$ 不限制度量"** 断言的是：**存在一个违反某条度量公理、且使 $T$ 为假的模型 —— 一个必须造出来的语义对象**。

**为什么这句是断言而不是描述**：它可被反例杀死。反例有两种，恰好对应两半：

- 若能出示一份 $T$ 的推导，其中某行实质用了"有限集必有最大元"却不在背景清单里 ⇒ **上界这一半被推翻**（审计表错了一行）。
- 若能出示一个满足 M1–M3 却使 $T$ 为假的 $(X,d)$ ⇒ **"依赖"这一半被推翻**（$T$ 根本不是三公理的推论）。

**删掉修饰词之后它还剩下什么**（这一步能反推出全部技术内容）：

| 剩下的成分 | 长出来的技术对象 |
|---|---|
| "一份推导" | 证明树 $\pi$、依赖集 $D(\pi)$、引理递归展开 |
| "只贴上背景与 M1–M3" | 三排序签名 + 背景理论 $T_{\mathrm{bg}}$ + 判据 $D(\pi)=\varnothing$ |
| "算得出来" | 审计的终止性（每行四类）+ 线性于证明长度的扫描 |
| "违反某条公理而 $T$ 为假" | 坏世界（pseudometric / quasimetric / semimetric）与逐条验公理 |

**它不是什么**（三个常见误读，都是"名词搬运"）：

1. 不是"$T$ 在实数上成立，所以在度量空间上也成立"。方向反了：**只有审计通过，迁移才被许可**。
2. 不是"$T$ 的证明里没有出现序/代数符号"。**出现**与**消费**是两件事（链接器的假阳性）。
3. 不是一个可以脱离**具体表述**回答的问题。同一句人话，两种形式化，两个依赖集（见 Q2 的账本第 2、3 行）。

## Q2 公式：最小充分形式

### 2.1 判据 v2（能推出"迁移"的最弱形式）

固定签名与背景：sort $X$（点，其上无专有符号）、sort $\mathbb R$（值域）、sort $\mathbb N$（指标），唯一跨 sort 符号 $d:X\times X\to\mathbb R$；**硬纪律：$T_{\mathrm{bg}}$ 中不得出现任何 sort-$X$ 的符号或量词**（否则"背景"就成了偷渡通道）。则

```math
T\ \text{只依赖度量三公理}\quad:\Longleftrightarrow\quad \exists\,\pi:\quad T_{\mathrm{bg}}+\{\mathrm{M1},\mathrm{M2},\mathrm{M3}\}\ \vdash\ T,\qquad D(\pi)=\varnothing ,
```

其中 $D(\pi)$ 是 $\pi$ 中出现的、**不属于 $T_{\mathrm{bg}}$** 的非逻辑公理集合（引理递归并入），$\pi$ 为**多类一阶**推导。

**迁移桥**（这才是"倚赖三公理 ⇒ 处处成立"的那一步）：

```math
\forall\Sigma\,\forall\pi\,\forall T:\quad \bigl(\pi\ \text{是}\ \Sigma\ \text{中}\ T\ \text{的证明}\bigr)\ \Longrightarrow\ \bigl(\forall\mathcal M\models\Sigma:\ \mathcal M\models T\bigr).
```

取 $\Sigma=T_{\mathrm{bg}}\cup\{\mathrm{M1,M2,M3}\}$ 即得：**对每个满足三公理的 $(X,d)$，$T$ 都真**。这是可靠性（soundness）的**相对化**版本 —— 它量化的对象是**可变的公理集**，不是固定系统里的某个证明。

### 2.2 符号现实化（逐符号；写不出来的符号 = 还没懂它为什么在那）

| 符号 | 数学身份 | 现实所指 | 失效条件（敏感性） |
|---|---|---|---|
| $d$ | 唯一的空间专有函数 | 「来源 → 目标的代价」，其余一律不许出现 | 一旦为了造新度量引入范数/图/测度 ⇒ **签名扩大**，判据不适用 |
| $\pi$ | 证明（有限树） | 一份**写下来的**推导 | 换一种写法 ⇒ 换一个 $D(\pi)$（账本第 2、3 行） |
| $D(\pi)$ | 叶子上超出底座的公理集 | 「未解析引用表」 | 定义展开时会把右侧符号全引进来 ⇒ 偷渡 |
| $T_{\mathrm{bg}}$ | 背景理论（完备有序域 + 组合基元） | 「一直免费在场」的那一层 | 一旦包含 sort-$X$ 的东西 ⇒ 判据空转/自证 |
| $\mathcal M$ | 模型（某个具体的 $(X,d)$） | 一个"坏世界"就是能跑的反例 | 造完必须逐条验证其余公理，否则反例只是断言 |
| $\varepsilon/2>0$、$\max$、$1/N<\varepsilon$ | $\mathbb R$ 的算术与序 | 背景（免费）或阿基米德性（要记账） | 背景清单没写清 ⇒ 读者无法自己判边界 |

**敏感性一句话**：**哪个符号最容易被悄悄换掉，结论就崩在那一处 —— 是 $T_{\mathrm{bg}}$（背景清单），不是三条公理。** 旧稿最脆的两处（背景泄漏、参数顺序）都长在这里。

### 2.3 账本：把判据跑在四条定理上

| 定理 | 上界 $D(\pi)$（读证明） | 下界（造世界） | 判决 |
|---|---|---|---|
| 极限唯一性 | $\{\mathrm{M1},\mathrm{M2},\mathrm{M3}\}$ | 删 M1 / M2 / M3 各一个坏世界 | **公理基恰为三条**（唯一闭合的案例） |
| 收敛 ⇒ 有界（**球形式**） | $\varnothing$ | 不存在反例 | 对**任意** $d:X^2\to\mathbb R$ 成立 ⇒ 它**不是**度量定理 |
| 收敛 ⇒ 有界（**直径形式**） | $\{\mathrm{M2},\mathrm{M3}\}$ | —— | 同一句人话，另一个依赖集 |
| 球是开集 | $\{\mathrm{M3}\}$ | 删 M3 即失效 | M3 那一族估计是几何的全部 |

**第 2、3 行是整份笔记的"啊哈"位置**：自然语言「收敛列有界」只有一种说法，形式化有两种（球形式 $\exists c\,\exists R\,\forall n: d(x_n,c)\le R$；直径形式 $\exists M\,\forall m,n: d(x_m,x_n)\le M$）。球形式零依赖；直径形式从球形式推过去要补两行：

```math
d(x_m,x_n)\le d(x_m,a)+d(a,x_n)=d(x_m,a)+d(x_n,a)\qquad[\text{M3 然后 M2}]
```

于是"这条定理依赖几条公理"这句话，在固定**表述 + 证法**之前是病句。这不是抬杠：它说的是 —— **形式化是一次设计决策，你选哪种表述，就是在选择愿意为度量结构付多少钱**（想让结论对最多空间成立，选球形式；想强调它要对称与三角，选直径形式）。

### 2.4 三个坏世界（下界的最小充分构造）

- **删 M1 的定性半**：$d\equiv0$（pseudometric）⇒ 每个序列收敛到每个点。**注意删的只是"$d=0\Rightarrow x=y$"这一半**：伪度量仍是非负的，因为非负性可由 `dist_self` + `dist_comm` + `dist_triangle` 推出（源码实证见 Q3 承重 1 的最后一条）。这一点不精确，坏世界就白造了。
- **删 M2**：$X=\{a,b\}$，$d(a,a)=d(b,b)=0$，$d(a,b)=0$，$d(b,a)=1$ ⇒ 常序列 $a,a,\dots$ 同时收敛到 $a$ 与 $b$。
- **删 M3**：$X=\{a,b\}\cup\{u_n:n\ge1\}$，$d(a,u_n)=d(b,u_n)=1/n$，$d(a,b)=1$，$d(u_m,u_n)=|1/m-1/n|$，其余自距离 $0$。逐条验：M1 ✓、M2 ✓、**M3 在 $n\ge3$ 失败**：

```math
d(a,b)=1\ >\ \frac1n+\frac1n=d(a,u_n)+d(u_n,b)\qquad(n\ge3),
```

而 $d(u_n,a)=d(u_n,b)=1/n\to0$ 且 $a\ne b$ ⇒ 极限不唯一。**上界 = 下界 = 三条。**

## Q3 现实承重：谁真的靠"只依赖三公理"活着

固定句式：`<机制> 承重于 <系统> 的 <功能>`，每条配**消失测试**（组件 + 功能 + 退化后的可观测后果）。

### 承重 1：`MetricSpace` 这个 typeclass —— 承重于「一次证明，所有实例复用」

- **组件 + 功能**：Lean/mathlib 的 `MetricSpace` 是 typeclass，**M1–M3 就是它的字段**，而且它把"删掉 M1 的定性半"直接做成了**类型层级**。源码坐标（`leanprover-community/mathlib4` master，本次用 `curl raw.githubusercontent.com` 实取核对）：
  - `Mathlib/Topology/MetricSpace/Pseudo/Defs.lean:140`：`class PseudoMetricSpace (α : Type u) : Type u extends Dist α`，三条字段紧接其后 —— `dist_self : ∀ x : α, dist x x = 0`（:141）、`dist_comm : ∀ x y : α, dist x y = dist y x`（:142）、`dist_triangle : ∀ x y z : α, dist x z ≤ dist x y + dist y z`（:143）。
  - `Mathlib/Topology/MetricSpace/Defs.lean:70`：`class MetricSpace (α : Type u) : Type u extends PseudoMetricSpace α where`，比伪度量**只多一条** `eq_of_dist_eq_zero`（即 M1 的定性半 $d(x,y)=0\Rightarrow x=y$）。
  **这正是 Q2.4「删 M1 的定性半」那个坏世界的机器版**：`PseudoMetricSpace` 不只是教学玩具，它是 `C(X,Y)`、半范数空间、以及一切商构造的中间层 —— 删掉一条公理得到的对象，正是生产代码里被复用最多的那个。
- **消失测试**：删掉抽象（每个空间各写一遍）⇒ 定理数量从"一份 × 实例数"变成"实例数份"，可观测后果是行数与维护成本线性膨胀，以及**改口径时漏改一处**。反过来把 M3 从字段里删掉 ⇒ 大量下游定理**无法通过类型检查**（`failed to synthesize instance`）—— **这是少数会当场"报错"的失败形态**，也是公理审计在工程里最强的形态。
- **一条与账本互相印证的源码事实**：`Pseudo/Defs.lean:113-118` 用
  `0 = dist x x ≤ dist x y + dist y x = 2 * dist x y`
  把**非负性**从另外三条推出来（只用了 `dist_self`、`dist_triangle`、`dist_comm`）。这从工程侧印证了 §2.3 账本第 1 行的精确归因：M1 里真正被消费的是**定性半**，而"非负"可由 M2+M3 推出，不必单独记账。

### 承重 2：Dijkstra / 最短路 —— 承重于「非负权的贪心正确性」

- **组件 + 功能**：优先队列 + relax 操作；功能是"已确定顶点的距离单调不减"，这条正是 **M3 型不等式**（绕路不短于直达）在算法侧的化身。
- **别把两件"非负"混成一件**（这是本笔记最容易翻车的一处）：Dijkstra 要的是**边权非负**（图的属性，`weight >= 0` 检查），而不是**度量的非负性**（后者可由 M2+M3 推出，见 Q3 承重 1）。M3 给的是"绕路不短于直达"，它保证的是**沿路径拼接距离不减**；负权边破坏的正是这一步。
- **消失测试**：允许负权（等价于删掉那族单侧估计）⇒ 已定顶点会被后续路径改小，输出不再是距离，且**不报错**：你会拿到一条"看起来合理"的路径。可观测后果：CLRS 里必须改用 Bellman–Ford，复杂度从 $O((V+E)\log V)$ 退化到 $O(VE)$。
- 坐标：CLRS Ch.24（单源最短路）与 6.006 L15–L17；拟度量版本（有向图，$d(u,v)\ne d(v,u)$）见 `networkx` 的 `DiGraph` 分支。

### 承重 3：度量索引（KD-tree / Ball-tree / VP-tree）的剪枝 —— 承重于「M3 让剪枝合法」

- **组件 + 功能**：候选集剪枝；正确性前提是三角不等式（"若 $d(q,c)-r>d(q,x)$ 则整个球可剪"）。
- **消失测试**：距离不满足 M3（浮点距离、学出来的近似相似度）⇒ **剪枝丢召回**，无异常、无日志，只是结果变少。这是"缺一条公理"在生产系统里最典型的形态：**没有异常，只有错误的答案。** 可观测后果：召回率下降而延迟不变（因为照样跑完了剪枝）。
- 坐标：`scipy.spatial.cKDTree`；`sklearn.neighbors` 的 `metric` 参数（工程上把 "metric" 与 "distance" 分开，正是本文判据的工程化）。

### 承重 4（反向承重）：DTW 相似度搜索 —— 缺 M3 的账单是「必须另造下界」

前三条都是"有 M1–M3 所以能复用"。这一条反过来：**一个真实系统因为没有 M3，被迫在算法层付一笔额外的构造费** —— 它把"三角不等式是承重项"从断言变成账单。

- **组件 + 功能**：时间序列相似度检索（DTW 距离）的候选剪枝；DTW 的朴素计算是 $O(n^2)$，检索必须在剪枝层省掉绝大多数距离计算。
- **事实（A 级，两处独立）**：DTW **不满足**三角不等式。Keogh & Ratanamahatana 因此不能像欧氏距离那样直接用三角剪枝，只能造 envelope 型下界 LB_Keogh，并**证明它确实是下界**（否则会漏报）；Lemire 的复述更直白：*"The DTW fails to satisfy the triangle inequality and its computation requires quadratic time. Hence, to find closest neighbors quickly, we use bounding techniques."*
- **定量后果**：LB_Keogh 把"对每个候选都算 $O(n^2)$ 的 DTW"降成"先算 $O(n)$ 的下界、只对少数候选算精确 DTW"；Ratanamahatana–Keogh 报告其在多个数据集上可**剪掉 90% 以上**的 DTW 计算（Lemire 的论文复述了这一数字）。
- **消失测试（两种方向，都成立）**：
  1. 若强行假定 M3 成立、直接套三角剪枝 ⇒ **静默漏报**：不报错、不抛异常，只是少返回真邻居。这与"度量索引剪枝"那条同型，但更危险，因为 DTW 场景里没有类型检查拦你。
  2. 若下界没被证明（只"看起来像"下界）⇒ 同样是静默漏报，而且更难查：错误依赖数据集分布。
- **这正是本条存在的理由**：`M-tree`（Ciaccia–Patella–Zezula, VLDB 1997）一类的 metric index，其剪枝判据**本身就是三角不等式**；而 non-metric 空间的检索文献（如 NeurIPS 2013《Learning to Prune in Metric and Non-Metric Spaces》）要给"非度量"另配一套剪枝函数。**同一件事的两种写法：在度量世界里三角不等式免费提供剪枝；离开它就得自己造一个可证的下界。**
- **还值得记一笔的活跃证据**：连"余弦相似度能不能当距离用"这件事，直到 SISAP 2021 才有人补出完整三角不等式（E. Schubert, *A Triangle Inequality for Cosine Similarity*）—— 说明"缺一条公理就得补一次"不是历史遗迹，是仍在进行中的工程工作。
- **仍然 `[未定位]` 的部分**（不许含糊掉）：一条"某业务系统的业务指标因为三公理而改善"的因果链，我查不到可引的一手材料；上面这一切都停在"库 / 算法 / 检索结构"层面。

## Q4 拓展进阶：四层坐标

### L1 上游：它依赖哪条更基本的事实

- **相对可靠性 + 证明树的结构归纳**：抽掉可靠性，"$D(\pi)=\varnothing$"只是一张纸；抽掉"树有限"，审计不再终止。
- **Gödel 1929 完备性定理**：$\Gamma\vdash\varphi\iff\Gamma\models\varphi$，保证"处处真"与"能证"等价 —— 这才是"逐行审计恰好充分"的真正依据（不是"我觉得够了"）。**注意与"度量空间的完备性"同名不同物**。
- **等距不变性/不可定义性**：无参数的 $\mathcal L_d$-可定义概念在等距下不变（automorphism invariance 的标准形态），其历史源头是 Padoa 1900 的不可定义性方法。[A] Hodges, *Tarski on Padoa's method*。

### L2 平行：另一个领域里同构的机制

- **CSAPP 第 7 章链接器**：证明 = 目标文件，公理 = 库符号，$D(\pi)$ = 未解析引用表。**失效点必须记**：链接器解析**名字**且可判定；数学依赖是**语义的**，于是有两类泄漏 —— 假阳性（提到没用）与假阴性（用了却没有名字）。修法就是 $T_{\mathrm{bg}}$ 的明文清单。
- **6.042J 偏序**：理论按 $\subseteq$ 排；"只依赖" = 上界；精确公理基 = 最小上界；独立性 = 严格不等式。**可判定性在这里丧失**：有限偏序看两眼就能判序，无穷理论之间"这份证明真的需要 M2"必须造模型 —— 这就是"反例是证书"的深层原因。
- **Lawvere 富化范畴 [A]**：度量空间 = 在 $[0,\infty]$ 上富化的范畴，三角不等式 = composition，$d(x,x)=0$ = identity。删 M2 = 换 enrichment base（非对称富化）⇒ "拟度量"从怪例子变成另一个 base 上的正常对象。[nLab `metric on a category`](https://ncatlab.org/nlab/show/metric+on+a+category)。

## 5. 五条疑问：原话 → 当时的答法 → 现在能站住的答法

这一节是本文的正文。**只有与"只依赖"这件事直接相关的疑问才入列**；度量空间自身的疑问（子空间、三角不等式出身、欧氏距离验证、$\varepsilon$ 与序、完备性、$d$ 的位置）已解决，不入列。

### 疑问 A｜「怎么证明只要该度量符合度量定义，数学工具就能迁移？」

> 原话（`DS#71645`）：「呃，怎么证明只要该度量符合度量定义，数学工具就能迁移？我的意思是，怎么证明一个工具只依赖于这三个条件？只要满足这三个条件就能使用的数学工具有哪些？有什么特征？」

**当时的答法**：五步操作法（抽象公理 → 重写证明 → 验证只用公理 → 若用了序就标"需额外结构"）+ 两张清单（可迁移 / 不可迁移）。**这是工程回答，把两个不同的问题混成了一个**：①"工具能迁移"（语义）②"工具只用三公理"（句法）。

**现在能站住的答法**：这两问必须拆开，各配一台机器 ——

- 句法机器：$D(\pi)$（Q2.1）。
- 语义机器：**相对可靠性**（Q2.1 的迁移桥）。

桥的接通方式值得单说一句：**这个归纳只做一次**。它是逻辑学的元定理，不需要为每个具体空间重跑 —— 所以"逐行检查"不是"每个空间各证一遍"的缩写，它是可靠性的**可操作版本**。

**残余风险（这才是当年答漏的部分）**：桥有两个前置条件，缺一个就悬空 ——① $T$ 的**陈述本身**必须属于度量语言（否则在一般 $(X,d)$ 里连解释都无定义）；② 背景必须明文（否则审计表无从填起）。

### 疑问 B｜「你这不就是循环论证？凭什么用'每步是否用到公理'去证'只依赖公理'？」

> 原话（`DS#73306`、`DS#73451`、`DS#74331`）：「为什么？自己定义的东西，循环定义？你这里证明有问题吧」→「你凭什么这么定义？你没证明」→「你没有从第一性原理来说明为什么这样证明」。

这条是全篇最硬的一次质疑，而且是**对的**。三句话拆掉它：

**(a) 检查是句法的，不是语义的。** 审计算的是 $D(\pi)$ 与 $\varnothing$ 的包含关系，**全程不预设 $T$ 的真假**。循环论证的形态是"结论混进前提"；这里结论只出现在树的**根**，每一行的合法性由比它更基本的东西保证。类比：链接器检查一个函数引用了哪些符号，它既不运行程序，也不假设程序正确；而"只用接口写的代码在所有实现上都跑得通"由语言语义背书。

**(b) 检查必然终止。** 每一行只有四类可能：纯逻辑规则 / 引用已入库引理（其依赖早已查过，归纳假设）/ 引用公理（逐条对表）/ 定义展开（**这一类有陷阱**，见 §6 第 3 条）。四类都在叶子处终结，证明树有限 ⇒ 审计是有限步的机械计算。**"引理查一次、永久入库"正是公理化方法防无限回溯的机制。**

**(c) 句法到语义的那一步不在审计里，在可靠性定理里。** 审计只负责"这份证明没有多要"；"没有多要 ⇒ 处处成立"是可靠性的工作。反过来（处处真 ⇒ 能证）由 Gödel 1929 完备性定理负责，而它的适用范围正是"可递归枚举的一阶系统" —— 我们的 $T_{\mathrm{bg}}+\{\mathrm{M1,M2,M3}\}$ 恰好在内。

**一句话诊断**（旧稿卡点 1 的原句，值得抄页边）：

> **可靠性不是桥本身；它是桥的另一岸。这一岸是句法事实（$D(\pi)$ 由证明树形状算出），对岸是语义结论（在所有模型里为真）。**

### 疑问 C｜「如何证明某条定理（某些概念）只依赖这三个公理？」

> 原话（`DS#71812`、`DS#71984`、`DS#75572`）：「如何证明实数轴上的这些定理本质上只用了这三个公理」→「如何证明你刚刚说的很多概念都只依赖于这三个公理？」→「我不接受任何除了公理以外的东西出现在你的前提里，一切从头证明，除非是公理」。

最后一句是你自己给出的纲领，且它与判据 v2 严格同构：**允许的原料必须写在清单上，清单外的一律入账。**

**当时答法的问题**：把"概念"与"定理"混在一起答（定义层用"概念的定义只用到 $d$"，定理层用"逐行替换"）。两层必须分开，因为它们的**检验手段不同**：

| | 概念层（可定义性） | 定理层（可证性） |
|---|---|---|
| 问法 | 这个概念说得出口吗？ | 这条定理证得出来吗？ |
| 手段 | 给一个 $\mathcal L_d$ 公式；或用**等距不变**快速否证 | 逐行审计 $D(\pi)$ |
| 失败形态 | 死在**表达层**（单调、可微、介值原形） | 说得出口但证不出来（完备、紧致、连通） |
| 免费否证器 | 不是等距不变的 $X$-概念 ⇒ 一定不是（无参数的）$\mathcal L_d$-可定义 | 造出反例模型 ⇒ 一定证不出来 |

**上界（审计）的四类行，配决策树**。把第 2 步写成可走的一棵树：

```text
○  这一步提到 d 了吗？
├─ 否 ─→ ◇【背景：逻辑 / ℝ 算术 / 有限组合】
│         └─ 是「未声明的背景」吗？（完备性 / 阿基米德 / sup 存在 / X 上带序）
│              └─ 是 → █ 越界：写进 T_bg 清单，或记入 D(π)
└─ 是 ─→ ○  d 以什么形式出现？
          ├─ d(x,x)=0 或 (d(x,y)=0 ⟹ x=y)     ─→ ▣ M1
          ├─ d(x,y)=d(y,x)（参数对换）          ─→ ▣ M2   ⚠ 写法不一致会在此偷渡
          ├─ d(x,z) ≤ d(x,y)+d(y,z)（三段链）   ─→ ▣ M3
          └─ ∀ε>0 与 d<ε                        ─→ ◇【背景：ℝ 的序 + ℕ】
               └─ 追问「这个 N 从哪来？」
                    ├─ 只靠「有限项取 max」「ε/2 仍是正数」 → ✓ 背景
                    └─ 靠阿基米德性 / 完备性 / 确界存在      → █ 越界，标红

合并规则：D(节点) = ∪ D(子节点)      树根输出 D(π)
```

**三个高危泄漏点（比成功路径重要）**：

1. **背景泄漏**：`取 N 使 1/N<ε` 在教材里连注释都不配，但它的根据是**阿基米德性** —— 这是 $\mathbb R$ 的结构事实，不是逻辑。要么在背景清单里声明，要么标红。
2. **定义展开偷渡**：展开一个定义会把它右侧的符号全引进证明。右侧若引入 sort-$X$ 上的新结构（序、开集族、测度）⇒ **记入 $D(\pi)$，判据立即失败**。
3. **参数顺序不一致**：收敛写 $d(x_n,a)$、有界写 $d(c,x_n)$，则 M2 会从"两处写法的翻译"里溜进来，$D$ 从 $\varnothing$ 变 $\{M2\}$。

### 疑问 D｜「度量还能自己换？只要满足性质就行？可塑性到哪一步算越界？」

> 原话（`DS#71529`）：「度量还能自己换？只要满足性质就行？那这度量很有可塑性啊，都有哪些应用？」

**当时的答法**：给了应用清单（最短路、汉明、编辑距离……）。**清单对，但没画边界**，而"只依赖度量三公理"这句话的适用范围**恰好由边界决定**。

**三条越界线**（越过后已不在本判据的场景里）：

| 越界线 | 表现 | 后果 |
|---|---|---|
| **签名扩大** | 为了造新度量引入范数、图结构、测度、"$X$ 上带序" | 定理变成"赋范空间/图/测度空间 + 度量"的定理，**不是度量定理** |
| **表达层失效** | 陈述里出现 $x\le y$、$f'$、介值原形 | 在一般 $(X,d)$ 里**说不出来** ⇒ 一行证明都不用读，直接判死 |
| **把结论预置成背景** | 把"$X$ 完备""$X$ 紧致"塞进 $T_{\mathrm{bg}}$ | 自证：判据空转（这是最隐蔽的一种违规） |

**可塑性的正确读法**：不是"度量可以随便造"，而是 —— **每换一次度量，都要重算一次"哪些定理还活着"，而"重算"的合法性来自签名与背景都没变。**

### 疑问 E｜「为什么不能依赖选择公理？」

> 原话（`DS#73744`）：「为什么不能依赖选择公里」（原文如此）。

**这问题问得极准**：它逼你把"逻辑"这一格算清。答案是分层的：

- **免检**（多类一阶逻辑本身）：重言式与命题公理、等词公理、量词规则、结构规则与 cut。它们在**任何**结构里成立，所以不计入依赖。
- **不免检**：二阶逻辑。full second-order validity 不可递归枚举，二阶量词可以定义"有限""$X$ 的完备性"，甚至编码实数结构 —— **二阶逻辑是一台大公理机器**。凡出现"对所有子集 / 对所有序列"，必须**降型**（把序列当 $\mathbb N\to X$ 的函数符号，量词跑在函数值上）或显式记账。
- **必须显式记账**：选择原则（AC/DC）、分离与替换。它们不是逻辑（在某些模型里真、某些里假），**用一次就该记账**。$T_{\mathrm{bg}}$ 里若要放 DC，必须写明。

**诊断句**：**"量词只在点与实数上跑"这句还不充分** —— 还要加上"无界量化不与选择合用"、"分离/替换/选择显式列表"、"$T_{\mathrm{bg}}$ 只约束 sort-$\mathbb R$"三条补充。

## 收束

这份笔记只回答一件事，用两个数字：

- **上界**：读证明，逐行记账 ⇒ 它**没有多要**什么。
- **下界**：造世界，逐条验公理 ⇒ 它**确实需要**什么。

两个数字相等的那一刻，"这条定理只依赖度量三公理"才从一句口号变成一句**结算完毕**的陈述。而这两个动作在方法论上不可互换 —— 上界由读证明得到，下界由造模型得到。
