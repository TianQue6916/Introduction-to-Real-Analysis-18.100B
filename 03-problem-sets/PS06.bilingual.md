# 18.100B Real Analysis · Problem Set 06（问题集 06）

## 术语口径

- **metric space（度量空间）**：一个集合 $X$ 配上一个满足正定性、对称性、三角不等式的距离函数 $d$。易混点：不是所有"距离"都来自欧氏距离，度量空间里没有"原点/加法"，只能谈"距离"。
- **metric / distance（度量 / 距离）**：$d:X\times X\to\mathbb{R}$，满足 $d(x,y)\ge 0$、$d(x,y)=0\iff x=y$、$d(x,y)=d(y,x)$、三角不等式。易混点：度量 $d$ 是抽象的二元函数，不要默认它是 $|x-y|$。
- **triangle inequality（三角不等式）**：$d(x,z)\le d(x,y)+d(y,z)$。易混点：这是验证 $d$ 是否为度量的核心一条，其余两条（正定、对称）通常明显。
- **Cauchy sequence（柯西序列）**：对任意 $\varepsilon>0$，存在 $N$，使 $n,m\ge N$ 时 $d(x_n,x_m)<\varepsilon$。易混点：柯西性只要求"序列自己越靠越近"，与是否收敛到某个点是两回事——这正是"完备性"要弥合的鸿沟。
- **convergence（收敛）**：存在 $x\in X$ 使 $d(x_n,x)\to 0$。易混点：收敛必有极限点在**同一个空间 $X$ 里**；若极限"跑出"了 $X$，就不能说收敛。
- **Cauchy complete（柯西完备）**：空间里每个柯西序列都收敛。易混点：完备性是"柯西 ⇒ 收敛"，$\mathbb{R}$ 完备而 $\mathbb{Q}$ 不完备。
- **open set（开集）**：每一点都有一个含于该集合内的开球。易混点：开集是"度量诱导"的概念，不同度量会给出不同开集。
- **closed set（闭集）**：余集为开集的集合。易混点：闭与开不互斥（既开又闭、既不开也不闭都可能）。
- **compact set（紧集）**：每个开覆盖都有有限子覆盖。易混点：这是 Heine–Borel 使用的原始定义；在 $\mathbb{R}^n$ 中等价于"有界闭"，但在一般度量空间两者不同。
- **open cover（开覆盖）**：一族开集，其并集包含目标集合。易混点：紧性说的是"任意开覆盖都能抽出有限个"，不是"存在一个有限覆盖"。
- **finite intersection property（有限交性质，FIP）**：任意有限个子集交非空。易混点：这是 Problem 5 的核心工具——它刻画了紧性的一个等价说法。

## Problem 1（问题 1）

**题干原文：** Let $X=\{\text{continuous functions defined on }[0,1]\}$ and $d:X\times X\to\mathbb{R}$ be defined by $d(f,g)=\max_{x\in[0,1]}|f(x)-g(x)|$. Show that $d$ satisfies the triangle inequality. In other words, for all continuous functions $f(x)$, $g(x)$ and $h(x)$, $d(f,h)\le d(f,g)+d(g,h)$.

**中文：** 令 $X$ 为定义在 $[0,1]$ 上的全体连续函数，并定义 $d:X\times X\to\mathbb{R}$ 为 $d(f,g)=\max_{x\in[0,1]}|f(x)-g(x)|$。证明 $d$ 满足三角不等式。换言之，对任意连续函数 $f(x)$、$g(x)$、$h(x)$，都有 $d(f,h)\le d(f,g)+d(g,h)$。

**证明：** 这里 $d$ 就是所谓的 **uniform metric（一致度量）**，也常写成 $\lVert f-g\rVert_\infty$（sup norm / 上确界范数）。注意：因为 $[0,1]$ 是 **compact（紧的）** 且 $f,g$ 连续，所以 $|f-g|$ 连续，从而在紧集上取到最大值，故 $\max$（而非 $\sup$）确实存在。

对任意 $x\in[0,1]$，由实数的三角不等式（即绝对值不等式）：

```math
|f(x)-h(x)| = |f(x)-g(x)+g(x)-h(x)| \le |f(x)-g(x)| + |g(x)-h(x)|.
```

对每个 $x$，右边被 $d(f,g)+d(g,h)$ 控制，因为

```math
|f(x)-g(x)| \le \max_{t\in[0,1]}|f(t)-g(t)| = d(f,g),
```

```math
|g(x)-h(x)| \le \max_{t\in[0,1]}|g(t)-h(t)| = d(g,h).
```

于是对任意 $x\in[0,1]$，

```math
|f(x)-h(x)| \le d(f,g) + d(g,h).
```

这说明常数 $d(f,g)+d(g,h)$ 是集合 $\{|f(x)-h(x)|:x\in[0,1]\}$ 的一个上界。上确界是最小上界，而最大值等于上确界，故

```math
d(f,h) = \max_{x\in[0,1]}|f(x)-h(x)| \le d(f,g)+d(g,h).
```

这正是要证的三角不等式。∎

## Problem 2（问题 2）

**题干原文：** Let $X=\mathbb{N}=\{1,2,3,\dots\}$ and $d:X\times X\to\mathbb{R}$ defined by $d(n,m)=\left|\tfrac1n-\tfrac1m\right|$. (1) Show that the sequence $x_n=5n$ is a Cauchy sequence. (2) Show that the sequence $x_n=5n$ doesn't converge. As a result, this metric space is not Cauchy complete.

**中文：** 令 $X=\mathbb{N}=\{1,2,3,\dots\}$，定义 $d:X\times X\to\mathbb{R}$ 为 $d(n,m)=\left|\tfrac1n-\tfrac1m\right|$。(1) 证明序列 $x_n=5n$ 是柯西序列。(2) 证明序列 $x_n=5n$ 不收敛。由此，这个度量空间不是柯西完备的。

**证明：**

**(1) 证明 $x_n=5n$ 是 Cauchy sequence：**

对 $n,m\in\mathbb{N}$，有

```math
d(x_n,x_m)=d(5n,5m)=\left|\frac1{5n}-\frac1{5m}\right|\le\frac1{5n}+\frac1{5m}.
```

任给 $\varepsilon>0$。取 $N$ 为一个满足 $\frac1{5N}<\frac{\varepsilon}{2}$ 的整数，例如取 $N>\frac{2}{5\varepsilon}$（即 $N=\left\lfloor\frac{2}{5\varepsilon}\right\rfloor+1$）。则当 $n,m\ge N$ 时，$\frac1{5n}\le\frac1{5N}<\frac{\varepsilon}{2}$，$\frac1{5m}\le\frac1{5N}<\frac{\varepsilon}{2}$，于是

```math
d(x_n,x_m)\le\frac1{5n}+\frac1{5m}<\frac{\varepsilon}{2}+\frac{\varepsilon}{2}=\varepsilon.
```

故 $x_n=5n$ 是 Cauchy sequence。∎

**(2) 证明 $x_n=5n$ 不收敛：**

用反证法。假设 $x_n=5n$ 在度量空间 $(\mathbb{N},d)$ 中收敛到某个 $a\in\mathbb{N}$，即

```math
\lim_{n\to\infty} d(5n,a)=0,\quad \text{即}\quad \lim_{n\to\infty}\left|\frac1{5n}-\frac1a\right|=0.
```

当 $n\to\infty$ 时 $\frac1{5n}\to 0$，故上式要求 $\left|\frac1a\right|=0$，即 $\frac1a=0$，这不可能（$\frac1a>0$ 对任何 $a\in\mathbb{N}$）。更严格地说：取 $\varepsilon_0=\frac1{2a}>0$，则对充分大的 $n$（使 $\frac1{5n}<\frac1{2a}$），有

```math
\left|\frac1{5n}-\frac1a\right|=\frac1a-\frac1{5n}>\frac1a-\frac1{2a}=\frac1{2a}=\varepsilon_0,
```

与收敛定义矛盾。因此 $x_n=5n$ 不收敛。∎

**结论：** 序列 $5n$ 是柯西的但不收敛，所以 $(\mathbb{N},d)$ 不是 **Cauchy complete**。直观上，柯西序列 $\frac1{5n}$ "想收敛"到 $0$，但 $0\notin\mathbb{N}$，极限落在了空间之外，于是空间不完备。∎

## Problem 3（问题 3）

**题干原文：** In this problem we consider the metric space with $X=\mathbb{R}^2$ and $d((x_1,y_1),(x_2,y_2))=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$. (1) Let $(x_n,y_n)$ be a sequence in $\mathbb{R}^2$. Show that $(x_n,y_n)$ converges if and only if both $x_n$ and $y_n$ converge as sequences of $\mathbb{R}$. (2) Let $(x_n,y_n)$ be a sequence in $\mathbb{R}^2$. Show that $(x_n,y_n)$ is a Cauchy sequence if and only if both $x_n$ and $y_n$ are Cauchy sequences of $\mathbb{R}$. (3) Show that $\mathbb{R}^2$ is Cauchy complete.

**中文：** 本题考虑度量空间 $X=\mathbb{R}^2$，距离为 $d((x_1,y_1),(x_2,y_2))=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$（即欧氏度量 / Euclidean metric）。(1) 设 $(x_n,y_n)$ 是 $\mathbb{R}^2$ 中的序列。证明 $(x_n,y_n)$ 收敛当且仅当 $x_n$ 与 $y_n$ 作为 $\mathbb{R}$ 中的序列都收敛。(2) 设 $(x_n,y_n)$ 是 $\mathbb{R}^2$ 中的序列。证明 $(x_n,y_n)$ 是柯西序列当且仅当 $x_n$ 与 $y_n$ 作为 $\mathbb{R}$ 中的序列都是柯西序列。(3) 证明 $\mathbb{R}^2$ 是柯西完备的。

**证明：**

先记两个基本不等式，它们贯穿整题（都是初等的）：

对任意 $a,b\in\mathbb{R}$，

```math
\max\{|a|,|b|\} \le \sqrt{a^2+b^2} \le |a|+|b|.
```

这两个不等式的含义是：欧氏范数与坐标的 $|a|+|b|$ 范数是**等价范数（equivalent norms）**，都刻画同一套收敛/柯西概念。

**(1) 收敛的等价性：**

$(\Rightarrow)$ 设 $(x_n,y_n)\to(x,y)$，即 $d((x_n,y_n),(x,y))\to 0$。由第一个不等式，

```math
|x_n-x| \le \sqrt{(x_n-x)^2+(y_n-y)^2} = d((x_n,y_n),(x,y)) \to 0,
```

故 $x_n\to x$；同理 $|y_n-y|\le d((x_n,y_n),(x,y))\to 0$，故 $y_n\to y$。

$(\Leftarrow)$ 设 $x_n\to x$ 且 $y_n\to y$。任给 $\varepsilon>0$，因为 $x_n\to x$，存在 $N_1$ 使 $n\ge N_1$ 时 $|x_n-x|<\frac{\varepsilon}{2}$；因为 $y_n\to y$，存在 $N_2$ 使 $n\ge N_2$ 时 $|y_n-y|<\frac{\varepsilon}{2}$。取 $N=\max\{N_1,N_2\}$，则当 $n\ge N$ 时，由第二个不等式，

```math
d((x_n,y_n),(x,y))=\sqrt{(x_n-x)^2+(y_n-y)^2}\le |x_n-x|+|y_n-y|<\frac{\varepsilon}{2}+\frac{\varepsilon}{2}=\varepsilon.
```

故 $(x_n,y_n)\to(x,y)$。∎

**(2) 柯西性的等价性：**

$(\Rightarrow)$ 设 $(x_n,y_n)$ 是 Cauchy。任给 $\varepsilon>0$，存在 $N$ 使 $n,m\ge N$ 时 $d((x_n,y_n),(x_m,y_m))<\varepsilon$。由第一个不等式，

```math
|x_n-x_m| \le d((x_n,y_n),(x_m,y_m))<\varepsilon,
```

故 $x_n$ 是 Cauchy；同理 $|y_n-y_m|\le d((x_n,y_n),(x_m,y_m))<\varepsilon$，故 $y_n$ 是 Cauchy。

$(\Leftarrow)$ 设 $x_n$、$y_n$ 都是 Cauchy。任给 $\varepsilon>0$，存在 $N_1$ 使 $n,m\ge N_1$ 时 $|x_n-x_m|<\frac{\varepsilon}{2}$，存在 $N_2$ 使 $n,m\ge N_2$ 时 $|y_n-y_m|<\frac{\varepsilon}{2}$。取 $N=\max\{N_1,N_2\}$，则当 $n,m\ge N$ 时，由第二个不等式，

```math
d((x_n,y_n),(x_m,y_m))\le |x_n-x_m|+|y_n-y_m|<\frac{\varepsilon}{2}+\frac{\varepsilon}{2}=\varepsilon.
```

故 $(x_n,y_n)$ 是 Cauchy。∎

**(3) $\mathbb{R}^2$ 完备：**

设 $(x_n,y_n)$ 是 $\mathbb{R}^2$ 中任意 Cauchy 序列。由 (2) 的 $(\Rightarrow)$ 方向，$x_n$ 与 $y_n$ 都是 $\mathbb{R}$ 中的 Cauchy 序列。由 **$\mathbb{R}$ 的完备性（Cauchy 完备性定理）**，$x_n$ 收敛到某 $x\in\mathbb{R}$，$y_n$ 收敛到某 $y\in\mathbb{R}$。再由 (1) 的 $(\Leftarrow)$ 方向，$(x_n,y_n)$ 收敛到 $(x,y)\in\mathbb{R}^2$。故 $\mathbb{R}^2$ 中每个 Cauchy 序列都收敛，即 $\mathbb{R}^2$ 是 **Cauchy complete**。∎

## Problem 4（问题 4）

**题干原文：** Let $A_j$, $j\in\mathbb{N}$ be open sets in a metric space $(X,d)$. (1) Show that $\bigcup_{j=1}^{\infty} A_j$ is open. (2) Show that $\bigcap_{j=1}^{\infty} A_j$ may not be open. Hint: Consider $X=\mathbb{R}$ and $A_j=(0,1+\tfrac1j)$.

**中文：** 设 $A_j$（$j\in\mathbb{N}$）是度量空间 $(X,d)$ 中的开集。(1) 证明 $\bigcup_{j=1}^{\infty}A_j$ 是开集。(2) 证明 $\bigcap_{j=1}^{\infty}A_j$ 未必是开集。提示：考虑 $X=\mathbb{R}$ 和 $A_j=(0,1+\tfrac1j)$。

**证明：**

**(1) 任意并集仍是开集：**

设 $x\in\bigcup_{j=1}^{\infty}A_j$，则存在某个 $j_0\in\mathbb{N}$ 使 $x\in A_{j_0}$。因为 $A_{j_0}$ 是 **open set**，由开集定义，存在 $\delta>0$ 使开球 $B_\delta(x)=\{y\in X:d(x,y)<\delta\}\subseteq A_{j_0}$。于是

```math
B_\delta(x)\subseteq A_{j_0}\subseteq\bigcup_{j=1}^{\infty}A_j.
```

这说明并集中的每一点都含有一个完全落在并集内的开球，故 $\bigcup_{j=1}^{\infty}A_j$ 是开集。∎

**要点：** 关键只用到"存在一个 $j_0$"——并集的性质恰好对应"存在"，所以任意多个（甚至不可数多个）开集的并仍是开集。

**(2) 无穷交未必开：反例构造与验证：**

取 $X=\mathbb{R}$，欧氏度量，$A_j=(0,1+\tfrac1j)$，$j\in\mathbb{N}$。每个 $A_j$ 都是开区间，故是开集。

现在算交集。注意 $A_{j+1}\subseteq A_j$（因为 $1+\frac1{j+1}<1+\frac1j$），故这是一个递减的开区间族，其交集为

```math
\bigcap_{j=1}^{\infty}A_j = \bigcap_{j=1}^{\infty}\left(0,1+\frac1j\right) = (0,1].
```

验证如下：若 $0\lt x\le 1$，则对所有 $j$，$x\le 1<1+\frac1j$，故 $x\in A_j$，所以 $(0,1]\subseteq\bigcap_j A_j$；反之若 $x\in\bigcap_j A_j$，则 $x>0$ 且对所有 $j$ 有 $x<1+\frac1j$，令 $j\to\infty$ 得 $x\le 1$，故 $x\in(0,1]$。因此交集确为 $(0,1]$。

现在证明 $(0,1]$ 不是开集：考虑点 $1\in(0,1]$。对任意 $\delta>0$，开球 $B_\delta(1)=(1-\delta,1+\delta)$ 中总含有 $1+\frac{\delta}{2}>1$，而 $1+\frac{\delta}{2}\notin(0,1]$。所以 $1$ 的**任何**开球都不含于 $(0,1]$，故 $(0,1]$ 不是开集。

因此 $\bigcap_{j=1}^{\infty}A_j=(0,1]$ 非开，反例成立。∎

**要点：** 有限个开集的交仍是开集，但**无穷**个开集的交可能不再是开集——本反例正是这个经典事实的体现。

## Problem 5（问题 5）

**题干原文：** Let $(X,d)$ be a metric space, $K$ be a compact set in $X$ and $A_j$, $j\in\mathbb{N}$ be closed sets in $X$. Suppose for all $k\in\mathbb{N}$, $K\cap\left(\bigcap_{j=1}^{k}A_j\right)$ is non-empty. Show that $K\cap\left(\bigcap_{j=1}^{\infty}A_j\right)$ is non-empty. Hint: Consider open sets $B_j=A_j^c$. Express $\bigcap_{j=1}^{\infty}A_j$ and $\bigcap_{j=1}^{k}A_j$ in terms of $B_j$. Then use the definition of a compact set.

**中文：** 设 $(X,d)$ 是度量空间，$K$ 是 $X$ 中的紧集，$A_j$（$j\in\mathbb{N}$）是 $X$ 中的闭集。假设对所有 $k\in\mathbb{N}$，$K\cap\left(\bigcap_{j=1}^{k}A_j\right)$ 非空。证明 $K\cap\left(\bigcap_{j=1}^{\infty}A_j\right)$ 非空。提示：考虑开集 $B_j=A_j^c$。把 $\bigcap_{j=1}^{\infty}A_j$ 和 $\bigcap_{j=1}^{k}A_j$ 用 $B_j$ 表达，然后利用紧集的定义。

**证明：** 这是 **finite intersection property（有限交性质，FIP）** 对紧集的一个标准刻画，用反证法加开覆盖论证。

**Step 1（用 $B_j$ 表达）：** 令 $B_j=A_j^c$（$A_j$ 的补集）。因为 $A_j$ 是 **closed set**，所以 $B_j$ 是 **open set**。由 **De Morgan 定律（德摩根律）**：

```math
\left(\bigcap_{j=1}^{\infty}A_j\right)^c = \bigcup_{j=1}^{\infty}A_j^c = \bigcup_{j=1}^{\infty}B_j,
```

即

```math
\bigcap_{j=1}^{\infty}A_j = \left(\bigcup_{j=1}^{\infty}B_j\right)^c.
```

**Step 2（反证）：** 假设结论不成立，即

```math
K\cap\left(\bigcap_{j=1}^{\infty}A_j\right)=\varnothing.
```

这等价于 $K\subseteq\left(\bigcap_{j=1}^{\infty}A_j\right)^c=\bigcup_{j=1}^{\infty}B_j$。于是 $\{B_j\}_{j=1}^{\infty}$ 是紧集 $K$ 的一个 **open cover（开覆盖）**。

**Step 3（用紧性抽有限子覆盖）：** 由 $K$ 的 **compactness（紧性）**，即每个开覆盖都有有限子覆盖，存在有限多个指标 $j_1\lt j_2<\dots\lt j_m$，使

```math
K\subseteq B_{j_1}\cup B_{j_2}\cup\cdots\cup B_{j_m}.
```

令 $k=\max\{j_1,\dots,j_m\}$。由于 $B_j$ 是递增的（$B_j=A_j^c$，而 $A_{j+1}$ 未必含于 $A_j$，但这里只需看有限子覆盖），我们有

```math
B_{j_1}\cup\cdots\cup B_{j_m}\subseteq B_1\cup B_2\cup\cdots\cup B_k,
```

（因为每个 $j_i\le k$，故 $B_{j_i}\subseteq\bigcup_{j=1}^{k}B_j$）。于是

```math
K\subseteq\bigcup_{j=1}^{k}B_j.
```

**Step 4（导出矛盾）：** 对 $\bigcup_{j=1}^{k}B_j$ 取补，再由德摩根律得

```math
\varnothing = K\cap\left(\bigcup_{j=1}^{k}B_j\right)^c = K\cap\left(\bigcap_{j=1}^{k}B_j^c\right) = K\cap\left(\bigcap_{j=1}^{k}A_j\right).
```

（最后一步用到 $B_j^c=A_j$。）但这与题设"对所有 $k\in\mathbb{N}$，$K\cap\left(\bigcap_{j=1}^{k}A_j\right)$ 非空"矛盾。

因此反证假设不成立，必有 $K\cap\left(\bigcap_{j=1}^{\infty}A_j\right)\neq\varnothing$。∎

**要点：** 本题实际上证明了：紧集 $K$ 具有 **finite intersection property**——若闭集族 $\{A_j\}$ 的任意有限交都与 $K$ 相交，则全体交也与 $K$ 相交。这是紧性的核心等价刻画之一（在 Hausdorff 空间下与紧性等价）。
