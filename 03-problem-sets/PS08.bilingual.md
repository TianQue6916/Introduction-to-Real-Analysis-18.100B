# 18.100B Real Analysis · Problem Set 08（问题集 08）

## 术语口径

- **derivative（导数）**：函数在一点的变化率。易混点：说「f is differentiable（可导）」指该点导数存在且有限；而 `f'` 作为函数存在，其本身是否连续是另一回事。
- **continuous（连续）**：极限等于函数值。易混点：`f'` 连续（continuous derivative）比 `f` 可导更强——前者要求导函数本身连续，后者只要求逐点导数存在。
- **nth derivative（n 阶导数）**：对函数反复求导 n 次。易混点：记号 `f^(n)` 表示 n 阶导数，与幂 `f^n` 不同。
- **strictly increasing（严格递增）**：$x_1\lt x_2\Rightarrow f(x_1)\lt f(x_2)$。易混点：与「nondecreasing（不减）」不同，后者允许相等。
- **inverse function（反函数）**：把函数「倒回去」的映射。易混点：反函数存在要求原函数是双射（one-to-one and onto，一一对应）。
- **convex（凸）**：图像上任两点连线段在函数图像上方。易混点：此处是「凸向下开口」的凸（convex up），不要与「凹（concave）」混淆。
- **Riemann integrable（黎曼可积）**：上下黎曼和（upper/lower Riemann sum）的极限相等。易混点：黎曼可积不要求连续，只要间断点「不太多」即可。
- **Mean Value Theorem（中值定理，MVT）**：区间上连续、内部可导的函数，存在一点使切线斜率等于割线斜率。
- **L'Hôpital's rule（洛必达法则）**：$\frac00$ 或 $\frac\infty\infty$ 型极限可转化为导函数之比的极限。
- **uniform convergence（一致收敛）**：函数列收敛速度与点无关，可用于交换极限与积分/求导。易混点：逐点收敛（pointwise convergence）不能保证交换极限顺序。

## Problem 1（问题 1）

**题干原文：** Let $f:\mathbb{R}\to\mathbb{R}$ be a function. Suppose that both $f'(x)$ and $f''(x)$ are continuous functions on $\mathbb{R}$ and that $f(0)=0$. Define the function
```math
g(x):=\begin{cases} f(x)/x, & x\neq 0,\\ f'(0), & x=0.\end{cases}
```
Show that $g'(x)$ exists for all $x\in\mathbb{R}$ and express $g'(x)$ in terms of $f(x)$ and its derivatives.

**中文：** 设 $f:\mathbb{R}\to\mathbb{R}$ 是一个函数。假设 $f'(x)$ 与 $f''(x)$ 在 $\mathbb{R}$ 上都连续，且 $f(0)=0$。定义函数
```math
g(x):=\begin{cases} f(x)/x, & x\neq 0,\\ f'(0), & x=0.\end{cases}
```
证明：对一切 $x\in\mathbb{R}$，$g'(x)$ 存在，并用 $f(x)$ 及其导数表示 $g'(x)$。

**证明：**

**第一步：在 $x\neq 0$ 处，$g$ 显然可导。** 由商的求导法则（quotient rule），当 $x\neq 0$ 时，
```math
g'(x)=\frac{x f'(x)-f(x)}{x^2}.
```
因为 $f'$ 连续、$f$ 也连续（可导蕴含连续），右端在 $x\neq 0$ 处处有定义且连续。

**第二步：在 $x=0$ 处，用定义求 $g'(0)$。** 依导数定义，
```math
g'(0)=\lim_{h\to 0}\frac{g(h)-g(0)}{h}
=\lim_{h\to 0}\frac{\frac{f(h)}{h}-f'(0)}{h}
=\lim_{h\to 0}\frac{f(h)-h f'(0)}{h^2}.
```
注意由题设 $f(0)=0$，故分子 $f(h)-h f'(0)$ 在 $h\to0$ 时趋于 $f(0)-0=0$，分母趋于 $0$，这是 $\frac00$ 型。由 **L'Hôpital's rule（洛必达法则）**：
```math
\lim_{h\to 0}\frac{f(h)-h f'(0)}{h^2}
=\lim_{h\to 0}\frac{f'(h)-f'(0)}{2h}
=\frac12\lim_{h\to 0}\frac{f'(h)-f'(0)}{h}
=\frac12 f''(0).
```
最后一步正是 $f'$ 在 $0$ 处的导数定义，即 $f''(0)$，且 $f''(0)$ 存在（题设 $f''$ 连续）。

于是
```math
g'(0)=\frac{f''(0)}{2}.
```

**结论：** 对一切 $x\in\mathbb{R}$，
```math
g'(x)=
\begin{cases}
\dfrac{x f'(x)-f(x)}{x^2}, & x\neq 0,\\[1ex]
\dfrac{f''(0)}{2}, & x=0.
\end{cases}
```

（补充说明：题目只要求 $g'$ 存在并写出表达式；实际上由 $f'$、$f''$ 连续还可进一步验证 $g'$ 在 $0$ 处连续，但并非本题所需。）

## Problem 2（问题 2）

**题干原文：** Suppose there exist two functions $S:\mathbb{R}\to\mathbb{R}$ and $C:\mathbb{R}\to\mathbb{R}$ which satisfy the following properties:
- $\frac{d}{dx}S(x)=C(x),\quad \frac{d}{dx}C(x)=S(x)$.
- $S(0)=0,\ C(0)=1$.

(1) Let $S^{(n)}(x)$ be the nth derivative of $S(x)$. Show that for $k\in\mathbb{N}\cup\{0\}$,
```math
S^{(2k)}(x)=S(x),\qquad S^{(2k+1)}(x)=C(x).
```
(2) Show that for all $x\in\mathbb{R}$,
```math
S(x)=\sum_{n=0}^{\infty}\frac{x^{2n+1}}{(2n+1)!}.
```

**中文：** 假设存在两个函数 $S:\mathbb{R}\to\mathbb{R}$ 与 $C:\mathbb{R}\to\mathbb{R}$，满足以下性质：
- $\frac{d}{dx}S(x)=C(x),\quad \frac{d}{dx}C(x)=S(x)$；
- $S(0)=0,\ C(0)=1$。

(1) 设 $S^{(n)}(x)$ 是 $S(x)$ 的 n 阶导数。证明：对 $k\in\mathbb{N}\cup\{0\}$，
```math
S^{(2k)}(x)=S(x),\qquad S^{(2k+1)}(x)=C(x).
```
(2) 证明：对一切 $x\in\mathbb{R}$，
```math
S(x)=\sum_{n=0}^{\infty}\frac{x^{2n+1}}{(2n+1)!}.
```

**证明：**

**(1)** 对 $k$ 用数学归纳法（mathematical induction）。

由微分方程直接写出前几阶：
```math
S^{(0)}=S,\quad S^{(1)}=C,\quad S^{(2)}=(S^{(1)})'=C'=S,\quad S^{(3)}=(S^{(2)})'=S'=C.
```
可见 $S^{(2k)}=S$ 与 $S^{(2k+1)}=C$ 的规律在 $k=0,1$ 时成立。

设命题对某个 $k$ 成立，即 $S^{(2k)}=S$ 且 $S^{(2k+1)}=C$。则
```math
S^{(2k+2)}=(S^{(2k+1)})'=C'=S,
```
```math
S^{(2k+3)}=(S^{(2k+2)})'=S'=C.
```
故对 $k+1$ 也成立。归纳得证：对一切 $k\in\mathbb{N}\cup\{0\}$，
```math
S^{(2k)}=S,\qquad S^{(2k+1)}=C.
```

**(2)** 用 **Taylor series（泰勒级数）** 与余项估计证明级数一致收敛到 $S$。

先取 $S$ 在 $x=0$ 处的各阶导数值。由 (1) 与初值：
```math
S^{(2k)}(0)=S(0)=0,\qquad S^{(2k+1)}(0)=C(0)=1.
```
于是 $S$ 在 $0$ 处的 Taylor 展开（Maclaurin series）为
```math
\sum_{n=0}^{\infty}\frac{S^{(n)}(0)}{n!}x^n
=\sum_{k=0}^{\infty}\frac{1}{(2k+1)!}x^{2k+1},
```
奇数阶系数为 $1$、偶数阶系数为 $0$，正是题目中的级数。

现在严格证明 $S$ 等于这个级数。对任意固定的 $R>0$ 与 $|x|\le R$，由 **Taylor's theorem（泰勒定理，带 Lagrange 余项）**，存在介于 $0$ 与 $x$ 之间的 $\xi$ 使得
```math
S(x)=\sum_{n=0}^{N-1}\frac{S^{(n)}(0)}{n!}x^n+\frac{S^{(N)}(\xi)}{N!}x^N.
```
关键是要控制余项。由于 $S$ 与 $C$ 的导数只可能交替等于 $S$ 或 $C$，且 $S,C$ 是 $C^\infty$ 函数，在紧区间 $[-R,R]$ 上它们及其所有导数有界：设
```math
M_R=\max\left\{\sup_{|t|\le R}|S(t)|,\ \sup_{|t|\le R}|C(t)|\right\}<+\infty.
```
（$S,C$ 可导故连续，在闭区间 $[-R,R]$ 上达到最大，故有限。）于是对任意 $N$ 与 $|\xi|\le R$，
```math
|S^{(N)}(\xi)|\le M_R,
```
从而余项满足
```math
\left|\frac{S^{(N)}(\xi)}{N!}x^N\right|\le M_R\,\frac{R^N}{N!}.
```
由 $\lim_{N\to\infty}\frac{R^N}{N!}=0$（对任意固定的 $R$），得
```math
\lim_{N\to\infty}\frac{S^{(N)}(\xi)}{N!}x^N=0.
```
因此 Taylor 级数在 $[-R,R]$ 上一致收敛（余项一致趋于 $0$），且
```math
S(x)=\sum_{n=0}^{\infty}\frac{S^{(n)}(0)}{n!}x^n=\sum_{n=0}^{\infty}\frac{x^{2n+1}}{(2n+1)!}.
```
由于 $R$ 任意，上式对一切 $x\in\mathbb{R}$ 成立。

（结论：这些函数正是 $\sin x$ 与 $\cos x$ 的公理化刻画——题目用两条微分方程与初值唯一确定了 $\sin$ 与 $\cos$。）

## Problem 3（问题 3）

**题干原文：** Let $a\lt b$ be two real numbers and $f:[a,b]\to\mathbb{R}$ be a function. Suppose $f(x)$ is continuous on $[a,b]$ and differentiable on $(a,b)$. Suppose $f'(x)>0$ for all $x\in(a,b)$.

(1) Show that $f(x)$ is strictly increasing on $[a,b]$. That is, $f(x_1)\lt f(x_2)$ for all $x_1\lt x_2$ in $[a,b]$.

(2) Show that for all $y\in(f(a),f(b))$, there exists a unique $x\in(a,b)$ such that $f(x)=y$.

(3) Let the function $g:(f(a),f(b))\to(a,b)$ be the inverse function of $f(x)$. Show that $g$ is continuous on $(f(a),f(b))$.

(4) Show that $g$ is differentiable on $(f(a),f(b))$ and that
```math
g'(y)=\frac{1}{f'(g(y))}\quad\text{for all }y\in(f(a),f(b)).
```

**中文：** 设 $a\lt b$ 为两个实数，$f:[a,b]\to\mathbb{R}$ 是一个函数。假设 $f(x)$ 在 $[a,b]$ 上连续、在 $(a,b)$ 上可导，且对一切 $x\in(a,b)$ 有 $f'(x)>0$。

(1) 证明 $f(x)$ 在 $[a,b]$ 上严格递增，即对 $[a,b]$ 中所有 $x_1\lt x_2$，有 $f(x_1)\lt f(x_2)$。

(2) 证明对一切 $y\in(f(a),f(b))$，存在唯一的 $x\in(a,b)$ 使得 $f(x)=y$。

(3) 设 $g:(f(a),f(b))\to(a,b)$ 是 $f(x)$ 的反函数（即 $g(y)=x$ 当且仅当 $f(x)=y$）。证明 $g$ 在 $(f(a),f(b))$ 上连续。

(4) 证明 $g$ 在 $(f(a),f(b))$ 上可导，且对一切 $y\in(f(a),f(b))$ 有
```math
g'(y)=\frac{1}{f'(g(y))}.
```

**证明：**

**(1)** 任取 $x_1\lt x_2$ 于 $[a,b]$。$f$ 在 $[x_1,x_2]$ 上连续、在 $(x_1,x_2)$ 上可导，满足 **Mean Value Theorem（中值定理）** 条件。于是存在 $c\in(x_1,x_2)$ 使得
```math
f(x_2)-f(x_1)=f'(c)\,(x_2-x_1).
```
因 $f'(c)>0$ 且 $x_2-x_1>0$，故 $f(x_2)-f(x_1)>0$，即 $f(x_1)\lt f(x_2)$。由 $x_1\lt x_2$ 的任意性，$f$ 在 $[a,b]$ 上严格递增。

**(2)** 先证存在性。任取 $y\in(f(a),f(b))$，即 $f(a)\lt y\lt f(b)$。因 $f$ 连续，由 **Intermediate Value Theorem（介值定理）**，存在 $x\in(a,b)$ 使得 $f(x)=y$。

再证唯一性。若还有 $x'\in(a,b)$ 满足 $f(x')=y$ 且 $x'\neq x$，不妨 $x'\lt x$（或反之），则由 (1) 的严格递增性，$f(x')\lt f(x)$，与 $f(x')=f(x)=y$ 矛盾。故这样的 $x$ 唯一。

**(3)** 证明 $g$ 在 $(f(a),f(b))$ 上连续。任取 $y_0\in(f(a),f(b))$，记 $x_0=g(y_0)$。因 $x_0\in(a,b)$（开区间），存在 $\delta_0>0$ 使 $[x_0-\delta_0,x_0+\delta_0]\subset(a,b)$。

对任意 $\varepsilon>0$，缩小 $\varepsilon$ 使得 $0<\varepsilon\le\delta_0$。令
```math
u=f(x_0-\varepsilon),\qquad v=f(x_0+\varepsilon).
```
由 (1) 严格递增，$u\lt f(x_0)=y_0\lt v$。取
```math
\delta=\min\{y_0-u,\ v-y_0\}>0.
```
现在若 $y\in(f(a),f(b))$ 且 $|y-y_0|<\delta$，则 $u\lt y\lt v$，即
```math
f(x_0-\varepsilon)<y<f(x_0+\varepsilon).
```
由 $f$ 连续及 (2) 的存在性（注意 $y\in(f(x_0-\varepsilon),f(x_0+\varepsilon))$），存在 $x\in(x_0-\varepsilon,x_0+\varepsilon)$ 使 $f(x)=y$，此 $x$ 即 $g(y)$。于是
```math
|g(y)-g(y_0)|=|x-x_0|<\varepsilon.
```
故 $g$ 在 $y_0$ 连续；由 $y_0$ 任意，$g$ 在 $(f(a),f(b))$ 上连续。

**(4)** 任取 $y_0\in(f(a),f(b))$，记 $x_0=g(y_0)$。由于 $x_0\in(a,b)$ 且 $f'(x_0)>0$，$f'(x_0)\neq0$。任取 $y\neq y_0$ 且 $y\in(f(a),f(b))$，记 $x=g(y)$，则 $x\neq x_0$（因 $f$ 严格递增）。由 $g(y)=x$、$g(y_0)=x_0$：
```math
\frac{g(y)-g(y_0)}{y-y_0}
=\frac{x-x_0}{f(x)-f(x_0)}
=\frac{1}{\frac{f(x)-f(x_0)}{x-x_0}}.
```
当 $y\to y_0$ 时，由 (3) 的连续性，$g(y)\to g(y_0)$，即 $x\to x_0$。于是
```math
g'(y_0)=\lim_{y\to y_0}\frac{g(y)-g(y_0)}{y-y_0}
=\lim_{x\to x_0}\frac{1}{\frac{f(x)-f(x_0)}{x-x_0}}
=\frac{1}{f'(x_0)}
=\frac{1}{f'(g(y_0))}.
```
（分母极限为 $f'(x_0)\neq0$，故可安全取倒数。）由 $y_0$ 任意，结论成立。这就是 **inverse function theorem（反函数求导法则）** 在一维情形的形式。

## Problem 4（问题 4）

**题干原文：** Define the function $f:[-1,1]\to\mathbb{R}$ by
```math
f(x)=\begin{cases}1,&x\in[-1,0)\cup(0,1],\\ 0,&x=0.\end{cases}
```
Show that $f(x)$ is Riemann integrable on $[-1,1]$ and that $\int_{-1}^{1}f(x)\,dx=2$.

**中文：** 定义函数 $f:[-1,1]\to\mathbb{R}$ 为
```math
f(x)=\begin{cases}1,&x\in[-1,0)\cup(0,1],\\ 0,&x=0.\end{cases}
```
证明 $f(x)$ 在 $[-1,1]$ 上黎曼可积，且 $\int_{-1}^{1}f(x)\,dx=2$。

**证明：**

$f$ 在 $[-1,1]$ 上除 $x=0$ 一点外恒等于 $1$，即它只有一个间断点。由 **Lebesgue 判据（Riemann integrability criterion）**：闭区间上有界函数黎曼可积当且仅当其不连续点集测度为零。$f$ 有界（$0\le f\le1$）且不连续点仅 $\{0\}$（单点集，测度为零），故 $f$ 在 $[-1,1]$ 上黎曼可积。

（若课程尚未引入 Lebesgue 判据，可改用 Riemann sum 直接论证，见下。）

**用 Darboux 和的直接构造（避免使用 Lebesgue 判据）：**

对任意 $\varepsilon>0$，构造一个分割 $P$。取充分小的 $\delta>0$（满足 $\delta<\varepsilon/2$），设
```math
P=\{-1,\ -\delta,\ \delta,\ 1\}.
```
在子区间上计算上、下和。注意 $f$ 在 $[-1,-\delta]$ 上恒为 $1$，在 $[\delta,1]$ 上恒为 $1$，而在 $[-\delta,\delta]$ 上取值集合为 $\{0,1\}$。

各子区间上 $f$ 的上确界与下确界：
- 在 $[-1,-\delta]$：$\sup f=\inf f=1$；
- 在 $[-\delta,\delta]$：$\sup f=1$，$\inf f=0$；
- 在 $[\delta,1]$：$\sup f=\inf f=1$。

于是上 Darboux 和（upper sum）与下 Darboux 和（lower sum）为：
```math
U(P,f)=1\cdot(-\delta-(-1))+1\cdot(\delta-(-\delta))+1\cdot(1-\delta)
=(1-\delta)+2\delta+(1-\delta)=2,
```
```math
L(P,f)=1\cdot(-\delta-(-1))+0\cdot(\delta-(-\delta))+1\cdot(1-\delta)
=(1-\delta)+0+(1-\delta)=2-2\delta.
```
故
```math
U(P,f)-L(P,f)=2\delta<\varepsilon.
```
由 **Darboux 可积判据（Riemann 可积的等价刻画：上下和之差可任意小）**，$f$ 在 $[-1,1]$ 上黎曼可积。

最后求积分值。因 $f$ 可积，积分介于上下和之间：$L(P,f)\le\int_{-1}^{1}f\le U(P,f)$，即
```math
2-2\delta\le\int_{-1}^{1}f(x)\,dx\le2.
```
令 $\delta\to0^+$，得
```math
\int_{-1}^{1}f(x)\,dx=2.
```
（直观：$f$ 在长度为 $2$ 的区间上除一点外恒为 $1$，单点改变不积分值，故积分为 $2$。）

## Problem 5（问题 5）

**题干原文：** Let $f:(a,b)\to\mathbb{R}$ be a function. $f(x)$ is called convex if for all $x_1\lt x_2\in(a,b)$ and all $\lambda\in[0,1]$,
```math
f(\lambda x_1+(1-\lambda)x_2)\le \lambda f(x_1)+(1-\lambda)f(x_2).
```
(1) Suppose that $f''(x)$ exists and is non-negative for all $x\in(a,b)$. Show that $f(x)$ is convex.

(2) Suppose that $f''(x)$ exists for all $x\in(a,b)$. Show that
```math
f''(x)=\lim_{h\to0}\frac{f(x+h)+f(x-h)-2f(x)}{h^2}.
```

(3) Suppose that $f''(x)$ exists for all $x\in(a,b)$ and that $f(x)$ is convex. Show that for all $x\in(a,b)$, $f''(x)\ge0$.

**中文：** 设 $f:(a,b)\to\mathbb{R}$ 是一个函数。若对一切 $x_1\lt x_2\in(a,b)$ 与一切 $\lambda\in[0,1]$ 有
```math
f(\lambda x_1+(1-\lambda)x_2)\le \lambda f(x_1)+(1-\lambda)f(x_2),
```
则称 $f(x)$ 是凸函数。

(1) 假设 $f''(x)$ 在 $(a,b)$ 上存在且非负，证明 $f(x)$ 是凸的。

(2) 假设 $f''(x)$ 在 $(a,b)$ 上处处存在，证明
```math
f''(x)=\lim_{h\to0}\frac{f(x+h)+f(x-h)-2f(x)}{h^2}.
```

(3) 假设 $f''(x)$ 在 $(a,b)$ 上处处存在且 $f(x)$ 是凸的，证明对一切 $x\in(a,b)$ 有 $f''(x)\ge0$。

**证明：**

**(1)** 固定 $x_1\lt x_2$ 与 $\lambda\in[0,1]$，记 $x_0=\lambda x_1+(1-\lambda)x_2$，即 $x_0$ 位于 $[x_1,x_2]$ 内。要证
```math
f(x_0)\le \lambda f(x_1)+(1-\lambda)f(x_2).
```
设 $x_0=\lambda x_1+(1-\lambda)x_2$，则
```math
\lambda=\frac{x_2-x_0}{x_2-x_1},\qquad 1-\lambda=\frac{x_0-x_1}{x_2-x_1}.
```
在 $[x_1,x_0]$ 与 $[x_0,x_2]$ 上分别应用 **Mean Value Theorem（中值定理）**：存在 $c_1\in(x_1,x_0)$、$c_2\in(x_0,x_2)$ 使
```math
f'(c_1)=\frac{f(x_0)-f(x_1)}{x_0-x_1},\qquad
f'(c_2)=\frac{f(x_2)-f(x_0)}{x_2-x_0}.
```
因 $c_1\lt c_2$ 且 $f''\ge0$，$f'$ 在 $(a,b)$ 上单调不减（由 MVT 应用于 $f'$ 可得），故 $f'(c_1)\le f'(c_2)$，即
```math
\frac{f(x_0)-f(x_1)}{x_0-x_1}\le\frac{f(x_2)-f(x_0)}{x_2-x_0}.
```
通分（两边分母均正）：
```math
(x_2-x_0)\big(f(x_0)-f(x_1)\big)\le(x_0-x_1)\big(f(x_2)-f(x_0)\big).
```
展开并整理（注意 $x_2-x_0+x_0-x_1=x_2-x_1$）：
```math
(x_2-x_1)f(x_0)\le(x_2-x_0)f(x_1)+(x_0-x_1)f(x_2).
```
两边同除以 $x_2-x_1>0$：
```math
f(x_0)\le\frac{x_2-x_0}{x_2-x_1}f(x_1)+\frac{x_0-x_1}{x_2-x_1}f(x_2)
=\lambda f(x_1)+(1-\lambda)f(x_2).
```
这正是凸性的定义。由 $x_1,x_2,\lambda$ 任意，$f$ 是凸函数。

（此即凸性的斜率刻画：$f''\ge0$ 时割线斜率随 $x$ 单调不减，与图中所示几何意义一致。）

**(2)** 对固定的 $x\in(a,b)$，取足够小的 $h$ 使 $x\pm h\in(a,b)$。定义分子
```math
N(h)=f(x+h)+f(x-h)-2f(x),\qquad D(h)=h^2.
```
当 $h\to0$ 时 $N(h)\to f(x)+f(x)-2f(x)=0$，$D(h)\to0$，为 $\frac00$ 型。由于 $f''$ 存在（故 $f$ 及 $f'$ 在 $x$ 附近存在且 $f'$ 在 $x$ 附近连续、$f$ 可导），可两次应用 **L'Hôpital's rule（洛必达法则）**。

第一次（对 $h$ 求导）：
```math
\lim_{h\to0}\frac{f(x+h)+f(x-h)-2f(x)}{h^2}
=\lim_{h\to0}\frac{f'(x+h)-f'(x-h)}{2h}.
```
（注意 $f(x-h)$ 对 $h$ 求导得 $-f'(x-h)$；$2f(x)$ 与 $h$ 无关，导数为 $0$。）分子在 $h\to0$ 时趋于 $f'(x)-f'(x)=0$，仍为 $\frac00$ 型。第二次应用洛必达：
```math
\lim_{h\to0}\frac{f'(x+h)-f'(x-h)}{2h}
=\lim_{h\to0}\frac{f''(x+h)+f''(x-h)}{2}.
```
由于 $f''$ 在 $x$ 处存在（连续），$f''(x+h)\to f''(x)$、$f''(x-h)\to f''(x)$，故
```math
f''(x)=\lim_{h\to0}\frac{f(x+h)+f(x-h)-2f(x)}{h^2}.
```
（补充：严格地说洛必达要求分子分母在 $0$ 附近可导且极限存在，这里 $f''$ 处处存在保证了这一点。）

**(3)** 用 (2) 的公式证 $f''(x)\ge0$。对固定的 $x\in(a,b)$，由凸性定义，取 $x_1=x-h$、$x_2=x+h$、$\lambda=\tfrac12$，则
```math
\lambda x_1+(1-\lambda)x_2=\frac{x-h}{2}+\frac{x+h}{2}=x,
```
凸性给出
```math
f(x)\le\frac12 f(x-h)+\frac12 f(x+h).
```
两边同乘 $2$：
```math
2f(x)\le f(x+h)+f(x-h)\quad\Longrightarrow\quad f(x+h)+f(x-h)-2f(x)\ge0.
```
对充分小的 $h>0$（使 $x\pm h\in(a,b)$），上式成立，且分母 $h^2>0$，故
```math
\frac{f(x+h)+f(x-h)-2f(x)}{h^2}\ge0.
```
由 (2) 的极限公式，取 $h\to0^+$：
```math
f''(x)=\lim_{h\to0}\frac{f(x+h)+f(x-h)-2f(x)}{h^2}\ge0.
```
（非负量的极限非负。）由 $x$ 任意，(3) 得证。

**综合 (1)(3)：** 在 $f''$ 处处存在的条件下，$f$ 是凸函数 $\iff f''(x)\ge0$ 对一切 $x\in(a,b)$ 成立。这是二阶导数凸性判据的完整刻画。
