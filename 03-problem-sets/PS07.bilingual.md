# 18.100B Real Analysis · Problem Set 07（问题集 07）

## 术语口径

- **metric space（度量空间）**：一个集合 $X$ 配上满足四条公理（正定性、对称性、三角不等式、以及 $d(x,x)=0$）的距离函数 $d:X\times X\to\mathbb R$。易混点：度量空间不一定是 $\mathbb R^n$，它没有"原点""线性结构"，只有"距离"这一件事。
- **Cauchy sequence（柯西序列）**：$\forall\epsilon>0,\exists N$ 使 $m,n\ge N$ 时 $d(x_m,x_n)<\epsilon$。易混点：Cauchy 是"自己跟自己越来越近"，**不**预设极限存在于 $X$ 内；收敛一定 Cauchy，反之要完备（complete）才成立。
- **complete（完备）**：度量空间中每个 Cauchy 序列都收敛于该空间内一点。易混点：$\mathbb R$ 完备，$\mathbb Q$ 不完备（$\sqrt2$ 的有理逼近是 Cauchy 但不收敛于 $\mathbb Q$）。
- **convergent subsequence（收敛子列）**：从原序列抽出（保持顺序）的无穷多项，其自身有极限。易混点："无收敛子列"比"不收敛"强得多——它要求**任何**子列都不收敛。
- **Bolzano–Weierstrass（波尔查诺–魏尔斯特拉斯定理）**：$\mathbb R$ 中有界序列必有收敛子列。易混点：它是**一维/有限维**的结论，在无穷维（如本题的 $\ell^2$ 空间）中不成立——这正是 Problem 1(3) 想展示的。
- **compact（紧）**：任意开覆盖有有限子覆盖。易混点：在度量空间中，紧 $\iff$ 完备且全有界；本题 Problem 2 本质上是"Heine–Borel 型命题在度量空间的反面刻画"。
- **continuous / differentiable（连续 / 可微）**：连续只要求函数值随自变量趋近而趋近；可微要求差商极限存在。易混点：可微 $\Rightarrow$ 连续，反之不然（如 $|x|$ 在 $0$ 处）。
- **Mean Value Theorem（MVT，中值定理）**：连续 + 开区间可微，则存在 $c$ 使割线斜率等于切线斜率。易混点：$c$ 只保证存在、一般**不唯一**；且 $c$ 依赖端点 $a,b$。
- **uniform convergence（一致收敛）**：$f_n\to f$ 且 $\sup_x|f_n(x)-f(x)|\to 0$，即 $N$ 与 $x$ 无关。易混点：逐点收敛的 $N$ 依赖 $x$；一致收敛能保证"连续函数列的极限连续"，逐点收敛则不能——这正是 Problem 5 的核心。

## Problem 1（问题 1）

**题干原文：**
Consider the set
```math
X := \left\{ (a_1,a_2,a_3,\dots) \,\middle|\, \sum_{j=1}^{\infty} a_j^2 \text{ converges} \right\}.
```
Define the function $d:X\times X\to\mathbb R$ as follows. For $x=(a_1,a_2,\dots)$ and $y=(b_1,b_2,\dots)$ in $X$,
```math
d(x,y) := \sqrt{\sum_{j=1}^{\infty}(a_j-b_j)^2}.
```
(1) Show that $d$ is well-defined, i.e. that $\sum_{j=1}^{\infty}(a_j-b_j)^2$ converges.
(2) Show that $d$ satisfies the triangle inequality (using the $\mathbb R^n$ triangle inequality without proof).
(3) Let $x_1=(1,0,0,\dots)$, $x_2=(0,1,0,\dots)$, etc., i.e. $x_n=(0,\dots,0,\underbrace{1}_{n\text{-th}},0,\dots)$. Show that $x_n$ has no convergent subsequence.

**中文：**

考虑集合 $X$，由所有"平方可和"的实数列组成，即 $X := \{(a_1,a_2,a_3,\dots) \mid \sum_{j=1}^{\infty} a_j^2 \text{ 收敛}\}$。

对 $x=(a_1,a_2,\dots)$ 与 $y=(b_1,b_2,\dots)$，定义 $d(x,y):=\sqrt{\sum_{j=1}^{\infty}(a_j-b_j)^2}$。

(1) 证明 $d$ 是 well-defined（良定义的），即证明 $\sum(a_j-b_j)^2$ 收敛。
(2) 证明 $d$ 满足三角不等式（可引用 $\mathbb R^n$ 中的三角不等式）。
(3) 取 $x_1=(1,0,0,\dots)$、$x_2=(0,1,0,\dots)$，一般地 $x_n=(0,\dots,0,1,0,\dots)$（$1$ 在第 $n$ 位）。证明 $x_n$ 没有收敛子列。

**证明：**

**(1) 良定义性。** 设 $x=(a_j),y=(b_j)\in X$，则 $\sum a_j^2$、$\sum b_j^2$ 均收敛。对每个固定的 $j$，由初等不等式 $(u-v)^2\le 2u^2+2v^2$ 得

```math
(a_j-b_j)^2 \le 2a_j^2 + 2b_j^2 .
```

两边对 $j$ 求和，正项级数可用比较判别法（comparison test）：

```math
\sum_{j=1}^{\infty}(a_j-b_j)^2 \le 2\sum_{j=1}^{\infty}a_j^2 + 2\sum_{j=1}^{\infty}b_j^2 < \infty .
```

故 $\sum(a_j-b_j)^2$ 收敛，$d(x,y)$ 良定义。□

**(2) 三角不等式。** 设 $x=(a_j),y=(b_j),z=(c_j)\in X$。要证 $d(x,z)\le d(x,y)+d(y,z)$，即

```math
\sqrt{\sum_{j=1}^{\infty}(a_j-c_j)^2}
\le
\sqrt{\sum_{j=1}^{\infty}(a_j-b_j)^2}
+
\sqrt{\sum_{j=1}^{\infty}(b_j-c_j)^2}.
```

对每个 $n\ge1$，由 $\mathbb R^n$ 中（欧氏范数）的三角不等式（题中允许直接引用），有

```math
\sqrt{\sum_{j=1}^{n}(a_j-c_j)^2}
\le
\sqrt{\sum_{j=1}^{n}(a_j-b_j)^2}
+
\sqrt{\sum_{j=1}^{n}(b_j-c_j)^2}.
```

左边关于 $n$ 单调递增，且三项的部分和分别收敛到三个级数和（均由 (1) 知有限）。记

```math
A_n=\sqrt{\sum_{j=1}^{n}(a_j-c_j)^2},\quad
B_n=\sqrt{\sum_{j=1}^{n}(a_j-b_j)^2},\quad
C_n=\sqrt{\sum_{j=1}^{n}(b_j-c_j)^2},
```

则 $A_n\le B_n+C_n$ 对一切 $n$ 成立，且 $B_n\to d(x,y)$，$C_n\to d(y,z)$，$A_n\to d(x,z)$（平方根函数连续，故和的极限取根号等于根号的极限）。对 $A_n\le B_n+C_n$ 两边取 $n\to\infty$ 的极限，得

```math
d(x,z) = \lim_{n\to\infty} A_n \le \lim_{n\to\infty}(B_n+C_n) = d(x,y)+d(y,z).
```

故三角不等式成立。□

**(3) 无收敛子列。** 序列 $x_n$ 定义为 $x_n$ 的第 $n$ 个分量为 $1$，其余为 $0$。注意：当 $m\ne n$ 时，

```math
d(x_m,x_n)^2 = \sum_{j=1}^{\infty}\big((x_m)_j-(x_n)_j\big)^2 = 1^2+1^2 = 2,
```

故 $d(x_m,x_n)=\sqrt2$（$m\ne n$）。

于是 $(x_n)$ 中任意两个不同项之间距离恒为 $\sqrt2>0$。设 $(x_{n_k})$ 是任意子列，若它收敛于某 $y\in X$，则它是 Cauchy 序列：$\forall\epsilon>0,\exists K$，使 $k,\ell\ge K$ 时 $d(x_{n_k},x_{n_\ell})<\epsilon$。取 $\epsilon=\sqrt2/2$，则当 $k,\ell\ge K$ 且 $k\ne\ell$ 时应有 $d(x_{n_k},x_{n_\ell})<\sqrt2/2$，但这与 $d(x_{n_k},x_{n_\ell})=\sqrt2$ 矛盾。

故任何子列都不收敛，即 $(x_n)$ 没有收敛子列。□

（注：这正说明无穷维 $\ell^2$ 空间中"有界闭集未必紧"——序列 $(x_n)$ 有界（每项范数 $=1$）但无收敛子列，与 $\mathbb R^n$ 中的 Bolzano–Weierstrass 形成对照。）

## Problem 2（问题 2）

**题干原文：**
Let $(X,d)$ be a metric space and $x_n$ a sequence in $X$. Denote $E=\{x_1,x_2,x_3,\dots\}$. Suppose $x_n$ has no convergent subsequence. Show that for all $k\in\mathbb N$, there exists $r_k>0$ such that $B(x_k,r_k)\cap E=\{x_k\}$. You may use: Fix $x\in X$; if for all $r>0$ there are infinitely many elements in $E\cap B(x,r)$, then $x_n$ has a subsequence converging to $x$.

**中文：**

设 $(X,d)$ 是度量空间，$x_n$ 是 $X$ 中序列，记 $E=\{x_1,x_2,x_3,\dots\}$。假设 $x_n$ 没有收敛子列。证明：对每个 $k\in\mathbb N$，存在 $r_k>0$ 使得 $B(x_k,r_k)\cap E=\{x_k\}$。可引用如下事实：固定 $x\in X$，若对一切 $r>0$，$E\cap B(x,r)$ 中都有无穷多个元素，则 $x_n$ 有收敛到 $x$ 的子列。

**证明：**

反设结论不成立，即存在某个 $k\in\mathbb N$，使得对**一切** $r>0$，都有 $B(x_k,r)\cap E \ne \{x_k\}$。

由于 $x_k\in E$ 且 $x_k\in B(x_k,r)$，故 $x_k\in B(x_k,r)\cap E$ 恒成立；于是 $B(x_k,r)\cap E\ne\{x_k\}$ 意味着交集里**还含有别的元素**，即存在 $x_m\ne x_k$ 且 $x_m\in B(x_k,r)$。

这样，对每个 $r>0$，都存在某个 $m$（可能随 $r$ 变化）使得 $0\lt d(x_m,x_k)\lt r$（若 $d=0$ 则 $x_m=x_k$，与 $x_m\ne x_k$ 矛盾，故严格大于 $0$）。

现在令 $r$ 取正实数序列 $r=1,1/2,1/3,\dots$。对 $r=1$ 找到 $x_{m_1}\ne x_k$ 使 $d(x_{m_1},x_k)<1$；对 $r=1/2$ 找到 $x_{m_2}\ne x_k$ 使 $d(x_{m_2},x_k)<1/2$；一般地，对 $r=1/j$ 找到 $x_{m_j}\ne x_k$ 使 $d(x_{m_j},x_k)<1/j$。

于是 $d(x_{m_j},x_k)\to 0$，即子列（当 $m_j$ 各异时）收敛到 $x_k$。若某些 $m_j$ 重复，由于每次都能取到无穷多个（实际上由题给 fact：$E\cap B(x_k,r)$ 含无穷多元素，可保证 $m_j$ 可互异），可把 $m_j$ 取得严格递增，从而 $x_{m_j}$ 是真正收敛到 $x_k$ 的子列。

这与题设"$x_n$ 没有收敛子列"矛盾。故反设不成立，原命题成立：对每个 $k$ 存在 $r_k>0$ 使 $B(x_k,r_k)\cap E=\{x_k\}$。□

**更严密的说明（直接调用题给 fact）：** 反设存在 $k$ 使对所有 $r>0$ 都有 $B(x_k,r)\cap E\ne\{x_k\}$。因 $x_k\in B(x_k,r)\cap E$ 恒成立，故这等价于 $B(x_k,r)\cap E$ 含某个 $\ne x_k$ 的点，从而 $B(x_k,r)\cap E$ 含无穷多元素（否则取 $r_0=\min\{d(x_k,x_m):x_m\in E,x_m\ne x_k\}>0$，则 $B(x_k,r_0)$ 只含 $x_k$）。于是由题给 fact（取 $x=x_k$），$x_n$ 有收敛到 $x_k$ 的子列，矛盾。□

（注：这一题的实质是——无收敛子列的序列，其每项都"被孤立"于集合 $E$ 之外，即每项都是 $E$ 的孤立点（isolated point）。这是"Heine–Borel 型紧性"在度量空间的反面刻画。）

## Problem 3（问题 3）

**题干原文：**
Let $f:\mathbb R\to\mathbb R$ be continuous. Suppose $f$ is differentiable on $(-\infty,0)\cup(0,\infty)$ and that $\lim_{x\to0}f'(x)$ exists. Show that $f$ is differentiable at $x=0$ and that $f'(0)=\lim_{x\to0}f'(x)$.

**中文：**

设 $f:\mathbb R\to\mathbb R$ 连续，且在 $(-\infty,0)\cup(0,\infty)$ 上可微，且 $\lim_{x\to0}f'(x)$ 存在。证明 $f$ 在 $x=0$ 处可微，且 $f'(0)=\lim_{x\to0}f'(x)$。

**证明：**

记 $L=\lim_{x\to0}f'(x)$（题设此极限存在）。要证 $f'(0)$ 存在且等于 $L$，即证差商极限

```math
\lim_{h\to0}\frac{f(h)-f(0)}{h} = L .
```

**先看 $h>0$ 的情形。** 对固定 $h>0$，在区间 $[0,h]$ 上应用 MVT：$f$ 在 $[0,h]$ 连续（由 $f$ 在 $\mathbb R$ 连续），在 $(0,h)$ 可微，故存在 $c_h\in(0,h)$ 使

```math
\frac{f(h)-f(0)}{h-0} = f'(c_h), \qquad 0<c_h<h .
```

当 $h\to0^+$ 时，$c_h\to0$（因 $0\lt c_h\lt h$）。由 $L=\lim_{x\to0}f'(x)$，得

```math
\lim_{h\to0^+}\frac{f(h)-f(0)}{h} = \lim_{h\to0^+}f'(c_h) = L .
```

**再看 $h<0$ 的情形。** 对固定 $h<0$，在区间 $[h,0]$ 上应用 MVT：存在 $c_h\in(h,0)$ 使

```math
\frac{f(0)-f(h)}{0-h} = f'(c_h), \qquad h<c_h<0 .
```

即

```math
\frac{f(h)-f(0)}{h} = f'(c_h).
```

当 $h\to0^-$ 时 $c_h\to0$，故

```math
\lim_{h\to0^-}\frac{f(h)-f(0)}{h} = \lim_{h\to0^-}f'(c_h) = L .
```

左、右差商极限均等于 $L$，故 $\lim_{h\to0}\frac{f(h)-f(0)}{h}=L$ 存在。因此 $f$ 在 $0$ 处可微，且 $f'(0)=L=\lim_{x\to0}f'(x)$。□

（注：此题的结论是——只要 $f$ 在 $0$ 附近连续、在 $0$ 两侧可微、且**导数的极限存在**，那么导数在 $0$ 处就"自动连续"，即 $f'$ 在该点无跳跃/振荡间断。这排除了 $f'$ 在孤立点有第一类间断的情形。）

## Problem 4（问题 4）

**题干原文：**
Use $\frac{d}{dx}e^x=e^x$ to show that $e^x\ge 1+x$ for all $x\in\mathbb R$. Hint: Apply MVT with $x$ and $0$ being the endpoints.

**中文：**

利用 $\frac{d}{dx}e^x=e^x$ 证明对所有 $x\in\mathbb R$ 有 $e^x\ge1+x$。提示：以 $x$ 和 $0$ 为端点应用中值定理。

**证明：**

**情形 1：$x>0$。** 在区间 $[0,x]$ 上对 $f(t)=e^t$ 应用 MVT（$e^t$ 连续且可微，$f'(t)=e^t$），存在 $c\in(0,x)$ 使

```math
\frac{e^x-e^0}{x-0} = e^c, \qquad \text{即}\quad e^x-1 = x\,e^c .
```

因 $c>0$，$e^c>1$，故 $x\,e^c>x$，从而 $e^x-1>x$，即 $e^x>1+x$。

**情形 2：$x=0$。** $e^0=1=1+0$，等号成立。

**情形 3：$x<0$。** 在区间 $[x,0]$ 上应用 MVT，存在 $c\in(x,0)$ 使

```math
\frac{e^0-e^x}{0-x}=e^c, \qquad \text{即}\quad 1-e^x = (-x)\,e^c .
```

因 $c<0$，$e^c<1$，故 $(-x)e^c<(-x)$（注意 $-x>0$），于是 $1-e^x<(-x)$，移项得 $e^x>1+x$。

综合三种情形，对所有 $x\in\mathbb R$，有 $e^x\ge1+x$，且等号当且仅当 $x=0$。□

（注：这是 $e^x$ 在 $x=0$ 处的一阶 Taylor 逼近的下界估计，也是凸函数切线在其下方的特例——$e^x$ 是凸函数，$y=1+x$ 是其在 $(0,1)$ 处的切线。）

## Problem 5（问题 5）

**题干原文：**
Let $X=\{\text{continuous functions on }[0,1]\}$ and $d(f,g)=\max_{x\in[0,1]}|f(x)-g(x)|$. Suppose $f_n\in X$ is a Cauchy sequence.
(1) Fix $x_0\in[0,1]$. Show $\lim_{n\to\infty}f_n(x_0)$ exists.
(2) Define $f(x):=\lim_{n\to\infty}f_n(x)$. Show that for all $\epsilon>0$ there is $N\in\mathbb N$ such that $|f_n(x)-f(x)|\le\epsilon$ for all $x\in[0,1]$, $n\ge N$.
(3) Show $f$ is continuous on $[0,1]$, i.e. $f\in X$.
(4) Show $\lim_{n\to\infty}f_n=f$ in $X$.

**中文：**

设 $X=\{[0,1]$ 上的连续函数$\}$，$d(f,g)=\max_{x\in[0,1]}|f(x)-g(x)|$。设 $f_n\in X$ 是 Cauchy 序列。
(1) 固定 $x_0\in[0,1]$，证明 $\lim_{n\to\infty}f_n(x_0)$ 存在。
(2) 定义 $f(x):=\lim_{n\to\infty}f_n(x)$，证明 $\forall\epsilon>0,\exists N$ 使 $|f_n(x)-f(x)|\le\epsilon$ 对一切 $x\in[0,1]$、$n\ge N$ 成立。
(3) 证明 $f$ 在 $[0,1]$ 连续，即 $f\in X$。
(4) 证明在 $X$ 中 $\lim_{n\to\infty}f_n=f$。

**证明：**

**(1) 逐点极限存在。** 固定 $x_0\in[0,1]$。因 $f_n$ 是 Cauchy，$\forall\epsilon>0,\exists N$，使 $m,n\ge N$ 时

```math
|f_m(x_0)-f_n(x_0)| \le \max_{x\in[0,1]}|f_m(x)-f_n(x)| = d(f_m,f_n) < \epsilon .
```

故实数序列 $(f_n(x_0))$ 是 $\mathbb R$ 中的 Cauchy 序列。因 $\mathbb R$ 完备（complete），其极限存在。记为 $f(x_0)=\lim_{n\to\infty}f_n(x_0)$。□

**(2) 一致收敛（$N$ 与 $x$ 无关）。** 取任意 $\epsilon>0$。由 Cauchy 性，$\exists N$，使 $m,n\ge N$ 时 $d(f_m,f_n)<\epsilon$，即对一切 $x\in[0,1]$：

```math
|f_m(x)-f_n(x)| < \epsilon .
```

固定 $x\in[0,1]$ 与 $n\ge N$，让 $m\to\infty$。因 $f_m(x)\to f(x)$（由 (1)），且绝对值函数连续，对不等式 $|f_m(x)-f_n(x)|<\epsilon$ 取 $m\to\infty$ 的极限得

```math
|f(x)-f_n(x)| \le \epsilon .
```

此式对一切 $x\in[0,1]$ 与一切 $n\ge N$ 成立。故 $N$ 只依赖 $\epsilon$、不依赖 $x$，即 $f_n$ **一致收敛（uniformly converge）** 到 $f$。□

**(3) $f$ 连续。** 固定 $x_0\in[0,1]$，证 $f$ 在 $x_0$ 连续。对任意 $\epsilon>0$：

由 (2)，$\exists N$ 使 $n\ge N$ 时 $\sup_x|f_n(x)-f(x)|<\epsilon/3$，特别地

```math
|f(x)-f_N(x)|<\epsilon/3,\qquad |f_N(x_0)-f(x_0)|<\epsilon/3 .
```

（即取 $n=N$，分别代入 $x$ 与 $x_0$。）

又 $f_N$ 连续（题设 $f_N\in X$），故 $\exists\delta>0$，使 $|x-x_0|<\delta$ 时 $|f_N(x)-f_N(x_0)|<\epsilon/3$。

于是当 $|x-x_0|<\delta$ 时，用题给的三项拆分：

```math
|f(x)-f(x_0)| \le |f(x)-f_N(x)| + |f_N(x)-f_N(x_0)| + |f_N(x_0)-f(x_0)| < \frac{\epsilon}{3}+\frac{\epsilon}{3}+\frac{\epsilon}{3} = \epsilon .
```

故 $f$ 在 $x_0$ 连续。由 $x_0$ 任意，$f$ 在 $[0,1]$ 连续，即 $f\in X$。□

（这正是"一致收敛保连续性"——连续函数列若一致收敛，则极限函数连续；若仅逐点收敛，此结论一般不成立。）

**(4) $f_n\to f$ 在 $X$ 中。** 需证 $d(f_n,f)=\sup_x|f_n(x)-f(x)|\to0$（$n\to\infty$）。

取任意 $\epsilon>0$。由 (2)，$\exists N$ 使 $n\ge N$ 时对一切 $x\in[0,1]$ 有 $|f_n(x)-f(x)|\le\epsilon$。于是对 $n\ge N$，

```math
d(f_n,f) = \max_{x\in[0,1]}|f_n(x)-f(x)| \le \epsilon .
```

即 $\lim_{n\to\infty}d(f_n,f)=0$，也就是在度量空间 $X$ 中 $f_n\to f$。□

**总结：** Problem 5 完整证明了——$C[0,1]$（带 sup 范数/一致范数）是**完备**的度量空间：任意 Cauchy 连续函数列都在该空间中收敛（逐点极限存在 → 一致收敛 → 极限连续 → 一致收敛到该连续函数）。这是"一致收敛空间的完备性"这一经典结论。

## 附：题末定理（Mean Value Theorem）

**定理原文：**
Let $f:[a,b]\to\mathbb R$. Suppose $f$ is continuous on $[a,b]$ and differentiable on $(a,b)$. Then there exists $c\in(a,b)$ such that $\dfrac{f(b)-f(a)}{b-a}=f'(c)$.

**中文：** 设 $f:[a,b]\to\mathbb R$ 在 $[a,b]$ 连续、在 $(a,b)$ 可微，则存在 $c\in(a,b)$ 使 $\dfrac{f(b)-f(a)}{b-a}=f'(c)$。本定理用于 Problem 3、4 的证明。
