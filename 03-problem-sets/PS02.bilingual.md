### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 1 (25pt)</span>

设 $a_n$ 和 $b_n$ 是实数的 sequence（序列）。

(1) 假设 $\displaystyle\lim_{n\to\infty} a_n$ 与 $\displaystyle\lim_{n\to\infty} b_n$ 都存在。证明
```math
\lim_{n\to\infty} (a_n b_n) = \Big(\lim_{n\to\infty} a_n\Big) \Big(\lim_{n\to\infty} b_n\Big).
```

(2) 给出一个例子：$\displaystyle\lim_{n\to\infty} (a_n b_n)$ 存在，但 $\displaystyle\lim_{n\to\infty} a_n$ 与 $\displaystyle\lim_{n\to\infty} b_n$ 都不存在。

> <span style="color:#2471a3;">**[solution]**</span> **Solution 1（解答一）.**
>
> **(1)** 记 $a = \lim a_n$，$b = \lim b_n$。第一步：收敛序列是有界的——这是证明的关键预备。由 $a_n \to a$，取 $\varepsilon = 1$，存在 $N_0$ 使 $n \ge N_0$ 时 $|a_n - a| < 1$，故 $|a_n| < |a| + 1$；对有限多个 $n < N_0$，$|a_n|$ 至多取有限个值。令
> ```math
> M := \max\{|a_1|, |a_2|, \ldots, |a_{N_0-1}|, |a|+1\} > 0
> ```
>
> （若 $N_0 = 1$，则 max 中的有限部分为空集，此时直接取 $M = |a|+1$），
> 则 $|a_n| \le M$ 对所有 $n$ 成立。
>
> 第二步：对任意 $n$，用"加一项减一项"（add and subtract）的技巧把乘积的差分解：
> ```math
> \begin{aligned}
> |a_n b_n - ab| &= |a_n b_n - a_n b + a_n b - ab| \\
> &\le |a_n||b_n - b| + |b||a_n - a| \\
> &\le M|b_n - b| + |b||a_n - a|.
> \end{aligned}
> ```
>
> 第三步：给定 $\varepsilon > 0$。因为 $a_n \to a$，存在 $N_1$ 使 $n \ge N_1$ 时 $|a_n - a| < \dfrac{\varepsilon}{2(|b|+1)}$（分母取 $|b|+1$ 而非 $|b|$，是为了避免 $b = 0$ 时分母为零）。因为 $b_n \to b$，存在 $N_2$ 使 $n \ge N_2$ 时 $|b_n - b| < \dfrac{\varepsilon}{2M}$。取 $N = \max\{N_1, N_2\}$，则当 $n \ge N$ 时
> ```math
> |a_n b_n - ab| \le M \cdot \frac{\varepsilon}{2M} + |b| \cdot \frac{\varepsilon}{2(|b|+1)} < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.
> ```
> 由 limit（极限）的定义，$\lim (a_n b_n) = ab = (\lim a_n)(\lim b_n)$。$\square$
>
> **(2)** 取
> ```math
> a_n = (-1)^n, \qquad b_n = (-1)^n.
> ```
> 则 $a_n b_n = (-1)^{2n} = 1$ 对所有 $n$，故 $\lim (a_n b_n) = 1$ 存在。但 $a_n = (-1)^n$ 不收敛：它有两个子列，$a_{2k} = 1 \to 1$ 与 $a_{2k+1} = -1 \to -1$，若序列收敛则所有子列收敛到同一极限，矛盾。同理 $b_n$ 不收敛。$\square$


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 证明 $\lim(a_n b_n)=ab$ 的困难在于：$a_n b_n - ab$ 里两个因子同时在变，没法像"和的极限"那样直接拆成两项分别控制。解法是往中间塞一个桥梁——把 $-ab$ 写成 $-a_n b + a_n b$（先减 $a_n b$ 再加回来），于是 $|a_n b_n - ab|\le |a_n||b_n-b| + |b||a_n-a|$，每一项里只剩一个因子在动。塞完之后立刻暴露第二个必要步骤：第一项里的 $|a_n|$ 仍是变量，必须先换成常数，于是有了"收敛必有界"的预备——取 $M$ 把它压住。最后把 $\varepsilon$ 劈成两半（ε/2 拆分），一半给 $M|b_n-b|$，一半给 $|b||a_n-a|$；分母写 $|b|+1$ 而非 $|b|$，是为了 $b=0$ 时不至于除零。这三步连起来是一个可复用模板：**有界化 → 加一项减一项 → ε/2 拆分**，本习题集 P4 会用到其中的「收敛必有界」一步，以后证明商的极限、连续函数的乘积则要用到完整模板。
>
> 🎥 *Colding 在 V04《Sequences; Convergence》讲解乘积极限时……*："So what you do is you're looking at $a_nb_n$, and you subtract $a$ and $b$, and then you add it immediately again."（翻译：你的做法是盯着 $a_n b_n$，先减去 $ab$，然后立刻又把它加回来。）


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> (2) 的价值在于给 (1) 划出边界：乘积极限存在并不倒推出两个因子各自的极限存在。取 $a_n=b_n=(-1)^n$，乘积 $(-1)^{2n}=1$ 恒为 $1$，极限当然是 $1$；但 $(-1)^n$ 本身是"符号来回翻"的序列，它的两个子列 $a_{2k}=1\to 1$、$a_{2k+1}=-1\to-1$ 收敛到不同极限，所以原序列不收敛。直觉上，两个"正负号互相抵消"的振荡乘在一起，振荡就被抹平了。注意这里用来证发散的工具是子列：收敛序列的所有子列都收敛到同一极限，这是 L07 才正式登场的实分析武器。反例思维也值得记：要否定一个"充分条件型"命题，只需给一个满足前提、破坏结论的具体对象，一个就够。

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 2 (25pt)</span>

求下列序列的极限（若极限存在），否则证明极限不存在。

(1) $\displaystyle a_n = \frac{n^2}{n+1} - \frac{n^2+1}{n}$

(2) $\displaystyle a_n = \frac{\sin(n)}{n}$

(3) $\displaystyle a_n = \frac{n^2}{\sqrt{n^6+1}} + \frac{n^2}{\sqrt{n^6+2}} + \frac{n^2}{\sqrt{n^6+3}} + \cdots + \frac{n^2}{\sqrt{n^6+n}}$，共 $n$ 项

> <span style="color:#2471a3;">**[solution]**</span> **Solution 2（解答二）.**
>
> **(1)** 先做代数化简——这是本题的要点：把两个"发散阶数"相同的分式拆成"整数部分 + 余项"。
> ```math
> \frac{n^2}{n+1} = \frac{(n+1)(n-1) + 1}{n+1} = n - 1 + \frac{1}{n+1},
> \qquad
> \frac{n^2+1}{n} = n + \frac{1}{n}.
> ```
> 因此
> ```math
> a_n = \Big(n - 1 + \frac{1}{n+1}\Big) - \Big(n + \frac{1}{n}\Big)
>     = -1 + \frac{1}{n+1} - \frac{1}{n}.
> ```
> 由于 $\dfrac{1}{n+1} \to 0$ 且 $\dfrac{1}{n} \to 0$（Archimedean property（阿基米德性质），见 L03），由 sum theorem（和的极限定理）得
> ```math
> \lim_{n\to\infty} a_n = -1 + 0 - 0 = -1.
> ```
>
> **(2)** 对任意 $n \ge 1$，
> ```math
> 0 \le |a_n| = \frac{|\sin n|}{n} \le \frac{1}{n}.
> ```
> 因为 $|\sin n| \le 1$ 对所有 $n$，且 $\dfrac{1}{n} \to 0$，由 squeeze theorem（夹逼定理）得 $|a_n| \to 0$，即 $a_n \to 0$。$\square$
>
> **(3)** 记 $a_n = \displaystyle\sum_{k=1}^{n} \frac{n^2}{\sqrt{n^6+k}}$。对每个 $k = 1, \ldots, n$，分母满足 $n^6 + 1 \le n^6 + k \le n^6 + n$，而平方根函数单调递增，故
> ```math
> \frac{n^2}{\sqrt{n^6+n}} \le \frac{n^2}{\sqrt{n^6+k}} \le \frac{n^2}{\sqrt{n^6+1}}.
> ```
> 对 $k$ 从 $1$ 到 $n$ 求和（$n$ 项，两端为常数项），得
> ```math
> n \cdot \frac{n^2}{\sqrt{n^6+n}} \le a_n \le n \cdot \frac{n^2}{\sqrt{n^6+1}}.
> ```
> 化简上下界：
> ```math
> \frac{n^3}{\sqrt{n^6+n}} = \frac{n^3}{n^3\sqrt{1 + 1/n^5}} = \frac{1}{\sqrt{1 + 1/n^5}} \to 1,
> ```
> ```math
> \frac{n^3}{\sqrt{n^6+1}} = \frac{n^3}{n^3\sqrt{1 + 1/n^6}} = \frac{1}{\sqrt{1 + 1/n^6}} \to 1.
> ```
> 两个夹逼边界都趋于 $1$，由 squeeze theorem（夹逼定理）得 $\displaystyle\lim_{n\to\infty} a_n = 1$。$\square$
>
> （数值验证：$n = 10$ 时 $a_n \approx 0.9999973$；$n = 10^4$ 时 $a_n \approx 1$ 精确到 $10^{-10}$ 以内。）


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> $a_n$ 的两项 $\tfrac{n^2}{n+1}$ 与 $\tfrac{n^2+1}{n}$ 各自都发散到 $+\infty$，不能直接套"和的极限 = 极限的和"——那是一个 $\infty-\infty$ 型不定式。本题要点是先把每个分式拆成"主导项 + 低阶余项"：$\tfrac{n^2}{n+1}=n-1+\tfrac{1}{n+1}$，$\tfrac{n^2+1}{n}=n+\tfrac{1}{n}$，这相当于各做一次多项式长除法。拆开之后两个发散的主导项 $n$ 恰好抵消，剩下的 $-1+\tfrac{1}{n+1}-\tfrac{1}{n}$ 每一项都有有限极限，此时极限运算法则才合法。（若直接套用「差的极限 = 极限的差」则会失败：两个分式的极限都是 $+\infty$，不在极限运算法则的适用范围之内。）这个"先分离主导项、让大的部分相消、余项单独取极限"的动作，与你将来在 6.006/6.046（Introduction to Algorithms，即 CLRS）里处理算法复杂度时"忽略低阶项、只保留最高阶"是同一种直觉的镜像：这里反其道而行，恰恰因为低阶余项才承载着真正的极限值 $-1$。


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> (2) 是 squeeze theorem（夹逼定理）的最小应用：$|\sin n|\le 1$，于是 $0\le \tfrac{|\sin n|}{n}\le \tfrac1n$，两端 $0$ 和 $1/n$ 都趋于 $0$，夹得中间也趋于 $0$。可复用的模板是：面对"有界振荡量除以无穷大量"，标准做法就是找一个上界为 $1/n$ 型衰减、下界为 $0$（或常数倍）的简单序列把它夹死。（这里的下界 $0$ 由绝对值 $|a_n| \ge 0$ 自动保证。）$\sin n$ 本身极限不存在——它在 $[-1,1]$ 内有界地来回振荡、永不趋于任何值，但乘上 $1/n$ 这个压缩因子后，振荡振幅被按 $1/n$ 的速率压扁，最终塌缩到 $0$——这和 6.004（CSAPP: Computer Systems: A Programmer's Perspective）浮点编码里"固定振幅乘 $2^{-k}$ 指数衰减"是同一类"振幅被逐步稀释"的现象。(3) 用的也是夹逼，只是上、下界要从 $n$ 项求和里构造，属于本模板的进阶版。

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 3 (15pt)</span>

设 $a_n$ 是实数序列，$L$ 是实数。证明下列两个命题等价——一个成立当且仅当另一个成立。

- 存在一个收敛到 $L$ 的 subsequence（子序列）$a_{n_k}$。
- 对任意 $\varepsilon > 0$，有无穷多个 $a_n$ 落在区间 $(L - \varepsilon, L + \varepsilon)$ 内。

> <span style="color:#2471a3;">**[solution]**</span> **Solution 3（解答三）.**
>
> **$(\Rightarrow)$** 设 $a_{n_k} \to L$。给定 $\varepsilon > 0$，由收敛定义，存在 $K$ 使得对所有 $k \ge K$，
> ```math
> |a_{n_k} - L| < \varepsilon, \qquad \text{即} \qquad a_{n_k} \in (L - \varepsilon, L + \varepsilon).
> ```
> 指标集 $\{n_k : k \ge K\}$ 是无限集（$n_k$ 严格递增），因此原序列有**无穷多个**项落在 $(L - \varepsilon, L + \varepsilon)$ 内。$\square$
>
> **$(\Leftarrow)$** 假设对任意 $\varepsilon > 0$，区间 $(L - \varepsilon, L + \varepsilon)$ 含有 $a_n$ 的无穷多项。我们递归地构造严格递增的指标 $n_1 < n_2 < n_3 < \cdots$，使得
> ```math
> |a_{n_k} - L| < \frac{1}{k} \qquad (k = 1, 2, 3, \ldots).
> ```
>
> - **基步**：取 $\varepsilon = 1$。区间 $(L-1, L+1)$ 含无穷多项 $a_n$，故指标集 $S_1 = \{n \in \mathbb{N} : |a_n - L| < 1\}$ 非空。由 well-ordering property（良序原理），$\mathbb{N}$ 的非空子集有最小元，取 $n_1 = \min S_1$。
> - **归纳步**：假设已选好 $n_1 < \cdots < n_k$。取 $\varepsilon = \dfrac{1}{k+1}$。区间 $(L - \frac{1}{k+1}, L + \frac{1}{k+1})$ 含无穷多项 $a_n$，其指标集 $S_{k+1} = \{n : |a_n - L| < \frac{1}{k+1}\}$ 是无限集，因此**无上界**（无限的自然数子集必无上界——否则它含于 $\{0, 1, \ldots, N\}$ 某个有限集）。特别地，$S_{k+1} \cap \{n > n_k\}$ 非空，由良序原理取 $n_{k+1} = \min\{n \in S_{k+1} : n > n_k\}$。这保证 $n_{k+1} > n_k$ 且 $|a_{n_{k+1}} - L| < \frac{1}{k+1}$。
>
> 由构造，$|a_{n_k} - L| < \frac{1}{k} \to 0$。对任意 $\varepsilon > 0$，取 $K$ 使 $\frac{1}{K} < \varepsilon$（Archimedean property），则对所有 $k \ge K$ 有 $|a_{n_k} - L| < \varepsilon$，即 $a_{n_k} \to L$。$\square$
>
> **结论**：两个命题等价。注意 $\Leftarrow$ 方向的构造**不需要选择公理**——每一步都由良序原理确定地选出最小指标。


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> $\Leftarrow$ 方向要把"每个 ε 邻域都含无穷多项"这个定性条件，变成"能挑出一串严格递增指标 $n_k$ 且 $a_{n_k}\to L$"这个定量结论。核心手法是把连续的 $\varepsilon$ 离散化：取 $\varepsilon=1/k$，得到一列越来越细的"阶梯"邻域 $(L-\tfrac1k, L+\tfrac1k)$，要求第 $k$ 个被选中的项落在第 $k$ 级阶梯里，即 $|a_{n_k}-L|<\tfrac1k$。为什么挑 $1/k$？因为它收敛到 $0$，且由 Archimedean 性质可任意小，于是 $1/k\to 0$ 自然把 $a_{n_k}$ 压向 $L$。但"每级阶梯里都有元素"只保证"存在"，真正困难的是**确定地**选出一个、还要保证指标严格递增——这正是 6.042J 的 well-ordering principle（良序原理）登场之处：非空自然数子集必有最小元，所以每步取 $S_{k+1}\cap\{n>n_k\}$ 的最小元，既可选、又自动大于 $n_k$。良序原理在这里扮演了"免于选择公理的确定性选择器"。


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 本题的两个等价命题其实是 Bolzano–Weierstrass 定理这幢大楼里的一块砖。BW 定理（L07）断言"任何有界序列都有收敛子列"，但"收敛子列"这个概念本身需要被刻画：一个序列何时能抽出收敛到 $L$ 的子列？答案正是本题——当且仅当 $L$ 的每个 ε 邻域都含无穷多项。$\Leftarrow$ 方向的构造（ε=1/k 阶梯 + 良序选指标）是"子列存在性"的一般机制，它不依赖序列是否有界，只依赖"$L$ 附近堆积无穷多项"这个局部条件。历史上，这条定理的证明最早由 Bernard Bolzano 在 1817 年（作为介值定理证明的引理）给出，约 50 年后 Karl Weierstrass 独立重新发现并推广，故得名。你会在 L07 讲义里看到同一个"每邻域含无穷多项 ⟺ 存在收敛到 $L$ 的子列"的刻画被反复调用；以后学 limit point（极限点）时，左边那个条件会直接变成 $L$ 是聚点的定义。
>
> 🎥 *Colding 在 V07《Bolzano-Weierstrass Theorem; Cauchy Sequences; Series》中陈述该定理……*："any bounded sequence, $a_n$, has a convergent subsequence."（翻译：任何有界序列 $a_n$ 都有收敛子列。）

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 4 (15pt)</span>

在可能的情况下，对下列序列找出一个单调的子序列和一个收敛的子序列。

(1) $a_n = \sin(n\pi/8)$

(2) $a_n = (-1)^n n$

> <span style="color:#2471a3;">**[solution]**</span> **Solution 4（解答四）.**
>
> **(1)** 序列 $a_n = \sin(n\pi/8)$ 是**周期序列**：$\sin((n+16)\pi/8) = \sin(n\pi/8 + 2\pi) = \sin(n\pi/8)$，周期为 $16$。因此它的值域是有限集
> ```math
> \{\sin(k\pi/8) : k = 0, 1, \ldots, 15\}
> ```
> ——至多 $16$ 个值，且每个值在序列中出现**无穷多次**（每 $16$ 项重复一次）。
>
> - **单调子序列**：取使 $\sin = 1$ 的指标。$n \equiv 4 \pmod{16}$ 时 $\sin(n\pi/8) = \sin(\pi/2 + 2k\pi) = 1$。于是子序列
>   ```math
>   a_{4}, \; a_{20}, \; a_{36}, \; \ldots \qquad (\text{即 } n_k = 4 + 16k)
>   ```
>   恒等于 $1$。常值序列既是 nondecreasing（非递减）又是 nonincreasing（非递增），因此它是一个单调子序列。
> - **收敛子序列**：同一个常值子序列收敛到 $1$。
>
> 事实上，因为值域有限、每个值重复无穷多次，任取一个值 $v$，取所有使 $a_n = v$ 的指标（按递增顺序）就得到一个收敛到 $v$ 的常值子序列——$v$ 例如可以是 $0, \pm\sin(\pi/8), \pm\frac{\sqrt2}{2}, \pm\frac{\sqrt{2+\sqrt2}}{2}, \pm 1$（值域共 9 个不同值，每个都重复无穷多次）中的任意一个。
>
> **(2)** 序列 $a_n = (-1)^n n$ 是无界序列（$|a_n| = n \to \infty$）。
>
> - **单调子序列**：存在，而且有两个——前者 strictly increasing（严格递增），后者 strictly decreasing（严格递减）：
>   ```math
>   a_{2k} = 2k \quad (k = 1, 2, \ldots) \quad \text{strictly increasing},
>   ```
>   ```math
>   a_{2k+1} = -(2k+1) \quad (k = 0, 1, \ldots) \quad \text{strictly decreasing}.
>   ```
> - **收敛子序列**：**不存在**。证明：设 $a_{n_k}$ 是任意子序列，其中 $n_k$ 是严格递增的指标序列，故 $n_k \ge k$（对任意正整数指标序列成立）。于是
>   ```math
>   |a_{n_k}| = |(-1)^{n_k} n_k| = n_k \ge k \to \infty,
>   ```
>   即 $|a_{n_k}|$ 无界，$a_{n_k}$ 不可能收敛（收敛序列必为有界序列——见 Problem 1 解答第一步）。$\square$


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> (1) 的 $a_n=\sin(n\pi/8)$ 周期为 $16$，值域是至多 $16$ 个点的有限集。由 6.042J 的鸽巢原理，把无穷多个 $n$ 分进有限多个"值"抽屉，必有某个值被无穷多项取到；于是把所有取该值的指标按递增顺序排出来，就得到一条常值子列——常值序列既单调又收敛，一次解决两个要求。这同时验证了 BW 定理对它的预言：有界序列必有收敛子列（这里直接手工造出一条）。(2) 的 $a_n=(-1)^n n$ 无界，结论是"单调子列存在、收敛子列不存在"。关键一步用到指标列的下界 $n_k\ge k$（严格递增的正整数指标序列必然满足），于是 $|a_{n_k}|=n_k\ge k\to\infty$ 无界；再套 P1 第一步证过的"收敛序列必有界"的逆否，无界就不可能收敛。P1 与 P4 的呼应说明"有界性"是贯穿序列收敛理论的闸门。
