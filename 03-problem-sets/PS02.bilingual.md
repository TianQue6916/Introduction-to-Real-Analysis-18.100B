## <span style="color:#c0392b">Problems（习题）</span>

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 1 (25pt)</span>

设 $a_n$ 和 $b_n$ 是实数的 sequence（序列）。

(1) 假设 $\displaystyle\lim_{n\to\infty} a_n$ 与 $\displaystyle\lim_{n\to\infty} b_n$ 都存在。证明
```math
\lim_{n\to\infty} (a_n b_n) = \Big(\lim_{n\to\infty} a_n\Big) \Big(\lim_{n\to\infty} b_n\Big).
```

(2) 给出一个例子：$\displaystyle\lim_{n\to\infty} (a_n b_n)$ 存在，但 $\displaystyle\lim_{n\to\infty} a_n$ 与 $\displaystyle\lim_{n\to\infty} b_n$ 都不存在。

> <span style="color:#2471a3;">**[solution]**</span> **Solution 1（解答一）.**
>
> **(1)** 记 $a = \lim a_n$，$b = \lim b_n$。第一步：收敛序列是有界的——这是证明的关键预备。由 $a_n \to a$，取 $\varepsilon = 1$，存在 $N_0$ 使 $n \ge N_0$ 时 $|a_n - a| < 1$，故 $|a_n| < |a| + 1$；对有限多个 $n < N_0$，$|a_n|$ 至多取有限个值。令
> ```math
> M := \max\{|a_1|, |a_2|, \ldots, |a_{N_0-1}|, |a|+1\} > 0
> ```
>
> （若 $N_0 = 1$，则 max 中的有限部分为空集，此时直接取 $M = |a|+1$），
> 则 $|a_n| \le M$ 对所有 $n$ 成立。
>
> 第二步：对任意 $n$，用"加一项减一项"（add and subtract）的技巧把乘积的差分解：
> ```math
> \begin{aligned}
> |a_n b_n - ab| &= |a_n b_n - a_n b + a_n b - ab| \\
> &\le |a_n||b_n - b| + |b||a_n - a| \\
> &\le M|b_n - b| + |b||a_n - a|.
> \end{aligned}
> ```
>
> 第三步：给定 $\varepsilon > 0$。因为 $a_n \to a$，存在 $N_1$ 使 $n \ge N_1$ 时 $|a_n - a| < \dfrac{\varepsilon}{2(|b|+1)}$（分母取 $|b|+1$ 而非 $|b|$，是为了避免 $b = 0$ 时分母为零）。因为 $b_n \to b$，存在 $N_2$ 使 $n \ge N_2$ 时 $|b_n - b| < \dfrac{\varepsilon}{2M}$。取 $N = \max\{N_1, N_2\}$，则当 $n \ge N$ 时
> ```math
> |a_n b_n - ab| \le M \cdot \frac{\varepsilon}{2M} + |b| \cdot \frac{\varepsilon}{2(|b|+1)} < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.
> ```
> 由 limit（极限）的定义，$\lim (a_n b_n) = ab = (\lim a_n)(\lim b_n)$。$\square$
>
> **(2)** 取
> ```math
> a_n = (-1)^n, \qquad b_n = (-1)^n.
> ```
> 则 $a_n b_n = (-1)^{2n} = 1$ 对所有 $n$，故 $\lim (a_n b_n) = 1$ 存在。但 $a_n = (-1)^n$ 不收敛：它有两个子列，$a_{2k} = 1 \to 1$ 与 $a_{2k+1} = -1 \to -1$，若序列收敛则所有子列收敛到同一极限，矛盾。同理 $b_n$ 不收敛。$\square$


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答的设计问题是：limit（极限）的四则运算法则里，为什么「和的法则」几乎不用单独费力，而「乘积的法则」必须当成一条 theorem（定理）认真证一遍？
>
> 先看失败的起点。要给 $\lim (a_n b_n) = ab$ 一个 $\varepsilon$-$N$ 证明，唯一可用的原料只有两句话：$a_n \to a$ 与 $b_n \to b$，而它们各自只承诺「离自己的目标足够近」。目标量 $|a_n b_n - ab|$ 里，$a_n$ 与 $b_n$ 同时在变。麻烦在于乘法的耦合是乘法而不是加法：求和法则之所以几乎白送，是因为 triangle inequality（三角不等式）直接给了 $|(a_n+b_n)-(a+b)| \le |a_n-a| + |b_n-b|$，误差天然可加、可拆成两半分别管。乘法没有任何现成的不等式能这样拆开。
>
> 于是有了第一个动作：往中间塞一个零。把 $-ab$ 写成 $-a_n b + a_n b$，即
>
> ```math
> a_n b_n - ab = a_n(b_n - b) + b(a_n - a).
> ```
>
> 这一步是纯代数恒等式，不需要任何假设，但它的效果是把「两个都在变」换成「一个在动、另一个被常数系数吸收」：第一项里 $(b_n-b)$ 小、$a_n$ 作系数，第二项里 $b$ 是常数、$(a_n-a)$ 小。选 $-a_n b$ 而不是 $-a b_n$ 的理由是把 $a_n$ 留在第一项，让 $|a_n|$ 显形，从而可以被界压住；若改减 $a b_n$，第一项变成 $|b_n||a_n-a|$，需要 $b_n$ 有界，逻辑完全对称，只是两个因子互换角色。两条路都通，选哪条只是记号习惯。
>
> 第二个动作由此被迫出现，不是可选项。第一项里 $|a_n|$ 仍是变量，而 $\varepsilon/(2M)$ 这种预算必须除以一个常数才成立。所以必须先证 bounded（有界）：取 $\varepsilon=1$ 得 $|a_n| < |a|+1$ 对所有 $n \ge N_0$ 成立，剩下有限前缀 $a_1,\ldots,a_{N_0-1}$ 取最大绝对值，合并成 $M>0$。这里有个容易跳过的事实：有限个数一定取得到最大值，这是实数序结构给的，与后面要用的 least upper bound（上确界）不是一回事，有限集取最大值靠归纳就够，不需要 completeness（完备性）。若这一步跳过，第一项的上界就随 $n$ 漂移，$\varepsilon/2$ 的预算无法落地。
>
> 第三个动作是 $\varepsilon/2$ 拆分。为什么是 2 而不是 3？因为拆完恰好剩两项要各自控制。系数 $M$ 与 $|b|$ 要吸收掉，所以给 $a_n$ 的预算写成 $\varepsilon/(2(|b|+1))$：分母加 1 是为了 $b=0$ 时不出现除零，这个改动只会让门槛更严，不破坏结论。
>
> 手算一例。设 $\varepsilon=0.01$、$b=3$、$M=7$。则要求 $|a_n-a| < 0.01/(2\cdot 4)=0.00125$，要求 $|b_n-b| < 0.01/14 \approx 0.000714$。若 $a_n \to a$ 从 $N_1=400$ 起达标、$b_n \to b$ 从 $N_2=900$ 起达标，就取 $N=900$，此时
>
> ```math
> |a_n b_n - ab| \le 7 \cdot 0.000714 + 3 \cdot 0.00125 \approx 0.005 + 0.00375 = 0.00875 < 0.01.
> ```
>
> 两半的预算在乘上系数后分别占 $0.5\varepsilon$ 与 $0.375\varepsilon$，加起来留了余量，这就是「劈成两半」在数值上的具体含义。
>
> 跨课程连接放在浮点上最自然。CSAPP 第 2 章的浮点乘法给出 $fl(xy) = (xy)(1+\delta)$、$|\delta| \le 2u$，其中 $u=2^{-53}$ 是 float64 的 unit roundoff（单位舍入误差）。把它改写成相对误差形式，就得到「乘积的相对误差约等于两个因子相对误差之和」，与上面那条恒等式结构同构：$a_n b_n - ab$ 的相对版本就是两份相对误差相加再加一个二阶小量。区别在于：浮点里 $u$ 是硬件固定的常数，每次乘法都注入一次、链越长累积越多；这里 $\varepsilon$ 是你任给的正数，$N$ 是它换来的门槛，$n$ 过了 $N$ 之后误差被压住而不再增长。给个量级：$u = 2^{-53} \approx 1.11\times 10^{-16}$，两个 float64 相乘的相对误差界约 $2.22\times 10^{-16}$，连乘一千次最坏累积到 $2.2\times 10^{-13}$，仍在 double 的可用精度内，这也解释了为什么现实中的乘法链很少靠这个界判错。
>
> 收束：把这三步记成一个有名字的 template（模板）——有界化、加一项减一项、$\varepsilon/2$ 拆分。以后证明 $\lim (a_n/b_n)=a/b$ 时要额外加一步「分母最终远离零」，其余骨架一模一样。


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> (2) 的价值不在于指出 (1) 有漏洞，而在于给 (1) 标出一条不能越过的边界：$\lim(a_n b_n)$ 存在推不出两个因子的 limit（极限）各自存在。
>
> 先看清逻辑位置。P1(1) 是一条「前提蕴含结论」的单向 statement（命题）：两个 limit 存在 $\Rightarrow$ 乘积的 limit 存在。它的 converse（逆命题）是下面的箭头反过来。要否定逆命题，只需造一个满足前提、破坏结论的对象，一个就够——这是 counterexample（反例）的标准用法，和后面对定理本身的工作量完全不对等：证一条蕴涵要覆盖所有情形，破一条蕴涵只要一个点。
>
> 但「必然失败」是有第一性原因的，不是碰巧找得到例子。映射 $(x,y) \mapsto xy$ 不是 injection（单射）：固定 $c$，所有满足 $xy=c$ 的点构成一条双曲线，整条曲线被压成一个点 $c$。也就是说乘积这个运算把信息销毁了，从像的性质反推原像的性质，原则上不可能。序列层面正是这样：$a_n$ 在 $1$ 与 $-1$ 之间来回跳，$b_n$ 同步地跳，于是 $a_n b_n = (-1)^{2n} = 1$ 恒定。相位同步是关键，若取 $b_n = (-1)^{n+1}$，乘积恒为 $-1$，同样收敛，只是极限换了号；若相位错开成 $\lfloor n/2 \rfloor$，乘积按 $-1,-1,1,1$ 循环，反而发散。可见「乘积收敛」这件事压根不携带「因子是否收敛」的信息，它只携带两者振荡方式的某种搭配。
>
> 换一个更能算的例子，说服力比 $(-1)^n$ 更强。取 $a_n = \sin(n\pi/2)$、$b_n = \cos(n\pi/2)$。逐项验算：$n=1$ 时 $1\cdot 0=0$；$n=2$ 时 $0\cdot(-1)=0$；$n=3$ 时 $(-1)\cdot 0=0$；$n=4$ 时 $0\cdot 1=0$。之所以恒为 0，是因为 $\sin\theta\cos\theta = \frac{1}{2}\sin 2\theta$，把 $\theta = n\pi/2$ 代入得 $\frac12 \sin(n\pi) = 0$。于是乘积是一个恒等于 0 的 constant（常值）序列，极限当然是 0；而两个因子分别在 $\{1,0,-1\}$ 与 $\{0,-1,0,1\}$ 上跳，各有两个子列收敛到不同值，都不收敛。这个例子的额外信息是：乘积不仅能收敛到非零常数，还能弱到恒等于零，说明「前提」与「结论」之间的落差可以大到什么程度。
>
> 判发散的工具是 subsequence（子序列）。规则是：convergent（收敛）序列的所有 subsequence（子序列）都收敛到同一个 limit（极限）。证明只需把 $\varepsilon$-$N$ 里的 $n$ 换成 $n_k$，并用 $n_k \ge k$（严格递增的正整数指标列必然满足，归纳两步即得）。于是只要找到两条子列分别趋于 $1$ 与 $-1$，就能宣布原序列不收敛。这套反证在 L07 里会反复出现，P4(2) 还要用一次，而且用法更进一步——那里连「子列收敛」都不可能出现，因为无界性直接堵死。
>
> 跨课程连接放在 6.042J 的等价关系上最自然。等价关系把一整个等价类里的多个元素粘成一个代表元，商掉之后你只知道代表元、不知道原像；这里是双曲线 $xy=c$ 上的整条曲线被粘成一个点 $c$，两者是同一件事的不同化身：不可逆就意味不能反推。区别要说清楚：等价关系是集合上的二元关系，必须满足自反、对称、传递三条性质，而这套性质在这里并不成立；这里只有「映射非单射」这一条事实。另一条更工程化的同类现象在 CLRS 的散列里：多个 key 落到同一个 bucket，你可以从 key 算出 hash，却不能从 hash 反推 key，冲突不可消除，只能靠链地址或开放寻址缓解。
>
> 收束：把这条反例记成一块边界标记。以后遇到商的极限、连续函数的乘积、级数的逐项相乘，都要先问一句「这个箭头是不是只单向」，再决定能不能拿它做代数变形。

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 2 (25pt)</span>

求下列序列的极限（若极限存在），否则证明极限不存在。

(1) $\displaystyle a_n = \frac{n^2}{n+1} - \frac{n^2+1}{n}$

(2) $\displaystyle a_n = \frac{\sin(n)}{n}$

(3) $\displaystyle a_n = \frac{n^2}{\sqrt{n^6+1}} + \frac{n^2}{\sqrt{n^6+2}} + \frac{n^2}{\sqrt{n^6+3}} + \cdots + \frac{n^2}{\sqrt{n^6+n}}$，共 $n$ 项

> <span style="color:#2471a3;">**[solution]**</span> **Solution 2（解答二）.**
>
> **(1)** 先做代数化简——这是本题的要点：把两个"发散阶数"相同的分式拆成"整数部分 + 余项"。
> ```math
> \frac{n^2}{n+1} = \frac{(n+1)(n-1) + 1}{n+1} = n - 1 + \frac{1}{n+1},
> \qquad
> \frac{n^2+1}{n} = n + \frac{1}{n}.
> ```
> 因此
> ```math
> a_n = \Big(n - 1 + \frac{1}{n+1}\Big) - \Big(n + \frac{1}{n}\Big)
>     = -1 + \frac{1}{n+1} - \frac{1}{n}.
> ```
> 由于 $\dfrac{1}{n+1} \to 0$ 且 $\dfrac{1}{n} \to 0$（Archimedean property（阿基米德性质），见 L03），由 sum theorem（和的极限定理）得
> ```math
> \lim_{n\to\infty} a_n = -1 + 0 - 0 = -1.
> ```
>
> **(2)** 对任意 $n \ge 1$，
> ```math
> 0 \le |a_n| = \frac{|\sin n|}{n} \le \frac{1}{n}.
> ```
> 因为 $|\sin n| \le 1$ 对所有 $n$，且 $\dfrac{1}{n} \to 0$，由 squeeze theorem（夹逼定理）得 $|a_n| \to 0$，即 $a_n \to 0$。$\square$
>
> **(3)** 记 $a_n = \displaystyle\sum_{k=1}^{n} \frac{n^2}{\sqrt{n^6+k}}$。对每个 $k = 1, \ldots, n$，分母满足 $n^6 + 1 \le n^6 + k \le n^6 + n$，而平方根函数单调递增，故
> ```math
> \frac{n^2}{\sqrt{n^6+n}} \le \frac{n^2}{\sqrt{n^6+k}} \le \frac{n^2}{\sqrt{n^6+1}}.
> ```
> 对 $k$ 从 $1$ 到 $n$ 求和（$n$ 项，两端为常数项），得
> ```math
> n \cdot \frac{n^2}{\sqrt{n^6+n}} \le a_n \le n \cdot \frac{n^2}{\sqrt{n^6+1}}.
> ```
> 化简上下界：
> ```math
> \frac{n^3}{\sqrt{n^6+n}} = \frac{n^3}{n^3\sqrt{1 + 1/n^5}} = \frac{1}{\sqrt{1 + 1/n^5}} \to 1,
> ```
> ```math
> \frac{n^3}{\sqrt{n^6+1}} = \frac{n^3}{n^3\sqrt{1 + 1/n^6}} = \frac{1}{\sqrt{1 + 1/n^6}} \to 1.
> ```
> 两个夹逼边界都趋于 $1$，由 squeeze theorem（夹逼定理）得 $\displaystyle\lim_{n\to\infty} a_n = 1$。$\square$
>
> （数值验证：$n = 10$ 时 $a_n \approx 0.9999973$；$n = 10^4$ 时 $a_n \approx 1$ 精确到 $10^{-10}$ 以内。）


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答的设计问题是：当两个分式各自都发散到 $+\infty$ 时，为什么不能直接做减法，而必须先把每个分式拆成「多项式部分 + 余项」再相减？
>
> 不能直接减的理由在于 limit law（极限运算法则）的 hypothesis（前提）没被满足。那条法则说的是：若两个 limit（极限）都存在且有限，则差的 limit 等于 limit 的差。这里两个分式都冲到 $+\infty$，$\infty - \infty$ 在实数里没有定义，套法则等于用一条前提不成立的定理，结论没有依据。这不是「答案算不出来」的技术困难，而是「表达式本身没有意义」的逻辑困难。
>
> 出路是代数化简，具体动作是两次多项式长除法：
>
> ```math
> \frac{n^2}{n+1} = \frac{(n+1)(n-1)+1}{n+1} = n - 1 + \frac{1}{n+1}, \qquad \frac{n^2+1}{n} = n + \frac{1}{n}.
> ```
>
> 验一遍：$n=3$ 时左边是 $9/4 = 2.25$，右边 $3-1+0.25 = 2.25$；另一个 $10/3 = 3.3333$，右边 $3+0.3333$ 也对得上。这一步为什么必须做到「常数项」为止，而不是只拆出主导项 $n$？因为两个主导项相减恰好抵消为零，剩下的是被抵消之后的第一个非零阶，如果只拆到 $n$、把后面的都当余项扔掉，相减得到的是两个 $O(1)$ 量的差，仍然是未定式，等于没做。
>
> 合并之后
>
> ```math
> a_n = -1 + \frac{1}{n+1} - \frac{1}{n} = -1 - \frac{1}{n(n+1)},
> ```
>
> 这一步的合并很关键：$\frac{1}{n+1}-\frac{1}{n} = -\frac{1}{n(n+1)}$ 把两个 $O(1/n)$ 的项压成一个 $O(n^{-2})$ 的项，衰减速度直接从一阶提到二阶。代入几个数看得更清楚：$n=1$ 时 $a_n = -1.5$，与直接算 $\frac12 - 2$ 一致；$n=10$ 时 $a_n = -1.0090909$；$n=100$ 时 $a_n = -1.00009901$。所有项都严格小于 $-1$，从下方向上贴，偏差按 $n^{-2}$ 缩，所以 $n$ 每乘 10，偏差就缩小到百分之一。这就是「从下方收敛」的具体形象。
>
> 换个说法：这一步是 asymptotic expansion（渐近展开）的零阶版本。渐近展开指的是把一个大 $n$ 下的表达式写成 $c_0 + c_1/n + c_2/n^2 + \cdots$ 这样的级数，前面几项决定常数极限、后面各项逐级变小、可以被单独控制。这里只用到了前两项：$c_0 = -1$ 是答案，$c_1 = 0$ 说明一阶项也恰好抵消，$c_2 = -1$ 是剩下最慢的尾巴。看出这一点，你就能预先判断「极限是 $-1$、从下方靠近、误差按 $n^{-2}$」，而不必等算完再观察。
>
> 跨课程连接有两处，方向相反，对照着记最省事。第一处是 CLRS 的复杂度分析：那里把 $3n^2+100n$ 直接写成 $\Theta(n^2)$，理由是低阶项被高阶项吸收，扔不扔不影响增长率。这里恰好反过来，必须保住低阶项，因为高阶项在相减时死掉了，活下来的是低阶项，它就是答案。同一套「分离主导项」的动作，一个用来丢弃，一个用来保留，判断标准是「相消之后谁还活着」。第二处是 CSAPP 第 2 章的整数溢出：若按原式用 int32 直接算，$n = 10^5$ 时 $n^2 = 10^{10}$ 已经超过 int32 的上限 $2^{31}-1 = 2147483647$，溢出后结果毫无意义；而先约分得到的 $-1 - 1/(n(n+1))$ 只需存 $10^{-5}$ 量级的量，double 的 53 位尾数（分辨率约 $2.2\times 10^{-16}$）绰绰有余，$n=10^5$ 时尾巴是 $10^{-10}$，仍能被分辨。也就是说，代数化简不只是为了理论上合法，它在数值实现上也是必需的：先算导致溢出，先约分则稳。
>
> 收束：给这个动作起个名字——主导项剥离法。遇到 $\sqrt{n^2+n}-n$、$\ln(n+1)-\ln n$、$\frac{1}{\sin n}-\frac{1}{n}$ 这类「同阶发散相减」的题，第一反应都是先各自展开到相消之后仍非零的那一阶，再看余项。


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答的设计问题是：一个自己都不收敛的振荡量，凭什么能靠乘上一个趋于零的因子把 limit（极限）逼出来？
>
> 先看为什么非夹不可。$a_n = \sin n$ 里 $n$ 取整数，$\sin n$ 的值在 $[-1,1]$ 内来回摆，永远不趋于任何数——要找两条子列分别逼近 $1$ 与 $-1$ 就能证它不收敛。既然它没有 limit（极限），一切 limit law（极限运算法则）都不能对 $\sin n$ 直接用。但整条序列 $b_n = \frac{1}{n}$ 也没有「乘积的极限等于极限的乘积」可套，因为第一个因子不合格。唯一能用的只剩 inequality（不等式）：$0 \le \frac{|\sin n|}{n} \le \frac{1}{n}$，两端都趋于零，中间被压住。
>
> squeeze theorem（夹逼定理）的证明短到三行，值得默写一遍：给定 $\varepsilon>0$，由右端趋于零存在 $N$，$n\ge N$ 时 $\frac1n < \varepsilon$；于是同一批 $n$ 上 $|a_n| \le \frac1n < \varepsilon$；左端的 $0$ 只用来保证 $|a_n|$ 非负，不参与估计。要点是：只用到「上界」这半边，下界交白卷也没关系，因为绝对值自带非负性。
>
> 顺带给出收敛速度的量级：要让 $\frac{1}{n} < 10^{-6}$，需要 $n > 10^{6}$。也就是说「$a_n$ 精确到百万分之一」这样的保证要等到第一百万项，而在此之前你对 $\sin n$ 的具体取值一无所知——上限管用，是因为它只依赖 $|\sin n|\le 1$ 这一条结构事实，不依赖任何一个具体值。
>
> 这个上界恰好是紧的，不是随手估的松界。取 $n=33$：$10.5\pi = 32.98672$，$33-10.5\pi = 0.01328$，而 $33 = \frac{\pi}{2} + 10\pi + 0.01328$，所以 $\sin 33 = \cos(0.01328) \approx 0.99991$，于是 $|a_{33}| \approx 0.03030$，而 $\frac{1}{33} = 0.030303$，两者只差万分之八。再取 $n=355$，它满足 $355/113$ 是 $\pi$ 的一个很好的近似：$113\pi = 354.99997$，$355-113\pi = 3.01\times10^{-5}$，所以 $\sin 355 \approx -3.01\times10^{-5}$，$|a_{355}| \approx 8.49\times10^{-8}$，比上界 $2.82\times10^{-3}$ 小了三万多倍。两个点合起来说明：上界 $1/n$ 在某些 $n$ 上几乎被取到，在另一些 $n$ 上松得离谱，实际值在 $[0, 1/n]$ 之间大幅摆动——而 squeeze 只需要上界成立，完全不需要知道实际值。
>
> 把「振幅被稀释」这件事量化一下会更清楚。若把 $\sin n$ 换成固定振幅 $1$ 乘指数因子 $2^{-k}$，降到 $8.7\times10^{-19}$ 只要 $k=60$ 步（$2^{-60}$）；而 $1/n$ 要降到同一量级，需要 $n \approx 1.15\times10^{18}$。两者极限都是零，可「稀释速率」差了十七个数量级，这就是多项式衰减与指数衰减的区别。
>
> 跨课程连接有两个落点。CSAPP 第 2 章的浮点编码给出同一图像的硬件版：float32 的最小正规数是 $2^{-126}$，再往下进入 subnormal（次正规）区，直到 $2^{-149}$ 才归零，一个固定振幅的值每乘一次 $2^{-1}$ 就往这个方向挪一格，126 步后掉出正规区。这里 $1/n$ 走的是同一条「振幅被逐级压扁」的路，只是幂次从指数换成了一次方，所以需要的步数从百级跳到 $10^{18}$ 级。另一处是 CLRS 的二分搜索：每步把区间减半，$2^{-k}$ 型收敛，$k$ 次比较后就精确到 $2^{-k}$ 的尺度；夹逼里若能用上二分构造的界，收敛会快得多的多。
>
> 至于 (3)，它用的是同一个定理的进阶形态：上、下界都不能从单项读出，必须先把 $n$ 项按分母的大小统一放缩成同一个常数项，再乘项数 $n$，得到 $n\cdot\frac{n^2}{\sqrt{n^6+n}}$ 与 $n\cdot\frac{n^2}{\sqrt{n^6+1}}$ 两条边界，各自化简成 $\frac{1}{\sqrt{1+1/n^5}}$ 与 $\frac{1}{\sqrt{1+1/n^6}}$，两端都趋于 $1$。要点是「项数在变」这件事本身要单独处理，不能假装它是固定的 $n$ 项中的某几项。
>
> 收束：把模板记成一句话——有界量乘趋于零的量必趋于零，具体做法是找一条算得出来的上界序列把它夹死；找界时优先用「$|{\cdot}|\le 1$」这类结构性的常数，而不是去求每一项的确切值。

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 3 (15pt)</span>

设 $a_n$ 是实数序列，$L$ 是实数。证明下列两个命题等价——一个成立当且仅当另一个成立。

- 存在一个收敛到 $L$ 的 subsequence（子序列）$a_{n_k}$。
- 对任意 $\varepsilon > 0$，有无穷多个 $a_n$ 落在区间 $(L - \varepsilon, L + \varepsilon)$ 内。

> <span style="color:#2471a3;">**[solution]**</span> **Solution 3（解答三）.**
>
> **$(\Rightarrow)$** 设 $a_{n_k} \to L$。给定 $\varepsilon > 0$，由收敛定义，存在 $K$ 使得对所有 $k \ge K$，
> ```math
> |a_{n_k} - L| < \varepsilon, \qquad \text{即} \qquad a_{n_k} \in (L - \varepsilon, L + \varepsilon).
> ```
> 指标集 $\{n_k : k \ge K\}$ 是无限集（$n_k$ 严格递增），因此原序列有**无穷多个**项落在 $(L - \varepsilon, L + \varepsilon)$ 内。$\square$
>
> **$(\Leftarrow)$** 假设对任意 $\varepsilon > 0$，区间 $(L - \varepsilon, L + \varepsilon)$ 含有 $a_n$ 的无穷多项。我们递归地构造严格递增的指标 $n_1 < n_2 < n_3 < \cdots$，使得
> ```math
> |a_{n_k} - L| < \frac{1}{k} \qquad (k = 1, 2, 3, \ldots).
> ```
>
> - **基步**：取 $\varepsilon = 1$。区间 $(L-1, L+1)$ 含无穷多项 $a_n$，故指标集 $S_1 = \{n \in \mathbb{N} : |a_n - L| < 1\}$ 非空。由 well-ordering property（良序原理），$\mathbb{N}$ 的非空子集有最小元，取 $n_1 = \min S_1$。
> - **归纳步**：假设已选好 $n_1 < \cdots < n_k$。取 $\varepsilon = \dfrac{1}{k+1}$。区间 $(L - \frac{1}{k+1}, L + \frac{1}{k+1})$ 含无穷多项 $a_n$，其指标集 $S_{k+1} = \{n : |a_n - L| < \frac{1}{k+1}\}$ 是无限集，因此**无上界**（无限的自然数子集必无上界——否则它含于 $\{0, 1, \ldots, N\}$ 某个有限集）。特别地，$S_{k+1} \cap \{n > n_k\}$ 非空，由良序原理取 $n_{k+1} = \min\{n \in S_{k+1} : n > n_k\}$。这保证 $n_{k+1} > n_k$ 且 $|a_{n_{k+1}} - L| < \frac{1}{k+1}$。
>
> 由构造，$|a_{n_k} - L| < \frac{1}{k} \to 0$。对任意 $\varepsilon > 0$，取 $K$ 使 $\frac{1}{K} < \varepsilon$（Archimedean property），则对所有 $k \ge K$ 有 $|a_{n_k} - L| < \varepsilon$，即 $a_{n_k} \to L$。$\square$
>
> **结论**：两个命题等价。注意 $\Leftarrow$ 方向的构造**不需要选择公理**——每一步都由良序原理确定地选出最小指标。


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答的设计问题是：怎么把「$L$ 的每个 $\varepsilon$-neighborhood（邻域）里都有无穷多项」这个只讲存在性的定性条件，变成一个能一步一步执行的构造，从而真的产出一条收敛到 $L$ 的 subsequence（子序列）？
>
> 第一步是把连续的 $\varepsilon$ 离散化。要构造的是可数无穷多步，每一步都得有一个具体的误差预算，而 $\varepsilon$ 是连续的、可任意取，没法直接编号。取 $\varepsilon = 1/k$ 就得到一列越来越细的阶梯：第 $k$ 级是 $(L-\frac1k, L+\frac1k)$，要求第 $k$ 个被选中的项落进第 $k$ 级，即 $|a_{n_k}-L| < \frac1k$。为什么偏偏取 $1/k$？两个理由：一是它趋于零，由 Archimedean property（阿基米德性质）对任意 $\varepsilon>0$ 都能找到 $K = \lceil 1/\varepsilon \rceil$ 使 $\frac1K < \varepsilon$，于是「阶梯细到足够」这件事总能兑现；二是它与 $\varepsilon$-$N$ 定义直接对接，把 $\frac1k$ 当 $\varepsilon$ 用，转述一步就完事，不需要额外引理。换成 $2^{-k}$ 也完全可以，只是最后的换算要多一步对数。
>
> 第二步是一个不起眼但必须点明的引理：自然数的无限子集一定 unbounded（无界）。反证：若 $S \subseteq \mathbb{N}$ 有上界 $N$，则 $S$ 含于 $\{0,1,\ldots,N\}$，而后者有限。有了它，「每级阶梯含无穷多项」才能推出「$S_k$ 里存在比 $n_{k-1}$ 更大的指标」，构造才走得下去。若只有「非空」而不知道「无穷」，构造会卡在某一级上——这就是为什么原条件必须写成无穷多项，不能弱化成「至少一项」。
>
> 第三步是良序原理，也是这条注真正的技术核心。当 $L=1$、$a_n = (-1)^n(1+\frac1n)$ 时，$S_k = \{n : |a_n - 1| < \frac1k\}$ 里的 $n$ 必须是偶数，且 $n>k$，即 $S_k = \{2, 4, 6, \ldots\}$ 中大于 $k$ 的那些。若偷懒取 $n_k = \min S_k$，跑出来是 $2, 4, 4, 6, \ldots$——第三项与第二项相等，指标不再严格递增，$a_{n_k}$ 就成了「带重复的子列」，收敛性论证随之崩塌。正确的做法是每步取 $S_{k+1} \cap \{n > n_k\}$ 的最小元：$n_1 = 2$，$n_2 = \min\{4,6,\ldots\} = 4$，$n_3 = \min\{6,8,\ldots\} = 6$，于是 $n_k = 2k$，且 $|a_{2k}-1| = \frac{1}{2k} < \frac1k$，逐级达标。这一个交集 $\{n > n_k\}$ 就是「子列」三个字的全部内容。
>
> 良序原理在这里扮演的角色值得说透：它提供的是一个确定性的选择器。axiom of choice（选择公理）说的是，给定任意多个非空集合，可以同时从每一个里取出一个元素；它对「取哪个」不作任何规定，因此是非构造性的。若这里只有「$S_{k+1}$ 非空」这一条信息，要构造无穷序列就得动用它的 countable choice（可数选择）版本。而良序原理保证了「最小元」的存在且唯一，每步取谁完全由 $\mathbb{N}$ 的序决定，不需要任何自由选择，所以这条证明是构造性的、可以写成程序。
>
> 跨课程连接有两处。6.042J 的 well-ordering principle（良序原理）与 strong induction（强归纳法）是等价的，那里用它来证「所有自然数都满足某性质」；这里反过来用它来定义序列——从「终止性」工具变成「生成性」工具，方向相反，但都靠同一句「非空子集有最小元」。另一处是 CLRS 的 greedy algorithm（贪心算法），典型载体是 Huffman 编码与 Kruskal 最小生成树这类题：每一步从当前可行集合里取最小的那个元素，正确性论证需要两条——所取元素合法（属于当前候选集）、取完之后问题规模单调推进。这里的构造与之一一对应：合法性是 $n_{k+1}\in S_{k+1}$，推进性是 $n_{k+1}>n_k$。区别在于贪心额外还要论证「局部最优导致全局最优」，而那一条在这里根本不存在——我们只要序列能造出来、能收敛，不要求它在任何意义下最优。
>
> 收束：这个「阶梯 + 良序取最小」的构造是很多后续概念的原型：Cauchy sequence（柯西序列）的 $\frac1k$ 门槛、limit point（极限点）的邻域刻画、乃至实数完备性的套区间证明，用的都是同一套「先把要求离散成阶梯，再靠良序逐步兑现」的手法。


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答的设计问题是：这条等价刻画自己站得住，那它在 Bolzano–Weierstrass theorem（波尔扎诺–魏尔斯特拉斯定理）的证明链条里占什么位置？
>
> 先把 BW 定理拆成两半看。它的陈述是「有界序列必有收敛子列」，这句话其实由两块拼成：第一块是「有界序列必有 limit point（极限点）」，即存在某个 $L$，它的每个邻域都含无穷多项；第二块是「若 $L$ 的每个邻域都含无穷多项，则存在收敛到 $L$ 的 subsequence（子序列）」。第一块靠二分法或套区间完成，第二块正是本题的 $\Leftarrow$ 方向。所以本题不是 BW 的推论，而是 BW 的一半零件：没有它，BW 的后半句无从谈起。
>
> 两者的强弱关系要分清。BW 需要 bounded（有界），本题完全不需要——只要 $L$ 附近堆积了无穷多项，无论序列整体跑到多远，都能抽出收敛到 $L$ 的子列；反过来，本题必须指定 $L$，而 BW 不指定，只说「存在某个」。这是一个「局部判据」与「全局存在性」的分工：BW 断言盒子里有东西，本题告诉你盒子具体在哪、怎么打开。
>
> 历史这一层只作背景，机制才是主线。这条引理最早由 Bernard Bolzano 在 1817 年的一篇论文里证出，用途是他证明 intermediate value theorem（介值定理）时需要一个「区间上连续、两端异号则必有根」的支撑，而支撑点正是「有界序列有凝聚点」。约半个世纪后，Karl Weierstrass 在柏林的教学中独立使用并系统化，据研究者对听课笔记的整理，1863/64 冬季学期的讲义里已经出现这个引理，另一处记载把它记在 1865 年的课程上。后来两人的名字被并列冠在定理上，是后人的追认，不是他们自己的署名。
>
> 数字层面，这条刻画解释了「为什么有界序列一定挤得出子列，却没人能写出那个子列」。取 $a_n = \sin n$，它有界于 $[-1,1]$，按 BW 必有收敛子列。用本题的判据操作：取 $\delta = 2^{-10} \approx 9.77\times10^{-4}$，问 $[-\delta,\delta]$ 里有多少项。$\{n \bmod 2\pi\}$ 在 $[0,2\pi)$ 上均匀分布，$\sin n \in [-\delta,\delta]$ 对应圆周上总长 $4\delta$ 的那几段区间，占比约 $\frac{4\delta}{2\pi} = \frac{2\delta}{\pi} \approx 6.2\times10^{-4}$；前一万项里大约 6 个，前一百万项里约 620 个。可见「无穷多项」是靠 $n\to\infty$ 兑现的，任何一个有限前缀里都只有零星几个——这正是为什么 BW 的证明只能断言存在，不能给出显式公式。
>
> 反过来，能显式写出的情形也有：$a_n = (-1)^n(1+\frac1n)$ 有界于 $[-2,2]$，取 $L=1$，则 $S_k = \{n \text{ 为偶数且 } n>k\}$，按注 5 的构造得 $n_k = 2k$，子列 $a_{2k} = 1+\frac{1}{2k}$ 单调下降趋于 1。这个例子把「有界」与「堆积」两个条件同时兑现，可以当作模板背下来。
>
> 跨课程连接放在 CLRS 的二分搜索上最贴切，因为 BW 的二分法证明本身就是一次二分搜索。做法是：把 $[-M,M]$ 对半切，问左半还是右半含无穷多项，含的那一半保留，长度减半，重复。要缩到长度 $\delta$，需要 $\log_2\frac{2M}{\delta}$ 步，取 $M=1$、$\delta=10^{-6}$ 就是 $\log_2(2\times10^6) \approx 21$ 步。区别在于：二分搜索跑在离散有序数组上，终止条件是左右指针相遇，输出的是一个确定的下标；BW 的二分是无限过程，每步只能断言「至少一半含有无穷多项」，靠 nested intervals（区间套）保证交集非空，输出的只是「存在某个极限点」这条存在性结论，拿不到坐标。
>
> 🎥 *Colding*："any bounded sequence, $a_n$, has a convergent subsequence."（翻译：任何有界序列 $a_n$ 都有收敛子列。）
>
> 收束：把本题记成「子列存在性的局部判据」——给定候选极限 $L$，抽出收敛到 $L$ 的子列这件事，等价于 $L$ 的每个邻域里堆着无穷多项。以后见到 limit point（极限点）的定义，会发现左边那个条件已经直接被改名为「$L$ 是序列的凝聚点」。

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 4 (15pt)</span>

在可能的情况下，对下列序列找出一个单调的子序列和一个收敛的子序列。

(1) $a_n = \sin(n\pi/8)$

(2) $a_n = (-1)^n n$

> <span style="color:#2471a3;">**[solution]**</span> **Solution 4（解答四）.**
>
> **(1)** 序列 $a_n = \sin(n\pi/8)$ 是**周期序列**：$\sin((n+16)\pi/8) = \sin(n\pi/8 + 2\pi) = \sin(n\pi/8)$，周期为 $16$。因此它的值域是有限集
> ```math
> \{\sin(k\pi/8) : k = 0, 1, \ldots, 15\}
> ```
> ——至多 $16$ 个值，且每个值在序列中出现**无穷多次**（每 $16$ 项重复一次）。
>
> - **单调子序列**：取使 $\sin = 1$ 的指标。$n \equiv 4 \pmod{16}$ 时 $\sin(n\pi/8) = \sin(\pi/2 + 2k\pi) = 1$。于是子序列
>   ```math
>   a_{4}, \; a_{20}, \; a_{36}, \; \ldots \qquad (\text{即 } n_k = 4 + 16k)
>   ```
>   恒等于 $1$。常值序列既是 nondecreasing（非递减）又是 nonincreasing（非递增），因此它是一个单调子序列。
> - **收敛子序列**：同一个常值子序列收敛到 $1$。
>
> 事实上，因为值域有限、每个值重复无穷多次，任取一个值 $v$，取所有使 $a_n = v$ 的指标（按递增顺序）就得到一个收敛到 $v$ 的常值子序列——$v$ 例如可以是 $0, \pm\sin(\pi/8), \pm\frac{\sqrt2}{2}, \pm\frac{\sqrt{2+\sqrt2}}{2}, \pm 1$（值域共 9 个不同值，每个都重复无穷多次）中的任意一个。
>
> **(2)** 序列 $a_n = (-1)^n n$ 是无界序列（$|a_n| = n \to \infty$）。
>
> - **单调子序列**：存在，而且有两个——前者 strictly increasing（严格递增），后者 strictly decreasing（严格递减）：
>   ```math
>   a_{2k} = 2k \quad (k = 1, 2, \ldots) \quad \text{strictly increasing},
>   ```
>   ```math
>   a_{2k+1} = -(2k+1) \quad (k = 0, 1, \ldots) \quad \text{strictly decreasing}.
>   ```
> - **收敛子序列**：**不存在**。证明：设 $a_{n_k}$ 是任意子序列，其中 $n_k$ 是严格递增的指标序列，故 $n_k \ge k$（对任意正整数指标序列成立）。于是
>   ```math
>   |a_{n_k}| = |(-1)^{n_k} n_k| = n_k \ge k \to \infty,
>   ```
>   即 $|a_{n_k}|$ 无界，$a_{n_k}$ 不可能收敛（收敛序列必为有界序列——见 Problem 1 解答第一步）。$\square$


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答的设计问题是：为什么「值域只有有限多个值」这一条信息，就能一次性解决「存在单调子列」和「存在收敛子列」两个要求？
>
> 先说清楚这里不能直接套 6.042J 的 pigeonhole principle（鸽巢原理）。那条原理的陈述是：若 $|A| > |B|$ 且 $A$ 有限，则从 $A$ 到 $B$ 的任何函数都不是 injection（单射），必有碰撞。它要求出发集有限。而这里的出发集是 $\mathbb{N}$，无限，所以严格来说不能用它。真正的论证要换一句话：设值域为 $V = \{v_1,\ldots,v_r\}$，若每个 $v_i$ 都只被有限多个 $n$ 取到，那么全体被取到的指标是有限多个有限集的并，仍是有限集，与 $\mathbb{N}$ 无限矛盾。于是至少有一个值被无穷多项取到。这个「有限并保持有限」的步骤是无限版鸽巢的全部内容，它和「无限并可以是有限」形成对照——后者在 $r$ 随 $n$ 增长时成立，正是 P2(3) 里项数在变所踩的坑。
>
> 有了「某个值被无穷多项取到」这条结论，剩下的是排序。把取该值的指标按从小到大排成 $n_1 < n_2 < \cdots$，得到的子列 $a_{n_k}$ 恒等于那个值 $v$。constant（常值）序列既是 nondecreasing（非递减）又是 nonincreasing（非递增），所以它同时满足「单调子列」和「收敛子列」两项要求，一次交付两个答案。这里省力的根本原因不是技巧，而是两个要求所定义的集合有交集：常值序列落在交集里。凡是遇到「同时求 A 与 B」的题，先问 A∩B 是否非空，比分别造两个对象省一半功夫。
>
> 把数字算出来。(1) 的周期是 16，因为 $\frac{\pi}{8}\times 16 = 2\pi$；值域是 $0,\ \pm\sin\frac{\pi}{8},\ \pm\sin\frac{\pi}{4},\ \pm\sin\frac{3\pi}{8},\ \pm 1$，其中 $\sin\frac{\pi}{8}\approx 0.38268$、$\sin\frac{\pi}{4}\approx 0.70711$、$\sin\frac{3\pi}{8}\approx 0.92388$，共 9 个互不相同的值。值 $\sin = 1$ 只在 $n \equiv 4 \pmod{16}$ 时出现，在前 1000 项里共有 $\frac{996-4}{16}+1 = 63$ 个；值 $\sin = 0$ 在 $n \equiv 0$ 或 $8 \pmod{16}$ 时出现，前 1000 项里分别有 62 个与 63 个，合计 125 个。可见每个值的出现频率都稳定在 $\frac{1}{16}$ 或 $\frac{2}{16}$ 量级，没有哪个值被稀释掉——这就是「有限值域 + 无限项」必有一个值无穷次重复的具体形状。
>
> (2) 的 $a_n = (-1)^n n$ 恰好站在反面：值域无限、序列无界，于是两种子列的命运分岔。单调子列不但存在，还有两条：偶数项 $a_{2k} = 2k$ 严格递增，奇数项 $a_{2k+1} = -(2k+1)$ 严格递减。收敛子列则一个也没有。证明只用一行：设 $a_{n_k}$ 是任意子列，$n_k$ 严格递增且为正整数，故 $n_k \ge k$（归纳：$n_1 \ge 1$；若 $n_k \ge k$ 则 $n_{k+1} > n_k \ge k$，整数性给出 $n_{k+1}\ge k+1$）。于是 $|a_{n_k}| = n_k \ge k$，取 $k \ge 100$ 就有 $|a_{n_k}|\ge 100$，整条子列根本进不了 $(-1,1)$，更谈不上收敛。这里用的是 P1 第一步那条「convergent（收敛）序列必有界」的逆否命题：无界 $\Rightarrow$ 不收敛。
>
> 跨课程连接落在 CSAPP 第 6 章的 cache 上，因为那里有一个同构的「有限像、无限原像」局面。设某 L1 的 set index 取 6 位，共 64 个 set，而地址是 32 位，于是 $2^{32}/64 = 2^{26} \approx 6.7\times10^{7}$ 个不同的块必须共享同一个 set。只要有程序按 $2^{6}$ 的步长扫内存，就会把几乎全部地址压进同一个 set 反复替换，这就是 conflict miss（冲突缺失）的来源。区别在于目的相反：cache 里想尽办法减少碰撞（提高相联度、改索引函数），这里反而要利用碰撞——碰撞越严重，「某个值被无穷多项取到」的保证越强。同一个数学事实，一个是灾祸，一个是工具。
>
> 收束：P1 证过「收敛必有界」，P4 用它的逆否一口气否掉 (2) 的全部子列；这两处呼应说明有界性是序列收敛理论的总闸门。而 (1) 之所以轻松，是因为周期序列把闸门换成了更强的条件——值域有限，这比有界强得多，强到可以直接手工造出子列，连 BW 定理都不必请出来。
