## 术语口径

| English（中文） | 易混点说明 |
| --- | --- |
| Riemann integrable（黎曼可积） | 指上下黎曼和/黎曼积分有定义且相等；是本题一切积分的默认前提，不代表连续或可导。 |
| upper/lower Riemann sum（上/下黎曼和） | 分割（partition）上取 supremum/infimum 得到的和；用来刻画可积性，与「积分值」不同。 |
| partition（分割/划分） | 区间的一组分点，不要求等距；黎曼和的收敛与分割的细分有关。 |
| continuity（连续性） | 逐点连续；注意「连续 ⇒ 黎曼可积」，但反过来不成立。 |
| Mean Value Theorem, MVT（中值定理） | 连续 + 可导时 `f(b)-f(a)=f'(c)(b-a)`；本题 P2、P5 都用它。 |
| integral mean value theorem（积分中值定理） | 连续函数在某点取到其「平均值」；P2(1) 的核心。 |
| differentiability（可微性） | 逐点导数存在；P2(2)、P3 额外要求导数连续。 |
| integration by parts（分部积分） | 由乘积求导法则 `(FG)'=F'G+FG'` 积分而来；P3。 |
| change of variables / substitution（换元积分） | 用单调换元把积分变量替换；P4，需 `φ'` 连续且 `φ'>0`。 |
| Lipschitz / contraction（利普希茨/压缩映射） | 距离被常数 `<1` 收缩的映射；P5 用压缩思想证唯一性。 |
| uniform bound（一致有界） | 对区间内所有点成立的同一个上界；P2(2) 的 `|f'|≤M` 就是一致有界。 |
| Picard iteration（皮卡迭代） | 解 ODE 的逐次逼近法；P5(2)(3) 的思路本质上是它的雏形。 |

## Problem 1（问题 1）

**题干原文：**
> Let f(x) and g(x) be functions defined on [a, b]. Suppose that f(x) and g(x) are Riemann integrable and that f(x) ≤ g(x) for all x ∈ [a, b].
> (1) Show that ∫_a^b f(x) dx ≤ ∫_a^b g(x) dx. Hint: Consider ∫_a^b [g(x) − f(x)] dx.
> (2) Further assume f(x) and g(x) are continuous and ∫_a^b f(x) dx = ∫_a^b g(x) dx. Show that f(x) = g(x) for all x ∈ [a, b].

**中文：** 设 f(x)、g(x) 是定义在 [a, b] 上的函数。设 f、g 都黎曼可积（Riemann integrable），且对所有 x ∈ [a, b] 有 f(x) ≤ g(x)。
(1) 证明 ∫_a^b f(x) dx ≤ ∫_a^b g(x) dx。提示：考虑 ∫_a^b [g(x) − f(x)] dx。
(2) 再设 f、g 连续，且 ∫_a^b f(x) dx = ∫_a^b g(x) dx。证明对所有 x ∈ [a, b] 有 f(x) = g(x)。

**证明：**

**(1)** 令 h(x) = g(x) − f(x)。因 f、g 均黎曼可积，故 h 也黎曼可积（可积函数之差可积）。又由条件 h(x) ≥ 0 对一切 x ∈ [a, b] 成立。

对任意分割（partition）P，设其任一子区间上的下确界为 `m_i = inf_{x∈[x_{i-1},x_i]} h(x)`。因 h ≥ 0，故每个 `m_i ≥ 0`，于是下黎曼和（lower Riemann sum）

```math
L(h, P) = \sum_i m_i \Delta x_i \ge 0 .
```

由于 h 可积，其黎曼积分等于所有下黎曼和的上确界（supremum），故

```math
\int_a^b h(x)\,dx = \sup_P L(h, P) \ge 0 .
```

另一方面，由积分的线性性（linearity），

```math
\int_a^b h(x)\,dx = \int_a^b g(x)\,dx - \int_a^b f(x)\,dx .
```

故

```math
\int_a^b g(x)\,dx - \int_a^b f(x)\,dx \ge 0 ,
```

即 ∫_a^b f(x) dx ≤ ∫_a^b g(x) dx。∎

**(2)** 仍令 h(x) = g(x) − f(x) ≥ 0。由 (1) 及题设积分相等，得

```math
\int_a^b h(x)\,dx = \int_a^b g(x)\,dx - \int_a^b f(x)\,dx = 0 .
```

现因 f、g 连续，h = g − f 也在 [a, b] 上连续。我们用反证法（proof by contradiction）：假设存在 x₀ ∈ [a, b] 使 h(x₀) > 0。

由 h 在 x₀ 连续，取 ε = h(x₀)/2 > 0，存在 δ > 0，使得当 `|x − x₀| < δ` 时有

```math
|h(x) - h(x_0)| < \frac{h(x_0)}{2}
\implies h(x) > \frac{h(x_0)}{2} > 0 .
```

取一个包含在 [a, b] 内、且含于 (x₀−δ, x₀+δ) 中的非退化闭区间 [α, β]（例如取 α = max(a, x₀−δ/2)，β = min(b, x₀+δ/2)，此时 α < β）。在 [α, β] 上 h(x) ≥ h(x₀)/2 > 0，于是由 (1) 的单调性，

```math
\int_a^b h(x)\,dx \ge \int_\alpha^\beta h(x)\,dx \ge \frac{h(x_0)}{2}(\beta-\alpha) > 0 ,
```

这与 ∫_a^b h(x) dx = 0 矛盾。

因此处处 h(x) ≤ 0，又由定义 h = g − f ≥ 0，故 h ≡ 0，即 f(x) = g(x) 对所有 x ∈ [a, b] 成立。∎

## Problem 2（问题 2）

**题干原文：**
> Let f : R → R be a continuous function.
> (1) Show that for any [a, b] ⊂ R, there exists c ∈ [a, b] such that f(c) = (1/(b−a)) ∫_a^b f(x) dx.
> (2) Assume f(x) is differentiable on (0, 1) and there exists M > 0 such that |f'(x)| ≤ M for all x ∈ (0, 1). Show that for all n ∈ N,
> |∫_0^1 f(x) dx − (1/n) Σ_{j=1}^{n} f(j/n)| ≤ M/n .

**中文：** 设 f : R → R 连续。
(1) 证明对任意 [a, b] ⊂ R，存在 c ∈ [a, b] 使 f(c) = (1/(b−a)) ∫_a^b f(x) dx。
(2) 设 f 在 (0, 1) 上可导，且存在 M > 0 使对所有 x ∈ (0, 1) 有 |f'(x)| ≤ M。证明对所有 n ∈ N，有 |∫_0^1 f(x) dx − (1/n) Σ_{j=1}^n f(j/n)| ≤ M/n。

**证明：**

**(1)** 设 `m = min_{[a,b]} f`，`M = max_{[a,b]} f`（连续函数在闭区间取到最值，即极值定理 Extreme Value Theorem）。由积分单调性（见 Problem 1(1)），

```math
m \le \frac{1}{b-a}\int_a^b f(x)\,dx \le M .
```

令 `A = (1/(b-a)) ∫_a^b f(x) dx`。由介值定理（Intermediate Value Theorem），f 在 [a, b] 上连续且 A 介于最小值 m 与最大值 M 之间，故存在 c ∈ [a, b] 使 f(c) = A。∎

（注意：本题给出的是**积分中值定理**（integral mean value theorem）的最直接版本。）

**(2)** 把 [0, 1] 等分成 n 份，分点为 `x_j = j/n`（j = 0, …, n），每份宽 1/n。于是黎曼和的「矩形近似」为

```math
\frac{1}{n}\sum_{j=1}^{n} f\!\left(\frac{j}{n}\right) ,
```

它对应在每个小区间 [(j−1)/n, j/n] 上取右端点的矩形和。我们逐小区间估计误差。

对任意 x ∈ [(j−1)/n, j/n]，由中值定理（Mean Value Theorem）存在 ξ ∈ (x, j/n) 使

```math
f\!\left(\frac{j}{n}\right) - f(x) = f'(\xi)\left(\frac{j}{n} - x\right) ,
```

故由 |f'| ≤ M，

```math
\left| f\!\left(\frac{j}{n}\right) - f(x) \right| \le M\left(\frac{j}{n} - x\right) .
```

于是对第 j 个小区间积分，得到

```math
\left| \int_{(j-1)/n}^{j/n} f(x)\,dx - \frac{1}{n} f\!\left(\frac{j}{n}\right) \right|
= \left| \int_{(j-1)/n}^{j/n} \left[ f(x) - f\!\left(\frac{j}{n}\right) \right] dx \right|
\le \int_{(j-1)/n}^{j/n} M\left(\frac{j}{n} - x\right) dx .
```

直接计算：

```math
\int_{(j-1)/n}^{j/n} M\left(\frac{j}{n} - x\right) dx
= M \cdot \frac{1}{2}\left(\frac{j}{n} - \frac{j-1}{n}\right)^2
= \frac{M}{2 n^2} .
```

把所有 n 个小区间加起来，用三角不等式（triangle inequality），

```math
\left| \int_0^1 f(x)\,dx - \frac{1}{n}\sum_{j=1}^{n} f\!\left(\frac{j}{n}\right) \right|
\le \sum_{j=1}^{n} \frac{M}{2 n^2} = \frac{M}{2n} .
```

这得到的是 `M/(2n)`，比题目要求的 `M/n` 更强，因此

```math
\left| \int_0^1 f(x)\,dx - \frac{1}{n}\sum_{j=1}^{n} f\!\left(\frac{j}{n}\right) \right|
\le \frac{M}{2n} \le \frac{M}{n} .
```

∎

> 注：这里每小区间的精确误差是 M/(2n$^{2}$)，累加后为 M/(2n)。题目只要求 M/n，是一个较松但足够的上界；我们的推导顺带给出了更优的常数。

## Problem 3（问题 3）

**题干原文：**
> Let F(x) and G(x) be two differentiable functions defined on [a, b]. Further assume that F'(x) and G'(x) are continuous on [a, b]. Show that
> ∫_a^b F'(x) G(x) dx = F(b) G(b) − F(a) G(a) − ∫_a^b F(x) G'(x) dx.

**中文：** 设 F(x)、G(x) 是定义在 [a, b] 上的两个可微函数，再设 F'(x)、G'(x) 在 [a, b] 上连续。证明分部积分公式 ∫_a^b F'(x) G(x) dx = F(b) G(b) − F(a) G(a) − ∫_a^b F(x) G'(x) dx。

**证明：**

由乘积求导法则（product rule），

```math
(FG)'(x) = F'(x) G(x) + F(x) G'(x) .
```

由于 F'、G' 连续，且 F、G 可微（从而连续），故 (FG)' 在 [a, b] 上连续，于是 (FG)' 黎曼可积。由微积分基本定理（Fundamental Theorem of Calculus），

```math
\int_a^b (FG)'(x)\,dx = F(b) G(b) - F(a) G(a) .
```

另一方面，由积分的线性性，

```math
\int_a^b (FG)'(x)\,dx
= \int_a^b F'(x) G(x)\,dx + \int_a^b F(x) G'(x)\,dx .
```

两式联立得

```math
F(b) G(b) - F(a) G(a)
= \int_a^b F'(x) G(x)\,dx + \int_a^b F(x) G'(x)\,dx ,
```

移项即得所需公式：

```math
\int_a^b F'(x) G(x)\,dx
= F(b) G(b) - F(a) G(a) - \int_a^b F(x) G'(x)\,dx .
```

∎

> 注：这就是**分部积分**（integration by parts）的标准形式，条件是 F、G 可导且导数连续，保证 (FG)' 可积、能套用微积分基本定理。

## Problem 4（问题 4）

**题干原文：**
> Let f : [a, b] → R be a continuous function and ϕ : [A, B] → R be a differentiable function with ϕ'(x) > 0. Further assume that ϕ(A) = a, ϕ(B) = b and that ϕ'(x) is continuous on [A, B]. Show that
> ∫_a^b f(x) dx = ∫_A^B f(ϕ(y)) ϕ'(y) dy.

**中文：** 设 f : [a, b] → R 连续，ϕ : [A, B] → R 可导且 ϕ'(x) > 0，再设 ϕ(A) = a、ϕ(B) = b、ϕ' 在 [A, B] 上连续。证明换元公式 ∫_a^b f(x) dx = ∫_A^B f(ϕ(y)) ϕ'(y) dy。

**证明：**

因为 ϕ'(y) > 0 且连续，ϕ 在 [A, B] 上严格递增（strictly increasing）。又 ϕ(A) = a、ϕ(B) = b，故 ϕ 是从 [A, B] 到 [a, b] 的一一对应（双射 bijection），且 ϕ 连续、ϕ⁻¹ 也连续。

定义 F(x) 为 f 的一个原函数：

```math
F(x) = \int_a^x f(t)\,dt , \quad x \in [a, b] .
```

因 f 连续，由微积分基本定理，F 在 [a, b] 上可导且 F'(x) = f(x)。

考虑复合函数 `H(y) = F(ϕ(y))`，y ∈ [A, B]。由链式法则（chain rule），

```math
H'(y) = F'(\phi(y)) \phi'(y) = f(\phi(y)) \phi'(y) .
```

由于 f、ϕ、ϕ' 都连续，H' 连续，故可积。再由微积分基本定理，

```math
\int_A^B f(\phi(y)) \phi'(y)\,dy
= \int_A^B H'(y)\,dy
= H(B) - H(A)
= F(\phi(B)) - F(\phi(A))
= F(b) - F(a) .
```

而

```math
F(b) - F(a) = \int_a^b f(x)\,dx .
```

故

```math
\int_a^b f(x)\,dx = \int_A^B f(\phi(y)) \phi'(y)\,dy .
```

∎

> 注：这就是**换元积分**（change of variables / substitution）。关键点有二：(i) ϕ 严格递增保证 ϕ(A)=a、ϕ(B)=b 时积分上下限对应正确（若 ϕ'<0 则上下限会颠倒并多一个负号）；(ii) ϕ' 连续使 f(ϕ(y))ϕ'(y) 连续可积，从而能套用微积分基本定理。

## Problem 5（问题 5）

**题干原文：**
> In this problem, we concern the uniqueness of the continuous solution of the equation
> y'(x) = y(x)$^{2}$, for all x ∈ [0, 1],   (?)
> y(0) = a.
> (1) Let y(x) be a continuous function on [0, 1]. Show that y(x) solves (?) if and only if
> y(x) = a + ∫_0^x y(t)$^{2}$ dt for all x ∈ [0, 1].   (??)
> (2) Let y₁(x) and y₂(x) be two continuous functions on [0, 1]. Show that there exists 1 > b > 0 such that the following holds. Suppose y₁(x) and y₂(x) both satisfy (??) and y₁(x₀) = y₂(x₀) for some x₀ ∈ [0, 1 − b]. Then y₁(x) = y₂(x) for all x ∈ [x₀, x₀ + b]. Hint: Pick a suitable b to deduce max |y₁(x) − y₂(x)| ≤ (1/2) max |y₁(x) − y₂(x)| over [x₀, x₀+b].
> (3) Let y₁(x) and y₂(x) be two continuous functions on [0, 1]. Suppose y₁ and y₂ both solve (?). Show that y₁(x) = y₂(x) for all x ∈ [0, 1].

**中文：** 本题讨论微分方程初值问题
y'(x) = y(x)$^{2}$，x ∈ [0, 1]；y(0) = a
的连续解的唯一性。
(1) 设 y(x) 是 [0, 1] 上的连续函数。证明 y 解 (?) 当且仅当 y(x) = a + ∫_0^x y(t)$^{2}$ dt 对所有 x ∈ [0, 1] 成立（即 (??)）。
(2) 设 y₁、y₂ 是 [0, 1] 上的两个连续函数。证明存在 1 > b > 0 使下列成立：若 y₁、y₂ 都满足 (??)，且对某 x₀ ∈ [0, 1 − b] 有 y₁(x₀) = y₂(x₀)，则 y₁(x) = y₂(x) 对所有 x ∈ [x₀, x₀ + b] 成立。提示：选取合适的 b 推出 max_{[x₀,x₀+b]} |y₁ − y₂| ≤ (1/2) max_{[x₀,x₀+b]} |y₁ − y₂|。
(3) 设 y₁、y₂ 都解 (?)，证明 y₁(x) = y₂(x) 对所有 x ∈ [0, 1] 成立。

**证明：**

**(1) 必要性（⇒）。** 设 y 解 (?)，则 y 可导且 y'(x) = y(x)$^{2}$。因 y 可导必连续，故 y(t)$^{2}$ 连续。由微积分基本定理，

```math
y(x) - y(0) = \int_0^x y'(t)\,dt = \int_0^x y(t)^2\,dt .
```

又 y(0) = a，故

```math
y(x) = a + \int_0^x y(t)^2\,dt .
```

**充分性（⇐）。** 设 y 连续且满足 (??)。由 y 连续，被积函数 y(t)$^{2}$ 连续，故右端 `a + ∫_0^x y(t)$^{2}$ dt` 是 x 的可微函数，其导数为 y(x)$^{2}$（微积分基本定理）。因此 y 可导且

```math
y'(x) = y(x)^2 .
```

又令 x = 0，由 (??) 得 y(0) = a + 0 = a。故 y 解 (?)。∎

**(2)** 设 y₁、y₂ 都满足 (??)。记 `d(x) = |y₁(x) − y₂(x)|`。对任意 x ∈ [x₀, x₀ + b]，由 (??)：

```math
y_1(x) - y_2(x)
= \left(a + \int_0^x y_1^2\,dt\right) - \left(a + \int_0^x y_2^2\,dt\right)
= \int_0^x \big(y_1(t)^2 - y_2(t)^2\big)\,dt .
```

利用平方差 `y₁$^{2}$ − y₂$^{2}$ = (y₁ − y₂)(y₁ + y₂)`，并注意 x₀ 处 y₁ = y₂，故从 x₀ 到 x 积分即可（0 到 x₀ 的部分两解差值抵消）：

```math
y_1(x) - y_2(x)
= \int_{x_0}^x \big(y_1(t) - y_2(t)\big)\big(y_1(t) + y_2(t)\big)\,dt .
```

取绝对值并用积分不等式：

```math
|y_1(x) - y_2(x)|
\le \int_{x_0}^x |y_1(t) - y_2(t)| \cdot |y_1(t) + y_2(t)|\,dt .
```

现在 y₁、y₂ 都在 [0, 1] 上连续，故有界，设 `|y_i(t)| ≤ C`（i = 1, 2）对 t ∈ [0, 1] 成立，从而 `|y₁(t) + y₂(t)| ≤ 2C`。于是

```math
|y_1(x) - y_2(x)|
\le 2C \int_{x_0}^x |y_1(t) - y_2(t)|\,dt .
```

令 `D = max_{[x₀,x₀+b]} |y₁ − y₂|`（连续函数在闭区间取到最大值）。对 x ∈ [x₀, x₀+b]，区间长 x − x₀ ≤ b，故

```math
|y_1(x) - y_2(x)| \le 2C \cdot D \cdot (x - x_0) \le 2C D b .
```

上式对一切 x ∈ [x₀, x₀+b] 成立，取左边关于 x 的最大值，得

```math
D \le 2C b\, D .
```

我们**选取 b** 满足 `0 < b < 1` 且 `2C b ≤ 1/2`，即

```math
b = \min\!\left(\frac{1}{4C},\, \frac{1}{2}\right) > 0 .
```

（这里取 1/2 同时保证 b < 1，当然若 C 较小则 b 可取到 1/2。）于是

```math
D \le \frac{1}{2} D .
```

由于 D ≥ 0，这迫使 **D = 0**（若 D > 0 则两边除以 D 得 1 ≤ 1/2，矛盾）。故

```math
\max_{x\in[x_0,x_0+b]} |y_1(x) - y_2(x)| = 0 ,
```

即 y₁(x) = y₂(x) 对所有 x ∈ [x₀, x₀ + b] 成立。∎

> 注：这正是提示所说的「压缩估计」。核心在于利用 (??) 把两点函数值的差「折叠」回区间上的最大差值，并让收缩因子 2Cb < 1，从而迫使其为零。这正是 Picard–Lindelöf（皮卡–林德勒夫）唯一性定理的雏形。

**(3)** 由 (1)，解 (?) 等价于满足 (??)。设 y₁、y₂ 都解 (?)，我们要证 y₁(x) = y₂(x) 对一切 x ∈ [0, 1] 成立。

由初值条件 y₁(0) = y₂(0) = a。取 (2) 中给出的 b > 0。

**第一步**：在 x₀ = 0 处 y₁ = y₂，由 (2)（注意 0 ∈ [0, 1 − b]），得 y₁ = y₂ 在 [0, b] 上成立。

**逐步推进**：假设已在 [0, x₀] 上证明了 y₁ = y₂，且 x₀ ≤ 1 − b。那么在 x₀ 处 y₁(x₀) = y₂(x₀)，再次由 (2)，得 y₁ = y₂ 在 [x₀, x₀ + b] 上成立。

以步长 b 递推，经过有限步（最多 ⌈1/b⌉ 步）可覆盖整个 [0, 1]：取 x₀ = 0, b, 2b, …, 直到越过 1。每一步的起点都满足 y₁ = y₂，而由 (2) 该点的相等关系向右传播长度 b。因此

```math
y_1(x) = y_2(x) \quad \text{对所有 } x \in [0, 1] .
```

∎

> 注：唯一性的本质是「局部相等关系可沿 x 轴向右传播」。只要在任意一点相等，且两解满足同一积分方程 (??)，就能在长度为 b 的一段上保持相等；再由初值 y₁(0) = y₂(0) = a 起步，逐段推进覆盖全区间。这里 b 是全局固定的（由两解的公共上界 C 决定），所以步数有限，传播能到达 x = 1。
