### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 1 (10pt)</span>

设 $x < y$ 是两个实数。证明存在 rational number（有理数）$r \in \mathbb{Q}$ 使得 $x < r < y$。

提示：使用 Archimedean property（阿基米德性质）。你还可以使用以下事实：设 $S$ 是 $\mathbb{Z}$ 的非空子集且上有界，则 $S$ 有最大元素。

> <span style="color:#2471a3;">**[solution]**</span> **Solution 1（解答一）.**
>
> 由 $x < y$，差 $y - x > 0$ 是正实数。由 Archimedean property（阿基米德性质，L03 / TBB Theorem 1.11, p.28），存在自然数 $N \in \mathbb{N}$ 使得
> ```math
> N(y - x) > 1, \qquad \text{即} \qquad \frac{1}{N} < y - x.
> ```
>
> 现在考虑整数集合
> ```math
> S := \{m \in \mathbb{Z} : m \le Nx\}.
> ```
> $S$ 非空：由 Archimedean property，存在整数 $m_0$ 使得 $m_0 \le Nx$（例如取 $m_0 = -\lfloor |Nx| \rfloor - 1$ 即可保证）。$S$ 上有界（$Nx$ 本身是上界）。由题给事实，$S$ 有最大元素，记为 $m$，则
> ```math
> m \le Nx < m + 1.
> ```
> 令
> ```math
> r := \frac{m+1}{N} \in \mathbb{Q}.
> ```
> 验证：
> ```math
> r = \frac{m+1}{N} > \frac{Nx}{N} = x,
> ```
> 且
> ```math
> r = \frac{m+1}{N} \le \frac{Nx + 1}{N} = x + \frac{1}{N} < x + (y - x) = y.
> ```
> 故 $x < r < y$。$\square$
>
> （构造的直观：$m+1$ 是"第一个超过 $Nx$ 的整数"，即 $\lfloor Nx \rfloor + 1$；$r$ 是分母为 $N$ 的、恰好落在 $x$ 右侧的分点，而 $\frac{1}{N}$ 小于整个区间长度，所以它不会越过 $y$。）


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 目标是在任意两个实数 $x<y$ 之间塞进一个有理数，即证有理数在实数里稠密。构造分两步，两步都用 Archimedean 性质：第一步取 $N$ 使 $\tfrac1N<y-x$，让单位网格 $\tfrac1N$ 比区间长度还细，保证"不会越过 $y$"；第二步在 $\mathbb{Z}$ 里取最大的 $m$ 使 $m\le Nx$，那么 $m+1$ 就是第一个超过 $Nx$ 的整数（即 $\lfloor Nx\rfloor+1$，floor function（取整函数）），于是 $r=\tfrac{m+1}{N}$ 恰好落在 $x$ 右侧、又因网格够细而不越出 $y$。历史脉络：这条"任给量总能被有限次倍加超越"的性质以 Archimedes 命名（《论球与圆柱》Axiom V，约公元前 3 世纪），思想源头是 Eudoxus 的穷竭法（method of exhaustion，用内接多边形不断细分、穷尽逼近面积的方法），而"Archimedean property"这一命名本身出自 Otto Stolz 在 19 世纪的工作。从公理体系看，实数完备性公理本身并不自带"自然数无上界"，所以必须把 $\mathbb{N}$ 无上界作为一条性质单独确立；它也是本习题集里所有"$\tfrac1N<\varepsilon$"操作的共同根基。（事实上同一个构造稍加改动，就能得到 $x$ 与 $y$ 之间的无穷多个有理数——对每个足够大的 $N$ 各造一个分点。）
>
> 🎥 *Colding 在 V03《How to Write a Proof; Archimedean Property》中给出该性质的一种表述……*："this is the theorem that the natural numbers is not bounded from above."（翻译：这条定理说的是：自然数集没有上界。）

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 2 (20pt)</span>

设 $E$ 是 $\mathbb{R}$ 的非空有界子集。定义
```math
F := \{x^2 \mid x \in E\}.
```
证明 $\sup F$ 存在，且
```math
\sup F = \max\{(\sup E)^2, (\inf E)^2\}.
```

> <span style="color:#2471a3;">**[solution]**</span> **Solution 2（解答二）.**
>
> 记 $M := \sup E$，$m := \inf E$。由 $E$ 非空有界，$m$ 与 $M$ 都是实数（completeness axiom，完备性公理）。
>
> **第一步：$\sup F$ 存在。** 对任意 $x \in E$，有 $m \le x \le M$，故
> ```math
> |x| \le \max\{|m|, |M|\},
> ```
> 从而
> ```math
> x^2 \le \max\{m^2, M^2\}.
> ```
> 因此 $\max\{m^2, M^2\}$ 是 $F$ 的一个上界；而 $F$ 非空（$E$ 非空）。由完备性公理，非空有上界的集合有上确界，$\sup F$ 存在。$\checkmark$
>
> **第二步：$\sup F \le \max\{m^2, M^2\}$。** 这是第一步的直接推论：$\max\{m^2, M^2\}$ 是 $F$ 的上界，故 $\sup F \le \max\{m^2, M^2\}$。
>
> **第三步：$\sup F \ge \max\{m^2, M^2\}$。** 设 $R := \max\{|m|, |M|\}$，则 $R^2 = \max\{m^2, M^2\}$。我们要证明 $\sup F \ge R^2$。分两种情况：
>
> *情况 A：$R = |M|$。* 此时 $|M| \ge |m|$。
>
> 先设 $M \ge 0$。给定 $\varepsilon > 0$，取
> ```math
> \delta := \min\Big\{\frac{\varepsilon}{4M+4},\; \frac{M}{2},\; 1\Big\} > 0
> ```
> （若 $M = 0$，则 $|M| \ge |m|$ 迫使 $m = 0$，$E = \{0\}$，$\sup F = 0 = R^2$ 平凡成立；下面设 $M > 0$）。由上确界的定义，$\exists x \in E$ 使 $x > M - \delta$。由于 $\delta \le M/2$，有 $x > M/2 > 0$，于是
> ```math
> x^2 > (M - \delta)^2 = M^2 - 2M\delta + \delta^2 \ge M^2 - 2M\delta \ge M^2 - \varepsilon,
> ```
> 其中最后一步用 $\delta \le \frac{\varepsilon}{4M+4} < \frac{\varepsilon}{2M}$。因为 $x^2 \in F$，$\sup F \ge x^2 > M^2 - \varepsilon = R^2 - \varepsilon$。$\varepsilon$ 任意，故 $\sup F \ge R^2$。
>
> 再设 $M < 0$。则 $|M| = -M \ge |m|$。因 $m \le M < 0$，有 $m \le 0$ 且 $|m| = -m \le -M = |M|$，即 $m \ge M$；又 $m \le M$，故 $m = M$。于是 $E \subseteq [M, M] = \{M\}$ 是单点集，$F = \{M^2\}$，$\sup F = M^2 = R^2$。$\checkmark$
>
> *情况 B：$R = |m|$。* 对称论证。
>
> 先设 $m \le 0$。给定 $\varepsilon > 0$，由下确界的定义，$\exists x \in E$ 使 $x < m + \delta$，其中
> ```math
> \delta := \min\Big\{\frac{\varepsilon}{-4m+4},\; \frac{-m}{2},\; 1\Big\} > 0
> ```
> （$m < 0$ 时 $-m > 0$；若 $m = 0$，则 $|m| \ge |M|$ 迫使 $M = 0$，$E = \{0\}$，平凡）。因为 $x < m + \delta < m/2 < 0$，有 $|x| = -x > -(m + \delta) = |m| - \delta$，于是
> ```math
> x^2 = |x|^2 > (|m| - \delta)^2 \ge |m|^2 - 2|m|\delta \ge |m|^2 - \varepsilon = R^2 - \varepsilon.
> ```
> 故 $\sup F > R^2 - \varepsilon$，由 $\varepsilon$ 任意，$\sup F \ge R^2$。
>
> 再设 $m > 0$。则所有 $x \in E$ 满足 $x \ge m > 0$，故 $x^2 \ge m^2$ 对所有 $x \in E$，于是 $F$ 的每个元素 $\ge m^2$，特别地 $\sup F \ge m^2 = R^2$（此时 $R = |m| = m$）。$\checkmark$
>
> 综合两种情况，$\sup F \ge R^2 = \max\{m^2, M^2\}$。
>
> **结论**：由第二、三步，
> ```math
> \boxed{\;\sup F = \max\{(\sup E)^2, (\inf E)^2\}.\;}
> ```
>
> （直觉：平方映射 $x \mapsto x^2$ 在区间 $[m, M]$ 上的最大值总是出现在端点 $m$ 或 $M$ 处，因为 $x^2$ 在 $[0, \infty)$ 上递增、在 $(-\infty, 0]$ 上递减——但严格证明必须处理"最大值点是否被 $E$ 取到"的问题，这正是上面用 sup/inf 的逼近性质逐情形论证的原因。）


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 直觉上，平方映射 $x\mapsto x^2$ 在区间 $[m,M]$ 上的最大值必在端点 $m$ 或 $M$ 处取到，所以 $\sup F$ 应当是 $\max(m^2, M^2)$。但直觉里藏着一个陷阱：$E$ 不一定是闭区间，端点 $m$、$M$ 可能根本不在 $E$ 里，你没法写"取 $x=M$"一步了事。这就是为什么严格证明要用 sup 的**逼近性质**：对任意 $\varepsilon>0$ 存在 $x\in E$ 使 $x>M-\delta$，再靠 $\delta$ 把 $x^2$ 与 $M^2$ 的差压到 $\varepsilon$ 以内。注意平方会放大误差——$x^2-(M-\delta)^2=2M\delta-\delta^2$，误差线性地乘上 $2M$，所以 $\delta$ 必须取成 $\varepsilon/(4M)$ 的量级；那串 $\delta=\min\{\tfrac{\varepsilon}{4M+4},\tfrac M2,1\}$ 里后两项纯粹是技术保险：$\tfrac M2$ 保证 $x$ 保持正号、$1$ 是归一化。整个第三步（情况 A 与情况 B）的本质是一个可复用模板：**要证 $\sup F\ge c$，就对每个 $\varepsilon$ 造一个 $f(x)>c-\varepsilon$ 的元素**。这正是下一题（P3）要单独提炼的工具。

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 3 (10pt)</span>

设 $E$ 是 $\mathbb{R}$ 的非空上有界子集。证明存在一个序列 $a_n$ 使得 $a_n \in E$ 且
```math
\lim_{n\to\infty} a_n = \sup E.
```
提示：证明对任意 $\varepsilon > 0$，存在 $a \in E$ 使得 $a > \sup E - \varepsilon$。

> <span style="color:#2471a3;">**[solution]**</span> **Solution 3（解答三）.**
>
> 记 $s := \sup E$。先确认提示中的事实：由 $s$ 是 $E$ 的上确界——即 $s$ 是上界且是最小上界——对任意 $\varepsilon > 0$，$s - \varepsilon$ **不是** $E$ 的上界（否则 $s - \varepsilon < s$ 是更小的上界，与 $s$ 最小矛盾）。故存在 $a \in E$ 使
> ```math
> a > s - \varepsilon.
> ```
>
> 现在对每个 $n \in \mathbb{N}$，取 $\varepsilon = \dfrac{1}{n}$，由上述事实选一个 $a_n \in E$ 满足
> ```math
> a_n > s - \frac{1}{n}.
> ```
> 另一方面，$s$ 是 $E$ 的上界，故 $a_n \le s$。于是
> ```math
> s - \frac{1}{n} < a_n \le s
> \quad\Longrightarrow\quad
> |a_n - s| < \frac{1}{n}.
> ```
> 对任意 $\varepsilon > 0$，取 $N$ 使 $\frac{1}{N} < \varepsilon$（Archimedean property），则对所有 $n \ge N$ 有 $|a_n - s| < \varepsilon$，即 $a_n \to s = \sup E$。$\square$
>
> （注：这里的构造与 Problem 2 第三步用的是同一个核心事实——上确界的"逼近性质"。本题把它提炼成了一条独立的构造工具。）


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 本题把 P2 第三步里反复用到的那个事实单独拎出来当独立命题：sup 的逼近性质——对任意 $\varepsilon>0$，存在 $a\in E$ 使 $a>\sup E-\varepsilon$。它为什么成立？因为 sup 是"最小的上界"，任何比它小的数（比如 $s-\varepsilon$）都必然不是上界，于是 $E$ 里一定有元素超过 $s-\varepsilon$。这是最小上界定义的直接回响，值得背下来。之后用 $\varepsilon=\tfrac1n$ 的阶梯（与 PS02 P3 的 ε=1/k 阶梯法同款）构造一串 $a_n\in E$，使 $s-\tfrac1n<a_n\le s$，夹逼得 $a_n\to s$。这给出一个值得记住的事实：即使 sup 本身不在 $E$ 里（比如 $E=(0,1)$，$\sup E=1$ 不在 $E$ 中），也总有一列 $E$ 里的元素把它逼近到任意精度——$1-\tfrac1n\to 1$。这条"逼近性质"是后面证明 $\sup(F+G)$、连续函数最值、乃至 Riemann 积分里"上确界可被逐步逼近"的公用引擎。

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 4 (15pt)</span>

设 $a_1 = 4$，并按如下方式归纳定义：
```math
a_n = 4 - \frac{4}{a_{n-1}} \qquad (n \ge 2).
```
证明 $\displaystyle\lim_{n\to\infty} a_n = 2$。

提示：证明 $a_n \ge 2$ 且 $a_n$ 单调递减。

> <span style="color:#2471a3;">**[solution]**</span> **Solution 4（解答四）.**
>
> 全程分三步：下界、单调性、收敛与极限。
>
> **第一步：$a_n \ge 2$ 对所有 $n$。** 用归纳法。基步：$a_1 = 4 \ge 2$。归纳步：设 $a_{n-1} \ge 2$，则 $\dfrac{4}{a_{n-1}} \le 2$（分母至少为 $2$，正数），故
> ```math
> a_n = 4 - \frac{4}{a_{n-1}} \ge 4 - 2 = 2.
> ```
> 注意：归纳假设 $a_{n-1} \ge 2 > 0$ 同时保证了 $\dfrac{4}{a_{n-1}}$ 有定义（分母非零）且为正。
>
> **第二步：$a_n$ 单调递减，即 $a_n \le a_{n-1}$。** 计算相邻差：
> ```math
> a_{n-1} - a_n = a_{n-1} - 4 + \frac{4}{a_{n-1}}
> = \frac{a_{n-1}^2 - 4a_{n-1} + 4}{a_{n-1}}
> = \frac{(a_{n-1} - 2)^2}{a_{n-1}} \ge 0,
> ```
> 其中分子是完全平方 $(a_{n-1} - 2)^2 \ge 0$，分母 $a_{n-1} \ge 2 > 0$（第一步）。故 $a_n \le a_{n-1}$ 对所有 $n \ge 2$。
>
> **第三步：收敛。** $\{a_n\}$ 是单调递减且有下界 $2$ 的序列。由 monotone convergence theorem（单调收敛定理，L05 / TBB Theorem 2.28, p.63），$\{a_n\}$ 收敛。
>
> **第四步：求极限。** 设 $L = \lim a_n$。由于 $a_n \ge 2$，$L \ge 2 > 0$。对递推式两边取极限：
> ```math
> L = \lim a_n = \lim \Big(4 - \frac{4}{a_{n-1}}\Big) = 4 - \frac{4}{L},
> ```
> 其中用到了 Problem 1 (PS02) 的乘积极限定理/商的极限定理（$L \ne 0$）。整理：
> ```math
> L^2 = 4L - 4 \quad\Longrightarrow\quad L^2 - 4L + 4 = 0 \quad\Longrightarrow\quad (L-2)^2 = 0 \quad\Longrightarrow\quad L = 2.
> ```
> 故 $\displaystyle\lim_{n\to\infty} a_n = 2$。$\square$
>
> （数值：$a_1 = 4,\; a_2 = 3,\; a_3 = \frac{8}{3} \approx 2.667,\; a_4 = \frac{5}{2} = 2.5,\; a_5 = \frac{12}{5} = 2.4,\; a_6 = \frac{7}{3} \approx 2.333,\ldots$ 单调递减逼近 $2$。）


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 把递推式写成 $a_n=f(a_{n-1})$，其中 $f(x)=4-\tfrac4x$，本题本质上是在问迭代序列 $f$ 反复作用是否收敛、收敛到哪里。答案 $2$ 不是凑出来的：若极限 $L$ 存在且 $f$ 连续，两边取极限得 $L=4-\tfrac4L$，即 $L$ 是 $f$ 的不动点，解方程得 $L=2$。所以整个证明骨架是标准的不动点套路——先证 $a_n\ge 2$（归纳法，顺带保证分母非零，这正是 6.042J 归纳法里"归纳假设要强到够用"的体现），再作差因式分解 $a_{n-1}-a_n=\tfrac{(a_{n-1}-2)^2}{a_{n-1}}\ge 0$ 证单调递减，然后用单调收敛定理（MCT，L05）保证收敛，最后取极限解不动点方程。值得预告的是，这与 P5 是同一主题的两个版本：$f'(x)=\tfrac{4}{x^2}$，而序列从 $a_2=3$ 起始终落在 $[3,4]$ 上，在此区间 $|f'|\le\tfrac{4}{9}<1$，故 $f$ 在序列实际活动的区间上是压缩映射——不动点 $2$ 处 $f'(2)=1$ 恰是"压缩常数取不到 1"的临界情形，而序列本身从不越过 $2$——所以本题正是 P5 Banach 不动点定理的一个具体实例。

### <span style="color:#2471a3;">**[problem]**</span> <span style="color:#c0392b">Problem 5 (20pt)</span>

设 $T: \mathbb{R} \to \mathbb{R}$ 是 contraction map（压缩映射），$x \in \mathbb{R}$ 是一个数。定义序列 $a_n$：$a_1 = x$，$a_{n+1} = T(a_n)$。

(1) 证明：对任意 $m \in \mathbb{N}$，
```math
|a_1 - a_m| \le \frac{1}{1-\lambda}\,|a_1 - a_2|.
```

(2) 证明 $a_n$ 是 Cauchy sequence（柯西序列）。

你可以在下一页找到 contraction map 和 Cauchy sequence 的定义。

> <span style="color:#2471a3;">**[solution]**</span> **Solution 5（解答五）.**（定义与定理见下）
>
> **(1)** 先用归纳法证明相邻项的"几何衰减"：对任意 $k \ge 1$，
> ```math
> |a_{k+1} - a_k| \le \lambda^{k-1}\,|a_2 - a_1|. \tag{★}
> ```
> 基步（$k = 1$）：$|a_2 - a_1| \le \lambda^0 |a_2 - a_1|$ 平凡成立。归纳步：设 $|a_k - a_{k-1}| \le \lambda^{k-2}|a_2 - a_1|$，则由 $T$ 是压缩映射（定义 1）：
> ```math
> |a_{k+1} - a_k| = |T(a_k) - T(a_{k-1})| \le \lambda |a_k - a_{k-1}| \le \lambda^{k-1}|a_2 - a_1|.
> ```
>
> 现在用 triangle inequality（三角不等式）把 $|a_1 - a_m|$ 拆成相邻差之和（telescoping）：
> ```math
> |a_1 - a_m| \le \sum_{k=1}^{m-1} |a_{k+1} - a_k| \le |a_2 - a_1| \sum_{k=1}^{m-1} \lambda^{k-1}
> = |a_2 - a_1| \cdot \frac{1 - \lambda^{m-1}}{1 - \lambda} \le \frac{|a_2 - a_1|}{1 - \lambda}.
> ```
> 其中最后一步用 $0 < \lambda < 1$ 得 $1 - \lambda^{m-1} \le 1$。$\square$
>
> **(2)** 设 $m > n$（$m < n$ 时对称；$m = n$ 时平凡）。同样用 telescoping：
> ```math
> \begin{aligned}
> |a_n - a_m| &\le \sum_{k=n}^{m-1} |a_{k+1} - a_k|
> \le |a_2 - a_1| \sum_{k=n}^{m-1} \lambda^{k-1} \\
> &= |a_2 - a_1| \cdot \frac{\lambda^{n-1}(1 - \lambda^{m-n})}{1 - \lambda}
> \le |a_2 - a_1| \cdot \frac{\lambda^{n-1}}{1 - \lambda}.
> \end{aligned}
> ```
> 因为 $0 < \lambda < 1$，$\lambda^{n-1} \to 0$（当 $n \to \infty$）。给定 $\varepsilon > 0$，存在 $N$ 使得对所有 $n \ge N$，
> ```math
> |a_2 - a_1| \cdot \frac{\lambda^{n-1}}{1 - \lambda} < \varepsilon.
> ```
> 于是对任意 $n, m \ge N$（不妨 $m \ge n$）有 $|a_n - a_m| < \varepsilon$，即 $\{a_n\}$ 是 Cauchy sequence（柯西序列，定义 2）。$\square$
>
> **补充**：由下一页的 Theorem（Every Cauchy sequence of real numbers converges，每个实数柯西序列收敛——实数完备性），$\{a_n\}$ 收敛；再由压缩映射的连续性，极限 $a^* = \lim a_n$ 满足 $T(a^*) = a^*$，即收敛到唯一的不动点（fixed point）。这正是 Banach fixed-point theorem（巴拿赫不动点定理，Banach 1922）在一维实数情形。事实上 $|a_{n+1} - a^*| \le \lambda |a_n - a^*|$，收敛是 geometric rate（几何速度）的。


> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> (1) 的核心是一个"几何衰减"引理：$|a_{k+1}-a_k|\le\lambda^{k-1}|a_2-a_1|$，即相邻差按公比 $\lambda\in(0,1)$ 每步缩水。接着用三角不等式把 $|a_1-a_m|$ 拆成相邻差之和，再用等比级数求和 $1+\lambda+\cdots+\lambda^{m-2}=\tfrac{1-\lambda^{m-1}}{1-\lambda}\le\tfrac{1}{1-\lambda}$ 一网打尽。等比级数可求和，正是"几何衰减"与"算术衰减"（如 $1/n$ 只衰减不求和）的本质差别——这同 6.004（CSAPP）中浮点相对误差按 $2^{-k}$ 几何衰减、其累加和始终有界的现象是同一件事。(2) 里同样的求和给出 $|a_n-a_m|\le\tfrac{\lambda^{n-1}}{1-\lambda}|a_2-a_1|\to 0$，即尾巴挤在一起。Cauchy 本人 1821 年在《Cours d'Analyse》中系统使用这种"尾部互相逼近"的收敛判据，因而得名。历史与前瞻：这个不动点结论由 Stefan Banach 于 1922 年陈述（又名 Banach–Caccioppoli 定理），它是 Picard 逐次逼近法（用迭代不断构造近似解的方法）的抽象化，也是常微分方程解的存在唯一性定理（本课程 L23 的 Picard–Lindelöf 定理）的核心引擎——你会看到同一个"压缩+几何衰减"的论证换个舞台再次上演。
>

### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3;">Definition 1（定义一，contraction map）</span>

**Definition 1.** 映射 $T: \mathbb{R} \to \mathbb{R}$ 称为 contraction map（压缩映射），如果存在 $\lambda \in (0, 1)$ 使得
```math
|T(x) - T(y)| \le \lambda|x - y| \qquad \text{对所有 } x, y \in \mathbb{R}.
```

### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3;">Definition 2（定义二，Cauchy sequence）</span>

**Definition 2.** 实数序列 $a_n$ 称为 Cauchy sequence（柯西序列），如果对任意 $\varepsilon > 0$ 存在 $N \in \mathbb{N}$ 使得 $|x_n - x_m| \le \varepsilon$ 对所有 $n, m \ge N$ 成立。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> （原文如此：序列名为 $a_n$，定义中却写 $x_n$，系原 PDF 笔误，应为 $|a_n - a_m|$。）

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b;">Theorem（定理）</span>

**Theorem.** 每个实数 Cauchy sequence（柯西序列）都收敛。
