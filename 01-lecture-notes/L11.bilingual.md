### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Reminder: Continuous function（回顾：连续函数）</span>

回顾一下，定义在某个集合 $A \subset \mathbb{R}$ 上的 function（函数）$f : A \to \mathbb{R}$ 被称为 continuous（连续），如果对一切 $x_0 \in A$ 都有：对任意 $\varepsilon > 0$，存在一个 $\delta = \delta(x_0) > 0$，使得只要 $|x - x_0| < \delta$（其中 $x \in A$），就有 $|f(x) - f(x_0)| < \varepsilon$。

> <span style="color:#7f8c8d;">TBB Definition 5.32–5.35, §5.4, p.214（ε-δ / 极限 / 邻域 / 序列四种版本）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这一行的 $\varepsilon$-$\delta$ 定义是整讲的出发点，但 Colding 今天真正想用的不是这个"输入接近 → 输出接近"的量化版本，而是它的序列版本。他在开场就点明思路：🎥 *"So today, we want to talk a little bit more about sequences and how sequences connect to a function being continuous."*（翻译：今天我们要多谈谈序列，以及序列如何与函数的连续性联系起来。）序列版本的好处是：证明"极限与函数可交换次序"只需处理数列的收敛，而不必直接摆弄 $\delta$ 的选取。你在 L04–L07 已经积累了大量数列工具——Bolzano-Weierstrass 定理（博尔扎诺-魏尔斯特拉斯定理）、Cauchy 收敛定理（柯西收敛定理）——今天要让这些工具在"连续性"问题上发挥威力。这是全讲的战略主线。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Two theorems about continuous functions（关于连续函数的两个定理）</span>

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Extreme Value Theorem（极值定理）</span>

设 $f : [a, b] \to \mathbb{R}$ 是连续函数，则存在 $x_M \in [a, b]$ 使得对一切 $x \in [a, b]$ 都有 $f(x_M) \ge f(x)$。类似地，存在 $x_m \in [a, b]$ 使得对一切 $x \in [a, b]$ 都有 $f(x_m) \le f(x)$。

> <span style="color:#7f8c8d;">TBB Theorem 5.50, §5.7 Extremal Properties, p.222</span>

> <span style="color:#1e8449;">**[note] Note（译者注，设计问题视角）:**</span> 本节的设计问题是：「什么样的函数、在什么样的集合上，才能保证最大值与最小值被真正取到？」答案的两个条件缺一不可，各自堵住一类反例：**区间闭**——开区间 $(0, 1)$ 上 $f(x) = x$ 连续但取不到上确界 $1$，因为极限点不在集合内；**函数连续**——设 $f(x) = x$（当 $x \in [0, 1)$）而 $f(1) = 0$，它在 $[0, 1]$ 上上确界为 $1$ 却取不到（在端点处跳变），因为不连续。第一性原理：闭区间保证了 Bolzano-Weierstrass 定理（博尔扎诺-魏尔斯特拉斯定理）能干活（有界序列有收敛子序列，极限点留在区间内），连续性保证了"极限与函数可交换"（即将证明的引理）。把这两件工具组合起来，就是本讲证明 EVT 的全部思路。你在微积分里早已默认"闭区间连续函数有最值"这件事，本讲要把这个"默认"变成可验证的证明。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Intermediate Value Theorem（介值定理）</span>

设 $f : [a, b] \to \mathbb{R}$ 是连续函数，则对位于 $f(a)$ 与 $f(b)$ 之间的每一个 $y$，都存在 $x \in [a, b]$ 使得 $f(x) = y$。

> <span style="color:#7f8c8d;">TBB Theorem 5.53, §5.8 Darboux Property, p.224</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 本节的表述是"值域充满中间值"：连续函数的值域是一整段区间，没有缝隙。Colding 强调他证的其实不算特殊情形——$f(a) < 0 < f(b)$ 时存在零点——然后说"一般情形类似"：🎥 *"I'm going to prove, but it's not really—the general case follows easily from this."*（翻译：我要证明的其实不算特殊情形——一般情形由它轻松推出。）为什么特殊情形就够？把一般情形平移缩放：设 $y$ 介于 $f(a)$ 与 $f(b)$ 之间，令 $g(x) = f(x) - y$，则 $g(a)$ 与 $g(b)$ 异号，$g$ 的零点正是 $f(x) = y$ 的解。这个"化一般为零点"的小技巧值得记住——它是分析学里反复出现的降维操作。IVT 在 TBB 中以 Darboux property（达布性质）的面貌出现（§5.8），二者是同一件事的两种说法。

---

我们将用一条把 sequence（序列）与 continuous function（连续函数）连接起来的引理，来证明上述两个定理（即 EVT 与 IVT）。引理如下：

### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma: Sequences and continuity（引理：序列与连续性）</span>

设 $f : [a, b] \to \mathbb{R}$ 是连续函数，且 $(x_n)$ 是收敛到 $x_\infty$ 的序列，则 $f(x_n) \to f(x_\infty)$。这也可以写成

```math
\lim_{n \to \infty} f(x_n) = f\left(\lim_{n \to \infty} x_n\right) .
```

> <span style="color:#7f8c8d;">TBB Definition 5.35（Sequential Version）, §5.4, p.214</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这个引理是"连续"的序列刻画（的一个方向）：**极限符号可以穿过连续函数**。Colding 特别指出它比 $\varepsilon$-$\delta$ 定义更常用：🎥 *"often, when you're proving that something is continuous, you would instead use this lemma here"*（翻译：通常，当你证明某个东西连续时，你反而会使用这个引理）。它的证明策略可以命名一个可复用模板——**「ε/δ 接力法」**：连续性给出 $\delta$，收敛性给出 $N$，把两个"接力棒"接起来就得到目标 $\varepsilon$。注意这里只用到"连续 ⇒ 序列保持收敛"这一个方向，反向（序列保持收敛 ⇒ 连续）是等价的另一面（TBB 要求用 Exercise 5.4.14 证明四种定义等价）。本讲 EVT 和 IVT 的证明都将以这个引理为唯一的"传送带"。

---

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 要证明 $f(x_n) \to f(x_\infty)$，给定 $\varepsilon > 0$。由于 $f$ 在 $x_\infty$ 处连续，存在 $\delta > 0$ 使得只要 $|x - x_\infty| < \delta$，就有 $|f(x) - f(x_\infty)| < \varepsilon$。由于 $x_n \to x_\infty$，存在 $N$ 使得当 $n \ge N$ 时 $|x_n - x_\infty| < \delta$，从而 $|f(x_n) - f(x_\infty)| < \varepsilon$。引理得证。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明节奏）:**</span> 注意证明的"接力"顺序：先请连续性出场（给出 $\delta$），再请收敛性出场（给出 $N$），最后两棒合并。这里 $N$ 的选取依赖 $\delta$，而 $\delta$ 依赖 $\varepsilon$——依赖链是 $\varepsilon \to \delta \to N$，每一步都由上一步决定。这种"先写目标 $\varepsilon$，反向递推需要什么"的思考方式，就是分析证明的标准心法：**从结论倒着问"要得到 $\varepsilon$，我需要什么？"**。等你写作业证明时，先列出这条依赖链，再落笔，顺序就自然对了。这条"接力"结构与你在 L06 的 Cauchy 收敛定理证明里的 $\frac{\varepsilon}{2}$ 劈分是同一副骨架的两个变体：那里是"两段路程各担一半误差"，这里是"连续性和收敛性各出一张牌"。把两类证明放到一起读，你会看到分析学的证明往往就是"把依赖链逐环接实"，而接法高度可复用。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Proof of the Extreme Value Theorem（极值定理的证明）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof of EVT（极值定理的证明）.* 令 $E = f([a, b])$ 并设 $M = \sup E$。我们要证明 $M < \infty$，并且存在某个 $x \in [a, b]$ 使得 $M = f(x)$。我们首先证明 $M$ 是有限的。否则，对每个 $n$ 都存在 $x_n \in [a, b]$ 使得 $f(x_n) > n$。由于序列 $\{x_n\}$ 有界，由 Bolzano-Weierstrass 定理（博尔扎诺-魏尔斯特拉斯定理）它有收敛子序列，我们把它记为 $x_{n_k}$。于是 $x_{n_k} \to x_\infty \in [a, b]$。由上面的引理，$f(x_{n_k}) \to f(x_\infty)$，但我们假设了序列 $f(x_{n_k})$ 是无界的——这正是想要的矛盾。

对每个整数 $n$，我们现在可以选取 $x_n \in [a, b]$ 使得 $f(x_n) > M - \frac{1}{n}$。同样由于该序列有界，由 Bolzano-Weierstrass 定理它有收敛子序列 $x_{n_k} \to x_\infty \in [a, b]$。由上面的引理，$f(x_{n_k}) \to f(x_\infty) \ge M$。由于 $M = \sup f([a, b])$，我们得到 $f(x_\infty) = M$。这就证明了 EVT。$\square$

> <span style="color:#7f8c8d;">TBB Theorem 5.50, §5.7, p.222（TBB 的证明用 g(x) = 1/(M − f(x)) 的有界性反证；本讲用序列方法，两种证明都值得对照）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这个证明是一个可以反复套用的模板——**「上确界逼近 + 子序列提取」三步法**。① 先用反证法证明 $M = \sup f([a,b])$ 有限。若 $M = \infty$，则存在 $f(x_n) > n$，由 B-W 定理提取收敛子序列，引理把"无界"变成矛盾。② 构造逼近序列：取 $x_n$ 使 $f(x_n) > M - \frac{1}{n}$。这是"上确界定义"的直接兑现——$M - \frac{1}{n}$ 不再是上界，所以必有函数值落进去。③ 再次提取收敛子序列，引理给出 $f(x_\infty) = M$，上确界被真正取到。关键洞察：**上确界只是"最小的上界"，它不一定被取到**。证明的全部工作就是把"被取到"逼出来。对比 TBB 的证明（用 $g(x) = \frac{1}{M - f(x)}$ 反证），你会发现两条路殊途同归。它们都在说"如果取不到，就会构造出无界的连续函数"。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Proof of the Intermediate Value Theorem（介值定理的证明）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof of IVT（介值定理的证明）.* 我们假设 $f(a) < 0 < f(b)$，并证明存在 $x \in [a, b]$ 使得 $f(x) = 0$。一般情形类似。令 $A = \{y \mid \text{for all } x \le y \text{ we have } f(x) \le 0\}$。注意 $a \in A$，所以该集合非空。设 $M = \sup A$，并取序列 $x_n$ 满足 $x_n < M$ 且 $x_n \to M$。由此得 $f(x_n) < 0$，于是由上面的引理我们必有 $f(M) \le 0$。若 $f(M) = 0$ 就完成了，所以假设 $f(M) < 0$。我们还有 $M < b$，由连续性，在 $M$ 周围存在一整个区间使得 $f < 0$。这与 $M$ 是集合 $A$ 的上确界矛盾。IVT 得证。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 这里的直觉陷阱在于集合 $A$ 的构造：$A$ 收集的是"从 $a$ 出发、一路都满足 $f \le 0$ 的右端点 $y$"。不要把它误读成"$f(y) \le 0$ 的点集"——它是"**零点右侧能推进到哪里**"的纪录。$M = \sup A$ 是这个推进的极限位置。然后证明分两支：若 $f(M) = 0$，零点找到了；若 $f(M) < 0$，连续性给出 $M$ 附近一整段 $f < 0$（这段区间内所有的 $y$ 都满足 $x \le y \Rightarrow f(x) \le 0$，即整段都该进 $A$），于是 $M$ 还能再往前推，与"上确界"矛盾。这个论证可以命名模板——**「上确界推进法」**：先让"能行的集合"推到极限位置，再证明极限位置处要么已经成功、要么矛盾。它与 EVT 证明共享同一骨架：**supremum + 连续性 + 引理（序列传递）**，只是敌人的形式不同。*（原文两处小瑕疵值得注意：其一，讲义写 $f(x_n) < 0$，严格说由 $x_n < M$ 只能推出 $f(x_n) \le 0$，但论证只用到 $\le$，不影响结论；其二，"$M < b$"应补半句理由——由 $f(M) < 0 < f(b)$ 且连续性，紧邻 $b$ 左侧的 $y$ 仍满足 $f(y) \le 0$ 会与 $M$ 是上确界冲突，故 $M$ 必严格小于 $b$。译文保留原文原样，此处仅作提示。）*

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Abstract metric space（抽象度量空间）</span>

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Metric space（度量空间）</span>

一个 metric space（度量空间）是一个集合 $X$，配备一个函数 $d : X \times X \to \mathbb{R}$，满足以下三条性质：

1. 对一切 $x, y \in X$ 有 $d(x, y) \ge 0$，且 $d(x, y) = 0$ 当且仅当 $x = y$。（距离非负。）
2. $d(x, y) = d(y, x)$。（对称。）
3. $d(x, z) \le d(x, y) + d(y, z)$。（三角不等式。）

> <span style="color:#7f8c8d;">TBB Definition 13.6, §13.2, p.541</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理）:**</span> 这三条公理是从实数上我们最熟悉的距离 $d(x, y) = |x - y|$ 中"蒸馏"出来的。第一性原理的问题是：$|x - y|$ 到底凭什么能当距离？答案是它满足这三条——非负且只在两点重合时为 0（两个不同点距离为正）、对称（x 到 y 与 y 到 x 一样远）、三角不等式（走捷径不比其他路径长）。而分析学中几乎所有关于"远近"的结论（收敛、连续、完备、紧致）都只依赖这三条，不依赖加减乘除。所以 Colding 说度量空间扮演 generalized real numbers（广义实数）的角色。注意 $\varepsilon$-$\delta$ 定义里我们唯一用到的正是这三条（尤其三角不等式），把 $|\cdot|$ 换成 $d$，整套论证原样移植——这就是第 13 章的全部方法论。🎥 *Colding 解释三角不等式*："if you went over y, then this distance here should be longer than if you went directly."（翻译：如果你绕道 $y$ 这个中间点，这段距离应该比直接走更长。）

---

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Examples（例）</span>

1. $X = \mathbb{R}$，且 $d(x, y) = |x - y|$。

2. $X = \mathbb{R}^2$，对 $x = (x_1, x_2)$ 与 $y = (y_1, y_2)$，

```math
d(x, y) = \sqrt{|x_1 - y_1|^2 + |x_2 - y_2|^2} .
```

3. $X = \mathbb{R}^3$，对 $x = (x_1, x_2, x_3)$ 与 $y = (y_1, y_2, y_3)$，

```math
d(x, y) = \sqrt{|x_1 - y_1|^2 + |x_2 - y_2|^2 + |x_3 - y_3|^2} .
```

> <span style="color:#7f8c8d;">TBB Example 13.2, 13.5, §13.2, p.539–541</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 例 2、3 就是 Euclidean distance（欧氏距离）——日常的"直线距离"。它的三角不等式并非不证自明。在 $\mathbb{R}^n$ 中，三角不等式等价于 Cauchy-Schwarz 不等式（柯西-施瓦茨不等式）。你在 18.06 Linear Algebra（Gilbert Strang）里见过它的内积形式 $\langle u, v \rangle^2 \le \|u\|^2 \|v\|^2$；在 18.065 矩阵方法（Strang）中它通过 Cauchy-Schwarz 进一步给出谱范数 $\|A\|_2$ 与奇异值的关系。这正是"验证某函数是度量"的第一个真实难度。前两条公理通常一眼看穿，第三条三角不等式往往才是需要动笔的地方。本讲后面的 French railway metric（法国铁路度量）也是同一处境。Colding 甚至不在此证明它的三角不等式。

---

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example: Continuous functions on an interval（区间上的连续函数）</span>

令 $X = C([a, b])$，其中 $C([a, b])$ 是 $[a, b]$ 上连续函数的集合。两个连续函数 $f$ 与 $g$ 之间的距离定义为

```math
d(f, g) = \max_{x \in [a, b]} |f(x) - g(x)| .
```

由于 $f - g$ 也是连续函数，EVT（极值定理）保证最大值在某个 $x \in [a, b]$ 处取到。

> <span style="color:#7f8c8d;">TBB Example 13.10–13.11, §13.3.2 Function Spaces, p.545</span>

> <span style="color:#1e8449;">**[note] Note（译者注，跨课程连接）:**</span> 这个例子第一次展示了度量的元素可以是**函数本身**——两个函数"有多近"由它们在整个区间上差值的最大值度量。这叫做 sup metric（上确界度量）或 uniform metric（一致度量）。这里有个精妙的循环：EVT 在本讲开头（第一页）刚被证明，立刻反过来成为定义这个度量的支撑——**没有 EVT，$\max$ 甚至不一定存在**（开区间上连续函数可以无最大值）。这个度量下的收敛就是你在级数理论 §9.3 Uniform Limits（TBB §9.3）会遇到的 uniform convergence（一致收敛）：函数列"整体一起靠近"极限函数，而不是逐点各自靠近（这正是 TBB Example 13.17 在度量空间语言下对 $M[a,b]$ 收敛的刻画）。它是分析学从"数的世界"跨入"函数的世界"的第一座桥——泛函分析（functional analysis）正是从这里出发的。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Metric spaces as generalised real numbers（度量空间作为广义实数）</span>

度量空间扮演 generalized real numbers（广义实数）的角色——这是本讲的核心洞见。我们在课堂上讨论过的很多内容对度量空间也成立，这在许多场合都很有用。例如，我们将在后面的一节课上看到，可以用它来解 ODE（ordinary differential equations，常微分方程）。

> <span style="color:#1e8449;">**[note] Note（译者注，拓展前沿·预告式）:**</span> "用度量空间解 ODE"听起来不可思议，但思路其实很直接。核心操作是把"解微分方程"改写成"在函数空间中找一个点"。具体地，把 $y' = f(x, y), \; y(x_0) = y_0$ 两边积分，变成求满足 $y(x) = y_0 + \int_{x_0}^{x} f(t, y(t)) \, dt$ 的函数 $y$。右端定义了一个把函数变成函数的算子 $T$，于是"解方程"变成"找 $T$ 的不动点"。在合适的完备度量空间上，$T$ 是 contraction map（压缩映射）。TBB §13.9–13.11 的 Banach fixed point theorem（巴拿赫不动点定理，即 Theorem 13.75, §13.9, p.584）保证存在且唯一（即 Picard's Theorem，皮卡德定理，§13.11.4, p.595）。这个预告的要点：**完备性**（马上在本讲出现）是这类存在性论证的地基。这个"存在唯一"论证模式本质上是证明"某算子有不动点"——你会在微分方程理论（如 18.03 的 Picard–Lindelöf 定理）里反复遇到它。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Sequences in a metric space（度量空间中的序列）</span>

度量空间 $(X, d)$ 中的 sequence（序列）是一个映射 $f : \mathbb{N} \to X$。我们通常把值 $f(n)$ 记为 $x_n$。类似地，我们把 subsequence（子序列）定义为严格递增映射 $g : \mathbb{N} \to \mathbb{N}$ 与 $f$ 的复合，即 $x_{n_k} = f(g(k))$。

> <span style="color:#7f8c8d;">TBB §13.4, p.548</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 序列的定义从"实数列"升级为"从 $\mathbb{N}$ 到 $X$ 的映射"。序列的**形式骨架完全没变**：仍是以自然数为指标、按顺序排列的一列点，只是点的身份从实数换成了抽象集合 $X$ 的元素（可以是函数、可以是点对）。子序列的严格递增条件 $g$ 保证了"下标越取越靠后"：$n_k$ 随 $k$ 严格增大。这个定义与你在 L04 学过的实数列子序列定义逐字对应，区别只是落点集合不同。所以 L04–L07 积累的直觉（子序列、收敛子序列、B-W 定理）在适当修改后仍能复用。这正是度量空间方法论的力量。

---

并不是所有我们在 $\mathbb{R}$ 中知道的结论都能推广到一般的度量空间。例如，一般情况下没有 algebraic properties（代数性质），没有 squeeze theorem（夹逼定理），没有 monotone convergence theorem（单调收敛定理）。另一方面，Cauchy convergence theorem（柯西收敛定理）与 Bolzano-Weierstrass 定理（博尔扎诺-魏尔斯特拉斯定理）的陈述在一般度量空间中都是有意义的。

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理）:**</span> 这一段是在划"边界"：哪些 $\mathbb{R}$ 的定理本质上是**度量**带来的，哪些本质上是**序或代数**带来的？夹逼定理需要 $\le$（序），单调收敛定理需要"单调"（序）+ 有界（序与度量），代数性质需要加减乘除（域结构）——这些在只有距离的度量空间里无从谈起。而"柯西"与"B-W"只依赖距离：收敛子序列、柯西列都只用 $d$ 定义。这个划分预告了本讲的走向：EVT 依赖 B-W（依赖度量），所以 EVT 会在度量空间中"变异"为更一般的版本（L14 的序列紧致，sequential compactness）；而单调收敛、夹逼这类依赖序的结论在一般度量空间没有对应物。理解"结论依赖什么结构"，比记住结论本身更接近第一性原理。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example: Box distance（方框距离）</span>

空间取 $X = \mathbb{R}^2$，若 $x = (x_1, x_2)$、$y = (y_1, y_2)$，则

```math
d(x, y) = |x_1 - y_1| + |x_2 - y_2| .
```

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> Box distance（方框距离）也叫 taxicab metric（出租车度量）或 Manhattan distance（曼哈顿距离）。想象城市街道网格：你只能沿着街道走，从 $(x_1, x_2)$ 到 $(y_1, y_2)$ 的最短路径是横着走 $|x_1 - y_1|$、竖着走 $|x_2 - y_2|$。🎥 *Colding 对比欧氏距离*："you didn't do this fancy thing with square root, but you did the more trivial thing, where you're just adding."（翻译：你没有做开平方那种花哨操作，只是直接相加。）同一集合 $\mathbb{R}^2$ 配上不同度量就成了不同的度量空间。欧氏距离的单位球是圆盘，而方框距离的单位球是菱形（顶点在坐标轴上）。度量决定几何——这是本讲反复出现的主题。

---

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example: Strange metric on integers（整数上的奇怪度量）</span>

空间取 $X = \mathbb{N}$，若 $m, n$ 是 natural number（自然数，即正整数），则

```math
d(m, n) = \left| \frac{1}{n} - \frac{1}{m} \right| .
```

> <span style="color:#1e8449;">**[note] Note（译者注，直觉颠覆）:**</span> 这个度量的"反直觉"在于：两个很大的整数 $m, n$，按通常距离 $|m - n|$ 可以离得很远，但在这个度量下却非常接近。原因是 $\frac{1}{n}$ 与 $\frac{1}{m}$ 都趋近于 $0$。🎥 *Colding 点破*："if one integer is really large and the other one is not very large, you would think that the distance was large... if both n and m are really large, then in this metric, they're very close together."（翻译：如果其中一个整数很大、另一个不那么大，你会觉得它们的距离很大……但如果 $n$ 和 $m$ 都很大，在这个度量下它们就非常接近。）换个视角：这个度量就是把 $\mathbb{N}$ 按 $n \mapsto \frac{1}{n}$ 嵌入 $(0, 1]$（通常度量），再拉回来的距离。$n \to \infty$ 对应 $\frac{1}{n} \to 0$，所以"无穷远处的整数"反而聚集在 $0$ 附近。它说明：**"远近"不是集合本身固有的，而是度量赋予的**。

---

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example: French railway metric（法国铁路度量）</span>

这里是一个度量空间的"野性"例子。空间取 $X = \mathbb{R}^2$，若 $x = (x_1, x_2)$、$y = (y_1, y_2)$，则

```math
d(x, y) = \begin{cases} |x - y| & \text{if } x = c y \text{ or } y = c x \text{ for some } c \in \mathbb{R} \\[2mm] |x| + |y| & \text{otherwise} \end{cases}
```

这里

```math
|x - y| = \sqrt{(x_1 - y_1)^2 + (x_2 - y_2)^2} ,
```

$|x|$ 与 $|y|$ 同理。

> <span style="color:#1e8449;">**[note] Note（译者注，历史与人物）:**</span> 名字的来历是真实的法国铁路史。传统法国铁路网以巴黎为枢纽呈星形（radial）布局，于是"不在同一条线路上"的两点往往绕行巴黎。Colding 在课上的例子最能说明问题：蔚蓝海岸的戛纳与尼斯近在咫尺（*"two cities on the French Riviera that are incredibly close together is Cannes and Nice"*，翻译：法国蔚蓝海岸上两座近得不可思议的城市就是戛纳与尼斯），坐铁路却"必须先到巴黎"（*"you would have to go to Paris first"*）。数学构造把这个几何直觉抽象成：原点充当"巴黎"这个 hub（枢纽）。两点落在同一条过原点的直线上（$x = c y$ 或 $y = c x$，即共线），就可以"直达"用欧氏距离；否则必须先回原点再出发，距离是 $|x| + |y|$。数学文献常把这传说戏称为乘法国铁路的"恶意的玩笑"（参见 PlanetMath 的 SNCF metric 条目）。在这个度量下，开球的形状是线段或"棒棒糖"：远离原点的点，其小球只是沿射线的一段线段，半径大到"够到"原点才变成棒棒糖形。验证三角不等式是它最不平凡的一步，可参考 TBB 习题或网络上的标准证明。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Convergent sequence in a metric space（度量空间中的收敛序列）</span>

若 $(X, d)$ 是度量空间且 $(x_n)$ 是 $X$ 中的序列，则我们说 $x_n$ 收敛到 $x$，记作 $x_n \to x$ 或 $x = \lim_{n \to \infty} x_n$，如果对任意 $\varepsilon > 0$，存在 $N$ 使得当 $n \ge N$ 时 $d(x, x_n) < \varepsilon$。这等价于序列 $d(x_n, x_\infty) \to 0$。

> <span style="color:#7f8c8d;">TBB Definition 13.15, §13.4, p.548</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 把这个定义与你在 L04 学的实数列收敛定义并排看，唯一的区别是 $|x_n - x| < \varepsilon$ 换成了 $d(x_n, x) < \varepsilon$——**换皮不换骨**。末尾那句"等价于 $d(x_n, x_\infty) \to 0$"其实是一个方便的记法。它把"度量下的收敛"翻译成"实数 $d(x_n, x_\infty)$ 的收敛"，这样你熟悉的实数列工具（如夹逼）又能间接用上。注意极限记号 $\lim_{n \to \infty} x_n$ 现在有更广的含义。它不再只是实数运算，而是"度量空间中那个被点列逼近的对象"。L12 将在这个框架下继续发展（度量空间的收敛与集合运算）。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Cauchy sequence in a metric space（度量空间中的柯西序列）</span>

若 $(X, d)$ 是度量空间且 $(x_n)$ 是 $X$ 中的序列，则我们说 $x_n$ 是 Cauchy sequence（柯西序列），如果对任意 $\varepsilon > 0$，存在 $N$ 使得当 $m, n \ge N$ 时 $d(x_m, x_n) < \varepsilon$。

> <span style="color:#7f8c8d;">TBB Definition 13.58, §13.8 Complete Spaces, p.575（正式定义）；本讲从视频直接采用的是 §13.4 的口语化表述</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 收敛与柯西的关键区别一句话：**收敛要求极限点在空间里，柯西只要求项们自己彼此靠近**。直觉陷阱是初学者常把两者混为一谈。"项们自己靠近"和"项们靠近某个点"在 $\mathbb{R}$ 中恰好等价（Cauchy 收敛定理，L06），于是这种混淆被掩盖了。但在一般度量空间中两者分道扬镳（马上见反例）。建议这样记忆：柯西序列的 $\varepsilon$ 条件只看序列内部（$m, n$ 都在下标尾部），不涉及任何"目标点"。而收敛定义里有一个显式的极限点 $x$。TBB 把"柯西序列"的定义留给读者在 Exercise 13.4.18 中自行构造（"用实数列理论作向导"）。这也是一个很好的自我检验：你能不能独立写出这个定义？

---

<span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem（定理）</span>

在任何度量空间 $(X, d)$ 中，收敛序列都是柯西序列。

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 设 $x_n \in X$ 是序列且 $x_n \to x$。给定 $\varepsilon > 0$，收敛意味着存在 $N$ 使得当 $n \ge N$ 时 $d(x, x_n) < \frac{\varepsilon}{2}$。若 $m, n \ge N$，则由三角不等式

```math
d(x_m, x_n) \le d(x_m, x) + d(x, x_n) < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon .
```

定理得证。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这是分析学出场率最高的模板——**「ε/2 技巧」**。它把目标误差 $\varepsilon$ 劈成两半，各由一段路程承担。具体到这里的几何图像：$x_m$ 与 $x_n$ 都在离 $x$ 不到 $\frac{\varepsilon}{2}$ 的范围内，所以它们彼此相距不到 $\varepsilon$。三角不等式正是"绕道 $x$"这句话的数学写法。你在 L06（Cauchy 收敛定理）中已经见过同样的结构，那里是 $|x_m - x_n| \le |x_m - x| + |x - x_n|$。这里只把 $|\cdot|$ 换成 $d$，证明一个字都不用改。**把新的证明归约到旧的证明骨架**，是学习分析学最省力的方式。

---

逆命题并不总是成立：若 $X = (0, 1) \subset \mathbb{R}$ 且 $d(x, y) = |x - y|$，则序列 $x_n = \frac{1}{n}$ 是柯西序列，但因为 $0 \notin X$，它不收敛。有时也表述为：在这个情形下 $X$ 不是 Cauchy complete（柯西完备的）。

> <span style="color:#7f8c8d;">TBB §13.4 Note, p.549 + §13.8 Complete Spaces, p.575</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 这个例子的全部要点浓缩在一个词里：**极限点 $0$ 不在空间里**。同一个序列 $\frac{1}{n}$：在 $\mathbb{R}$ 中收敛到 $0$；在 $(0, 1)$ 中却"不收敛"。序列本身一点没变，变的是承载它的空间——这直观地说明**收敛不是序列的固有属性，而是序列与空间的关系**。柯西性质则不受影响（它只看内部靠近程度）。当一个度量空间里每个柯西序列都收敛时，我们说它完备（complete）。为什么完备性如此重要？因为大量存在性证明的套路是：**造一个柯西序列，然后断言它收敛**——如果空间不完备，这个断言就是空中楼阁。预告：TBB §13.8 会系统研究完备空间（以"把 $\mathbb{Q}$ 完备化为 $\mathbb{R}$"为原型），L12 也将继续；而 ODE 解的存在性（前面注过）正是完备性的应用。

---

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Continuous function on a metric space（度量空间上的连续函数）</span>

设 $F : X \to \mathbb{R}$ 是函数。我们说 $f$ 在 $x_0 \in X$ 处连续，如果对任意 $\varepsilon > 0$，存在 $\delta > 0$，使得若 $x \in X$ 且 $d(x, x_0) < \delta$，则 $|F(x) - F(x_0)| < \varepsilon$。

> <span style="color:#7f8c8d;">TBB Theorem 13.27, §13.6.1 Continuity, p.560（ε-δ 版本；Def 13.26 是序列版本）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，模式匹配）:**</span> 请把这个定义与讲义第一行的 $\varepsilon$-$\delta$ 定义逐词对照：**输入侧**的距离 $|x - x_0| < \delta$ 换成了 $d(x, x_0) < \delta$（输入来自一般度量空间），**输出侧**仍是 $|F(x) - F(x_0)| < \varepsilon$（输出仍是实数）。也就是说：自变量可以是任何抽象对象（函数、序列、点对），因变量仍是实数。记号上的细节值得注意：定义里先说 $F : X \to \mathbb{R}$，后面却说"$f$ 在 $x_0$ 连续"。讲义这里 $f$ 与 $F$ 是同一个函数，只是书写时混用了（原文如此，不影响内容）。这是"连续"概念在本课程范围内的最后一次"换皮"。从 $\mathbb{R}$ 上的函数到度量空间上的实值函数，骨架始终是同一副。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example: Evaluation functional（赋值泛函）</span>

再次令 $X = C([0, 1])$ 为 $[0, 1]$ 上连续函数的集合，赋予上面描述的距离。于是两个连续函数 $f$ 与 $g$ 之间的距离为

```math
d(f, g) = \max_{x \in [0, 1]} |f(x) - g(x)| .
```

在 $X$ 上定义函数 $F$ 为 $F(f) = f(0)$（其中 $f \in C([0, 1])$）。容易看出 $F$ 是度量空间 $X$ 上的连续函数。

> <span style="color:#1e8449;">**[note] Note（译者注，跨课程连接）:**</span> 这个例子是泛函分析的第一块跳板：$F$ 的输入是**函数**，输出是**数**——把"函数映射到数"的函数称为 functional（泛函），这里 $F(f) = f(0)$ 是 evaluation functional（赋值泛函，取函数在 $0$ 点的值）。为什么连续？直觉上：两个函数在整个区间上"距离小"，特别地它们在 $0$ 点的值就接近。严格的验证是一个漂亮的不等式：$|F(f) - F(g)| = |f(0) - g(0)| \le \max_{x \in [0,1]} |f(x) - g(x)| = d(f, g)$——满足这个不等式意味着 $F$ 不仅连续，而且是 **1-Lipschitz**（1-利普希茨）的。这个"用整体距离控制局部取值"的技巧（$|F(f) - F(g)| \le d(f, g)$）在函数空间分析里会反复出现。它与你在 Strang 讲的 18.06 线性代数中学到的算子范数（operator norm）是同一件事：$F$ 是一个线性泛函，而恒有 $|F(f) - F(g)| \le d(f, g)$ 正说明它的 operator norm 为 $1$——把"映射的膨胀上界"这个线性代数观念从矩阵扩展到了函数空间。

#### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma: Sequences and continuity in a metric space（度量空间中的序列连续性引理）</span>

设 $(X, d)$ 是一般度量空间。设 $f : X \to \mathbb{R}$ 是连续函数，$x_n$ 是 $X$ 中的序列且 $x_n \to x_\infty$，则 $f(x_n) \to f(x_\infty)$。

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 要证明 $f(x_n) \to f(x_\infty)$，给定 $\varepsilon > 0$。由于 $f$ 在 $x_\infty$ 处连续，存在 $\delta > 0$ 使得若 $d(x, x_\infty) < \delta$ 则 $|f(x) - f(x_\infty)| < \varepsilon$。由于 $x_n \to x_\infty$，存在 $N$ 使得当 $n \ge N$ 时 $d(x_n, x_\infty) < \delta$，因此 $|f(x_n) - f(x_\infty)| < \varepsilon$。引理得证。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这个引理与本讲第一个引理几乎逐字相同——唯一改动是 $|x - x_\infty| < \delta$ 变成 $d(x, x_\infty) < \delta$。这正是"把 $\mathbb{R}$ 中的论证移植到度量空间"的标准范式：**证明骨架不动，只换距离记号**。🎥 *Colding 总结*："that lemma is just the lemma that I had over here... if I had a continuous function and I have a sequence that converges to a limit, then I could exchange the order of limits."（翻译：那个引理就是我上面那个引理……如果我有连续函数和收敛到极限的序列，那么我可以交换取极限的顺序。）至此，本讲形成了一个完整的循环：第一页的引理证明了 EVT 与 IVT；结尾处同一个引理在度量空间中重生——度量空间中的 EVT/IVT 推广（如 L14 的序列紧致）将沿着同一路线继续。Colding 最后还提到度量空间在 general relativity（广义相对论）中的应用（那里的时空通常不完备），作为"抽象结构有现实用处"的收尾。
