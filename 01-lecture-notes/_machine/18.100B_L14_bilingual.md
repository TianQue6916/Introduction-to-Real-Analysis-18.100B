## 1. 紧子集的定义（Compact subset）

**Definition（定义）— Compact subset（紧子集）**：若 $(X,d)$ 是一个度量空间（metric space，即带有一个距离函数 $d$ 的集合，$d$ 满足非负性、对称性、三角不等式与「$d(x,y)=0\iff x=y$」），而 $A\subseteq X$ 是它的一个子集，则称 **$A$ 是紧的（compact）**，如果 $A$ 的**每一个**开覆盖（open cover，即一族开集，其并集包含 $A$）都存在一个**有限子覆盖**（finite sub-cover，即从这族开集中挑出有限多个，其并集仍覆盖 $A$）。

> **一句话判定**：$A$ 紧 $\iff$ 任意用开集去盖 $A$，都能从中抽出有限个开集仍然盖住 $A$。

---

## 2. Theorem 0 — 紧 ⇒ 闭且有界

**Theorem 0（定理 0）**：若 $(X,d)$ 是度量空间，$A\subseteq X$ 是紧子集，则 $A$ **既闭又有界**（closed and bounded）。

### 证明思路（Proof outline）

**（i）证「有界」（bounded）：**

任取一个点 $p\in X$，考虑一族开球

```math
\{ B(p, n) : n\in\mathbb N \},
```

即半径为 $1,2,3,\dots$ 的、中心都在 $p$ 的开球。由于这些开球（连同整个空间）显然覆盖 $X$，从而覆盖 $A$，所以它构成 $A$ 的一个开覆盖。因为 $A$ 紧，故存在**有限子覆盖**，即存在有限多个半径 $n_1,\dots,n_k$，使得

```math
A \subseteq B(p,n_1)\cup\cdots\cup B(p,n_k) .
```

令 $N=\max\{n_1,\dots,n_k\}$，则 $A\subseteq B(p,N)$。于是对任意 $x,y\in A$，由三角不等式

```math
d(x,y)\le d(x,p)+d(p,y) < N + N = 2N .
```

这说明 $A$ 的直径不超过 $2N$，故 $A$ **有界**。

**（ii）证「闭」（closed）：**

等价地证 $A$ 的补集 $A^{c}=X\setminus A$ 是开集。任取 $q\in A^{c}$，要找一个以 $q$ 为心的开球完全落在 $A^{c}$ 内。

对每个 $x\in A$，因 $x\ne q$ 且度量空间满足分离性，故 $d(x,q)>0$。取 $r_x=\tfrac12 d(x,q)>0$，并考虑一族开球

```math
\{ B(x, r_x) : x\in A \} .
```

这族开球覆盖 $A$。因 $A$ 紧，存在有限子覆盖：存在有限多个点 $x_1,\dots,x_m\in A$ 使得

```math
A \subseteq B(x_1,r_{x_1})\cup\cdots\cup B(x_m,r_{x_m}) .
```

令

```math
r = \min\{ r_{x_1},\dots,r_{x_m} \} > 0 .
```

**断言**：$B(q,r)\cap A=\varnothing$。反设存在 $z\in B(q,r)\cap A$。因 $A$ 被有限个开球覆盖，故 $z\in B(x_i,r_{x_i})$ 对某个 $i$ 成立，即 $d(z,x_i)\lt r_{x_i}=\tfrac12 d(x_i,q)$。又 $z\in B(q,r)$，且 $r\le r_{x_i}$，故 $d(z,q)\lt r_{x_i}$。于是由三角不等式

```math
d(x_i,q) \le d(x_i,z)+d(z,q) < r_{x_i}+r_{x_i} = 2r_{x_i} = d(x_i,q),
```

矛盾。故 $B(q,r)\subseteq A^{c}$，即 $q$ 是 $A^{c}$ 的内点。由 $q$ 的任意性，$A^{c}$ 是开集，故 $A$ **闭**。$\blacksquare$

## 3. Warning — 逆命题不成立

**Warning（注意）**：**逆命题不成立！！** 度量空间中存在「闭且有界」的子集，它**并不是**紧的。也就是说，「闭 + 有界」在一般的度量空间里**不足以**推出「紧」。

> 这一点与 $\mathbb R^n$（欧氏空间）中著名的 **Heine–Borel 定理**形成对照：在 $\mathbb R^n$ 里「紧 $\iff$ 闭且有界」是对的；但在一般度量空间中，「闭且有界」只是紧的**必要条件**，不是充分条件。

---

## 4. Example 1 — $(0,1)$：闭有界却不紧

**Example（例子）**：取 $X=(0,1)$（开区间），配备通常的度量 $d(x,y)=|x-y|$，并把 $(0,1)$ 本身当作**全空间**来看。

- $(0,1)$ 作为它自己这个度量空间里的子集，当然是**闭**的（全空间永远是自身中的闭集），也是**有界**的（直径 $=1$）。
- 但它**不是紧的**。理由：考虑开覆盖

```math
\Big\{ \Big(\tfrac1n,\,1\Big) : n\in\mathbb N \Big\}.
```

这族开区间并起来等于 $(0,1)$，覆盖了全空间。但**任何有限子族**都盖不住：取有限多个 $n$，其中最大者为 $N$，则这些区间并起来只是 $(\tfrac1N,1)$，点 $\tfrac{1}{N+1}\in(0,1)$ 落不进去。故不存在有限子覆盖，所以 $(0,1)$ **不紧**。

## 5. Example 2 — $C([0,1])$：更有启发性的例子

**Example（例子）**：令 $X=C([0,1])$ 表示单位区间 $[0,1]$ 上全体**连续函数**构成的集合。在 $X$ 上配备度量（称为**一致度量 / supremum metric**）：

```math
d(f,g) = \max_{x\in[0,1]} \big| f(x) - g(x) \big| .
```

即两个函数之间的「距离」是它们图像上**铅直方向的最大偏差**。

考虑 $X$ 中的一列连续函数 $f_n$（$n=1,2,3,\dots$），定义为：

```math
f_n(x) =
\begin{cases}
1, & 0\le x\le \dfrac{1}{n+1}, \
\text{（在 } x=\tfrac{1}{n+1}\text{ 与 } x=\tfrac1n \text{ 之间线性下降到 }0\text{）}, & \dfrac{1}{n+1}\le x\le \dfrac1n, \
0, & \dfrac1n\le x\le 1 .
\end{cases}
```

〔原书此处模糊：第 1 页末尾截断于 `if 0 ≤ x ≤ 1/(n+1)` 处，函数在 $\tfrac{1}{n+1}\lt x<\tfrac1n$ 的具体表达式疑似为一段线性下降（线性插值），待核。〕

### 这一例说明了什么

这一列函数 $\{f_n\}$ 的**全体**（连同它们的极限点）构成的集合 $\{f_n:n\in\mathbb N\}$ 具有如下性质：在一致度量下它是**有界**的（每个 $f_n$ 满足 $0\le f_n\le 1$，故 $\{f_n\}$ 落在以 $0$ 为心、半径 $1$ 的闭球里），但在一致度量下它**没有收敛子列**（因为任意两个函数 $f_n,f_m$ 当 $n\ne m$ 时满足 $d(f_n,f_m)=1$，任何子列都不可能是 Cauchy 序列）。

> 这构成了一个**更直观**的「闭 + 有界却不紧」的例子：在 $C([0,1])$ 这个**无限维**度量空间中，「闭 + 有界」同样推不出「紧」。它与上面 $(0,1)$ 的例子不同——$(0,1)$ 不紧是因为它「缺了端点」（不完整、有洞），而 $C([0,1])$ 不紧是因为空间本身是**无限维**的、单位闭球并非紧的。

## 6. 核心概念速查（Key concepts）

| 术语 | 英文 | 可判定定义 |
| --- | --- | --- |
| 度量空间 | metric space | 集合 $X$ 配距离函数 $d$，满足非负、对称、三角不等式、$d(x,y)=0\iff x=y$ |
| 紧子集 | compact subset | 任一开覆盖都有有限子覆盖 |
| 开覆盖 | open cover | 一族开集，其并集包含目标集合 |
| 有限子覆盖 | finite sub-cover | 从开覆盖中选有限个，并集仍盖住目标集合 |
| 闭集 | closed | 补集是开集（或含全部极限点） |
| 有界 | bounded | 直径有限，即存在开球包含整个集合 |
| 一致度量 | supremum metric | $d(f,g)=\max_x|f(x)-g(x)|$ |
| Cauchy 序列 | Cauchy sequence | 对任意 $\varepsilon>0$，存在 $N$，使 $m,n\ge N$ 时 $d(x_m,x_n)<\varepsilon$ |

> 注：本讲正文尚未触及 Bolzano–Weierstrass 定理在度量空间中的完整陈述与证明（原文第 1 页被截断）。该定理的核心表述为：**紧的度量空间必是列紧的（sequentially compact），即其中每个序列都有收敛子列**；在度量空间中「紧」与「列紧」二者等价。这一等价关系将作为后续 lecture 的衔接内容。
