## 1. 闭集的定义

**Definition（定义）— Closed subsets（闭集）**：设 $(X,d)$ 是一个度量空间（metric space）。若子集 $C$ 的补集 $X \setminus C$ 是开集，则称 $C$ 是 $X$ 的**闭子集（closed subset）**。

> 即：闭集 = 「补集为开集」的集合。这里 “开集” 沿用上一讲由开球（open ball）生成的定义。

注意，$\varnothing$（空集）与 $X$ 本身都是闭集。

**Examples（例子）**：

- $(0,1)$ **不是** $\mathbb{R}$ 的闭子集。
- $\{0\}$ 是 $\mathbb{R}$ 的闭子集。
- $[0,1]$ 是 $\mathbb{R}$ 的闭子集。
- $[0,1]\times[0,1]$ 是 $\mathbb{R}^2$ 的闭子集。

---

## 2. 一个关键引理：闭球是闭集

**Lemma（引理）**：设 $(X,d)$ 是度量空间且 $r>0$，则
```math
A_r = \{y \mid d(x,y) > r\}
```
是开集；等价地，闭球
```math
\overline{B_r(x)} = \{y \mid d(x,y) \le r\}
```
是闭集。

**Proof（证明）**：设 $y \in A_r$，则 $d(y,x) > r$。令 $s = d(y,x) - r$，则 $s > 0$。若 $z \in B_s(y)$（即 $d(y,z) < s$），则由三角不等式（triangle inequality）
```math
d(x,y) \le d(y,z) + d(z,x).
```

于是
```math
r < r + s - d(y,z) \le d(x,y) - d(y,z) \le d(z,x).
```

（关键一步：由 $s = d(y,x) - r$ 得 $r + s = d(y,x)$，又 $d(y,z) < s$ 故 $s - d(y,z) > 0$，从而 $r < r + s - d(y,z)$ 成立。）

这表明 $B_s(y) \subset A_r$，即 $A_r$ 中每个点都有整个开球落在 $A_r$ 内，故 $A_r$ 是开集。$\square$

## 3. 闭集的序列等价刻画

下面的定理给出闭集的另一种定义方式，它与“补集为开集”的定义等价。

**Theorem（定理）**：度量空间 $(X,d)$ 的子集 $C$ 是闭集，**当且仅当** 对所有收敛序列 $x_n$，若每个 $x_n$ 都在 $C$ 中，则其极限也在 $C$ 中。

> **一句话**：闭集 = 「在序列极限下封闭」的集合。

**Proof（证明）**：

**（⇒ 充分性）** 先设 $A$ 是闭集，令 $x_n$ 是 $A$ 中的收敛序列，极限为 $x$，需证 $x \in A$。因 $A$ 闭，故补集 $X \setminus A$ 开。反设 $x \in X \setminus A$，则存在某个 $r > 0$ 使得 $B_r(x) \subset X \setminus A$，于是对一切 $y \in A$ 都有 $d(y,x) \ge r$。这便与 $x_n \to x$（即 $d(x_n,x) \to 0$）且 $x_n \in A$ 矛盾。故 $x \in A$。

**（⇐ 必要性）** 现设 $A$ 满足性质：凡 $A$ 中且在 $X$ 内收敛的序列，其极限都在 $A$ 中。需证 $A$ 闭，即证补集开。反设补集 $X \setminus A$ 不是开集，则存在 $x \in X \setminus A$，使得 $x$ 周围没有任何一个开球整个落在补集内。于是对每个 $n$，存在 $x_n \in A$ 且 $d(x_n,x) < \tfrac{1}{n}$（即球 $B_{1/n}(x)$ 总有 $A$ 中的点）。这样构造出的序列 $x_n$ 收敛到 $x$，而 $x$ 被假定不在 $A$ 中，这与 “$A$ 含 $A$ 中序列的一切极限” 相矛盾。故补集必为开集，$A$ 本身闭。$\square$

## 4. 闭集族的并与交

**Theorem（定理）**：

- **交（Intersection）**：若 $\{C_\alpha\}$ 是一族闭子集，则 $\bigcap_\alpha C_\alpha$ 也是闭集。
- **并（Union）**：若 $C_1,\dots,C_n$ 是闭子集，则 $C_1\cup\cdots\cup C_n$ 也是闭集。

> 注意两个方向的不对称性：**任意多个**闭集的**交**仍是闭集；但**有限多个**闭集的**并**才是闭集。

**Proof（证明）**：有多种证法，最简便的是直接用集合运算。对第一条结论，需证 $\bigcap_\alpha C_\alpha$ 的补集是开集。由集合运算（De Morgan 律）：
```math
X \setminus \bigcap_\alpha C_\alpha = \bigcup_\alpha (X \setminus C_\alpha).
```
每个 $X \setminus C_\alpha$ 都是开集，故上式右边是开集之并，从而为开集。第一条得证。

第二条同理。需证 $C_1\cup\cdots\cup C_n$ 闭，即证 $X \setminus (C_1\cup\cdots\cup C_n)$ 开。而
```math
X \setminus (C_1\cup\cdots\cup C_n) = (X \setminus C_1) \cap \cdots \cap (X \setminus C_n),
```
右边是**有限多个**开集的交，故为开集。第二条得证。$\square$

**Warning（警告）**：无限多个闭集的**并**未必是闭集！！！

## 5. 覆盖与开覆盖

**Definition（定义）— Cover, open cover, finite sub-cover（覆盖、开覆盖、有限子覆盖）**：设 $A$ 是 $X$ 的子集。$A$ 的一个**覆盖（cover）** 是一族 $X$ 的子集 $U_\alpha$，满足
```math
A \subset \bigcup_\alpha U_\alpha .
```
若其中有限个 $U_{\alpha_1},\dots,U_{\alpha_n}$ 仍构成覆盖，则称 $\{U_{\alpha_i}\}_i$ 为一个**有限子覆盖（finite sub-cover）**。若 $(X,d)$ 是度量空间且所有 $U_\alpha$ 均为开集，则称 $\{U_\alpha\}_\alpha$ 为一个**开覆盖（open cover）**。

---

## 6. 例子：覆盖的存在性与有限子覆盖的缺失

**Example（例子）**：若 $X = \mathbb{R}\times\mathbb{R}$，则 $A_n = (-n,n)\times(-n,n)$ 是 $X$ 的一个开覆盖。

**Example（例子）**：注意在上例中（$X=\mathbb{R}\times\mathbb{R}$，$A_n = (-n,n)\times(-n,n)$ 为开覆盖），该覆盖**不存在有限子覆盖**。反之，若 $A \subset \mathbb{R}\times\mathbb{R}$ 有界，则当 $n$ 充分大时 $A \subset A_n$，故对 $A$ 而言，该覆盖存在有限子覆盖。

> **解读**：覆盖全体 $\mathbb{R}^2$ 需要 “无穷无尽” 的一串正方形；但一个有界集合总可以被某一个足够大的正方形 $A_N$ 单独盖住，从而有「单元素」的有限子覆盖。这正暗示：**有界**是获得有限子覆盖的关键前提之一。

## 7. 紧集的定义

**Definition（定义）— Compact subset（紧子集）**：设 $(X,d)$ 是度量空间，$A$ 是其子集。若 $A$ 的**每个开覆盖都有有限子覆盖**，则称 $A$ 是**紧集（compact）**。

> **一句话**：紧集 = 「任何开覆盖都能抽出有限子覆盖」的集合。这是度量空间中「有界闭」概念的真正替代品（见下）。

**Example（例子）**：设 $(X,d)$ 为带通常度量（usual metric）的 $\mathbb{R}$，$A=(0,1)$。则 $A_n = (\tfrac{1}{n},1)$ 是 $A$ 的一个开覆盖，但 $\{A_n\}_n$ 不存在能盖住 $A$ 的有限子覆盖。

> **为什么没有有限子覆盖**：任何有限个 $A_n$ 中最小的 $n$ 记为 $N$，则这些集合的并只覆盖 $(\tfrac1N,1)$，而 $0<\tfrac{1}{N+1}<\tfrac1N$，点 $\tfrac{1}{N+1}\in(0,1)$ 却不在并中，故漏点。开区间的左端点 “无处安放”，正是 $(0,1)$ 不紧的根源。

## 9. 紧集必闭且有界

**Theorem（定理）**：若 $(X,d)$ 是度量空间，$A$ 是紧子集，则 $A$ **闭且**有界。

**Proof（证明）**：

**（先证闭）** 反设 $A$ 不闭。则不闭意味着存在 $A$ 中收敛序列 $x_n$，其极限 $x \notin A$。对每个 $n$，令
```math
O_n = \left\{ y \;\middle|\; d(x,y) > \tfrac{1}{n} \right\}.
```
由前面的引理，这些 $O_n$ 都是开集。又 $\bigcup_n O_n = X \setminus \{x\}$，而 $x$ 被假定不在 $A$ 中，故 $\{O_n\}$ 确实是 $A$ 的开覆盖。因为 $O_n \subset O_{n+1}$（嵌套递增），任何有限个 $O_n$ 的覆盖都落在某个足够大的 $O_N$ 中；但这意味着对一切 $y \in A$ 都有 $d(x,y) > \tfrac{1}{N}$，这与 $x_n \in A$ 且 $x_n \to x$（即 $d(x_n,x)\to 0$）矛盾。故极限 $x$ 必在 $A$ 中，$A$ 闭。

**（再证有界）** 因 $A$ 紧，考虑全空间的开覆盖 $X = \bigcup_y B_1(y)$（其中每个 $B_1(y)$ 是以 $y$ 为中心、半径 $1$ 的开球，均为开集），则其中有限个就能盖住 $A$。设
```math
A \subset B_1(y_1) \cup \cdots \cup B_1(y_n).
```
令 $r = 1 + \max_i \{d(y_1, y_i)\}$。由三角不等式可得 $A \subset B_r(y_1)$。故 $A$ 有界。$\square$

> **有界性的推理细节**：对任意 $x \in A$，$x$ 落在某个 $B_1(y_i)$ 中，故 $d(x,y_i)<1$；再由三角不等式 $d(x,y_1)\le d(x,y_i)+d(y_i,y_1) < 1 + d(y_i,y_1) \le r$。于是所有 $x$ 都落在 $B_r(y_1)$ 内，$A$ 有界。

**Warning（警告）**：**逆命题不成立！！！** 存在度量空间中「闭且有界」却**不紧**的子集。

## 10. 反例：闭有界未必紧

若 $(X,d) = (0,1)$（作为度量空间，带通常度量），则 $X$ 本身是闭且有的界，但它**不紧**。

> 这里是把 $(0,1)$ 当作「整个空间」来看：它作为自己的子集当然是闭的，也显然有界；但取开覆盖 $\{(\tfrac1n,1)\}$ 仍无有限子覆盖，故不紧。

下面是一个更具启发性的例子：

**Example（例子）**：设 $X = C([0,1])$，即闭区间 $[0,1]$ 上全体连续函数（continuous function）构成的空间。给 $X$ 装配度量
```math
d(f,g) = \max_{x} |f(x) - g(x)| .
```
（这是**一致范数** / sup 范数诱导的度量。）令 $f_n(x)$ 为 $[0,1]$ 上的一列连续函数，其定义为：

```math
f_n(x) =
\begin{cases}
1, & \text{若 } 0 \le x \le \tfrac{1}{n+1}, \
1 - n(n+1)\left(x - \tfrac{1}{n+1}\right), & \text{若 } \tfrac{1}{n+1} \le x \le \tfrac{1}{n}, \
0, & \text{否则（otherwise）}.
\end{cases}
```

> **译注（三段的来源与斜率核对）**：原书文字层在分式与区间处被打散成碎片（`1 − n (n + 1) x − 1` / `1 ≤ x ≤ 1` / `n+1` / `n` 各自单独成行），但数学意义唯一：斜坡宽度 $\tfrac1n-\tfrac{1}{n+1}=\tfrac{1}{n(n+1)}$，要把高度 $1$ 在这一段线性降到 $0$，斜率必须恰为 $-n(n+1)$。代入 $x=\tfrac1n$ 得 $1-n(n+1)\cdot\tfrac{1}{n(n+1)}=0$ ✓，代入 $x=\tfrac{1}{n+1}$ 得 $1$ ✓ —— 两端衔接，故这就是原式。

> **译注（为什么它说明「闭有界 ⇏ 紧」）**：所有 $f_n$ 都落在 $B_2(\mathbf 0)$ 内（$\max|f_n|=1<2$，$\mathbf 0$ 为恒零函数），且对任意 $m\ne n$ 有 $d(f_m,f_n)=1$ —— 取 $n>m$，则在 $[0,\tfrac{1}{n+1}]$ 上 $f_n\equiv1$ 而 $f_m\equiv0$，故 $\sup$ 差为 $1$。既然两项距离恒为 $1>0$，这列函数**没有 Cauchy 子列**，自然没有收敛子列；于是闭球 $A=\overline{B_1(\mathbf 0)}$ 有界闭而不紧。$C([0,1])$ 在 $\sup$ 范数下，紧性要求的是**等度连续 + 一致有界**（Arzelà–Ascoli），逐点有界远远不够。

> **本讲的整体脉络**：闭集（补集开 / 序列极限封闭）→ 覆盖与开覆盖 → 紧集（任一开覆盖有有限子覆盖）→ 紧 ⇒ 闭且有界（但反之不然）。下一讲将证明 $[a,b]$ 的紧性，并引出 Heine–Borel 定理与紧集的若干等价刻画。
