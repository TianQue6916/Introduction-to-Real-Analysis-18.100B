## 定理：Bolzano-Weierstrass 定理（Bolzano-Weierstrass Theorem）

> **任意有界序列都含有一个收敛子列（convergent subsequence）。**

### 证明（Proof）

设 $a_n$ 是有界序列。为简单起见，假设 $a_n\in[0,1]$。

**构造子列 $a_{n_k}$：**

要么有无穷多个 $n$ 使得 $a_n\in[0,\tfrac12]$，要么有无穷多个 $a_n$ 落在 $[\tfrac12,1]$ 中（或两者同时成立）。假设有无穷多项落在 $[0,\tfrac12]$ 中。令 $a_{n_1}=a_1$。令 $a_{n_2}$ 为下一个满足 $a_n\in[0,\tfrac12]$ 的 $a_n$。于是

```math
n_2>n_1=1,\qquad a_{n_1}\in[0,1],\qquad a_{n_2}\in\left[0,\tfrac12\right].
```

接着，要么有无穷多项落在 $[0,\tfrac14]$，要么有无穷多项落在 $[\tfrac14,\tfrac12]$。假设无穷多项落在 $[\tfrac14,\tfrac12]$。选取一个 $n>n_2$ 使得 $a_n\in[\tfrac14,\tfrac12]$，并令 $a_{n_3}=a_n$。如此继续下去。

**说明子列 $a_{n_k}$ 收敛：**

注意，对 $k_1,k_2\ge k$，我们有

```math
|a_{n_{k_1}}-a_{n_{k_2}}|\le 2^{1-k}.
```

由于 $2^{-k}\to 0$（当 $k\to\infty$），这表明子列 $a_{n_k}$ 是一个 Cauchy 序列。

不过实际上还能得到更强的结论：$a_{n_k}$ 被两条序列 **夹逼（squeezed）** 在中间，$b_k\le a_{n_k}\le c_k$。我们如下定义序列 $b_k$ 和 $c_k$：

- $b_k$ 是「长度 $2^{1-k}$ 的区间」的左端点，所有 $i\ge k$ 的项 $a_{n_i}$ 都落在这个区间里；
- $c_k$ 是同一区间的右端点。

于是序列 $b_k$ **递增（increasing）**，序列 $c_k$ **递减（decreasing）**，而 $a_{n_k}$ 被夹在二者之间。

因为 $b_k$ 单调递增且（有界，故）收敛，同理 $c_k$ 也收敛。又因为 $c_k-b_k=2^{1-k}$，故 $b_k$ 与 $c_k$ 收敛到**同一个数**；而后面那些 $a_{n_k}$ 全部被夹在两者之间，所以它们也收敛到同一个数。$\square$

## 人物注记：Karl Weierstrass（魏尔斯特拉斯）

> 摘自 Wikipedia：Karl Theodor Wilhelm Weierstrass（1815–1897）是德国数学家，常被誉为「现代分析之父（father of modern analysis）」。尽管他大学未取得学位便肄业，他仍自修数学并受训成为中学教师，最终教授数学、物理、植物学和体操。在众多贡献中，Weierstrass 形式化了函数连续性（continuity）的定义与复分析（complex analysis），证明了中值定理（intermediate value theorem）与 Bolzano–Weierstrass 定理，并利用后者研究了闭有界区间上连续函数的性质。

## 级数（Series）

设 $a_n$ 是序列，我们可以构造一个新序列 $s_n$ 如下。令

```math
s_1=a_1,\qquad s_2=a_1+a_2,\qquad s_3=a_1+a_2+a_3,
```

一般地，令

```math
s_n=a_1+\cdots+a_n=\sum_{i=1}^{n}a_i.
```

若序列 $s_n$ 收敛，则称级数（series）$\sum_{i=1}^{\infty}a_i$ 收敛；若收敛，我们也用 $\sum_{i=1}^{\infty}a_i$ 表示它的极限（即部分和 $s_n$ 的极限）。

> 注：这里 $s_n$ 称为级数的**部分和（partial sum）**；级数收敛的定义就是「部分和序列收敛」。

---

## 几何级数（Geometric Series）

设 $a_n=c^n$，于是级数为

```math
s_n=\sum_{i=0}^{n}c^i.
```

这就是**几何级数**。它当且仅当 $|c|<1$ 时收敛；而且当 $|c|<1$ 时，极限（无穷和）为

```math
\sum_{i=0}^{\infty}c^i=\frac{1}{1-c}.
```

**证明：** 观察

```math
(1-c)\sum_{i=0}^{n}c^i=1-c^{n+1}.
```

由此推出，当 $c\neq 1$ 时，

```math
s_n=\sum_{i=0}^{n}c^i=\frac{1-c^{n+1}}{1-c}.
```

因此，当 $|c|<1$ 时 $s_n$ 收敛，极限为 $\frac{1}{1-c}$；当 $|c|>1$ 或 $c=-1$ 时发散。此外可单独验证，$c=1$ 时也发散。（注：$c=1$ 时 $s_n=n+1\to\infty$；$c=-1$ 时 $s_n$ 在 $0,1$ 间振荡。）

## 调和级数（Harmonic Series）

对调和级数取 $a_n=\frac1n$，即级数 $\sum_{i=1}^{\infty}\frac1i$。这个级数**发散**。

为说明这一点，我们证明

```math
s_{2^n-1}\ge\frac n2.
```

**归纳基：** $n=1$ 时成立，因为 $s_1=1\ge\tfrac12$。

**归纳步：** 假设对 $n$ 成立，证明对 $n+1$ 也成立。即

```math
\begin{aligned}
s_{2^{n+1}-1}
&\ge s_{2^n-1}+\sum_{i=2^n}^{2^{n+1}-1}\frac{1}{2^{n+1}-1}\\
&\ge \frac n2+2^n\cdot\frac{1}{2^{n+1}-1}\\
&\ge \frac n2+\frac12=\frac{n+1}{2}.
\end{aligned}
```

> 注：中间一步用到「从 $2^n$ 到 $2^{n+1}-1$ 共有 $2^n$ 项，而每项 $\frac1i\ge\frac1{2^{n+1}-1}$」。

于是公式对 $n+1$ 也成立，从而对所有 $n$ 成立。

因为 $\frac n2\to\infty$，所以子列 $s_{2^n-1}$ 发散，故原级数也发散。

## 绝对收敛（Absolutely Convergent）

我们称级数

```math
\sum_{n=0}^{\infty}a_n
```

**绝对收敛（absolutely convergent）**，如果级数

```math
\sum_{n=0}^{\infty}|a_n|
```

收敛。

绝对收敛蕴含收敛，但反之不成立。

**例子：** 我们稍后会看到级数

```math
\sum_{n=1}^{\infty}\frac{(-1)^n}{n}
```

是收敛的；但若取各项 $a_n$ 的绝对值，就得到调和级数，而它是发散的。（注：这就是「条件收敛（conditionally convergent）」的典型例子。）

### 证明（为什么绝对收敛蕴含收敛）

由 Cauchy 收敛定理，我们只需证明：若级数 $\sum_{n=0}^{\infty}|a_n|$ 收敛，则序列 $\sum_{i=0}^{\infty}a_i$ 是 Cauchy 序列。

令

```math
s_n=\sum_{i=0}^{n}a_i,\qquad \widetilde{s_n}=\sum_{i=0}^{n}|a_i|.
```

对 $m\lt n$，有

```math
|s_n-s_m|=|a_n+\cdots+a_{m+1}|\le |a_n|+\cdots+|a_{m+1}|=|\widetilde{s_n}-\widetilde{s_m}|.
```

因为序列 $\widetilde{s_n}$ 是 Cauchy 序列，故 $s_n$ 也是。$\square$

## 定理：非负项级数的收敛准则

级数

```math
\sum_{i=0}^{\infty}a_i,\qquad a_n\ge 0,
```

收敛**当且仅当**序列 $s_n$ 有上界（bounded from above）。

### 证明

序列 $s_n$ 单调不减（monotone nondecreasing），因为

```math
s_{n+1}=s_n+a_n\ge s_n.
```

结论随即由**单调收敛定理（monotone convergence theorem）**推出。$\square$

> 注：单调收敛定理——单调不减且有上界的序列必收敛。

---

### 例子：级数 $\sum_{i=1}^{\infty}\frac1{i^2}$ 收敛

这是一个非负项序列，因此只需证明存在 $M$ 使得对所有 $n$，

```math
s_n=\sum_{i=1}^{n}\frac1{i^2}\le M.
```

**断言（Claim）：**

```math
s_{2^n-1}\le\sum_{i=0}^{n-1}\left(\frac12\right)^{i}.
```

这已足够，因为右边是一个收敛的几何级数，特别是有界的。

**用归纳法证明：** $n=1$ 时，$s_1=1=\left(\tfrac12\right)^0$，成立。假设对 $n$ 成立，证对 $n+1$ 也成立：

```math
\begin{aligned}
s_{2^{n+1}-1}
&=s_{2^n-1}+\sum_{i=2^n}^{2^{n+1}-1}\frac1{i^2}\\
&\le \sum_{i=0}^{n-1}\left(\frac12\right)^i+2^n\cdot\frac{1}{(2^n)^2}\\
&\le \sum_{i=0}^{n-1}\left(\frac12\right)^i+\frac{1}{2^n}\\
&=\sum_{i=0}^{n}\left(\frac12\right)^i.
\end{aligned}
```

这完成了归纳步，证明完毕。$\square$

## 级数收敛性的判别法（Tests）

为帮助判断级数是否收敛，有若干判别法：

- 比较判别法（Comparison test）
- 比值判别法（Ratio test）
- 根值判别法（Root test）

### 比较判别法（Comparison test）版本 1

设 $a_n$ 与 $b_n$ 是两个序列，满足

```math
0\le a_n\le b_n.
```

若 $\sum_{n=1}^{\infty}b_n$ 收敛，则 $\sum_{n=1}^{\infty}a_n$ 也收敛。

**例子：** 级数 $\sum_{n=1}^{\infty}\frac{2^{-n}}{n}$ 收敛。因为若令

```math
a_n=\frac{2^{-n}}{n},\qquad b_n=2^{-n},
```

则 $0\le a_n\le b_n$；又 $\sum_{n=1}^{\infty}b_n$ 收敛，故由比较判别法，$\sum_{n=1}^{\infty}a_n$ 也收敛。

### 比较判别法（Comparison test）版本 2

设 $a_n$ 与 $b_n$ 是两个序列，$b_n\neq 0$，且

```math
\lim_{n\to\infty}\frac{a_n}{b_n}=L\neq 0.
```

则级数 $\sum_{n=1}^{\infty}a_n$ 收敛**当且仅当** $\sum_{n=1}^{\infty}b_n$ 收敛。

**例子：** 级数

```math
\sum_{n=2}^{\infty}\frac{1}{n^2-1}
```

收敛，因为

```math
\frac{\frac1{n^2-1}}{\frac1{n^2}}=\frac{n^2}{n^2-1}\to 1,
```

而 $\sum_{n=2}^{\infty}\frac1{n^2}$ 收敛。（注：这里 $L=1\neq 0$，故两个级数同敛散。）

### 比值判别法（Ratio test）

设 $a_n\ge 0$，且假设

```math
\frac{a_{n+1}}{a_n}\to a.
```

- 若 $a<1$，则级数 $\sum a_n$ 收敛；
- 若 $a>1$，则级数 $\sum a_n$ 发散；
- 若 $a=1$，则无法判定（inconclusive）。

**例 1：** $a_n=\frac1n$。此时 $\frac{a_{n+1}}{a_n}\to 1$，判别法无法判定，但级数发散。

**例 2：** $a_n=\frac1{n^2}$。此时 $\frac{a_{n+1}}{a_n}\to 1$，判别法无法判定，但级数收敛。

> 注：这两个例子恰好说明 $a=1$ 时比值判别法「失效」，需要借助比较判别法等其它手段。
