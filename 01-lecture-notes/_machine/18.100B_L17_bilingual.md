## 回顾上一讲（Last time）

上一讲我们证明了 **Taylor 展开定理（Taylor expansion theorem）**：

> **定理（Taylor 展开，Taylor expansion）。** 设 $f:[a,b]\to\mathbb{R}$ 是一个函数，$k$ 是一个正整数。假设 $f, f', f^{(2)},\dots,f^{(k-1)}$ 在 $[a,b]$ 上存在且连续，且 $f^{(k)}$ 在 $(a,b)$ 上有定义，则存在一个介于 $a$ 与 $b$ 之间的点 $c$，使得
>
> ```math
> f(b)=f(a)+f'(a)(b-a)+\frac{f^{(2)}(a)}{2}(b-a)^2+\cdots+\frac{f^{(k-1)}(a)}{(k-1)!}(b-a)^{k-1}+\frac{f^{(k)}(c)}{k!}(b-a)^k .
> ```

> 注：上式最后一项 $\frac{f^{(k)}(c)}{k!}(b-a)^k$ 称为**余项（remainder term）**，其中 $c$ 是 $a$ 与 $b$ 之间的某个点；这是 Lagrange（拉格朗日）余项形式。

对于一个在 $\mathbb{R}$ 上**无穷次可微（infinitely differentiable）**的函数 $f$，我们定义它在 $a$ 处的 $(k-1)$ 次 Taylor 多项式（Taylor polynomial）为

```math
P_{k-1}(x)=f(a)+f'(a)(x-a)+\frac{f^{(2)}(a)}{2}(x-a)^2+\cdots+\frac{f^{(k-1)}(a)}{(k-1)!}(x-a)^{k-1}.
```

**问题（Question）：** 一个自然的问题是，当 $x$ 靠近 $a$ 时，这个多项式对 $f$ 的近似程度究竟如何？

**回答（Answer）：** 这取决于余项

```math
R_k(x)=\frac{f^{(k)}(c)}{k!}(x-a)^k
```

的大小。

## 例 1（Example 1）

设 $f(x)=e^x$，于是对一切 $k$ 有 $f^{(k)}(x)=f(x)$。这意味着在 $a=0$ 处的 Taylor 展开成为

```math
P_{k-1}(x)=\sum_{i=0}^{k-1}\frac{x^i}{i!}.
```

由 Taylor 展开定理，我们有

```math
f(x)=P_{k-1}(x)+\frac{f^{(k)}(c)}{k!}x^k.
```

由于对一切 $k$ 都有 $f^{(k)}(x)=f(x)$，由 Taylor 展开定理推出

```math
|f(x)-P_{k-1}(x)|\le \frac{e^{|x|}|x|^k}{k!}.
```

> 注：这里用到余项 $\frac{f^{(k)}(c)}{k!}x^k=\frac{e^c}{k!}x^k$，而 $c$ 在 $0$ 与 $x$ 之间，故 $e^c\le e^{|x|}$，从而 $|f(x)-P_{k-1}(x)|=\left|\frac{e^c}{k!}x^k\right|\le\frac{e^{|x|}|x|^k}{k!}$。

我们得出结论：当 $k$ 很大时，多项式 $P_{k-1}$ 对 $f$ 给出了相当好的近似。例如，若 $|x|\le 1$，则有

```math
|f(x)-P_{k-1}(x)|\le \frac{e}{k!}.
```

> 注：因为 $|x|\le 1$ 时 $e^{|x|}|x|^k\le e\cdot 1=e$，而分母 $k!$ 随 $k$ 迅速增大，故误差 $\frac{e}{k!}$ 迅速趋于 $0$。

## 例 2（Example 2）

在 $\mathbb{R}$ 上如下定义函数 $f$：

```math
f(x)=
\begin{cases}
0, & \text{若 } x\le 0,\
e^{-1/x^2}, & \text{其余情况}.
\end{cases}
```

容易看出 $f$ 是无穷次可微的，且对一切 $k$ 有 $f^{(k)}(0)=0$。由此推出，对一切 $k$，在 $0$ 处的 Taylor 多项式是 $P_{k-1}\equiv 0$。于是在这种情况下 $f(x)=R_k(x)$。

> 注：这是一个极重要的「非解析光滑函数」的例子——$f$ 在 $0$ 处各阶导数全为 $0$，故其 Taylor 级数恒为 $0$，与 $f$ 本身（在 $x>0$ 处 $f(x)>0$）不相等。这说明「无穷次可微」并不足以保证函数能被其 Taylor 级数表示（即函数未必是**解析的 analytic**）。

## Riemann 积分（Riemann Integrals）

### 划分（Partition）

设 $[a,b]$ 是一个区间。区间 $[a,b]$ 的一个**划分（partition）** $P$ 是由若干分点 $x_i$ 组成，使得

```math
a=x_0<x_1<x_2<\cdots<x_n=b.
```

这个划分由子区间 $[x_{i-1},x_i]$ 构成。我们记 $\Delta x_i=x_i-x_{i-1}$。

### 上和与下和（Upper and Lower Sums）

设 $f:[a,b]\to\mathbb{R}$ 是一个**有界函数（bounded function）**，$P=\{x_i\}$ 是区间 $[a,b]$ 的一个划分。我们如下定义上和与下和。令

```math
M_i=\sup_{[x_{i-1},x_i]} f,\qquad
m_i=\inf_{[x_{i-1},x_i]} f,
```

> 注：$M_i$ 是 $f$ 在第 $i$ 个子区间 $[x_{i-1},x_i]$ 上的**上确界（supremum，即最小上界）**，$m_i$ 是**下确界（infimum，即最大下界）**。这里的 sup/inf 是对整个子区间取的，不是只在分点上取。

并如下定义上和 $U(f,P)$ 与下和 $L(f,P)$：

```math
U(f,P)=\sum_{i=1}^{n}M_i\,\Delta x_i,\qquad
L(f,P)=\sum_{i=1}^{n}m_i\,\Delta x_i.
```

## 例 3（Example 3）

设函数为 $f(x)=x^2+1$，区间为 $[-2,2]$，划分为 $P=\{-2,-1,0,1,2\}$。我们有

```math
m_1=2,\ M_1=5;\qquad
m_2=1,\ M_2=2;\qquad
m_3=1,\ M_3=2;\qquad
m_4=2,\ M_4=5.
```

> 注：逐一验算——在 $[-2,-1]$ 上 $x^2\in[1,4]$，故 $f=x^2+1\in[2,5]$；在 $[-1,0]$ 上 $x^2\in[0,1]$，故 $f\in[1,2]$；在 $[0,1]$ 上同理 $f\in[1,2]$；在 $[1,2]$ 上 $x^2\in[1,4]$，故 $f\in[2,5]$。

于是下和与上和为

```math
L(f,P)=2\cdot 1+1\cdot 1+1\cdot 1+2\cdot 1=6,
```

```math
U(f,P)=5\cdot 1+2\cdot 1+2\cdot 1+5\cdot 1=14.
```

> 注：这里每个子区间长度 $\Delta x_i=1$，故各和就是把 $m_i$（或 $M_i$）相加。

下面的引理是显然的（由 $M_i\ge m_i$ 立即得到）：

> **引理 1（Lemma 1）：** 我们恒有
>
> ```math
> U(f,P)\ge L(f,P).
> ```

## 细分（Sub-partition）

设 $[a,b]$ 是一个区间，$P_1$ 与 $P_2$ 是区间 $[a,b]$ 的两个划分。若 $P_1$ 中的所有分点都出现在 $P_2$ 中（并且 $P_2$ 可能还含有一些额外的分点），则称 $P_2$ 是 $P_1$ 的一个**细分（sub-partition，或 refinement，加细）**。

> 注：原文此处「all the dividing points in $P_1$ are also in $P_1$」应为笔误，正确表述是「$P_1$ 的所有分点也在 $P_2$ 中」，即 $P_2\supseteq P_1$。〔原书此处有笔误，已按数学含义修正，待核〕

## 例 4（Example 4）

设区间为 $[-2,2]$，给定划分 $P_1$ 为

```math
\{-2,-1,0,1,2\}.
```

则划分

```math
P_2=\left\{-2,-1,-\frac12,0,\frac12,1,2\right\}
```

是 $P_1$ 的一个加细（细分）。事实上，$P_2$ 含有 $P_1$ 的全部（相同的）分点，此外还多了一些分点。

## 引理 2（Lemma 2）

设 $f:[a,b]\to\mathbb{R}$ 是有界函数，$P_1$ 是区间 $[a,b]$ 的一个划分，$P_2$ 是 $P_1$ 的一个细分，则

```math
L(f,P_1)\le L(f,P_2)\le U(f,P_2)\le U(f,P_1).
```

> 注：这个引理说的是——划分越细，下和**不减**（不会变小），上和**不增**（不会变大）。

### 证明（Proof）

中间那个不等式就是前面的引理 1。

右边那个不等式由「$P_2$ 是 $P_1$ 的细分」推出。具体地，设 $a=x_0\lt x_1<\cdots\lt x_n=b$ 是 $P_1$ 的分点，且在某个 $x_{i-1}$ 与 $x_i$ 之间，$P_2$ 有一个额外的分点 $y$，即 $x_{i-1}\lt y\lt x_i$。那么

```math
\sup_{[x_{i-1},y]} f\le M_i,\qquad
\sup_{[y,x_i]} f\le M_i,
```

> 注：这是因为 $[x_{i-1},y]$ 与 $[y,x_i]$ 都是 $[x_{i-1},x_i]$ 的子区间，而函数在一个更小的集合上的上确界不会超过在整个集合上的上确界。

于是

```math
\Big[\sup_{[x_{i-1},y]} f\Big](y-x_{i-1})+\Big[\sup_{[y,x_i]} f\Big](x_i-y)\le M_i\,\Delta x_i.
```

> 注：左边正是把子区间 $[x_{i-1},x_i]$ 拆成 $[x_{i-1},y]$ 与 $[y,x_i]$ 两段后、对 $U$ 和所做的贡献；由于两段长度之和为 $y-x_{i-1}+x_i-y=x_i-x_{i-1}=\Delta x_i$，且每段的上确界 $\le M_i$，故两段贡献之和 $\le M_i(y-x_{i-1})+M_i(x_i-y)=M_i\Delta x_i$。

由此易得

```math
U(f,P_2)\le U(f,P_1).
```

> 注：对每一个被拆分出的子区间都做同样的估计，再求和，就得到 $U(f,P_2)\le U(f,P_1)$。

类似地可证左边那个不等式（$L(f,P_1)\le L(f,P_2)$）。$\square$

> 注（左边不等式的对称论证）：对下和，函数在更小子区间上的下确界 $\ge$ 在整段上的下确界 $m_i$，即 $\inf_{[x_{i-1},y]}f\ge m_i$ 且 $\inf_{[y,x_i]}f\ge m_i$，故两段下和贡献之和 $\ge m_i\Delta x_i$，求和得 $L(f,P_2)\ge L(f,P_1)$。

## 上积分与下积分（Upper and Lower Integrals）

设 $f:[a,b]\to\mathbb{R}$ 是有界函数。定义 $f$ 的**上 Riemann 积分（upper Riemann integral）**为

```math
\overline{\int_a^b} f\,dx=\inf_{P}\, U(f,P),
```

这里下确界是对 $[a,b]$ 的所有划分取的。同样地，定义**下 Riemann 积分（lower Riemann integral）**为

```math
\underline{\int_a^b} f\,dx=\sup_{P}\, L(f,P).
```

> 注：原文用带横线的积分号 $\overline{\int}$ 与 $\underline{\int}$ 分别表示上、下积分，此处为排版清晰改用上标形式 $\overline{\int}$（上积分）与 $\underline{\int}$（下积分）。

---

## Riemann 积分（Riemann Integral）

设 $f:[a,b]\to\mathbb{R}$ 是有界函数。若

```math
\underline{\int_a^b} f\,dx=\overline{\int_a^b} f\,dx,
```

则称 $f$ 是 **Riemann 可积的（Riemann integrable）**。

若函数 Riemann 可积，则其 Riemann 积分为

```math
\int_a^b f\,dx=\underline{\int_a^b} f\,dx=\overline{\int_a^b} f\,dx.
```

所有 Riemann 可积函数的集合记为 $\mathcal{R}([a,b])$。

> 注：这里完整地呈现了 Riemann 积分的严格构造——先把区间划分成小块，用「矩形面积」给出上和（过高估计）与下和（过低估计），再分别取 sup 与 inf 得到上、下积分，最后要求二者相等，从而唯一确定积分值。这一构造正是对「曲线下面积」的严格化。

## 人物注记：Georg Friedrich Bernhard Riemann（黎曼）

> 摘自 Wikipedia：Georg Friedrich Bernhard Riemann（1826–1866）是德国数学家，在分析、数论和微分几何方面做出了深刻贡献。Riemann 于 1854 年首次授课，奠定了 Riemannian geometry（黎曼几何）这一领域的基础，从而为 Albert Einstein 的广义相对论铺平了道路。在实分析领域，他最负盛名的是首次给出积分的严格表述——即 **Riemann 积分（Riemann integral）**，以及他在 Fourier 级数方面的工作。他对复分析的贡献中最引人注目的是引入了 **Riemann surfaces（黎曼面）**，为复分析的自然几何处理开辟了新天地。他 1859 年关于素数计数函数的论文，包含 **Riemann hypothesis（黎曼假设）** 的最初陈述，被视为解析数论的奠基性论文。他被许多人认为是史上最伟大的数学家之一。

## 例 5（Example 5）

设 $f:[0,1]\to\mathbb{R}$ 为

```math
f(x)=
\begin{cases}
0, & \text{若 } x\in[0,1]\cap\mathbb{Q},\
1, & \text{其余情况}.
\end{cases}
```

对于这个函数以及所有的划分 $P$，我们有

```math
L(f,P)=0,\qquad U(f,P)=1.
```

> 注：因为在任意子区间 $[x_{i-1},x_i]$ 内，既含有理数也含无理数（有理数 $\mathbb{Q}$ 与无理数都在实数中处处稠密），故 $m_i=\inf f=0$（区间里有取 $0$ 的有理数点），$M_i=\sup f=1$（区间里有取 $1$ 的无理数点），于是对任意划分 $L=0$、$U=1$。

因此 $f$ **不是** Riemann 可积的。

第二个问题的答案将是**微积分基本定理（fundamental theorem of calculus，FTC）**。这将是之后一讲的主题。

## 引理 3（Lemma 3）

设 $f:[a,b]\to\mathbb{R}$ 是有界函数，则 $f\in\mathcal{R}([a,b])$ **当且仅当**对任意 $\varepsilon>0$，存在一个划分 $P$ 使得

```math
U(f,P)-L(f,P)<\varepsilon.
```

> 注：这个引理给出了 Riemann 可积性的一个可操作的**判定准则**：只要能让上和与下和的差任意小，函数就可积。后面定理「连续函数可积」正是靠它来证明的。

### 证明（Proof）

**（$\Rightarrow$）** 设 $f\in\mathcal{R}([a,b])$，则

```math
\sup_P L(f,P)=\underline{\int_a^b}f\,dx=\overline{\int_a^b}f\,dx=\inf_P U(f,P).
```

这意味着：给定 $\varepsilon>0$，存在划分 $P_1$ 与 $P_2$ 使得

```math
\underline{\int_a^b}f\,dx-\frac{\varepsilon}{2}<L(f,P_1),
```

且

```math
U(f,P_2)\le \underline{\int_a^b}f\,dx+\frac{\varepsilon}{2}.
```

> 注：这两条分别来自「上确界的性质」与「下确界的性质」——由 $\sup$ 的定义，存在划分 $P_1$ 使 $L(f,P_1)$ 落在上确界（即积分值）的 $\varepsilon/2$ 邻域内；由 $\inf$ 的定义，存在 $P_2$ 使 $U(f,P_2)$ 落在下确界的 $\varepsilon/2$ 邻域内。这里「取 $\varepsilon/2$」正是为了最后凑出 $\varepsilon$。

令 $P$ 为同时含有 $P_1$ 与 $P_2$ 所有分点的划分，于是 $P$ 既是 $P_1$ 的细分也是 $P_2$ 的细分。由此（结合引理 2）推出

```math
\underline{\int_a^b}f\,dx-\frac{\varepsilon}{2}<L(f,P_1)\le L(f,P)\le U(f,P)\le U(f,P_2)\le \underline{\int_a^b}f\,dx+\frac{\varepsilon}{2}.
```

于是 $U(f,P)-L(f,P)<\varepsilon$，命题得证。

**（$\Leftarrow$）** 反过来，假设对某个 $\varepsilon>0$，存在划分 $P$ 使得

```math
U(f,P)-L(f,P)<\varepsilon.
```

由于

```math
L(f,P)\le \underline{\int_a^b}f\,dx
```

且

```math
\overline{\int_a^b}f\,dx\le U(f,P),
```

> 注：这两条由定义直接得到——下积分是 $L(f,P)$ 的上确界，故 $\ge$ 任意一个 $L(f,P)$；上积分是 $U(f,P)$ 的下确界，故 $\le$ 任意一个 $U(f,P)$。

我们有

```math
\overline{\int_a^b}f\,dx-\underline{\int_a^b}f\,dx\le U(f,P)-L(f,P)<\varepsilon.
```

由于这对**所有** $\varepsilon>0$ 都成立，故

```math
\overline{\int_a^b}f\,dx=\underline{\int_a^b}f\,dx,
```

> 注：这里用到「非负数小于一切正数则必为 $0$」——两个积分的差 $\ge 0$（因为 $\overline{\int}\ge\underline{\int}$），若它小于一切 $\varepsilon>0$，则必等于 $0$，即上、下积分相等。

从而 $f\in\mathcal{R}([a,b])$。$\square$

## 关键定理（Key Theorem）

现在我们得到一个关键定理，它给出了函数 Riemann 可积的一个简洁判定准则：

> **定理：** $[a,b]$ 上的任意**连续函数（continuous function）**都属于 $\mathcal{R}([a,b])$，即连续函数必 Riemann 可积。

### 证明（Proof）

> 下一次我们证明了「闭有界区间上的连续函数实际上是一致连续的」之后，再给出证明。$\square$

> 注：这个定理的完整证明需要下一节的关键概念——**一致连续（uniform continuity）**。

---

## 定义：一致连续（Uniformly Continuous）

设 $f:I\to\mathbb{R}$ 是一个函数，其中 $I$ 是一个区间。若对任意 $\varepsilon>0$，存在一个 $\delta>0$ 使得

```math
|f(x)-f(y)|<\varepsilon \quad \text{当 } |x-y|<\delta,
```

则称 $f$ 是**一致连续的（uniformly continuous）**。

> 注：一致连续比「（逐点）连续（continuous）」更强。它的含义是：对于给定的 $\varepsilon>0$，**同一个** $\delta$ 可以对**所有的** $x$（以及 $y$）通用。与之对照，逐点连续只要求每个点 $x$ 各自对应一个（可能随 $x$ 变化的）$\delta$，即 $\delta=\delta(x,\varepsilon)$ 可依赖于 $x$；而一致连续要求 $\delta=\delta(\varepsilon)$ 与位置 $x$ 无关。

> 例子（区分二者）：函数 $f(x)=1/x$ 在 $(0,1)$ 上逐点连续但**不是**一致连续——越靠近 $0$，函数变化越剧烈，找不到一个对所有 $x$ 都通用的 $\delta$。
