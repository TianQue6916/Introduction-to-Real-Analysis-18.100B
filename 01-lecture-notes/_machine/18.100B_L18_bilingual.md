## 1. 一致连续（Uniformly Continuous）

**定义：一致连续。** 设 $f : I \to \mathbb{R}$ 是一个函数，其中 $I$ 是一个区间（interval）。我们称 $f$ 是**一致连续**（uniformly continuous）的，如果对任意 $\epsilon > 0$，都存在 $\delta > 0$，使得只要 $|x-y| < \delta$，就有

```math
|f(x) - f(y)| < \epsilon .
```

注意：一致连续比（逐点）连续（continuous）更强。它的意思是：给定一个 $\epsilon > 0$，同一个 $\delta$ 可以对**所有** $x$ 一起使用（而逐点连续中 $\delta$ 一般随点 $x$ 变化）。

**例 1：** 设 $f(x) = x^2$ 在 $\mathbb{R}$ 上，则 $f$ **不是**一致连续的。

证明思路（反证）：给定 $\epsilon > 0$，若 $f$ 一致连续，则应存在 $\delta > 0$ 使得对所有 $x$ 都有

```math
f(x+\delta) - f(x) < \epsilon .
```

这意味着对所有 $x$ 都有

```math
2\delta x < (x+\delta)^2 - x^2 < \epsilon ,
```

而这对所有 $x$ 显然不可能成立（因为 $2\delta x$ 随 $x$ 增大可任意大）。故 $f(x)=x^2$ 在 $\mathbb{R}$ 上不一致连续。

**例 2：** 设 $f(x) = \frac{1}{x}$ 在 $(0,1]$ 上，则 $f$ **不是**一致连续的。

证明思路：考虑 $x_n = \frac{1}{n}$，$y_n = \frac{1}{2n}$，则

```math
|f(x_n) - f(y_n)| = n ,
```

而

```math
|x_n - y_n| = \frac{1}{2n} < \frac{1}{n} .
```

即 $|x_n - y_n| \to 0$，但 $|f(x_n)-f(y_n)| = n \to \infty$。由此容易推出 $f$ 不一致连续。（一致连续要求 $|x-y|$ 足够小时 $|f(x)-f(y)|$ 一致地小，这里 $x_n,y_n$ 无限接近，函数值之差却发散。）

**定理 1：** 闭区间 $[a,b]$ 上的任何连续函数都是一致连续的。

### 定理 1 的证明

证明（反证法）。假设不然，则存在 $\epsilon > 0$，使得对每个 $n > 0$，都存在 $x_n$、$y_n$ 满足

```math
|x_n - y_n| < \frac{1}{n}
```

且

```math
|f(x_n) - f(y_n)| \ge \epsilon .
```

因为区间 $[a,b]$ 是**紧致**（compact）的，我们可以从 $x_n$ 中选出子列（subsequence）$x_{n_k}$，使得

```math
x_{n_k} \to x .
```

（注：紧致性（compactness）的定义是：闭且且有界区间上的任何序列都有收敛子列，即 Bolzano–Weierstrass 定理。）由于

```math
|x - y_{n_k}| \le |x - x_{n_k}| + |x_{n_k} - y_{n_k}| ,
```

且 $|x_{n_k} - y_{n_k}| < \frac{1}{n_k} \to 0$，我们有 $y_{n_k} \to x$ 也成立。因为 $f$ 连续，所以 $f(x_{n_k}) \to f(x)$ 且 $f(y_{n_k}) \to f(x)$。然而，这与

```math
|f(x_{n_k}) - f(y_{n_k})| \ge \epsilon
```

矛盾（因为若两者都趋于 $f(x)$，其差应趋于 $0$）。$\Box$

## 2. 连续函数可黎曼积分

我们现在得到一个关键定理，它给出了函数黎曼可积（Riemann integrable）的一个简单判据：

**定理 2：** $[a,b]$ 上的任何连续函数都属于 $\mathcal{R}([a,b])$（即黎曼可积函数类）。

### 定理 2 的证明

证明。给定 $\epsilon > 0$，由定理 1 知 $f$ 一致连续，故存在 $\delta > 0$，使得当 $|x-y| < \delta$ 时，

```math
|f(x) - f(y)| < \frac{\epsilon}{b-a} .
```

设 $P$ 是一个分割（partition），使得对所有 $i$ 都有 $\Delta x_i < \delta$（即每个小区间 $[x_{i-1},x_i]$ 的长度小于 $\delta$）。则在分割的每个区间 $[x_{i-1},x_i]$ 上，有

```math
M_i - m_i < \frac{\epsilon}{b-a} .
```

（其中 $M_i = \sup_{[x_{i-1},x_i]} f$ 是 $f$ 在该区间上的**上确界**（supremum），$m_i = \inf_{[x_{i-1},x_i]} f$ 是**下确界**（infimum）。上确界指最小的上界，下确界指最大的下界。）

于是

```math
U(f,P) - L(f,P) = \sum_i M_i \Delta x_i - \sum_i m_i \Delta x_i
```

```math
= \sum_i [M_i - m_i] \Delta x_i < \frac{\epsilon}{b-a} \sum_i \Delta x_i = \epsilon .
```

（其中 $U(f,P)$、$L(f,P)$ 分别是上、下 Darboux 和。）因为这对所有 $\epsilon > 0$ 成立，所以 $f$ 可积。$\Box$

## 3. 积分的基本性质

**定理 3：** 积分有以下基本公式：

**(1)** 若 $f \in \mathcal{R}([a,b])$ 且 $c \in \mathbb{R}$，则 $cf \in \mathcal{R}([a,b])$，且

```math
\int_a^b (cf)\, dx = c \int_a^b f\, dx .
```

**(2)** 若 $f,g \in \mathcal{R}([a,b])$，则 $f+g \in \mathcal{R}([a,b])$，且

```math
\int_a^b (f+g)\, dx = \int_a^b f\, dx + \int_a^b g\, dx .
```

**(3)** 若 $f,g \in \mathcal{R}([a,b])$ 且 $f \le g$，则

```math
\int_a^b f\, dx \le \int_a^b g\, dx .
```

**(4)** 若 $f \in \mathcal{R}([a,b])$ 且 $c \in (a,b)$，则 $f \in \mathcal{R}([a,c])$、$f \in \mathcal{R}([c,b])$，且

```math
\int_a^c f\, dx + \int_c^b f\, dx = \int_a^b f\, dx .
```

### 定理 3 的证明

**证明第 (1) 条。** 这由如下事实得到：若 $P$ 是一个分割，则（当 $c \ge 0$ 时）

```math
L(cf,P) = c\, L(f,P), \qquad U(cf,P) = c\, U(f,P) .
```

（当 $c<0$ 时乘以 $c$ 会交换上下确界，结论经同样论证仍成立。）故 $cf$ 的上下和之差等于 $c$ 倍的 $f$ 的上下和之差，可积性保持，且积分等于 $c$ 倍。

**证明第 (2) 条。** 给定 $\epsilon > 0$，取分割 $P_1$、$P_2$ 使得

```math
U(f,P_1) - L(f,P_1) < \frac{\epsilon}{2}, \qquad U(g,P_2) - L(g,P_2) < \frac{\epsilon}{2} .
```

设 $P$ 是同时含有 $P_1$ 与 $P_2$ 分点的分割（即 $P_1$ 与 $P_2$ 的公共加细 refinement）。则有

```math
U(f,P) - L(f,P) < \frac{\epsilon}{2}, \qquad U(g,P) - L(g,P) < \frac{\epsilon}{2} .
```

（加细分割只会使上下和之差更小。）因此

```math
U(f+g,P) - L(f+g,P) < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon .
```

由此第 (2) 条成立。

**证明第 (3) 条。** 设 $P$ 是 $[a,b]$ 的任意分割。由 $f \le g$ 可知

```math
U(f,P) \le U(g,P) .
```

（原文此处写的是 $U(g,P)\le U(f,P)$，应为笔误，正确方向是 $U(f,P)\le U(g,P)$，否则与结论 $\int f \le \int g$ 矛盾。〕因为

```math
\int_a^b g\, dx = \inf_P U(g,P)
```

（积分为下确界，即最大的下界），$f$ 也同理，故结论成立：$\int_a^b f\, dx \le \int_a^b g\, dx$。

**证明第 (4) 条。** 设 $P$ 是 $[a,b]$ 的任意分割，令 $P_0$ 是 $P$ 的加细，它在 $P$ 的分点之外还把 $c$ 作为一个分点。则有

```math
U(f, P_0 \cap [a,c]) + U(f, P_0 \cap [c,b]) = U(f, P_0) ,
```

同理

```math
L(f, P_0 \cap [a,c]) + L(f, P_0 \cap [c,b]) = L(f, P_0) .
```

因此

```math
U(f, P_0 \cap [a,c]) - L(f, P_0 \cap [a,c]) + U(f, P_0 \cap [c,b]) - L(f, P_0 \cap [c,b]) = U(f,P_0) - L(f,P_0) .
```

由于左端两项都是非负的，$f$ 在 $[a,c]$ 与 $[c,b]$ 上的上下和之差都受 $U(f,P_0)-L(f,P_0)$ 控制，故 $f$ 在两个子区间上都可积，且积分可加性成立。由此第 (4) 条成立。$\Box$

## 4. 推论：积分的绝对值估计

**推论：** 设 $f, |f| \in \mathcal{R}([a,b])$，则

```math
\left| \int_a^b f\, dx \right| \le \int_a^b |f|\, dx .
```

（注：原文误写为 $\int_x^b$，应为 $\int_a^b$。〕

### 推论的证明

证明。这由 $f \le |f|$ 与 $-f \le |f|$ 以及第 (3) 条（单调性）得到。具体地，由第一个不等式结合第 (3) 条得

```math
\int_a^b f\, dx \le \int_a^b |f|\, dx ,
```

而由第二个不等式得

```math
-\int_a^b f\, dx = \int_a^b (-f)\, dx \le \int_a^b |f|\, dx .
```

两者合起来即得 $\left| \int_a^b f\, dx \right| \le \int_a^b |f|\, dx$。$\Box$

## 5. 微积分基本定理第一版本

**微积分基本定理（版本 1）：** 设 $f$ 是 $[a,b]$ 上的连续函数，定义 $[a,b]$ 上的 $F$ 为

```math
F(x) = \int_a^x f(s)\, ds .
```

则函数 $F$ 可微，且导数为 $f$（即 $F'(x) = f(x)$）。

### 版本 1 的证明

证明。固定 $x_0 \in [a,b]$，先假设 $x > x_0$。此时有

```math
F(x) = \int_a^x f(s)\, ds = \int_a^{x_0} f(s)\, ds + \int_{x_0}^x f(s)\, ds = F(x_0) + \int_{x_0}^x f(s)\, ds .
```

于是

```math
F(x) - F(x_0) = \int_{x_0}^x f(s)\, ds .
```

因此

```math
(x-x_0)\,\min_{[x_0,x]} f \le F(x) - F(x_0) \le (x-x_0)\,\max_{[x_0,x]} f ,
```

从而

```math
\min_{[x_0,x]} f \le \frac{F(x) - F(x_0)}{x-x_0} \le \max_{[x_0,x]} f .
```

（这里 $\min_{[x_0,x]} f$ 与 $\max_{[x_0,x]} f$ 分别是 $f$ 在 $[x_0,x]$ 上的最小值与最大值，因 $f$ 连续必可取得。）当 $x \to x_0$ 时，由于 $f$ 在 $x_0$ 连续，这串不等式的左端和右端都收敛到 $f(x_0)$。由夹逼可得

```math
\lim_{x\to x_0^+} \frac{F(x)-F(x_0)}{x-x_0} = f(x_0) .
```

这证明了 $x > x_0$ 的情况。当 $x < x_0$ 时，可把 $F(x)$ 写成

```math
F(x) + \int_x^{x_0} f(s)\, ds = F(x_0) ,
```

因此

```math
F(x) - F(x_0) = -\int_x^{x_0} f(s)\, ds .
```

与上面完全类似的论证（此时 $x-x_0<0$，除以负数后夹逼方向保持）也给出同样结论。故 $F'(x_0)=f(x_0)$，由 $x_0$ 的任意性得证。$\Box$

## 6. 微积分基本定理第二版本

**微积分基本定理（版本 2）：** 设 $F : [a,b] \to \mathbb{R}$ 可微，且 $F' = f \in \mathcal{R}([a,b])$，则

```math
\int_a^b f(s)\, ds = F(b) - F(a) .
```

### 版本 2 的证明

证明。因为 $f$ 可积，对任意 $\epsilon > 0$，存在 $[a,b]$ 的一个分割 $P$ 使得

```math
U(f,P) - L(f,P) < \epsilon .
```

对给定的分点为 $x_i$ 的分割 $P$，有

```math
L(f,P) = \sum_i m_i (x_i - x_{i-1}), \qquad U(f,P) = \sum_i M_i (x_i - x_{i-1}) .
```

此外，由**中值定理**（mean value theorem，原文写 mean value inequality，此处应为均值定理）在每个小区间 $[x_{i-1},x_i]$ 上存在 $y_i$ 使得

```math
F(x_i) - F(x_{i-1}) = f(y_i)\,(x_i - x_{i-1}) .
```

（注：$F$ 在闭区间上连续、开区间上可微，满足均值定理条件。）因为 $m_i \le f(y_i) \le M_i$，我们有

```math
m_i (x_i - x_{i-1}) \le F(x_i) - F(x_{i-1}) \le M_i (x_i - x_{i-1}) .
```

于是

```math
L(f,P) \le \sum_{i=1}^n [F(x_i) - F(x_{i-1})] \le U(f,P) .
```

最后，注意到（望远镜和 telescoping sum）

```math
\sum_{i=1}^n [F(x_i) - F(x_{i-1})] = F(b) - F(a) .
```

即对任意 $\epsilon > 0$，存在分割 $P$ 使 $F(b)-F(a)$ 落在宽度小于 $\epsilon$ 的区间 $[L(f,P), U(f,P)]$ 内，而积分 $\int_a^b f$ 也落在同一区间内。令 $\epsilon \to 0$ 即得

```math
F(b) - F(a) = \int_a^b f(s)\, ds .
```

$\Box$

## 7. 例 3：用基本定理计算积分

**例 3：** 计算

```math
\int_0^1 x^2\, dx .
```

我们使用微积分基本定理第二版本。注意到函数

```math
F(x) = \frac{x^3}{3}
```

的导数是 $x^2$。因此，由微积分基本定理第二版本，我们有

```math
\int_0^1 x^2\, dx = F(1) - F(0) = \frac{1}{3} - 0 = \frac{1}{3} .
```
