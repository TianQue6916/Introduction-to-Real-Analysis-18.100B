## 2. 一个例子：中间值定理（Intermediate Value Theorem）

**Intermediate value theorem**（**中间值定理**）：设 $f: [a,b] \to \mathbb{R}$ 是一个连续函数（continuous function），且 $f(a) < 0$、$f(b) > 0$。那么中间值定理断言：**存在**一个 $c \in (a,b)$，使得 $f(c) = 0$。

讲义提出的问题链：

- 怎么证明它？（How do we prove this?）
- 画一张图似乎「显然」成立，但**真正严格地**证明该如何下手？
- 「连续」从图形上讲，大致就是：画函数图像时**铅笔不允许离开纸面**（the pencil is not allowed to leave the paper）。
- 怎么把这个直观想法变成一个**严格的证明**（proper proof）？
- 证明这件事需要用到**实数的哪些性质**（what properties of the real numbers）？

这引出三个问题：

- **Q1**：什么是实数（What is a real number）？
- **Q2**：为什么 $\sqrt{2}$ 是实数？
- **Q3**：$\sqrt{2}$ 到底是什么？

**这些问题共同的答案**：$\mathbb{R}$ 是一个**完备有序域**（complete ordered field），且它**包含有理数 $\mathbb{Q}$**（contains the rational numbers）。

> 译注：这句话是全课程的纲领。「complete ordered field」三个词各司其职——后面会逐一展开。

## 3. 记号（Notation）

- **(1)** $\mathbb{N}$ 是**自然数**（natural numbers），即 $\mathbb{N} = \{1, 2, 3, \dots\}$。
- **(2)** $\mathbb{Z}$ 是**整数**（integers），即 $\mathbb{Z} = \{0, \pm 1, \pm 2, \pm 3, \dots\}$。
- **(3)** $\mathbb{Q}$ 是**有理数**（rational numbers），即所有形如 $\frac{m}{n}$ 的数，其中 $m \in \mathbb{Z}$，$n \in \mathbb{N}$。

> 译注：注意这里的自然数从 1 开始，不含 0（这是 Colding 讲义的口径；不同教材对 $\mathbb{N}$ 是否含 0 有分歧）。

## 4. 有理数（Rational Numbers）的运算与比较

有理数 $\mathbb{Q}$ 是形如 $\frac{m}{n}$（$m \in \mathbb{Z}$，$n \in \mathbb{N}$）的数。讲义用「分数」这一表示来逐条定义它的基本规则：

**(1) 两数何时相等？**

```math
\frac{m_1}{n_1} = \frac{m_2}{n_2} \iff m_1 n_2 = m_2 n_1 .
```

**(2) 两数如何相加？**

```math
\frac{m_1}{n_1} + \frac{m_2}{n_2} = \frac{m_1 n_2 + m_2 n_1}{n_1 n_2} .
```

**(3) 两数如何相乘？**

```math
\frac{m_1}{n_1} \cdot \frac{m_2}{n_2} = \frac{m_1 m_2}{n_1 n_2} .
```

**(4) 一数何时小于另一数？**

```math
\frac{m_1}{n_1} < \frac{m_2}{n_2} \iff m_1 n_2 < m_2 n_1 .
```

> 译注：这四条看起来「显然」，但它们的要害在于——分数 $\frac{m}{n}$ 的写法**不唯一**（例如 $\frac{1}{2} = \frac{2}{4}$）。所以必须验证：用不同的写法代入这些定义，结果是否一致。这就是下面「良定义（well-defined）」要解决的问题。

### 4.1 乘法是良定义的（well-defined）

为了让上述定义「讲得通」（make sense），需要证明（例如）乘法是 **well-defined**（**良定义的**）——即：若同一有理数有两种写法

```math
\frac{m_1}{n_1} = \frac{m_2}{n_2} \quad \text{以及} \quad \frac{p_1}{q_1} = \frac{p_2}{q_2},
```

那么

```math
\frac{m_1 p_1}{n_1 q_1} = \frac{m_2 p_2}{n_2 q_2}.
```

**证明（完整思路）**：

由两个相等条件，我们有

```math
m_1 n_2 = m_2 n_1 \quad \text{且} \quad p_1 q_2 = p_2 q_1.
```

我们要证明 $\frac{m_1 p_1}{n_1 q_1} = \frac{m_2 p_2}{n_2 q_2}$，按「两数相等」的定义 (1)，这等价于验证

```math
(m_1 p_1)(n_2 q_2) = (m_2 p_2)(n_1 q_1).
```

从左端出发（利用整数乘法可交换、可结合，且 $m_1 n_2 = m_2 n_1$、$p_1 q_2 = p_2 q_1$）：

```math
m_1 p_1 n_2 q_2 = (m_1 n_2)(p_1 q_2) = (m_2 n_1)(p_2 q_1) = m_2 p_2 n_1 q_1.
```

这正是所需等式，故乘法良定义成立。$\square$

> 译注：这个证明看似琐碎，却示范了实分析「证明到底该有多细」的标准——每一步都回到定义，不跳步。

## 5. 域（Field）

**定义（Field / 域）**：一个 **Field** $F$（**域**）是一个集合，配备两个运算，我们「暗示性地」记为 $+$ 和 $\cdot$。这两个运算满足下列公理（axioms）。

**加法性质（Additive properties）**：

1. 若 $x, y \in F$，则 $x + y \in F$（**加法封闭**）。
2. $x + y = y + x$（**交换律**）。
3. $(x + y) + z = x + (y + z)$（**结合律**）。
4. 存在一个元素 $0 \in F$，使得对一切 $x \in F$ 有 $0 + x = x$（**零元**存在）。
5. 对每个 $x \in F$，存在一个「暗示性地」记为 $(-x)$ 的元素，使得 $x + (-x) = 0$（**加法逆元**存在）。

**乘法性质（Multiplicative properties）**：

1. 若 $x, y \in F$，则 $xy \in F$（**乘法封闭**）。
2. $xy = yx$（**交换律**）。
3. $(xy)z = x(yz)$（**结合律**）。
4. 存在一个元素，记为 $1$，使得对一切 $x \in F$ 有 $1 \cdot x = x$（**单位元**存在）。
5. 对每个 $x \in F \setminus \{0\}$，存在一个元素，记为 $\frac{1}{x}$，使得 $x \cdot \frac{1}{x} = 1$（**乘法逆元**存在）。

最后一条公理把加法和乘法「串联」起来：

```math
(x + y) z = x z + y z .
```

这就是**分配律**（distributive law）。

> 译注：公理 (1)–(5) 中，乘法逆元那条特意把 $0$ 排除在外（$F \setminus \{0\}$）——这正是「不能除以 0」的公理化来源。分配律是唯一同时涉及 $+$ 与 $\cdot$ 的公理。

### 5.1 定理：域中的「零」是唯一的

**定理（Theorem）**：任何域中，零元是**唯一**的。

**证明（完整思路）**：

反证/构造法：假设有两个零元，分别记为 $0_1$ 和 $0_2$。

- 因为 $0_1$ 是零元，由加法公理 (4)，对一切 $x$ 有 $0_1 + x = x$。取 $x = 0_2$，得

```math
0_1 + 0_2 = 0_2.
```

- 又因为 $0_2$ 也是零元，同理有 $0_2 + x = x$。取 $x = 0_1$，得

```math
0_2 + 0_1 = 0_1.
```

由加法交换律，$0_1 + 0_2 = 0_2 + 0_1$，于是把上面两式连起来：

```math
0_2 = 0_1 + 0_2 = 0_2 + 0_1 = 0_1.
```

所以 $0_1 = 0_2$，零元唯一。$\square$

> 译注：这个证明的思路极经典——**先假设存在两个候选，再用各自的定义互推，逼它们相等**。它演示了「存在且唯一」类定理的标准证明范式：存在性 + 唯一性（唯一性通常靠「设两个、推出相等」）。

### 5.2 例子

- $\mathbb{Q}$ 是域（Field）。
- $\mathbb{N}$ 和 $\mathbb{Z}$ **不是**域。

> 译注：$\mathbb{N}$ 缺零元和加法逆元；$\mathbb{Z}$ 有零元、有加法逆元，但除 $\pm 1$ 外没有乘法逆元（例如 $2$ 在 $\mathbb{Z}$ 内无逆），故两者都不是域。

## 6. 有序集（Ordered Set）

**定义（Ordered set / 有序集）**：一个 **ordered set** $S$（**有序集**）是一个带有一个关系 $<$ 的集合，满足：

1. 对任意 $x, y \in S$，下列三者**恰有一个**成立：$x < y$，或 $y < x$，或 $x = y$（**三歧性 / trichotomy**）。
2. 若 $x, y, z \in S$ 且 $x < y$、$y < z$，则 $x < z$（**传递性 / transitivity**）。

> 译注：三歧性保证「任何两个元素都能比较且只落一种关系」，这是「线性序（total order / linear order）」的关键。讲义这里只给了 $<$ 的两条性质，未单独列出「自反性/反对称」的变体，但三歧性 + 传递性已足以刻画严格线性序。

## 7. 有序域（Ordered Field）

**定义（Ordered field / 有序域）**：一个 **ordered Field**（**有序域**）是一个有序集，同时也是一个域，并且额外满足下面两条「把运算与序串联起来」的性质：

1. 若 $x < y$，则 $x + z < y + z$（**加法保序**，对任意 $z$）。
2. 若 $x > 0$ 且 $y > 0$，则 $xy > 0$（**正正得正**）。

**例子**：$\mathbb{Q}$ 是一个有序域。

> 译注：这两条是「不等式可以像等式那样运算」的公理化依据——性质 1 允许不等式两边同加一个数；性质 2 保证两个正数相乘仍为正，从而能推出后面「同乘正数不变号」的规则。

### 7.1 定理：同乘正数保持不等式方向

**定理（Theorem）**：若 $x < y$ 且 $z > 0$，则 $x z < y z$。

**证明（完整思路）**：

我们要证 $xz < yz$，等价于证 $yz - xz > 0$。

把后者改写（利用分配律，把 $z$ 提出来）：

```math
yz - xz = (y - x) z.
```

因为 $x < y$，由有序域性质 1（取加法逆元 $-x$，即两边同加 $-x$）可得

```math
y - x > 0.
```

又已知 $z > 0$。于是由有序域性质 2（正正得正），得

```math
(y - x) z > 0,
```

即 $yz - xz > 0$，故 $xz < yz$。$\square$

> 译注：注意证明中「$x < y \Rightarrow y - x > 0$」这一步本身用到了性质 1（令 $z = -x$：$x + (-x) < y + (-x)$，即 $0 < y - x$）。整条证明没有一处「显然」，每一步都落回有序域的两条公理。

## 附：本讲「实分析核心概念」速查

> 本讲尚未正式定义 supremum / infimum / completeness axiom / Archimedean property / Cauchy sequence / limsup / uniform convergence / compactness 等概念，只在开篇以「complete ordered field」埋下伏笔。这些概念将在后续讲义中逐一给出英文原名、中文与可判定定义。本讲已明确的核心概念如下：

- **well-defined（良定义）**：一个依赖「表示法」的定义，若同一对象的任意两种表示代入后得到相同结果，则该定义是良定义的。可判定准则：任取两套相等表示，验证代入运算结果仍相等（见 §4.1 对乘法的验证）。
- **Field（域）**：配备 $+$、$\cdot$ 两运算且满足加法/乘法/分配三组公理的集合（见 §5）。
- **ordered set（有序集）**：带一个满足三歧性与传递性的关系 $<$ 的集合（见 §6）。
- **ordered field（有序域）**：既是域又是有序集，且加法保序、正正得正（见 §7）。
