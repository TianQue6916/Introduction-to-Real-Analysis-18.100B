## 0. 开篇回顾：连续性的定义

> Reminder: A function $f : A \to \mathbb{R}$ on some set $A \subset \mathbb{R}$ is said to be continuous if for all $x_0 \in A$ we have: for all $\epsilon > 0$, there exists a $\delta = \delta(x_0) > 0$ such that if $|x - x_0| < \delta$（$x \in A$），then $|f(x) - f(x_0)| < \epsilon$.

**回顾**：设 $A \subset \mathbb{R}$ 是某个集合，函数 $f : A \to \mathbb{R}$ 称为**连续**（continuous）的，是指对每个 $x_0 \in A$，都有：对任意 $\epsilon > 0$，存在一个 $\delta = \delta(x_0) > 0$（注意这里的 $\delta$ 一般既依赖 $\epsilon$ 也依赖点 $x_0$，所以写成 $\delta(x_0)$），使得当 $|x - x_0| < \delta$（且 $x \in A$）时，就有 $|f(x) - f(x_0)| < \epsilon$。

**译注**：这是逐点连续（pointwise continuity）的 $\epsilon$-$\delta$ 定义。核心思想是「自变量的误差控制在 $\delta$ 以内，函数值的误差就能控制在 $\epsilon$ 以内」。这里的 $\delta(x_0)$ 记号强调 $\delta$ 通常随点而变；若对某个区间上所有点能取到**同一个** $\delta$ 只依赖 $\epsilon$，那就升级成了后面会学的一致连续（uniform continuity）。

## 1. 关于连续函数的两个定理

### 1.1 极值定理（Extreme Value Theorem）

> **Extreme Value Theorem**: Suppose that $f : [a, b] \to \mathbb{R}$ is a continuous function, then there exist $x_M \in [a, b]$ such that $f(x_M) \ge f(x)$ for all $x \in [a, b]$. Similarly, there exists $x_m \in [a, b]$ such that $f(x_m) \le f(x)$ for all $x \in [a, b]$.

**极值定理（Extreme Value Theorem，EVT）**：设 $f : [a, b] \to \mathbb{R}$ 是闭区间 $[a,b]$ 上的连续函数，则存在 $x_M \in [a, b]$，使得对一切 $x \in [a, b]$ 都有 $f(x_M) \ge f(x)$（即 $x_M$ 处取得最大值）；同理，存在 $x_m \in [a, b]$，使得对一切 $x$ 都有 $f(x_m) \le f(x)$（即 $x_m$ 处取得最小值）。

**译注**：这条定理说的是——**闭区间**上的连续函数一定同时取到最大值和最小值。两个条件缺一不可：区间必须是「闭」的（$[a,b]$ 含端点），函数必须是「连续」的。若换成开区间 $(a,b)$，例如 $f(x)=x$ 在 $(0,1)$ 上就既无最大也无最小。

### 1.2 介值定理（Intermediate Value Theorem）

> **Intermediate Value Theorem**: Suppose that $f : [a, b] \to \mathbb{R}$ is a continuous function, then for all $y$ between $f(a)$ and $f(b)$, there exists $x \in [a, b]$ such that $f(x) = y$.

**介值定理（Intermediate Value Theorem，IVT）**：设 $f : [a, b] \to \mathbb{R}$ 连续，则对任意介于 $f(a)$ 与 $f(b)$ 之间的值 $y$，都存在 $x \in [a, b]$，使得 $f(x) = y$。

**译注**：直觉是——连续函数的图像是「连成一片」的曲线，所以从高度 $f(a)$ 爬到高度 $f(b)$ 的过程中，中间每一个高度都必然被经过。这条定理是「连续」的几何本质体现。

## 2. 桥梁引理：序列与连续函数的关系

为了证明上面两条定理，讲义先建立一个连接「序列收敛」与「函数连续」的引理。

> **Lemma**: Suppose that $f : [a, b] \to \mathbb{R}$ is a continuous function and $x_n \to x_\infty$ a sequence, then $f(x_n) \to f(x_\infty)$. We can also write this as
>
> ```math
> \lim_{n\to\infty} f(x_n) = f\Big(\lim_{n\to\infty} x_n\Big).
> ```

**引理（序列连续性引理）**：设 $f : [a, b] \to \mathbb{R}$ 连续，$x_n \to x_\infty$ 是一个收敛序列，则 $f(x_n) \to f(x_\infty)$。也可写作

```math
\lim_{n\to\infty} f(x_n) = f\Big(\lim_{n\to\infty} x_n\Big).
```

**译注**：这条引理给出了「连续」与「序列」之间的等价刻画——**连续函数可以「穿过」极限号**：先取极限再代入函数，等于先代入函数再取极限。这是后面把「逐点连续」推广到「序列语言」的关键，也是度量空间里连续性的桥梁。

### 2.1 引理证明

**Proof（证明）**：要证 $f(x_n) \to f(x_\infty)$。任给 $\epsilon > 0$。

- 因为 $f$ 在 $x_\infty$ 处连续，故存在 $\delta > 0$，使得当 $|x - x_\infty| < \delta$ 时，$|f(x) - f(x_\infty)| < \epsilon$。
- 又因为 $x_n \to x_\infty$，故对这个 $\delta > 0$，存在 $N$，使得当 $n \ge N$ 时，$|x_n - x_\infty| < \delta$。
- 于是当 $n \ge N$ 时，把 $x = x_n$ 代入连续性的结论，即得 $|f(x_n) - f(x_\infty)| < \epsilon$。

这就证明了 $f(x_n) \to f(x_\infty)$。$\Box$

**译注（选法说明）**：这是一次典型的「两段接力」论证。$\epsilon > 0$ 是「目标精度」；先用连续性**由 $\epsilon$ 找到 $\delta$**（$\delta$ 由连续性给出，具体取值依赖函数，无法统一写出）；再用 $x_n$ 收敛**由 $\delta$ 找到 $N$**。两段拼起来：$n \ge N \Rightarrow |x_n - x_\infty| < \delta \Rightarrow |f(x_n)-f(x_\infty)| < \epsilon$。逻辑链条每一步都有明确依据，没有跳步。

## 3. 用引理证明极值定理

> **Proof (of EVT)**: Let $E = f([a, b])$ and set $M = \sup E$. We will show that $M < \infty$ and that $M = f(x)$ for some $x \in [a, b]$.

**极值定理的证明**：记 $E = f([a,b])$ 为函数的值域（range），并令 $M = \sup E$（值域的上确界）。我们要证明两件事：① $M < \infty$（值域有上界）；② 存在某个 $x \in [a,b]$ 使 $M = f(x)$（上确界能被取到）。

**译注**：**上确界**（supremum，记 $\sup E$）是集合 $E$ 的「最小上界」——即 $M$ 是 $E$ 的一个上界（对所有 $y \in E$ 有 $y \le M$），且任何比 $M$ 小的数都不是 $E$ 的上界（即 $\forall \epsilon>0$，存在 $y\in E$ 使 $y > M-\epsilon$）。它与「最大值」的区别在于：上确界**一定存在**（只要 $E$ 有上界，这是实数的完备性公理保证的），但未必属于 $E$ 本身；只有当 $M \in E$ 时才成为最大值。EVT 的核心正是要证明 $M \in E$。

### 3.1 第一步：证明 $M < \infty$（值域有上界）

先证 $M$ 有限。反证法：假设 $M = \infty$（即值域无上界），则对每个 $n$，都存在 $x_n \in [a,b]$ 使得 $f(x_n) > n$（即函数值能任意大）。

- 序列 $\{x_n\}$ 有界（因为都落在 $[a,b]$ 内），由 **Bolzano–Weierstrass 定理**（有界数列必有收敛子列），它有一个收敛子列，记为 $x_{n_k}$。
- 设 $x_{n_k} \to x_\infty \in [a,b]$（闭区间保证了极限点仍落在区间内）。
- 由上面的引理，$f(x_{n_k}) \to f(x_\infty)$。但按构造 $f(x_{n_k}) > n_k$，即 $f(x_{n_k})$ 无界，这与「收敛序列必有界」矛盾。

故 $M < \infty$，值域有上界。

**译注（选法与关键点）**：反证法中的「$f(x_n) > n$」是典型的「无界」构造——它保证子列 $f(x_{n_k}) \to +\infty$。而收敛序列一定是有界的（这是之前讲过的结论），于是产生矛盾。这里 **Bolzano–Weierstrass 定理**（每个有界实数列都有一个收敛子列）是决定性工具，它本质上是闭区间「列紧」性质的体现。

### 3.2 第二步：证明 $M$ 能被取到

现在对每个整数 $n$，由 $M = \sup E$ 的上确界性质，可选取 $x_n \in [a,b]$，使得 $f(x_n) > M - \frac{1}{n}$（上确界定义保证：比 $M$ 小 $\frac{1}{n}$ 的数都还不是上界，所以能取到这样的函数值）。

- 序列 $\{x_n\}$ 有界，再由 **Bolzano–Weierstrass 定理**，有收敛子列 $x_{n_k} \to x_\infty \in [a,b]$。
- 由引理，$f(x_{n_k}) \to f(x_\infty)$，且由 $f(x_{n_k}) > M - \frac{1}{n_k}$ 两边取极限得 $f(x_\infty) \ge M$。
- 但另一方面，$M$ 是值域的上确界，故 $f(x_\infty) \le M$。
- 综上 $f(x_\infty) = M$。

这就证明了 EVT。$\Box$

**译注（选法说明）**：$\epsilon = \frac{1}{n}$ 的选取是「逼近上确界」的标准手法：让函数值不断逼近 $M$，再借收敛子列把「逼近」升级为「达到」。两边的夹逼（$f(x_\infty) \ge M$ 又 $\le M$）正是上确界「最小上界」与「上界」两个身份的同时使用。最大值的证明完全对称，只需对 $-f$ 应用已证结论即可。

## 4. 用引理证明介值定理

> **Proof (of IVT)**: We will assume that $f(a) < 0 < f(b)$ and show that there exists $x \in [a, b]$ such that $f(x) = 0$. The general case is similar.

**介值定理的证明**：我们只证特殊情形 $f(a) < 0 < f(b)$，证明存在 $x \in [a,b]$ 使 $f(x) = 0$。一般情形（任意介于 $f(a)$ 与 $f(b)$ 之间的 $y$）只需考虑辅助函数 $g(x) = f(x) - y$ 即可化归到此情形。

**译注（化归）**：要证任意中间值 $y$ 都能取到，只需令 $g(x) = f(x) - y$，则 $g(a) = f(a) - y < 0$，$g(b) = f(b) - y > 0$，问题等价于求 $g$ 的零点。所以只需证明「异号两端点必有零点」这一特殊形式。

### 4.1 构造集合 $A$ 并取上确界

定义集合 $A = \{ y : \text{对所有 } x \le y \text{ 都有 } f(x) \le 0 \}$，即「$y$ 左侧（含 $y$）函数值都不超过 $0$」的那些位置。

- 因为 $f(a) < 0 \le 0$，故 $a \in A$，所以 $A$ 非空（non-empty）。
- 令 $M = \sup A$（$A$ 的上确界）。
- 取序列 $x_n$ 满足 $x_n < M$ 且 $x_n \to M$（这样的序列存在，因为 $M$ 是 $A$ 的最小上界，可以从左侧逼近它）。

### 4.2 证明 $f(M) \le 0$，再排除 $f(M) < 0$

- 由 $x_n < M$ 且 $x_n \to M$，以及 $A$ 的定义，可知 $f(x_n) \le 0$。
- 由前面的引理（连续性），$f(x_n) \to f(M)$。
- 因为「非正序列」的极限也非正（取极限保持 $\le 0$），故 $f(M) \le 0$。

如果 $f(M) = 0$，命题已证，结束。下面假设 $f(M) < 0$，推出矛盾：

- 由于 $f(M) < 0$ 而 $f(b) > 0$，必有 $M < b$。
- 又因 $f$ 在 $M$ 处连续，且 $f(M) < 0$，由连续性（取 $\epsilon$ 足够小，例如 $\epsilon = \frac{|f(M)|}{2}$，则存在 $\delta > 0$），存在一个包含 $M$ 的整段区间 $(M-\delta, M+\delta)$，在其上处处 $f < 0$。
- 于是存在 $M' > M$（取在 $M$ 右侧那段区间内）使得所有 $x \le M'$ 都有 $f(x) \le 0$，即 $M' \in A$。
- 这与 $M$ 是 $A$ 的上确界（$M$ 已是 $A$ 的最小上界，不可能有更大的元素属于 $A$）矛盾。

故假设 $f(M) < 0$ 不成立，只能 $f(M) = 0$。IVT 得证。$\Box$

**译注（思路梳理）**：IVT 的证明是「上确界法」的典范。思路分三层：
1. **定义好集合**：$A$ 是「函数值仍 $\le 0$」的临界位置集合，$M = \sup A$ 是「从负到正」的分水岭。
2. **用连续性夹出 $f(M) \le 0$**：左侧逼近 $M$ 的点都在 $A$ 里，函数值 $\le 0$，连续性把它传到极限点 $M$。
3. **用连续性排除 $f(M) < 0$**：若 $f(M) < 0$，连续性能保证 $M$ 右侧一小段仍为负，说明 $M$ 还不是「最靠右」的临界点，与上确界身份矛盾。

唯一可能剩下的就是 $f(M) = 0$，零点存在。整个论证没有用到「显然」，每一步都落实到连续性或上确界定义。

## 5. 度量空间（Metric Space）

讲义从这里开始抽象：把「距离」的概念一般化。

> **Definition: Metric space.** A metric space is a set $X$ with a function $d : X \times X \to \mathbb{R}$ with the following three properties:
>
> (1) $d(x, y) \ge 0$ for all $x, y \in X$ and $d(x, y) = 0$ if and only if $x = y$. (Distances $\ge 0$.)
>
> (2) $d(x, y) = d(y, x)$. (Symmetric.)
>
> (3) $d(x, z) \le d(x, y) + d(y, z)$. (Triangle inequality.)

**定义：度量空间（metric space）**。一个度量空间由一个集合 $X$ 和一个函数 $d : X \times X \to \mathbb{R}$（称为**度量**或**距离函数**，metric/distance）组成，它满足以下三条性质：

1. **正定性（positivity）**：对所有 $x, y \in X$，$d(x, y) \ge 0$，且 $d(x, y) = 0$ 当且仅当 $x = y$。（距离非负，且「距离为零」等价于「两点重合」。）
2. **对称性（symmetry）**：$d(x, y) = d(y, x)$。（两点间距离与方向无关。）
3. **三角不等式（triangle inequality）**：$d(x, z) \le d(x, y) + d(y, z)$。（绕道第三方不更近。）

**译注**：度量空间把「距离」抽象成满足这三条公理的函数，从而把实数轴上的分析（极限、连续、收敛）推广到任意集合。它不要求 $X$ 上有加法、乘法或序——所以下面会强调，实数上依赖代数或序的那些定理（夹逼、单调收敛）在一般度量空间里不再成立，而只依赖「距离」的结论（Cauchy、Bolzano–Weierstrass）依然有意义。

### 5.1 度量空间的例子

**例 1（实数轴）**：$X = \mathbb{R}$，$d(x, y) = |x - y|$。

**例 2（平面）**：$X = \mathbb{R}^2$，对 $x = (x_1, x_2)$、$y = (y_1, y_2)$，

```math
d(x, y) = \sqrt{|x_1 - y_1|^2 + |x_2 - y_2|^2}.
```

**例 3（空间）**：$X = \mathbb{R}^3$，对 $x = (x_1, x_2, x_3)$、$y = (y_1, y_2, y_3)$，

```math
d(x, y) = \sqrt{|x_1 - y_1|^2 + |x_2 - y_2|^2 + |x_3 - y_3|^2}.
```

**译注**：例 2、例 3 就是通常的**欧氏距离**（Euclidean distance），是勾股定理在高维的直接推广。例 1 是 $\mathbb{R}^n$ 在 $n=1$ 的特例。

**例 4（连续函数空间）**：令 $X = C([a,b])$，即 $[a,b]$ 上全体连续函数的集合。两个连续函数 $f$ 与 $g$ 之间的距离定义为

```math
d(f, g) = \max_{x \in [a,b]} |f(x) - g(x)|.
```

由于 $f - g$ 也是连续函数，EVT 保证这个最大值确实在某个 $x \in [a,b]$ 处被取到。

**译注**：这个例子极重要——它把「函数」本身当成「点」，用两个函数图像的最大纵向差距来度量它们「相距多远」。这种度量叫**上确界度量**或**一致度量**（uniform/sup metric），是后面一致收敛（uniform convergence）与解 ODE 的基础。EVT 在这里的作用是保证 $\max$（而非仅 $\sup$）确实取到。

### 5.2 度量空间的作用

> Metric spaces play the role of generalised real numbers. A lot of the discussion that we have had in the class holds also for metric spaces and this is useful in many circumstances. For instance, we will see in a later class that we can use it to solve ODEs.

**度量空间扮演「广义实数」的角色**。我们在课上讨论过的许多内容对度量空间也成立，这在很多情形下很有用。例如，后面课程会看到可以用它来解常微分方程（ODE）。

## 6. 度量空间中的序列

> **Sequences in a metric space**: A sequence in a metric space $(X, d)$ is a map $f : \mathbb{N} \to X$. We typically denote the image $f(n)$ by $x_n$.

**度量空间中的序列**：度量空间 $(X,d)$ 中的序列是一个映射 $f : \mathbb{N} \to X$（即从自然数集到 $X$ 的函数）。通常把 $f(n)$ 记为 $x_n$。

> Similarly we define a subsequence as the composition of a strictly increasing map $g : \mathbb{N} \to \mathbb{N}$ with $f$ and $x_{n_k} = f(g(k))$.

**子列（subsequence）**：类似地，把一个严格递增的映射 $g : \mathbb{N} \to \mathbb{N}$ 与 $f$ 复合，就得到子列，记 $x_{n_k} = f(g(k))$。

**译注**：这里把序列、子列都统一成「映射」的语言：序列是 $\mathbb{N} \to X$ 的映射，子列则是先经过一个**严格递增**的重新编号 $g$ 再复合。严格递增保证了子列保持原顺序且下标单调上升（$n_1 < n_2 < \cdots$）。

### 6.1 什么能推广、什么不能

> It is not all results that we know from $\mathbb{R}$ that generalises to general metric spaces. For instance, in general there are no algebraic properties, no squeeze theorem, no monotone convergence theorem.

并不是我们从 $\mathbb{R}$ 上知道的所有结论都能推广到一般度量空间。例如，一般度量空间里**没有代数运算**，**没有夹逼定理（squeeze theorem）**，**没有单调收敛定理（monotone convergence theorem）**。

> On the other hand the statement of both the Cauchy convergence theorem and the Bolzano–Weierstrass theorems makes sense in a general metric space.

另一方面，**Cauchy 收敛定理**和 **Bolzano–Weierstrass 定理**的表述在一般度量空间中仍有意义。

**译注**：这个对比很关键，它刻画了「什么依赖 $\mathbb{R}$ 的特殊结构、什么只依赖距离」：
- **夹逼定理**依赖 $\le$（序），**单调收敛**依赖「单调」+ 上确界（序 + 完备性公理），这些在只有「距离」的度量空间里没有意义。
- **Cauchy 序列**和**有界序列**只依赖「距离」的概念，因此可以原样搬过来。

### 6.2 更多例子

**例 5（Box 距离 / 曼哈顿距离）**：空间是 $X = \mathbb{R}^2$，若 $x = (x_1, x_2)$、$y = (y_1, y_2)$，则

```math
d(x, y) = |x_1 - y_1| + |x_2 - y_2|.
```

**译注**：这是**曼哈顿距离**（taxicab/Manhattan distance，也叫 $L^1$ 距离），像在城市方格街区里只能横竖走。它满足度量三公理，但几何形状与欧氏距离完全不同（例如「圆」是菱形）。

**例 6（整数上的奇怪度量）**：空间是 $X = \mathbb{N}$，若 $m, n$ 是整数，则

```math
d(m, n) = \left| \frac{1}{n} - \frac{1}{m} \right|.
```

**译注**：这个度量把「自然数」按 $\frac{1}{n}$ 的差异来量距离。注意 $n$ 越大，$\frac{1}{n}$ 越小、彼此越近，所以在这个度量下自然数「向 $\infty$ 挤在一起」——这是一个与直观很不相同的例子，用来展示「距离」可以非常任意，只要满足三条公理。

**例 7（法国铁路度量 / French railway metric）**：空间是 $X = \mathbb{R}^2$，若 $x = (x_1, x_2)$、$y = (y_1, y_2)$，则

```math
d(x, y) =
\begin{cases}
|x - y|, & \text{若 } x = cy \text{ 或 } y = cx \text{（对某个 } c \in \mathbb{R} \text{）}, \\
|x| + |y|, & \text{其他情形}.
\end{cases}
```

其中 $|x - y| = \sqrt{(x_1-y_1)^2 + (x_2-y_2)^2}$，$|x|$、$|y|$ 同理。

**译注**：这个「狂野」例子很有名。它的几何含义是：像法国铁路网一样，任何两点若不与原点共线（即不在同一条过原点的直线上），就必须先走到原点再折返，距离等于两者到原点距离之和。它满足度量三公理（正定、对称、三角不等式都需验证），但极不「欧氏」。这类例子用来提醒我们：度量的抽象定义允许很多「反直觉」的距离。

## 7. 度量空间中的收敛

> **Definition: Convergent sequence in a metric space.** If $(X, d)$ is a metric space and $x_n$ is a sequence in $X$, then we say that $x_n$ converges to $x$ and write $x_n \to x$ or $x = \lim_{n\to\infty} x_n$ if for all $\epsilon > 0$, there exists an $N$ such that if $n \ge N$, then $d(x, x_n) < \epsilon$.

**定义：度量空间中的收敛序列（convergent sequence）**。若 $(X,d)$ 是度量空间，$x_n$ 是 $X$ 中的序列，则称 $x_n$ 收敛到 $x$，记 $x_n \to x$ 或 $x = \lim_{n\to\infty} x_n$，是指：对任意 $\epsilon > 0$，存在 $N$，使得当 $n \ge N$ 时，$d(x, x_n) < \epsilon$。

> This is equivalent to that the sequence $d(x_n, x_\infty) \to 0$.

这等价于说，实数列 $d(x_n, x_\infty) \to 0$。

**译注**：收敛的定义和实数情形完全平行，只是把「$|x_n - x|$」换成了「$d(x_n, x)$」。最后的等价说法很有用——它把「度量空间里的收敛」翻译成「一个实数列收敛到 $0$」，于是可以借用实数上已有的工具。注意原文这里记号为 $x_\infty$，与前面的 $x$ 同义。

## 8. 度量空间中的 Cauchy 序列

> **Definition: Cauchy sequence in a metric space.** If $(X, d)$ is a metric space and $x_n$ is a sequence in $X$, then we say that $x_n$ is a Cauchy sequence if for all $\epsilon > 0$, there exists an $N$, such that if $m, n \ge N$, then $d(x_m, x_n) < \epsilon$.

**定义：度量空间中的 Cauchy 序列（Cauchy sequence）**。若 $(X,d)$ 是度量空间，$x_n$ 是 $X$ 中的序列，则称 $x_n$ 是 **Cauchy 序列**，是指：对任意 $\epsilon > 0$，存在 $N$，使得当 $m, n \ge N$ 时，$d(x_m, x_n) < \epsilon$。

**译注（可判定定义）**：**Cauchy 序列**是「项与项之间越来越近」的序列——即只要下标 $m,n$ 都足够大（$\ge N$），$x_m$ 与 $x_n$ 的距离就能小于任意指定的 $\epsilon$。它与「收敛」的关键区别是：收敛要求序列「逼近某个具体的极限点 $x$」，而 Cauchy 只要求「序列内部的项彼此逼近」，**不预先指定极限是什么**。直觉上 Cauchy 序列「像是会收敛」，但极限点是否仍在空间 $X$ 内，是另一回事（见下文完备性）。

---

## 9. 收敛蕴含 Cauchy（定理）

> **Theorem**: In any metric space $(X, d)$ a convergent sequence is also a Cauchy sequence.

**定理**：在任何度量空间 $(X,d)$ 中，收敛序列必是 Cauchy 序列。

### 9.1 证明

**Proof（证明）**：设 $x_n \in X$ 是序列且 $x_n \to x$。任给 $\epsilon > 0$。

- 由收敛定义，存在 $N$，使得当 $n \ge N$ 时，$d(x, x_n) < \frac{\epsilon}{2}$。
- 若 $m, n \ge N$，由三角不等式：

```math
d(x_m, x_n) \le d(x_m, x) + d(x, x_n) < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon.
```

所以 $x_n$ 是 Cauchy 序列。$\Box$

**译注（选法说明）**：这里 $\frac{\epsilon}{2}$ 的选取是关键技巧——为了让三角不等式后得到精确的 $\epsilon$，把「收敛精度」预先取成 $\frac{\epsilon}{2}$，两个 $\frac{\epsilon}{2}$ 相加恰好凑成 $\epsilon$。这是 $\epsilon$-论证里最常见的「预留一半」手法：把目标 $\epsilon$ 拆成两份分配给两个中间步骤。三角不等式扮演了「从 $x_m$ 到 $x_n$ 绕道极限点 $x$」的桥梁。

### 9.2 逆命题不成立：Cauchy 不必然收敛

> The converse is not always the case: If $X = (0, 1) \subset \mathbb{R}$ with $d(x, y) = |x - y|$, then the sequence $x_n = \frac{1}{n}$ is a Cauchy sequence but since $0$ is not in $X$, it is not convergent. We sometimes express this by saying that in this case $X$ is not Cauchy complete.

**逆命题未必成立**：取 $X = (0,1) \subset \mathbb{R}$，$d(x,y) = |x-y|$，则序列 $x_n = \frac{1}{n}$ 是 Cauchy 序列，但因为极限 $0$ 不在 $X$ 内，它不收敛。我们有时把这种情形说成「$X$ 不是 Cauchy 完备的（not Cauchy complete）」。

**译注**：这个反例直击要害——$x_n = \frac{1}{n}$ 在开区间 $(0,1)$ 里，项与项确实越来越近（Cauchy），但它「想」收敛到的点 $0$ 被挖掉了（不在 $X$ 里），所以在 $X$ 内部没有极限。这引出**完备性（completeness）**的概念：一个度量空间若其中每个 Cauchy 序列都收敛（到 $X$ 内的点），就称它是**完备**的。$\mathbb{R}$ 是完备的，而 $(0,1)$ 不完备——区别就在于「极限点是否都包含在空间里」。

---

## 10. 度量空间上的连续函数

> **Definition: Continuous function on a metric space $(X, d)$.** Suppose that $F : X \to \mathbb{R}$ is a function. We say that $f$ is continuous at $x_0 \in X$, if for all $\epsilon > 0$, there exists a $\delta > 0$, such that if $x \in X$ with $d(x, x_0) < \delta$, then $|F(x) - F(x_0)| < \epsilon$.

**定义：度量空间 $(X,d)$ 上的连续函数**。设 $F : X \to \mathbb{R}$ 是函数。称 $F$ 在 $x_0 \in X$ 处连续，是指：对任意 $\epsilon > 0$，存在 $\delta > 0$，使得当 $x \in X$ 且 $d(x, x_0) < \delta$ 时，$|F(x) - F(x_0)| < \epsilon$。

**译注**：连续性的 $\epsilon$-$\delta$ 定义照搬过来，只是自变量的「距离」由 $|x - x_0|$ 换成 $d(x, x_0)$（定义域用度量），函数值仍在 $\mathbb{R}$ 中所以仍用绝对值 $|F(x)-F(x_0)|$。注意原文定义与证明中记号 $F$ / $f$ 混用，均指同一函数，〔原书此处大小写不统一，属笔误，不影响理解〕。

**例**：再取 $X = C([0,1])$，即 $[0,1]$ 上连续函数的集合，配上前面定义的距离 $d(f,g) = \max_{x \in [0,1]} |f(x) - g(x)|$。定义 $X$ 上的函数 $F(f) = f(0)$（即 $F$ 把函数 $f$ 映到它在 $0$ 点的取值）。容易验证 $F$ 是度量空间 $X$ 上的连续函数。

**译注**：这个例子展示了「以函数为点」的空间上如何谈连续性——$F$ 是「取值泛函」（evaluation functional，把函数映射到某一点的函数值）。验证其连续性只需注意 $|F(f) - F(g)| = |f(0) - g(0)| \le \max_{x \in [0,1]} |f(x) - g(x)| = d(f,g)$，故取 $\delta = \epsilon$ 即可。这正说明「上确界度量」很强：两点（函数）距离一旦小，它们在每一点的取值都小。

## 11. 序列连续性引理（度量空间版）

> **Lemma**: Let $(X, d)$ be a general metric space. Suppose that $f : X \to \mathbb{R}$ is a continuous function and $x_n$ is a sequence in $X$ with $x_n \to x_\infty$, then $f(x_n) \to f(x_\infty)$.

**引理（度量空间版）**：设 $(X,d)$ 是一般度量空间，$f : X \to \mathbb{R}$ 连续，$x_n$ 是 $X$ 中的序列且 $x_n \to x_\infty$，则 $f(x_n) \to f(x_\infty)$。

### 11.1 证明

**Proof（证明）**：要证 $f(x_n) \to f(x_\infty)$，任给 $\epsilon > 0$。

- 因为 $f$ 在 $x_\infty$ 连续，存在 $\delta > 0$，使得当 $d(x, x_\infty) < \delta$ 时，$|f(x) - f(x_\infty)| < \epsilon$。
- 因为 $x_n \to x_\infty$，存在 $N$，使得当 $n \ge N$ 时，$d(x_n, x_\infty) < \delta$。
- 于是当 $n \ge N$ 时，$|f(x_n) - f(x_\infty)| < \epsilon$。

引理得证。$\Box$

**译注**：与第 2 节的引理证明逐字平行，只是把 $|x - x_\infty|$ 换成 $d(x, x_\infty)$。这印证了讲义的中心思想——**凡只依赖「距离」的结论都能原封不动推广到度量空间**，连续函数「穿过极限号」这一性质在度量空间里依然成立。
