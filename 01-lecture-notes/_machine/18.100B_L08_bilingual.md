## 1. 级数的基本概念（Series）

假设 $a_n$ 是一个序列（sequence），我们可以据此构造一个新的序列 $s_n$。令

```math
s_1 = a_1,
```

```math
s_2 = a_1 + a_2,
```

```math
s_3 = a_1 + a_2 + a_3,
```

一般地，令

```math
s_n = a_1 + \cdots + a_n = \sum_{i=1}^{n} a_i.
```

一个级数（series）$\sum_{i=1}^{\infty} a_i$ 收敛（converges），当且仅当序列 $s_n$ 收敛；若它收敛，我们也用 $\sum_{i=1}^{\infty} a_i$ 来表示这个极限值。

> **译注（部分和的框架）**：级数本质上就是一个「部分和（partial sums）」序列 $s_n$ 的收敛问题。把无穷多项相加是否「有意义」，归结为有限部分和 $s_n$ 是否有极限。这是整讲的主线：判断级数收敛 = 判断部分和序列 $s_n$ 收敛。

### 几何级数（Geometric series）

```math
\sum_{i=0}^{\infty} c^{i}.
```

当且仅当 $|c| < 1$ 时收敛。

> **译注**：部分和 $s_n = \frac{1-c^{n+1}}{1-c}$（$c\ne 1$）。当 $|c|<1$ 时 $c^{n+1}\to 0$，故 $s_n \to \frac{1}{1-c}$；当 $|c|\ge 1$ 时 $c^{n}$ 不趋于 $0$，故发散。

### 调和级数（Harmonic series）

```math
\sum_{i=1}^{\infty} \frac{1}{n}.
```

此级数发散。

> **译注**：经典证法是把各项按「块」分组：$1 + \frac12 + (\frac13+\frac14) + (\frac15+\cdots+\frac18) + \cdots$，每块的和 $\ge \frac12$，故部分和可任意大，发散。注意 $\frac1n \to 0$，但「通项趋于 0」只是收敛的**必要**条件而非充分条件——调和级数就是反例。

## 2. 绝对收敛（Absolutely convergent）

若级数 $\sum_{n=0}^{\infty} |a_n|$ 收敛，则称级数 $\sum_{n=0}^{\infty} a_n$ 绝对收敛（absolutely convergent）。绝对收敛蕴含（implies）收敛，但反之不成立。

> **译注**：绝对收敛 $\Rightarrow$ 收敛，其证明思路是：对每个 $n$，$a_n \le |a_n|$ 且 $-a_n \le |a_n|$，即 $0 \le a_n + |a_n| \le 2|a_n|$，所以 $\sum (a_n + |a_n|)$ 由比较判别法（下见）收敛；而 $a_n = (a_n+|a_n|) - |a_n|$ 是两个收敛级数之差，故 $\sum a_n$ 收敛。
>
> 反例（收敛但不绝对收敛）：交错调和级数 $\sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n}$ 收敛到 $\ln 2$，但 $\sum \frac1n$ 发散。

## 3. 非负项级数的收敛判据（基本定理）

**定理**：一个非负项级数 $a_i \ge 0$ 的级数 $\sum_{i=0}^{\infty} a_i$ 收敛，当且仅当（if and only if）其部分和序列 $s_n$ 上有界（bounded from above）。

> **译注**：因为 $a_i \ge 0$，部分和 $s_n = s_{n-1} + a_n \ge s_{n-1}$ 是单调不减序列（monotone nondecreasing）。单调不减序列收敛当且仅当它上有界（这是实数的完备性公理 / completeness axiom 的推论）。所以「部分和 $s_n$ 上有界」就是非负项级数收敛的充要条件。此定理是下面所有判别法的根基。
>
> **核心概念定义**：
> - **supremum（上确界）**：集合 $S$ 的上确界 $\sup S$ 是 $S$ 的最小上界，即它 $\ge S$ 中每个元素，且任何比它小的数都不能作为 $S$ 的上界。
> - **infimum（下确界）**：集合 $S$ 的下确界 $\inf S$ 是 $S$ 的最大下界。
> - **completeness axiom（完备性公理）**：任何非空、上有界的实数集必有上确界。这是实数系区别于有理数系的根本性质，也是「单调有界必收敛」的来源。
> - **Archimedean property（阿基米德性质）**：对任意正实数 $x,y$，存在正整数 $n$ 使 $nx > y$。等价地，不存在「无穷大」或「无穷小」的实数。
> - **Cauchy sequence（柯西序列）**：序列 $a_n$ 满足「$\forall \varepsilon>0,\ \exists N,\ m,n\ge N \Rightarrow |a_m-a_n|<\varepsilon$」。实数完备性保证：实数上的柯西序列必收敛。
> - **limsup（上极限）**：见后文第 6 节。
> - **uniform convergence（一致收敛）**：本讲未直接使用，指函数序列/级数「对全体 $x$ 用同一个 $N$」收敛，比逐点收敛更强。
> - **compactness（紧性）**：本讲未直接使用，指集合「闭且有界」或「任一开覆盖有有限子覆盖」的性质。

为了帮助判断级数是否收敛，有若干判别法（tests）：

- 比较判别法（Comparison test）。
- 比值判别法（Ratio test）。
- 根值判别法（Root test）。
- 其他判别法（之后讨论）。

## 4. 比较判别法（Comparison test）

### 版本一（直接比较）

设 $a_n$ 与 $b_n$ 是两个满足 $0 \le a_n \le b_n$ 的序列。若 $\sum_{n=1}^{\infty} b_n$ 收敛，则 $\sum_{n=1}^{\infty} a_n$ 也收敛。

> **译注（证明思路）**：设 $A_n=\sum_{k=1}^n a_k$、$B_n=\sum_{k=1}^n b_k$ 为部分和。因 $0\le a_k\le b_k$，故 $0\le A_n \le B_n$。$b_n$ 的级数收敛 $\Rightarrow$ $B_n$ 上有界 $\Rightarrow$ $A_n$ 上有界；又 $A_n$ 单调不减，由第 3 节定理，$\sum a_n$ 收敛。

**例**：级数

```math
\sum_{n=1}^{\infty} \frac{2^{-n}}{n}
```

收敛。设 $a_n = \frac{2^{-n}}{n}$，$b_n = 2^{-n}$，则 $0 \le a_n \le b_n$；又 $\sum_{n=1}^{\infty} b_n$ 是公比 $c = \frac12 < 1$ 的几何级数，收敛，故由比较判别法 $\sum_{n=1}^{\infty} a_n$ 收敛。

> **译注**：这里利用了 $\frac{1}{n}\le 1$（对 $n\ge 1$），从而 $a_n = 2^{-n}\cdot\frac1n \le 2^{-n} = b_n$。

### 版本二（极限比较）

设 $a_n$、$b_n$ 是两个序列，$b_n \ne 0$，且

```math
\lim_{n\to\infty} \frac{a_n}{b_n} = L \ne 0.
```

则级数 $\sum_{n=1}^{\infty} a_n$ 收敛，当且仅当 $\sum_{n=1}^{\infty} b_n$ 收敛。

> **译注（证明思路）**：由极限 $\frac{a_n}{b_n}\to L>0$，取 $\varepsilon = \frac{L}{2}$，存在 $N$ 使当 $n\ge N$ 时有 $\frac{L}{2} < \frac{a_n}{b_n} < \frac{3L}{2}$，即 $\frac{L}{2} b_n < a_n < \frac{3L}{2} b_n$（此处默认 $a_n,b_n\ge 0$）。于是 $a_n$ 与 $b_n$ 的级数相互「只差常数倍」，据版本一（直接比较）双向成立，故两者同收敛或同发散。
>
> 〔原书此处公式有损，$b_n$ 的符号与收敛条件依赖非负假设，上文按标准陈述补出 $\frac{L}{2},\frac{3L}{2}$ 的具体夹逼，待核。〕

**例**：级数 $\sum_{n=2}^{\infty} \frac{1}{n^2-1}$ 收敛，因为

```math
\frac{n^2}{n^2-1} \to 1,
```

且级数 $\sum_{n=2}^{\infty} \frac{1}{n^2}$ 收敛。

> **译注**：这里用 $b_n = \frac{1}{n^2}$，$\frac{a_n}{b_n} = \frac{1/(n^2-1)}{1/n^2} = \frac{n^2}{n^2-1}\to 1 = L \ne 0$。而 $\sum \frac{1}{n^2}$ 是 $p$-级数（$p=2>1$）收敛，故由极限比较判别法原级数收敛。

## 5. 比值判别法（Ratio test）

设 $a_n \ge 0$，且假设

```math
\frac{a_{n+1}}{a_n} \to a.
```

- 若 $a < 1$，则级数 $\sum a_n$ 收敛。
- 若 $a > 1$，则级数 $\sum a_n$ 发散。
- 若 $a = 1$，则判别法失效（inconclusive）。

> **译注（证明思路）**：
> - $a<1$：取 $r_0$ 使 $a < r_0 < 1$。由 $\frac{a_{n+1}}{a_n}\to a$，取 $\varepsilon = r_0-a$，存在 $N$ 使当 $n\ge N$ 时 $\frac{a_{n+1}}{a_n} \le r_0$。于是对 $n\ge N$，$a_{n+1} \le r_0 a_n$，递推得 $a_{N+k} \le r_0^{k} a_N$。故从第 $N$ 项起被收敛的几何级数 $\sum r_0^k$（$r_0<1$）控制，由比较判别法收敛。
> - $a>1$：取 $r_0$ 使 $1 < r_0 < a$，同理得 $n\ge N$ 时 $\frac{a_{n+1}}{a_n}\ge r_0$，故 $a_{N+k}\ge r_0^{k}a_N$，通项不趋于 0（反而 $\ge$ 一个递增几何项），故发散。

**例 1**：$a_n = \frac{1}{n}$。此时

```math
\frac{a_{n+1}}{a_n} = \frac{1/(n+1)}{1/n} = \frac{n}{n+1} \to 1,
```

判别法失效，但级数发散（调和级数）。

**例 2**：$a_n = \frac{1}{n^2}$。此时

```math
\frac{a_{n+1}}{a_n} = \frac{n^2}{(n+1)^2} \to 1,
```

判别法失效，但级数收敛。

> **译注**：例 1 与例 2 说明 $a=1$ 时比值判别法**无法区分**收敛与发散，必须改用其他方法（如比较判别法、积分判别法、$p$-级数结论等）。

## 6. 根值判别法（Root test）

设 $a_n \ge 0$ 是非负项序列，假设 $\lim_{n\to\infty} (a_n)^{1/n} = r$。

- 若 $r < 1$，则级数 $\sum_{n=0}^{\infty} a_n$ 收敛。
- 若 $r > 1$，则级数 $\sum_{n=0}^{\infty} a_n$ 发散。
- 若 $r = 1$，则判别法失效。

**证明（根值判别法）**：

先证 $r<1$ 的情形。任取 $r_0$ 满足 $r < r_0 < 1$，由 $\lim (a_n)^{1/n} = r$ 可知存在 $N$，使当 $n\ge N$ 时

```math
(a_n)^{1/n} \le r_0.
```

（**具体选法**：因 $(a_n)^{1/n}\to r$，对 $\varepsilon = r_0 - r > 0$，存在 $N$ 使 $n\ge N \Rightarrow (a_n)^{1/n} < r + \varepsilon = r_0$。）于是

```math
0 \le a_n \le r_0^{\,n}.
```

而 $\sum_{n=0}^{\infty} r_0^{\,n}$ 是公比为 $r_0<1$ 的几何级数，收敛。由比较判别法（版本一），$\sum_{n=0}^{\infty} a_n$ 也收敛。

再证 $r>1$ 的情形。任取 $r_0$ 满足 $1 < r_0 < r$，同理存在 $N$ 使当 $n\ge N$ 时

```math
(a_n)^{1/n} \ge r_0.
```

于是对 $n\ge N$，

```math
a_n \ge r_0^{\,n},
```

而 $\sum r_0^{\,n}$ 是公比 $r_0>1$ 的发散几何级数。故由比较判别法，原级数发散。$\square$

> **译注**：根值判别法的核心在于「通项的 $n$ 次根渐近到 $r$」，即 $a_n$ 大致像 $r^n$ 增长，于是与几何级数 $\sum r^n$ 比较。比值判别法依赖相邻项的比，根值判别法依赖整体开 $n$ 次根，两者对幂级数都极有用（见下一节）。

## 7. 幂级数（Power series）

一些熟悉的例子：

```math
\sum_{n=0}^{\infty} x^{n} = \frac{1}{1-x}.
```

```math
\sum_{n=0}^{\infty} \frac{x^{n}}{n!} = \exp x.
```

```math
\sum_{n=0}^{\infty} (-1)^{n} \frac{x^{2n}}{(2n)!} = \cos x.
```

```math
\sum_{n=0}^{\infty} (-1)^{n} \frac{x^{2n+1}}{(2n+1)!} = \sin x.
```

**形式定义（Formal definition）**：设 $c_n$ 是一个序列，则 $\sum_{n=0}^{\infty} c_n x^n$ 称为幂级数（power series）。

幂级数何时收敛？

它为什么给出我们熟悉的函数？（第二个问题将在下次课对指数函数作出回答。）

第一个问题的答案来自根值判别法或比值判别法。

**例**：考虑幂级数

```math
\sum_{n=0}^{\infty} \frac{x^{n}}{n!}.
```

用比值判别法，取 $a_n = \frac{x^n}{n!}$，则

```math
\frac{a_{n+1}}{a_n} = \frac{x^{n+1}}{(n+1)!} \cdot \frac{n!}{x^{n}} = \frac{x}{n+1} \to 0.
```

故该幂级数对所有 $x$ 都收敛。

**例**：

```math
\sum_{n=0}^{\infty} x^{n}.
```

此级数当 $|x|<1$ 时收敛，其余情形发散。

## 8. 上极限（limsup）与收敛半径（Radius of convergence）

为了讨论一般幂级数的收敛性，我们需要序列的**上极限（limsup）**的概念。定义如下：

设 $a_n$ 是一个序列。若它不（在）上有界（not bounded from above），则令 $\limsup a_n = \infty$。否则，从 $a_n$ 构造一个新序列 $b_n$：

```math
b_n = \sup\,\{a_n,\ a_{n+1},\ a_{n+2},\ \cdots\}.
```

注意：由于假设 $a_n$ 上有界，每个 $b_n$ 都是实数，且 $b_n$ 是递减（decreasing）序列——它递减是因为

```math
b_n = \sup\,\{a_n, a_{n+1}, a_{n+2}, \cdots\} \ge \sup\,\{a_{n+1}, a_{n+2}, \cdots\} = b_{n+1},
```

（因为 $b_{n+1}$ 的上确界取自一个更小的集合。）

由于 $b_n$ 递减，它收敛，其极限 $b$ 可能为 $-\infty$（若 $b_n$ 不下有界）。

**定义（上极限）**：

```math
\limsup_{n\to\infty} a_n = \lim_{n\to\infty} b_n = b.
```

> **译注（上极限的直观）**：$\limsup a_n$ 是「序列尾部上确界的极限」，即序列「最终保持在什么高度附近」的最大可能值。例如 $a_n = (-1)^n + \frac1n$ 时，$\limsup a_n = 1$（偶子列逼近 1），而 $\lim a_n$ 不存在。若 $\lim a_n = L$ 存在，则 $\limsup a_n = L$。

回到幂级数。设 $\sum_{n=0}^{\infty} a_n x^n$ 是一个幂级数。令

```math
R = \frac{1}{\limsup_{n\to\infty} |a_n|^{1/n}}.
```

$R$ 称为收敛半径（radius of convergence）。

**约定（Convention）**：若 $\limsup_{n\to\infty} |a_n|^{1/n} = 0$，则称收敛半径为 $\infty$；若 $\limsup_{n\to\infty} |a_n|^{1/n} = \infty$，则令 $R = 0$。

由根值判别法可证明如下结论：

幂级数当 $|x| < R$ 时收敛，当 $|x| > R$ 时发散。

> **译注（证明思路）**：对 $\sum a_n x^n$ 用根值判别法，看 $\limsup |a_n x^n|^{1/n} = |x| \cdot \limsup |a_n|^{1/n} = \frac{|x|}{R}$。当 $|x|\lt R$ 时 $\frac{|x|}{R}<1$，收敛；当 $|x|>R$ 时 $\frac{|x|}{R}>1$，发散。这正是收敛半径公式的来源。（严格地，$|x|>R$ 时通项 $|a_n x^n|$ 不趋于 0，故发散。）

$|x| = R$ 的情形需逐例单独考察（case by case）。
