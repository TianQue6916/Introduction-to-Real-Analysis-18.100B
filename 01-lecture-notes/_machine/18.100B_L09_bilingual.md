## 1. Power series（幂级数）

Suppose that $a_n$ is a sequence（数列），for each $x$ we can form a series（级数）

```math
\sum_{n=0}^{\infty} a_n x^{n}.
```

> **译注**：设 $\{a_n\}$ 是一个数列，则对每一个 $x$，都可以构造一个级数 $\sum_{n=0}^{\infty} a_n x^n$。这里 $a_n$ 称为系数（coefficient），$x^n$ 是 $x$ 的 $n$ 次幂。所谓幂级数，就是以「系数 × 幂」为通项的级数。

---

## 2. Exponential map as a power series（用幂级数定义指数映射）

Define $E(x)$ as the power series（幂级数）

```math
E(x) = \sum_{n=0}^{\infty} \frac{x^{n}}{n!}.
```

> **译注**：把 $E(x)$ 定义为以 $\frac{1}{n!}$ 为系数的幂级数，即
> $E(x)=1+\frac{x}{1!}+\frac{x^2}{2!}+\frac{x^3}{3!}+\cdots$
> 这是指数函数 $e^x$ 的严格构造起点：我们**先**用这个级数定义 $E(x)$，再逐步证明它满足指数的一切性质。

### Step 0（第 0 步）：证明级数对所有 $x$ 收敛

The power series converges for all $x$（幂级数对所有 $x$ 收敛）。Namely, since

```math
\frac{|a_{n+1} x^{n+1}|}{|a_n x^n|} = \frac{|n!\, x^{n+1}|}{|(n+1)!\, x^n|} = \frac{|x|}{n+1} \to 0,
```

the claim follows from the ratio test（比值判别法）.

> **译注（完整证明思路）**：
> 1. 相邻两项的绝对值之比为
>    $\left|\frac{a_{n+1}x^{n+1}}{a_n x^n}\right|=\left|\frac{x^{n+1}/(n+1)!}{x^n/n!}\right|=\left|\frac{x^{n+1}}{(n+1)!}\cdot\frac{n!}{x^n}\right|=\frac{|x|}{n+1}.$
> 2. 固定任意 $x$（无论多大），$|x|$ 是一个**常数**，而分母 $n+1\to\infty$，因此
>    $\lim_{n\to\infty}\frac{|x|}{n+1}=0<1.$
> 3. 由比值判别法（ratio test）：若 $\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|=L<1$，则级数 $\sum a_n$ **绝对收敛**（absolutely convergent）。
> 4. 这里比值极限 $L=0<1$，故对**每一个** $x$，级数 $\sum \frac{x^n}{n!}$ 都绝对收敛。于是 $E(x)$ 对一切 $x\in\mathbb{R}$ 都有定义。

---

### Step 1（第 1 步）：先把 $e^x$ 定义到整数、有理数上

Define $e = E(1)$，并定义

```math
e^2 = e \cdot e,\quad e^3 = e \cdot e \cdot e,\quad \dots
```

This way $e^k$ is defined for all $k \in \mathbb{N}$（自然数）. We also define

```math
e^{-k} = \frac{1}{e^k}.
```

(The idea is that we would like to have $e^{x+y} = e^x e^y$.) We set $e^0 = 1$.

> **译注**：
> - 令 $e=E(1)=1+\frac1{1!}+\frac1{2!}+\cdots$，这就是欧拉数 $e$ 的级数定义。
> - 对正整数 $k$，用连乘定义 $e^k$；再规定 $e^{-k}=\frac1{e^k}$、$e^0=1$，于是 $e^k$ 对所有**整数** $k\in\mathbb{Z}$ 都有了定义。
> - 括号里的想法是关键：我们希望将来成立**加法变乘法**的指数律 $e^{x+y}=e^x e^y$。现在这些定义都是为了朝这个目标铺路。

If $q=\frac{m}{n}\in\mathbb{Q}$（有理数），where $m\in\mathbb{Z}$ and $n\in\mathbb{N}$，then we let $e^q$ be the positive number（正数）$\alpha$ so that

```math
\alpha^n = e^m.
```

> **译注**：对有理数 $q=\frac mn$，定义 $e^q$ 为满足 $\alpha^n=e^m$ 的**正数** $\alpha$。也就是 $e^{m/n}=(e^m)^{1/n}=\sqrt[n]{e^m}$。这里要求「正数」是为了保证 $n$ 次方根的存在与唯一（正数的正 $n$ 次方根唯一）。于是 $e^q$ 对所有**有理数**都有了定义。

What about the irrational numbers（无理数）like $\sqrt{2}$?

> **译注**：那无理数（如 $\sqrt2$）上的 $e^x$ 该怎么定义？—— 这正是后面几步要解决的问题：**用连续性（continuity）把定义从有理数“填满”到全体实数。**

---

## 3. Step 2（第 2 步）：$E$ 满足指数律且恒正

Next time we will show that

```math
E(x+y) = E(x)\, E(y).
```

> **译注**：下一讲将证明核心的加法公式 $E(x+y)=E(x)E(y)$（这需要用到两个绝对收敛级数的乘积展开）。本讲先把它当作将要成立的结论来用。

Here we claim that $E(x)>0$ for all $x$（对所有 $x$ 恒正）.

If $x \ge 0$，this is clear since

```math
E(x) = 1 + \frac{x}{1!} + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots \ge 1.
```

If $x<0$，then using the formula we will show next time we have

```math
1 = E(0) = E(x)\, E(-x).
```

Therefore,

```math
E(x) = \frac{1}{E(-x)} > 0.
```

> **译注（证明思路）**：
> - 当 $x\ge0$：级数每一项 $x^n/n!\ge0$，且常数项为 $1$，故 $E(x)\ge1>0$。
> - 当 $x<0$：由将要证明的公式 $E(x+y)=E(x)E(y)$ 取 $y=-x$，得 $E(0)=E(x)E(-x)$；而 $E(0)=1$，$-x>0$ 故 $E(-x)>0$，从而 $E(x)=\frac1{E(-x)}>0$。
> - 结论：$E(x)>0$ 对一切 $x$ 成立。

Using that $E(x+y)=E(x)E(y)$ we now claim that $E(q)=e^q$ for all rational numbers $q$（对一切有理数 $q$）.

For integers $m$ this is how we defined $e^m$. For $m=-k$, where $k\in\mathbb{N}$, we defined

```math
e^{-k} = \frac{1}{e^k} = \frac{1}{E(k)} = E(-k).
```

For a general rational number $q=\frac mn$, where $m\in\mathbb{N}$ and $n\in\mathbb{Z}$, we have

```math
\Big[ E\Big(\tfrac{m}{n}\Big) \Big]^{n} = E\Big(\tfrac{m}{n}\Big) \cdots E\Big(\tfrac{m}{n}\Big) = E\Big(\tfrac{m}{n}+\cdots+\tfrac{m}{n}\Big) = E(m),
```

and

```math
E\Big(\tfrac{m}{n}\Big) > 0.
```

This gives us that $E(q)=e^q$ for all rational numbers $q$.

> **译注（证明思路）**：
> 1. **整数情形**：正整数 $m$ 时由定义 $E(m)=E(1+\cdots+1)=E(1)\cdots E(1)=e^m$；负整数 $-k$ 时 $E(-k)=1/E(k)=1/e^k=e^{-k}$；$0$ 时 $E(0)=1=e^0$。
> 2. **有理数情形**：对 $q=\frac mn$，反复用加法公式把 $n$ 个 $E(\frac mn)$ 相乘，得到
>    $\left[E(\tfrac mn)\right]^n=E(\tfrac mn+\cdots+\tfrac mn)=E(m).$
> 3. 又 $E(\frac mn)>0$（前面已证 $E$ 恒正）。而 $e^{m/n}$ 正是「满足 $\alpha^n=e^m$ 的那个**正数** $\alpha$」。
> 4. 于是 $E(\frac mn)$ 与 $e^{m/n}$ 都等于同一个正数，故 $E(q)=e^q$ 对一切有理数 $q$ 成立。

---

## 4. Step 3（第 3 步）：我们希望指数函数「连续」

We now have $E(x)$ defined for all $x$（对所有实数），whereas $e^x$ is defined for all rational numbers（对所有有理数）.

What other properties would we want of the exponential function? We would want it to be **continuous**（连续）!

> **译注**：现在 $E(x)$ 已在全体实数上定义，而 $e^x$ 只在有理数上定义。要让二者「无缝衔接」，我们希望指数函数是连续的——连续能把有理点上的值唯一地“延续”到无理点上。

### Reminder（回顾）：连续函数的定义

A function $f: A\to\mathbb{R}$ on some set $A\subset\mathbb{R}$ is said to be **continuous**（连续）if for all $x_0\in A$ we have:

> For all $\epsilon>0$，there exists a $\delta=\delta(x_0)>0$ such that if $|x-x_0|<\delta$（$x\in A$），then $|f(x)-f(x_0)|<\epsilon$.

> **译注（核心概念）**：
> - **Continuous（连续）**：函数 $f$ 在点 $x_0$ 处连续，是指**任意给定误差 $\epsilon>0$**，都能找到**一个正数 $\delta$**，使得只要自变量 $x$ 与 $x_0$ 的距离 $|x-x_0|<\delta$，函数值 $f(x)$ 与 $f(x_0)$ 的距离就 $<\epsilon$。
> - 一句话判定：**“输入变化足够小，输出变化就足够小”。** $\delta$ 可以依赖于 $x_0$（记为 $\delta(x_0)$），即不同点允许选不同的 $\delta$。
> - 这是**点态连续**（continuity at a point）；若对**每个** $x_0\in A$ 都成立，则称 $f$ 在 $A$ 上连续。

On Pset 5 you will be asked to show that $E(x)$ is continuous at all points.

> **译注**：作业 5 会要求你证明 $E(x)$ 在每一点都连续（可借助 $E(x+h)-E(x)=E(x)\big(E(h)-1\big)$ 以及 $E(h)\to E(0)=1$）。

---

## 5. Step 4（第 4 步）：$E(x)$ 是唯一的连续延拓

We will next show that $E(x)$ is the **unique continuous function**（唯一连续函数）where $E(q)=e^q$ for all rational numbers $q$.

> **译注**：我们要证明：在所有满足「在有理点上等于 $e^q$」的连续函数里，$E(x)$ 是**唯一的**。这由下面这个一般定理保证。

**Theorem（定理）**：Let $f$ and $g$ be two continuous functions on $\mathbb{R}$ that agree on all rational numbers, then $f=g$.

> **译注（定理表述）**：若两个定义在 $\mathbb{R}$ 上的连续函数 $f$、$g$ 在**所有有理数**上取值相同，则 $f=g$（处处相等）。

**证明思路（将在下一讲给出，本讲预告）**：
> 1. 对任意实数 $x$，有理数集 $\mathbb{Q}$ 在 $\mathbb{R}$ 中**稠密**（dense）：存在有理数列 $q_n\to x$。
> 2. 由 $f$ 连续，$f(q_n)\to f(x)$；由 $g$ 连续，$g(q_n)\to g(x)$。
> 3. 但对每个 $n$ 有 $f(q_n)=g(q_n)$，故两侧极限相同，于是 $f(x)=g(x)$。
> 4. 由 $x$ 任意，$f=g$。

> 把这个定理用到 $f=E(x)$ 与 $g=$（任意满足「有理点等于 $e^q$」的连续函数）上，即得 $E(x)$ 的**唯一性**。

---

## 6. Examples（连续函数的例子）

### Example 1（例 1）：常值函数连续

Suppose $f(x)=c$, where $c$ is a constant. We show that $f$ is continuous.

Given $x_0\in\mathbb{R}$ and $\epsilon>0$, set $\delta=1$. Then if $|x-x_0|<\delta=1$，we have

```math
|f(x)-f(x_0)| = 0 < \epsilon.
```

This shows $f$ is continuous.

> **译注（证明思路）**：对任意 $x_0$、$\epsilon>0$，**具体取** $\delta=1$（取什么都行，因为函数值根本不变）。若 $|x-x_0|<1$，则 $|f(x)-f(x_0)|=|c-c|=0<\epsilon$。故常值函数连续。

### Example 2（例 2）：恒等函数连续

Suppose $f(x)=x$. Given $x_0\in\mathbb{R}$ and $\epsilon>0$, set $\delta=\epsilon$. Then if $|x-x_0|<\delta=\epsilon$，we have

```math
|f(x)-f(x_0)| = |x-x_0| < \epsilon.
```

This shows $f$ is continuous.

> **译注（证明思路）**：对任意 $x_0$、$\epsilon>0$，**具体取** $\delta=\epsilon$。若 $|x-x_0|<\delta=\epsilon$，则 $|f(x)-f(x_0)|=|x-x_0|<\epsilon$。故 $f(x)=x$ 连续。

## 7. Algebraic properties of continuous functions（连续函数的代数性质）

- If $f$ and $g$ are continuous，then so is $f+g$（和连续）.
- If $f$ is continuous and $c$ is a constant，then $cf$ is continuous（数乘连续）.
- If $f$ and $g$ are continuous，then $fg$ is also continuous（积连续）.
- If $f$ is continuous and $f\neq 0$，then $\frac1f$ is continuous（倒数连续，需 $f\neq0$）.
- If $f(x)$ and $g(x)$ are continuous，then $f(g(x))$ is continuous（复合连续）.

**Proof**：the proof is very similar to the one we gave for the algebraic properties of limits. □

> **译注（证明思路概述）**：这五条性质都可由「极限的代数运算」平移而来。以 $f+g$ 为例：
> - 设 $\lim_{x\to x_0}f(x)=f(x_0)$、$\lim_{x\to x_0}g(x)=g(x_0)$（连续的定义等价于“函数值等于极限值”）。
> - 由极限加法法则 $\lim(f+g)=\lim f+\lim g=f(x_0)+g(x_0)=(f+g)(x_0)$。
> - 故 $f+g$ 在 $x_0$ 连续；$x_0$ 任意，故 $f+g$ 连续。
> - 其余四条分别对应极限的数乘、乘法、倒数、复合法则，证法同理。

## 8. Theorem: All polynomials are continuous（所有多项式连续）

> **译注（定理）**：每个多项式函数都在 $\mathbb{R}$ 上连续。

### Example 3（例 3）：$f(x)=x^2+1$ 连续

If $f(x)=x^2+1$, then $f$ is continuous. We have already proven that $g(x)=x$ is continuous, so by the algebraic properties we have that $x^2=g\cdot g$ is continuous. We have also shown that constant functions are continuous, so $h(x)=1$ is continuous, and therefore by the algebraic properties $f=g^2+h$ is continuous.

> **译注（证明思路）**：
> 1. 已证 $g(x)=x$ 连续（例 2）。
> 2. 由「积连续」性质，$x^2=g\cdot g$ 连续。
> 3. 已证常值函数连续（例 1），故 $h(x)=1$ 连续。
> 4. 由「和连续」性质，$f=g^2+h=x^2+1$ 连续。
>
> 一般地，$x^n$（$n$ 次幂）由有限次「积连续」得到连续，再与常数线性组合，即得一切多项式连续。
