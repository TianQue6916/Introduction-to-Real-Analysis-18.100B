### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Definition: Compact subset（定义：紧致子集）</span>

我们从一个定义出发。设 $(X, d)$ 是一个 metric space（度量空间），$A$ 是 $X$ 的一个子集。我们称 $A$ 是 compact（紧致的），如果 $A$ 的每一个 open cover（开覆盖）都存在一个 finite sub-cover（有限子覆盖）。

> <span style="color:#7f8c8d;">TBB Theorem 13.94(2), §13.12 Compactness, p.602（"每个开覆盖可缩减为有限子覆盖"即 TBB 所称的 Heine-Borel 性质；TBB 的 Definition 13.88, §13.12, p.598 则以 Bolzano-Weierstrass 性质作为紧致的定义，两刻画等价）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，承上启下）:**</span> 本节是 L13（开闭集、覆盖与紧致性）的直系续篇。覆盖的术语链是：cover（覆盖）——一族子集 $u_\alpha$ 使 $X \subset \bigcup_\alpha u_\alpha$；open cover（开覆盖）——由开集组成的覆盖；compact（紧致）——每个开覆盖都有有限子覆盖。🎥 *Colding 在课堂上复述定义*："then we say that a is compact if every open cover of a has a finite subcover."（翻译：如果 $A$ 的每一个开覆盖都有有限子覆盖，我们就称 $A$ 是紧致的。）为什么选择这条定义？他在随后解释了动机：🎥 *"So now, the Bolzano-Weierstrass does not hold for every metric space, but it holds-- so when this space here is compact. So that's what I want to prove. And that's one of the motivations here for the definition of being compact."*（翻译：Bolzano-Weierstrass 定理并非对每个度量空间都成立，但当空间紧致时成立——这正是我要证明的，而这正是紧致性定义的动机之一。）也就是说：**紧致性这个定义本身，就是为了让 Bolzano-Weierstrass 性质在度量空间中复活**。本讲标题的"序列紧致"（sequential compactness）指的正是"每个序列都有收敛子序列"这条性质——你将看到开覆盖定义与序列性质在这里会师。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 0: Compact subsets are closed and bounded（定理 0：紧致子集既闭又有界）</span>

设 $(X, d)$ 是一个度量空间，$A$ 是一个紧致子集，则 $A$ 是 closed（闭的）且 bounded（有界的）。

> <span style="color:#7f8c8d;">TBB Theorem 13.90, §13.12, p.598（TBB 版本列出四条必要性质：闭、有界、完备、可分）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，与上一讲的连接）:**</span> 这是 L13 已经证明过的结论，本讲原文以"Theorem 0"开头把它登记在册：闭（补集是开集）、有界（被 $X$ 中某点的某个大球包住）。🎥 *Colding 上课回顾*："we proved last time, that if you have a here is compact, then a is bounded and closed. Right, so it's a is a closed subset, meaning that the complement is open, and a itself is contained in some large ball centered at some point in x."（翻译：我们上次证明了：紧致集既闭又有界——闭指补集是开集，有界指它被 $X$ 中某点为中心的一个大球包含。）在 TBB 中，Theorem 13.90 实际给出四条：$K$ 闭、有界、complete（完备）、separable（可分）——本讲只用到前两条。这个定理的地位是"必要条件清单"：它告诉你紧致集必须长什么样，但（下一个警告）这些条件并不充分。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Warning: The converse fails（警告：逆命题不成立）</span>

警告：逆命题不成立！！！度量空间中存在既闭又有界、却并不紧致的子集。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example: The open interval as a whole space（例：作为全空间的开区间）</span>

取 $(X, d) = (0, 1)$ 并配以 usual metric（通常度量），则 $X$ 既是闭的又是有界的，但它并不紧致。

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 这里有一个初学者最容易绊倒的语言点：**"闭"是相对于承载它的度量空间而言的**。🎥 *Colding 特别停下来解释*："So x here, if this here is the metric space, then x is, by definition, closed because the whole set is closed. It's not closed as a subset of r, but if the metric space just is x, then it is closed, and it's bounded."（翻译：如果度量空间就是 $X$ 本身，那么 $X$ 按定义是闭的，因为全空间总是闭的——它作为 $\mathbb{R}$ 的子集当然不闭，但当度量空间恰好就是 $X$ 时，它就是闭的，而且有界。）不紧致的理由：$X = \bigcup_{n=1}^{\infty} \left( \frac{1}{n}, 1 \right)$ 是一个开覆盖，但🎥 *"if you only take finitely many of them, then you don't get all the way down to zero"*（翻译：如果只取有限多个，就覆盖不到贴近 $0$ 的部分）。从第一性原理看，$(0,1)$ 的毛病出在"有界"太弱：对任意固定的半径 $\varepsilon$，它需要无穷多个 $\varepsilon$-球才能盖住（比如靠近 $0$ 处要无穷多个小球）。这种"任意小半径下都可用有限多个球覆盖"的强化版本，TBB 称为 totally bounded（完全有界的，Definition 13.95, §13.12, p.604）——它才是紧致性真正需要的"有界"。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example: The closed unit ball in C([0,1]) is not compact（例：C([0,1]) 中的闭单位球不紧致）</span>

这是一个更有启发性的例子。取 $X = C([0, 1])$ 为单位区间 $[0, 1]$ 上连续函数的集合，并配备 $X$ 上的度量

```math
d(f, g) = \max_{x \in [0, 1]} |f(x) - g(x)| .
```

设 $f_n(x)$ 是 $[0, 1]$ 上的如下连续函数序列：

```math
f_n(x) = \begin{cases} 1, & \text{if } 0 \le x \le \dfrac{1}{n+1} \\[3mm] 1 - n(n+1)\left(x - \dfrac{1}{n+1}\right), & \text{if } \dfrac{1}{n+1} \le x \le \dfrac{1}{n} \\[3mm] 0, & \text{otherwise} \end{cases}
```

序列 $(f_n)$ 是有界的：毕竟它们都落在 metric ball（度量球）$B_2(0)$ 之中，其中 $0$ 指 zero function（零函数），即在 $[0, 1]$ 上恒等于零的函数。然而序列 $(f_n)$ 没有收敛子序列——它甚至没有成为 Cauchy sequence（柯西序列）的子序列。事实上，对任意 $m \ne n$ 都有

```math
d(f_m, f_n) = 1 .
```

同样注意（闭）球 $A = \bar{B}_1(0)$ 是闭且有界的，但不紧致。它不紧致的原因是：形如 $B_{\frac{1}{2}}(f)$ 的球无论取多少个（finitely many，有限多个）都无法覆盖 $A$。假如有限多个真的覆盖了 $A$，那么其中某个球 $B_{\frac{1}{2}}(f)$ 内就会落入无穷多个 $f_n$；可是这种球中的任意两个元素的距离都小于 $1$，而如上所示任意两个不同的 $f_n$ 相距恰为 $1$——因此这样的球里至多只能装下一个 $f_n$，矛盾。

> <span style="color:#1e8449;">**[note] Note（译者注，函数构造的几何图像）:**</span> $f_n$ 的图像：在 $[0, \frac{1}{n+1}]$ 上是高度 $1$ 的平台，随后在 $[\frac{1}{n+1}, \frac{1}{n}]$ 上🎥 *"I choose it to die off linearly"*（翻译：我让它线性地衰减下来），此后恒为 $0$。斜率为什么是 $-n(n+1)$？平台高度差为 $1$，水平宽度为 $\frac{1}{n} - \frac{1}{n+1} = \frac{1}{n(n+1)}$，通分后即得系数 $n(n+1)$。再看距离为何恰为 $1$：🎥 *"if I'm now just evaluate it, if I'm looking at fn, and now I just evaluate it in this point here, in this point 1 over n plus 1-- you see this value here, this first function here, and at this point, it's 1. ... But for the next one, you see at that point it's 0. So this means that this max here, is for all n and n plus 1, is actually equal to 1."*（翻译：把 $f_n$ 在 $x = \frac{1}{n+1}$ 处取值是 $1$，而 $f_{n+1}$ 在该点已是 $0$，所以差的最大值恰为 $1$。）于是以 $\frac{1}{2}$ 为半径的球之间彼此 disjoint（不相交）：🎥 *"Because this here is an open ball, so it means that's strictly less than one half, so this means that fn plus 1 is not in that ball."*（翻译：开球意味着距离严格小于 $\frac{1}{2}$，所以 $f_{n+1}$ 不在 $f_n$ 的球里。）而"球内任意两点距离小于 $1$"正是你在 L11 反复用过的三角不等式论证：$d(g, h) \le d(g, f) + d(f, h) < \frac{1}{2} + \frac{1}{2} = 1$。这个例子与上一个 $(0,1)$ 例子性质不同：$(0,1)$ 是不完备导致的病态，而 $C([0,1])$ 完备、闭球也闭且有界，问题出在**无穷维**——"点"（函数）可以挤在互相分离的方向上。直觉上：$(f_n)$ 的"质量"不断向 $0$ 逃跑，却没有一个连续函数可以当它的极限。这正是紧致性在泛函分析中如此珍贵的原因。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 1: Heine-Borel in Rⁿ（定理 1：$\mathbb{R}^n$ 中的 Heine-Borel 定理）</span>

利用前面各讲已证的内容可以证明：在 $\mathbb{R}^n$ 中，一个子集是紧致的当且仅当它既闭又有界。

在一般度量空间中结论并非如此，正如上面的例子所示。

我们在这里不证明这个定理，而是改为证明度量空间版本的 Bolzano-Weierstrass 定理。这就是下一个定理。

> <span style="color:#7f8c8d;">TBB §13.12, p.605（Theorem 13.97 之前的讨论原文即"compact in $\mathbb{R}^n$ is equivalent to closed and bounded"的重新解读；Theorem 13.97, §13.12, p.605 给出一般版本：紧致 ⟺ 完备 + 完全有界）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，战略选择）:**</span> 🎥 *"So In Rn the usual metric, Euclidean metric, the converse is the case but in general not-- but not in general."*（翻译：在 $\mathbb{R}^n$ 的通常度量即欧氏度量下，逆命题成立；但在一般情形下不成立。）Colding 明确宣布跳过 Heine-Borel 定理的证明：🎥 *"We won't show this theorem here but instead we will show a version of the Bolzano-Weirstrass theorem for metric spaces."*（翻译：我们不在这里证明这个定理，而是转而证明度量空间版本的 Bolzano-Weierstrass 定理。）这个取舍背后的逻辑值得体会：Heine-Borel 的证明要动用 $\mathbb{R}^n$ 的特殊结构（比如列紧性论证、$\mathbb{R}$ 的完备性加嵌套区间），而在一般度量空间里你手里只有"开覆盖的有限子覆盖"这一件武器；所以本讲把力气花在**紧致 ⇒ 序列紧致**这个对所有度量空间都成立的单向蕴涵上。TBB 走的路略有不同：它干脆用 Bolzano-Weierstrass 性质定义紧致（Definition 13.88），再证明其与 Heine-Borel 性质等价（Theorem 13.94, p.602），并另证紧致 ⟺ 完备 + 完全有界（Theorem 13.97, p.605）。两条路线、同一幅地图。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 2: Sequential compactness of compact sets（定理 2：紧致集的序列紧致性）</span>

设 $(X, d)$ 是一个度量空间，$A$ 是一个紧致子集，则 $A$ 中的任意序列都有 convergent subsequence（收敛子序列）。

> <span style="color:#7f8c8d;">TBB Definition 13.88, §13.12, p.598（TBB 以此"Bolzano-Weierstrass 性质"定义紧致）；证明构造与 TBB Theorem 13.96 的证明（§13.12, p.604–605，用半径 1、1/2、……的球逐层提取 Cauchy 子序列）同源</span>

> <span style="color:#1e8449;">**[note] Note（译者注，证明的必要性）:**</span> 在 $\mathbb{R}$ 中，Bolzano-Weierstrass 定理（L04）说有界序列必有收敛子序列，而"收敛子序列 + 极限在集合内"几乎是白送的，因为极限点可以借 $\mathbb{R}$ 的完备性现成拿到。但在一般度量空间里，Colding 强调没有任何捷径：🎥 *"I mean, just that there's no assumption-- I'm not talking about some Cauchy complete set space or something like that. So in this case, I really have to construct the convergence sequence. But I also have to construct the limits. And so this is where in particular... this is why we want this thing here to have a unique intersection."*（翻译：这里没有柯西完备性之类的假设，所以我不仅得构造出收敛子序列，还得亲手把极限也构造出来——这正是我们要让闭球套的交"只含唯一点"的原因。）他还将本定理的证明拆成台阶：🎥 *"when you're trying to prove something, there are things that are really easy to prove, but then there are things that are much more complicated. So one thing is that you try to prove it. Another thing is that you try to explain to other the proof. And so in either case, if you can divide it into substeps-- and so this here is a substep in the proof."*（翻译：有些结论好证、有些复杂；无论为了自己证明还是向别人解释，把证明分成子步骤都是好办法——下面这条引理就是证明中的一个子步骤。）注意定理只承诺收敛子序列的**存在**，而极限点由闭球套的交唯一确定——这就是"紧致"比"完备"更强的地方。

#### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma: Nested closed sets（引理：嵌套闭集套）</span>

设 $(X, d)$ 是一个 compact metric space（紧致度量空间）。设 $C$ 是一族 closed（闭的）、递减嵌套的子集，即诸闭子集满足 $C_{n+1} \subset C_n$。若所有 $C_n$ 都非空，则

```math
\bigcap_{n} C_n \ne \varnothing .
```

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 令 $O_n = X \setminus C_n$，则每个 $O_n$ 都是开集。若 $\bigcap_{n} C_n = \varnothing$，则

```math
\bigcup_{n} O_n = X .
```

因此，由紧致性，有限多个 $O_n$ 就覆盖了 $X$。把这些记为 $O_i$，$i = 1, \cdots, k$。既然

```math
O_1 \cup \cdots \cup O_k = X ,
```

便知

```math
C_1 \cap \cdots \cap C_k = \varnothing .
```

然而由嵌套性，这 $k$ 个闭子集中有一个是最小的，设为 $C_k$，于是

```math
C_1 \cap \cdots \cap C_k = C_k .
```

这与交集为空相矛盾。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这个证明是本讲反复出现的组合拳——**「取补集 + 有限子覆盖」**：① 反证：假设闭集套的交为空；② 对每个 $C_n$ 取补集得开集 $O_n = X \setminus C_n$，由 De Morgan 律，交为空当且仅当补集之并等于全空间；③ "全空间被开集覆盖"正是紧致性发挥作用的暗号——抽出一个有限子覆盖；④ 把"有限"翻译回闭集语言，得到前 $k$ 个闭集之交为空；⑤ 嵌套性把"前 $k$ 个之交"坍缩为最小的一个 $C_k$，与非空假设正面相撞。课堂上有同学问这是不是本质上就是制造矛盾，Colding 确认：🎥 *"So is that essentially just creating a contradiction? TOBIAS COLDING: That's right. And that's a contradiction because now let's show that this one here, this Cn is empty."*（翻译：这本质上就是在制造矛盾吧？——没错，矛盾就在于我们将证明某个 $C_n$ 是空集。）与你已学的 Cantor 交集思想对照：在完备空间里"半径趋零的闭球套交于一点"（TBB Theorem 13.65），在紧致空间里"非空闭集套之交非空"——本引理正是后者，它不需要半径趋于零，只需要非空与紧致。

在陈述下一个结果之前，先回顾：在度量空间 $(X, d)$ 中，集合 $\bar{B}_r(x) = \{y \in X \mid d(x, y) \le r\}$ 是闭的，被称为 closed ball（闭球）。上面的引理给出如下有用的推论。

#### <span style="color:#2471a3;">**[corollary]**</span> <span style="color:#c0392b">Corollary: Nested closed balls（推论：嵌套闭球套）</span>

设 $(X, d)$ 是一个紧致度量空间，并设 $B_{r_n}(x_n)$ 是一族以 $x_n$ 为中心、半径 $r_n > 0$ 的球，其中 $r_n \to 0$，且诸闭球满足嵌套关系 $\bar{B}_{r_{n+1}}(x_{n+1}) \subset \bar{B}_{r_n}(x_n)$。则

```math
\bigcap_{n} \bar{B}_{r_n}(x_n) = \{x\} .
```

也就是说，交集非空，并且只由单独一个点构成。

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 令

```math
A = \bigcap_{n} \bar{B}_{r_n}(x_n) .
```

首先观察到：对每个 $n$ 都有 $x_n \in \bar{B}_{r_n}(x_n)$，于是由上面的引理知 $A$ 非空。我们断言 $A$ 只含一个元素。设 $x, y \in A$，则对任意整数 $n$ 都有

```math
x, y \in \bar{B}_{r_n}(x_n) ,
```

于是由三角不等式

```math
d(x, y) \le d(x, x_n) + d(x_n, y) \le r_n + r_n = 2 r_n .
```

由于此式对一切 $n$ 成立，故 $d(x, y) = 0$，从而这样的点至多只有一个。$\square$

> <span style="color:#7f8c8d;">TBB Theorem 13.65, §13.8 Complete Spaces, p.578（TBB 的对应刻画：度量空间完备 ⟺ 半径趋零的递减闭球套之交恰为一点）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡的诊断）:**</span> 两处细节容易含糊。其一，"每个闭球包含自己的中心"为什么成立？把 $y = x$ 代入定义 $d(x, y) \le r$ 得 $0 \le r$，所以中心永远在自己的闭球里——非空性是白送的，引理的其余假设（闭、嵌套）也逐一满足。其二，为什么交集"只含一点"？因为半径 $r_n \to 0$：任意两个公共点被夹在同一个半径 $r_n$ 的球里，距离不超过 $2r_n$，而 $2r_n$ 可以任意小。Colding 提醒大家，这一步里"球"并没有享受任何特权：🎥 *"But if you just think about it, the balls play no particular role, except for saying that the intersection of all of them contain just one point. And that was because the radii went to zero. The important points were that the sets were closed subsets."*（翻译：仔细想想，球本身并没有什么特殊作用，除了保证交集中只含一点——而那是因为半径趋于零。真正重要的是这些集合都是闭子集。）另外，课堂上有同学追问"嵌套"假设意味着对中心与半径的什么约束：🎥 *"when you make this assumption about nested, there's some assumption about the centers, the distance between centers, and there's also something about the radii. How large is one radii relative to the other?"*（翻译：一旦假设嵌套，就隐含了对中心的位置、中心之间的距离以及半径之间相对大小的约束。）这个推论正是定理 2 中"亲手构造极限"的引擎：球的交唯一确定一个点，那个点就是子序列的极限。

<span style="color:#2471a3;">**[proof]**</span> *Proof of Theorem 2（定理 2 的证明）.* 设 $(x_n)$ 是度量空间中紧致子集 $A$ 里的一个序列。取定 $r > 0$，并写

```math
A \subset \bigcup_{x \in A} B_r(x) .
```

由于 $A$ 紧致，其中有限多个球就覆盖了 $A$。这意味着在某个球——设为 $B_r(y_1)$——之中落有无穷多个 $x_n$。从现在起我们只关注这个球。

由于 $A \cap \bar{B}_r(y)$ 是紧致集的闭子集，我们现在可以用半径为 $\frac{r}{4}$ 的球去覆盖 $\bar{B}_r(y)$。由紧致性，其中有限多个子球覆盖了球 $\bar{B}_r(y)$。在这些子球之中，同样有一个子球内落有无穷多个 $x_n$。取定这样一个子球，记为 $\bar{B}_{\frac{r}{4}}(y_2)$。我们有

```math
\bar{B}_{\frac{r}{2}}(y_2) \subset \bar{B}_{2r}(y_1) ,
```

并且无穷多个 $x_n$ 属于 $B_{\frac{r}{4}}(y_2)$。若一开始取 $r = 1$，则把这一过程重复 $i$ 次之后，我们得到一系列球 $B_{\frac{1}{4^{i-1}}}(y_i)$，使得

```math
\cdots \subset \bar{B}_{\frac{2}{4^{i-1}}}(y_i) \subset \cdots \subset \bar{B}_{\frac{2}{4}}(y_2) \subset \bar{B}_{2}(y_1) .
```

其中每一个球都含有来自原序列的无穷多个元素。由于这一列球的半径收敛到零，它满足上述推论的假设，于是由该推论得

```math
\bigcap_{i} \bar{B}_{\frac{2}{4^{i-1}}}(y_i) = \{x\} .
```

此外，我们可以从原序列中选出一个子序列 $x_{n_k}$，使得

```math
x_{n_k} \in \bar{B}_{\frac{2}{4^{k-1}}}(y_k) .
```

由此可知该子序列收敛到 $x$。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这是全讲的压轴证明，可以命名为**「逐层开球覆盖 + 闭球套取极限」四步法**。① 用半径 $r$ 的开球覆盖 $A$：这是"开覆盖"定义的兑现——注意覆盖必须用开球，因为🎥 *"When I cover things, they are open because I have to have-- when I have a compact set, I have to cover it by open subset."*（翻译：覆盖时用的必须是开球，因为紧致集必须用开子集来覆盖。）② 鸽笼原理：有限多个球、无穷多个序列项，必有某球含无穷多个 $x_n$——从这一步起，序列"收缩"进一个球。③ 缩半径重复：在刚才那个球的范围内再用 $\frac{r}{4}$ 的开球覆盖、再选含无穷多项的子球，如此往复。④ 取闭球套交给推论：把每层的子球加倍，就得到嵌套的闭球套，其半径 $\frac{2}{4^{i-1}} \to 0$，推论给出唯一的交点 $x$；第 $k$ 层选一个 $x_{n_k}$，它到 $x$ 的距离不超过球半径 $\frac{2}{4^{k-1}} \to 0$，故 $x_{n_k} \to x$。
>
> 三个课堂追问值得留档。**为什么要加倍？**🎥 *"Why do I double this ball? Well, I double this ball here because these guys here cover this. But it means, of course, that there could be something outside."*（翻译：为什么要把球加倍？因为那些小球虽然盖住了这个球，但它们完全可能有部分伸到球外面——不取闭包、不放大，就保证不了嵌套。）**为什么半径取四分之一而不是一半？**🎥 *"You didn't quite have to do a quarter. You could actually have gotten away with a half, but I thought it wasn't as clear if I did it. So I did it with a quarter because then I thought it looked more obvious."*（翻译：其实不必用四分之一，用一半也能奏效，只是那样看起来不够一目了然；我取四分之一是因为这样更明显。）**覆盖用开球、嵌套用闭球，会不会打架？**🎥 *"But then once I'm looking at the nested things, I have to go to the closure, because otherwise the lemma and the corner would not apply."*（翻译：一旦进入嵌套结构，就必须取闭包，否则引理与推论都不适用——引理和推论要的是闭集。）此外还有一条隐含事实：$A \cap \bar{B}_r(y)$ 是紧致集的闭子集、因而仍紧致——课堂上有同学问起，Colding 回答：🎥 *"We prove that it's compact. And I can prove it again because it's very easy."*（翻译：我们证明过它是紧致的，我可以再证一遍，因为这很容易。）思路是：把"补集 + $A$ 的覆盖"拼成一个开覆盖，有限子覆盖中补集那一份对 $B$ 毫无贡献，于是有限份覆盖就落在了 $B$ 上。
>
> 最后把镜头拉远：这个证明与你在 L04 见过的实数 Bolzano-Weierstrass 定理的二分法/区间套证明是同一精神的两代人——**每一步都把"候选区域"缩小四分之三，同时保住无穷多个序列项**；实数版的极限来自区间套原理，度量空间版的极限来自刚证的闭球套推论。挑选子序列时还有一个实操细节，Colding 特意叮嘱：🎥 *"Remember, if you keep waiting, then you will end up getting nothing. So you pick-- at each stage, you pick one element in the subsequence. And then when you have the next ball, you pick the next element in the subsequent and so on."*（翻译：记住，如果一直等下去不选，最后将一无所获；每一阶段都要从子序列中选出一个元素，有了下一个球就选下一个元素，以此类推。）也就是说每层必须选一个新的、更靠后的指标，这正是子序列定义中"严格递增指标"的用武之地。TBB Theorem 13.96 的证明（p.604–605）用半径 $1, \frac{1}{2}, \frac{1}{4}, \cdots$ 的球做同样的层层筛选来构造 Cauchy 子序列，与本证明血统相同，值得对照阅读。
