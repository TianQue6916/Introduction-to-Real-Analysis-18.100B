### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Ordinary differential equations（常微分方程：问题设定）</span>

一个 differential equation（微分方程）是包含 unknown function（未知函数）及其 derivative（导数）的方程。

假设我们有：

- $f$ 是 $\mathbb{R}$ 上 continuously differentiable（连续可微）的函数。
- $g$ 是 $\mathbb{R}$ 上 continuous（连续）的函数。
- $a$ 是一个 real number（实数）。

我们将感兴趣于下述 ODE 的 existence and uniqueness（存在性与唯一性）：

```math
\begin{cases} y'(x) = f(y(x)) + g(x), \\ y(0) = a . \end{cases} \tag{$*$}
```

我们说这是一个 first order equation（一阶方程），因为它只涉及函数及其一阶导数，而不涉及更高阶的导数。

> <span style="color:#1e8449;">**[note] Note（译者注，为什么这个问题值得讲一整讲）:**</span> 这是研究微分方程时的标准问题：方程也许在描述自然界的某种现象，你问它有没有解、解是否唯一。Colding 强调这个问题的分量：🎥 *"So this is a fundamental question used all over science and engineering."*（翻译：这是一个在科学和工程各处都被用到的基础问题。）而本讲最有意思的地方在于工具的反差：微分方程看起来与度量空间毫无关系，证明却完全建立在度量空间理论上——🎥 *"the proof uses the theory of metric spaces, which is sort of surprising because it seems to have nothing to do with metric spaces."*（翻译：证明使用了度量空间理论，这有点令人惊讶，因为它看起来与度量空间毫无关系。）这套证明的各种变体已被用来证明各种微分方程的存在唯一性：🎥 *"various versions of the proof have been used to prove existence and uniqueness of various differential equations."*（翻译：这个证明的各种版本已被用于证明各种微分方程的存在性与唯一性。）

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Picard-Lindelöf theorem（皮卡德–林德勒夫定理）</span>

下面的定理为这一 ODE 的存在性与唯一性问题给出了一个令人满意的回答：存在 $\delta > 0$，使得 $(*)$ 在 $(-\delta, \delta)$ 上有唯一的解。

> <span style="color:#7f8c8d;">TBB Theorem 13.86 (Picard), §13.11.4 Picard's Theorem, p.595（TBB 的版本：$f$ 在 $D$ 上连续且对 $y$ 满足 Lipschitz 条件，初值问题在 $[x_0-\delta, x_0+\delta]$ 上有唯一解）</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Recollections from metric spaces（度量空间工具回顾）</span>

在证明这条定理之前，让我们回顾一个早前证明过的结果。设 $[a, b]$ 是一个区间，令 $C([a, b])$ 为 $[a, b]$ 上 continuous functions（连续函数）的空间。我们为这个空间配备 metric（度量）$d$：若 $h_1, h_2 \in C([a, b])$，则

```math
d(h_1, h_2) = \max_{x \in [a, b]} |h_1(x) - h_2(x)| .
```

我们早前证明过下面的定理：

<span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 1（定理 1）</span>

度量空间 $\big(C([a, b]), d\big)$ 是 Cauchy complete（柯西完备）的。

> <span style="color:#7f8c8d;">TBB Definition 13.60, §13.8 Complete Spaces, p.576（complete metric space 的定义）；$C[a,b]$ 的完备性证明见 §13.8.2 Subspaces of a Complete Space, p.578（经由 TBB Theorem 13.64：完备度量空间的闭子空间完备）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，闭球与 $\le$）:**</span> 稍后我们会看到，真正被使用的并不是整个空间 $C([a,b])$，而是其中一个闭球。Colding 特意澄清：🎥 *"It's actually not quite this space, as I mentioned last time. It's a ball in this space that it's using."*（翻译：正如上次提到的，其实并不完全是这个空间，它用的是这个空间里的一个球。）课上还有同学追问"为什么取 $\le$ 而不是 $<$"，答案直指完备性：闭球是完备空间里的闭子集，因而继承完备性，而开球未必——🎥 *"If you take a metric space and you're checking something like this, if the metric space is Cauchy complete, then this subset is also Cauchy complete. But this require I have less than or equal to-- because I also could kind of converge to something where you got equality."*（翻译：如果你在度量空间里检验这件事，那么当度量空间柯西完备时，这个子集也柯西完备——但这要求我取"$\le$"，因为序列可能收敛到恰好取等号的边界点。）

我们还需要回忆，从一个 metric space（度量空间）到自身的映射何时是 contracting（收缩）的。映射 $T$ 是度量空间 $(X, d)$ 上的 contracting map（收缩映射），如果存在某个 $c < 1$，使得对一切 $x, y \in X$ 都有

```math
d(T(x), T(y)) \le c\, d(x, y) .
```

> <span style="color:#7f8c8d;">TBB Definition 13.70 (contraction map), §13.9 Contraction Maps, p.582；fixed point（不动点）见 TBB Definition 13.71, p.582</span>

> <span style="color:#1e8449;">**[note] Note（译者注，从 Newton 法到一般度量空间）:**</span> 这个定义是课程早前（讲 Newton 法时）那个一维版本的推广：当时收缩映射是从 $\mathbb{R}$ 到 $\mathbb{R}$ 的，用来找零点。Colding 点明为什么要推广：🎥 *"when we talked about it, we talked about a map from R into R. And then we used this notion of contracting map to finding zeros using Newton's method. But here we're going to use it for something different, and so we need a more general notion."*（翻译：我们当时讨论的映射是从 $\mathbb{R}$ 到 $\mathbb{R}$ 的，用收缩映射的概念配合 Newton 法找零点。但这里我们要用它做完全不同的事，所以需要一个更一般的概念。）收缩的几何含义一句话：映射把点对拉近——🎥 *"So this means that under the map, things get closer together."*（翻译：这意味着在映射作用下，点与点之间靠得更近了。）

我们还将用到早前证明过的下面这个事实：

<span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 2（定理 2）</span>

若 $(X, d)$ 是 Cauchy complete（柯西完备）的度量空间，且 $T : X \to X$ 是收缩映射，则 $T$ 有唯一的 fixed point（不动点）。

> <span style="color:#7f8c8d;">TBB Theorem 13.75 (Banach), §13.9 Contraction Maps, p.584；唯一性部分另见 TBB Lemma 13.72, §13.9, p.582（收缩映射至多有一个不动点）</span>

事实上，这条定理是这样证明的：对任意 $x \in X$，序列

```math
x,\ T(x),\ T^2(x),\ T^3(x),\ \cdots
```

是柯西序列，而且其极限就是 $T$ 的唯一不动点。证明用到了

```math
d\big(T^{n+1}(x), T^n(x)\big) \le c^n\, d(T(x), x) ,
```

从而由三角不等式得到

```math
d\big(T^{n+k}(x), T^n(x)\big) \le \sum_{i=1}^{k} d\big(T^{i+n}(x), T^{i-1+n}(x)\big) \le \sum_{i=1}^{k} c^{i-1+n}\, d(T(x), x) .
```

容易看出，这就蕴含序列 $T^n(x)$ 是柯西序列。

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 把这条定理的完整证明（课上重新过了一遍）拆成可复用的四步——**「相邻估计 → 三角求和 → 几何级数 → 平移取极限」**。① 相邻估计：$d(T^{l+1}(x), T^l(x)) = d(T(T^{l-1}x), T(T^l x)) \le c\, d(T^{l-1}x, T^l x)$，对收缩性质迭代即得 $c^n$ 因子。② 三角求和：把相距 $k$ 步的两项拆成 $k$ 段相邻路程。③ 几何级数：$\sum_{i=1}^{k} c^{i-1+n} \le \frac{c^n}{1-c}$，而 $c < 1$ 保证尾项随 $n \to \infty$ 一致趋于 $0$（注意 $d(T(x), x)$ 是固定常数，因为起点 $x$ 任取后固定）。④ 平移取极限：由完备性 $T^n(x) \to x_\infty$；又 $T^{n+1}(x)$ 只是原序列平移一位，故也收敛到 $x_\infty$：🎥 *"So this one here will still converge to x infinity, because it's just shifted by 1."*（翻译：这个序列仍会收敛到 $x_\infty$，因为它只是平移了 1 位。）另一方面用收缩性质估计 $d(T(x_\infty), T^{n+1}(x)) \le c\, d(x_\infty, T^n(x)) \to 0$，故 $T^{n+1}(x) \to T(x_\infty)$；同一序列不能有两个极限，所以 $x_\infty = T(x_\infty)$。唯一性则更简单：若 $x, y$ 都是不动点，则 $d(x, y) = d(Tx, Ty) \le c\, d(x, y)$，非负数被 $c < 1$ 压缩只能为 $0$。还有一个与 Newton 法的漂亮对比：🎥 *"And this time, we don't even need to make a good choice."*（翻译：这一次，我们甚至不需要做一个好的初始选择。）任意起点都行——最坏只是收敛得慢一些；而 Newton 法当时必须小心选起点，因为它的映射并非处处收缩（见下文引理 2 处的同款困难）。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Lemma 1: Uniqueness propagates（引理 1：唯一性可以从一点向外传播）</span>

我们还将使用下面的引理：

<span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 1（引理 1）</span>

设 $u_1$ 与 $u_2$ 是区间 $I$ 上的 continuous functions（连续函数）。再假设：

- $u_1(x_0) = u_2(x_0)$。
- 若 $u_1(x) = u_2(x)$，则 $u_1$ 与 $u_2$ 在 $x$ 的某个 neighborhood（邻域）内相等。

那么 $u_1 = u_2$。

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 令

```math
J^{+} = \left\{ z \in I \;\middle|\; z \ge x_0 \ \text{ and } \ u_1(x) = u_2(x)\ \text{ for all } \ x \in [x_0, z] \right\} .
```

则 $x_0 \in J^{+}$，所以 $J^{+} \neq \varnothing$。令 $z_0 = \sup J^{+}$。若 $z_0 \in I$，则由连续性有 $u_1(z_0) = u_2(z_0)$。又由于 $u_1$ 与 $u_2$ 在 $z_0$ 的一个邻域内相等，可知 $z_0$ 必须是 $I$ 的右端点。类似地可以证明，在 $z_0$ 左侧的每一点处也有 $u_1 = u_2$。这就证明了引理。$\square$

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">The Picard operator and Lemma 2（皮卡德算子与引理 2）</span>

最后，在 Picard-Lindelöf 定理的证明中我们还需要下一条引理。在这条引理里，$f$ 是如上所述的 $\mathbb{R}$ 上的函数——即 $f$ 可微且 $f$ 的导数连续——而 $g$ 是 $\mathbb{R}$ 上的连续函数。对 $\delta > 0$，在 $[-\delta, \delta]$ 上连续函数构成的空间中，我们对函数 $y$ 定义一个映射 $T$ 如下：

```math
T(y)(x) = a + \int_0^x \left[ f(y(s)) + g(s) \right] ds .
```

注意：当 $y$ 连续时，$T(y)$ 也连续。

> <span style="color:#1e8449;">**[note] Note（译者注，设计的精巧处）:**</span> 这个定义有两处妙笔值得停下来看。第一，整个框架只动用 continuous functions（连续函数）——你不需要先验地知道解可微：🎥 *"the way it's set up is that you just need to use continuous functions. But of course, if you want a solution to this, it means that the function must have a derivative."*（翻译：这套框架的妙处在于你只需要使用连续函数。当然，如果你想要这个方程的解，那就意味着函数必须有导数。）而由 fundamental theorem of calculus（微积分基本定理），$T(y)$ 甚至自动可微：🎥 *"by the fundamental theorem of calculus, this function here is actually even differentiable."*（翻译：由微积分基本定理，这个函数其实还是可微的。）并且恒有 $T(y)(0) = a$——积分区间缩成一点，初值条件被"焊"进了定义。第二，一旦 $y$ 是不动点，它立刻就是解：由微积分基本定理对 $T(y)$ 求导得 $y'(x) = f(y(x)) + g(x)$，加上 $y(0) = a$，正是原方程：🎥 *"So you see that if it is a fixed point, then it is a solution to the differential equation."*（翻译：你看，如果它是不动点，那它就是微分方程的解。）"解方程"就此改写成"找不动点"，而找不动点正是收缩映射定理的专职。

<span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 2（引理 2）</span>

设 $a$ 为常数并令 $R = |a| + 2$。则存在 $\delta > 0$，使得：

- 映射 $T$ 把（度量空间 $\big(C([-\delta, \delta]), d\big)$ 中的）以常值零函数为中心、半径为 $R$ 的球映入其自身。我们把这个球记作 $B_R(0)$，于是有 $T : B_R(0) \to B_R(0)$。
- 映射 $T$ 在 $B_R(0)$ 上是收缩的。

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 令

```math
L_1 = \max_{|z| \le R} |f(z)| ,
```

```math
L_2 = \max_{|x| \le 1} |g(x)| .
```

我们将首先证明：只要把 $\delta_0 > 0$ 选得足够小，$T$ 就把 $B_R(0)$ 映入其自身。也就是说，我们将证明：若 $|y| \le R$ 在 $[-\delta_0, \delta_0]$ 上成立，则 $|T(y)| \le R$。为此，令

```math
\delta_0 = \min\left(1,\ \frac{1}{L_1 + 1},\ \frac{1}{L_2 + 1}\right) .
```

现在设 $|y| \le R$ 且 $|x| \le \delta_0$，那么

```math
\left| T(y)(x) \right| \le |a| + \int_0^x |f(y(s))|\, ds + \int_0^x |g(s)|\, ds \le |a| + \delta_0 L_1 + \delta_0 L_2 \le |a| + 2 = R .
```

这说明 $T$ 把 $B_R(0)$ 映入其自身。

接下来令

```math
M = \max_{|z| \le R} |f'(z)| ,
```

并令

```math
\delta = \min\left(\delta_0,\ \frac{1}{2M + 1}\right) .
```

设 $y_1$ 与 $y_2$ 是 $[-\delta, \delta]$ 上、属于 $B_R(0)$ 的两个连续函数，那么

```math
\left| T(y_1)(x) - T(y_2)(x) \right| = \left| \int_0^x \left[ f(y_1(s)) - f(y_2(s)) \right] ds \right| .
```

对每个 $s$ 把 mean value theorem（中值定理）应用于 $f$，可得介于 $y_1(s)$ 与 $y_2(s)$ 之间的 $z_s$，使得

```math
f(y_1(s)) - f(y_2(s)) = f'(z_s)\left( y_1(s) - y_2(s) \right) .
```

由于 $|y_i| \le R$，对每个 $s$ 我们有

```math
\left| f(y_1(s)) - f(y_2(s)) \right| \le M\, |y_1(s) - y_2(s)| \le M \max |y_1 - y_2| = M\, d(y_1, y_2) ,
```

从而

```math
\left| T(y_1)(x) - T(y_2)(x) \right| \le \delta\, M\, d(y_1, y_2) < \frac{1}{2}\, d(y_1, y_2) .
```

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略：为什么必须缩小区间）:**</span> 整个引理 2 的骨架是两个独立的"限缩"动作。第一步选 $\delta_0$，保证 $T$ 把球映入球——否则根本无法反复迭代：如果映射把迭代点带出收缩有效的范围，收缩性质就再也无法使用了。Colding 用一句话点破动机：🎥 *"But if somehow the map was taking us out of the space where it's contracting, then we couldn't keep applying the contracting map."*（翻译：但如果映射不知怎么把我们带出了它收缩的那个空间，我们就无法继续应用收缩映射了。）这正是 Newton 法当年必须"选好起点"的同款困难：🎥 *"It's exactly like this that this map is not contracting on this whole space. So we have to-- in a way, we have to do the same stuff. We have to make a good choice first."*（翻译：恰恰就是这样，这个映射在整个空间上并不收缩。所以在某种意义上我们必须做同样的事：先做一个好的选择。）第二步再选更小的 $\delta = \min(\delta_0, \frac{1}{2M+1})$，用中值定理把 $f$ 的非线性"压平"成常数 $M$ 乘距离，并让 $\delta M < \frac{1}{2}$——收缩常数是显式的：🎥 *"My constant c will be explicit. It will be just one half, so that certainly is less than 1."*（翻译：我的常数 $c$ 会是显式的，就取 $\frac{1}{2}$，当然严格小于 1。）几个常数选取的小机关也都有出处：$L_1, L_2$ 的下限 $+1$ 是防止分母为零——🎥 *"L is non-negative. In principle, it could be zero. I don't want to worry about that, so I just add 1."*（翻译：$L$ 非负，原则上可能是零，我不想为这事操心，所以直接加 1。）而 $\min$ 里的 $1$ 是为了让工作区间落在单位区间内——🎥 *"the 1 here, it just comes in that I want this here to be a subset of this unit interval."*（翻译：这里的 1，只是为了让它成为单位区间的子集。）至于 $R = |a| + 2$：常数 $2$ 来自 $\delta_0 L_1 + \delta_0 L_2 \le \frac{L_1}{L_1+1} + \frac{L_2}{L_2+1} < 2$ 的那两个"小于 1"。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Proof of the Picard-Lindelöf theorem（皮卡德–林德勒夫定理的证明）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof of the Picard-Lindelöf theorem（皮卡德–林德勒夫定理的证明）.* 设 $T$ 如上定义，$R$ 与 $\delta > 0$ 由引理 2 给出。$T$ 的 fixed point（不动点）是满足 $T(y) = y$ 的函数 $y$。由 fundamental theorem of calculus（微积分基本定理），若 $y$ 是 $T$ 的不动点，则

```math
y'(x) = \big( T(y) \big)'(x) = f(y(x)) + g(x) .
```

而且 $y(0) = a$。换言之，$T$ 的任何不动点都是这个 ODE 的解。

我们需要证明解是唯一的。设 $y$ 是任何一个解，那么由微积分基本定理，

```math
y(x) = a + \int_0^x y'(s)\, ds = T(y)(x) .
```

注意：即使 $y$ 所定义的区间 $I$（包含 $0$）与 $[-\delta, \delta]$ 不同，上式依然成立。由此我们得到：任何解都是 $T$ 的不动点。由于 $T$ 在 $B_R(0)$ 上收缩，故满足 $|y| \le R$ 的不动点是唯一的。

一般地，设 $y_1$ 与 $y_2$ 是分别定义在包含 $0$ 的区间 $I_1$ 与 $I_2$ 上的两个解。由以上论证可知它们在 $0$ 的某个邻域内相等。引理 2 中在 $0$ 的小邻域里证明唯一性的论证，同样适用于任何其他点的小邻域。于是由引理 1 可知，$y_1$ 与 $y_2$ 处处相等。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，课堂现场与收尾）:**</span> 实际的课堂在引理 2 的中值定理一步戛然而止——时间用尽，Colding 决定把剩余部分留到下次课：🎥 *"So I will keep you in suspension, and so we'll pick up from here on Tuesday."*（翻译：我先让你们悬在半空，周二我们从这里继续。）他还预告了开场时那个"听起来有点疯狂"的方法（用度量空间解微分方程）值得等待的原因：这套看似迂回的抽象路线，事后看几乎是 optimal（最优的）——🎥 *"this method, which seems a little crazy in a way because it's bringing in all these things, why it turned out to be basically optimal."*（翻译：这个方法——它把这么多东西都拉进来，乍看有点疯狂——为什么最终证明基本上是最优的。）从阅读的角度，本讲义文本已经给出了完整的论证链条：不动点 $\Leftrightarrow$ 解、闭球上的收缩性、以及引理 1 的"邻域拼接"把局部唯一性推广成整体唯一性。
