### <span style="color:#2471a3;">**[lecture]**</span> <span style="color:#c0392b">Series（级数）</span>

假设 $a_n$ 是一个 sequence（序列），我们可以如下构造一个新的序列 $s_n$。令

```math
s_1 = a_1, \qquad s_2 = a_1 + a_2, \qquad s_3 = a_1 + a_2 + a_3,
```

一般地，

```math
s_n = a_1 + \cdots + a_n = \sum_{i=1}^{n} a_i.
```

序列 $s_n$ 称为**部分和序列（sequence of partial sums）**。级数 $\sum_{i=1}^{\infty} a_i$ **收敛（converges）**当且仅当序列 $s_n$ 收敛；若收敛，我们也把极限记为 $\sum_{i=1}^{\infty} a_i$。

> <span style="color:#7f8c8d;">TBB §3.4, p.83</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注真正处理的是 well-definedness（合法性）问题：为什么 series（级数）不能被直接定义成无穷多项相加，而必须绕着 partial sum（部分和）走一圈。把一个还没被定义过的对象先假设存在，是逻辑上的循环；把有限次加法与 limit（极限）这两件已经良定义的事串起来，才是不欠债的路线。
>
> 机制分三层。第一层，有限次加法没有歧义：对每个固定的 $n$，$\sum_{k=1}^{n} a_k$ 是一个实数，因为实数加法满足结合律与交换律，加的顺序不影响结果。第二层，把这些 finite sum（有限和）按 $n$ 重新排成一个新的 sequence（序列）$s_n$，问题于是从无穷相加转成这个 sequence（序列）是否稳定，而 convergence（收敛）的 $\varepsilon$-$N$ 定义在第四讲已经给出，可以直接调用。第三层，只有当 $(s_n)$ 有 limit（极限）时，我们才把这个 limit（极限）命名为 $\sum_{k=1}^{\infty} a_k$——符号是事后命名，不是事前对象。三层走完，series（级数）被完整地化归成 sequence（序列），此后所有关于 sequence（序列）的定理都自动对 series（级数）生效。
>
> 这套定义还顺手把一条常被当成直觉的规则变成定理：若 series（级数）收敛，则项必须趋于零。推导只有一行，$a_n = s_n - s_{n-1}$，而两个收敛 sequence（序列）之差仍收敛，于是 $a_n \to 0$。方向要盯住：这是 necessary condition（必要条件），反过来不成立，调和级数那一节会给反例。定义的价值正在这里——项趋于零从严密的定义被机械地推出来之后，你才知道它什么时候会失效，而直觉恰恰在这种地方最容易骗人。
>
> 定义还立刻给出第二条推论，使用频率比第一条更高：改动 series（级数）的有限多项，不改变它收敛与否。理由是 partial sum（部分和）序列只在前面有限个位置上被改动，从某个下标起两条 partial sum（部分和）序列逐项相同，而 sequence（序列）的收敛性只由尾巴决定。这条看似平淡的性质是所有检验只要求"最终成立"的许可证：comparison test（比较检验）里的不等式只要从某一项开始成立就够，ratio test（比值检验）里的比率只要在尾部被压住就够，全靠这一条撑住。你在 CSAPP 里见过同一个思想——渐进复杂度只看输入足够大时的行为，小规模的特例不改变结论，两者都是"尾巴决定命运"。
>
> 做一个能自己复核的演算。取 geometric series（几何级数）$c = 1/2$，有 $s_n = 2 - 2^{-n}$，于是 $s_{10} = 1.9990234375$，与 limit（极限）$2$ 相差 $2^{-10} = 0.0009765625$；$s_{20} = 1.9999990463256836$，误差 $2^{-21} \approx 4.77 \times 10^{-7}$。误差按指数缩小，要让误差低于 $10^{-6}$ 只需 $n \ge 21$，定义里的那个 $N$ 在这里可以手算出具体值。反面再看 harmonic series（调和级数）：$H_{10} = 2.928968254$、$H_{1000} = 7.485470861$、$H_{10^{6}} = 14.39272672$。项确实在趋于零，总和却还在爬，说明那条 necessary condition（必要条件）管不住总和。
>
> 跨课程连接落在 CSAPP 第 2 章的浮点与第 3 章的机器级运算。floating point（浮点）加减在有限精度下不满足结合律：在 double precision（双精度）下算 $(10^{16} + 1) - 10^{16}$，结果是 $0$ 而不是 $1$，因为 $1$ 落在 $10^{16}$ 的 rounding（舍入）误差之下被吞掉。这意味着无穷多项相加在机器上连良定义都做不到——先加谁后加谁，结果就不同。series（级数）的定义恰好把这个坑绕过去：它把无限操作换成有限的 partial sum（部分和）加一个 limit（极限），实算时只算到第 $n$ 项再估计 tail（余项）。区别要讲清：数学定义要求 limit（极限）精确存在，实现只保证 tail（余项）被 machine epsilon（机器精度）压住；而在 $|c| \lt 1$ 的 geometric series（几何级数）上两者刚好对齐，因为余项 $2^{-n}$ 会在 $n = 53$ 附近跌破 double precision（双精度）的 $2^{-53}$。
>
> 回到正文：那句先有 sequence（序列）再构造新 sequence（序列）不是绕弯子，而是这个符号唯一合法的出生方式。你把每个关于 series（级数）的问题翻译成关于 $(s_n)$ 的问题，就永远有具体的东西可抓，而不是面对一串没有定义的点点点。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Geometric Series（几何级数）</span>

```math
\sum_{i=0}^{\infty} c^i
```

这个级数**恰好当 $|c| < 1$ 时收敛**。

> <span style="color:#7f8c8d;">TBB §3.4.2, p.85</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要把 geometric series（几何级数）的地位讲透：它不是众多例子里的一个，而是整套收敛检验体系的 standard of comparison（量尺）。它之所以能当量尺，是因为同时具备两个别的 series（级数）给不出的性质——收敛侧有精确的闭式，发散侧能被一眼看出无界，所以同一件工具可以从上面压也可以从下面顶。
>
> 先看那个被背下来的公式是怎么长出来的。令 $S_n = 1 + c + \cdots + c^{n}$，乘 $c$ 得 $cS_n = c + \cdots + c^{n+1}$，相减时中间项两两抵消，只剩 $(1-c)S_n = 1 - c^{n+1}$，于是 $S_n = \frac{1-c^{n+1}}{1-c}$。这个抵消不是巧合：$c^{k}$ 是一阶线性递推 $x_{k+1} = c x_k$ 的解，凡是 $x_{k+1} = c x_k + b$ 型的 sequence（序列），都能用一个常数位移化成纯等比，这也顺带解释了特解为什么是 $\frac{1}{1-c}$。换成 6.042J 的语言，就是 generating function（生成函数）把递推方程变成代数方程，再把 $\frac{1}{1-cz}$ 展开回系数序列——两条路给出同一个答案，因为解的是同一个线性结构。
>
> 第二层要问的是：为什么它当得起量尺。任取一个检验，它做的判断无非两种——某项序列被某个 geometric series（几何级数）压住，或者它压住了某个发散的 geometric series（几何级数）。也就是说，所有判断最终都被翻译成对参数 $|c|$ 与 $1$ 的比较，而 $|c|$ 与 $1$ 的大小关系恰好把整个几何族切成收敛与发散两半，只有边界 $|c| = 1$ 失效。同一把尺子既能从上往下压、又能从下往上顶，这是 $p$ 级数做不到的：$p$ 级数自己还要靠别的工具来判定，它是被量的对象，不是量尺。
>
> 边界那一侧不必动用求和公式。$|c| \ge 1$ 时项 $|c|^{n}$ 不趋于零，necessary condition（必要条件）直接垮掉，series（级数）发散；先看项本身，过不了这一关就不必启动更重的机器。$c = -1$ 更细一层：partial sum（部分和）在 $1, 0, 1, 0, \dots$ 之间振荡，项有界却不趋于零，limit（极限）仍不存在。这两种失效方式值得分开记住，因为后面的发散判定几乎都先走这条路。
>
> 给四个具体数字，把收敛速度的差别摆出来。$c = 1/2$ 时 $S_{10} = 1.9990234375$，误差 $2^{-10} = 9.77 \times 10^{-4}$，要到误差低于 $10^{-4}$ 需要 $n \ge 14$。$c = 0.9$ 时和是 $10$，但 $S_{10} = 6.8618940391$、$S_{20} = 8.9058101087$，同一条 $10^{-4}$ 的标准需要 $n \ge 109$，代价相差接近八倍。$c = 0.99$ 时更极端：$S_{100} = 63.7627982140$，算满一千项才到 $S_{1000} = 99.9957260465$，离 $100$ 还差 $0.0043$。$c = 2$ 时 $S_{10} = 2047$、$S_{20} = 2097151$，每加一项翻一倍，无界一眼可见。四个数字合起来说明：收敛与否由 $|c|$ 决定，收敛多快由 $1 - |c|$ 决定，后者在工程里比前者更值钱。
>
> 跨课程连接有两处。6.006 的递归树分析中，若第 $k$ 层代价是首层的 $c^{k}$ 倍且 $c \lt 1$，总代价就被首层放大 $\frac{1}{1-c}$ 倍，Master theorem（主定理）的 case 1 与 case 3 判的正是这个 geometric series（几何级数）收不收敛。CSAPP 第 6 章的 cache（缓存）层次同理：L1 到 DRAM 的访问延迟大致按 $1:10:100$ 的几何比例放大，平均访问时间是按命中率加权的有限和，比率 $c = 0.1$ 意味着最内几层就吃掉了九成以上的时间。区别在于：递归树是确定性的代价累加，cache（缓存）是概率加权的期望值，一个是计数，一个是均值，形式同构而语义不同。
>
> 所以量尺这个词是准确的：后面的 ratio test（比值检验）与 root test（根值检验）问的其实是同一句话——这个 series（级数）的项，最终能不能被某个 geometric series（几何级数）压住；能，就收敛，不能，就得换更细的尺子。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Harmonic Series（调和级数）</span>

```math
\sum_{n=1}^{\infty} \frac{1}{n}
```

这个级数是**发散（divergent）**的。

> <span style="color:#7f8c8d;">TBB §3.4.2, p.85</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要立的是一个反例的坐标：harmonic series（调和级数）$\sum \frac{1}{n}$ 的每一项都老老实实趋于零，necessary condition（必要条件）完全过关，sum（总和）却发散。它把"必要条件不等于充分条件"从口号变成可以指认的对象，也是 $p$ 级数家族里唯一站在边界上的那个点。
>
> 标准证明用 grouping（分组放缩）。把项按 $2$ 的幂切段：第 $k$ 段从 $\frac{1}{2^{k-1}+1}$ 到 $\frac{1}{2^{k}}$，共 $2^{k-1}$ 项，每项都不小于 $\frac{1}{2^{k}}$，所以这一段的 sum（和）至少是 $2^{k-1} \cdot \frac{1}{2^{k}} = \frac{1}{2}$。段数无限，每段至少交出 $\frac{1}{2}$，partial sum（部分和）因而无界，写成一行就是 $H_{2^{m}} \ge 1 + \frac{m}{2}$。这个做法的要点是：它不去估具体的 sum（和），只证明 partial sum（部分和）能无限往上抬，属于用下界打穿非负项定理的正面做法。
>
> 把这条界当工具用一次：$m = 10$ 时它断言 $H_{1024} \ge 1 + 5 = 6$，实际算出 $H_{1024} = 7.5091756723$；$m = 20$ 时断言 $H_{10^{6}} \ge 11$，实际是 $14.39272672$。界是粗的，但它只需要"随 $m$ 无限增长"这一条性质，精度被换成了普适性——这正是放缩类证明的取舍：宁可估得松，也要让这个不等式对每一段都成立。
>
> 把两件反例并排摆，位置就清楚了：geometric series（几何级数）在 $|c| \ge 1$ 时过不了第一道安检（项趋于零），属于一眼出局；harmonic series（调和级数）是过了第一道才倒下的，属于退到最后一关被拦。第二类反例才真正教人，因为它证明 necessary condition（必要条件）与 sufficient condition（充分条件）之间有实质空隙，不是只差一个技术细节。
>
> 为什么非按 $2$ 的幂切？因为 $\frac{1}{n}$ 在区间 $[2^{k-1}, 2^{k}]$ 上的总贡献恰好是常数：段长翻倍、每项减半，乘积不变。把这条观察搬到 $p$ 级数 $\sum n^{-p}$ 上，同一段上的贡献正比于 $2^{k(1-p)}$：$p \gt 1$ 时它以 $2$ 的负幂衰减，段和可求和；$p = 1$ 时指数归零，段和恒定，这就是临界的全部含义。所以"临界"不是形容词，而是指数 $1 - p$ 在何处归零的一次计算；后面的 condensation test（凝聚检验）就是把这条分段思想正式化的产物。
>
> 数字见分晓。$H_{10} = 2.928968254$、$H_{1000} = 7.485470861$、$H_{10^{6}} = 14.39272672$；而 $\ln 1000 + \gamma = 6.907755279 + 0.577215665 = 7.484970944$，与 $H_{1000}$ 只差 $5 \times 10^{-4}$ 量级，说明 $H_n \approx \ln n + \gamma$ 在 $n = 1000$ 已经很好用。反过来解方程：要让 $H_n$ 摸到 $100$，需要 $n \approx e^{100 - \gamma} \approx 1.51 \times 10^{43}$；按每纳秒加一项估算，也是 $4.8 \times 10^{26}$ 年量级。发散真的存在，但任何物理过程都追不上它，这正是"发散"与"爆炸"必须分开的理由。
>
> 跨课程连接用 CSAPP 第 6 章的 cache（缓存）层次。真实负载的访问频次常近似 Zipf distribution（Zipf 分布：第 $k$ 热门块的访问次数正比于 $\frac{1}{k}$，用来描述极不均匀的访问热度；这里只用它的期望公式）。它的期望访问次数落在 $H_m$ 上，于是每多加一层 cache（缓存）所覆盖的 miss（缺失）比例只按对数增长，而不是像等比模型那样迅速收敛。这和调和级数发散是同一件事：$H_m$ 能长到无穷，速度却是 $\ln m$，所以加层永远有用，却永远只换来对数级的增量。区别在于：cache（缓存）里是概率权重下的期望，series（级数）里是确定的逐项求和，形式同构，一个是统计量，一个是极限。
>
> 所以这条注的落点是位置感：harmonic series（调和级数）是 $p$ 级数家族的边界标本，$p \gt 1$ 一侧收敛、$p \le 1$ 一侧发散，而边界这一侧的证明用的正是"等比分段 + 每段常数贡献"这个可反复复用的模板。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Absolutely Convergent（绝对收敛）</span>

我们说级数 $\sum_{n=0}^{\infty} a_n$ 是**绝对收敛（absolutely convergent）**的，如果级数 $\sum_{n=0}^{\infty} |a_n|$ 是收敛的。

绝对收敛蕴含收敛，但反过来不成立。

> <span style="color:#7f8c8d;">TBB §3.5.3, p.92</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要立的是 absolute convergence（绝对收敛）通往 convergence（收敛）的最短路径，以及这条路径的端点：反方向不成立，反例就是 alternating harmonic series（交错调和级数）。
>
> 第一条路走 Cauchy criterion（Cauchy 判据），即第六讲的收敛准则：series（级数）收敛等价于它的 partial sum（部分和）是 Cauchy sequence（Cauchy 序列）。若 $\sum |a_n|$ 收敛，则对任意 $\varepsilon \gt 0$ 存在 $N$，使 $m \gt n \ge N$ 时 $\sum_{k=n+1}^{m} |a_k| \lt \varepsilon$。接上 triangle inequality（三角不等式）就有 $|\sum_{k=n+1}^{m} a_k| \le \sum_{k=n+1}^{m} |a_k| \lt \varepsilon$，于是原 series（级数）的 partial sum（部分和）也是 Cauchy sequence（Cauchy 序列），从而收敛。整条推理没有用到 limit（极限）的值，只用"尾巴能被压到任意小"——这正是 Cauchy criterion（Cauchy 判据）相对 $\varepsilon$-$N$ 定义的唯一优势：把"知道 sum（和）是多少"换成"知道 tail（余项）有多小"。
>
> 第二条路更能说明 absolute convergence（绝对收敛）这个名字的来历。把每项拆成正部与负部，$a_n^{+} = \max(a_n, 0)$、$a_n^{-} = \max(-a_n, 0)$，两者都非负且都不超过 $|a_n|$，所以 $\sum a_n^{+}$ 与 $\sum a_n^{-}$ 各自收敛，而 $a_n = a_n^{+} - a_n^{-}$ 是两条收敛 series（级数）之差。换言之，绝对收敛不是"更强的一种收敛"，而是把收敛性拆给两条非负 series（级数）分别承担、再让它们相减；非负 series（级数）只要 partial sum（部分和）有上界就收敛，这一步恰好用上本讲开头的非负项定理。
>
> 这立刻解释了条件收敛为什么怕重排。若 $\sum |a_n|$ 发散而 $\sum a_n$ 收敛，正部与负部的 series（级数）必须都发散到无穷——否则由第二条路，原 series（级数）就会绝对收敛。两边都是无穷，sum（和）就完全靠抵消的时序决定：先花光所有正项，partial sum（部分和）奔向正无穷；先花光所有负项，奔向负无穷。Riemann rearrangement theorem（Riemann 重排定理）把这个自由度用尽，说任意实数都能被某个重排实现为 sum（和）。所以"条件"二字指的是收敛依赖项的顺序，而不是"有条件地收敛"。
>
> 数字上更直白。alternating harmonic series（交错调和级数）的 $S_{10} = 0.6456349206$、$S_{1000} = 0.6926474306$，limit（极限）是 $\ln 2 = 0.6931471806$；而同一批项的 absolute value（绝对值）之和在第 10 项就已经是 $H_{10} = 2.928968254$。正负抵消把 $2.93$ 压成 $0.65$，而且这个抵消按秩序发生、可复现。误差也能量化：$n = 1000$ 时差为 $4.9975 \times 10^{-4}$，与 $\frac{1}{2n} = 5 \times 10^{-4}$ 吻合，说明 convergence（收敛）速率只有 $O(\frac{1}{n})$，残量由第一项没被抵消掉的尾巴决定。
>
> 重排能把 sum（和）推到多远，可以手算一个片段。原 series（级数）的前 4 个正项是 $1 + \frac{1}{3} + \frac{1}{5} + \frac{1}{7} = 1.6761904762$，先扣掉一项 $\frac{1}{2}$ 得 $1.1761904762$，再接上第 5 到第 8 个正项 $\frac{1}{9} + \frac{1}{11} + \frac{1}{13} + \frac{1}{15} = 0.3456099456$，partial sum（部分和）已经到 $1.5218004218$，而原来的 sum（和）只有 $\ln 2 = 0.693$。这条"先攒正项、再补一项负项"的配方就是重排定理证明的骨架：正项组越攒越大，减掉一项负项只是舀走一勺，水位照样往上走。
>
> 跨课程连接落在 CSAPP 第 2 章的浮点。数学上绝对收敛的 series（级数）任意重排后 sum（和）不变，条件收敛的不行；到了机器上，这条分界变成误差放大的分界。浮点求和时每项都带一个与自身大小成正比、与 sum（和）大小无关的相对误差，"大项吃掉小项"的现象叫 catastrophic cancellation（灾难性抵消）：绝对收敛的 series（级数）里正负两侧都在同一量级上收敛，重排只改变 rounding（舍入）误差的累积次序；条件收敛的 series（级数）里正负两侧各自无界，任何重排都可能让中间结果先冲到极大再跌回来，误差被彻底放大。区别要说清：数学的重排是无穷多次交换后取 limit（极限），浮点的重排只是有限精度下的误差传播，但两者指向同一句话——抵消型求和的稳定性来自绝对收敛。
>
> 一句话收束：absolute convergence（绝对收敛）把 sum（和）的稳定性写进了定义，条件收敛把稳定性交给了顺序，而顺序恰恰是无穷和唯一不能随便动的东西。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem: 非负项级数收敛 ⟺ 部分和有上界</span>

一个由非负数组成的级数（$a_n \ge 0$）

```math
\sum_{i=0}^{\infty} a_i
```

**收敛当且仅当**部分和序列 $s_n$ 是**有上界的（bounded from above）**。

> <span style="color:#7f8c8d;">TBB §3.5.1, p.91</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要立的是本讲的地基：非负项定理把"series（级数）收敛"整个翻译成"partial sum（部分和）bounded from above（有上界）"，极限存在性被换成了上界存在性，从此判收敛不必再去猜那个 sum（和）究竟是多少。
>
> 为什么可以这样换？因为非负性让 partial sum（部分和）单调不减：$s_{n+1} = s_n + a_{n+1} \ge s_n$。单调 sequence（序列）收敛当且仅当它有上界，这正是第五讲的 monotone convergence theorem（单调收敛定理）。而这条定理的证明并不玄：设 $B = \sup_n s_n$，则对任意 $\varepsilon \gt 0$ 存在 $N$ 使 $s_N \gt B - \varepsilon$；由单调性，$n \ge N$ 时 $B - \varepsilon \lt s_N \le s_n \le B$，于是 $|s_n - B| \lt \varepsilon$，sequence（序列）收敛到 $B$。所以定理真正的内容是：这个 series（级数）的 sum（和）就是 partial sum（部分和）全体所成集合的 supremum（上确界），极限值不用另算，它已经摆在那里了。
>
> 非负这个前提是承重的，去掉它定理当场失效。取 $a_n = (-1)^{n+1}$，partial sum（部分和）在 $1$ 与 $0$ 之间来回跳，有界却显然不收敛；单调性一旦消失，"有上界"就退化成一条毫无用处的必要条件。所以这条定理应当读作"非负加有界合起来才收敛"，而不是"有界即收敛"。
>
> 反方向同样有用：若 partial sum（部分和）无界，则对每个 $M$ 都存在 $n$ 使 $s_n \gt M$，再由单调性，此后的项一直大于 $M$，partial sum（部分和）发散到正无穷。这解释了为什么所有"判发散"的动作最后都能收口成"我构造不出上界"：证明 $p \le 1$ 的 $p$ 级数发散，本质就是在证明它的 partial sum（部分和）能越过任意给定的数。
>
> 和第七讲的 Bolzano–Weierstrass theorem（Bolzano–Weierstrass 定理）对照，更能看清它的位置：那条定理只保证有界 sequence（序列）里有收敛的 subsequence（子列），子列以外的项可以继续乱跑；monotone convergence theorem（单调收敛定理）因为有单调性，直接把"某个子列收敛"升级成"整条 sequence（序列）收敛到同一个值"。两条定理都在用完备性，一条用聚点，一条用上确界，是同一块地基的两种用法。
>
> 算一个带数字的对照。$\sum \frac{1}{n^2}$ 的 partial sum（部分和）是 $S_{10} = 1.5497677312$、$S_{100} = 1.6349839002$、$S_{1000} = 1.6439345667$，其 supremum（上确界）为 $\frac{\pi^2}{6} = 1.6449340668$。每把项数乘十，与上确界的距离也缩小约十倍：$n = 100$ 时差 $9.95 \times 10^{-3}$，$n = 1000$ 时差 $9.995 \times 10^{-4}$，与 $\frac{1}{n}$ 同阶，这就是 $p = 2$ 的可算收敛速度。换成 $\sum \frac{1}{n^2+1}$，连 sum（和）都不必知道：逐项有 $\frac{1}{n^2+1} \lt \frac{1}{n^2}$，$S_{1000} = 1.0756745476$，上界直接借用上一条的 $1.6449$，判据一步到位。
>
> 跨课程连接用 6.006 的 amortized analysis（摊还分析）。势能法的结论形如"前 $n$ 次操作的总代价不超过 $c n$"，本质上是给累计代价 sequence（序列）找一个上界，再说它不会回落；CSAPP 第 6 章讨论 cache（缓存）平均访问时间的上限，也是同一件事。区别在于：摊还分析给的 $c$ 是估出来的、可以很松，够用就行；而非负项定理里上界与 sum（和）是同一个数，supremum（上确界）既给结论又给数值，把"够用的界"升级成了"精确的值"。
>
> 所以后面每一条检验，最后一步几乎都是同一个动作：给 partial sum（部分和）找一个上界，或者证明找不到。comparison test（比较检验）借的是邻居的上界，ratio test（比值检验）借的是 geometric series（几何级数）的上界，root test（根值检验）借的是 $r_0^{n}$ 的上界——工具不同，收口处只有这一条。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Convergence Tests（收敛检验方法一览）</span>

为了帮助判断一个级数是否收敛，有一系列检验方法：

- **Comparison test（比较检验）**。
- **Ratio test（比值检验）**。
- **Root test（根值检验）**。
- 其他检验方法我们以后讨论。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答"为什么需要这么多检验"。答案是：每个检验都是一次 lossy compression（有损压缩），把整个项 sequence（序列）压成有限几个数；压得越狠，适用面就越窄。comparison test（比较检验）几乎不压，所以必须在外部另找基准；ratio test（比值检验）与 root test（根值检验）把一个 sequence（序列）压成单个 limit（极限），自给自足，但只认几何级数那种衰减方式。
>
> 拆开看信息需求。comparison test（比较检验）要求你手里另有一个已知收敛或发散的 series（级数），知识成本最高，可结论最强：它不限制项的形状，只要逐项不等式成立就管用。ratio test（比值检验）只看相邻两项的 ratio（比值），信息需求极小，能力也极小：它只回答"项最终是不是按几何速率衰减"，回答不了多项式级别的衰减。这不是一强一弱的选择题，而是分辨率和成本的兑换率。
>
> 失明是必然，不是技术缺陷。若一个检验的输入只是单个实数 $r$，输出只有收敛、发散、无法判定三种，那么把 $\frac{1}{n}$ 与 $\frac{1}{n^2}$ 同时映射到 $r = 1$ 并输出"无法判定"，已经是它能给出的最诚实结果——两个真相不同的对象被压到同一个特征值上，任何只依赖该特征值的判据都不可能把它们分开。要分开，只能换基准：把 geometric series（几何级数）换成 $p$ 级数，或者把整段尾巴拿去做积分、做凝聚，也就是主动引入更多信息。
>
> 一个超级检验不可能存在，理由不在工程而在信息。判收敛要看整条 tail（尾巴）的联合行为，而任何能一次算完的检验，输入必然是项 sequence（序列）的有限摘要；给定任何一个这样的摘要，都能构造两条 series（级数）让它给出同一个值，却一条收敛一条发散——$\frac{1}{n}$ 与 $\frac{1}{n^2}$ 在 ratio（比值）这一摘要下就是活证据。所以检验族不会被压缩成一个，只会被组织成一个分辨率递增的序列。
>
> 用三个例子把这条谱系走一遍。$\sum 2^{-n}$ 与 $\sum \frac{2^{-n}}{n}$：后者逐项小于前者，而前者 sum（和）为 $1$，comparison test（比较检验）一步结束，后者 sum（和）实际是 $\ln 2 = 0.6931471806$。$\sum \frac{1}{n!}$：ratio（比值）为 $\frac{1}{n+1} \to 0$，ratio test（比值检验）一步判定，sum（和）是 $e - 1 = 1.7182818285$。$\sum \frac{1}{n}$：ratio（比值）为 $\frac{n}{n+1} \to 1$，ratio test（比值检验）交白卷，只能退回分组放缩判发散。三个例子正好落在"外部基准、自身特征、特征失效"三级台阶上。
>
> 跨课程连接放在 6.006 的递推求解工具链上。Master theorem（主定理）把递归式压成三种情形，遇到 $T(n) = 2T(n/2) + n \log n$ 这类形式就交白卷，于是需要 Akra–Bazzi 一类更一般的方法；这套"强工具—盲区—更强工具"的谱系与收敛检验完全同构。区别在于：算法分析追求 $\Theta$ 量级，常数可以丢；收敛检验只关心收敛与否，反而对常数方向敏感——comparison test（比较检验）里那个 $\le$ 的系数必须真的不超过 $1$。
>
> 所以检验多不是历史包袱，而是设计上的必然：每多一个检验就多一层分辨率，而每提一层分辨率，都要付出更多计算或更多外部信息作为代价。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Comparison Test; Version 1（比较检验，第 1 版）</span>

假设 $a_n$ 与 $b_n$ 是两个序列，且满足

```math
0 \le a_n \le b_n.
```

如果 $\sum_{n=1}^{\infty} b_n$ 收敛，那么 $\sum_{n=1}^{\infty} a_n$ 也收敛。

> <span style="color:#7f8c8d;">TBB §3.6.2, p.96（Direct Comparison Test I）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要把 comparison test（比较检验）第 1 版的机制拆成一条可以照抄的链子，我管它叫one-sided squeezing（单向挤压法）：只把待判 series（级数）从一个方向压住，另一个方向由非负性免费提供。
>
> 证明是四步连锁，每一步都能点名到一条已经证过的结果。第一步，逐项不等式 $0 \le a_n \le b_n$ 成立时，由有限次加法的单调性得 $\sum_{k=1}^{n} a_k \le \sum_{k=1}^{n} b_k$；第二步，若 $\sum b_n$ 收敛，它的 partial sum（部分和）有上界 $B$，于是 $a$ 侧的 partial sum（部分和）也被 $B$ 压住；第三步，"非负且有上界"正好是本讲非负项定理的入口；第四步，由 monotone convergence theorem（单调收敛定理）把上界兑现成 limit（极限）。每一环都只调用前面的结果，所以它可以整块当模板抄。
>
> 非负性是承重的，去掉就塌。若 $a_n$ 可以取负，partial sum（部分和）不再单调，$s_n$ 可以在上界之下无限次起落而不收敛，取 $a_n$ 为 $2, -1, 2, -1, \dots$ 就能看到：partial sum（部分和）有界，却没有 limit（极限）。所以第 1 版的完整条件是"非负 + 被压住"，缺一不可。
>
> 方向错误是本条最容易犯的错，用反例钉住。取 $a_n = \frac{1}{n^2}$、$b_n = \frac{1}{n}$，则 $0 \le a_n \le b_n$ 恒成立，可 $b$ 发散、$a$ 收敛，$\sum \frac{1}{n^2} = 1.6449340668$。所以"大级数发散"对小级数一个字也说不出——大级数尾巴厚，不代表夹在它里面的那条也厚。四条推理只有两条成立：大收敛推小收敛，小发散推大发散，后一条是前一条的逆否命题。
>
> 还有一处常被忽略的宽松：不等式不必对每一项成立，只要"最终"成立。依据是注 1 的那条推论——改动 series（级数）的有限多项不改变收敛性。所以写"存在 $N$，当 $n \ge N$ 时 $a_n \le b_n$"是合法的，前有限项既不进上界也不改结论。抽掉这条宽松，检验在实践中会难用得多，因为你几乎总要在小 $n$ 处应付分母为零或不等式反号的情形。
>
> 把正文那个例子算到底。$a_n = \frac{2^{-n}}{n}$、$b_n = 2^{-n}$，逐项不等式成立，而 $\sum_{n=1}^{\infty} 2^{-n} = 1$ 是 geometric series（几何级数），所以上界取 $1$ 就够。实际 sum（和）是 $\sum \frac{2^{-n}}{n} = \ln 2 = 0.6931471806$，算到第 $30$ 项得 $0.6931471805$，误差只有 $2.9 \times 10^{-11}$。这说明比较检验给的是"存在上界"，精度差得远，但判收敛足够了；如果你还想知道 sum（和）的值，那得靠别的展开。
>
> 上界还附带一份可用的误差预算，这是它在工程上比"能判收敛"更值钱的地方。$\sum_{k \gt n} b_k$ 本身就把 tail（余项）压住了：对 $\sum \frac{2^{-n}}{n}$，剩余项被 $\sum_{k \gt n} 2^{-k} = 2^{-n}$ 压住，取 $n = 30$ 得界 $9.31 \times 10^{-10}$，而实际误差是 $2.9 \times 10^{-11}$，界松了约三十二倍。界粗但不假，这正是"先保证，再优化"的顺序：先拿一个能写进文档的保证，再考虑把常数收紧。
>
> 跨课程连接放在 6.006 的递归不等式。解 $T(n) \le 2T(n/2) + n$ 时也是逐层相加、与首层比较，得到 $O(n \log n)$ 这类界。区别有两处：算法分析允许丢常数、只求 $\Theta$ 量级，而 comparison test（比较检验）里那个系数必须真的不超过 $1$，放大一点点结论就没了；算法分析的界对每个 $n$ 都成立，而这里的上界只需要最终成立。
>
> 一句话收束：单向挤压法的全部本事在于"只压一边"，另一边由 $a_n \ge 0$ 白送；一旦项可能为负，这套模板立刻失效，必须换成 Cauchy criterion（Cauchy 判据）那条更贵的路。

<span style="color:#2471a3;">**[example]**</span> **Example（例）:** 级数

```math
\sum_{n=1}^{\infty} \frac{2^{-n}}{n}
```

是收敛的。事实上，令

```math
a_n = \frac{2^{-n}}{n}, \qquad b_n = 2^{-n},
```

则 $0 \le a_n \le b_n$，且由于 $\sum_{n=1}^{\infty} b_n = \sum_{n=1}^{\infty} 2^{-n}$ 是一个收敛的几何级数，由比较检验（第 1 版）知 $\sum_{n=1}^{\infty} a_n$ 收敛。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Comparison Test; Version 2（比较检验，第 2 版）</span>

假设 $a_n$ 与 $b_n$ 是两个序列，$b_n \ne 0$，且

```math
\lim_{n \to \infty} \frac{a_n}{b_n} = L \ne 0.
```

则级数 $\sum_{n=1}^{\infty} a_n$ **收敛当且仅当**级数 $\sum_{n=1}^{\infty} b_n$ 收敛。

> <span style="color:#7f8c8d;">TBB §3.6.3, p.98（Limit Comparison Test I）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要立的是 comparison test（比较检验）第 2 版的机制：把"逐项不等式"这种逐点的、苛刻的条件，换成"最终同阶"这种只在极限意义下成立的条件，你付出的代价是必须多检查一个数——那个比值的 limit（极限）不能是零。
>
> 机制分两半，一半是夹逼，一半是对称性。若 $\frac{a_n}{b_n} \to L$ 且 $L \gt 0$，取 $\varepsilon = \frac{L}{2}$，则存在 $N$，当 $n \ge N$ 时 $\frac{L}{2} \le \frac{a_n}{b_n} \le \frac{3L}{2}$，也就是 $\frac{L}{2} b_n \le a_n \le \frac{3L}{2} b_n$。对左边用一次第 1 版得到 $a$ 可控于 $b$，对右边用一次得到 $b$ 可控于 $a$，两次合起来才有"同收敛或同发散"。这里的关键是夹逼的两侧都由同一个 $L \gt 0$ 提供，所以它能双向走；一旦 $L = 0$，夹逼只剩 $a_n \le \varepsilon b_n$ 一侧，对称性当场断裂。
>
> 把三种情形一次讲清，因为教材例子里只演示了 $L$ 有限正这一种。$L$ 有限且为正：双向，两条 series（级数）同敛散。$L = 0$：只有"$b$ 收敛则 $a$ 收敛"这一向，$b$ 发散时对 $a$ 无话可说——$a_n$ 可能薄到收敛，也可能刚好卡在边界。$L = \infty$：方向反过来，只有"$b$ 发散则 $a$ 发散"。把这三格记住，就不会在 $L = 0$ 的题目上硬写"同敛散"。
>
> "同阶"这个说法比"逐项不等式"更贴近实际题目。真实题目里 $a_n$ 与 $b_n$ 往往在开头互相交叉，你的直觉只对"足够大之后"有把握；极限同阶法恰好只要求后半段的形状，前有限项由"有限项不改变敛散"这条引理吞掉。这就是为什么它比第 1 版好用——不是条件变松了，而是它只考察你真正看得清的那一段。
>
> 正文那个例子可以算到精确值。$\sum_{n=2}^{\infty} \frac{1}{n^2-1}$ 与 $\frac{1}{n^2}$ 相比，比值是 $\frac{n^2}{n^2-1} = 1 + \frac{1}{n^2-1} \to 1$，所以同收敛。更强的是它其实可以望远镜化：$\frac{1}{n^2-1} = \frac{1}{2}\left(\frac{1}{n-1} - \frac{1}{n+1}\right)$，求和后只剩前面几项没配对的残量，sum（和）恰为 $\frac{3}{4}$；算到 $n = 100$ 时 $S_{100} = 0.7400495050$，与 $0.75$ 差 $0.00995$，残量正是被留下的两条 $\frac{1}{n}$ 型尾巴。
>
> 边界条件不能省。定理要求 $b_n \ne 0$，否则比值根本没定义；也要求 $a_n$ 最终不为零，否则 $a_n$ 反复取零会让比值的 limit（极限）掉到 $0$，落进"单向"那一格。这一条在实操里最常见的踩法是：分子有震荡符号或零项时仍然照搬"同阶同敛散"，忘了先看极限是不是真的落在正数区。
>
> $L = 0$ 那一格配一个具体反例：$a_n = \frac{1}{n^2}$、$b_n = \frac{1}{n}$，比值是 $\frac{1}{n} \to 0$。此时 $b$ 发散而 $a$ 收敛，$\sum \frac{1}{n^2} = 1.6449340668$，正好演示了"$b$ 发散推不出 $a$ 发散"。反过来 $a$ 收敛也推不出 $b$ 收敛，因为同阶的信息在 $L = 0$ 处被彻底丢掉——这正是必须要求 $L \gt 0$ 的全部理由。
>
> 跨课程连接放在 CLRS 的极限比较法与 $\Theta$ 记号。你在算法课里判断 $f(n)$ 与 $g(n)$ 同阶，用的也是"比值趋于正数"这条判据，形式完全一样。区别只有一处：$\Theta$ 会主动丢掉常数倍，而这里的 $L$ 只要是个正数就行，常数大小无关紧要——两者的共同点更值得记：同阶的函数、同阶的项，在无穷和这件事上同生共死。
>
> 一句话收束：极限同阶法的价值不是"更宽松"，而是"把逐项比较换成了渐近比较"，让不等式只需要在尾部成立，代价是把对称性托付给了 $L \ne 0$ 这一个条件。

<span style="color:#2471a3;">**[example]**</span> **Example（例）:** 级数

```math
\sum_{n=2}^{\infty} \frac{1}{n^2 - 1}
```

是收敛的，因为

```math
\frac{n^2}{n^2 - 1} \to 1,
```

而级数 $\sum_{n=2}^{\infty} \frac{1}{n^2}$ 是收敛的。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Ratio Test（比值检验）</span>

设 $a_n \ge 0$，并假设

```math
\frac{a_{n+1}}{a_n} \to a.
```

则：

- 若 $a < 1$，则级数 $\sum a_n$ **收敛（convergent）**；
- 若 $a > 1$，则级数 $\sum a_n$ **发散（divergent）**；
- 若 $a = 1$，则**无法判定（inconclusive）**。

> <span style="color:#7f8c8d;">TBB §3.6.5, p.100（d'Alembert's Ratio Test）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要回答 ratio test（比值检验）到底在测什么：它测的不是项的大小，而是相邻两项的 relative change（相对变化率）。若这个比值最终被某个小于 $1$ 的常数压住，项就被一条 geometric series（几何级数）从上方罩住，收敛与否当场定案。
>
> 机制可以写成三行。设 $\lim \frac{a_{n+1}}{a_n} = r \lt 1$，取 $r_0$ 使 $r \lt r_0 \lt 1$，则存在 $N$，当 $n \ge N$ 时 $\frac{a_{n+1}}{a_n} \le r_0$，即 $a_{n+1} \le r_0 a_n$。迭代这步不等式得 $a_n \le a_N \cdot r_0^{n-N}$，右端正是 geometric series（几何级数）的项。注意这里真正被用到的是"最终"两个字：前 $N$ 项可以完全不按这个比率走，它们由"有限项不改变敛散"吞掉。
>
> 这套推理有一个容易忽略的技术细节：$r_0$ 必须严格大于 $r$、严格小于 $1$。若直接写 $a_{n+1} \le r a_n$ 是不成立的，极限只保证"最终小于任意略大的数"，不保证逐项小于极限本身；$r \lt 1$ 的作用正是保证这个"略大的数"还能落在 $1$ 以内。这个取中间值的动作在本讲会重复出现三次，比值检验、根值检验、收敛半径证明都用同一手。
>
> 这个检验的来历值得一提一句，因为它解释了为什么这件事到十八世纪才被说清：只有当 geometric series（几何级数）的求和公式被完全掌握之后，人们才可能把别的 series（级数）"折回"几何级数去判定。d’Alembert 在 1768 年的著作里给出它，Waring 也独立得到同一个结论；两人走的路都是"把待判对象换算成已知对象"，而不是发明新的求和法。
>
> 为什么它比 comparison test（比较检验）省事？因为它自足。comparison test（比较检验）要你在外部另找一个已知敛散的 series（级数）当基准，你得先知道那个基准的答案；ratio test（比值检验）只用这个 series（级数）自己的相邻两项，不需要任何外部知识，代价是它只认"几何级数级别"的衰减方式，别的形状它看不见。
>
> 把正文里的典型例子算一遍。$a_n = \frac{n}{2^{n}}$ 的 ratio（比值）是 $\frac{n+1}{2n}$，$n = 10$ 时 $0.55$，$n = 100$ 时 $0.505$，$n = 1000$ 时 $0.5005$，极限是 $\frac{1}{2}$。既然 $r = 0.5 \lt 1$，series（级数）收敛，而且 sum（和）可以精确算出来是 $2$（把 $\sum n x^{n}$ 在 $x = \frac{1}{2}$ 处求值即可），$S_{100}$ 已经是 $2.0$；第 $100$ 项本身只有 $7.89 \times 10^{-29}$。$r$ 越小，收敛越快，$r = 0.5$ 时每算一项就多一位十进制精度，收敛速度是线性于项数的。
>
> $r \gt 1$ 那一侧更省事：不需要任何上界论证，只看必要条件就够了。$r \gt 1$ 时存在 $N$ 与 $r_0 \gt 1$ 使 $a_n \ge a_N r_0^{n-N}$，项按几何速率增长，绝不趋于零，series（级数）必然发散。这类"一眼判死"的结论值得单独记住，因为它把最贵的工具留给了真正需要它的情形。
>
> 跨课程连接放在 CSAPP 第 2 章的浮点。$r = \frac{1}{2}$ 意味着第 $n$ 项之后的 tail（余项）不超过 $2^{-n}$ 量级，而 double precision（双精度）只有 $53$ 位有效位，于是算到 $50$ 多项以后再加项也改不动结果——这就是数值库里"对这个级数截断在五十项左右"的经验值从哪来。区别在于：数学定理只承诺 limit（极限）存在，工程实现对"何时可以停"要另给一份余项界，而这份界恰好可以从比值本身读出来。
>
> 一句话收束：比值检验把"收敛问题"压缩成一个数 $r$ 与 $1$ 的比较，压缩率极高，而它的盲区也正是压缩的代价——所有"衰减得比几何慢"的项都会被压到 $r = 1$ 上，那里它什么也说不出。

<span style="color:#2471a3;">**[example]**</span> **Example 1（例 1）:** $a_n = \frac{1}{n}$。此时

```math
\frac{a_{n+1}}{a_n} \to 1,
```

检验无法判定，但该级数（调和级数）发散。

<span style="color:#2471a3;">**[example]**</span> **Example 2（例 2）:** $a_n = \frac{1}{n^2}$。此时

```math
\frac{a_{n+1}}{a_n} \to 1,
```

检验无法判定，但该级数收敛。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要说明的是：$r = 1$ 不是偶尔失灵，而是结构性失明。$\frac{1}{n}$ 与 $\frac{1}{n^2}$ 一个发散一个收敛，比值却都趋于 $1$，ratio test（比值检验）对两者给出同一张白卷——这不是工具不够聪明，而是它读的那个量已经不携带区分信息了。
>
> 机制可以量化。对 $a_n = \frac{1}{n}$，比值是 $\frac{n}{n+1} = 1 - \frac{1}{n+1}$；对 $a_n = \frac{1}{n^2}$，比值是 $\frac{n^2}{(n+1)^2} = 1 - \frac{2}{n} + \frac{1}{n^2}$ 量级。两者都趋于 $1$，但"接近 $1$ 的方式"不同：前者的缺口是 $\frac{1}{n}$ 级，后者是 $\frac{2}{n}$ 级。把缺口乘以 $n$，前者趋于 $1$，后者趋于 $2$——差别就藏在"缺口乘上项数"这个量里，而比值本身把这个量抹平了。
>
> 这条路走下去就是更细的判据。对 $p$ 级数 $\sum n^{-p}$，比值缺口满足 $n\left(1 - \frac{a_{n+1}}{a_n}\right) \to p$，于是 $p \gt 1$ 收敛、$p \lt 1$ 发散、$p = 1$ 仍在边界上失明。这正是 Raabe 判据的序参量：它把原来只有"是否小于 $1$"两档的判据，扩成了一条连续刻度。工具变细的代价是计算变重，收益是分辨率提高了一整级。
>
> 具体数字。$n = 100$ 时，$\frac{1}{n}$ 的比值是 $0.9900989900$，缺口 $0.009901$；$\frac{1}{n^2}$ 的比值是 $0.9802960494$，缺口 $0.019704$。缺口乘 $n$ 得 $0.990099$ 与 $1.970395$，两者相差近一倍——这就是"看得见"与"看不见"的临界差别。$n = 1000$ 时这两个量分别是 $0.999001$ 与 $1.997004$，差距仍在，说明区分信息一直都在，只是被比值的形式丢掉了。
>
> 这一对例子在教材里总是并排放，用意很明确：用同一把尺子量出两个相反的结论，你才会相信它的失效不是运气不好，而是尺子本身的分辨率不够。单看一个反例，你总能怀疑"是不是这一题太特殊"；两个方向相反的反例并排，怀疑就没有落脚点了。
>
> 而且这个区分在很小的 $n$ 上就已经可见：$n = 10$ 时 $\frac{1}{n}$ 的缺口乘 $n$ 是 $0.909091$，$\frac{1}{n^2}$ 是 $1.735537$，两者已经分得很开。这说明区分信息从头就在数据里，问题只出在比值这个读数方式把所有 $n$ 的影响都归一化掉了。
>
> 为什么几何基准太粗？因为 geometric series（几何级数）只有两档结局——按指数衰减的收敛，不衰减的发散——而多项式衰减的整个连续谱，全部被压到 $r = 1$ 这同一个点上。用一把两格的尺子去量一条连续的刻度，精度损失是必然的。要跨过 $p = 1$ 这道门槛，只能换基准：integral test（积分检验）把 series（级数）与反常积分绑在一起，condensation test（凝聚检验）把 $p$ 级数凝聚成 geometric series（几何级数），两者都在同一个位置接上了更细的分辨率。
>
> 跨课程连接放在 CLRS 的界估计。$\Theta(n)$ 与 $\Theta(n \log n)$ 之间的缝隙，正是"只看增长率分档"的工具看不见的那一段，于是需要 Master theorem（主定理）之外的方法去分辨；这与"比值只分几何与非几何两档"是同一类损失。区别在于：算法分析里这条缝隙是连续的、可以用更强的渐近分析逐步逼近；而收敛判据必须给出"收敛或发散"的二元答案，所以任何有限级判据都必然留下边界档。
>
> 一句话收束：这一对反例的价值不在"促成引入新工具"，而在钉住一件事——判据的分辨率由它读入的信息量决定，$r = 1$ 的失明是设计上的必然，不是证明上的疏漏。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Root Test（根值检验）</span>

设 $a_n \ge 0$ 是一个非负数序列。假设 $\lim_{n \to \infty} (a_n)^{\frac{1}{n}} = r$。则：

- 若 $r < 1$，则级数 $\sum_{n=0}^{\infty} a_n$ **收敛**；
- 若 $r > 1$，则级数 $\sum_{n=0}^{\infty} a_n$ **发散**；
- 若 $r = 1$，则**无法判定**。

> <span style="color:#7f8c8d;">TBB §3.6.6, p.101（Cauchy's Root Test）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要说明 root test（根值检验）测的是什么：它直接给项量级拍一张照。$n$ 次根 $a_n^{1/n}$ 的极限就是项的 geometric mean（几何平均）增长率，若这个平均增长率小于 $1$，项整体按指数衰减，series（级数）收敛；大于 $1$，项整体按指数膨胀，连必要条件都过不去。
>
> 机制比比值检验还短。若 $a_n^{1/n} \to r \lt 1$，取 $r_0$ 使 $r \lt r_0 \lt 1$，则存在 $N$，当 $n \ge N$ 时 $a_n^{1/n} \le r_0$，两边取 $n$ 次方得 $a_n \le r_0^{n}$；右端是 geometric series（几何级数）的项，于是由 comparison test（比较检验）第 1 版直接收敛。$r \gt 1$ 时反向同理，取 $r_0 \gt 1$ 得 $a_n \ge r_0^{n}$，项按指数增长，绝不趋于零，必然发散。整条推理只用到"取中间值 + 最终成立"，没有别的机关。
>
> 和比值检验的差别全在"哪两项相比"上。比值看相邻两项，测的是 instantaneous growth（瞬时增长率）；根值把前 $n$ 项的效果平均掉，测的是 average growth（平均增长率）。平均对局部尖峰不敏感：某一项突然放大 $4$ 倍，在 $n = 100$ 时对 $n$ 次根只贡献 $4^{1/100} = 1.0139595$，几乎看不出来；而比值检验会看到那个 $4$ 倍跳变，并因此失去 limit（极限）。这就是为什么正文说根值对"偶尔跳变"鲁棒。
>
> 构造一个能把两者分开的例子。令 $a_n = 2^{-n}$ 当 $n$ 为偶数，$a_n = 2^{-n+2}$ 当 $n$ 为奇数，则前几项是 $2, 0.25, 0.5, 0.0625, 0.125, 0.015625$。相邻两项的 ratio（比值）在 $0.125$ 与 $2$ 之间来回跳，根本不收敛，ratio test（比值检验）只能说"无法判定"；但 $a_n^{1/n}$ 稳定趋于 $\frac{1}{2}$，实测 $n = 100$ 时为 $0.5$、$n = 101$ 时为 $0.5069102$，于是 root test（根值检验）判收敛。这个 series（级数）的 sum（和）还真能精确算：偶项贡献 $\frac{1}{3}$，奇项贡献 $\frac{8}{3}$，合起来正好是 $3$。
>
> 历史上一句就够：这个检验是 Cauchy 在 1821 年的《分析教程》里给出的。他当时要处理的正是比值检验够不着的对象——幂级数在复平面上的收敛范围，以及那些相邻项比值振荡的级数。检验的名字挂在他名下，是因为他第一次把它当作一般工具来陈述，而不只是零散地用在个别例子上。
>
> 两条检验有强弱关系，值得记住：$\liminf \frac{a_{n+1}}{a_n} \le \liminf a_n^{1/n} \le \limsup a_n^{1/n} \le \limsup \frac{a_{n+1}}{a_n}$。中间那个不等式说明，凡比值检验能判的，根值检验也能判；反过来不成立。这就是教材先讲比值、再讲根值的顺序来源：先给便宜的工具，再给更强的工具，并明确强在哪里。
>
> 实用上还有一个理由让人偏爱根值：$n$ 次根常常比相邻比更容易算。涉及阶乘的项，比值要展开 $\frac{(n+1)!}{n!}$ 才能约掉，根值则可以借 Stirling 近似一步给出量级；涉及 $n$ 次方的项更直接，根号一开，指数就被 $\frac{1}{n}$ 削平，剩下的通常是个常数。
>
> 跨课程连接放在 CSAPP 第 6 章的 cache（缓存）指标。衡量一个 cache（缓存）要好坏，你可以看每一次访问的 instantaneous miss（瞬时缺失），也可以看长期的 average miss rate（平均缺失率）；后者对偶发的冷启动缺失不敏感，给出的结论更稳。criterion（判据）的选择在这里同样是"局部 vs 全局"的取舍，和比值与根值的关系完全同构。区别在于：cache（缓存）的指标是统计意义下的期望，root test（根值检验）里的平均是确定性的几何平均，$n$ 次根对每个 $n$ 都有确切的值。
>
> 一句话收束：根值检验的价值不只是"更强"，而是它把"项的量级"这个本来要靠肉眼观察的东西，变成了一个可以取 limit（极限）的数。

### <span style="color:#2471a3;">**[proof]**</span> <span style="color:#c0392b">Proof（根值检验的证明）</span>

**情形 $r < 1$。** 取 $r < r_0 < 1$，则存在 $N$ 使得当 $n \ge N$ 时，

```math
(a_n)^{\frac{1}{n}} \le r_0.
```

因此

```math
0 \le a_n \le r_0^n.
```

然而级数 $\sum_{n=0}^{\infty} r_0^n$ 是一个几何级数，且 $r_0 < 1$，故收敛。由比较检验（第 1 版），级数 $\sum_{n=0}^{\infty} a_n$ 也收敛。

**情形 $r > 1$。** 此时取 $1 < r_0 < r$，则存在 $N$ 使得当 $n \ge N$ 时，

```math
(a_n)^{\frac{1}{n}} \ge r_0.
```

于是对 $n \ge N$，

```math
a_n \ge r_0^n,
```

而 $\sum_{n=0}^{\infty} r_0^n$ 是发散的几何级数。因此由比较检验，原级数发散。 $\square$

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要把 root test（根值检验）的证明抽象成一个能反复用的模板，我管它叫 geometric squeeze（几何夹逼法）：在 limit（极限）与边界 $1$ 之间插进一个中间值 $r_0$，用它把"趋于"改写成"逐项不等式"，再把逐项不等式交给 comparison test（比较检验）与 monotone convergence theorem（单调收敛定理）去收尾。
>
> 为什么必须插这个 $r_0$？因为极限的定义只保证"最终落进任意小的邻域"，它从不保证逐项成立任何具体的界。若你直接把 $a_n^{1/n} \le r$ 写下去，那是拿结论当条件用；而取 $r_0$ 落在 $r$ 与 $1$ 之间，邻域半径就取 $r_0 - r \gt 0$，定义保证存在 $N$ 使 $n \ge N$ 后 $a_n^{1/n} \lt r_0$。这一步是整条模板的枢纽：它把"极限意义下的信息"兑换成"逐点成立的不等式"，而后者才是比较检验的输入格式。$r \gt 1$ 一侧对称处理，取 $1 \lt r_0 \lt r$，得到 $a_n \gt r_0^{n} \gt 1$，项不趋于零。
>
> 模板还有一个值得注意的性质：$r_0$ 怎么取、$N$ 有多大，都不影响结论。$r_0$ 越贴近 $r$，需要的 $N$ 越大；但收敛性只由 tail（尾巴）决定，前有限项被"有限项不改变敛散"吞掉，所以论证从头到尾只依赖"存在这样的 $N$"。这正是存在性论证的典型形状：你不需要能算出那个常数，只需要知道它存在。
>
> $r = 1$ 时模板为什么必然垮？因为两侧夹板分别落在不同的结论上：$r_0 \lt 1$ 那侧要给出上界、走收敛，$r_0 \gt 1$ 那侧要给出下界、走发散。当 $r$ 正好等于 $1$，可插中间值的区间长度为零，你既插不进一个小于 $1$ 的 $r_0$，也插不进一个大于 $1$ 的 $r_0$，夹逼的两条腿同时断掉。这不是证明写得不够严谨，而是这个论证格式在边界上确实没有可用的输入。
>
> 算一个具体例子。取 $a_n = 1.2^{-n}$，则 $a_n^{1/n} = \frac{1}{1.2} = 0.8333333$，极限 $r$ 就是这个常数。选 $r_0 = 0.9$，由于 $0.8333 \lt 0.9$，逐项不等式 $a_n \le 0.9^{n}$ 对每个 $n$ 都成立，$N = 1$ 就够。series（级数）的 sum（和）是 $\frac{1}{1.2 - 1} = 5$，算到 $50$ 项得 $S_{50} = 4.9994505759$，误差 $5.49 \times 10^{-4}$。而按几何夹逼给出的界是 $\frac{0.9^{51}}{0.1} = 0.0464$，比真实误差松了约八十五倍——界很粗，但它是真的，模板要的也只是"真"。
>
> 这个"取中间值"的手法在本讲里出现三次，在课程里是第四次：第四讲证明极限的四则运算时取 $\varepsilon = \frac{1}{2}$ 或类似的中值，比值检验取 $r_0$，根值检验取 $r_0$，等会儿证 Cauchy–Hadamard（Cauchy–Hadamard 公式）还要再取一次。同一个动作反复出现，说明它不是技巧，而是"把极限语句翻成有限语句"的标准转换器。
>
> 跨课程连接放在 CSAPP 的循环不变式。不变式断言"从某一点起，某个性质永远成立"，与这里"存在 $N$，当 $n \ge N$ 时 $a_n^{1/n} \lt r_0$"是同一种逻辑形状：都是把无限长的过程压缩成"起点的存在"。区别在于：不变式靠离散归纳一步步维持，这里的"永远成立"由 limit（极限）的定义一次性给出，靠的是度量收敛而不是计数归纳。
>
> 一句话收束：这条模板的灵魂不是那个不等式，而是"先造一个中间值，把严格与不严格之间的缝补上"；补缝的那一步，永远是证明里最容易被跳过、也最容易被阅卷人盯住的一步。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Power Series（幂级数）</span>

- $\displaystyle \sum_{n=0}^{\infty} x^n = \frac{1}{1-x}$。
- $\displaystyle \sum_{n=0}^{\infty} \frac{x^n}{n!} = \exp x$。
- $\displaystyle \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n}}{(2n)!} = \cos x$。
- $\displaystyle \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n+1}}{(2n+1)!} = \sin x$。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要说明四个 power series（幂级数）并排出现的用意：有理函数、指数函数、三角函数这三类在中学看来毫不相干的函数，全部被 $\sum a_n x^{n}$ 这一个形式表示。不是它们碰巧都能展开，而是"展开成无穷多项式"这件事本身就定义了什么叫 analytic（解析）函数。
>
> 机制上，power series（幂级数）就是函数在 monomial basis（单项式基）$1, x, x^2, x^3, \dots$ 下的坐标。你把 $x$ 当成一个符号，那么 $\sum a_n x^{n}$ 与一个无穷维向量 $\left(a_0, a_1, a_2, \dots\right)$ 是一回事，$a_n$ 就是坐标分量。这种"把函数变成一列数"的视角，与你在 Strang 里做的事完全同构：给一个向量，选一组基，读出它在基下的坐标；只不过这里的基有可数无穷多个，向量空间是函数空间。
>
> 这一步为什么重要？因为它把函数的全部结构信息搬进了系数 sequence（序列）。$\frac{1}{1-x}$ 的系数全是 $1$，这个"全 $1$"就编码了它的代数性质（乘 $(1-x)$ 得 $1$，正是 geometric series（几何级数）求和公式的重写）；$e^{x}$ 的系数是 $\frac{1}{n!}$，这个衰减率既编码了它的增长性，也编码了它在每一点都能被多项式逼近；$\cos x$ 的系数严格按奇偶分布、偶数位交替变号，这正是周期性与对称性的代数影子。函数看起来是几何对象，展开之后变成一串数字，而串的形状就是它的身份。
>
> 把数字算出来看收敛之快。取 $x = 0.5$：$e^{0.5} = 1.6487212707$，用 $0$ 项得 $1$，用 $1$ 项得 $1.5$，用 $3$ 项得 $1.6458333333$，用 $5$ 项得 $1.6486979167$，误差已经只有 $2.34 \times 10^{-5}$。$\cos 0.5 = 0.8775825619$，只用两项（常数项与 $x^2$ 项）就给出 $0.8776041667$，误差 $2.16 \times 10^{-5}$。$\frac{1}{1-0.5} = 2$，算 $20$ 项得 $1.9999990463$。三个函数用同一个公式、同一套算法，精度还都是几何级数式的——这就是"统一表示"的实际好处。
>
> 值得停一下的是：这三类函数的收敛半径完全不同。$\frac{1}{1-x}$ 只到 $R = 1$，因为 $x = 1$ 处有竖直的障碍；$e^{x}$ 处处收敛，$R = \infty$；$\cos x$ 与 $\sin x$ 也处处收敛。同一个形式、同一种算法，却在"能展开多远"这件事上分道扬镳——这件事要到讲 radius of convergence（收敛半径）时才被完全解释，但在这里已经能感到：系数 sequence（序列）的衰减速度决定了它能管多宽的 $x$。
>
> 拓展出去一个反直觉的Borel theorem（Borel 定理）：给定任意系数 sequence（序列）$a_n$，无论它增长多快，都存在一个无限次可导的函数，使它在 $0$ 处的各阶导数恰好对应这些系数，也就是以 $\sum a_n x^{n}$ 为它的 Taylor series（Taylor 级数）。哪怕这个 power series（幂级数）除 $x = 0$ 外处处发散，函数依然存在。矛盾的解释只有一句话：Borel 只保证 $0$ 点的导数匹配，不保证 $x \ne 0$ 处函数值等于级数的值；在别处，这个函数的 Taylor series（Taylor 级数）已经换成了另一串系数。这正是"光滑"与"解析"必须分开的原因，也是下一讲的主题入口。
>
> 跨课程连接放在 Strang 的基与投影。矩阵分解把向量写成基向量的线性组合，系数由内积读出；幂级数把函数写成单项式的线性组合，系数由导数读出（$a_n = \frac{f^{(n)}(0)}{n!}$）。区别在于：矩阵的基通常选成正交的，坐标可以直接投影；而 $1, x, x^2, \dots$ 根本不正交，所以系数不能靠内积直接读，必须绕道导数——这也解释了为什么 Taylor 系数里会出现阶乘，它是正交性的替代品。
>
> 一句话收束：四个例子并排不是为了让你记住四条展开式，而是让你看到"函数等于一列数"这件事在四类完全不同的对象上都成立，从而有资格被当作定义。

### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#c0392b">Formal Definition（形式定义）</span>

设 $c_n$ 是一个序列，则

```math
\sum_{n=0}^{\infty} c_n x^n
```

是一个 **power series（幂级数）**。

> <span style="color:#7f8c8d;">TBB §10.2, p.404</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">两个问题</span>

- **幂级数何时收敛？**
- **为什么它能给出我们熟悉的函数？**

第二个问题我们下次课对 exponential function（指数函数）回答。

第一个问题的答案来自 root test（根值检验）或 ratio test（比值检验）。

<span style="color:#2471a3;">**[example]**</span> **Example（例）:** 考虑幂级数

```math
\sum_{n=0}^{\infty} \frac{x^n}{n!}.
```

用比值检验，$a_n = \frac{x^n}{n!}$，我们有

```math
\frac{a_{n+1}}{a_n} = \frac{n! \, x^{n+1}}{(n+1)! \, x^n} = \frac{x}{n+1} \to 0.
```

因此该幂级数对**所有** $x$ 都收敛。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要讲清 factorial（阶乘）为什么能碾压任何指数：$\sum \frac{x^{n}}{n!}$ 对每个固定的 $x$ 都收敛，收敛半径是无穷。原因不是运气好，而是 $n!$ 的增长比 $c^{n}$ 高了一整级。
>
> 先看比值这一层。$a_n = \frac{x^{n}}{n!}$ 时，$\frac{a_{n+1}}{a_n} = \frac{|x|}{n+1}$。这个表达式的意思极直白：分子是固定长度 $|x|$ 连乘 $n$ 次留下的一份，分母是 $1, 2, 3, \dots, n+1$ 连乘。一旦 $n + 1 \gt |x|$，比值就小于 $1$，此后每个新因子又都比前一个更小，比值持续下降、加速趋零。所以交叉点只由 $|x|$ 决定，粗略就是 $n \approx |x|$。
>
> 再看更深一层的量级。$n!$ 里含 $n^{n}$ 级的因子，Stirling 公式给出 $n! \approx \sqrt{2\pi n}\left(\frac{n}{e}\right)^{n}$，取对数得 $\ln n! \approx n \ln n - n$，这是超线性的；而 $\ln c^{n} = n \ln c$ 是线性的。超线性压线性，差一级就是差一个"无穷大阶"，所以任何固定 $c$ 都拦不住它。换成根值检验的语言是同一个结论：$\left(\frac{1}{n!}\right)^{1/n} \approx \frac{e}{n} \to 0$，实测 $n = 100$ 时为 $0.0263209$，早就是零附近的量级了。
>
> 数字能把"直觉"和"事实"分开，这一步值得细看。取 $x = 10$：$n = 9$ 时比值恰为 $1.0$，$n = 10$ 时 $0.909091$，$n = 20$ 时 $0.476190$——收敛从第 $10$ 项左右就开始被保证。可是项的绝对值要真正被 $10^{n}$ 压住，得晚得多：$10! = 3628800$，而 $10^{10} = 10^{10}$，前者比后者小 $2755$ 倍；到 $20! = 2.432902 \times 10^{18}$ 对 $20^{20} = 1.048576 \times 10^{26}$，还小 $4.3 \times 10^{7}$ 倍；真正翻过来要到 $n = 25$，$25! = 1.551121 \times 10^{25}$ 才第一次超过 $10^{25}$。所以"比值小于 $1$ 就收敛"和"项小于 $1$"是两件事，前者早在第 $10$ 项就成立，后者要等到第 $25$ 项，混为一谈就会误判收敛速度。
>
> 收敛速度也能量化，办法就是看下一项。取 $x = 1$，$e$ 的前十一项和是 $2.7182818011$，与 $2.7182818285$ 相差 $2.74 \times 10^{-8}$，而 $\frac{1}{11!} = 2.505 \times 10^{-8}$，两者同量级——说明 tail（余项）被下一项主导。"余项约等于下一项"这条经验规律对衰减快的正项级数普遍成立，它是数值实现里"算到下一项小于容差就停"的理论依据，比固定项数的截断可靠得多。反过来看慢级数就有警示：对 $\sum \frac{1}{n}$，下一项比 tail（余项）小得多，同一条规则会把误差估小到离谱，这正是收敛速度决定余项估计可信度的原因。
>
> 跨课程连接有两处。概率论里组合数 $\binom{n}{k}$ 与 Poisson 分布都靠 $n!$ 撑着，Stirling 公式是估计这些量的标准手段，Bertsekas 会正式用到它。CSAPP 第 2 章的浮点更直接：double precision（双精度）的最大值是 $1.7977 \times 10^{308}$，而 $\ln 171! \approx 306.86$、$\ln 172! \approx 309.09$，也就是说 $171! $ 已在溢出边缘、$172!$ 直接变成 inf。所以数值库从不先算阶乘再相除，而是用 lgamma（对数阶乘）在 log 域里算——这不是技巧，而是被量级逼出来的设计。
>
> 收敛半径是无穷这件事，是后面指数函数理论的许可证。因为对每个 $x$ 都收敛，把 $x$ 换成 $ix$ 才合法；换完之后逐项比对 $\sum \frac{(ix)^{n}}{n!}$ 与 $\cos x + i\sin x$ 的展开式，才可能得到 $e^{ix} = \cos x + i\sin x$。如果收敛半径有限，这个替换在 $|x| \gt R$ 处就没有依据，欧拉公式的证明会当场断掉。
>
> 再补一个量级对照：$\frac{n!}{c^{n}}$ 最终趋于无穷，速度大约是 $\left(\frac{n}{ec}\right)^{n}$，也就是指数套指数地跑开；而 $\frac{c^{n}}{n!} \to 0$ 正是它的反面。固定 $x$ 时 $\frac{|x|^{n}}{n!}$ 最终单调递减，这一点由比值 $\frac{|x|}{n+1}$ 小于 $1$ 就能直接读出，不必再引任何估计。一句话收束：阶乘碾压法的实质是"超线性压线性"，而它在数值上留下的痕迹是溢出——数学上的处处收敛，在有限精度机器上表现为必须先取对数才能算。

<span style="color:#2471a3;">**[example]**</span> **Example（例）:**

```math
\sum_{n=0}^{\infty} x^n.
```

该级数当 $|x| < 1$ 时收敛，否则发散。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Lim Sup（上极限）</span>

要讨论一般幂级数的收敛性，我们需要序列的 **lim sup（上极限，limit superior）** 概念。定义如下。

设 $a_n$ 是一个序列。如果它不有上界，则我们规定 $\limsup a_n = \infty$。否则，我们由 $a_n$ 定义一个新序列 $b_n$ 如下：

```math
b_n = \sup \{ a_n, a_{n+1}, a_{n+2}, \cdots \}.
```

注意由于我们假设 $a_n$ 们有上界，$b_n$ 们都是实数，且序列 $b_n$ 是**递减（decreasing）**的——它递减是因为

```math
b_n = \sup \{ a_n, a_{n+1}, a_{n+2}, \cdots \} \ge \sup \{ a_{n+1}, a_{n+2}, \cdots \} = b_{n+1}.
```

（对 $b_{n+1}$ 而言，supremum（上确界）是在一个更小的集合上取的。）

由于序列 $b_n$ 递减，它收敛到极限 $b$；若 $b_n$ 不有下界，这个极限可能是 $-\infty$。

### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#c0392b">Definition（lim sup 的定义）</span>

```math
\limsup_{n \to \infty} a_n = \lim_{n \to \infty} b_n = b.
```

> <span style="color:#7f8c8d;">TBB Definition 2.44, §2.13, p.62</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要说明 limsup（上极限）为什么必须被发明出来：ratio test（比值检验）与 root test（根值检验）都要求比值或 $n$ 次根有 limit（极限），可极限本来就不保证存在。limsup（上极限）就是"极限不存在时的代替品"，它把"最终能达到的最大聚集水平"变成一个总是存在的数。
>
> 定义分两步，两步都用已经学过的工具。第一步，取 tail（尾巴）集合 $\left\{x_k : k \ge n\right\}$ 的 supremum（上确界），记作 $b_n$；第二步，对 sequence（序列）$(b_n)$ 取 limit（极限）。关键性质是 $(b_n)$ 单调不增：把集合里的一项拿掉，上确界只可能变小，不会变大。于是 $(b_n)$ 单调递减且有下界（可能取 $-\infty$），由 monotone convergence theorem（单调收敛定理）的对偶形式，它一定有 limit（极限）——这个极限就是 limsup（上极限）。换句话说，limsup（上极限）的存在性不是假设，而是单调有界定理直接送的。
>
> 拿三个例子把定义走一遍。$x_n = 2 + (-1)^{n}$ 给出 $1, 3, 1, 3, \dots$，任意尾巴里都同时含 $1$ 与 $3$，所以每个 $b_n = 3$，limsup（上极限）为 $3$；对称地，liminf（下极限）为 $1$。$x_n = \frac{1}{n}$ 时 $b_n = \frac{1}{n}$，limsup（上极限）为 $0$。$x_n = n$ 无上界，按约定 limsup（上极限）取 $+\infty$。三个例子里只有第一个的 limit（极限）不存在，而三个 limsup（上极限）都存在——这就是"代替品"三个字的含义。
>
> 它的用处在你已经见过的地方兑现。前面构造过 $a_n = 2^{-n}$（$n$ 偶）、$a_n = 2^{-n+2}$（$n$ 奇），相邻比值在 $0.125$ 与 $2$ 之间跳，ratio test（比值检验）无话可说；但 $a_n^{1/n}$ 的 limsup（上极限）等于 $\frac{1}{2}$，小于 $1$，root test（根值检验）照样判收敛。所以定理可以改写成不需要极限存在的版本：$\limsup a_n^{1/n} \lt 1$ 收敛，$\gt 1$ 发散，等于 $1$ 仍然失明。改写的代价是零，收益是适用范围扩大了一整类振荡 sequence（序列）。
>
> limsup（上极限）最有用的不是它的定义，而是它的刻画性质：$b = \limsup x_n$ 是满足"对每个 $\varepsilon \gt 0$，最终所有 $x_n$ 都不超过 $b + \varepsilon$，且有无穷多项超过 $b - \varepsilon$"的那个数。前半句说它是上包络，后半句说它是最紧的上包络，两句缺一不可。后面所有关于 limsup（上极限）的论证，例如"$|x| \cdot \limsup |a_n|^{1/n} \lt 1$"，实际上用的都是这两句话，而不是定义里那两步 sup 与 limit（极限）。
>
> 跨课程连接放在 CSAPP 第 6 章的延迟指标。测 cache（缓存）或内存的延迟时，你会区分平均值、p99 与最大值；limsup（上极限）对应的正是"最终最坏情况"那一端，liminf（下极限）对应"最终最好情况"那一端。区别要讲清：p99 是分位数，允许百分之一的访问越界；limsup（上极限）是确定的上包络，尾巴里一次越界都不许——它是比任何一个分位数都更严格的量，代价是它对有限次异常完全不敏感，因为有限项被尾巴丢掉了。
>
> 顺带把 limsup（上极限）与 limit（极限）的关系钉住：liminf（下极限）$\le$ limsup（上极限）恒成立；limit（极限）存在当且仅当两者相等，且等于这个公共值。所以极限不存在在 limsup（上极限）的语言里有一个精确含义——上下包络不重合，而不是没法算。这一句把上极限从技术工具提升成了概念判据。
>
> 一句话收束：limsup（上极限）把"极限是否存在"这个信息不完整的问题，改造成了"上包络有多高"这个信息完整的问题；极限存在时两者相等，极限不存在时它仍然给出唯一答案，这就是它在收敛半径公式里不可替代的原因。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Radius of Convergence（收敛半径）</span>

回到幂级数。假设

```math
\sum_{n=0}^{\infty} a_n x^n
```

是一个幂级数。令

```math
R = \frac{1}{\limsup_{n \to \infty} |a_n|^{\frac{1}{n}}}.
```

$R$ 被称为 **radius of convergence（收敛半径）**。

> <span style="color:#7f8c8d;">TBB §10.2, p.404（Cauchy–Hadamard 公式）</span>

**Convention（约定）:** 若 $\limsup_{n \to \infty} |a_n|^{\frac{1}{n}} = 0$，则称收敛半径为 $\infty$。若 $\limsup_{n \to \infty} |a_n|^{\frac{1}{n}} = \infty$，则令 $R = 0$。

由根值检验现在可以证明：

**幂级数在 $|x| < R$ 时收敛，在 $|x| > R$ 时发散。**

$|x| = R$ 的情形必须**逐例分析（case by case）**。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条注要说明 Cauchy–Hadamard（Cauchy–Hadamard 公式）不是背出来的定理，而是 root test（根值检验）在 power series（幂级数）上的一次代入：把 $a_n x^{n}$ 当作项，问它的 $n$ 次根收敛到哪里，$|x|$ 的范围就自动解出来了。
>
> 推导只有三行，但每一行都要说清依据。取项 $a_n x^{n}$，其 $n$ 次根是 $|a_n|^{1/n} |x|$；对这列数取 limsup（上极限），常数因子 $|x|$ 可以提到外面，得 $|x| \cdot \limsup |a_n|^{1/n}$。记 $L = \limsup |a_n|^{1/n}$，若 $|x| L \lt 1$，即 $|x| \lt \frac{1}{L}$，root test（根值检验）判收敛；若 $|x| L \gt 1$，判发散。把 $|x|$ 的阈值命名为 $R = \frac{1}{L}$，radius of convergence（收敛半径）就定义出来了。整个过程没有新的思想，只有一次代入和一次解不等式。
>
> 为什么这里必须用 limsup（上极限）而不能用 limit（极限）？因为系数 sequence（序列）的 $n$ 次根完全可能不收敛。例如系数在 $1$ 与 $2$ 之间振荡，$|a_n|^{1/n}$ 就振荡，limit（极限）不存在，但 limsup（上极限）照样给出一个确定的 $R$。这正是上一注准备的工具在这里第一次真正派上用场：定理的普适性，全靠 limsup（上极限）总是存在。
>
> 边界 $|x| = R$ 处定理失明，而且必须失明——三种边界行为都能出现，所以不可能有一条通用结论。$\sum x^{n}$ 在 $x = 1$ 与 $x = -1$ 都发散；$\sum \frac{x^{n}}{n}$ 在 $x = 1$ 发散（变成调和级数），在 $x = -1$ 收敛（变成交错调和级数，和为 $\ln 2$）；$\sum \frac{x^{n}}{n^{2}}$ 在 $x = 1$ 收敛（$\frac{\pi^{2}}{6}$），在 $x = -1$ 也收敛。同一个 $R = 1$，边界上从"两端都发散"到"两端都收敛"都能实现，任何只依赖 $R$ 的定理都不可能覆盖它。
>
> 把里面的数字核对一遍。$\sum \frac{(-1)^{n+1}}{n}$ 的前一千项和是 $0.6926474306$，而 $\ln 2 = 0.6931471806$，误差 $4.9975 \times 10^{-4}$，与 $\frac{1}{2n} = 5 \times 10^{-4}$ 吻合。这印证了上一注说过的"条件收敛只能以 $\frac{1}{n}$ 的速率逼近"，也说明边界点上的收敛可以很慢——慢到你以为它发散了。数值上判断边界敛散，几乎总是要回到具体的结构，而不是读 $R$。
>
> 历史值得一提一句，因为它解释了为什么这个公式长时间被埋着：Cauchy 在 1821 年的《分析教程》里已经给出，但当时幂级数主要被当作形式工具，收敛区域的问题还没有被当成核心问题；直到 Hadamard 在 1888 年前后独立重新得到它，并把它放进复分析的框架里，它才成为标准工具，冠名也就成了两个人的。
>
> 跨课程连接放在 Strang 的谱半径。矩阵幂 $A^{n}$ 的增长率由 spectral radius（谱半径）控制：$\rho(A) \lt 1$ 时 $A^{n} \to 0$，$\rho(A) \gt 1$ 时范数增长，临界同样是"等于 $1$ 时无法判定"。两条结论的结构完全同构：都是"以某个几何速率为临界值，把参数空间切成收敛与发散两半"。区别在于：谱半径由有限多个特征值决定，是一个代数对象，算得出来；收敛半径由 limsup（上极限）决定，可能在无穷多个值之间取上包络，只能估计。
>
> 还有一处结构性事实值得记：$R$ 只由系数决定，与函数的其他信息无关；而同一个函数在不同基点展开会有不同的系数 sequence（序列），也就有不同的 $R$。这解释了为什么在原点展开与在别处展开得到的收敛范围不同——不是函数变了，而是所选基点离奇点有多远，这件事被系数吃进去了。
>
> 一句话收束：这个公式的全部内容是"把根值检验的 $r$ 换成 $|x| L$，再把 $|x|$ 解出来"；真正需要记住的不是公式本身，而是"边界永远要回到具体级数去判"这条纪律。
