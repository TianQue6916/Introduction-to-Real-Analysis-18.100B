### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Question: What kind of functions are integrable?（问题：什么样的函数是可积的？）</span>

本讲从一个问题出发：什么样的 function（函数）是 integrable（可积的）？

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem（定理）</span>

任何在 $[a, b]$ 上的 continuous function（连续函数）都属于 $\mathcal{R}([a, b])$（这里 $\mathcal{R}([a, b])$ 表示 $[a, b]$ 上 Riemann integrable functions（黎曼可积函数）的全体）。

> <span style="color:#7f8c8d;">TBB Theorem 8.17 (Riemann–Lebesgue), §8.6.3 Lebesgue's Criterion, p.353（连续函数是"除一个零测集外连续"的特例；另见 Corollary 8.19, §8.6.4, p.355）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这条定理在 L18 已经证过，今天是把它作为出发点重新亮出来。Colding 开讲先花了十几分钟完整复盘 L18 的整套定义：partition（划分）$P$、小区间上的 $M_i = \sup f$ 与 $m_i = \inf f$、upper sum（上和）与 lower sum（下和）、upper Riemann integral（上黎曼积分）与 lower Riemann integral（下黎曼积分），以及"$f$ 可积当且仅当这两个数相等"。他随后点明本讲的工作引擎是 L18 证明过的一个判据引理：🎥 *"we were talking about that this was a useful lemma to determine whether a function was Riemann integrable"*（翻译：我们上次说过，这是一个判定函数是否黎曼可积的有用引理）。该引理说：有界函数 $f$ 可积当且仅当对任意 $\varepsilon > 0$ 存在划分 $P$ 使 $U(f, P) - L(f, P) < \varepsilon$。本讲证明"和与积分"的各条代数性质时，全部是靠这个引理把"可积性"问题化成"找一个划分"的问题——你在下面会反复看到这个套路。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Basic properties of integrals（积分的基本性质）</span>

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem: Basic formulas for integrals（定理：积分的基本公式）</span>

我们关于积分有如下几条基本公式：

**(1)** 若 $f \in \mathcal{R}([a, b])$ 且 $c \in \mathbb{R}$，则 $cf \in \mathcal{R}([a, b])$，且

```math
\int_a^b (cf)(x)\,dx = c \int_a^b f(x)\,dx .
```

**(2)** 若 $f, g \in \mathcal{R}([a, b])$，则 $f + g \in \mathcal{R}([a, b])$，且

```math
\int_a^b (f + g)(x)\,dx = \int_a^b f(x)\,dx + \int_a^b g(x)\,dx .
```

**(3)** 若 $f, g \in \mathcal{R}([a, b])$ 且 $f \le g$，则

```math
\int_a^b f(x)\,dx \le \int_a^b g(x)\,dx .
```

**(4)** 若 $f \in \mathcal{R}([a, b])$ 且 $c \in (a, b)$，则 $f \in \mathcal{R}([a, c])$ 且 $f \in \mathcal{R}([c, b])$，并且

```math
\int_a^c f(x)\,dx + \int_c^b f(x)\,dx = \int_a^b f(x)\,dx .
```

> <span style="color:#7f8c8d;">TBB 8.22 (Additive), 8.23 (Linear), 8.24 (Monotone), 8.25 (Absolute), §8.7 Properties of the Riemann Integral, p.356（TBB 的 8.22 是"两段拼一段"方向，本讲的 (4) 是"一段拆两段"方向，两者等价）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，课堂取舍）:**</span> 这四条在课上并未全部展开。Colding 在黑板上证明了 (2) 与 (4)，而 (1)、(3) 只讲了思路：🎥 *"I won't prove this... maybe I'll just say words"*（翻译：这条我不证明了……也许我只说说想法）。对 (3)，他的口头理由是：固定任一划分，在小区间 $[x_{i-1}, x_i]$ 上由 $f \le g$ 处处成立，立即有 $\sup f \le \sup g$（对 $\inf$ 同理），于是每个上和都被逐项压住，取极限即得不等式。他还补充说明：🎥 *"the proofs of all of these four here... are all in the notes"*（翻译：这四条的全部证明都在讲义里）。本讲义手稿只列陈述；下面的两个 [proof] 块按课堂板书（据字幕）补出 (2) 与 (4) 的证明，供你对照。

> <span style="color:#1e8449;">**[note] Note（译者注，符号的来历）:**</span> 记号 $\int_a^b \cdots \, dx$ 本身值得停下来看一眼。Colding 专门解释了 Leibniz 记号的词源：🎥 *"this is like a giant S. So it's referring to summation. This here is, of course, a d. And delta is the Greek letter for d. And so this here, you should think about this here as referring to some sort of limit of this delta xi."*（翻译：积分号像一个拉长的 S，指代 summation（求和）；$d$ 当然就是 $d$，而 $\delta$ 是希腊字母版的 $d$；所以 $dx$ 应当被理解为 $\Delta x_i$ 的某种极限。）也就是说：$\int$ 是"求和"的变形，$dx$ 是小区间长度 $\Delta x_i$ 在极限下的化身——黎曼和 $\sum_i M_i \Delta x_i$ 正是积分的原型。理解了这层，"上和、下和夹出积分"的整套语言就不再抽象。

<span style="color:#2471a3;">**[proof]**</span> *Proof of (2)（性质 (2) 的证明）.* 我们证明：若 $f, g$ 都 Riemann 可积，则 $f + g$ 也 Riemann 可积。给定 $\varepsilon > 0$。由于 $f$ 可积，由 L18 的引理，存在划分 $P_1$ 使得 $U(f, P_1) - L(f, P_1) < \frac{\varepsilon}{2}$；同样地，由于 $g$ 可积，存在第二个划分 $P_2$ 使得 $U(g, P_2) - L(g, P_2) < \frac{\varepsilon}{2}$。现在令 $P$ 为同时拥有 $P_1$ 与 $P_2$ 的全部分点的划分，即 $P$ 是 $P_1$ 与 $P_2$ 两者的 refinement（加细）。加细只会让上和下降、下和上升，于是

```math
U(f, P) - L(f, P) \le U(f, P_1) - L(f, P_1) < \frac{\varepsilon}{2}, \qquad U(g, P) - L(g, P) \le U(g, P_2) - L(g, P_2) < \frac{\varepsilon}{2} .
```

接着看任一小区间 $[x_{i-1}, x_i]$ 上的贡献。这里要小心一个细节：在这个区间上，

```math
m_i(f) + m_i(g) \;\le\; m_i(f + g) \;\le\; M_i(f + g) \;\le\; M_i(f) + M_i(g),
```

其中两端的两个不等式（"和的下确界不小于下确界之和"、"和的上确界不大于上确界之和"）一定成立，但中间的等号不必成立——两个不等式都可能严格。Colding 给的反例是：取 $g = -f$，则 $f + g$ 恒为零，而 $M_i(f) + M_i(g)$ 与 $m_i(f) + m_i(g)$ 是一正一负的两个数，可以离 $0$ 很远。由上述不等式，这个小区间对上、下和之差的贡献满足

```math
\bigl(M_i(f + g) - m_i(f + g)\bigr)\,\Delta x_i \;\le\; \bigl(M_i(f) - m_i(f)\bigr)\,\Delta x_i + \bigl(M_i(g) - m_i(g)\bigr)\,\Delta x_i .
```

对所有 $i$ 求和，右边恰好拆成两个黎曼和之差，得

```math
U(f + g, P) - L(f + g, P) \;\le\; \bigl[U(f, P) - L(f, P)\bigr] + \bigl[U(g, P) - L(g, P)\bigr] \;<\; \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon .
```

由引理即知 $f + g \in \mathcal{R}([a, b])$。至于积分的等式部分：把上面得到的 $m_i(f) + m_i(g) \le m_i(f+g) \le M_i(f) + M_i(g)$ 两端对 $i$ 求和并取极限，配合 $f+g$ 与 $f+g$ 上、下积分的夹逼，即得 $\int_a^b (f+g)\,dx = \int_a^b f\,dx + \int_a^b g\,dx$。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这个证明是两个老模板的合体。第一个是**「公共加细法」**：两个函数各自给出一个"好划分"，两者未必相同，就把它们的分点并起来得到公共加细 $P$——由于加细只会改善上、下和，两个函数的好性质在 $P$ 下同时保留。Colding 特别提醒这里有两处易错：一是"一个函数一个划分"，必须取并；二是**"$\sup$ 与 $\inf$ 不与加法交换"**：🎥 *"when you're looking at two functions, and you're looking at a little interval, and you're taking the sup of the sum, then that's bounded by the sum of the sup. But it's not equal to the sum, and likewise for the inf."*（翻译：对两个函数在小区间上取和的上确界，它被上确界之和所控制，但并不等于上确界之和，下确界同理。）第二个模板是**「ε/2 劈分」**：把目标误差 $\varepsilon$ 平半分给 $f$ 与 $g$，各自出一张牌再合并——这正是你在 L06 柯西收敛、L11 度量空间"收敛 ⇒ 柯西"证明里见过的同一副骨架。还要注意：本证明只用引理证了"可积性"，等式部分是顺着同样的上、下和不等式夹逼出来的，两条结论的证明深度并不对称。

<span style="color:#2471a3;">**[proof]**</span> *Proof of (4)（性质 (4) 的证明）.* 先证：$f$ 在 $[a, b]$ 上可积，则 $f$ 限制到 $[a, c]$ 与 $[c, b]$ 这两个子区间上仍可积。再次使用引理：给定 $\varepsilon > 0$，由于 $f$ 在 $[a, b]$ 上可积，存在划分 $P$ 使得 $U(f, P) - L(f, P) < \varepsilon$。划分 $P$ 未必把 $c$ 作为分点，于是取 $P^*$ 为在 $P$ 的全部分点之外再添入 $c$ 的加细（若 $c$ 本来就是分点，则 $P^* = P$ 即可）。由于 $P^*$ 是 $P$ 的加细，仍有

```math
U(f, P^*) - L(f, P^*) < \varepsilon .
```

现在把 $P^*$ 按 $c$ 切开：$P^*$ 在 $[a, c]$ 上的部分记为 $P^*|_{[a,c]}$，在 $[c, b]$ 上的部分记为 $P^*|_{[c,b]}$。由黎曼和逐段相加的算术性质，

```math
U(f, P^*) = U(f, P^*|_{[a,c]}) + U(f, P^*|_{[c,b]}), \qquad L(f, P^*) = L(f, P^*|_{[a,c]}) + L(f, P^*|_{[c,b]}) .
```

两式相减并重新排列，得

```math
\bigl[U(f, P^*|_{[a,c]}) - L(f, P^*|_{[a,c]})\bigr] + \bigl[U(f, P^*|_{[c,b]}) - L(f, P^*|_{[c,b]})\bigr] < \varepsilon .
```

方括号里的两项都是非负的（上和总不小于下和），而它们的和小于 $\varepsilon$，所以每一项各自都不超过 $\varepsilon$。由引理，$f$ 在 $[a, c]$ 与 $[c, b]$ 上都可积。至于积分的拆分等式：上述两个等式在上、下和层面本来就是"整体和等于两段之和"，对上、下积分取极限即得 $\int_a^c f\,dx + \int_c^b f\,dx = \int_a^b f\,dx$。（等式部分的细节 Colding 留作练习，并说课堂证明的核心是可积性那一半：🎥 *"But really, what I, technically speaking, proved was just this part here."*（翻译：不过严格来说，我证明的其实只是这一部分。））$\square$

### <span style="color:#2471a3;">**[corollary]**</span> <span style="color:#c0392b">Corollary（推论）</span>

设 $f, |f| \in \mathcal{R}([a, b])$，则

```math
\left| \int_a^b f(x)\,dx \right| \le \int_a^b |f(x)|\,dx .
```

> <span style="color:#7f8c8d;">TBB 8.25 (Absolute Property), §8.7, p.356（TBB 进一步证明 $f$ 可积时 $|f|$ 自动可积，见 Corollary 8.21, §8.6.4, p.355，故其陈述无需假设 $|f|$ 可积）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 这是一个非常简单却极其有用的不等式。既然已假设一切函数都 Riemann 可积，我们只需建立这个不等式。对一切 $x$ 显然有

```math
f(x) \le |f(x)|,
```

因为 $f$ 为正时二者相等，$f$ 为负时右边非负。同样显然的是 $-f(x) \le |f(x)|$。把第一条不等式（记为 $*$）与性质 (3) 结合，得 $\int_a^b f\,dx \le \int_a^b |f|\,dx$。把第二条不等式（记为 $**$）与性质 (3) 结合，得 $\int_a^b (-f)\,dx \le \int_a^b |f|\,dx$。而 $-f$ 就是 $-1$ 乘以 $f$，由性质 (1)，$-1$ 可以提到积分号外，于是左端等于 $-\int_a^b f\,dx$。两个不等式合起来，正是 $-\int_a^b f\,dx \le \int_a^b |f|\,dx$ 与 $\int_a^b f\,dx \le \int_a^b |f|\,dx$ 同时成立，即积分的绝对值被 $\int_a^b |f|\,dx$ 控制。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，方法论）:**</span> 这个证明是**「双边夹出绝对值」**的又一实例：要证 $|A| \le B$，就分别证 $A \le B$ 与 $-A \le B$，再把后者通过"提负号"归到前者。它和你在绝对值不等式 $|a + b| \le |a| + |b|$、三角不等式里用过的心法完全一样。注意证明把担子全压在性质 (1) 与 (3) 上——这也是为什么 Colding 说它"是 (3) 的 corollary（推论），而不是 (4) 的"。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Fundamental theorem of calculus（微积分基本定理）</span>

接下来要谈的是**如何计算积分**。这里的主角就是 fundamental theorem of calculus（微积分基本定理），我们给出它的两个版本。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Fundamental theorem of calculus, version 1（微积分基本定理，版本 1）</span>

设 $f$ 是 $[a, b]$ 上的连续函数，并在 $[a, b]$ 上定义

```math
F(x) = \int_a^x f(s)\,ds .
```

则函数 $F$ 是 differentiable（可微的），且其导数为 $F' = f$。

> <span style="color:#7f8c8d;">TBB 8.26 (Differentiation of the Indefinite Integral), §8.7, p.358（TBB 版本对可积 $f$ 只断言在 $f$ 的连续点处 $F'(x) = f(x)$；本讲 $f$ 连续，故结论处处成立）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 要证明 $F$ 在某点 $x_0$ 处可导，就要考察 difference quotient（差商）$\frac{F(x) - F(x_0)}{x - x_0}$，并证明它当 $x \to x_0$ 时有极限，其中 $x_0$ 固定。为了估计它，先不除，只看差 $F(x) - F(x_0)$ 本身。不妨设 $x > x_0$（从另一侧逼近的论证类似）。这时

```math
F(x) - F(x_0) = \int_a^x f(s)\,ds - \int_a^{x_0} f(s)\,ds ,
```

对第一个积分使用性质 (4)（积分可以拆开）：$\int_a^x = \int_a^{x_0} + \int_{x_0}^x$，于是

```math
F(x) - F(x_0) = \int_{x_0}^x f(s)\,ds + \int_a^{x_0} f(s)\,ds - \int_a^{x_0} f(s)\,ds = \int_{x_0}^x f(s)\,ds ,
```

后两项相消，差恰好是 $f$ 在 $[x_0, x]$ 上的积分。现在对这个积分上下夹逼：$f$ 在 $[x_0, x]$ 上连续，由 EVT（极值定理），$\max$ 与 $\sup$ 相同，且 $f(s)$ 介于该区间上 $f$ 的 $\inf$ 与 $\sup$ 之间；常数提出积分号（性质 (1)），剩下 $\int_{x_0}^x 1\,ds$ 就是区间长度，故

```math
\bigl(\inf_{[x_0,x]} f\bigr)(x - x_0) \;\le\; F(x) - F(x_0) \;\le\; \bigl(\sup_{[x_0,x]} f\bigr)(x - x_0) .
```

两边同除以 $x - x_0 > 0$，得差商被夹在 $\inf_{[x_0,x]} f$ 与 $\sup_{[x_0,x]} f$ 之间。当 $x \to x_0$ 时，$f$ 在 $x_0$ 处连续，不仅 $x$ 点的值、而是整个区间 $[x_0, x]$ 上的值都趋于 $f(x_0)$，于是夹逼的两端都趋于 $f(x_0)$。差商被两个收敛到同一数的量夹住，从而也趋于 $f(x_0)$。严格说我们只做了 $x > x_0$ 的情形；对 $x < x_0$ 从下方收敛到 $x_0$ 的情形，只需平凡修改，同样的证明成立（细节在讲义中）。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这个证明可以命名模板——**「积分中值夹逼」**。它由三件旧工具拼成：性质 (4) 负责把 $F(x) - F(x_0)$ 化简成一段积分（"差的消失"是全场最漂亮的一步）；$\sup/\inf$ 界住积分（L18 上、下和思想的单区间版）；最后由 squeeze theorem（夹逼定理）收尾。Colding 在课上把最后一步点得很白：🎥 *"this difference quotient here goes to f of x0, because it's squeezed between those two numbers that converge to the same number — namely, to little f of x0."*（翻译：这个差商趋于 $f(x_0)$，因为它被两个收敛到同一个数的量夹住了——那个数就是 $f(x_0)$。）注意这里的夹逼是"函数版的夹逼"：两端不是数列而是随 $x$ 变动的量，但其"被夹者与夹逼者同极限"的逻辑与你在 L04–L05 数列夹逼定理里学的完全同构。可微性从此有了第二个来源：L15 用差商直接定义导数，而今天看到"变上限积分"自动生成导数——微分与积分互为逆运算，正是下面版本 2 的内容。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Fundamental theorem of calculus, version 2（微积分基本定理，版本 2）</span>

设 $F : [a, b] \to \mathbb{R}$ 是可微函数，且 $F' = f \in \mathcal{R}([a, b])$，则

```math
F(b) - F(a) = \int_a^b f(s)\,ds .
```

> <span style="color:#7f8c8d;">TBB 8.27 (Integral of a Derivative), §8.7, p.358</span>

> <span style="color:#1e8449;">**[note] Note（译者注，课堂取舍与一个隐患）:**</span> 课上没有证明版本 2：🎥 *"I did the proof for this out in the notes also. So maybe I'll just skip that."*（翻译：这个证明我也写在讲义里了，所以也许我就跳过了。）但有一个值得警惕的细节，TBB 在 p.358 明确点出：由 $\int_a^b F'(x)\,dx$ 出发并不能不加检验地套用 8.27——必须先确认 $F'$ 是 Riemann 可积的，而这件事可能不成立，甚至对有界的导数也可能失败（见 TBB §9.7 的讨论）；正是黎曼积分"积不动某些导数"这一缺陷，被 Lebesgue 自述为他寻找更一般积分理论的动机。Colding 本人也不把两个版本看得彼此独立：🎥 *"I don't really think about it as two versions... it's two things about the same stuff."*（翻译：我其实并不把它当作两个版本……它们是关于同一件事的两个侧面。）课堂上的应用示范：要计算 $\int_0^1 x^2\,dx$，取 $F(x) = x^3/3$，则 $F'(x) = x^2$ 连续（从而可积），由版本 2 得原积分等于 $F(1) - F(0) = \frac{1}{3} - 0 = \frac{1}{3}$——"求极限的黎曼和"被化简成了"找 antiderivative（原函数）"，这正是 FTC 的计算威力。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Application of integrals: arclength（积分的应用：弧长）</span>

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#c0392b">Definition: Arclength（弧长）</span>

设 $f, g : [a, b] \to \mathbb{R}$ 是可微函数，且它们的导数连续，则我们定义曲线

```math
s \mapsto (f(s), g(s))
```

的 arclength（弧长）为

```math
L = \int_a^b \sqrt{(f'(s))^2 + (g'(s))^2}\,ds .
```

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这是本讲的收尾定义，只用了一段话。Colding 用 $\gamma(s) = (f(s), g(s))$ 这样的曲线记号讲它：曲线是平面上的映射，有两个坐标；他假设 $f$ 与 $g$ 可微、导数连续，参数 $s$ 跑遍区间 $[a, b]$，然后宣布"曲线的长度，按定义，就是"这个积分。这是典型的"定义而非定理"——平面曲线的弧长不是被推导出来的，而是被这个积分**规定**的（其合理性来自"小线段长度 $\sqrt{\Delta x^2 + \Delta y^2}$ 求和取极限"的直觉）。他说这个话题后面还会回来：🎥 *"Maybe I'll talk a little bit more about that next time."*（翻译：也许下次我会再多讲一点这一点。）

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1（例 1）</span>

设 $f(s) = s$，$g(s) = s^2$，则 $f'(s) = 1$，$g'(s) = 2s$。于是曲线 $(s, s^2)$（其中 $s \in [0, 1]$，即抛物线的一段）的弧长为

```math
L = \int_0^1 \sqrt{1 + (2s)^2}\,ds = \int_0^1 \sqrt{1 + 4s^2}\,ds .
```

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Improper integrals（反常积分）</span>

接下来讨论 improper integrals（反常积分，又称瑕积分）。它有两个版本：**版本 1** 是 interval（区间）无界，**版本 2** 是函数无界。当然还有各种变体（区间向左无界、左右均无界，奇点在右端点等），课上以"向右无界/奇点在左端点"为代表。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Unbounded interval（无界区间）</span>

设对一切 $b > a$ 都有 $f \in \mathcal{R}([a, b])$（$a$ 固定）。如果极限

```math
\lim_{b \to \infty} \int_a^b f(x)\,dx
```

存在，那么我们说 improper integral（反常积分）$\int_a^\infty f(x)\,dx$ 存在，且

```math
\int_a^\infty f(x)\,dx = \lim_{b \to \infty} \int_a^b f(x)\,dx .
```

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Unbounded function（无界函数）</span>

设对一切 $c > a$ 都有 $f \in \mathcal{R}([c, b])$（$a, b$ 固定，$f$ 可能在 $a$ 处无界甚至没有定义）。如果极限

```math
\lim_{c \to a^+} \int_c^b f(x)\,dx
```

存在，那么我们说反常积分 $\int_a^b f(x)\,dx$ 存在，且

```math
\int_a^b f(x)\,dx = \lim_{c \to a^+} \int_c^b f(x)\,dx .
```

> <span style="color:#7f8c8d;">TBB Definition 8.29（无界区间 $[a, \infty)$）与 Definition 8.28（无界函数，左端点奇点）, §8.8 The Improper Riemann Integral, p.359–360（TBB 标注此节为 enrichment（选学）章节，思想是回到 Cauchy 的第二方法——用极限把黎曼积分拼接出去）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，直观图像与级数的平行）:**</span> 为什么要叫"improper（反常的）"？Colding 说得直白：因为这个区间不是有界的（或函数不是有界的），黎曼积分的原始定义根本不适用，只能靠极限"外推"出去。他把积分想成 weighted area（加权面积）——"加权"只是说函数在某段取负时那块面积带负号计数。随后他给出了理解全部四个例子的总钥匙：与级数的平行。🎥 *"it's a little bit like what we did for series that you're summing infinitely many numbers."*（翻译：这有点像我们处理级数时对无穷多个数求和的情形。）判别直觉也只有一句话：函数必须"足够快地"趋于零，否则面积发散——若曲线整体停留在某条直线之上，图形下的面积就会超过那条线下的无穷大面积：🎥 *"if we kind of stay above a certain line... the area below the graph would, of course, be larger than this thing. And that would be infinite. So it's not going to converge. So it will have to go to 0 in some way."*（翻译：如果我们在某种意义上保持在某条直线之上……图形下的面积当然会大于它，而那是无穷大，所以不会收敛；函数必须以某种方式趋于零。）这与级数里"通项趋于零是收敛的必要条件、远非充分条件"如出一辙。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 2（例 2）</span>

在 $[1, \infty)$ 上设 $f(x) = \frac{1}{x^2}$，则

```math
\int_1^c \frac{1}{x^2}\,dx = \left[ -\frac{1}{x} \right]_1^c = -\frac{1}{c} + 1 .
```

由于 $-\frac{1}{c} + 1 \to 1$（当 $c \to \infty$），反常积分 $\int_1^\infty \frac{1}{x^2}\,dx$ 存在且等于 $1$。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 3（例 3）</span>

在 $[1, \infty)$ 上设 $f(x) = \frac{1}{x}$，则

```math
\int_1^c \frac{1}{x}\,dx = \bigl[\log x\bigr]_1^c = \log c .
```

反常积分

```math
\int_1^\infty \frac{dx}{x}
```

不存在（$\log c \to \infty$）。

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 例 2 与例 3 的对比是本节最重要的信息。两个函数都趋于零，命运却相反。关于例 2，Colding 先卖了个关子：🎥 *"It still goes to 0. So maybe it has a chance."*（翻译：它仍然趋于零，所以也许它有机会。）然后揭晓：$\frac{1}{x^2}$ 的制胜性质是"趋于零真的非常快"；而 $\frac{1}{x}$ 虽趋于零却"不够快"：🎥 *"It does not go to 0 fast enough."*（翻译：它趋于零的速度不够快。）这段直觉与级数完全同构：$\sum \frac{1}{n^2}$ 收敛而调和级数 $\sum \frac{1}{n}$ 发散，反常积分不过是把"离散求和"换成"连续求面积"。注意计算全程只靠微积分基本定理的版本 2：对例 2 用 $F(x) = -\frac{1}{x}$，对例 3 用 $F(x) = \log x$——FTC 是判断反常积分收敛性的实用工具。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 4（例 4）</span>

在 $(0, 1]$ 上设 $f(x) = \frac{1}{\sqrt{x}}$（当 $x \to 0$ 时函数无界），则对 $c > 0$，

```math
\int_c^1 \frac{1}{\sqrt{x}}\,dx = \bigl[\,2\sqrt{x}\,\bigr]_c^1 = 2 - 2\sqrt{c} .
```

由于 $2 - 2\sqrt{c} \to 2$（当 $c \to 0$），反常积分存在且等于

```math
\int_0^1 \frac{dx}{\sqrt{x}} = 2 .
```

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 5（例 5）</span>

在 $(0, 1]$ 上设 $f(x) = \frac{1}{x}$，则

```math
\int_c^1 \frac{1}{x}\,dx = \bigl[\log x\bigr]_c^1 = -\log c .
```

注意 $-\log c \to \infty$（当 $c \to 0$），所以反常积分

```math
\int_0^1 \frac{dx}{x}
```

不存在。

> <span style="color:#1e8449;">**[note] Note（译者注，直觉颠覆）:**</span> 例 4 是"无界函数也能有有限积分"的示范：函数在 $0$ 附近 blow up（爆炸），但图形下的面积仍然有限。Colding 问的自然是反面：如果函数爆得更快呢？例 5 给出答案——$\frac{1}{x}$ 在 $0$ 附近比 $\frac{1}{\sqrt{x}}$ 爆得更猛，积分就发散了。判断的关键照旧是看原函数在奇点处的极限行为：$2\sqrt{x}$ 在 $0$ 处有极限，$\log x$ 没有。把例 2/3（区间无界）与例 4/5（函数无界）并排看：**收敛与否取决于"无穷"被压制的速度，而不是"无穷"是否存在**——区间可以无限长，函数可以无限高，只要速度够快，面积依然有限。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Question: How do we define angle?（问题：我们如何定义角？）</span>

问题：我们如何定义 angle（角）？回答：我们通过弧长来定义它。

在单位圆

```math
\{(x, y) \mid x^2 + y^2 = 1\}
```

上，我们同时定义角与弧长。也就是说，设 $(x, y)$ 位于单位圆上，则 $(1, 0)$ 与 $(x, y)$ 之间的角 $\theta$ 定义为单位圆上从 $(1, 0)$ 到 $(x, y)$ 那一段的弧长。这一段圆弧被

```math
(f(s), g(s)) = (s, \sqrt{1 - s^2})
```

参数化，其中 $x \le s \le 1$。由于 $f'(s) = 1$ 且 $g'(s) = -\frac{s}{\sqrt{1 - s^2}}$，我们得到

```math
\theta = \int_x^1 \sqrt{1 + \frac{s^2}{1 - s^2}}\;ds = \int_x^1 \frac{1}{\sqrt{1 - s^2}}\,ds .
```

于是函数 $\arcsin x$ 定义为

```math
\arcsin x = \int_0^x \frac{1}{\sqrt{1 - s^2}}\,ds .
```

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理）:**</span> 这最后一页回答的是一个平时不会追问的问题："角"到底是什么？答案出人意料地依赖于积分：**角就是弧长**。它的好处是避免了循环论证——三角函数与反三角函数通常靠"角"来定义，而"角"又悄悄依赖长度度量；这里用"弧长的积分定义"反过来锚定 $\arcsin$，再由 $\sin(\arcsin x) = x$ 恢复正弦函数，逻辑链条上没有环。验证一下被积函数：$f'(s) = 1$，$g'(s) = \frac{-s}{\sqrt{1 - s^2}}$，故 $\sqrt{1 + \frac{s^2}{1 - s^2}} = \sqrt{\frac{1}{1 - s^2}} = \frac{1}{\sqrt{1 - s^2}}$，这正是 $\arcsin$ 的标准导数 $\frac{1}{\sqrt{1 - x^2}}$ 的积分形式。用"积分定义函数"的手法你已经见过一次：对数函数同样可以被定义为 $\log x = \int_1^x \frac{ds}{s}$（例 3 正是基于它）——这是分析学处理初等函数的统一姿势。
