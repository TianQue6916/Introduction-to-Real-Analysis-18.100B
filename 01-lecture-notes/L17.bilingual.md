### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Recall: The Taylor expansion theorem（回顾：泰勒展开定理）</span>

回忆一下，上一讲我们证明了 Taylor expansion theorem（泰勒展开定理）：

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem: Taylor expansion（泰勒展开定理）</span>

设 $f : [a, b] \to \mathbb{R}$ 是一个函数，$k$ 是正整数。假设 $f, f', f^{(2)}, \cdots, f^{(k-1)}$ 在 $[a, b]$ 上存在且连续，而 $f^{(k)}$ 在 $(a, b)$ 上有定义，则存在介于 $a$ 与 $b$ 之间的 $c$ 使得

```math
f(b) = f(a) + f'(a) (b - a) + \frac{f^{(2)}(a)}{2} (b - a)^2 + \cdots + \frac{f^{(k-1)}(a)}{(k - 1)!} (b - a)^{k-1} + \frac{f^{(k)}(c)}{k!} (b - a)^k .
```

> <span style="color:#7f8c8d;">TBB Theorem 7.43 (Lagrange 余项形式), §7.12 Taylor Polynomials, p.320（该节自 p.319 起）</span>

对 $\mathbb{R}$ 上 infinitely differentiable（无穷次可导）的函数 $f$，我们把它在 $a$ 处的 $(k-1)$ 阶 Taylor polynomial（泰勒多项式）定义为

```math
P_{k-1}(x) = f(a) + f'(a) (x - a) + \frac{f^{(2)}(a)}{2} (x - a)^2 + \cdots + \frac{f^{(k-1)}(a)}{(k - 1)!} (x - a)^{k-1} .
```

> <span style="color:#7f8c8d;">TBB §7.12, p.319–321（TBB 记 $P_n$ 为 nth Taylor polynomial，并指出它是泰勒级数的第 $n$ 个部分和）</span>

<span style="color:#2471a3;">**[question]**</span> <span style="color:#c0392b">**Question（问题）.**</span> 很自然会问：当 $x$ 靠近 $a$ 时，这个多项式把 $f$ 逼近（approximate）得有多好？

<span style="color:#2471a3;">**[answer]**</span> <span style="color:#c0392b">**Answer（回答）.**</span> 这取决于 remainder（余项）

```math
R_k(x) = \frac{f^{(k)}(c)}{k!} (x - a)^k
```

的值。

And these are these—L'Hopital's rule."*（翻译：第二件我想谈的事，是我们上次没来得及讲的内容——也就是洛必达法则。）而且当堂只讲了一个版本：🎥 *"There are two versions, and they're both in the notes, but I will just state one of them."*（翻译：有两个版本，它们都在讲义里，但我只陈述其中一个。）视频里还重演了"取 $g(x) = x$ 由 Cauchy 中值定理恢复普通中值定理"的观察。本讲义文本则直接从泰勒展开定理的回顾切入。本节还有一个贯穿全讲的问题意识：余项 $R_k(x)$ 的表达式里藏着那个"介于 $a$ 与 $x$ 之间的 $c$"，而我们对它几乎一无所知。Colding 点破了难处：🎥 *"The catch is, that you don't really know what c is. The only thing you know about c is that c is lying between a and x."*（翻译：麻烦在于，你并不知道 $c$ 是什么——关于 $c$ 你唯一知道的就是它介于 $a$ 与 $x$ 之间。）接下来两个例子（一好一坏）正是围绕"如何与这个未知的 $c$ 打交道"展开的。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Two examples（两个例子）</span>

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1: The exponential function（例 1：指数函数）</span>

设 $f(x) = e^x$，则对一切 $k$ 都有 $f^{(k)}(x) = f(x)$。这意味着在 $a = 0$ 附近的泰勒展开变为

```math
P_{k-1}(x) = \sum_{i=0}^{k-1} \frac{x^i}{i!} .
```

由泰勒展开定理我们有

```math
f(x) = P_{k-1}(x) + \frac{f^{(k)}(c)}{k!} x^k .
```

由于对一切 $k$ 都有 $f^{(k)}(x) = f(x)$，由泰勒展开定理可得

```math
|f(x) - P_{k-1}(x)| \le \frac{e^{|x|}}{k!} .
```

我们得出结论：当 $k$ 很大时，多项式 $P_{k-1}$ 给出 $f$ 的相当好的逼近。例如，若 $|x| \le 1$，则我们有

```math
|f(x) - P_{k-1}(x)| \le \frac{e}{k!} .
```

> <span style="color:#1e8449;">**[note] Note（译者注，跨讲连接与"好的那一个"）:**</span> 这个例子把你带回了 L08–L09 的幂级数世界：$\sum_{i=0}^{\infty} \frac{x^i}{i!}$ 正是 $e^x$ 的幂级数展开，而泰勒多项式 $P_{k-1}$ 就是它的部分和——泰勒定理如今给出了"部分和与真值相差多少"的定量答案。估计的要点是压住那个未知的 $c$：由 $c$ 介于 $0$ 与 $x$ 之间，得 $e^c \le e^{|x|}$；$k!$ 的爆炸式增长让余项迅速归零。Colding 在课上对这个收敛速度有个很生动的口误式强调：🎥 *"you don't even need to make k very large because it's exponential. Not exponential, it's factorial."*（翻译：你甚至不需要让 $k$ 很大，因为它是指数级的——不对，是阶乘级的。）另外提醒一个概念细节：泰勒多项式是"围绕 $a$"展开的，把 $x = a$ 代入自然精确相等，所有导数也在 $a$ 处取值，所以 🎥 *"the Taylor polynomial, it's only a good approximation near a"*（翻译：泰勒多项式只在 $a$ 附近才是好的逼近）。想"逼近得更远"，就是下一节学生提问的主题。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 2: A function equal to its remainder（例 2：一个等于自己余项的函数）</span>

在 $\mathbb{R}$ 上定义函数 $f$ 为

```math
f(x) = \begin{cases} 0 & \text{if } x \le 0 \\ e^{-\frac{1}{x^2}} & \text{otherwise} \end{cases}
```

容易看出 $f$ 是无穷次可导的，且对一切 $k$ 都有 $f^{(k)}(0) = 0$。于是对一切 $k$，在 $0$ 处的泰勒多项式都满足 $P_{k-1} \equiv 0$。因此在这个情形下 $f(x) = R_k(x)$。

> <span style="color:#1e8449;">**[note] Note（译者注，直觉颠覆：泰勒多项式可以完全失灵）:**</span> 这个反例与例 1 形成刻意的对照：泰勒逼近的质量**取决于函数本身**。当 $x \to 0^+$ 时 $e^{-1/x^2}$ 的指数上是一个巨大的负数，函数值"小到不可理喻"，于是在 $0$ 处任何阶导数都是 $0$——泰勒多项式的所有系数全为零。Colding 的原话：🎥 *"all of the coefficients in the polynomial are 0. So this polynomial is just 0."*（翻译：多项式的所有系数都是 $0$，所以这个多项式就是 $0$。）于是 $f$ 与它的泰勒多项式之差就是 $f$ 自己：$f(x) = R_k(x)$，余项完全没有变小。🎥 *"the Taylor polynomial is too trivial. It doesn't really help you all that much."*（翻译：这个泰勒多项式太平凡了，帮不上你什么忙。）这说明"无穷次可导"远弱于"能被泰勒级数表示"（后者称为 analytic（解析））：此函数的泰勒级数收敛到 $0$，而不是收敛到 $f$。顺带一提，这类"光滑截断"函数是构造光滑单位分解、光滑支集函数的标准原材料，在微分几何与偏微分方程理论中会反复遇到。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Riemann integrals（黎曼积分）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理：从矩形出发）:**</span> 这是本讲第二 half（半场）的全新主题。定义积分有若干种不同的方式（TBB 前几节走的是 Cauchy 的两条路线，§8.2 与 §8.4），视频里 Colding 说以黎曼命名的这种方式"也许是最自然的"。目标只有一个：对区间 $[a, b]$ 上的有界函数 $f$，定义 graph below area（图像下方的面积）。而他强调地基只有一块砖：🎥 *"if this length here is d, and this here is e, then you know that the area here—so area—is d times e. That's the only thing we have."*（翻译：如果这段长是 $d$、这段是 $e$，那么这块面积就是 $d$ 乘 $e$——这是我们唯一拥有的东西。）整座积分大厦就建在"矩形面积"上：用分割把 $[a, b]$ 切成小段，每段上用矩形从外面罩住函数（上和）或从里面垫住函数（下和）。若函数穿过 $x$ 轴，还有符号约定：🎥 *"then this area here would count negatively and this area here would count positively."*（翻译：那么这边的面积按负的计，那边的面积按正的计。）你从微积分里背过的 $\int_a^b f\,dx$，在这里将第一次获得严格的定义。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Partition（分割）</span>

设 $[a, b]$ 是一个区间。区间 $[a, b]$ 的一个 partition（分割）$P$ 是若干 sub-division（细分点）$x_i$，使得

```math
a = x_0 < x_1 < x_2 < \cdots < x_n = b .
```

这个分割就是那些 sub-interval（子区间）$[x_{i-1}, x_i]$。我们记 $\Delta x_i = x_i - x_{i-1}$。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Upper and lower sums（上和与下和）</span>

现在设 $f : [a, b] \to \mathbb{R}$ 是一个 bounded function（有界函数），且 $P = \{x_i\}$ 是区间 $[a, b]$ 的一个分割。我们如下定义上和与下和。令

```math
M_i = \sup_{[x_{i-1}, x_i]} f ,
```

```math
m_i = \inf_{[x_{i-1}, x_i]} f ,
```

并定义 upper sum（上和）$U(f, P)$ 与 lower sum（下和）$L(f, P)$ 为

```math
U(f, P) = \sum_{i=1}^{n} M_i \, \Delta x_i ,
```

```math
L(f, P) = \sum_{i=1}^{n} m_i \, \Delta x_i .
```

> <span style="color:#7f8c8d;">TBB Exercise 8.2.17, p.338（上/下和在 TBB 中以习题形式引入：$M(f, \dot{\mathcal{P}})$、$m(f, \dot{\mathcal{P}})$）；Darboux 积分视角见 TBB Exercise 8.10.1, §8.10, p.363</span>

> <span style="color:#1e8449;">**[note] Note（译者注，几何图像）:**</span> 上和与下和的几何含义是"外接矩形"与"内接矩形"：在子区间 $[x_{i-1}, x_i]$ 上，$M_i \Delta x_i$ 是能罩住图像的最小矩形面积（高度取上确界），$m_i \Delta x_i$ 是能塞进图像下方的最大矩形面积（高度取下确界）。注意上确界/下确界（而不是最大值/最小值）的使用是刻意的——它使定义对任意有界函数都有意义，哪怕函数在这些子区间上根本取不到极值。这与 L11 极值定理的教训一脉相承：**sup 与 inf 永远存在（有界集内），max 与 min 却未必被取到**。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 3（例 3）</span>

设函数为区间 $[-2, 2]$ 上的 $f(x) = x^2 + 1$，分割为 $P = \{-2, -1, 0, 1, 2\}$。我们有

```math
m_1 = 2 \text{ 且 } M_1 = 5 ,
```

```math
m_2 = 1 \text{ 且 } M_2 = 2 ,
```

```math
m_3 = 1 \text{ 且 } M_3 = 2 ,
```

```math
m_4 = 2 \text{ 且 } M_4 = 5 .
```

对下和与上和我们有

```math
L(f, P) = 2 + 1 + 1 + 2 = 6 ,
```

```math
U(f, P) = 5 + 2 + 2 + 5 = 14 .
```

下面的引理是立时的（immediate）——由每个子区间上 $M_i \ge m_i$ 立得：

### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 1（引理 1）</span>

我们总有

```math
L(f, P) \le U(f, P) .
```

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Sub-partitions（子分割）</span>

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Sub-partition（子分割）</span>

设 $[a, b]$ 是一个区间，$P_1$ 与 $P_2$ 是区间 $[a, b]$ 的两个分割。若 $P_1$ 的所有分点也在 $P_2$ 中（于是 $P_2$ 大概还有一些额外的分点），我们就说 $P_2$ 是 $P_1$ 的 sub-partition（子分割），或 refinement（加细）。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 4（例 4）</span>

设区间为 $[-2, 2]$，给定的分割 $P_1$ 为

```math
\{-2, -1, 0, 1, 2\} .
```

则分割

```math
P_2 = \left\{-2, -\frac{3}{2}, -1, 0, \frac{1}{2}, 1, 2\right\}
```

是 $P_1$ 的一个加细（或细分）。确实，$P_2$ 除了拥有 $P_1$ 的全部分点之外还多出一些分点。

现在我们有：

### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 2（引理 2）</span>

设 $f : [a, b] \to \mathbb{R}$ 是有界函数，$P_1$ 是区间 $[a, b]$ 的分割，$P_2$ 是 $P_1$ 的加细，则

```math
L(f, P_1) \le L(f, P_2) \le U(f, P_2) \le U(f, P_1) .
```

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 中间那个不等式就是前一条引理。右边的不等式来自"$P_2$ 是 $P_1$ 的细分"这一事实。也就是说，设 $a = x_0 < x_1 < \cdots < x_n = b$ 是 $P_1$ 的分点，并设在 $x_{i-1}$ 与 $x_i$ 之间有 $P_2$ 的一个额外分点 $y$，即 $x_{i-1} < y < x_i$，则我们有

```math
\sup_{[x_{i-1}, y]} f \le M_i
```

以及

```math
\sup_{[y, x_i]} f \le M_i ,
```

于是

```math
\left[ \sup_{[x_{i-1}, y]} f \right] (y - x_{i-1}) + \left[ \sup_{[y, x_i]} f \right] (x_i - y) \le M_i \, \Delta x_i .
```

由此容易得出

```math
U(f, P_2) \le U(f, P_1) .
```

左边的不等式同理（把 sup 换成 inf）。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 引理 2 说的是同一件事的两面：**加细分割后，上和只降不升，下和只升不降**——"罩在外面"的矩形随分割变细而收紧，"垫在下面"的矩形随分割变细而长高。证明只用了 sup 的单调性（大区间上的上确界 ≥ 小区间上的上确界）加上一次拆项合并（$(y - x_{i-1}) + (x_i - y) = \Delta x_i$）。Colding 对这组不等式的评价是：每一步都平凡，但合起来非平凡——🎥 *"Each of these steps is completely trivial, but together, it actually means that you can really define something non-trivial."*（翻译：每一步都完全平凡，但合在一起，它实际上意味着你真的能定义出一个非平凡的东西。）这正是分析学里"用平凡的估计搭建深刻定义"的典型路径。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Upper and lower integrals; the Riemann integral（上积分与下积分；黎曼积分）</span>

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Upper and lower Riemann integrals（上黎曼积分与下黎曼积分）</span>

现在设 $f : [a, b] \to \mathbb{R}$ 是有界函数。定义 $f$ 的 upper Riemann integral（上黎曼积分）为

```math
\overline{\int_a^b} f \, dx = \inf_P U(f, P) .
```

这里的 infimum（下确界）取遍 $[a, b]$ 的所有分割。同样地，我们定义 lower Riemann integral（下黎曼积分）为

```math
\underline{\int_a^b} f \, dx = \sup_P L(f, P) .
```

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断："极限"要打引号）:**</span> 直觉上，上积分是"分割越取越细时上和的极限"，下积分是对偶的下和极限。但严格说来这里并没有取极限——Colding 特意澄清：🎥 *"when I say that it's a limit over finer and finer partitions, you should really think about that in quotation marks... the precise statement is just that it's infimum over all partitions."*（翻译：当我说"越来越细的分割上的极限"时，你真应该把这句话放进引号里理解……精确的陈述就是：对所有分割取下确界。）课后还有学生追问是不是只允许有限多个分点，他补充了关键设定：每个分割只有 finitely many（有限多个）分点，但分割的全体是无穷的——"取极限"只是对无穷多个分割值取 sup/inf 的形象说法。把"直观说法"与"精确定义"分开，是这门课从第一讲起就在训练的习惯。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Riemann integrable（黎曼可积）</span>

设 $f : [a, b] \to \mathbb{R}$ 是有界函数。若

```math
\underline{\int_a^b} f \, dx = \overline{\int_a^b} f \, dx ,
```

我们就说 $f$ 是 Riemann integrable（黎曼可积）的。若函数黎曼可积，则 Riemann integral（黎曼积分）就是

```math
\int_a^b f \, dx = \overline{\int_a^b} f \, dx = \underline{\int_a^b} f \, dx .
```

黎曼可积函数全体记作 $\mathcal{R}([a, b])$。

> <span style="color:#7f8c8d;">TBB Definition 8.12, §8.6 The Riemann Integral, p.347–348（TBB 主线用 Riemann sum（黎曼和）极限定义黎曼可积；上/下积分的 Darboux 定义见 TBB Exercise 8.10.1, §8.10, p.363，其中让读者自证两种定义等价）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，"躲懒"背后的真问题）:**</span> 这个定义乍看像是"躲懒"：我们并没有直接定义 $\int f\,dx$，而是说"当上、下积分相等时才有积分"。Colding 自己承认了这一点：🎥 *"you may think that we wimped out of saying when this—because we just define it, we just say that it's Riemann-integrable if those two things are equal. But then the question, of course, becomes, when are those two things equal?"*（翻译：你们可能觉得我们在这里躲懒了——因为我们只是定义：若这两样东西相等，就称它是黎曼可积的。但问题当然就变成了：这两样东西何时相等？）这才是本讲真正的引擎：**"何时相等"是可积性理论的核心问题**。另一个值得注意的口径细节：TBB 教材的正文用黎曼和的极限（Definition 8.12）来定义可积性，而本讲采用上/下积分（Darboux 式）的定义——两种定义等价，TBB 把等价性留作练习（Exercise 8.10.1）。读教材与听课时若发现定义"长得不一样"，先查等价性，再对照两条路线的证明风格。

> <span style="color:#1e8449;">**[note] Note（译者注，人物背景，译自讲义所引 Wikipedia）:**</span> 讲义此处原文附了一段 Wikipedia 的黎曼小传，逐句译出如下。Georg Friedrich Bernhard Riemann（格奥尔格·弗里德里希·伯恩哈德·黎曼，1826–1866）是一位德国数学家，他在 analysis（分析学）、number theory（数论）与 differential geometry（微分几何）中都做出了深刻的贡献。黎曼于 1854 年首次开课授课，这些讲稿创立了 Riemannian geometry（黎曼几何）这一领域，从而为 Albert Einstein 的 general theory of relativity（广义相对论）搭好了舞台。在实分析领域，他最广为人知的是对积分的首次严格表述——即 Riemann integral（黎曼积分）——以及他在 Fourier series（傅里叶级数）上的工作。他对 complex analysis（复分析）的贡献中最著名的是引入 Riemann surface（黎曼面），为复分析的自然而几何化的处理开辟了新天地。他 1859 年关于 prime-counting function（素数计数函数）的论文——其中包含 Riemann hypothesis（黎曼猜想）的原始陈述——被公认为 analytic number theory（解析数论）的奠基性论文。许多人认为他是历史上最伟大的数学家之一。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 5: Not Riemann integrable（例 5：不可积的有界函数）</span>

设 $f : [0, 1] \to \mathbb{R}$ 为

```math
f(x) = \begin{cases} 1 & \text{if } x \in [0, 1] \cap \mathbb{Q} \\ 0 & \text{otherwise} \end{cases}
```

对此函数与一切分割 $P$ 我们都有

```math
L(f, P) = 0 \text{ 且 } U(f, P) = 1 .
```

因此 $f$ 不是黎曼可积的。

> <span style="color:#7f8c8d;">TBB Example 8.13, §8.6.1 Some Examples, p.349（同一函数：有理点取 $1$、无理点取 $0$，任何黎曼和都无法收敛）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 这就是著名的 Dirichlet function（狄利克雷函数）的变体。为什么对一切分割都有 $L = 0$、$U = 1$？因为任何子区间内既有有理数又有无理数：有理点的存在逼出 $M_i = 1$，无理点的存在压住 $m_i = 0$——上和与下和之间隔着永远无法弥合的鸿沟 $1$。这个例子宣告：**有界远远不足以保证可积**。有趣的是，TBB Example 8.14（§8.6.1, p.349）紧随其后给出了一个"不连续点稠密、却仍可积"的对照例子（Thomae 函数：$f(p/q) = 1/q$），说明"不连续"并不自动判死刑——真正的判据（不连续点集"测度为零"）要到 Lebesgue 的判别法，本课不展开。

我们将会关心这两个问题："什么样的函数是黎曼可积的？"……以及"我们如何计算积分？"第二个问题的答案将是 fundamental theorem of calculus（微积分基本定理）。这将是后面某一讲的主题。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">A criterion for integrability（可积性判据）</span>

### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 3（引理 3）</span>

设 $f : [a, b] \to \mathbb{R}$ 是有界函数，则 $f \in \mathcal{R}([a, b])$ 当且仅当对任意 $\varepsilon > 0$，存在一个分割 $P$ 使得

```math
U(f, P) - L(f, P) < \varepsilon .
```

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 设 $f \in \mathcal{R}([a, b])$，则

```math
\sup_P L(f, P) = \underline{\int_a^b} f \, dx = \overline{\int_a^b} f \, dx = \inf_P U(f, P) .
```

这意味着：给定 $\varepsilon > 0$，存在分割 $P_1$ 与 $P_2$ 使得

```math
\int_a^b f \, dx - \frac{\varepsilon}{2} < L(f, P_1)
```

以及

```math
U(f, P_2) < \int_a^b f \, dx + \frac{\varepsilon}{2} .
```

令 $P$ 为同时拥有 $P_1$ 与 $P_2$ 全部分点的分割，于是 $P$ 是 $P_1$ 与 $P_2$ 两者的加细。由此得

```math
\int_a^b f \, dx - \frac{\varepsilon}{2} < L(f, P_1) \le L(f, P) \le U(f, P) \le U(f, P_2) < \int_a^b f \, dx + \frac{\varepsilon}{2} .
```

这就证明了命题的前一半。

为看相反方向，设对任意 $\varepsilon > 0$ 存在分割 $P$ 使得 $U(f, P) - L(f, P) < \varepsilon$。由于

```math
L(f, P) \le \underline{\int_a^b} f \, dx
```

以及

```math
\overline{\int_a^b} f \, dx \le U(f, P) ,
```

我们有

```math
\overline{\int_a^b} f \, dx - \underline{\int_a^b} f \, dx \le U(f, P) - L(f, P) < \varepsilon .
```

由于这对一切 $\varepsilon > 0$ 成立，我们得到结论。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板与文本复原说明）:**</span> 前一半的证明又是你在 L06（Cauchy 收敛定理）与 L11（序列-连续性引理）里见过的**「ε/2 劈分」**模板：让 $P_1$ 的下和从下方贴住下积分、$P_2$ 的上和从上方贴住上积分，各担 $\frac{\varepsilon}{2}$；再用引理 2 的单调性把两个分割"合并加细"成 $P$，四条不等式一串联，上积分与下积分就被夹进宽度 $\varepsilon$ 的窗口里。后半句只需一次相减。**文本复原说明**：源 PDF 中本证明的两行积分上下确界记号（上划线/下划线积分）在提取时丢失，上面按上下文还原；另外原文倒数第二段写 "suppose that for some $\varepsilon > 0$"，按引理假设应为"对任意 $\varepsilon > 0$"，译文已按引理陈述改正。TBB 的对应结果是 Theorem 8.16（§8.6.2 Riemann's Criteria, p.351）——用 oscillation（振幅）$\omega(f([x_{k-1}, x_k]))$ 表述的可积性充要条件；其前的 Theorem 8.15（Riemann, p.351）则要求"所有足够细的分割"满足条件，本讲的"存在一个分割"版本正是 TBB 强调的"更容易应用的变体"。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Continuous functions are integrable; uniform continuity（连续函数可积；一致连续）</span>

我们现在来到一个关键定理，它给出了"函数黎曼可积"的一个简单判据：

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem（定理）</span>

$[a, b]$ 上的任何连续函数都属于 $\mathcal{R}([a, b])$。

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 我们将在下一讲证明它——先证明"闭有界区间上的连续函数其实是一致连续的"之后再来证。$\square$

> <span style="color:#7f8c8d;">TBB §8.6 开头的两条 observations（p.348–349）：所有连续函数都黎曼可积；所有黎曼可积函数都有界</span>

> <span style="color:#1e8449;">**[note] Note（译者注，课后问答实录）:**</span> 视频在下课前只把这个定理立为"欠账"，并预告了证明路线（先证一致连续）。课堂上学生追问这是不是充要条件，Colding 的回答很值得记住：🎥 *"No... It's a good initial answer, but there are many functions that are not continuous that... play key roles."*（翻译：不是……它是一个很好的初始答案，但有许多不连续的函数扮演着关键角色。）也就是说：**连续是可积的充分条件，而非必要条件**——黎曼可积函数可以有不连续点（甚至稠密的不连续点，见 TBB Example 8.14），只是"不能坏得太厉害"。他还说明对"上积分 ≥ 下积分"的证明也要留到下一讲：🎥 *"we return to that next time because to make it really clear, it will take a few minutes."*（翻译：这个我们下次再讲，因为要把它真正讲清楚，需要几分钟。）

这个定理的证明需要下面这个关键概念。

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Uniformly continuous（一致连续）</span>

设 $f : I \to \mathbb{R}$ 是一个函数，其中 $I$ 是一个区间。若对任意 $\varepsilon > 0$，存在一个 $\delta > 0$ 使得只要 $|x - y| < \delta$ 就有

```math
|f(x) - f(y)| < \varepsilon ,
```

我们就称 $f$ 是 uniformly continuous（一致连续）的。

注意：一致连续比连续更强。它的意思是：对一个给定的 $\varepsilon > 0$，同一个 $\delta$ 可以用于所有的 $x$。

> <span style="color:#7f8c8d;">TBB Definition 5.46, §5.6 Uniform Continuity, p.219；TBB Theorem 5.48（$[a,b]$ 上连续 ⇒ 一致连续），§5.6, p.220</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 把这个定义与 L11 开头的逐点连续定义并排看，差别只有一个字：逐点版本里 $\delta = \delta(x_0, \varepsilon)$ 可以随点变化，一致连续版本要求 $\delta = \delta(\varepsilon)$ 对整个区间**统一**适用——这就是 "uniformly"（一致）的含义。反例直击要害：$f(x) = \frac{1}{x}$ 在 $(0, 1)$ 上连续但不一致连续（TBB Example 5.45 正用此例说明 $\delta$ 无法对所有 $x_0$ 统一选取）。为什么连续性证明可积性需要这个升级？轮廓已在：要把 $U(f, P) - L(f, P) = \sum_i (M_i - m_i)\Delta x_i$ 压小，需要"每个子区间上振幅都小"，而这恰好要求"同一个 $\delta$ 处处有效"——逐点连续只能保证"每个点各自存在某个 $\delta$"，无法统一拼成有限分割。闭有界区间上连续 ⇒ 一致连续（TBB Theorem 5.48, p.220）正是补上这一环的关键，下一讲见分晓。
