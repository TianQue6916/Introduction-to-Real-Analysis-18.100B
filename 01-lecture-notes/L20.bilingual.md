### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Application of integrals: arclength（积分的应用：弧长）</span>

设 $f, g : [a, b] \to \mathbb{R}$ 是可微函数，且它们的导数连续，则我们定义曲线

```math
s \mapsto (f(s), g(s))
```

的 arclength（弧长）为

```math
L = \int_a^b \sqrt{(f'(s))^2 + (g'(s))^2}\,ds .
```

> <span style="color:#1e8449;">**[note] Note（译者注，定义的合理性）:**</span> 本页开头的弧长定义在上一讲（L19）结尾已经出现过，今天 Colding 先花几分钟把"为什么这是一个合理的定义"补讲完整——讲义正文只给定义，论证全在口头。他的思路是一个可复用的模板——**「分割 + 线段逼近 + 中值定理 + 黎曼和」**：把 $[a, b]$ 分成小区间，曲线上每一小段用连接端点的 line segment（线段）近似，线段长度由 Pythagoras（勾股定理）给出为 $\sqrt{(\Delta f)^2 + (\Delta g)^2}$；关键一步是请 mean value theorem（中值定理，L16）出场，把每个增量 $\Delta f$ 化成"中间点的导数乘以 $\Delta s$"：🎥 *"the mean value theorem tells you that this thing here is essentially the derivative at some point in between these two."*（翻译：中值定理告诉你，这个量本质上就是这两点之间某个中间点处的导数。）于是每段线段长变成 $\sqrt{(f'(\xi))^2 + (g'(\eta))^2}\,\Delta s$，由 $f'$、$g'$ 连续，中间点的值可以用端点值近似，求和后令 $\Delta s \to 0$，黎曼和就收敛到上面的积分。你在 L17–L18 学的黎曼积分理论正是这一步的地基。

---

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1（例 1）</span>

设 $f(s) = s$，$g(s) = s^2$，则 $f'(s) = 1$，$g'(s) = 2s$。于是曲线 $(s, s^2)$（其中 $s \in [0, 1]$）的弧长为

```math
L = \int_0^1 \sqrt{1 + (2s)^2}\,ds = \int_0^1 \sqrt{1 + 4s^2}\,ds .
```

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Question: How do we define angle?（问题：我们如何定义角？）</span>

问题：我们如何定义 angle（角）？答案：我们通过弧长来定义它。

在 unit circle（单位圆）

```math
\{(x, y) \mid x^2 + y^2 = 1\}
```

上，我们定义角与弧长。也就是说，设 $(x, y)$ 落在单位圆上，则 $(1, 0)$ 与 $(x, y)$ 之间的角 $\theta$ 定义为单位圆上从 $(1, 0)$ 到 $(x, y)$ 那一段的弧长。这一段圆弧由 $(f(s), g(s)) = \left(s, \sqrt{1 - s^2}\right)$ 参数化，其中 $x \le s \le 1$。由于 $f'(s) = 1$ 且 $g'(s) = -\dfrac{s}{\sqrt{1 - s^2}}$，我们得到

```math
\theta = \int_x^1 \sqrt{1 + \frac{s^2}{1 - s^2}}\;ds = \int_x^1 \frac{1}{\sqrt{1 - s^2}}\,ds .
```

于是函数 $\arccos x$ 定义为

```math
\arccos x = \int_x^1 \frac{1}{\sqrt{1 - s^2}}\,ds .
```

由 fundamental theorem of calculus（微积分基本定理，L19）我们看到

```math
(\arccos x)' = -\frac{1}{\sqrt{1 - x^2}} .
```

> <span style="color:#1e8449;">**[note] Note（译者注，第一性原理）:**</span> "角"通常被默认为原始概念，这里却被弧长（一个积分）定义——这是 Colding 刻意避免循环论证的做法：🎥 *"The angle is defined as the arc length of the curve."*（翻译：角被定义为曲线的弧长。）两个技术细节值得吃透。其一，$(\arccos x)'$ 带负号，是因为积分变量 $x$ 出现在**下限**而不是上限；处理手法是把 $\int_x^1 = \int_a^1 - \int_a^x$ 拆成"常数减去一个上限积分"，常数的导数为 $0$，于是只剩负号：🎥 *"if it is downstairs and not upstairs, you have to just remember the sign."*（翻译：如果变量在下限而不是上限，你只需记住这个符号。）这正是 L19 微积分基本定理的下限变体。其二，把本页与 L19 结尾对照：那里定义了 $\arcsin x = \int_0^x \frac{ds}{\sqrt{1 - s^2}}$，这里定义了 $\arccos x = \int_x^1 \frac{ds}{\sqrt{1 - s^2}}$，两者恰好相差一个常数——对 $0 < x < 1$ 有 $\arcsin x + \arccos x = \frac{\pi}{2}$，同一个被积函数，从不同端点积分，就得到互余的两个反三角函数。这也解释了为什么"用积分定义函数"是分析学的标准姿势（对数函数 $\log x = \int_1^x \frac{ds}{s}$ 是另一个例子）。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Pointwise convergence（逐点收敛）</span>

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Pointwise convergence（逐点收敛）</span>

设 $f_n$ 是区间 $I$ 上的一列函数（即 function sequence，函数列），则我们说 $f_n$ pointwise（逐点）收敛到函数 $f$，如果对一切 $x$ 都有

```math
f_n(x) \to f(x) .
```

> <span style="color:#7f8c8d;">TBB Definition 9.2, §9.2 Pointwise Limits, p.367</span>

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 这个定义的要点是**降维**：把"函数列的收敛"拆成"一串数列的收敛"。固定一个 $x$，$f_1(x), f_2(x), \dots$ 就只是普通的实数列，你在 L04–L07 积累的全部数列工具立刻适用。Colding 在课上反复强调固定 $x$ 这个动作：🎥 *"So this is a sequence of real numbers because x is fixed. Then you want this thing here to converge to f of x."*（翻译：因为 $x$ 是固定的，这就是一个实数列，然后你要它收敛到 $f(x)$。）但立刻要问一个致命问题：定义里"对每个固定的 $x$，存在 $N$"——**这个 $N$ 允许依赖 $x$**。🎥 *"there exists an N. But this N is now allowed to depend on x"*（翻译：存在一个 $N$，但这个 $N$ 现在允许依赖于 $x$。）正是这个"允许依赖"埋下了伏笔：下一节的 uniform convergence（一致收敛）就是把"依赖"没收之后得到的更强概念。本节的定义与 TBB §9.2 的框架一致——TBB 用 $\lim_{n} f_n(x) = f(x)$ 定义 pointwise limit（逐点极限）。

---

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1（例 1）</span>

设 $f_n(x) = x^n$，$x \in [0, 1]$，则 $f_n$ 逐点收敛到函数 $f$，其中

```math
f(x) = \begin{cases} 0 & \text{if } 0 \le x < 1 \\ 1 & \text{if } x = 1 . \end{cases}
```

我们先设 $0 \le x < 1$，则 $f_n(x) = x^n \to 0$。若 $x = 1$，则 $f_n(x) = 1$ 对一切 $n$ 成立，所以 $f_n(x) \to 1$。这就证明了上述断言。

> <span style="color:#7f8c8d;">TBB Example 9.4 (A discontinuous limit of continuous functions), §9.2, p.368–369</span>

> <span style="color:#1e8449;">**[note] Note（译者注，警钟长鸣）:**</span> 这个例子是整章的"反面教材"，请把它钉在墙上：每一个 $f_n(x) = x^n$ 都是**连续**函数（多项式），但逐点极限 $f$ 却在 $x = 1$ 处**不连续**（整列函数的极限是一个带跳变的函数）。连续性没能穿过极限——"连续函数列的逐点极限未必连续"。TBB 在 §9.3 复述这个例子时给它起了个形象的名字：这个序列在 $(0, 1)$ 上"无限缓慢地收敛"（infinitely slowly），并指出一致收敛的定义正是为了排除这种可能（TBB Definition 9.9 之前的讨论，§9.3, p.373）。请记住这里埋下的两个问题：**极限还连续吗？积分和极限能交换吗？**（TBB 在 §9.2 还给出了另一个例子——Example 9.6, §9.2, p.369–370，其中每个 $f_n$ 的积分都等于 $1$，但极限函数的积分是 $0$，即"积分的极限 ≠ 极限的积分"。）这两个问题的答案都将在 L21 用一致收敛补齐。

---

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 2（例 2）</span>

若 $E_n(x) = \sum_{k=0}^{n} \dfrac{x^k}{k!}$，则 $E_n(x)$ 逐点收敛到 $\exp x$。我们已经证明过幂级数

```math
\sum_{k=0}^{\infty} \frac{x^k}{k!}
```

的 radius of convergence（收敛半径）为无穷大。由此即得结论。

> <span style="color:#1e8449;">**[note] Note（译者注，回收旧结果）:**</span> 这里的"我们已经证明过"指的是 L08–L09 的幂级数收敛理论：用比值判别法或根值判别法可得 $\sum \frac{x^k}{k!}$ 对一切 $x \in \mathbb{R}$ 收敛（系数满足 $\frac{a_{k+1}}{a_k} = \frac{1}{k+1} \to 0$，收敛半径 $R = \infty$）。于是对每个固定的 $x$，部分和数列 $E_n(x)$ 收敛到指数函数。注意这个例子与例 1 的对照：指数函数的例子"表现良好"，而 $x^n$ 的例子"举止怪异"——但我们目前用的度量（逐点收敛）无法区分这两种行为的优劣。要看到差别，需要更强的收敛概念。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Uniform convergence（一致收敛）</span>

#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Uniform convergence（一致收敛）</span>

设 $f_n$ 是区间 $I$ 上的一列函数，则我们说 $f_n$ uniformly（一致）收敛到函数 $f$，如果对任意 $\varepsilon > 0$，存在 $N$，使得只要 $n \ge N$，就有对一切 $x$ 成立

```math
|f(x) - f_n(x)| < \varepsilon .
```

> <span style="color:#7f8c8d;">TBB Definition 9.9, §9.3 Uniform Limits, p.373</span>

> <span style="color:#1e8449;">**[note] Note（译者注，一个字的天壤之别）:**</span> 与逐点收敛定义逐词对照，唯一改动是量词顺序："存在 $N$ 使得对**一切** $x$"取代了"对每个 $x$ 存在（可能不同的）$N$"。这一个字的改动把 $N$ 从"允许依赖 $x$"变成"对所有 $x$ 通用"：🎥 *"the uniformness, it holds for all x. You can use the same capital N for all x."*（翻译：所谓"一致"，就是对一切 $x$ 成立——你可以对所有 $x$ 使用同一个 $N$。）几何图像：以 $f \pm \varepsilon$ 为上下边界画一条宽度为 $2\varepsilon$ 的"管道"，一致收敛要求当 $n$ 足够大时 $f_n$ 的**整条图像**都被压进管道里；而逐点收敛只要求在每个竖直切片上各自进入管道，时间表可以参差不齐。回看例 1 就明白差别在哪：$x^n$ 在靠近 $x = 1$ 处收敛得"无限缓慢"，没有任何一个 $N$ 能让整条曲线同时进入 $\varepsilon$-管道。另外留意与 L11 的连接：$C([a,b])$ 上的一致度量 $d(f, g) = \max |f - g|$ 度量的正是"最坏处的误差"，L21 将把两者正式画上等号。

---

#### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 1: Uniform convergence implies pointwise convergence（引理 1：一致收敛蕴含逐点收敛）</span>

设 $I$ 是一个区间，$f_n$ 是 $I$ 上的一列函数，且 $f_n$ 一致收敛到函数 $f$，则 $f_n$ 也逐点收敛到 $f$。

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 这由一致收敛的定义立即得到。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 证明虽然只写了一行，但值得在心里把逻辑链补全：一致收敛给出的 $N$ 对**所有** $x$ 通用，那么对任何一个固定的 $x$ 它当然也管用——强条件蕴含弱条件，这正是"一致"的含义。注意这个引理的方向很重要：一致收敛 ⇒ 逐点收敛，反之不然（例 1A 马上给出反例）。所以"一致"是严格更强的收敛概念，凡能证一致就不必退而求其次。

---

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1A: Pointwise but not uniform（例 1A：逐点但不一致）</span>

再看 $f_n(x) = x^n$，$x \in [0, 1]$，则 $f_n$ 逐点收敛到

```math
f(x) = \begin{cases} 0 & \text{if } 0 \le x < 1 \\ 1 & \text{if } x = 1 , \end{cases}
```

但收敛**不**是一致的。为看清这一点，注意对每个 $n$，由于 $f_n$ 连续，由 intermediate value theorem（介值定理，L11），存在 $x_n$（其中 $0 < x_n < 1$）使得 $f_n(x_n) = \frac{1}{2}$。于是

```math
\sup_{x \in [0,1]} |f(x) - f_n(x)| \;\ge\; |f(x_n) - f_n(x_n)| = \frac{1}{2} .
```

由此可见收敛不是一致的。我们在例 1 中已经看到收敛是逐点的。

> <span style="color:#7f8c8d;">TBB Example 9.8, §9.3, p.373（TBB 重新审视 $f_n(x) = x^n$ 并讨论其非一致性）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这是一个可以反复套用的反证模板——**「造最坏点」法**。要证"$\sup_{x} |f - f_n| \not\to 0$"，就主动构造一个让误差**最大化**的点 $x_n$：由介值定理，$f_n$ 在某处恰好取值 $\frac{1}{2}$（因为 $f_n(0) = 0$、$f_n(1) = 1$ 且连续），而在这一点上 $f(x_n) = 0$（因为 $x_n \ne 1$，而 $f$ 只在 $x = 1$ 处取值 $1$），误差精确等于 $\frac{1}{2}$，永远压不下去。Colding 点出了这些 $x_n$ 的去向：🎥 *"the thing is that as n gets large, this point will have to move very close to 1."*（翻译：关键在于，随着 $n$ 变大，这个点将不得不移到非常靠近 $1$ 的地方。）——"最坏点"不断向不连续点 $x = 1$ 退却，这正是"无限缓慢收敛"的几何内涵。取 $\varepsilon < \frac{1}{2}$ 即可把矛盾写干净：若一致收敛，则应有 $|f(x) - f_n(x)| < \varepsilon$ 对一切 $x$ 成立，代入 $x = x_n$ 得 $\frac{1}{2} < \varepsilon$，矛盾。把"挑最坏点 + 介值定理"这个组合记住，它是证"不一致收敛"的标准武器。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 2A: Uniform convergence of the exponential series（例 2A：指数函数级数的一致收敛）</span>

若 $E_n(x) = \sum_{k=0}^{n} \dfrac{x^k}{k!}$，则 $E_n(x)$ 在任何形如 $[-L, L]$ 的区间上一致收敛到 $\exp x$。这将是下面讨论的 Weierstrass M-test（魏尔斯特拉斯 M-判别法）的一个推论。

> <span style="color:#1e8449;">**[note] Note（译者注，前瞻）:**</span> 注意"在任何形如 $[-L, L]$ 的区间上"这个限定语：收敛半径 $R = \infty$ 的级数在**每一个有界区间**上一致收敛，但一致收敛是"逐区间"的性质，不是全 $\mathbb{R}$ 上的性质（$|x|$ 越大误差越大，无界区间上不存在统一的 $N$）。后面证明 Theorem 之后，这个例子将成为该定理在 $R = \infty$ 时的直接特例。与例 1A 对照着记：两个例子都逐点收敛，但 $x^n$ 的极限函数不连续、指数级数的极限函数连续——判别器马上揭晓：一致收敛保连续性（L21 Theorem 1）。

---

#### <span style="color:#2471a3;">**[lemma]**</span> <span style="color:#c0392b">Lemma 2 [Weierstrass M-test]（引理 2：魏尔斯特拉斯 M-判别法）</span>

设 $I$ 是一个区间，$f_n$ 是 $I$ 上的一列函数。再设 $M_n$ 是一列非负数，满足

```math
|f_n(x)| \le M_n \quad \text{for all } x \in I .
```

若级数

```math
\sum_{n=1}^{\infty} M_n
```

收敛，则函数列

```math
S_n(x) = \sum_{k=0}^{n} f_k(x)
```

一致收敛。

> <span style="color:#7f8c8d;">TBB Theorem 9.16 (M-Test), §9.3.2 Weierstrass M-Test, p.377</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 对每个固定的 $x$，数列

```math
\sum_{k=0}^{n} f_k(x)
```

收敛。此外，对一切 $x$ 与一切 $m < n$，我们有

```math
|S_n(x) - S_m(x)| \le |f_n(x)| + |f_{n-1}(x)| + \cdots + |f_{m+1}(x)| \le M_n + \cdots + M_{m+1} .
```

固定 $m$，由于 $S_n(x) \to S(x)$，可得

```math
|S(x) - S_m(x)| \le \sum_{k=m+1}^{\infty} M_k .
```

由于 $\sum_{k=0}^{\infty} M_k$ 收敛，故对任意 $\varepsilon > 0$，存在 $N$，使得当 $m \ge N$ 时 $\sum_{k=m+1}^{\infty} M_k < \varepsilon$。因此，当 $m \ge N$ 时对一切 $x$ 都有

```math
|S(x) - S_m(x)| < \varepsilon .
```

断言得证。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这个证明的骨架可以命名为**「柯西定底 + 尾巴碾平」两步法**，Colding 在课上把它讲得非常直白：🎥 *"The first step is to say that there exists some function S, and they converge to that function pointwise. In order to prove that, I proved that these sums here, for each fixed x, is a Cauchy sequence... And then the thing is that I have to upgrade this convergence, which initially is pointwise to uniform convergence."*（翻译：第一步是证明存在某个函数 $S$，使得它们逐点收敛到它——为此我对每个固定的 $x$ 证明部分和是柯西列；然后要做的是把这个起初只是逐点的收敛升级为一致收敛。）第一步动用的是 L06 的 Cauchy 收敛定理：由 $\sum M_k$ 收敛（L07 的级数理论），尾巴 $\sum_{k=m+1}^{\infty} M_k$ 可以任意小，于是固定 $x$ 时部分和是实数的柯西列，从而定义出极限函数 $S(x)$。第二步是全证明的枢纽：在不等式 $|S_n(x) - S_m(x)| \le \sum_{k=m+1}^{\infty} M_k$ 中令 $n \to \infty$（$S_n(x) \to S(x)$），右端**不含 $n$**，而右端本来就对一切 $x$ 一致地小——"一致"就这样免费升级完成。注意与 L11 度量空间版本的对应：那里"收敛 ⇒ 柯西"用 $\frac{\varepsilon}{2}$ 接力，这里反着用"柯西 ⇒ 收敛"来制造极限，两讲互相成全。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 2A (continued)（例 2A（续））</span>

在区间 $I = [-L, L]$ 上设

```math
f_n = \frac{x^n}{n!} .
```

则

```math
|f_n| \le \frac{L^n}{n!} .
```

由于

```math
\sum_{n} \frac{L^n}{n!}
```

收敛，Weierstrass M-test 给出：级数

```math
\sum_{n=0}^{\infty} f_n
```

在 $I$ 上一致收敛。

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这是 M-判别法的标准用法，注意"配对"的写法：把第 $n$ 个函数 $f_n(x) = \frac{x^n}{n!}$ 与一个**与 $x$ 无关的常数** $M_n = \frac{L^n}{n!}$ 配对。因为 $|x| \le L$，所以 $|x|^n \le L^n$，配对成立。剩下的判断"$\sum \frac{L^n}{n!}$ 是否收敛"是纯粹的**数项级数**问题，用 L08 的 ratio test（比值判别法）立得收敛（相邻项之比 $\frac{L}{n+1} \to 0 < 1$）。这正是 M-判别法好用之处：它把"函数级数是否一致收敛"这个二维问题降维成"数项级数是否收敛"这个一维问题。Colding 特别强调这一点：🎥 *"why is the Mn so much easier to determine? Because they are just numbers... And so since they're non-negative, it just means that the sum is finite. And so that's much easier to determine."*（翻译：为什么 $M_n$ 容易得多？因为它们只是数字……由于它们非负，只需判断和是否有限，这容易判断得多。）

<span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem: Uniform convergence of power series（定理：幂级数的一致收敛）</span>

若

```math
\sum_{k=0}^{\infty} a_k x^k
```

是一个 power series（幂级数），$R$ 是它的收敛半径，则它在任何（有限）形如 $[-L, L]$（其中 $L < R$）的区间上一致收敛。

> <span style="color:#7f8c8d;">TBB Theorem 10.9 (3), §10.3 Uniform Convergence, p.410–411（收敛半径公式见 TBB Definition 10.7, §10.2, p.407–408）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 回忆：若 $M = \limsup_{n} |a_n|^{1/n}$，则收敛半径为 $R = \frac{1}{M}$。由此可得：若 $|x| \le L < R$，则

```math
\limsup_{n} \left| a_n x^n \right|^{1/n} = |x| \cdot \frac{1}{R} = |x|\, M \le L M < 1 .
```

选取 $1 > \varepsilon > L M$。则对足够大的 $n$ 有 $|a_n x^n| \le M_n = \varepsilon^n$。由于几何级数 $\sum_n \varepsilon^n$ 收敛，由 Weierstrass M-test 即得结论。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，两个细节）:**</span> 其一，证明里 limsup 那一步请用 L09 的 limsup 工具核对：$\limsup_n |a_n x^n|^{1/n} = |x| \cdot \limsup_n |a_n|^{1/n} = |x| M$（正的常数 $|x|$ 可以提出 limsup）。这个量 $\le LM < 1$ 意味着：对足够大的 $n$，$|a_n x^n|^{1/n} \le \varepsilon$（任取 $\varepsilon$ 介于 $LM$ 与 $1$ 之间），即 $|a_n x^n| \le \varepsilon^n$。其二，为何要"严格"取 $L < R$？因为 $\varepsilon$ 必须严格小于 $1$ 才能让几何级数 $\sum \varepsilon^n$ 收敛；$L$ 逼近 $R$ 时 $LM \to 1$，余量耗尽。Colding 提醒边界是另一回事：🎥 *"It's convergent inside here, and it's divergent outside. But it's not completely clear what happened on the boundary. So you have to check the boundary separately."*（翻译：内部收敛，外部发散，但边界上发生什么并不清楚，必须单独检验。）本定理的用途在下一讲兑现：🎥 *"a lot of operations, like integration and differentiation, you can do that over here and then go to the limit."*（翻译：像积分、求导这样的许多运算，可以先在级数上做，然后再取极限。）——这正是 L21 三个定理的主题。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 3: The geometric power series（例 3：几何幂级数）</span>

几何幂级数

```math
\sum_{k=0}^{\infty} x^k
```

在所有形如 $[-L, L]$（其中 $L < 1$）的区间上一致收敛到 $\dfrac{1}{1 - x}$。由于该幂级数的收敛半径为 $1$，结论由上面的定理得到。

> <span style="color:#7f8c8d;">TBB §3.4 Geometric Series, p.85–86（$\sum_k r^{k-1} = \frac{1}{1-r}$，$|r| < 1$）</span>

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这是定理最朴素的实例：系数全为 $1$ 的幂级数，收敛半径 $M = \limsup_n |a_n|^{1/n} = 1$ 故 $R = 1$，于是在任何 $[-L, L]$（$L < 1$）上一致收敛到 $\frac{1}{1-x}$。注意老朋友 $1 - x$ 在分母上：$x$ 越接近 $1$，函数值爆炸得越厉害，这与"边界上必须单独检验"（在 $x = 1$ 处级数发散）完全吻合。几何级数你在 L07 就见过它的数列版本，如今套上"函数级数 + 一致收敛"的新衣——同一件工具在不同抽象层级上反复出场，是这门课的常态。
