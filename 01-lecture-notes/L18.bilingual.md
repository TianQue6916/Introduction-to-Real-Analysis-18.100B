#### <span style="color:#2471a3;">**[definition]**</span> <span style="color:#2471a3">Definition: Uniformly continuous（一致连续）</span>

设 $f : I \to \mathbb{R}$ 是一个 function（函数），其中 $I$ 是一个 interval（区间）。我们称 $f$ 是 uniformly continuous（一致连续的），如果对任意 $\varepsilon > 0$，存在一个 $\delta > 0$，使得

```math
|f(x) - f(y)| < \varepsilon \quad \text{if } |x - y| < \delta .
```

注意：一致连续比 continuous（连续）更强。它的含义是：对一个给定的 $\varepsilon > 0$，同一个 $\delta$ 可以对所有 $x$ 通用。

> <span style="color:#7f8c8d;">TBB Definition 5.46, §5.6 Uniform Continuity, p.219</span>

> <span style="color:#1e8449;">**[note] Note（译者注，一字之差的升级）:**</span> 把这个定义与你在 L11 见过的 $\varepsilon$-$\delta$ 连续定义逐词对照：唯一的改动是"先固定点 $x_0$、再找依赖它的 $\delta(x_0)$"变成了"一个 $\delta$ 打天下"。Colding 在课上反复强调这个词根：🎥 *"Uniform, again, refer to that $x$ is not fixed, or $x_0$... It's like the same delta works for all $x_0$'s."*（翻译：uniform 又是指 $x$——或者说 $x_0$——不被固定……也就是说同一个 $\delta$ 对所有 $x_0$ 都适用。）有同学在课上问这是不是就是"斜率有界"：🎥 *"is that essentially just the same thing as saying that the slope is bounded."*（翻译：这本质上是不是就等于说斜率有界？）Colding 的回答很谨慎：🎥 *"slope is something about being differentiable, and you can have a uniformly continuous function that is not differentiable. But it's definitely related."*（翻译：斜率牵涉到可微，而一致连续函数可以处处不可微——但两者确实有关联。）这句话预告了本讲的路线：要证明"连续 $\Rightarrow$ 可积"（Theorem 2），必须先把逐点的连续性"升级"为全域一致的一致连续性。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1: $f(x) = x^2$ on $\mathbb{R}$（例 1：$\mathbb{R}$ 上的 $x^2$ 不是一致连续的）</span>

设 $f(x) = x^2$ 定义在 $\mathbb{R}$ 上，则 $f$ 不是一致连续的。为了看清这一点，任给 $\varepsilon > 0$；假如 $f$ 一致连续，那么会存在一个 $\delta > 0$，使得对一切 $x$ 都有

```math
f(x + \delta) - f(x) < \varepsilon .
```

这意味着对一切 $x$ 都有

```math
2\delta x < (x + \delta)^2 - x^2 < \varepsilon ,
```

而这显然不成立（让 $x \to \infty$ 即可）。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 2: $f(x) = \frac{1}{x}$ on $(0, 1]$（例 2：$(0,1]$ 上的 $\frac{1}{x}$ 不是一致连续的）</span>

设 $f(x) = \dfrac{1}{x}$ 定义在 $(0, 1]$ 上，则 $f$ 也不是一致连续的。为了看清这一点，取 $x_n = \dfrac{1}{n}$ 与 $y_n = \dfrac{1}{2n}$，于是

```math
|f(x_n) - f(y_n)| = n ,
```

而

```math
|x_n - y_n| < \frac{1}{n} .
```

由此立刻得出 $f$ 不是一致连续的。

> <span style="color:#1e8449;">**[note] Note（译者注，两个反例的分工）:**</span> 这两个反例各堵死一条退路，与 L11 讨论 EVT 时"开区间 / 不连续"各堵一条的格局完全同构。例 1 的病灶是**区间无界**：$x^2$ 的图像越往右越陡，Colding 画图时说得很形象：🎥 *"as you're moving further and further out... the length of that interval would have to be smaller and smaller. But you can't use the same uniform size."*（翻译：当你在图像上越走越远时，所需输入区间的长度必须越来越小——你没法用同一个统一尺寸。）例 2 的病灶是**区间不闭**：$0$ 不在 $(0, 1]$ 里，函数在 $0$ 附近爆炸。注意例 2 的验证手法正是"序列法"：$x_n$ 与 $y_n$ 的输入距离趋于 $0$（$\frac{1}{2n} < \frac{1}{n}$），输出距离却趋于 $\infty$——这与你已在 L04–L07 千锤百炼的序列语言一脉相承，马上就会在 Theorem 1 的证明里正式上岗。还有一个细节：$(0,1]$ 与 L06 里"柯西列 $\frac{1}{n}$ 在 $(0,1)$ 中不收敛"用的是同一类区间——**毛病不在函数，而在端点缺失**。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 1: Uniform continuity on a compact interval（定理 1：$[a,b]$ 上的连续函数必一致连续）</span>

> <span style="color:#7f8c8d;">TBB Theorem 5.48, §5.6 Uniform Continuity, p.220</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 使用 proof by contradiction（反证法）。假设结论不成立；那么存在一个 $\varepsilon > 0$，使得对一切 $n > 0$ 都存在 $x_n$ 与 $y_n$ 满足

```math
|x_n - y_n| < \frac{1}{n}
```

并且

```math
|f(x_n) - f(y_n)| \ge \varepsilon .
```

由于区间 $[a, b]$ 是 compact（紧的），我们可以选取 $x_n$ 的一个 subsequence（子序列），记作 $x_{n_k}$，使得

```math
x_{n_k} \to x .
```

由于

```math
|x - y_{n_k}| \le |x - x_{n_k}| + |x_{n_k} - y_{n_k}| ,
```

我们得到 $y_{n_k} \to x$ 也成立。又因为 $f$ 是连续的，所以 $f(x_{n_k}) \to f(x)$ 且 $f(y_{n_k}) \to f(x)$。然而这与

```math
|f(x_{n_k}) - f(y_{n_k})| \ge \varepsilon
```

矛盾。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这个证明是本讲最值得收藏的模板——**「否命题展开 + $\delta_n = \frac{1}{n}$ 阶梯 + Bolzano-Weierstrass 提取」三步法**。第一步，把"不是一致连续"的否命题老实展开：存在 $\varepsilon_0$，对每个 $\delta$ 都失败。第二步，Colding 点明"对每个 $\delta$ 都失败"这句话该怎么用——把失败的距离排成阶梯：🎥 *"But now we choose a sequence of delta... We look at a sequence of delta. And this is where we use this for delta equal to 1 over $n$."*（翻译：现在我们取一列 $\delta$……这正是我们取 $\delta = \frac{1}{n}$ 的地方。）第三步，$[a,b]$ 紧致保证子序列 $x_{n_k}$ 收敛且极限留在区间内，再用三角不等式把 $y_{n_k}$ 也拽到同一极限，最后"两列都收敛到 $f(x)$"与"差恒 $\ge \varepsilon$"迎头相撞：🎥 *"Then these two things here must get closer and closer together. But they're saying that they are some fixed thing apart. So that's clearly a contradiction."*（翻译：这两列本该越来越接近，可它们却被要求永远隔着固定的距离——显然矛盾。）对照 L11 的 EVT 证明（无界序列 + B-W 提取子序列 + 连续性引理），你会发现骨架一模一样：**紧致性提供收敛子序列，连续性把极限传过去，反证提供矛盾**。Colding 还顺带提醒了"紧致"在这里的含义：🎥 *"for a subset of the real line, compact is the same as saying that it's bounded and closed."*（翻译：对实直线的一个子集而言，紧致就等价于既有界又闭。）这正是 L13–L14 度量空间紧致性讨论在一维情形的具体化。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">A key criterion for Riemann integrability（黎曼可积的一个关键判别定理）</span>

我们现在来到一个 key theorem（关键定理），它给出了一个函数成为 Riemann integrable（黎曼可积）的简单判别准则：

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 2: Continuous functions are Riemann integrable（定理 2：$[a,b]$ 上的连续函数都属于 $\mathcal{R}([a,b])$）</span>

> <span style="color:#7f8c8d;">TBB §8.6, p.349（"All continuous functions are Riemann integrable"）+ Theorem 8.16, §8.6, p.351（$\varepsilon$-判据）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 给定 $\varepsilon > 0$。由于 $f$ 由 Theorem 1 知是一致连续的，所以存在 $\delta > 0$，使得只要 $|x - y| < \delta$，就有

```math
|f(x) - f(y)| < \frac{\varepsilon}{b - a} .
```

设 $P$ 是一个 partition（分割），满足对一切 $i$ 都有 $\Delta x_i < \delta$。那么在形如 $[x_{i-1}, x_i]$ 的每一个分割子区间上，我们都有

```math
M_i - m_i < \frac{\varepsilon}{b - a} .
```

于是

```math
\begin{aligned}
U(f, P) - L(f, P) &= \sum_i M_i \, \Delta x_i - \sum_i m_i \, \Delta x_i \\
&= \sum_i [M_i - m_i] \, \Delta x_i < \frac{\varepsilon}{b - a} \sum_i \Delta x_i = \varepsilon .
\end{aligned}
```

由于这对一切 $\varepsilon > 0$ 都成立，所以 $f$ 是可积的。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，历史与证明策略）:**</span> 先说历史部分。Colding 在讲黎曼积分定义时给了它极高的历史地位：🎥 *"So this is Riemann's way of defining integrals. There are other ways, but this is—I think this was the first way where you have a definition that really made sense."*（翻译：这就是黎曼定义积分的方式。还有别的方式，但我认为这是历史上第一个真正讲得通的定义。）他还讲了段掌故：黎曼是 Gauss（高斯）的学生，博士论文选题按惯例导师勾第一项，Gauss 偏偏勾了黎曼自己都不懂的第三项"高维曲率"，六个月后黎曼拿出了 curvature tensor（曲率张量）：🎥 *"and this lay the foundation for general relativity that came many years later, 70 years or so later."*（翻译：这为大约七十年之后问世的广义相对论奠定了基础。）再说证明策略。本证明的全部前置工作在 L17 已备好：upper sum（上和）$U(f,P)$ 与 lower sum（下和）$L(f,P)$ 满足"$f$ 可积当且仅当 $\forall \varepsilon > 0$ 能找到分割使 $U - L < \varepsilon$"这一判据，Colding 是这样定位它的：🎥 *"if we want to check that a function is Riemann integrable, then we just need to check that for all epsilon, we can find a partition with this property."*（翻译：要检验一个函数黎曼可积，我们只需检验：对每个 $\varepsilon$，都能找到一个具有该性质的分割。）而本证明的独门一招是**「误差摊派」**：把总预算 $\varepsilon$ 除以区间长度 $b - a$，摊派成每个子区间上的局部容许量 $\frac{\varepsilon}{b-a}$，再由一致连续性兑换成网格宽度 $\delta$。注意摊派之所以可行，是因为求和恰好封顶：$\sum_i \Delta x_i = b - a$。这里还悄悄用了一次 L11 的 EVT——每个子区间上 $M_i$、$m_i$ 作为连续函数的上确界、下确界必须真的被取到，Colding 在课上说：🎥 *"the sup here... it's actually achieved by the extreme value theorem."*（翻译：这里的上确界……实际上是由极值定理取到的。）

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Basic properties of integrals（积分的基本性质）</span>

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 3: Basic formulas for integrals（积分的基本公式）</span>

我们有以下几条积分的基本公式：

**(1)** 若 $f \in \mathcal{R}([a, b])$ 且 $c \in \mathbb{R}$，则 $cf \in \mathcal{R}([a, b])$，且

```math
\int_a^b (c f) \, dx = c \int_a^b f \, dx .
```

**(2)** 若 $f, g \in \mathcal{R}([a, b])$，则 $f + g \in \mathcal{R}([a, b])$，且

```math
\int_a^b (f + g) \, dx = \int_a^b f \, dx + \int_a^b g \, dx .
```

**(3)** 若 $f, g \in \mathcal{R}([a, b])$ 且 $f \le g$，则

```math
\int_a^b f \, dx \le \int_a^b g \, dx .
```

**(4)** 若 $f \in \mathcal{R}([a, b])$ 且 $c \in (a, b)$，则 $f \in \mathcal{R}([a, c])$ 且 $f \in \mathcal{R}([c, b])$，并且

```math
\int_a^c f \, dx + \int_c^b f \, dx = \int_a^b f \, dx .
```

> <span style="color:#7f8c8d;">TBB Theorem 8.22 (Additive), §8.7, p.356；Theorem 8.23 (Linear)、8.24 (Monotone), §8.7, p.357（Riemann 版本；连续函数版本见 Theorem 8.4, 8.5, §8.3, p.339 与 Theorem 8.6, §8.3, p.340）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 第一条来自：若 $P$ 是一个分割，则

```math
L(cf, P) = c L(f, P)
```

且

```math
U(cf, P) = c U(f, P) .
```

为证第二条，给定 $\varepsilon > 0$，设 $P_1$ 与 $P_2$ 是满足下列条件的分割：

```math
U(f, P_1) - L(f, P_1) < \frac{\varepsilon}{2}
```

以及

```math
U(g, P_2) - L(g, P_2) < \frac{\varepsilon}{2} .
```

设 $P$ 是同时拥有 $P_1$ 与 $P_2$ 的全部分割点的分割。于是（因为 $P$ 是二者的加细，加细只会让上和下降、下和上升）

```math
U(f, P) - L(f, P) < \frac{\varepsilon}{2}
```

以及

```math
U(g, P) - L(g, P) < \frac{\varepsilon}{2} .
```

因此

```math
U(f + g, P) - L(f + g, P) < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon .
```

第二条得证。

为看第三条，设 $P$ 是 $[a, b]$ 的任意一个分割。由 $f \le g$ 立得

```math
U(g, P) \ge U(f, P) .
```

由于

```math
\int_a^b g \, dx = \inf_P U(g, P)
```

且对 $f$ 同理，第三条得证。

最后，为看第四条。设 $P$ 是 $[a, b]$ 的任意分割，并设 $P'$ 是在 $P$ 的分割点之外还把 $c$ 也作为分割点的 refinement（加细分割）。于是

```math
U(f, P' \cap [a, c]) + U(f, P' \cap [c, b]) = U(f, P') .
```

同理，

```math
L(f, P' \cap [a, c]) + L(f, P' \cap [c, b]) = L(f, P') .
```

因此

```math
\begin{aligned}
&U(f, P' \cap [a, c]) - L(f, P' \cap [a, c]) + U(f, P' \cap [c, b]) - L(f, P' \cap [c, b]) \\
&\qquad = U(f, P') - L(f, P') .
\end{aligned}
```

由此第四条轻松得证。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 讲义只列了四条公式，但视频里 Colding 透露了教学的分工：🎥 *"And so maybe we might prove some of these next time."*（翻译：也许我们下次会证明其中几条。）也就是说：视频把详证留到 V19 与讲义，讲义上四条的证明俱全。读证明时要抓两个隐藏机关。**机关一**：第二条里"$U(f+g,P)-L(f+g,P) < \frac{\varepsilon}{2}+\frac{\varepsilon}{2}$"这步并不平凡——$\sup(f+g) \le \sup f + \sup g$ 与 $\inf(f+g) \ge \inf f + \inf g$ 只是单向不等式，Colding 在 V19 里专门警告了等号会失灵：取 $g = -f$ 时和恒为零，但 $\sup f + \sup g$ 可以是正的（详见 L19 译文对应注）。**机关二**：第四条先给分割 $P$ 补上分点 $c$ 得到 $P'$，再利用"$U - L$ 在加细下不增"（L17 的关键事实），把 $[a,b]$ 上的误差拆成 $[a,c]$ 与 $[c,b]$ 两段之和，然后由"两段各自非负、总和不超过 $\varepsilon$"逼出每段都不超过 $\varepsilon$。这两处正是"$\varepsilon$ 预算"思想的两笔支出，与 L06 的 $\frac{\varepsilon}{2}$ 劈分同宗同源。

### <span style="color:#2471a3;">**[corollary]**</span> <span style="color:#c0392b">Corollary: $|\int_a^b f \, dx| \le \int_a^b |f| \, dx$（绝对值不等式）</span>

设 $f, |f| \in \mathcal{R}([a, b])$，则

```math
\left| \int_a^b f \, dx \right| \le \int_a^b |f| \, dx .
```

> <span style="color:#7f8c8d;">TBB Theorem 8.25 (Absolute Property), §8.7, p.357（另见 Corollary 8.21, §8.6, p.355：$f$ 可积 $\Rightarrow |f|$ 可积）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 这由上面的性质 (3)（原文称"引理"）得出，因为 $f \le |f|$ 且 $-f \le |f|$。具体地，由第一个不等式连同性质 (3) 我们得到

```math
\int_a^b f \, dx \le \int_a^b |f| \, dx ,
```

而由第二个不等式我们得到

```math
-\int_a^b f \, dx = \int_a^b (-f) \, dx \le \int_a^b |f| \, dx .
```

两者合在一起即给出结论。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注）:**</span> 这是"积分版的三角不等式"。Colding 在视频里对它的定位一句话：🎥 *"This is a very—this is very simple inequality, but extremely useful."*（翻译：这是个非常——非常简单的不等式，但极其有用。）证明思路是"双侧夹击"：$f \le |f|$ 与 $-f \le |f|$ 分别控制 $\int f$ 的上界与下界，合起来就是绝对值不等式——这与你在 L06 证明柯西收敛时"$\le$ 与 $\ge$ 各打一半"的套路同构。注意讲义把 $|f|$ 的可积性当作假设写进了陈述（"$f, |f| \in \mathcal{R}([a,b])$"），而 TBB 的 Theorem 8.25 更进一步证明了 $f$ 可积自动推出 $|f|$ 可积（Corollary 8.21, p.355）——讲义的表述更保守，但避免了对可积性的循环论证。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Fundamental theorem of calculus, version 1（微积分基本定理，第一版）</span>

设 $f$ 是 $[a, b]$ 上的 continuous function（连续函数），并用

```math
F(x) = \int_a^x f(s) \, ds
```

在 $[a, b]$ 上定义 $F$。则函数 $F$ 是 differentiable（可微的），且其导数为 $f$。

> <span style="color:#7f8c8d;">TBB Theorem 8.8 (Differentiation of the Indefinite Integral), §8.3, p.340（连续版本）；Riemann 版本见 Theorem 8.26, §8.7, p.358</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 固定 $x_0 \in [a, b]$，先设 $x > x_0$。由性质 (4) 的可加性，我们有

```math
F(x) = \int_a^x f(s) \, ds = \int_a^{x_0} f(s) \, ds + \int_{x_0}^{x} f(s) \, ds = F(x_0) + \int_{x_0}^{x} f(s) \, ds .
```

于是

```math
F(x) - F(x_0) = \int_{x_0}^{x} f(s) \, ds .
```

因此（由 $f$ 在 $[x_0, x]$ 上的最大值与最小值夹住积分）

```math
(x - x_0) \min_{[x_0, x]} f \le F(x) - F(x_0) \le (x - x_0) \max_{[x_0, x]} f ,
```

从而

```math
\min_{[x_0, x]} f \le \frac{F(x) - F(x_0)}{x - x_0} \le \max_{[x_0, x]} f .
```

由于 $f$ 在 $x_0$ 处连续，当 $x \to x_0$ 时这串不等式的左端与右端都收敛到 $f(x_0)$。这就证明了 $x > x_0$ 情形的结论。当 $x < x_0$ 时，我们可以把 $F(x)$ 写成

```math
F(x) + \int_{x}^{x_0} f(s) \, ds = F(x_0) ,
```

因此

```math
F(x) - F(x_0) = -\int_{x}^{x_0} f(s) \, ds .
```

与上面完全相同的论证给出此情形的结论。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，夹逼战术）:**</span> 这个证明的发动机是**「max/min 夹逼」**：把 $F(x)-F(x_0)$ 这块"曲边面积"夹在"最低矩形"与"最高矩形"之间，除以 $x - x_0$ 后得到差商被 $\min f$ 与 $\max f$ 三明治夹住，而连续性保证两端同时塌缩到 $f(x_0)$——这正是 L05 夹逼定理（squeeze theorem）的胜利。Colding 在 V19（讲义与视频的分工是：这几条在视频里于下一讲才完整展开，他原话是🎥 *"this here was stuff I actually had from the previous lecture"*，翻译：这些内容其实是我上一讲就有的讲义里的东西）现场演示了同一证明，落点是：🎥 *"this difference quotient here goes to $f(x_0)$, because it's squeezed between those two numbers that converge to the same number—namely, to little $f(x_0)$."*（翻译：这个差商趋于 $f(x_0)$，因为它被那两个收敛到同一个数——即小 $f(x_0)$——的量夹在中间。）这里还有个细节：讲义敢把两端的界直接写成 $\min$ 与 $\max$ 而不是 $\inf$ 与 $\sup$，靠的又是 L11 的 EVT——连续函数在闭区间上确实取到最值。另外"$x < x_0$ 情形"不是简单照抄：积分上限变成了下限，多出一个负号，所以讲义改用 $F(x) + \int_x^{x_0} f = F(x_0)$ 重排后再论证——做题时这个负号最容易漏。

### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Fundamental theorem of calculus, version 2（微积分基本定理，第二版）</span>

设 $F : [a, b] \to \mathbb{R}$ 是可微的，且 $F' = f \in \mathcal{R}([a, b])$，则

```math
F(b) - F(a) = \int_a^b f(s) \, ds .
```

> <span style="color:#7f8c8d;">TBB Theorem 8.9 (Integral of a Derivative), §8.3, p.341（$F'$ 连续版本）；Riemann 版本见 Theorem 8.27, §8.7, p.358</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 由于 $f$ 是可积的，对一切 $\varepsilon > 0$，存在 $[a, b]$ 的一个分割 $P$ 使得

```math
U(f, P) - L(f, P) < \varepsilon .
```

对一个给定分割 $P$ 及其分割点 $x_i$，我们有

```math
L(f, P) = \sum_i m_i (x_i - x_{i-1}) ,
```

以及

```math
U(f, P) = \sum_i M_i (x_i - x_{i-1}) .
```

此外，由 mean value inequality（中值不等式，即 L16 的中值定理的不等式形式），

```math
F(x_i) - F(x_{i-1}) = f(y_i) (x_i - x_{i-1}) ,
```

其中 $y_i$ 是 $[x_{i-1}, x_i]$ 中的某个点。于是我们有

```math
m_i (x_i - x_{i-1}) \le F(x_i) - F(x_{i-1}) \le M_i (x_i - x_{i-1}) .
```

由此得

```math
L(f, P) \le \sum_{i=1}^{n} \left[ F(x_i) - F(x_{i-1}) \right] \le U(f, P) .
```

最后，观察到 telescope sum（相消求和/望远镜求和）

```math
F(b) - F(a) = \sum_{i=1}^{n} \left[ F(x_i) - F(x_{i-1}) \right] ,
```

再结合 $P$ 可以选得使 $U(f,P) - L(f,P) < \varepsilon$ 对任意 $\varepsilon$ 成立，即从上述不等式得到结论。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 这个证明漂亮在"双向夹逼 + 相消求和"的组合拳：中值不等式把 $F$ 在每个子区间上的增量写成 $f(y_i)\Delta x_i$，自动落进下和与上和的包围圈；而左边那列增量首尾相消，恰好还原出 $F(b) - F(a)$。这种 telescoping（望远镜求和/相消求和）手法你在 L07 处理级数部分和时已经用过——同一个"错位相消"在这里把微分与积分焊在一起。有一个逻辑细节值得警惕（TBB 在 Theorem 8.27, p.358 处特别强调）：第二版**必须假设 $F' = f$ 可积**才能陈述——存在有界的导数不黎曼可积，TBB 指出"正是黎曼积分无法积掉所有导数这一失败，据 Lebesgue 自述，促使他寻找更一般的积分理论"。Colding 在 V19 里干脆把第二版的证明留给了讲义：🎥 *"I did the proof for this out in the notes also. So maybe I'll just skip that."*（翻译：这个证明我也写在讲义里了，所以也许我就跳过它。）两个版本合起来才是完整的微积分基本定理：第一版说"积分出来再求导还原"，第二版说"求导出来再积分还原到端点差"——微分与积分互为逆运算。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 3: Computing $\int_0^1 x^2 \, dx$（计算 $\int_0^1 x^2 \, dx$）</span>

为了计算

```math
\int_0^1 x^2 \, dx ,
```

我们使用微积分基本定理的第二版。具体地，注意到函数

```math
F(x) = \frac{x^3}{3}
```

的导数是 $x^2$，因此由微积分基本定理的第二版得到

```math
\int_0^1 x^2 \, dx = F(1) - F(0) = \frac{1}{3} - 0 = \frac{1}{3} .
```

> <span style="color:#1e8449;">**[note] Note（译者注，第一份"真计算"）:**</span> 这是本课程第一次算出一个具体的积分值——注意我们没有做任何"取分割、算黎曼和、求极限"的苦工，而是找到了一个导数恰好等于被积函数的 antiderivative（原函数）$F$ 就走人了。这正是第二版基本定理的威力：它把"求积分"这个分析学问题降格为"找原函数"这个代数式的问题。对比一下：若用 L17 的定义硬算 $\int_0^1 x^2\,dx$，就得对上和 $\sum \sup \cdot \Delta x_i$ 做求和取极限（TBB §8.2 的 Cauchy 第一方法正是为此引入的）。视频里 Colding 还顺带解释了记号 $\int$ 的来历——它像一个拉长的 $S$，代表 summation（求和），而 $dx$ 承接自 $\Delta x_i$：这个注记出自 V19 课堂提问，详见 L19 译文。
