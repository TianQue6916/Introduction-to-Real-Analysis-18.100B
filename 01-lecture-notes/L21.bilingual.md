### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 1: Uniform limits of continuous functions（定理 1：连续函数的一致极限）</span>

设 $I$ 是一个区间，$f_n$ 是 $I$ 上的一列 continuous functions（连续函数）。若 $f_n$ 一致收敛到 $f$，则 $f$ 也是连续的。

> <span style="color:#7f8c8d;">TBB Theorem 9.22, §9.4 Uniform Convergence and Continuity, p.383–384（级数版本为 TBB Corollary 9.23, §9.4, p.385）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 任取 $x_0 \in I$ 并固定，我们要证明 $f$ 在 $x_0$ 处连续。给定 $\varepsilon > 0$，由于 $f_n \to f$ 一致收敛，存在 $N$，使得当 $n \ge N$ 时对一切 $x \in I$ 有

```math
|f(x) - f_n(x)| < \frac{\varepsilon}{3} .
```

由于 $f_N$ 在 $x_0$ 处连续，存在 $\delta > 0$，使得当 $|x - x_0| < \delta$ 时

```math
|f_N(x) - f_N(x_0)| < \frac{\varepsilon}{3} .
```

把两者结合起来，当 $|x - x_0| < \delta$ 时就有

```math
|f(x) - f(x_0)| \le |f(x) - f_N(x)| + |f_N(x) - f_N(x_0)| + |f_N(x_0) - f(x_0)| < \frac{\varepsilon}{3} + \frac{\varepsilon}{3} + \frac{\varepsilon}{3} = \varepsilon .
```

结论得证。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，为什么需要这个定理）:**</span> 开场先回收 L20 的反面教材：$f_n(x) = x^n$ 在 $[0,1]$ 上每一项都连续，但逐点极限在 $x = 1$ 处有跳变。Colding 把教训总结成一句话：🎥 *"note that pointwise convergence is not enough to guarantee that... the limit of continuous function is continuous."*（翻译：注意，逐点收敛不足以保证连续函数的极限仍然连续。）本定理则说明：换成一致收敛，问题立刻消失——**连续性可以穿过一致极限**。证明策略可以命名为**「 stepping stone（踏脚石）」三段估计**（TBB 在 Theorem 9.22 后的 Note 里正用了 stepping stone 这个词）：在 $f$ 与 $f_N$ 之间硬插一个固定的桥梁函数 $f_N$，把误差拆成三段——首尾两段由一致收敛负责（同一个 $N$，对一切 $x$ 通用），中间一段由 $f_N$ 自身的连续性负责（给出 $\delta$）。这是 L11「$\varepsilon/\delta$ 接力法」的升级版：当年的依赖链是 $\varepsilon \to \delta \to N$，今天是 $\varepsilon \to N \to \delta$——先花掉 $\frac{2\varepsilon}{3}$ 选定 $N$，再请 $f_N$ 的连续性给出配得上剩余 $\frac{\varepsilon}{3}$ 的 $\delta$。"取 $\varepsilon$ 的三分之一"是分析里最常用的分账手法，后续两个定理还会再用。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1: The exponential function is continuous（例 1：指数函数是连续的）</span>

设

```math
E_n(x) = \sum_{k=0}^{n} \frac{x^k}{k!} , \qquad E(x) = \sum_{k=0}^{\infty} \frac{x^k}{k!} .
```

在上一讲中我们证明了 Weierstrass M-test（魏尔斯特拉斯 M-判别法）蕴含 $E_n \to E$ 在 $[-L, L]$ 上一致收敛。由于每个 $E_n$ 都是连续的，由 Theorem 1 可得 $E$ 是连续的。

> <span style="color:#7f8c8d;">TBB Theorem 10.11, §10.4.1 Continuity of Power Series, p.413（幂级数在收敛区间上连续）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，回报时刻）:**</span> 这是 L20 埋下的伏笔第一次兑现：指数函数 $E(x) = \sum_{k=0}^{\infty} \frac{x^k}{k!}$ 不再是"每个部分和都连续、但极限函数的性质未知"的悬案，而是被定理 1 盖章认证的连续函数。逻辑链是一条流水线：L08–L09 证收敛半径 $R = \infty$ → L20 的 M-判别法证 $[-L,L]$ 上一致收敛 → 本定理证极限函数连续。注意每一步只在前一步之上加盖一层新结论——这正是分析学"逐级升级"的典型节奏。对照 L20 例 1A 的 $x^n$：同样都是"多项式的极限"，一致收敛版本给出连续的极限，逐点版本给出不连续的极限——差距完全来自收敛的"均匀程度"。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Uniform convergence as convergence in a metric space（作为度量空间收敛的一致收敛）</span>

这里给出思考一致收敛的另一种有用视角。回忆在区间 $I = [a, b]$ 上的连续函数空间 $C(I)$ 上有一个 natural metric（自然度量）：

```math
d(f, g) = \max_{x \in I} |f(x) - g(x)| .
```

我们有以下命题。

> <span style="color:#7f8c8d;">TBB Example 13.17, §13.4 Convergence, p.548–549（在 M[a,b] 中收敛 ⟺ 一致收敛；参考 Exercise 9.3.12）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，跨讲连接）:**</span> 这个度量就是 L11 已经介绍过的 sup metric（上确界度量）/ uniform metric（一致度量）——当时还用 EVT（极值定理）证明了 $\max$ 确实存在（$f - g$ 连续且定义在闭区间上）。今天的命题把这个度量从"一个例子"升格为"一把标尺"：一致收敛不再是"一句话定义"，而是"函数空间中的距离趋于零"。Colding 对这个视角评价很高：🎥 *"There's another way of thinking about uniform convergence that, in a way, makes it more natural."* 与 *"So it makes uniform convergence much more natural."*（翻译：还有另一种看待一致收敛的方式，它让一致收敛显得自然得多。）这就是 L11 那句"度量空间扮演广义实数角色"的宣言第一次大规模兑现：把函数当成点，把一致收敛当成收敛，度量空间的一般理论（柯西列、完备性）原封不动地搬进来用。

---

<span style="color:#2471a3;">**[proposition]**</span> <span style="color:#c0392b">Proposition: Uniform convergence equals metric convergence（命题：一致收敛等价于度量收敛）</span>

设 $I = [a, b]$ 是一个区间，且 $f_n, f \in C(I)$，则 $f_n$ 在该 metric space（度量空间）中收敛到 $f$ 当且仅当 $f_n$ 一致收敛到 $f$。

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 注意到

```math
|f(x) - f_n(x)| \le \varepsilon \quad \text{for all } x \in I
```

当且仅当

```math
d(f, f_n) \le \varepsilon .
```

因此"$f_n \to f$ 一致收敛"等价于"$d(f, f_n) \to 0$"，命题得证。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，卡点诊断）:**</span> 证明是一行的不等式互推，但两个方向各有含义，值得拆开：若对一切 $x$ 都有 $|f(x) - f_n(x)| \le \varepsilon$，则最大值（度量）也 $\le \varepsilon$；反之若最大值 $\le \varepsilon$，则每个 $x$ 处的偏差更不在话下——这正是"上确界 = 最坏点的偏差"的两个方向。Colding 坦言这近乎同义反复：🎥 *"So this is sort of a tautology."*（翻译：这多少算是个同义反复。）但它的价值在于**换语言**：把逐点量化（对一切 $x$）翻译成单个数字 $d(f, f_n)$，于是"$\forall x$"这个量词消失，度量空间里关于收敛的一切定理都自动适用。注意命题要求 $f_n, f \in C(I)$——把 $\max$ 写进定义需要连续性保证最大值取到；若极限函数的连续性尚未建立，就要改用 $\sup$（见下面推论证明的译者注）。

---

<span style="color:#2471a3;">**[corollary]**</span> <span style="color:#c0392b">Corollary: C([a, b]) is Cauchy complete（推论：C([a, b]) 是柯西完备的）</span>

$C([a, b])$（赋予上述度量）是 Cauchy complete（柯西完备）的。

> <span style="color:#7f8c8d;">TBB Definition 13.60, §13.8 Complete Spaces, p.576（完备度量空间：每个柯西列都收敛）；对照 TBB Example 13.59, §13.8, p.575–576 与 Theorem 13.64, §13.8, p.578（完备空间的闭子空间完备）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 设 $f_n$ 是 $C([a, b])$ 中的 Cauchy sequence（柯西序列），我们需要找到 $f \in C([a, b])$ 使得 $f_n$ 一致收敛到 $f$。对每个固定的 $x$，数列 $f_n(x)$ 是 $\mathbb{R}$ 中的柯西序列。理由是

```math
|f_n(x) - f_m(x)| \le d(f_n, f_m) .
```

因此，由于 $\mathbb{R}$ 是柯西完备的（L06 的 Cauchy 收敛定理），对每个 $x$ 存在 $f(x)$ 使得 $f_n(x) \to f(x)$。这就定义了函数 $f$，并说明 $f_n$ 逐点收敛到 $f$。我们还需要证明收敛是一致的。为此注意：给定 $\varepsilon > 0$，由于 $f_n$ 是柯西序列，存在 $N$，使得当 $n, m \ge N$ 时

```math
|f_n(x) - f_m(x)| < \frac{\varepsilon}{2} \quad \text{for all } x \in I .
```

于是，对 $f(x) = \lim_{m} f_m(x)$ 我们有

```math
|f_n(x) - f(x)| \le \frac{\varepsilon}{2} < \varepsilon \quad \text{for all } x \in I .
```

这说明收敛是一致的。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，三处细节）:**</span> 其一，这是 L11 埋下的"完备性是存在性论证地基"的第一次实战：套路完全照搬 TBB §13.8.1 的完备性证明三步曲（p.577）——**①造 candidate（候选极限）：**固定 $x$，用 $|f_n(x) - f_m(x)| \le d(f_n, f_m)$ 把"度量空间中的柯西列"压成"实数的柯西列"，请 L06 出场得到极限函数 $f$；**②升级：**在柯西不等式 $|f_n(x) - f_m(x)| < \frac{\varepsilon}{2}$ 中**固定 $n$、令 $m \to \infty$**，用极限的保号性把 $f_m(x)$ 换成 $f(x)$——这是全证明的枢纽，Colding 强调这一步的合法性：🎥 *"It's still true. I can still let m vary."*（翻译：不等式仍然成立，我仍然可以让 $m$ 变动。）**③验明正身：**一致收敛 + 各 $f_n$ 连续 + Theorem 1 ⇒ $f$ 连续，于是极限确实落在空间 $C([a,b])$ 里面。其二，课堂上 Colding 现场修正了一个记号疏忽：在此阶段 $f$ 的连续性还没证明，所以不能用 $\max$，必须用 $\sup$——🎥 *"Sorry, here, I should have taken the sup. The reason why I should take the sup here is that f is just a function. It's not necessarily continuous at this stage."*（翻译：抱歉，这里我应该取上确界。原因是 $f$ 目前只是个函数，在这个阶段未必连续。）其三，TBB 给了一条更省力的路线：先证 $M[a,b]$ 完备（Example 13.59），再用 Theorem 13.64"完备空间的闭子空间完备"推出 $C[a,b]$ 完备；讲义的直接证明与这条路线殊途同归。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Uniform convergence and the integral（一致收敛与积分）</span>

> <span style="color:#1e8449;">**[note] Note（译者注，全节的问题意识）:**</span> 本节回答一个悬了很久的问题：幂级数是**无限和**，若想对它积分或求导，能不能把无限和与积分/求导**交换次序**？Colding 开门见山：🎥 *"if you want to take the derivative, can you interchange this infinite sum with taking derivative? And likewise, if you want to integrate this infinite sum, is it OK to interchange the infinite sum taking the integral? And the answer is, it's OK."*（翻译：如果想求导，能把无限和与求导交换吗？想积分，能把无限和与积分交换吗？答案是：可以。）有限和时这些都是平凡的（和的积分 = 积分的和），无限和却需要理由——一致收敛正是那个理由。反例警示：对逐点收敛，交换可以失败——TBB Example 9.6（§9.2, p.369–370）构造了一列每个积分都等于 $1$ 的连续函数，而其逐点极限的积分却是 $0$，即"极限的积分 ≠ 积分的极限"。

#### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 2: Integrals under uniform convergence（定理 2：一致收敛下的积分）</span>

若 $f_n \in \mathcal{R}([a, b])$（即 $f_n$ 在 $[a, b]$ 上 Riemann integrable（黎曼可积））且 $f_n$ 一致收敛到 $f$，则 $f \in \mathcal{R}([a, b])$，且

```math
\int_a^b f_n \,dx \;\longrightarrow\; \int_a^b f \,dx .
```

> <span style="color:#7f8c8d;">TBB Theorem 9.29, §9.5.2 Sequences of Riemann Integrable Functions, p.389–390（连续函数版本为 TBB Theorem 9.26, §9.5.1, p.388）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 我们首先要证 $f \in \mathcal{R}([a, b])$，即要证：给定 $\varepsilon > 0$，存在 $[a, b]$ 的一个 partition（分割）$P$，使得

```math
U(f, P) - L(f, P) < \varepsilon .
```

由于 $f_n \to f$ 一致收敛，存在 $N$，使得当 $n \ge N$ 时

```math
|f(x) - f_n(x)| < \frac{\varepsilon}{3(b - a)} .
```

于是对任何分割 $P$ 都有

```math
\left| m_i^{f_n} - m_i^{f} \right| \le \frac{\varepsilon}{3(b - a)} , \qquad \left| M_i^{f_n} - M_i^{f} \right| \le \frac{\varepsilon}{3(b - a)} ,
```

其中 $m_i$ 与 $M_i$ 分别是函数在第 $i$ 个小区间上的 infimum（下确界）与 supremum（上确界）。由此可得，当 $n \ge N$ 时对任何分割都有

```math
|U(f, P) - U(f_n, P)| \le \frac{\varepsilon}{3} , \qquad |L(f, P) - L(f_n, P)| \le \frac{\varepsilon}{3} .
```

现在用 $f_N \in \mathcal{R}([a, b])$ 这一事实：存在分割 $P$ 使得

```math
U(f_N, P) - L(f_N, P) < \frac{\varepsilon}{3} .
```

把全部估计串起来就得到

```math
U(f, P) - L(f, P) \le \left| U(f, P) - U(f_N, P) \right| + \left( U(f_N, P) - L(f_N, P) \right) + \left| L(f_N, P) - L(f, P) \right| < \frac{\varepsilon}{3} + \frac{\varepsilon}{3} + \frac{\varepsilon}{3} = \varepsilon .
```

这说明 $f \in \mathcal{R}([a, b])$。我们还需要证明

```math
\int_a^b f \,dx = \lim_{n} \int_a^b f_n \,dx .
```

而这由以下事实得到：

```math
L(f, P) \le \int_a^b f \,dx \le U(f, P) , \qquad L(f_n, P) \le \int_a^b f_n \,dx \le U(f_n, P) ,
```

以及当 $n \ge N$ 时

```math
|U(f, P) - U(f_n, P)| \le \frac{\varepsilon}{3} , \qquad |L(f, P) - L(f_n, P)| \le \frac{\varepsilon}{3} .
```

也就是说，我们还有

```math
L(f, P) - \frac{\varepsilon}{3} \;\le\; \int_a^b f_n \,dx \;\le\; U(f, P) + \frac{\varepsilon}{3} ,
```

因此

```math
\left| \int_a^b f \,dx - \int_a^b f_n \,dx \right| < \varepsilon .
```

$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，证明策略模板）:**</span> 这个证明是旧工具的"三重奏"，每一件你都见过：**①黎曼判别法**（L18）：可积 ⟺ 存在分割使 $U(f,P) - L(f,P) < \varepsilon$，这是整个证明的靶子；**②上下确界的扰动估计**（L17–L18 的 $m_i, M_i$ 记号）：一致收敛把 $f_n$ 与 $f$ 在每个小区间上的上下确界之差都压进 $\frac{\varepsilon}{3(b-a)}$，乘上小区间长度 $\Delta x_i$ 再求和时，$\sum_i \frac{\varepsilon}{3(b-a)} \Delta x_i = \frac{\varepsilon}{3(b-a)}(b-a) = \frac{\varepsilon}{3}$——分母里的 $(b-a)$ 就是为了让这一步恰好凑出 $\frac{\varepsilon}{3}$，这是"预先归一化"的小技巧；**③三段分账**：$U(f,P)$ 与 $L(f,P)$ 被夹在 $U(f_N,P)$、$L(f_N,P)$ 各自的 $\frac{\varepsilon}{3}$ 邻域里，与 Theorem 1 的踏脚石结构一模一样。最后一段的收尾用"夹逼"：两个积分 $\int f$ 与 $\int f_n$ 都落在同一个长度为 $\varepsilon$ 的区间 $[L(f,P) - \frac{\varepsilon}{3},\, U(f,P) + \frac{\varepsilon}{3}]$ 里，故彼此相差不足 $\varepsilon$。注意结论是两件事的合取：极限函数**可积** + 积分值**收敛到正确极限**——缺一不可，前者是后者的前提。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1A: Term-by-term integration of the exponential series（例 1A：指数函数级数的逐项积分）</span>

设

```math
E_n(x) = \sum_{k=0}^{n} \frac{x^k}{k!} , \qquad E(x) = \sum_{k=0}^{\infty} \frac{x^k}{k!} .
```

由例 1 我们有 $E_n \to E$ 在 $[-L, L]$ 上一致收敛。于是由 Theorem 2 得到

```math
\sum_{k=0}^{n} \int_0^1 \frac{x^k}{k!}\,dx \;\longrightarrow\; \int_0^1 E(x)\,dx .
```

> <span style="color:#1e8449;">**[note] Note（译者注，具体怎么算）:**</span> 定理 2 在这里的用法：每个 $E_n$ 是多项式，当然可积，且有限和可以自由穿过积分号：

```math
\int_0^1 E_n(x)\,dx = \sum_{k=0}^{n} \int_0^1 \frac{x^k}{k!}\,dx = \sum_{k=0}^{n} \frac{1}{(k+1)\,k!} = \sum_{k=0}^{n} \frac{1}{(k+1)!} .
```

Colding 课上把这一步的原理讲得很细：积分多项式就是在找 antiderivative（原函数/反导数）——🎥 *"Such a function is often called the antiderivative."*（翻译：这样的函数通常被称为原函数。）对 $\frac{x^k}{k!}$ 而言，原函数是 $\frac{x^{k+1}}{(k+1)\,k!} = \frac{x^{k+1}}{(k+1)!}$：指数加一、分母多乘一个 $k+1$，恰好凑成 $(k+1)!$；再由 L19 的微积分基本定理代入上下限即得。于是定理 2 断言：$\int_0^1 E(x)\,dx = \sum_{k=0}^{\infty} \frac{1}{(k+1)!} = e - 1$。这就是"先逐项积分、再取极限"的完整兑现。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b">Uniform convergence and derivatives（一致收敛与导数）</span>

#### <span style="color:#2471a3;">**[theorem]**</span> <span style="color:#c0392b">Theorem 3: Derivatives under uniform convergence（定理 3：一致收敛下的导数）</span>

设 $f_n$ 是 $[a, b]$ 上的 differentiable functions（可微函数），且 $x_0 \in [a, b]$。若

- $f_n(x_0) \to c$，
- $f_n' \to g$ 一致收敛，
- $f_n'$ 在 $[a, b]$ 上连续，

则存在可微函数 $f$ 使得

- $f_n \to f$ 一致收敛，
- $f_n' \to f'$ 一致收敛（从而 $f' = g$）。

> <span style="color:#7f8c8d;">TBB Theorem 9.34, §9.6 Uniform Convergence and Derivatives, p.393（TBB 的版本假设 $f_n$ 逐点收敛到 $f$ 且 $f_n'$ 一致收敛到 $g$，结论相同）</span>

<span style="color:#2471a3;">**[proof]**</span> *Proof（证明）.* 在 $[a, b]$ 上定义函数 $F$ 为

```math
f(x) = c + \int_{x_0}^{x} g \,dt ,
```

注意到由于各 $f_n'$ 连续且 $f_n' \to g$ 一致收敛，由 Theorem 1 可得 $g$ 也是连续的。因此，由 fundamental theorem of calculus（微积分基本定理，L19），$f$ 可微且 $f' = g$。此外，由微积分基本定理我们有

```math
f_n(x) = f_n(x_0) + \int_{x_0}^{x} f_n' \,dt .
```

只要能证明 $f_n \to f$ 就大功告成。为此注意

```math
|f(x) - f_n(x)| = \left| c + \int_{x_0}^{x} g \,dt - f_n(x_0) - \int_{x_0}^{x} f_n' \,dt \right|
\;\le\; |c - f_n(x_0)| + \int_{x_0}^{x} |g - f_n'| \,dt
\;\le\; |c - f_n(x_0)| + (b - a)\, d(g, f_n') .
```

由于 $f_n(x_0) \to c$ 且 $d(g, f_n') \to 0$，结论得证。$\square$

> <span style="color:#1e8449;">**[note] Note（译者注，三个亮点）:**</span> **①求导问题的"化积分为方程"反转：**与 Theorem 2 不同，这里不能直接对 $f_n$ 求导取极限（导数的极限未必是极限的导数），而是**反过来造极限函数**：把目标导数 $g$ 积分一次定义出 $f$，再验证 $f_n$ 收敛到它。FTC 两次出场：先保证 $f' = g$，再给 $f_n$ 写出牛顿-莱布尼茨公式。**②度量的亮相：**最后一步的关键估计 $(b-a)\,d(g, f_n')$ 用的是 L11 的一致度量——$d(g, f_n') = \max_{t} |g(t) - f_n'(t)|$，一致收敛恰好就是 $d(g, f_n') \to 0$（上一节的命题在这里被默默使用）。**③条件的分工值得细读：**$f_n'$ 只需在一个点 $x_0$ 上收敛（$f_n(x_0) \to c$），加上 $f_n'$ 一致收敛、$f_n'$ 连续三个条件，就换来 $f_n$ 整体一致收敛 + 导数可交换。另外说明一个课堂实况：视频里本定理被顺延到了下一讲，讲义却已将它收录——🎥 *"I had wanted to do one more thing, but I don't have time to do that quite. So I'll pick up on that next time."*（翻译：我还想做一件事，但时间不够，下次接着讲。）以及 *"next time, I'll go through the one theorem I didn't get to, which is how to interchange the differentiation."*（翻译：下次我会讲那个没来得及讲的定理——如何交换求导。）读的时候把它当作 L20→L21 这条"幂级数流水线"的收官定理即可。

#### <span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">Example 1B: The exponential function satisfies E′ = E（例 1B：指数函数满足 E′ = E）</span>

设

```math
E_n(x) = \sum_{k=0}^{n} \frac{x^k}{k!} , \qquad E(x) = \sum_{k=0}^{\infty} \frac{x^k}{k!} .
```

则

```math
E_n'(x) = \sum_{k=1}^{n} \frac{k\,x^{k-1}}{k!} = \sum_{k=1}^{n} \frac{x^{k-1}}{(k-1)!} = E_{n-1}(x) .
```

由例 1 我们有 $E_{n-1} \to E$ 在 $[-L, L]$ 上一致收敛，且每个 $E_n$ 都连续。此外，对一切 $n$ 我们有

```math
E_n(0) = 1 = E(0) .
```

于是由 Theorem 3 可得

```math
E_n' = E_{n-1} \;\longrightarrow\; E'
```

是一致收敛的；又由于 $E_n' = E_{n-1}$，我们得到 $E' = E$。

> <span style="color:#1e8449;">**[note] Note（译者注，全课程的里程碑）:**</span> 这个一页的论证同时完成了三件事。**①验证定理 3 的三个条件各就各位：**$E_n(0) = 1 \to c = 1$（条件一）；导数列 $E_n' = E_{n-1}$ 在 $[-L, L]$ 上一致收敛到 $E$（条件二，直接继承例 1 的 M-判别法结论）；$E_n'$ 是多项式故连续（条件三）。**②得到全分析学最著名的微分方程：**$E' = E$ 且 $E(0) = 1$——指数函数被"刻画"出来了：它是唯一满足这个初值问题的函数。这条特征性质在 L09 就以级数面目出现过，如今升级为微分方程刻画；它正是 ODE $y' = y$ 的解。**③向前看的引线：**"求导与无限和交换次序"的技术在 L22 将用于一般幂级数（逐项求导、逐项积分），而"用不动点式论证解 ODE"的思路则通向 L23 的 Picard–Lindelöf 定理——本讲在函数空间 $C([a,b])$ 上建立的完备性（柯西完备）正是那里存在唯一性证明的地基。逐项求导时注意指标平移的细节：$\frac{k}{k!} = \frac{1}{(k-1)!}$，求和指标从 $k \ge 1$ 开始，平移后恰好得到 $E_{n-1}$——"求导把级数往左挪一格"，这是幂级数求导的标准心算。
